## §R1 Precise definition

A discrete discontinuity in the log-price path, distinct from Brownian diffusion. Lee–Mykland (2008) [documented] tests each return against a local diffusion scale; the regime is the *share* of variance from jumps: `J = 1 − BV/RV` (Barndorff-Nielsen–Shephard [documented]; BV = bipower variation). The individual-observation rejection threshold at size `α = 0.01` [documented] is the Gumbel 1%-quantile `4.6001` [documented]; the skeleton uses `4.5` [default] as its practical rounding. For the maximum over a full day of `n` tests, the paper's Gumbel-max critical value at 5-min sampling (`n = 78` [default]) is `8.944` [documented] (paper's formula applied in a Duke thesis — see §R10 lead note).

## §R2 Exact calculation

**Normative pseudocode** (prose is commentary; this block is normative):

```
function DETECT_JUMP_REGIME(bars, cfg, prev_state):
  # bars: canonical Events, newest last; causality: only bars with event_ts <= t
  1. assert bars are non-decreasing in event_ts                       # ordering [default]
  2. if any bar lacks r or r is non-finite → return (UNKNOWN, "invalid")          # F1, never interpolate
  3. if any bar.adj_flag != "split_adjusted" → return (DEGRADED, "unadjusted")    # corporate-action contract
  4. if len(bars) < cfg.min_bars → return (DEGRADED, "warming")                   # min_bars = 10 [default]
  5. r_i = ln(close_i / close_{i-1}) for i = 2..n                                 # 5-min log-returns [default]
  6. for each i:  σ_i = sqrt(π/2) · mean(|r_j| for j in {i-2,i-1,i+1,i+2})         # local diffusion scale [documented]
                  L_i = |r_i| / σ_i
                  jump_i = (L_i > c),  c = -ln(-ln((1-α)^(1/n_day))), α = 0.01 [default]
                  # skeleton: c ≈ 4.5 [default]; exact 4.6001 [documented]; day-max at 5-min = 8.944 [documented]
  7. RV = Σ r_i² ;  BV = (π/2) · Σ |r_i · r_{i-1}| ;  J = clamp(1 − BV/RV, 0, 1)  # [documented]
     if RV ≤ 0 → return (UNKNOWN, "degenerate")                                    # F2
  8. label = HYSTERESIS_LABEL(J, prev_state, cfg.jumpy_entry, cfg.jump_share_extreme, cfg.hysteresis)
  9. return RegimeState(regime_id="R005", state=label, value=J, estimator_version,
                        data_vintage, computed_at=newest event_ts, module_state="OK")

function HYSTERESIS_LABEL(J, prev, lo, hi, h):   # lo=0.10, hi=0.25, h=0.05 [default]
  if J is non-finite → return "degenerate"
  if prev in {None, "warming", "diffusion"}:
      return "jump_dominated" if J > hi else ("jumpy" if J >= lo else "diffusion")
  if prev == "jumpy":
      if J > hi: return "jump_dominated"        # entry: strictly greater
      if J < lo − h: return "diffusion"         # exit: inclusive on the offset band
      return "jumpy"                            # hold
  if prev == "jump_dominated":
      if J ≤ hi − h: return "jumpy" if J ≥ lo − h else "diffusion"  # single-step exit
      return "jump_dominated"                   # hold
```

Edge cases: missing bars → step 2 (`UNKNOWN`, mask, never interpolate); halts/auctions → freeze per §R0.6, discard contributions across reopen; zero-variance flat tape → step 7 (`UNKNOWN` via F2); unadjusted closes → step 3 (`DEGRADED`, label withheld — splits/dividends masquerade as jumps); `n_day` for the Gumbel max = bars per session (`78` at 5-min [default], `390` at 1-min [documented]).

**Threshold bands** (with hysteresis `h = 0.05` [default]; entry/exit semantics above):

| Condition (from diffusion) | Label | Tag |
|---|---|---|
| `J < 0.10` | diffusion | [default] |
| `0.10 ≤ J ≤ 0.25` | jumpy | [default] |
| `J > 0.25` | jump-dominated (gaps/halts dominate the variance budget) | [default] |

A 'jump regime' as jump-day frequency > `5`% [example] of days in a trailing window is illustrative. Production window: trailing `78` 5-min bars (one session) [default]; the fixture uses an expanding window for arithmetic illustration [example].

**Calibration recipe (normative):**

1. **Reference labels:** run exact Lee–Mykland on 1-min bars [default] (local vol from bipower variation of neighboring returns, Gumbel max-of-`n` critical value `c = −ln(−ln((1−α)^(1/n)))`, `α = 0.01` [documented], `n` = bars/day) over a calibration window; daily reference state via the same bands.
2. **Candidate grid** [example]: `jumpy_entry ∈ {0.05, 0.075, 0.10, 0.125, 0.15}`; `jump_share_extreme ∈ {0.20, 0.25, 0.30, 0.35, 0.40}`; `hysteresis ∈ {0.0, 0.02, 0.05}`; constraint `jump_share_extreme > jumpy_entry + hysteresis`.
3. **OOS selection criterion:** maximize macro-F1 of candidate states vs reference states on the validation segment; tie-break = fewest state flips per day (hysteresis preference); report flip-rate and per-state precision/recall.
4. **Split:** first `6` months calibration, next `6` months OOS validation [example]; minimum `60` jump-dominated days [example] in validation or the shipped band defaults are retained.
5. **Re-calibration cadence:** quarterly [example], or on feed schema change, symbol-set change, or flip-rate drift > `2`× [example] the calibrated baseline.
6. **Shipped defaults** (until calibrated): `jumpy_entry 0.10`, `jump_share_extreme 0.25`, `hysteresis 0.05` [default].

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Stop-based / latency-sensitive strategies | **inverts** | dies in jump-dominated states: slippage through stops; fills at dislocated prints — diffusion assumptions break |
| Gap-fade (overnight reversal) | **amplifies then inverts** | improves when jumps are isolated and liquidity returns; dies when jumps cluster (news regime) |
| Options market-making | **degrades** | jump risk reprices wings → widen quotes or withdraw |

## §R5 Cost interface: regime state → cost-function adjustment

Jump-dominated states blow up the adverse-fill leg: expected slippage through stops is modeled as a multiple of the stop distance, and few-bps edges are vetoed outright. The adjustment is consumed by T-chapter `expected_cost_bps(notional, adv_pct, venue, side, urgency)`: the **slippage leg** of the 4-component stack (spread/fees/borrow/impact) is multiplied by `slip_mult`, and the **fee-covering entry gate** is evaluated as `expected_cost_bps(...) * edge_mult <= k * edge_bps` (the regime marks up cost before the gate — `edge_mult > 1` [example] demands more edge).

```python
def cost_adjustment(rsv, base):
    """Normative: regime state -> cost-function adjustment (§R5)."""
    adj = dict(base)
    adj['trade_ok'] = True
    adj['slip_mult'] = 1.0   # [default] multiplier on the slippage leg
    adj['edge_mult'] = 1.0   # [default] markup on cost in the fee-covering gate
    if rsv['state'] == 'jump_dominated':
        adj['trade_ok'] = False   # diffusion assumptions broken: veto before costing
        adj['slip_mult'] = 5.0    # [example] expected slippage through stops
    elif rsv['state'] == 'jumpy':
        adj['slip_mult'] = 2.0    # [example]
        adj['edge_mult'] = 1.5    # [example] demand more edge before trading
    return adj
```

`trade_ok = False` short-circuits costing entirely (veto); otherwise the T-chapter's `expected_cost_bps` call is wrapped as above. Which components scale: slippage leg only (spread/fees/borrow pass through unscaled); the gate markup applies to total expected cost.
