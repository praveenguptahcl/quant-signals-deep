## §R1 Precise definition

A discrete discontinuity in the log-price path, distinct from Brownian diffusion. Lee–Mykland (2008) [documented] tests each return against a local diffusion scale; the regime is the *share* of variance from jumps: `J = 1 − BV/RV` (Barndorff-Nielsen–Shephard [documented]; BV = bipower variation).

## §R2 Exact calculation

Test statistic: $L_i = |R_i| / \hat{\sigma}_i$; reject 'no jump at i' when $L_i$ exceeds the Gumbel-normalized threshold at size `α = 0.01` [documented]; practical skeleton: standardized return `> 4.5` [documented] with bipower-variation local vol.

$$J = 1 - \frac{BV}{RV}, \qquad BV = \frac{\pi}{2}\sum |r_i r_{i-1}| \quad\text{[documented]}$$

Reference implementation is a documented-limitation skeleton: LM is a high-frequency test; the daily proxy is coarse by design.

**Data inputs.** intraday log-returns (5-min bars [default]); local-vol window of neighboring returns.

**Cadence.** daily (from intraday bars); intraday flag on detection.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `J < 0.1` | diffusion | [example] |
| `0.1 ≤ J ≤ 0.25` | jumpy | [example] |
| `J > 0.25` | jump-dominated (gaps/halts dominate the variance budget) | [example] |

Bands are `[example]`. A 'jump regime' as jump-day frequency > `5`% of days in a trailing window is illustrative.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Stop-based / latency-sensitive strategies | **inverts** | dies in jump-dominated states: slippage through stops; fills at dislocated prints — diffusion assumptions break |
| Gap-fade (overnight reversal) | **amplifies then inverts** | improves when jumps are isolated and liquidity returns; dies when jumps cluster (news regime) |
| Options market-making | **degrades** | jump risk reprices wings → widen quotes or withdraw |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** runs Lee–Mykland on 5-min bars; publishes RSV with the jump flag.
- **Verifier:** uses BNS `J` as the second estimator; states must agree within ±`0.10` [example] or `UNKNOWN`.
- **Grok-Researcher:** proposes thresholds; leads only.
- **Adversary:** checks the flag is never used predictively; Gate rejects any chapter that trades 'predicted jumps'.
- **Gate:** rejects any chapter that classifies the jump bar as a regime during the bar (lookahead); LM-on-daily chapters are quarantined as coarse proxies.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Jump-dominated states blow up the adverse-fill leg: expected slippage through stops is modeled as a multiple of the stop distance, and few-bps edges are vetoed outright.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'jump_dominated':
        adj['trade_ok'] = False     # diffusion assumptions broken
        adj['slip_mult'] = 5.0      # [example] slippage through stops
    elif rsv['state'] == 'jumpy':
        adj['slip_mult'] = 2.0      # [example]
        adj['edge_mult'] = 1.5      # [example] demand more edge
    else:
        adj['slip_mult'] = 1.0      # [default]
    return adj
```
