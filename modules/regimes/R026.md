### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Whether inflation prints are surprising up or down: the standardized surprise `z = (actual − consensus) / σ_surprises` on CPI/PPI/PCE releases, plus the 5y5y breakeven 20-day change as a slow-moving confirm. The regime exists only in a tight window around the print — before it the state is pre-release compression, after it repricing/digestion — and the label flips only *after* the `08:30` ET print, never before. Entry uses `z_hot`; exit uses the lower `z_cool` (hysteresis): once HOT, the label persists while `z ≥ z_cool`, so boundary prints do not flicker the gated strategies.

### §R2.1 Normative detection pseudocode

The pseudocode below is normative; prose is commentary. It mirrors the
reference implementation exercised by `test_cmd`.

```
# detect(state, events, cfg) -> RegimeState
# state = {surprises: list[float]  # trailing as-published surprises, oldest first
#          last: HOT|COLD|NEUTRAL|null, last_value: float|null}
# events: canonical Events, ascending event_ts. cfg: §R0.2 Config.
# All guards run BEFORE history append — a rejected row never poisons σ.

on_event(e):
  ts = int(e.event_ts)                      # integer parse only (§R0.4 rule)
  ms = e.market_state or CONTINUOUS_TRADING
  if ms == HALTED:                          # freeze; discard across reopen
      emit(label=state.last or UNKNOWN, value=state.last_value or NaN,
           module_state=UNKNOWN); return
  if ms == AUCTION:                         # no new labels; hold last
      emit(label=state.last or UNKNOWN, value=state.last_value or NaN,
           module_state=DEGRADED); return
  if ms == CLOSED:
      emit(module_state=OFF); return
  (y, C) = (e.actual, e.consensus)           # same convention, as-published vintage
  if not finite(y) or not finite(C):         # F1: missing / unparseable
      emit(UNKNOWN, NaN, module_state=UNKNOWN); return
  if e.consensus_vintage_ns >= ts:           # leak guard: strictly before release
      emit(UNKNOWN, NaN, UNKNOWN); alert(page, "consensus-vintage leak"); return
  s = y - C
  if finite(e.vendor_actual) and |e.vendor_actual - y| > cfg.dual_tol_pp:  # F3
      emit(UNKNOWN, NaN, UNKNOWN); alert(page, "dual disagreement"); return
  if cfg.sigma_override is not None:
      sigma = cfg.sigma_override            # operator asserts σ; history gate bypassed
  else:
      state.surprises.append(s)
      if len(state.surprises) < cfg.min_history:        # F1: insufficient history
          emit(UNKNOWN, NaN, UNKNOWN); return
      sigma = stdev(state.surprises[-cfg.L:], ddof=1)   # §R3.1 estimator
  if not finite(sigma) or sigma <= 0:        # F2: σ collapse
      emit(UNKNOWN, NaN, UNKNOWN); alert(page, "sigma non-positive"); return
  z = s / sigma
  if not finite(z) or |z| > cfg.z_abs_max:   # F2: bounds
      emit(UNKNOWN, NaN, UNKNOWN); alert(page, "z out of bounds"); return
  label = transition(z, state.last or NEUTRAL, cfg)
  state.last, state.last_value = label, z
  emit(label=label, value=z, module_state=OK, estimator_version,
       data_vintage, computed_at=ts, min_lag_bars=cfg.min_lag_bars)

transition(z, prev, cfg):                    # hysteresis state machine
  if z >=  cfg.z_hot:  return HOT
  if z <= -cfg.z_hot:  return COLD
  if prev == HOT  and z >=  cfg.z_cool: return HOT   # latch through the cool band
  if prev == COLD and z <= -cfg.z_cool: return COLD
  return NEUTRAL
```

### §R2.2 Edge cases (normative)

- **Missing bars (breakeven confirm):** a missing 5y5y day is masked — the
  confirm is marked stale, the surprise label is unaffected, never interpolated.
- **Halts:** per the market-state table; contributions across a reopen are discarded.
- **Corporate actions:** not applicable to CPI prints. The structural-break
  analog is a **BLS methodology/weight revision**: on a `methodology_break`
  event, flush `state.surprises`, require an operator `sigma_override` (logged),
  and emit `DEGRADED` for `recal_releases` = `6` [default] releases; then
  re-run the §R3.1 recipe before returning to the estimator path.
- **Late / duplicate release events:** idempotent on `release_id`; duplicates are ignored.
- **Clock:** `event_ts` is authoritative for causality; `consensus_vintage_ns`
  is the as-of clock for the freeze discipline.

## §R3 Exact calculation

Per release `r`, with actual `y_r` and pre-release consensus `C_r` in the same
convention (YoY or MoM percent), as-published vintage:

$$s_r = y_r - C_r, \qquad z^{\pi}_r = \frac{s_r}{\sigma^{\pi}_L}$$

$\sigma^{\pi}_L$ is the sample standard deviation (`ddof=1`) of `s` over the
trailing `L = 12` releases [default], estimated per the §R3.1 recipe (or
operator-asserted via `sigma_override`). Confirm (slow): `ΔBE_20d = BE_t − BE_{t−20}` on the
5y5y breakeven (FRED T5YIFR, daily [documented]). Worked check: actual `3.5`%, consensus `3.1`%,
`σ = 0.25`% [example] → `s = 0.4` pp, `z = 1.6` — a large positive surprise
(hawkish). The surprise construction is the standard z-score (textbook).

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** BLS CPI-U (or core) release actual, as-published; pre-release consensus median frozen at `08:29` ET [example freeze time] with a vintage timestamp; trailing `12`-release surprise σ [default]; 5y5y breakeven daily series.

**Cadence.** Event-driven on release days (CPI `08:30` ET [documented release time]); breakeven monitor daily.

**Threshold bands (hysteresis).**

| `z` | Label | Tag |
|---|---|---|
| `≥ +z_hot` (`1.5` [default]) | HOT (hawkish) — entry, inclusive | [default] |
| `≤ −z_hot` | COLD (dovish) — entry, inclusive | [default] |
| prev HOT and `z ≥ +z_cool` (`0.75` [default]) | HOT persists (latch) | [default] |
| prev COLD and `z ≤ −z_cool` | COLD persists (latch) | [default] |
| otherwise | NEUTRAL | [default] |

A HOT print followed by a merely warm `z = 1.2` [example] stays HOT — the
gated strategy is not whipsawed by boundary prints. Recalibrate every
`[default]`-tagged band per instrument with the recipe below before
production use.

### §R3.1 Detection-calibration recipe (normative)

No magic numbers: every `[default]` threshold above must be re-derivable from
this recipe. Ship the recipe's chosen config plus its OOS report with the module.

1. **Calibration dataset.** Vintage-correct panel: BLS as-published actuals +
   vendor consensus frozen `≤` release `− 1` min, CPI/PPI/PCE monthly, `≥ 5`
   years [default] (`≈60` monthly releases — arithmetic); breakeven T5YIFR daily
   for the confirm [documented]. Reject any row whose consensus vintage is not
   strictly before the release timestamp (leak guard, F5).
2. **Grid.** `z_hot ∈ {1.0, 1.25, 1.5, 1.75, 2.0}` [default];
   `z_cool ∈ {0.5, 0.75, 1.0}` [default] subject to `z_cool ≤ z_hot − 0.5`
   [default]; `L ∈ {6, 9, 12, 18, 24}` [default];
   `window_min ∈ {5, 15, 30, 60}` [default]; `min_history` fixed at `6`
   [default]; `dual_tol_pp` per vendor rounding spec.
3. **OOS objective.** For each config, run the reference gated pair (a rates/FX
   intraday reaction strategy, gated vs ungated): metric = out-of-sample
   after-cost `ΔSharpe` (gated − ungated) on release-window trades only;
   require `≥ 30` OOS release events [default]. Select the config maximizing
   `ΔSharpe` subject to Deflated Sharpe Ratio significance over the grid as
   the trial count (Bailey & López de Prado 2014 [documented]).
   Report the variant count, or "not computed".
4. **Walk-forward.** Expanding window anchored at `≥ 24` releases [default];
   event embargo: drop releases within `±1` release of each train/test
   boundary [default] (event embargo, not day embargo); refit quarterly
   [default]. No ex-post period selection (F5).
5. **Re-cal cadence.** Quarterly [default]; immediate re-calibration on BLS
   methodology revision or consensus-vendor freeze-semantics change
   (structural break → flush history, `DEGRADED` for `6` releases [default]).

| `borrow_mult` | borrow bps/day leg | `1.0` | [default] — reason: gated rates/FX intraday holds carry no overnight stock borrow |
| `fee_add_bps` | additive fee leg | `0.0` | [default] — reason: venue fee schedules do not change on CPI days |

**Multiplier calibration recipe (normative until measured).**
`spread_mult` = median quoted spread in `[release, release + window_min)` ÷
median quoted spread in `[release − 30min, release)` on the venue [default
recipe]; `impact_mult` from an implementation-shortfall regression on
release-window fills [default recipe]. Until measured, `4.0`/`2.0` remain
[example] and must not be presented as venue facts.

**Side applicability.** The record applies to `taker` and `mixed` sides. For
maker-heavy gated strategies the spread leg is mostly adverse selection, not
quoted spread — substitute an adverse-selection add-on calibrated per venue
[unverified — calibrate] rather than `spread_mult`.

**Application rule (normative).** For a trade at `ts` on a release with
timestamp `rel`: if `rel ≤ ts ≤ rel + window_min × 60`s [default] and the label
is HOT/COLD, apply that label's record; outside the window the record is
identity (NEUTRAL). If the label is `UNKNOWN`, apply the HOT record —
restrictive default [default]. Every application is decision-logged with
`estimator_version` and `data_vintage` (Appendix g v1.0.0).
