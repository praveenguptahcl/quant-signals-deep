# R016 — Fragmentation / off-exchange regime

Share of volume executing off-exchange: `OffEx% = TRF volume / consolidated volume` (FINRA ATS + non-ATS transparency data). High off-exchange share = the displayed book is a worse map of true liquidity — the lit quotes get stubbier as price discovery migrates. Labels are assigned with **entry/exit hysteresis** (narrow band around each cut) so the regime does not flap on boundary noise. Provenance **[D]**.

### R0.2.1 Calibration recipe (per parameter — grid + OOS selection, no hand-tuning in production)

- `window_bars` (`10` [default]): grid `{5, 10, 21}` [example]; data: ≥ `2` years [default] of daily venue-flagged volume (name-level or universe aggregate; Massive Starter gives `5` years [documented]); selection: minimize the OOS label-flip rate (flips per `100` name-days [example]) subject to the constraint that a fragmentation regime persists ≥ `1`× window before it gates downstream; freeze before any forward use. - `dark_exit`/`lit_exit` (derived via hysteresis half-width `0.01` [default] each side): grid half-width `{0.005, 0.01, 0.015}` [example]; objective: OOS flip rate < `2` flips per `100` name-days [example] while retaining ≥ `90`% [example] of the no-hysteresis `dark_dominated` name-days; re-calibrated together with the entries [default]. Sensitivity: medium.
- `dual_tol` (`0.05` [default]): set to the `99`th percentile [default] of `|mean-of-ratios − aggregate-ratio|` on clean validation history (measures bar-size heterogeneity); verified by synthetic TRF-mislabel injection — the F3 trip must catch ≥ `99`% [example] of injected mislabels. ## §R1 Precise definition

Off-exchange share `OfEx_t = V^{TRF}_t / (V^{TRF}_t + V^{lit}_t)` [documented]; ATS-only share from the lagged weekly FINRA file is a subset [documented]. Sentinel: trailing-window mean of per-bar `OfEx` (`window_bars = 10` [default]). Verifier: aggregate share ratio `ΣV^{TRF} / ΣV^{total}` over the same unmasked window — FINRA's published-aggregate convention; absolute agreement tolerance `0.05` [default].

## §R2 Exact calculation

$$\text{OfEx}_t = \frac{V^{TRF}_t}{V^{TRF}_t + V^{lit}_t} \quad\text{[documented]}$$

$$v_t = \frac{1}{\min(W, n_t)}\sum_{i \in \text{window}(t)} \text{OfEx}_i \quad\text{[default]}$$

where `W = window_bars` (`10` [default]) and `window(t)` contains only
unmasked bars (zero-total or halted bars are excluded, never interpolated).

Worked example [documented Grok RB2]: lit `32.0m`, TRF `28.0m` → `OfEx = 0.467` ⇒ high vs own median. Bands [example — re-anchor per §R0.2.1; aggregate off-exchange reached `52.27`% in Oct 2025 [documented Rosenblatt]]: `< 0.35` lit-dominated · `0.35–0.45` normal · `> 0.45` dark-dominated.

**Data inputs.** consolidated tape with venue/TRF flags (§R0.3); weekly FINRA ATS file for the ATS split (reconciliation only, never a daily feature).

**Cadence.** weekly (FINRA); daily TRF proxy.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `v < 0.35` (strict entry; exit at `> 0.37`) | lit-dominated | [example] |
| `0.35–0.45` | normal (US large-cap norm) | [example] |
| `v > 0.45` (strict entry; exit at `< 0.43`) | dark-dominated (lit book is stubbier) | [example] |

The hysteresis bands (`0.02` [default] half-width) are part of the detector, not decoration: without them a value hovering at `0.45` flips the label every bar.

**Normative detection pseudocode** (pseudocode is normative; prose is commentary):

```python
def detect(state, events, cfg):          # events: canonical Bars, newest last
    bars = [e for e in events if e.market_state == CONTINUOUS_TRADING]
    # F1: negative legs or missing fields -> UNKNOWN, never interpolate
    if any(e.lit is None or e.trf is None or e.lit < 0 or e.trf < 0 for e in bars):
        return RegimeState("R016", "invalid", NaN, UNKNOWN)
    # Edge case: zero-total or halted bars are MASKED (excluded from the window)
    ratios = [e.trf / (e.lit + e.trf) for e in bars
              if (e.lit + e.trf) > 0 and not e.halted]
    if len(ratios) == 0:
        return RegimeState("R016", "missing", NaN, UNKNOWN)      # F1: nothing usable
    if len(ratios) < cfg.warmup_bars:                             # [default] 5
        return RegimeState("R016", "warming", mean(ratios), DEGRADED)  # label withheld
    v = mean(ratios[-cfg.window_bars:])                           # [default] 10
    if not (0.0 <= v <= 1.0):
        return RegimeState("R016", "out_of_bounds", v, UNKNOWN)  # F2
    # Hysteresis over the CAUSAL state path: replay per-prefix, never future data
    prev = state.last_label                                       # None on cold start
    label = transition(prev, v, cfg)
    # F3: Verifier = aggregate share ratio over the same unmasked window
    v2 = sum_trf(window) / sum_total(window)
    if abs(v - v2) > cfg.dual_tol:                                # [default] 0.05
        return RegimeState("R016", label, v, UNKNOWN)
    if now_ns() - computed_at > 3 * CADENCE:                     # F4 staleness
        return RegimeState("R016", label, v, UNKNOWN)
    return RegimeState("R016", label, v, OK)

def transition(prev, v, cfg):
    """Strict entry, wider exit band: no flapping at the boundary."""
    if prev == "dark_dominated":
        return "normal" if v < cfg.dark_exit else "dark_dominated"   # exit: strictly below 0.43 [default]
    if prev == "lit_dominated":
        return "normal" if v > cfg.lit_exit else "lit_dominated"     # exit: strictly above 0.37 [default]
    if v > cfg.dark_entry:                                          # entry: strictly above 0.45 [default]
        return "dark_dominated"
    if v < cfg.lit_entry:                                           # entry: strictly below 0.35 [default]
        return "lit_dominated"
    return "normal"
```

**Edge cases (normative).** Missing bars → masked, never interpolated (F1). Trading halts → the halted bars are masked and contributions are discarded across reopen (§R0.6). Corporate actions → the ratio is invariant under splits (a `2:1` split doubles both legs; test-pinned) so no adjustment is needed; dividends do not touch volume. Late/corrected prints → ordered by `event_ts` (not `asof_ts`); corrections replace the original print. Vendor venue-code changes → the §R0.3.1 entitlement assertion (`TRF_set ∪ lit_set == consolidated total`) must pass or the module goes `UNKNOWN`. Bars with `event_ts` in the future → rejected (F1).

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** trailing-window mean of per-bar OffEx from the daily TRF proxy; publishes RSV with `data_vintage` (proxy date vs FINRA file week).
- **Verifier:** aggregate share ratio `ΣV^{TRF}/ΣV^{total}` over the same window; monthly reconciliation against FINRA ATS + OTC monthly files — the ATS file must not overwrite same-day TRF proxy values [documented Grok RB2].
- **Grok-Researcher:** proposes windows and bands; leads only.
- **Adversary:** checks TRF is not labeled 'dark pool'; checks vintage tags are honored; oscillates synthetic `v` across `0.45`/`0.43` [default] and asserts the label does not flap (hysteresis); injects TRF mislabels and asserts F3 trips.
- **Gate:** rejects real-time treatment of lagged ATS data; rejects lit-only impact models in dark-dominated states; rejects hardcoded TRF letter codes without a documented vendor mapping.
- **F1–F5 instantiated:** F1 missing/stale/invalid → `UNKNOWN` (restrictive downstream); masking — never interpolation;
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Fragmentation changes *where* liquidity is, not its price: the adjustment routes flow (midpoint/conditional/SOR) and widens the lit-book depth assumption. Components scaled per the 4-component stack (spread / fees / borrow / impact); borrow is untouched.

```python
def cost_adjustment(rsv, base):
    # base: 4-component stack in bps:
    #   {spread_bps, fee_bps, borrow_bps, impact_bps} [documented units]
    adj = dict(base)
    adj['borrow_bps'] = base['borrow_bps']      # unaffected [default]
    adj['trade_ok'] = True
    if rsv['state'] == 'dark_dominated':
        adj['route'] = 'midpoint_or_conditional'        # [default]
        adj['spread_bps'] = base['spread_bps'] * 1.25   # [example] lit book stubbier: displayed spread wider
        adj['impact_bps'] = base['impact_bps'] * 1.50   # [example] lit lambda degraded: do not work lit
        adj['fee_bps']    = base['fee_bps'] * 0.50      # [example] midpoint/ATS fills avoid the lit taker fee
        adj['lit_depth_mult'] = 0.5                     # [example] capacity haircut on lit-book depth
    elif rsv['state'] == 'lit_dominated':
        adj['route'] = 'lit_aggressive'                 # [default]
    else:  # normal
        adj['route'] = 'sor_blend'                      # [default]
    return adj
```

| Cost component | dark_dominated | lit_dominated | normal | Rationale |
|---|---|---|---|---|
| spread | ×`1.25` [example] | ×`1.0` [default] | ×`1.0` [default] | displayed book is stubbier when flow migrates off-exchange |
| impact | ×`1.50` [example] | ×`1.0` [default] | ×`1.0` [default] | lit λ degrades; route away from lit |
| fees | ×`0.50` [example] | ×`1.0` [default] | ×`1.0` [default] | midpoint/ATS fills avoid lit taker fees |
| borrow | unchanged [default] | unchanged [default] | unchanged [default] | fragmentation does not move borrow |
| capacity | `lit_depth_mult = 0.5` [example] | `1.0` [default] | `1.0` [default] | halve the lit-book depth assumption |

Calibrate the multipliers on the desk's own fill data (spread realized vs quoted, lit vs midpoint fill rates); the `[example]` values are starting points, not fitted constants.
