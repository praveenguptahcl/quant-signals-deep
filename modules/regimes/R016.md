### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; FINRA vintage is ~2 weeks stale — the RSV carries the vintage tag; never presented as intraday [documented]).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Off-exchange share `OfEx_t = V^{TRF}_t / (V^{TRF}_t + V^{lit}_t)` [documented]; ATS-only share from the lagged weekly FINRA file is a subset [documented]. Cross-check: median vs mean; absolute tolerance `0.05` [default].

## §R2 Exact calculation

$$\text{OfEx}_t = \frac{V^{TRF}_t}{V^{TRF}_t + V^{lit}_t} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: lit `32.0m`, TRF `28.0m` → `OfEx = 0.467` ⇒ high vs own median. Bands [example]: `< 0.35` lit-dominated · `0.35–0.45` normal · `> 0.45` dark-dominated.

**Data inputs.** consolidated tape with venue/TRF flags; weekly FINRA ATS file for the ATS split.

**Cadence.** weekly (FINRA); daily TRF proxy.

| `0.35–0.45` | normal (US large-cap norm) | [example] |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** ingests FINRA weekly files (vintage-tagged); publishes RSV.
- **Verifier:** TRF-proxy daily cross-check; the ATS file must not overwrite same-day TRF [documented Grok RB2].
- **Grok-Researcher:** proposes windows; leads only.
- **Adversary:** checks TRF is not labeled 'dark pool'; checks vintage tags are honored.
- **Gate:** rejects real-time treatment of lagged ATS data; rejects lit-only impact models in dark-dominated states.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Fragmentation changes *where* liquidity is, not its price: the adjustment routes flow (midpoint/conditional/SOR) and widens the lit-book depth assumption — the cost of trading against a stub book.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'dark_dominated':
        adj['reroute'] = True         # [default] midpoint/conditional/SOR
        adj['lit_depth_mult'] = 0.5   # [example] stub book
        adj['spread_mult'] = 1.25     # [example]
    else:
        adj['reroute'] = False        # [default]
        adj['lit_depth_mult'] = 1.0   # [default]
        adj['spread_mult'] = 1.0      # [default]
    return adj
```
