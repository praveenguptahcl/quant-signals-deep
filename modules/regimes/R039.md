## §R2 Precise definition

Max-pain pinning: the strike K* minimizing total option-holder payout Π(K) = Σ max(0, K−K_i)·P_i + Σ max(0, K_i−K)·C_i [example formula] acts as gamma gravity into expiry. State PIN when spot is within `0.5`% [example] of K*. Max-pain is descriptive, not causal — the pin holds only if dealer positioning matches the assumption.

## §R3 Exact calculation

Chain strikes `K_i`, put OI `P_i`, call OI `C_i`:

$$\Pi(K) = \sum_i \max(0, K-K_i)\,P_i + \sum_i \max(0, K_i-K)\,C_i, \qquad
K^* = \arg\min_K \Pi(K)$$

Pin flag: `PIN_t = 1[|S_t − K^*| / S_t ≤ 0.005]` [example]. Worked check
(spot `100`, OI in thousands): `Π(96) = 460`, `Π(98) = 260`, `Π(100) = 160`,
`Π(102) = 260`, `Π(104) = 460` [example chain] → `K^* = 100`, pin distance
`0` → PIN.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*
