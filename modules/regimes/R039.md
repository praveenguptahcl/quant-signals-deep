## §R2 Precise definition

Max-pain pinning: the strike K* minimizing total option-holder payout Π(K) = Σ max(0, K−K_i)·P_i + Σ max(0, K_i−K)·C_i [example formula] acts as gamma gravity into expiry. Labels use hysteresis: enter PIN when pin distance `≤ 0.005` [example], exit only when distance `> 0.008` [example] — the band between is the hysteresis zone where the previous label holds (no flip-flopping on noise). Max-pain is descriptive, not causal — the pin holds only if dealer positioning matches the assumption.

**Normative detection pseudocode** (pseudocode is normative; prose is commentary):

```
function detect(state, events, cfg):
  # state = {k_star, label ∈ {OFF, WATCH, PIN}, ts}; events ascending event_ts
  for each row in events:
    if row.event_type == "HALT":                       # §R0.5 HALTED
      emit RegimeState(state=UNKNOWN, value=state.k_star ?? NaN,
                       module_state=UNKNOWN)           # freeze; never interpolate
      continue                                         # discard contributions across reopen
    if row.event_type == "SPLIT":                       # corporate action
      f = parse(row.factor)
      if not finite(f) or f <= 0 or state.k_star is None:
        emit RegimeState(state=UNKNOWN, module_state=UNKNOWN); continue
      v = state.k_star * f                             # rebase cached chain
      d = |row.spot − v| / row.spot
      label = transition(state.label, d, cfg)
      state = {k_star: v, label: label, ts: row.ts_ns}
      emit RegimeState(state=label, value=v, module_state=DEGRADED, ...)
      continue
    accumulate row into current snapshot group keyed by ts_ns
  on snapshot boundary (new ts_ns, control row, or end of events):
    rows = snapshot rows at ts
    if any strike/call_oi/put_oi non-finite, or spot non-finite, or spot <= 0:
      emit RegimeState(state=UNKNOWN, module_state=UNKNOWN)   # F1/F2
      continue
    lo, hi = min(strikes), max(strikes)
    if spot < lo/2 or spot > hi*2:                     # corporate-action guard, [default] band
      emit RegimeState(state=UNKNOWN, module_state=UNKNOWN)   # F2; page
      continue
    K* = argmin over snapshot strikes of Π(K)          # §R3
    d  = |spot − K*| / spot
    label = transition(state.label, d, cfg)
    state = {k_star: K*, label: label, ts: ts}
    emit RegimeState(state=label, value=K*, module_state=OK,
                     estimator_version, data_vintage, computed_at=ts)

function transition(prev, d, cfg):                    # hysteresis, §R3 bands
  if prev == "PIN":  return "PIN" if d <= cfg.pin_tol_exit  else "WATCH"   # exit strict
  return "PIN" if d <= cfg.pin_tol_entry else "WATCH"                      # entry inclusive
```

**Edge cases (normative):** empty events → single `UNKNOWN` (F1); a snapshot
with zero rows emits nothing and the F4 staleness watchdog expires the last
label downstream; non-finite OI/spot or `spot ≤ 0` → `UNKNOWN`, never
interpolate (F2); halt rows freeze the cached `k_star` and emit `UNKNOWN` —
the label after reopen is computed from the fresh snapshot only (no
contributions carried across the halt); a `SPLIT` row rescales the cached
`k_star` by `factor` and emits `DEGRADED` until the next full snapshot restores
`OK`; an unannounced split (no `SPLIT` event) is caught by the `2`× strike-band
guard [default] → `UNKNOWN` + page; dual-estimator disagreement on K* (F3)
→ `UNKNOWN`.

## §R3 Exact calculation

Chain strikes `K_i`, put OI `P_i`, call OI `C_i`:

$$\Pi(K) = \sum_i \max(0, K-K_i)\,P_i + \sum_i \max(0, K_i-K)\,C_i, \qquad
K^* = \arg\min_K \Pi(K)$$

Worked check on the fixture chain [example chain — arithmetic hand-verified]:
strikes `96, 98, 100, 102, 104`; call OI `10, 30, 60, 40, 50`; put OI
`50, 40, 20, 30, 10`; spot `100`:
`Π(96) = 940`, `Π(98) = 680`, `Π(100) = 560`, `Π(102) = 600`,
`Π(104) = 780` → `K^* = 100`, pin distance `0` → PIN.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Strike-level call/put open interest; underlying spot; expiry calendar.

**Cadence.** Daily in expiry week.

**Threshold bands (hysteresis).**

| pin distance `d = \|spot − K*\| / spot` | Label | Tag |
|---|---|---|
| `d ≤ 0.005` from WATCH/OFF | enter PIN (inclusive) | [example] |
| `0.005 < d ≤ 0.008` | hold previous label (hysteresis zone) | [example] |
| `d > 0.008` from PIN | exit to WATCH (strict) | [example] |

**Calibration recipe (normative before production use — no magic numbers ship).**

1. **Data:** `≥ 12` months [example] of daily OI chain snapshots + spot for the
   target underlying, covering all expiry weeks; hold out the most recent
   `2` expiry weeks [example] as OOS.
2. **Grid:** entry ∈ {`0.003`, `0.005`, `0.0075`, `0.01`} [example];
   exit = entry × {`1.4`, `1.6`, `2.0`} [example]; the invariant
   `exit > entry` is asserted, never violated.
3. **Objective:** on OOS expiry weeks, agreement between PIN labels and
   realized expiry-day pinning (spot closes within the entry band of K* on
   expiry Friday) — maximize F1 [example]; tie-break toward the wider exit
   band (fewer label flips).
4. **Selection:** argmax on OOS only; in-sample is diagnostic, never selection
   (F5). Record the calibration report ID; replace the `[example]` tags on the
   shipped bands with `[measured]` + report ID.
5. **Re-cal cadence:** quarterly [default]; plus event-driven re-cal on
   OI-snapshot schema/vendor change, or after `2` consecutive expiry weeks
   [example] with zero PIN labels (regime-death tripwire → notify, do not
   silently widen bands).

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

```python
COST_ADJUSTMENT_R039 = {"regime_id": "R039", "version": "1.1.0", "PIN": {"spread_mult": 1.0, "impact_mult": 0.7, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[example]"}, "WATCH": {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[default]"}}
```

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when |
|---|---|---|---|---|---|
| PIN | `1.0` | `0.7` | `1.0` | `0.0` | inside the pin window (`d ≤ pin_tol_entry`) — pinned expiry-week tape compresses realized range, lowering market impact [example] |
| WATCH | `1.0` | `1.0` | `1.0` | `0.0` | identity [default] |

**Which components scale and why.** Only **impact** scales in PIN: gamma
gravity compresses the realized intraday range into expiry, so a given
participation rate moves the tape less — `0.7`× [example] is the placeholder
until venue-calibrated (calibrate per venue; replace with `[measured]`).
**Spread** does not scale (`1.0`× [example]): no documented systematic spread
compression at the pin — expiry-week spreads are often *wider* on retail
flow, so claiming a discount would be dishonest. **Borrow** does not scale
(`1.0`× [example]): pinning has no mechanism on stock-loan rates.
**Fees** do not change (`0.0` bps [example]): exchange/regulatory fees are
schedule-driven, unaffected by regime state.

**Application rule.** Apply the PIN record only when `state == PIN` and the
label's pin distance `d ≤ pin_tol_entry`; otherwise identity. The record is
versioned with `estimator_version` and every application is decision-logged
(Appendix g v1.0.0). All multipliers `[example]` unless tagged otherwise —
calibrate per venue before production.
