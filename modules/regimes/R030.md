## §R2 Precise definition

Trading-day distance to the next scheduled FOMC/ECB/BOJ decision: pre-event drift/compression vs event-day repricing vs post-event digestion. Documented facts: equities drift up `+49` bp in the 24 hours before scheduled FOMC vs `~4` bp on a normal day, 1994–2011 (Lucca–Moench (2015) [documented]); the drift is limited to announcements with press conferences and begins at the prior-day market open (Boguth–Gregoire–Martineau (2019) [documented via Kurov–Wolfe–Gilbert survey]); the drift has substantially weakened since January 2016 (Kurov–Wolfe–Gilbert [documented]) — the drift window is a *compression* regime now, not a tradable drift; volume falls before and rises after (Zhu/BIS lineage, per Grok [unverified]); the 30-minute statement window (T−10m to T+20m) is the high-frequency identification convention (Gürkaynak–Sack–Swanson (2005) [documented]); realized volatility jumps at the statement release while pre-announcement vol/liquidity are lower (Lucca–Moench NY Fed Staff Report 512 §3.5 [documented]).

### §R2.1 Normative detection pseudocode (pseudocode is normative; prose is commentary)

```
# detect(state, events, cfg) -> RegimeState
# state: module-owned, persists prev_label across calls ("FAR" on cold start)
# cfg: drift_lo=2.0 [calibrate], drift_hi=25.0 [calibrate], pre_lo=0.5 [calibrate],
#      shock_exit=-0.02 [calibrate], h=0.5 [calibrate], min_lag_bars=1 [default]

function detect(state, events, cfg):
    if events is empty:
        return RegimeState(state="UNKNOWN", module_state="UNKNOWN")   # F1
    e = last event at-or-before now with event_ts in [now - 2 trading days, +inf]
    cal = latest calendar snapshot with vintage <= now
    if cal is missing:                    return UNKNOWN + page          # F1
    if cal.vintage older than 400 days:   return UNKNOWN + notify        # F4
    if now is an exchange holiday per NYSE calendar and e.event_ts is today:
        return UNKNOWN + page                                          # F3
    market_state = current market-state value (§R0.5)
    if market_state == HALTED:
        return UNKNOWN, prev_label frozen                               # freeze
    if market_state == CLOSED:
        module_state = OFF; emit nothing; return
    if market_state == AUCTION:
        return last label, module_state=DEGRADED                        # hold
    T* = e.event_ts                      # announcement timestamp
    if |T* - scheduled_time| > 15 min:    # adversary check [default]
        module_state = DEGRADED; page; T* = observed time; recalibrate schedule
    tau = trading_day_distance(now, T*)   # §R2.2; intraday fractional on event day
    if tau is uncomputable (bad dates, inverted):  return UNKNOWN       # F1/F2
    if not isfinite(tau):                            return UNKNOWN       # F2
    # corporate actions: no-op — tau is calendar-based, unaffected by splits/dividends
    label = hysteresis_transition(state.prev_label, tau, cfg)           # §R2.3
    state.prev_label, state.tau_days, state.next_event = label, tau, T*
    cost_rec = COST_ADJUSTMENT_R030[label_bucket(label)]                # §R5
    assert gated trades only at t+1 or later                            # Lag contract
    return RegimeState(regime_id="R030", state=label, value=tau,
                       estimator_version="1.1.0", data_vintage=cal.vintage,
                       computed_at=now_ns, module_state=module_state,
                       min_lag_bars=cfg.min_lag_bars), cost_rec

function label_bucket(label):          # cost interface only sees three buckets
    if label == "EVENT_DAY": return "EVENT_DAY"
    if label == "PRE_EVENT": return "PRE_EVENT"
    return "OTHER"                      # FAR / DRIFT / POST_DIGEST = identity
```

### §R2.2 τ definition (trading-day distance)

`tau = signed trading days from now to T*`, computed on the NYSE calendar
(weekends and NYSE holidays excluded). Intraday on the event day, τ is
fractional: `tau = (T* − now) / 6.5h` [default] so the 30-minute shock window
maps to `−0.02 < τ ≤ 0.5` (`0.5` trading day ≈ `3.25` h [internal-est] before the statement;
`−0.02` ≈ `8` min [internal-est] after). For ECB, `event_ts` = `14:15` CET release
[documented]; for BoJ, `event_ts` = day-2 `12:00` JST ± `3` h [default] and the
module runs `DEGRADED` on BoJ event days until the statement is observed.

### §R2.3 Hysteresis transition table (normative)

Entry is inclusive (`≤`), exit is strict (`>`), with hysteresis width `h`.
`prev` is the label from the prior call (cold start: `FAR`).

| prev \ τ | entry rule | exit rule |
|---|---|---|
| FAR | → DRIFT iff τ ≤ `drift_hi` | (cold start only) |
| DRIFT | → PRE_EVENT iff τ ≤ `drift_lo` | → FAR iff τ > `drift_hi + h` |
| PRE_EVENT | → EVENT_DAY iff τ ≤ `pre_lo` | → DRIFT iff τ > `drift_lo + h` |
| EVENT_DAY | → POST_DIGEST iff τ ≤ `shock_exit` | → PRE_EVENT iff τ > `pre_lo + h` (calendar shifted) |
| POST_DIGEST | (absorbing until rollover) | → FAR iff τ > `drift_hi + h`; → DRIFT iff τ > `drift_lo + h`; → PRE_EVENT iff τ > `pre_lo + h` |

Cycle rollover rule (checked first): if `prev ∈ {EVENT_DAY, POST_DIGEST}` and
τ > `drift_hi + h`, return `FAR` — the calendar has rolled to a far next
event. Exact-boundary pins are in the fixture (rows 6–19): τ = `25.5` holds
DRIFT, τ = `25.51` exits; τ = `0.5` from DRIFT → PRE_EVENT but from PRE_EVENT →
EVENT_DAY (hysteresis, not a bug).

### §R2.4 Detection-calibration recipe (no magic numbers)

Every `calibrate`-status threshold ships with this recipe; the current defaults
are starting values only.

1. **Data.** `30` years [example] of public FOMC/ECB/BoJ calendars
   (1994–2024) + NYSE trading calendar. No price data needed for threshold
   selection (regime-only); optional validation uses SPX daily bars to check
   drift-window conditioning.
2. **Grid.** `drift_hi ∈ {15, 20, 25, 30}`, `drift_lo ∈ {1, 2, 3}`,
   `pre_lo ∈ {0.25, 0.5, 1.0}`, `shock_exit ∈ {−0.05, −0.02, 0}`,
   `h ∈ {0, 0.25, 0.5, 1.0}` [example grids].
3. **Objective.** Minimize label transitions per event cycle, subject to the
   hard constraint: zero label flips inside `[T* − 30 min, T* + 30 min]`
   [rule]. Ties → largest `h`.
4. **OOS selection.** Walk-forward: calibrate on 1994–2014, select on
   2015–2024 for FOMC (analogous in/out splits per bank); no ex-post period
   selection (F5).
5. **Re-cal cadence.** Yearly each January after the year's calendars publish
   (FOMC tentative ~August [documented]; ECB/BoJ ~December [documented]); plus
   on any statement-time convention change or meeting-count change.
6. **Recording.** Selected values, OOS transition counts, and vintage go in
   the decision log (Appendix g v1.0.0) and bump `estimator_version`.

## §R3 Exact calculation

Let `T*` be the announcement timestamp, `t` now:

$$\tau = \frac{T^* - t}{\text{1 trading day}} \qquad (\tau > 0 \text{ is pre-event})$$

Window map (operational, entry boundaries; exit adds hysteresis `h`):
`τ > 25` far · `2 < τ ≤ 25` drift window ·
`0.5 < τ ≤ 2` pre-announcement day · `−0.02 < τ ≤ 0.5` event/30-min shock window ·
`τ ≤ −0.02` post-digest. The 24h pre-window is close-to-5-minutes-before-release
(Lucca–Moench [documented]). High-frequency policy shock: Kuttner /
Bernanke–Kuttner / GSS surprises from FF futures around the statement (phase 2;
skip-listed in §1.5).

*Formula tag: calibrate — constants inside this formula inherit `calibrate` status per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags. The normative
transition logic is the §R2.1 pseudocode + §R2.3 table, not this formula alone.*

**Data inputs.** FOMC calendar (unscheduled meetings handled separately); ECB/BOJ calendars; FF futures for the shock (phase 2).

**Cadence.** Daily; intraday on event days.

**Threshold bands** (entry inclusive, exit with hysteresis `h = 0.5` [calibrate]):

| `τ` (trading days) | Slice | Entry | Exit |
|---|---|---|---|
| `> 25` | far | — | τ > `25.5` from DRIFT |
| `2–25` | drift / monetary-momentum window | τ ≤ `25` from FAR | τ > `2.5` → back to DRIFT; τ > `25.5` → FAR |
| `0.5–2` | pre-announcement day | τ ≤ `2` from DRIFT | τ > `2.5` → DRIFT |
| `−0.02–0.5` | event / shock window | τ ≤ `0.5` from PRE_EVENT | τ ≤ `−0.02` → POST_DIGEST; τ > `1.0` → back to PRE_EVENT |
| `≤ −0.02` | post-digest | τ ≤ `−0.02` from EVENT_DAY | rollover: next event τ > `25.5` → FAR |

All band constants are `calibrate` status — run the §R2.4 recipe per instrument
before production use. The `25`-day drift-window default is consistent with the
`~25`-day pre-expansionary-drift documented in NBER w24748 (Monetary Momentum)
[documented]; it is a starting default, not a measured optimum.

## §R4 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: breakout strategies | degrades | pre-event directionless drift kills breakouts — false breakouts into the event |
| T: intraday reaction strategies | amplifies | event window is the highest intraday efficacy *after* the statement — genuine information, one-sided flow |
| T: post-event momentum | amplifies | institutional repositioning takes days — follow-through or reversal day |
| T: short-gamma / event-blind mean-reversion | degrades | reduce initiation into the event; vol expansion is the base case |
