## §R2 Precise definition

Mechanical rebalancing pressure: at month/quarter-end, funds targeting fixed weights must trade the drift. Equity-weight drift from target `Δw = w_e − w*` (with month-to-date equity/bond returns) predicts the *direction* of the flow: positive drift → sell equities into the close. The timing within the window is not predictable — the module gates for the window, not the instant. Front-running of these predictable flows by hedge funds is documented (Harvey–Melone–Mazzoleni 2025 [documented]) — that is the mechanism behind "ride the flow"; the documented risk is paying the front-runner's markup.

### R2.1 Month-to-date return construction (normative)

```python
def mtd_returns(adj_e, adj_b, t, cal):
    # adj_e/adj_b: dividend/split-ADJUSTED total-return closes, event_ts <= t, newest last [default]
    # cal: NYSE trading calendar (pandas_market_calendars [documented])
    m0 = first trading day of t's calendar month
    base_e = close of last trading day before m0 if present else adj_e[0]  # degenerate [default]
    base_b = close of last trading day before m0 if present else adj_b[0]
    R_e = adj_e[t] / base_e - 1.0
    R_b = adj_b[t] / base_b - 1.0
    return R_e, R_b   # on the first trading day of the month, R_e = R_b = 0.0 by construction [default]
```

- Adjusted closes are **normative**: unadjusted ex-div/split gaps distort the
  drift. If adjusted closes are unavailable, drop the bar and mask (F1) — never
  interpolate [default].
- `R_e`/`R_b` use only closes `≤ t` (causal per the Lag contract).

### R2.2 Drift, window flag, and hysteresis machine (normative)

```python
def weight_drift(R_e, R_b, w_star):
    w_e = w_star*(1.0+R_e) / (w_star*(1.0+R_e) + (1.0-w_star)*(1.0+R_b))
    return w_e - w_star

def in_window(t, cal, window_days):
    # t is one of the last `window_days` TRADING days of its calendar month [default]
    return t in last_n_trading_days(cal, month_of(t), window_days)

def transition(prev, drift, cfg):
    e, x = cfg.flow_entry, cfg.flow_exit
    assert x < e          # startup assertion: positive deadband [default]
    if drift > e:  return 'SELL_EQUITY'    # strict entry: exactly +e does NOT enter [default]
    if drift < -e: return 'BUY_EQUITY'     # strict entry [default]
    if abs(drift) < x: return 'NEUTRAL'    # strict exit [default]
    return prev                            # deadband hold: hysteresis [default]

def detect_bar(R_e, R_b, in_w, t_ns, cal, cfg, prev_label):
    if not (finite(R_e) and finite(R_b) and in_w is not None):
        return ('UNKNOWN', 'UNKNOWN', nan)      # F1: missing level or window flag
    d = weight_drift(R_e, R_b, cfg.w_star)
    if not (finite(d) and abs(d) < 1.0):
        return ('UNKNOWN', 'UNKNOWN', d)        # F2: non-finite / out of bounds
    if not in_w:
        return ('NEUTRAL', 'OK', d)             # outside window: drift measurable, no flow
    return (transition(prev_label, d, cfg), 'OK', d)
```

**Why hysteresis.** `Δw` oscillates around the band as equity/bond legs move
intraday-to-daily; without a deadband the label flickers SELL→NEUTRAL→SELL and
downstream gates churn. The `flow_entry − flow_exit` deadband (`0.005` wide
[default]) holds the last label inside the band.

### R2.3 Edge cases (normative)

- Missing bar (index level or `in_window`) → F1 `UNKNOWN`, mask, never
  interpolate; recovery resumes on the next print with no backfill.
- Halt/auction day → freeze per §R0.5; discard contributions across reopen.
- Corporate action (split/dividend in SPY/AGG) → adjusted closes per §R2.1;
  unadjusted feed → drop the bar (F1).
- First trading day of month → `R_e = R_b = 0.0` → `Δw = 0.0` → `NEUTRAL`
  (not an error) [default].
- Trading-calendar failure (window unknowable) → `UNKNOWN` (restrictive, F1)
  [default] — a silently-wrong window is worse than no label.
- `w_star` survey vintage > `12` months [example] → `DEGRADED` (label emitted
  but flagged); downstream must not treat it as fresh calibration.

## §R3 Exact calculation

Month-to-date returns `R_e, R_b`, target equity weight `w* = 0.60`
[example]:

$$w_e = \frac{w^*(1+R_e)}{w^*(1+R_e) + (1-w^*)(1+R_b)}, \qquad
\Delta w = w_e - w^*$$

Flow direction: `Δw > 0` → funds must **sell** equities (SELL_EQUITY);
`Δw < 0` → **buy**. Worked checks [example]: `R_e = +10%`, `R_b = 0` →
`w_e = 0.622642`, `Δw = +0.022642` → SELL_EQUITY. `R_e = −5%`, `R_b = +2%` →
`w_e = 0.582822`, `Δw = −0.017178` → BUY_EQUITY.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Equity and bond index levels (month-to-date returns); target weight; month-end calendar.

**Cadence.** Daily; window flag on the last `window_days` = `3` trading days of the month [default].

**Threshold bands** (entry strict, exit looser — the deadband prevents flicker; all `[default]`, calibration recipe in §R3.1):

| Condition | Label | Tag |
|---|---|---|
| `Δw > +flow_entry` (`+0.01`) | SELL_EQUITY | [default] |
| `Δw < −flow_entry` | BUY_EQUITY | [default] |
| `\|Δw\| < flow_exit` (`0.005`) | NEUTRAL | [default] |
| deadband between (holds previous label) | hysteresis | [default] |

## §R5 Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment applied to the strategy's cost inputs.
The adjustment scales the strategy's *cost inputs* and the *required-edge
multiplier* — never the edge estimate itself. Consuming strategies wire it as:

```python
adj = cost_adjustment(rsv, base, quarter_end=is_quarter_end(rsv['computed_at']))
# entry gate: expected_cost_bps(notional, adv_pct, venue, side, urgency,
#                               impact_bps=adj['impact_bps'], ...) * adj['edge_mult'] <= edge_bps  [default]
# routing:    adj['trade_ok'] False -> block new entries in the window [default]
```

```python
def cost_adjustment(rsv, base, quarter_end=False):
    # base: dict(spread_bps, impact_bps, borrow_bps, *_mult) from the strategy COST block
    adj = dict(base)
    adj['edge_mult'] = 1.0                    # [default] required-edge multiplier
    adj['trade_ok'] = True                    # [default]
    adj['tags'] = ['R037:' + rsv['state']]    # provenance tag on the adjustment
    ms, st = rsv['module_state'], rsv['state']
    if ms == 'UNKNOWN':
        adj['trade_ok'] = False               # [default] restrictive: unknown blocks
        return adj
    if ms == 'DEGRADED':
        adj['trade_ok'] = False               # [default] warming/stale-config: label withheld
        adj['edge_mult'] = 1.5                # [example]
        return adj
    if st in ('SELL_EQUITY', 'BUY_EQUITY'):
        q = 2.0 if quarter_end else 1.5       # [example] quarter-end flow is heavier
        adj['impact_mult'] = adj.get('impact_mult', 1.0) * q
        adj['edge_mult'] = 2.0                # [example] strategies fighting the flow demand 2x edge
        # spread_mult, borrow_mult unchanged: no documented spread/borrow widening
        # for this calendar effect [default]
    return adj   # NEUTRAL: identity passthrough
```

Which components scale, by how much: `SELL_EQUITY`/`BUY_EQUITY` scale **impact
×`1.5`** [example] (**×`2.0`** [example] in quarter-end months — March, June,
September, December — when pension rebalancing coincides with quarter-end
institutional flows, documented as abnormally high on quarter-end days
[documented]) and demand **`2.0`×** [example] the required edge for strategies
fighting the flow; spread and borrow are untouched [default] (no documented
widening). Context for the impact scaling: `12%–14%` of US share volume traded
at the closing auction (AMF 2019 [documented]) — one-sided rebalancing flow
concentrates at the close, which is where impact lands. `NEUTRAL` passes
through; `UNKNOWN`/`DEGRADED` block new entries [default] (restrictive — never
treated as benign). The record is versioned with `estimator_version` (`1.1.0`)
and every application is decision-logged (Appendix g v1.0.0).
`test_cost_interface` pins every multiplier.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Missing index level or `in_window` (F1) → detect: unparseable/empty field → action: `UNKNOWN`, mask (never interpolate); recovery: resume on next print, no backfill | `check: finite(R_e) and finite(R_b) and in_window is not None` |
| 2 | Non-finite drift (F2) → detect: `Δw` NaN/inf or `\|Δw\| ≥ 1.0` → action: `UNKNOWN` + page; recovery: quarantine the bar, resume next bar | `check: finite(drift) and abs(drift) < 1.0` |
| 3 | Dual-source band disagreement (F3) → detect: SPY-derived label ≠ SPX-total-return-derived label (same machine, same config) → action: `UNKNOWN`; recovery: investigate vendor divergence before re-arm | `check: label(alt_source) == label(primary)` |
| 4 | Stale index series (F4) → detect: no new print for `> stale_days` = `3` trading days [default] → action: `UNKNOWN` + notify; recovery: refetch, resume (prior state persists, no re-warm) | `check: data_vintage within 3 trading days` |
| 5 | Calendar-date vs trading-day window (Adversary) → detect: window computed on calendar dates lands on a holiday/early-close → action: recompute window from the NYSE calendar; recovery: automatic | `check: window ⊆ trading days` |
| 6 | Corporate action distortion → detect: unadjusted SPY/AGG close across ex-div/split → action: recompute on adjusted closes; if unavailable, drop the bar (F1) | `check: closes are dividend/split-adjusted` |
| 7 | Halt/auction → detect: market state ≠ CONTINUOUS_TRADING → action: freeze state per §R0.5, emit `UNKNOWN` (halt) / hold + `DEGRADED` (auction); recovery: discard contributions across reopen | `check: market_state` |
| 8 | Stale target-weight survey → detect: `w_star` config vintage > `12` months [example] → action: `DEGRADED`, notify; recovery: refresh survey, re-run §R3.1 | `check: w_star vintage ≤ 12 months` |

**Honest DEGRADED/UNKNOWN behavior.** Outside the month-end window the module
emits `NEUTRAL` with module state `OK` — the absence of flow is measurable, not
an error; `UNKNOWN` is reserved for data faults (F1–F4). `UNKNOWN` is
restrictive: downstream must block new window-gated entries, never treat it as
benign. During `w_star`-vintage `DEGRADED` the label is still emitted but
flagged — downstream halves size [default]. The detector is EOD by design:
intraday flow timing (which hour the flow prints) is *not* measurable here —
the Grok-supplied 14:00–15:30 ET fade window is an [unverified] lead in §R10,
not a fallback. A halted underlying freezes the state per §R0.5; contributions
across the reopen are discarded, never interpolated.

## §R9 Loop spec

| Role | Responsibility |
|---|---|
| Sentinel | computes the weight drift from index levels per §R2 |
| Verifier | recomputes the full label from a second index source (e.g. SPX total return vs SPY); band disagreement → UNKNOWN |
| Grok-Researcher | tracks rebalancing-calendar conventions — leads only |
| Adversary | shifts the month-end date (holiday/early-close calendar); the window must follow the trading calendar, not calendar dates; injects unadjusted closes |
| Gate | accepts only with the trading-calendar window; quarantines on band disagreement |

**F1–F5 instantiated for this regime.**

- **F1.** missing index level or `in_window` → `UNKNOWN`
- **F2.** non-finite drift or `|Δw| ≥ 1.0` → `UNKNOWN` + alert
- **F3.** second index source must agree on band or `UNKNOWN`
- **F4.** index series stale > `stale_days` = `3` trading days [default] → `UNKNOWN`
- **F5.** rebalancing calendar fixed ex ante; no ex-post window-picking; calibration disclosed in §R8
