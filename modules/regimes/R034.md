## §R2 Precise definition

Discrete energy-price shock state with hysteresis: the standardized cumulative
move in WTI front-month over an `H`-trading-day horizon [default] crosses a
shock band, and the label persists until the z retreats through a looser exit
band. The deadband is load-bearing — without it the label flickers on
borderline prints (the fixture pins `z = 1.8` labeling `NORMAL` from rest and
`SHOCK_UP` from shock). Futures rolls are handled explicitly via a
back-adjusted continuous series (§R3.1) — the Adversary injects a roll date to
test this. Do not use USO as the shock series: ETF roll/contango is a
different object.

### R2.1 Detection pseudocode (normative)

```python
def detect(state, events, cfg):
    # events: ascending event_ts, strictly causal; state carries hysteresis memory
    assert cfg.z_entry - cfg.deadband > 0          # startup assertion [default]
    if not events:
        return [regime_state('UNKNOWN', nan, 'UNKNOWN', 0)]        # F1
    prev_label = state.get('label', 'NORMAL')      # warm start [default]
    prev_value = state.get('shock_z', 0.0)
    out = []
    for e in events:
        ts = e['event_ts']
        if e.get('halt'):
            # §R0.5: freeze — label/value held, no contribution, emit UNKNOWN
            out.append(regime_state(prev_label, prev_value, 'UNKNOWN', ts))
            continue
        v = row_inputs(e)                          # P_now, P_then, mu_R, sigma_R
        if not (finite(v.P_now) and finite(v.P_then)):
            out.append(regime_state('UNKNOWN', nan, 'UNKNOWN', ts)); continue   # F1
        if v.P_now <= 0 or v.P_then <= 0:
            out.append(regime_state('UNKNOWN', nan, 'UNKNOWN', ts)); continue   # F2
        if not (finite(v.mu_R) and finite(v.sigma_R) and v.sigma_R > 0):
            out.append(regime_state('UNKNOWN', nan, 'UNKNOWN', ts)); continue   # F2
        z = (log(v.P_now / v.P_then) - v.mu_R) / v.sigma_R
        if not finite(z):
            out.append(regime_state('UNKNOWN', z, 'UNKNOWN', ts)); continue     # F2
        prev_label = transition(prev_label, z, cfg)  # §R2.2 (normative)
        prev_value = z
        out.append(regime_state(prev_label, z, 'OK', ts))
    state['label'], state['shock_z'] = prev_label, prev_value
    return out

def transition(prev, z, cfg):                      # hysteresis machine (normative)
    up_out = cfg.z_entry - cfg.deadband
    if prev == 'SHOCK_UP':
        return 'NORMAL' if z <= up_out else 'SHOCK_UP'
    if prev == 'SHOCK_DOWN':
        return 'NORMAL' if z >= -up_out else 'SHOCK_DOWN'
    if z >= cfg.z_entry:   return 'SHOCK_UP'       # exact-band entry (>=) [default]
    if z <= -cfg.z_entry:  return 'SHOCK_DOWN'
    return 'NORMAL'
```

Polarity never flips in one bar: `SHOCK_UP` → deep-negative z passes through
`NORMAL` (pinned by the tape) [default]. Exact-band behavior (`z = 2.0`
enters, `z = 1.5` exits from shock) is normative — `test_entry_exit_boundary_pins`
fails on any `>`/`>=` drift.

### R2.2 Threshold bands (entry strict, exit looser — the deadband prevents flicker; all `[default]`, calibration recipe in §R2.4)

| Entry | Exit | Label | Tag |
|---|---|---|---|
| `z ≥ 2.0` | `z ≤ 1.5` (deadband `0.5`) | SHOCK_UP | [default] |
| `z ≤ −2.0` | `z ≥ −1.5` (deadband `0.5`) | SHOCK_DOWN | [default] |
| otherwise | — | NORMAL | [default] |

The `|z|` magnitude is retained in `RegimeState.value` — severity is a
downstream sizing input, not a separate label.

### R2.3 Edge cases (normative)

- **Missing bars.** Mask the bar, emit `UNKNOWN` (F1), never interpolate.
  Recovery: resume on the next settlement; the prior label persists — no
  re-warm [default].
- **Halts / limit-locked bars.** Freeze per §R0.5: label/value held,
  `module_state` `UNKNOWN`, zero contribution to z or trailing moments.
  CL has `15`% daily price limits [documented] — on consecutive limit-locked
  settlements the z may saturate; do **not** winsorize or clip [default]
  (clipping hides the shock); hold the label per the hysteresis machine and
  note the saturation in the decision log.
- **Corporate actions.** Futures have no dividends or splits; the analogue is
  the **contract roll** (§R3.1). An unhandled roll date — `Delivery Month`
  flips with no roll-calendar entry — emits `UNKNOWN` (F2), never a shock.
  This is the Adversary's injection and the Gate's lint target.
- **Negative prints.** WTI front-month settled negative on 2020-04-20
  [documented]; `P ≤ 0` makes the log undefined → that bar is `UNKNOWN`
  (F2), and any `H`-day window spanning it stays masked [default].
- **Warm-up.** The production trailing-moments path (§R3.2) with fewer than
  `moments_min_bars = 63` bars [example] emits `DEGRADED`/`warming` and the
  label is withheld — downstream must not gate on it [default].
- **Stale series.** `now − computed_at > 3`× cadence [default] → `UNKNOWN`
  (F4) via `apply_freshness`; recovery resumes on the next fresh bar.

### R2.4 Detection calibration recipe (normative procedure; candidate values [example])

The `2.0`/`1.5` bands are **uncalibrated defaults** — no OOS calibration run
exists in the changelog as of v1.1.0 [documented]. Do not hand-tune; run this:

1. **Data:** ≥ `10` years [example] of daily NYMEX CL settlements plus a
   back-adjusted continuous series with an explicit roll calendar (Norgate
   back-adjusted continuous back to ~`1980` [documented], or Databento
   GLBX.MDP3 OHLCV-1d settlements [documented]).
2. **Grid** [example]: `z_entry ∈ {1.5, 1.75, 2.0, 2.25, 2.5, 2.75, 3.0}`;
   `deadband ∈ {0, 0.25, 0.5, 0.75, 1.0}`; `H ∈ {10, 20, 30, 60}`;
   `moments_window ∈ {126, 252, 504}`.
3. **OOS protocol:** walk-forward — fit trailing moments on trailing data
   only, evaluate on the next `63` trading days [example], step `21` days
   [example]; embargo `21` days [default] between fit and evaluation windows
   (purged embargo, López de Prado 2018 [documented]).
4. **Selection criterion (normative):** maximize OOS state separation
   `S = mean(forward 21-day |R(H)| on shock-labeled days) − mean(forward
   21-day |R(H)| on normal days)`, subject to label churn ≤ `6` flips/year
   [example] and ≥ `30` shock-days per fold [example]; tie-break toward the
   wider deadband (fewer flips) [default].
5. **Re-calibration cadence:** annually in Q1 [default]; freeze mid-year unless
   F2/F3/F4 trips exceed `3` in a quarter [example] → mandatory review.
6. **Selection disclosure (F5):** publish chosen parameters, OOS `S`, fold
   dates, and the grid in §R9 before deploying calibrated values; calibrated
   values replace `[default]` tags with `[measured]`.

## §R3 Exact calculation

Horizon-`H` log return on the back-adjusted settlement `P_t`:

$$R_t(H) = \ln(P_t / P_{t-H}), \qquad
z_t = \frac{R_t(H) - \mu_R}{\sigma_R}$$

`μ_R, σ_R` from the trailing history of `H`-day log returns (§R3.2). Label via
the §R2.2 hysteresis machine. Worked check: `P_{t−20} = 70`, `P_t = 82.6`
(+18% simple [example]), `μ_R = 0.01`, `σ_R = 0.06` [example] → `R = 0.1655`,
`z ≈ 2.59` → SHOCK_UP (upside).

*Formula tag: [default] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** WTI nearby settlement; horizon H; trailing moments; explicit roll calendar.

**Cadence.** Daily (settlement-date bars).

### R3.1 Back-adjusted continuous series (normative)

Arithmetic back-adjustment — the only adjustment this module permits
[default] (ratio adjustment distorts the log-return scale and is forbidden
here):

```python
def back_adjust(prices, rolls):
    # prices: [(ts, contract_id, price)] ascending, one bar per ts;
    #         the roll-date bar is taken from the NEW contract.
    # rolls:  [(roll_ts, old_id, old_close, new_id, new_close)];
    #         roll_ts = first ts sourced from the new contract.
    out = []
    for ts, cid, px in prices:
        adj = sum(new_c - old_c for (rts, _o, old_c, _n, new_c) in rolls if rts > ts)
        out.append((ts, px + adj))
    return out
```

- Every bar strictly before a roll is shifted by `(new_close − old_close)`,
  compounded across rolls; bars on/after a roll are already in
  new-contract terms. Hand-check in `test_back_adjust_handcheck`.
- **Roll-rule options** (document the choice in dataset lineage; changing it
  silently invalidates the shock statistic): (a) Norgate convention —
  deliverable contracts roll on the business day prior to First Notice Day
  [documented]; (b) fixed `N`-days-before-last-trading-day [example];
  (c) volume/open-interest crossover [example].
- Or buy it: Norgate ships pre-computed arithmetically back-adjusted
  continuous contracts [documented] — the §1.5 buy leg.

### R3.2 Trailing moments estimator (normative)

```python
def trailing_moments(returns, cfg):
    # returns: H-day log returns with event_ts <= t, newest last (strictly causal)
    hist = [r for r in returns if isfinite(r)]
    if len(hist) < cfg.moments_min_bars:
        return (None, None, 'DEGRADED')     # warming: label withheld [default]
    win = hist[-cfg.moments_window:]        # leave-one-out: current bar never in its own window
    mu = mean(win)
    sd = stdev(win, ddof=1) if len(win) > 1 else 0.0
    if sd <= 0:
        return (mu, None, 'UNKNOWN')        # F2: degenerate history
    return (mu, sd, 'OK')
```

- `moments_window = 252` bars [default], `moments_min_bars = 63` [example];
  hand-check in `test_trailing_moments_handcheck` (mean `0.006`, sd
  `0.0207364` on the pinned `5`-bar series).
- The fixture supplies `(mu_R, sigma_R)` directly (validation-run) so the z
  is exact by construction; the estimator above is pinned separately and is
  the production path.
