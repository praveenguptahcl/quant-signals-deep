## §R2 Precise definition

Liquidity state as realized-vs-baseline: cumulative session volume divided by
the `20`-day [default] same-time-of-day baseline, and quoted spread divided by
its baseline. Thin = low volume ratio and/or wide spread ratio. The two legs
are scored by independent hysteresis machines and combined by worst-of
(`SEVERE > THIN > NORMAL`) — the spread leg can declare THIN while the volume
leg reads NORMAL (adverse selection without a volume drought).

**Baseline (normative).** The baseline `B_t` is the mean cumulative volume at
the same intraday bin over the trailing `baseline_window_days` [default]
trading days, restricted to regular-session bars (09:30–16:00 ET [default]),
full sessions only (half-day sessions excluded from the baseline and binned
separately per §R3.1). The baseline window is fixed ex ante — changing it
flips labels on trending volume.

**Corporate actions (normative).** Volume is share-count based: splits and
reverse-splits change `V_t` mechanically. The detector consumes
split-adjusted volume when available; otherwise the split bar is masked
(`UNKNOWN`, §R3.1) — a split bar never contributes to a label.

## §R3 Exact calculation

Cumulative volume `V_t` vs baseline `B_t` (`20`-day [default] same-time
mean):

$$\mathrm{liq\_ratio}_t = \frac{V_t}{B_t}, \qquad
\mathrm{spr\_ratio}_t = \frac{s_t}{\bar{s}}$$

$$\mathrm{state}_t = \mathrm{worst}(\mathrm{vol\_state}_t,\ \mathrm{spr\_state}_t),
\quad \mathrm{worst} \in \{\mathrm{SEVERE} > \mathrm{THIN} > \mathrm{NORMAL}\}$$

*Formula tag: [default] — thresholds are uncalibrated defaults (calibration
recipe §R3.3); constants inside this formula inherit it per the tag law
(Appendix i v1.0.0).*

### R3.1 Normative detection pseudocode

```python
def assemble_bar(raw_bars, corp_actions):
    # raw_bars: vendor 1-min bars (event_ts <= t), regular session only
    # returns (V_t, halted, corp_action) for the 5-min bin
    if any halt flag in bin from status schema: return (None, True, 'none')
    ca = corp_actions.at(bin_date)              # {none, split, reverse_split, dividend}
    V = sum(split_adjusted_volume(raw_bars)) if available else sum(volume(raw_bars))
    return (V, False, ca)

def baseline(cumvol_history, cfg, session_code):
    # cumvol_history: same-bin cumulative volumes, newest last, event_ts <= t
    full = [v for v in cumvol_history if v.session == 'full']   # half days excluded
    if len(full) < cfg.min_baseline_days: return (None, 'DEGRADED')
    return (mean(last cfg.baseline_window_days of full), 'OK')

def transition_vol(prev, liq, cfg):            # hysteresis machine (normative)
    assert cfg.thin_exit > cfg.thin_entry and cfg.severe_exit > cfg.severe_entry
    assert cfg.severe_exit < cfg.thin_entry     # startup assertions [default]
    if prev == 'SEVERE':
        if liq < cfg.severe_exit: return 'SEVERE'
        # demote: fall through to the thin/normal machine
    elif liq < cfg.severe_entry:
        return 'SEVERE'
    if prev in ('THIN', 'SEVERE'):
        return 'NORMAL' if liq >= cfg.thin_exit else 'THIN'   # exit is looser
    return 'THIN' if liq < cfg.thin_entry else 'NORMAL'       # entry is strict

def transition_spr(prev, spr, cfg):            # spread leg (normative)
    assert cfg.spr_thin_exit < cfg.spr_thin_entry and cfg.spr_severe_exit < cfg.spr_severe_entry
    assert cfg.spr_severe_exit > cfg.spr_thin_entry
    if prev == 'SEVERE':
        if spr > cfg.spr_severe_exit: return 'SEVERE'
    elif spr >= cfg.spr_severe_entry:
        return 'SEVERE'
    if prev in ('THIN', 'SEVERE'):
        return 'NORMAL' if spr <= cfg.spr_thin_exit else 'THIN'
    return 'THIN' if spr >= cfg.spr_thin_entry else 'NORMAL'

def detect_bar(e, cfg, prev_vol, prev_spr):    # per-bar core (normative)
    if e.halted:                      return unknown('halted')          # freeze, F1
    if e.corp_action in ('split', 'reverse_split'):
        return unknown('corp-action mask')                             # F1, never adjust blindly
    if not (finite(e.cumvol) and finite(e.baseline) and e.baseline > 0
            and finite(e.spread) and finite(e.spread_base) and e.spread_base > 0):
        return unknown('F1/F2')                                       # never interpolate
    liq, spr = e.cumvol / e.baseline, e.spread / e.spread_base
    if not (finite(liq) and finite(spr)) or liq < 0 or spr < 0:
        return unknown('F2 bounds')
    vol_state = transition_vol(prev_vol, liq, cfg)
    spr_state = transition_spr(prev_spr, spr, cfg)
    vol2 = transition_vol(prev_vol, e.cumvol_v2 / e.baseline_v2, cfg)  # verifier leg
    spr2 = transition_spr(prev_spr, e.spread_v2 / e.spread_base_v2, cfg)
    if worst(vol2, spr2) != worst(vol_state, spr_state):
        return unknown('F3 dual-estimator disagreement')               # restrictive
    return ok(worst(vol_state, spr_state), liq, spr)
```

**Edge cases (normative).** Missing bar → `UNKNOWN`, hysteresis state frozen
(no re-warm on recovery — the label before the gap is the machine's memory).
Halt → freeze per §R0.5; contributions across the reopen are discarded, never
interpolated. Half-day session → bars binned on the half-day map; the
`20`-day [default] baseline uses full sessions only; a bar with no matching
baseline bin → `DEGRADED`. Split/reverse-split without adjusted volume →
mask the bar (`UNKNOWN`); with adjusted volume, proceed normally. Dividend →
no mask (does not change share counts) [default]. `spread = 0` (locked market)
is finite and valid; `spread_base ≤ 0` → F2. `baseline_window_days` counts
trading days only — weekends/holidays are not bars [default].

**Data inputs.** Intraday volume bars; NBBO spread; `20`-day [default]
same-time baselines.

**Cadence.** Intraday (5-min bars).

### R3.3 Detection calibration recipe (normative procedure; candidate values [example])

The bands above are **uncalibrated defaults** — no OOS calibration run exists
in the changelog as of v1.1.0 [documented]. Do not hand-tune; run this:

1. **Data:** ≥ `1` year [example] of `5`-min [default] bars (`ohlcv-1m`
   aggregated) + NBBO spread series, session-aware, split-adjusted; per-ticker
   (liquidity regimes are not portable across market-cap deciles [default]).
2. **Grid** [example]: `thin_entry ∈ {0.60, 0.65, 0.70, 0.75, 0.80}`;
   deadband `thin_exit − thin_entry ∈ {0, 0.05, 0.10, 0.15}`;
   `severe_entry ∈ {0.40, 0.45, 0.50, 0.55}`;
   `spr_thin_entry ∈ {1.75, 2.0, 2.25, 2.5}`;
   `baseline_window_days ∈ {10, 20, 60}`.
3. **OOS protocol:** walk-forward — fit baselines and thresholds on trailing
   data only, evaluate on the next `21` trading days [example], step `5`
   days [example]; embargo `5` trading days [default] between fit and
   evaluation windows.
4. **Selection criterion (normative):** maximize OOS label separation
   `S = mean(forward 1-hour effective spread on THIN-labeled bars) −
   mean(forward 1-hour effective spread on NORMAL bars)`, subject to label
   churn ≤ `2` flips/day [example] and ≥ `50` THIN-bars per fold [example];
   tie-break toward the wider deadband (fewer flips) [default].
5. **Re-calibration cadence:** quarterly [default]; freeze mid-quarter unless
   F2/F3/F4 trips exceed `3` in a month [example] → mandatory review.
6. **Selection disclosure (F5):** publish chosen parameters, OOS `S`, fold
   dates, and the grid in §R8 before deploying calibrated values; calibrated
   values replace `[default]` tags with `[measured]`.

## §R4 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: intraday momentum | degrades | assumed fills do not exist; slippage dominates |
| T: market-making without spread adjustment | degrades | adverse selection at normal spreads |
| T: patient liquidity provision | amplifies | wide spreads reward provision — with inventory limits |

- **F1.** missing bar / halted bar / split bar → `UNKNOWN`, hysteresis frozen
- **F2.** non-finite ratio, `baseline ≤ 0`, or `spread_base ≤ 0` → `UNKNOWN` + alert
- **F3.** second venue must agree on the *label* (not the ratio value) or `UNKNOWN`

```python
def cost_adjustment(rsv, base):

    adj = dict(base)
    adj['tags'] = ['R038:' + rsv['state']]      # provenance tag on the adjustment
    adj['edge_mult'] = 1.0                      # [default] required-edge multiplier
    st, ms = rsv['state'], rsv['module_state']
    if ms in ('UNKNOWN', 'DEGRADED') or st == 'SEVERE':
        adj['trade_ok'] = False                 # [default] restrictive: unknown/stand-down blocks

    if st == 'THIN' and ms == 'OK':
        adj['spread_bps'] = base['spread_bps'] * 2.5    # [example] wide NBBO
        adj['impact_bps'] = base['impact_bps'] * 3.0    # [example] thin-book impact
        adj['edge_mult'] = 1.5                          # [example]
    elif st == 'SEVERE':
        adj['spread_bps'] = base['spread_bps'] * 5.0    # [example]
        adj['impact_bps'] = base['impact_bps'] * 5.0    # [example]
        adj['edge_mult'] = 2.0                           # [example] if manually overridden

        adj['edge_mult'] = 1.5                          # [example] label withheld
    return adj
```

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Split/reverse-split inflates `V_t` → detect: `corp_action ∈ {split, reverse_split}` from the `definition` schema, or unflagged volume discontinuity → action: mask bar (`UNKNOWN`), never label → recovery: resume on split-adjusted bars; no re-warm | `check: volume is split-adjusted or bar masked` |
| 2 | Half-day session (early close) → detect: session code ≠ full; bins past the close have no baseline → action: `DEGRADED` for unmatched bins, full sessions stay labeled → recovery: next full session resumes normally | `check: session calendar; baseline uses full sessions only` |
| 3 | Trading halt → detect: `status` schema halt flag → action: freeze hysteresis, emit `UNKNOWN`, discard contributions across reopen → recovery: resume on first post-halt bar | `check: halt flag per bar` |
| 4 | Venue mix change (e.g. new ATS flow) shifts the NBBO baseline → detect: baseline residual drift monitor → action: quarantine labels, require errata + re-calibration (§R3.3) → recovery: Gate clears after re-cal | `check: venue-mix fingerprint unchanged since calibration` |
| 5 | SIP quote feed stale / NBBO lag → detect: spread vintage older than TTL (`3`× cadence [default]) → action: `DEGRADED`, spread leg held at last value is *not* used → recovery: resume on fresh quotes | `check: quote vintage ≤ TTL` |
| 6 | Second-venue label disagreement → detect: F3 check per §R3.1 → action: `UNKNOWN` (restrictive) → recovery: auto-clear when labels re-agree for `3` consecutive bars [example] | `check: labels agree` |
| 7 | Baseline window or window-days changed without errata → detect: Gate compares live config hash to calibrated hash → action: reject labels, page → recovery: publish errata + re-run §R3.3 | `check: config hash == calibrated hash` |
| 8 | Baseline history shorter than `min_baseline_days` (new listing) → detect: count of baseline days → action: `DEGRADED`, label withheld (never a guess) → recovery: label starts once `10` days [default] accumulate | `check: baseline days ≥ 10` |
| 9 | Data-rights violation risk → detect: any job redistributing licensed DBEQ.BASIC data → action: block at deploy (startup assertion); redistribution restricted [documented] | `check: fixtures synthetic; no licensed bytes in repo` |

**Honest DEGRADED/UNKNOWN behavior.** During warm-up (`< min_baseline_days`
[default]) the module emits `DEGRADED` and the label is withheld — downstream
must not gate on it. `UNKNOWN` is restrictive: downstream halves size /
widens stops / stands down (per the Lag contract), never treated as benign
(F1). A halted underlying freezes the hysteresis state per §R0.5;
contributions across the reopen are discarded, never interpolated. The spread
leg is only as good as the NBBO feed: consolidated SIP quotes lag direct
feeds by low-single-digit milliseconds [unverified] — the `5`-min [default]
cadence makes this immaterial here, but a sub-minute variant would need a
direct-feed budget (see §R10 leads).
