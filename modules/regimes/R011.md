### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; λ̂ at t uses flow ≤ t; sizes orders at t+1+).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).
- **Threshold freezing:** calibrated `$`-thresholds are frozen between
  re-calibrations; mid-month tuning is ex-post period selection (F5).

## §R1 Precise definition

Kyle (1985) [documented]: market maker sets `p = μ + λ·y`; empirical λ̂ is the OLS slope of `ΔP` on signed volume q [documented standard implementation]. Book depth = `bid_size_1 + ask_size_1` in shares and in minutes of ADV, percentile vs `63`-day [documented RB-list].

## §R2 Exact calculation

$$\Delta P_t = \alpha + \lambda\, q_t + \varepsilon_t, \qquad \hat{\lambda} = \frac{\sum (q_t-\bar q)(\Delta P_t-\overline{\Delta P})}{\sum (q_t-\bar q)^2} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: `Σ(q−q̄)(ΔP−ΔP̄) = 74.86`, `Σ(q−q̄)² = 361,140` → `λ̂ ≈ 2.07×10⁻⁴` $/share. Terciles of λ̂ against trailing history: deep / normal / stressed [example cutoffs]. Cross-check: ratio estimator `Σ|ΔP|/Σ|q|` with relative tolerance `0.5` [default]. Honesty rule H6 [documented RB-list]: without L1/L2 the depth state is `UNKNOWN` — SIP-only depth inference is forbidden.

**Data inputs.** Signed order flow `q`: the aggressor `side` field (`A` = buyer-initiated, `B` = seller-initiated [documented]) when present; otherwise the Lee–Ready quote rule with tick-rule fallback [documented Lee & Ready 1991]. Bar price change `ΔP` on the same bar grid. Book depth = `bid_sz_1 + ask_sz_1` in shares and in minutes of ADV, percentile vs `63`-day [documented RB-list] — from direct-feed L1/L2 in production (H6; §R0.3b). ≥ `warmup_bars` = `2` [default] session bars for any label; the production window is `est_bars` = `10` [default].

**Warm-up & degenerate windows.** With fewer than `warmup_bars` [default] session bars the module emits `DEGRADED`/`warming` and withholds the label. A window with Σ(q−q̄)² = `0` [default] (no regressor variation, e.g. a single-bar window by construction) ⇒ `UNKNOWN`/`invalid`.

**Cadence.** `15`-min [default] intraday for depth; daily for λ.

### Hysteresis specification (normative)

A state is entered at the entry threshold and held until the exit threshold is crossed — inside the band the label is sticky, which kills chatter:

| Transition | Rule | Tag |
|---|---|---|
| normal → stressed | λ̂ ≥ `stressed_entry` = `5.0×10⁻⁴` $/share | [example] |
| stressed → normal | λ̂ < `stressed_exit` = `4.5×10⁻⁴` $/share | [example] |
| normal → deep | λ̂ ≤ `deep_entry` = `1.5×10⁻⁴` $/share | [example] |
| deep → normal | λ̂ > `deep_exit` = `2.0×10⁻⁴` $/share | [example] |
| cold start | previous label = `normal` | [default] |

E.g. a stressed state with λ̂ between `4.5×10⁻⁴` and `5.0×10⁻⁴` [example] stays stressed. The transition fixture pins entry, in-band hold, and exit per-bar.

### Normative detection pseudocode

Prose is commentary; this block is binding (mirrored by `detect()` in `modules/tests/test_R011.py`).

```python
def detect(state, events, cfg):                       # events newest-last
    rows = events
    if not rows:
        return RSV("missing", NaN, 0, UNKNOWN)        # F1
    last = rows[-1]
    if last.flag == "halt":                           # freeze across halt
        return RSV(state.last_label or "undefined",
                   state.last_value or NaN, last.event_ts, UNKNOWN)
    usable, splits, last_halt = [], set(), -1
    for i, r in enumerate(rows):                       # F1 input validation
        if r.flag == "halt": last_halt = i; continue
        if r.flag == "split": splits.add(i); continue
        if not (finite(r.dp) and finite(r.q)) or r.q == 0:
            return RSV("invalid", NaN, r.event_ts, UNKNOWN)
        usable.append((i, r))
    masked = {j + k for j in splits                     # corporate-action mask
              for k in range(cfg.split_mask_bars + 1)}  # [default] bar + 1
    if len(rows) - 1 in masked:
        return RSV("masked", NaN, last.event_ts, UNKNOWN)
    sess = [b for (i, b) in usable                      # discard across reopen
            if i > last_halt and i not in masked]
    if len(sess) < cfg.warmup_bars:                    # [default] 2
        return RSV("warming", NaN, last.event_ts, DEGRADED)
    win = sess[-cfg.est_bars:]                         # trailing window
    module = OK
    if max_gap(win, skip_masked=True) > cfg.gap_factor * median_gap(win):  # [default] 2.0
        module = DEGRADED                              # label from available bars; never interpolate
    lam, t = OLS_slope(dp on q over win)               # [documented] Kyle empirical form
    if no regressor variation:
        return RSV("invalid", NaN, last.event_ts, UNKNOWN)
    if lam < 0:
        return RSV("invalid", lam, last.event_ts, UNKNOWN)   # not equilibrium [documented]
    if not (BOUNDS.lo <= lam <= BOUNDS.hi):            # F2, [default] ±0.01 $/share
        return RSV("out_of_bounds", lam, last.event_ts, UNKNOWN)
    if rel_diff(lam, ratio_estimator(win)) > cfg.dual_tol:    # F3, [default] 0.5
        return RSV("invalid", lam, last.event_ts, UNKNOWN)
    if t is defined and abs(t) < cfg.t_min:            # [default] 2.0: level untrusted
        module = DEGRADED                              # label kept, flagged
    label = hysteresis(state.last_label or "normal", lam, cfg)  # entry/exit bands
    if now - last.event_ts > 3 * cadence:              # F4 staleness
        return RSV(label, lam, last.event_ts, UNKNOWN)
    return RSV(label, lam, last.event_ts, module)      # F5 enforced by caller
```

### Threshold calibration recipe (normative)

No magic numbers: every threshold below is either a grid default or a calibrated output recorded with status `calibrate`.

1. **Data.** Trailing `min_hist_days` = `30` [default] trading days of daily λ̂ (from `15`-min bars [default]) plus L1 depth percentiles. Chronological split: first `2/3` [default] in-sample, last `1/3` [default] OOS; walk-forward refit; embargo `1` day [default] between fit and evaluation (F5).
2. **Grid.** `stressed_entry_pct` ∈ {`60`, `67`, `75`} [default]; hysteresis offset ∈ {`5`, `10`, `15`} [default] percentile points (`stressed_exit_pct` = entry − offset; `deep_exit_pct` = `deep_entry_pct` + offset); `deep_entry_pct` ∈ {`25`, `33`, `40`} [default]; `est_bars` ∈ {`5`, `10`, `21`} [default].
3. **Objective.** OOS average cost-per-share of a fixed probe slice (`5`% of `1`-min ADV [example]) under regime sizing vs flat sizing, at FULL-COST; maximize saved bps [default]; tie-break on fewer label flips per day.
4. **Guardrails.** ≥ `30` [default] OOS bars in each state; reject grid points with flips/day > `2`× [default] the in-sample median (chatter guard); thresholds frozen between re-calibrations — mid-month tuning is ex-post selection (F5).
5. **Re-calibration.** Every `calib_cadence_days` = `21` [default]; early trigger if the `5`-day [default] flip rate exceeds `2`× [default] the calibrated baseline.
6. **Recording.** Chosen percentiles become frozen $/share thresholds in Config (status `calibrate`); the percentile-history vintage goes in `data_vintage`.

### Edge cases (normative)

- **Missing bars.** A bar-to-bar interval > `gap_factor` = `2.0` [default] × the window median interval ⇒ the window is discontinuous: emit the label from available bars as `DEGRADED`, never interpolate (F1). Intervals spanning a corporate-action mask are known-good and skipped. Recovery is automatic once the trailing window refills.
- **Halts / auctions.** A `status`-schema halt/auction flag (DBEQ.BASIC `status` [documented]) ⇒ freeze: emit the last label with module state `UNKNOWN`; discard contributions across the reopen — the post-halt window restarts and needs `warmup_bars` = `2` [default] bars before `OK`.
- **Corporate actions.** A split/dividend factor ≠ `1` [default] ⇒ rescale `q` and `ΔP` by the factor when the definition feed provides it [default]; otherwise mask the bar plus the next `split_mask_bars` = `1` [default] bar (`UNKNOWN`/`masked`). Never estimate λ across an unadjusted split — the price jump fabricates a λ spike.
- **Zero-flow bars.** `q == 0` on an unflagged bar ⇒ invalid input, `UNKNOWN` (F1). Names with frequent zero-flow bars must be aggregated to wider bars [default], not patched with zeros.
- **UNDEF_PRICE.** Databento sends `INT64_MAX` when no quote exists or the instrument is halted [documented]: treat as a missing quote and exclude from depth — never as a price.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Large-size execution (VWAP/POV) | **inverts** | dies in thin-book/high-λ states — scheduled participation becomes predatory (impact ∝ λ·√participation) |
| Small-size microstructure signals | **amplifies then inverts** | improves mildly (bigger microprice moves per imbalance) but fill rates collapse — net neutral to negative |
| Market-making | **amplifies** | high λ + high VPIN (R014) = impact and adverse selection — widen quotes or withdraw |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** estimates λ̂ on 5-min bars rolling `21` days [documented RB-list]; publishes RSV; after a halt the window restarts and needs `warmup_bars` = `2` [default] post-halt bars before `OK`.
- **Verifier:** ratio-estimator cross-check within `dual_tol` = `0.5` [default] (F3); λ̂ < 0 ⇒ window discarded, `UNKNOWN` [documented Grok RB2]; λ regression |t| < `2` [default] ⇒ `DEGRADED` (level untrusted, label kept) — the t-stat gate is enforced, not advisory.
- **Grok-Researcher:** proposes bar counts; leads only.
- **Adversary:** feeds unsigned volume and checks the Gate rejects; feeds SIP-only depth and checks H6 fires; feeds a split day and checks the mask fires; feeds a halt and checks the freeze fires.
- **Gate:** rejects unsigned-volume λ̂; rejects same-day-fill circularity; rejects SIP-only depth inference (H6); rejects estimation across unadjusted splits; rejects interpolation across gaps.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

λ is the temporary-impact coefficient: expected temporary impact ≈ λ̂ × size [documented Kyle 1985]; capacity of any signal is O(1/λ). Component mapping — **only the spread and temporary-impact components scale with the depth regime; fees and borrow are regime-invariant** [default]:

- **Spread.** Widens with adverse selection (Glosten–Milgrom 1985 [documented]): `spread_mult` = `1.00` / `1.25` / `1.75` [example] for deep / normal / stressed.
- **Temporary impact.** Scales with the λ tercile: `impact_mult` = `1.0` / `1.5` / `3.0` [example].
- **Fees.** Per-share schedule, regime-invariant: `fee_mult` = `1.0` [default] (record `fee_schedule_as_of` in the strategy's COST block).
- **Borrow.** Financing is unaffected by intraday depth: `borrow_mult` = `1.0` [default].
- **Sizing.** `size_mult` = `1.0` / `1.0` / `0.5` [example]; stressed forces slicing at `max_participation` = `0.10` (`10`% of `1`-min ADV [default]).
- **Veto.** The regime never vetoes outright: `trade_ok` = `True` [default] — veto is the strategy's call.

```python
def cost_adjustment(rsv, base):
    """Regime state -> cost-function adjustment (R011 v1.1.0)."""
    adj = dict(base)
    scaling = {  # (spread_mult, impact_mult, size_mult) [example]
        "deep":     (1.00, 1.0, 1.0),
        "normal":   (1.25, 1.5, 1.0),
        "stressed": (1.75, 3.0, 0.5),
    }[rsv["state"]]
    adj["spread_mult"], adj["impact_mult"], adj["size_mult"] = scaling
    adj["fee_mult"] = 1.0       # [default] per-share fees are regime-invariant
    adj["borrow_mult"] = 1.0    # [default] financing unaffected by depth regime
    adj["slice"] = (rsv["state"] == "stressed")                       # [default]
    adj["max_participation"] = 0.10 if rsv["state"] == "stressed" else 1.0  # [default]
    adj["trade_ok"] = True      # [default] the regime sizes; it never vetoes
    return adj
```

Effective cost = `spread_bps × spread_mult + impact_bps × impact_mult + fee_bps × fee_mult + borrow_bps × borrow_mult` — multiplicative on the scaled components only. Pinned by acceptance test `17`.
