## §R1 Precise definition

Bollinger Bandwidth `BW = (Upper − Lower)/Middle`, `n = 20`, `k = 2` [documented] Bollinger defaults. Squeeze iff `BW_t` < 10th percentile of its own trailing history [example]. Head-fake filter: require compression ≥ `6` bars [example].

## §R2 Exact calculation

$$BW = \frac{Upper - Lower}{Middle}, \qquad n=20,\ k=2 \ \text{[documented]}$$

Percentile-rank `BW_t` vs trailing `120` [example] bars (chapter minimum `5` [default] for the reference fixture). Keltner cross-check: bandwidth from ATR bands must show the squeeze too, or the state is `UNKNOWN` (F3).

**Data inputs.** daily closes + `20`+ prior days [documented minimum]; split-adjusted.

**Cadence.** daily; intraday on 15-min bars for day-trading.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Breakout entries | **amplifies then inverts** | improves from squeeze (measured move ≈ expansion to median width); dies when entering after expansion (buying the exhaustion tail) — bandwidth mean-reverts |
| Iron-condor / short-strangle premium sellers | **amplifies** | improves entering at expansion extremes (IV rich, width about to contract) |
| Range-fade | **inverts** | fade-the-band dies once expansion starts |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** tracks BW percentile; publishes RSV.
- **Verifier:** recomputes with Keltner (ATR-based) bands — the squeeze must appear on *both* or `UNKNOWN` (F3).
- **Grok-Researcher:** proposes percentile windows; leads only.
- **Adversary:** appends a synthetic breakout bar and checks the percentile used at t does not move (lookahead audit).
- **Gate:** rejects any chapter that assigns direction to the squeeze; rejects split-unadjusted inputs.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Post-squeeze expansion widens expected slippage on breakout entries (exhaustion tail): the adjustment demands a larger measured move before entry and vetoes fade-the-band entries during expansion.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'expansion':
        adj['slip_mult'] = 2.0      # [example] exhaustion tail
        adj['fade_veto'] = True     # [default] do not fade the band
    elif rsv['state'] == 'squeeze':
        adj['arm_breakout'] = True  # [default] arm, do not fire
        adj['slip_mult'] = 1.0      # [default]
    else:
        adj['slip_mult'] = 1.0      # [default]
    return adj
```
