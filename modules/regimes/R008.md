### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes. The percentile at `t` ranks `BW_t` against bandwidth
  values strictly before `t` (mid-rank ties, [default]).
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; BW percentile at t uses closes ≤ t; gates t+1+ entries).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts == indicator_ts` for every prefix and that appending a synthetic
  breakout bar does not move the trailing percentile used at `t`.
- **Detection lag (honest):** the `6`-bar [example] confirmation gate plus
  estimator warm-up impose a minimum detection lag of `min_compression_bars`
  bars after labeling begins; the fixed-window BB can additionally lag
  compression onset by up to `bb_n` bars [example] while the Verifier already
  confirms — during that window the module emits `UNKNOWN` (F3), never a
  forced label.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Bollinger Bandwidth `BW = (Upper − Lower)/Middle`, `n = 20`, `k = 2`
[documented] Bollinger defaults. Let `pct_t` be the mid-rank percentile of
`BW_t` against its trailing `252` [default] bandwidth values (strictly prior
bars). **Squeeze** is a *confirmed* state, entered only after
`min_compression_bars = 6` [example] consecutive bars with
`pct < 10` [example] (strict), and exited when `pct > 20` [example] (strict)
— the `10–20` [example] band is hysteresis: inside it the state holds.
**Expansion** is entered when `pct > 90` [example] (strict) and exited when
`pct < 80` [example] (strict). Boundary values (`10.0`, `20.0`, `80.0`,
`90.0`) never trigger a transition — pinned by boundary unit tests. The
Verifier recomputes the same percentile/FSM on Keltner (ATR) bandwidth with
multiplier `1.5` [documented] (Carter); both estimators must agree on the
state label or the module emits `UNKNOWN` (F3). No direction is ever assigned
to the squeeze.

## §R2 Exact calculation

$$BW = \frac{Upper - Lower}{Middle}, \qquad n=20,\ k=2 \ \text{[documented]}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
DETECT(events, cfg) -> RegimeState:                      # R008 v1.1.0
 1. Sort events by event_ts ascending, newest last.
    If empty -> return UNKNOWN(state='missing').                       # F1
 2. For each event e: require finite e.c > 0 and integer e.event_ts > 0;
    else -> UNKNOWN(state='invalid'). Never interpolate.               # F1
 3. dates = UTC calendar dates of event_ts. Require every date to be a
    trading day (weekday and not in cfg.holidays); else -> UNKNOWN('invalid').
 4. expected = all trading days in [dates.first, dates.last].
    If any expected date is absent from the feed -> UNKNOWN('missing').# F1
    (Weekend/holiday gaps are expected; a missing trading-day bar is not.)
 5. For t in 1..N-1: if |ln(c_t / c_{t-1})| > cfg.max_single_bar_logret
    (0.693 [example] = ln 2) -> UNKNOWN(state='corp_action').
    (Split/dividend-unadjusted input signature; feed must be adjusted.) # F1
 6. SENTINEL (Bollinger): for t >= bb_n-1:
      mid_t = SMA(c, bb_n); sd_t = sample stdev(c, bb_n, ddof=1) [default]
      bw_t  = 2*bb_k*sd_t / mid_t            # == (Upper-Lower)/Middle
 7. VERIFIER (Keltner/ATR): ema seeded by SMA(c, kc_n) [default],
      alpha = 2/(kc_n+1); ATR by Wilder's smoothing [documented];
      tr_t  = max(h-l, |h-c_prev|, |l-c_prev|) when h/l present [documented],
              else |c_t - c_{t-1}| (close-only fallback) [example];
      kw_t  = 2*kc_m*atr_t / ema_t, kc_m = 1.5 [documented] (Carter).
 8. F2: if bw at the newest bar is not in [0, cfg.f2_bw_max] ([0,5] [example])
    or non-finite -> UNKNOWN(state='out_of_bounds').
 9. For each estimator series x in {bw, kw}, for each bar t:
      hist_t = last min(pct_window, available) values of x strictly before t;
      if |hist_t| < pct_min_history (60 [default]) -> label 'undefined'
      else pct_t = (#{h < x_t} + 0.5*#{h == x_t}) / |hist_t|   # mid-rank [default]
10. compression_age_t = age_{t-1}+1 if pct_t < squeeze_entry/100 else 0.
11. HYSTERESIS FSM (causal, per estimator), entry strict / exit strict:
      if state == 'squeeze':    hold unless pct_t > squeeze_exit/100  -> 'normal'
      elif state == 'expansion': hold unless pct_t < expansion_exit/100 -> 'normal'
      else: # 'normal'
        if age_t >= min_compression_bars and pct_t < squeeze_entry/100 -> 'squeeze'
        elif pct_t > expansion_entry/100 -> 'expansion'
        else -> 'normal'
12. ALIGNMENT: a bar is labeled only when BOTH estimators leave 'undefined';
    before that -> DEGRADED(state='warming'), labels withheld (never faked).
13. F3: if sentinel_state_t != verifier_state_t -> UNKNOWN (keep the
    sentinel's label; module_state UNKNOWN). Disagreement is expected for up
    to ~1 bandwidth window [example] around regime transitions — the module
    stays blind rather than whipsawing.
14. F4: if now - computed_at > 3*cadence [default] -> UNKNOWN (staleness).
15. F5: any regime-gated backtest-period selection requires a pre-registered
    (grid, objective, seed) definition; else raise.
16. Emit RegimeState{regime_id='R008', state, value=bw_t,
    estimator_version='1.1.0', data_vintage, computed_at=event_ts(newest),
    module_state}. The label may gate only trades at t+1 or later.
```

### Detection calibration recipe (no hand-tuned magic numbers)

The `calibrate`-status parameters (`pct_window`, `squeeze_entry`,
`squeeze_exit`, `expansion_entry`, `expansion_exit`,
`min_compression_bars`) are set by this protocol, pre-registered before
running (F5). The recipe itself is [example] — a proposed protocol, not a
published study.

- **Data:** split/dividend-adjusted daily closes, US common stocks, ≥ `5`
  years [example] per name; multiple names (≥ `20` [example]) to avoid
  single-name overfit.
- **Protocol:** expanding-window walk-forward. Train on the expanding window;
  evaluate on the next `252`-bar [default] out-of-sample block; `5`-bar
  [example] embargo gap between train end and OOS start (no shared bandwidth
  windows across the boundary).
- **Grid [example]:** `squeeze_entry ∈ {5, 10, 15}`, `squeeze_exit ∈ {15, 20,
  30}`, `expansion_entry ∈ {85, 90, 95}`, `expansion_exit ∈ {70, 80}`,
  `pct_window ∈ {60, 120, 252}`, `min_compression_bars ∈ {3, 6, 10}` →
  `486` configurations [example].
- **OOS objective [example]:** `precision = P(5-day forward realized vol ≥
  1.5× trailing-20d RV | squeeze confirmed)`; `flip_rate` = share of bars
  within `2` bars of a state change; `score = precision − 0.25 × flip_rate`.
  Reject configurations with OOS squeeze occupancy outside `[2%, 30%]`
  [example] (degenerate always/never-squeeze).
- **Selection:** highest `score` on embargoed OOS only; grid, objective, and
  seed logged before the run (F5); winner must beat the chapter defaults on
  a held-out name set or defaults stand.
- **Re-calibration cadence:** annual [default]; early re-trigger if the
  `60`-day [example] rolling state-flip rate exceeds `2`× [example] the
  calibration baseline, or if the `252`-day [default] BW distribution shifts
  (KS test `p < 0.01` [example]).

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Breakout entries | **amplifies then inverts** | improves from squeeze (measured move ≈ expansion to median width); dies when entering after expansion (buying the exhaustion tail) — bandwidth mean-reverts |
| Iron-condor / short-strangle premium sellers | **amplifies** | improves entering at expansion extremes (IV rich, width about to contract) |
| Range-fade | **inverts** | fade-the-band dies once expansion starts |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** tracks BB bandwidth percentile + hysteresis FSM; publishes RSV.
- **Verifier:** recomputes with Keltner (ATR) bandwidth, Wilder's smoothing
  [documented], multiplier `1.5` [documented] (Carter) — the squeeze must
  appear on *both* estimators' labels or `UNKNOWN` (F3). The two estimators
  adapt at different speeds, so transitions pin `UNKNOWN` for up to `~1`
  bandwidth window [example] rather than whipsawing.
- **Grok-Researcher:** proposes percentile windows and calibration grids; leads only.
- **Adversary:** appends a synthetic breakout bar and checks the percentile used at t does not move (lookahead audit).
- **Gate:** rejects any chapter that assigns direction to the squeeze; rejects split-unadjusted inputs; rejects labels emitted before both estimators are warmed up.
- **F1–F5 instantiated:** F1 missing/stale/invalid → `UNKNOWN` (restrictive downstream), calendar-gap check (no interpolation), corporate-action guard `|ln| > 0.693` [example]; F2 bounds `[0, 5]` [example] on every emission; F3 dual-estimator label agreement or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`; F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

The adjustment maps the regime state onto the 4-component cost stack
(`spread_bps`, `fee_bps`, `borrow_bps_per_day`, `impact_bps`) plus gating
flags. Which components scale, by how much, and with what tag:

| Regime state | Cost-component adjustment | Tag |
|---|---|---|
| `squeeze` (confirmed) | no component scaled; sets `arm_breakout=true` (arm, do not fire) and `fade_veto=true` | [default] |
| `expansion` | `impact_bps × 2.0` (exhaustion tail); `spread_bps × 1.25`; fade entries `trade_ok=false` (`fade_veto`) | [example] / [default] |
| `normal` | baseline (no adjustment) | [default] |
| `DEGRADED` (warming) | `size_mult × 0.5` (halve, do not stand down fully) | [default] |
| `UNKNOWN` | `size_mult = 0.0`, `trade_ok=false` (restrictive stand-down) | [default] |

`fee_bps` and `borrow_bps_per_day` are never touched by this regime
[default] — the squeeze modulates slippage, not fees or borrow.

```python
def cost_adjustment(rsv, base):
    """rsv: regime_state_vector dict; base: dict with spread_bps, fee_bps,
    borrow_bps_per_day, impact_bps, trade_ok, size_mult, edge_mult."""
    adj = dict(base)
    if rsv.get("module_state") == "UNKNOWN":
        adj["size_mult"] = 0.0   # [default] restrictive stand-down
        adj["trade_ok"] = False  # [default]
        return adj
    if rsv.get("module_state") == "DEGRADED":
        adj["size_mult"] = min(adj.get("size_mult", 1.0), 0.5)  # [default]
    if rsv["state"] == "expansion":
        adj["impact_bps"] = adj["impact_bps"] * 2.0  # [example] exhaustion tail
        adj["spread_bps"] = adj["spread_bps"] * 1.25  # [example]
        adj["fade_veto"] = True   # [default] never fade the band in expansion
    elif rsv["state"] == "squeeze":
        adj["arm_breakout"] = True  # [default] arm, do not fire
        adj["fade_veto"] = True     # [default] never fade the band while arming
    return adj
```

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Breakout bar contaminates the percentile window → detect: Adversary appends a bar, trailing percentile used at t must not move → action: none (causal by construction) | `check: label_t unchanged by bar t+1` |
| 2 | Split/dividend-unadjusted input → detect: single-bar `|ln| > 0.693` [example] → action: `UNKNOWN` (`corp_action`), require `adjusted=true` at ingest → recovery: re-ingest adjusted closes, recompute | `check: corp_action guard` |
| 3 | Missing trading-day bar in feed → detect: calendar check vs expected trading days → action: `UNKNOWN` (`missing`), never interpolate → recovery: backfill, then recompute | `check: expected_trading_days coverage` |
| 4 | Trading halt mid-session → detect: halt flag / market-state table → action: freeze state, emit `UNKNOWN`, discard contributions across reopen → recovery: resume on next continuous bar | `check: market-state table` |
| 5 | Sentinel/Verifier disagree at a regime transition → detect: F3 label mismatch → action: `UNKNOWN` (restrictive; expected up to `~1` bandwidth window [example]) → recovery: automatic on re-agreement; page if the stretch exceeds `20` bars [example] (stuck transition) | `check: F3-fires-only-at-transitions` |
| 6 | Stale feed → detect: `now - computed_at > 3`× cadence [default] → action: `UNKNOWN`, page → recovery: fresh bar recomputes | `check: staleness test` |
| 7 | Insufficient history (new listing, feed start) → detect: < `60` [default] bandwidths on either estimator → action: `DEGRADED`/`warming`, labels withheld → recovery: automatic once warmed | `check: warmup is DEGRADED` |
| 8 | Intraday (`15`-min) squeeze requested on a SIP-less/EOD-only stack → detect: cadence/entitlement assertion at deploy → action: honest `OFF`/`UNKNOWN` — only daily labels supported without consolidated intraday bars → recovery: provision SIP entitlement (Alpaca SIP `~$99`/mo [unverified]; Polygon Starter `$29`/mo [documented]) or stay daily | `check: deployment assertion` |
| 9 | Flip-flop: ≥ `3` state changes in `10` bars [example] → detect: monitoring rule on the decision log → action: `DEGRADED` + recalibration review trigger → recovery: recalibrate per §R2 recipe | `check: monitoring alert` |
