### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; funding prints per interval; the label uses the latest settled interval).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Annualized funding `f_ann = f_8h × 3 × 365` (simple; `0.01% × 3 × 365 = 10.95%` [documented arithmetic]). Cross-check: median venue mean; relative tolerance `0.3` [default]. Verifier requires cross-venue agreement on sign [documented RB-list].

## §R2 Exact calculation

$$f_{ann} = f_{8h}\times 3\times 365 \quad\text{[documented]}$$

Worked example [documented Grok RB2]: mean 8h rate `0.020%` → `0.00020 × 3 × 365 = 21.9%` ⇒ moderately elevated. Bands [example]: `< 5%` balanced · `5–20%` leaning · `20–50%` crowded · `> 50%` extreme.

## §R5 Cost interface: regime state → cost-function adjustment

Funding is a direct holding-cost line: the adjustment adds the annualized funding rate to the cost model — extreme funding can exceed the signal's expected move, which is when naked longs are cut.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    adj['funding_ann'] = rsv['value']  # [documented] direct P&L line
    if rsv['state'] == 'extreme':
        adj['size_mult'] = 0.25       # [example] rented trend
    elif rsv['state'] == 'crowded':
        adj['size_mult'] = 0.5        # [example]
    else:
        adj['size_mult'] = 1.0        # [default]
    return adj
```
