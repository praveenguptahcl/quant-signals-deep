### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; quotes at t label t; execution at t+1+ uses the label).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **Hysteresis is causal:** the state machine carries only the *previously
  emitted* label; the label at `t` never depends on data after `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Proportional quoted spread as a fraction [documented definition]:

$$\text{QS}_t = \frac{2(A_t - B_t)}{A_t + B_t}$$

in bps: `qs_bps = 10000 × QS_t`. Time-weighted over the session
[documented]. The regime is the percentile of today's TW-QS against its
`252`-day [default] history — the absolute level (e.g. `3` bps [example]) is
not portable across names or venues.

## §R2 Exact calculation

### R2.1 Normative pseudocode

The pseudocode is normative; prose is commentary. All spreads in bps.

```
function detect(state, events, cfg):                        # §R0.1
    # --- 1. ingest: causal order, reject bad quotes (F1) ---
    quotes = []
    for e in events sorted by e.event_ts ascending:         # newest last
        if e.event_ts > asof: continue                      # future-stamped: hold
        if market_state(e) in {HALTED, AUCTION}:             # §R0.6
            freeze(); continue
        if e.quote_cond in {CROSSED, LOCKED, FAST}:          # reject set [default]
            continue                                        # never interpolate (F1)
        if not (e.ask > e.bid > 0): continue                # crossed/invalid: reject
        quotes.append(e)
    if len(quotes) == 0:
        return RegimeState(state='invalid', module_state=UNKNOWN)        # F1
    # --- 2. quote lifetimes by supersession ---
    for i, q in enumerate(quotes):
        q.life = quotes[i+1].event_ts - q.event_ts  if i < n-1
               else min(session_close, asof) - q.event_ts
    # --- 3. time-weighted quoted spread, bps [documented] ---
    qs_i = 20000 * (q.ask - q.bid) / (q.ask + q.bid)         # = 10000 * 2(A-B)/(A+B)
    TW   = sum(qs_i * q.life) / sum(q.life)
    if len(quotes) < cfg.min_quotes_per_day:                # 50 [default]
        return RegimeState(value=TW, state='insufficient',  # value known,
                           module_state=DEGRADED)           # label withheld
    # --- 4. dual estimators (F3) ---
    MU = mean(qs_i)                                         # unweighted verifier
    if abs(TW - MU) / max(TW, MU, eps) > cfg.dual_tol:      # 0.25 [default]
        return RegimeState(value=TW, module_state=UNKNOWN)  # F3
    roll = 2 * sqrt(max(0, -cov(ΔP_trades)))                # Roll 1984 [documented]
    if cov(ΔP_trades) > 0: roll = 0                         # no veto (Grok rule)
    # --- 5. percentile vs trailing history ---
    pct = (count(h < TW) + 0.5 * count(h == TW)) / len(history)
    raw = 'extreme' if pct >= cfg.extreme_pct/100           # 90 [default], inclusive
          else 'wide' if pct >= cfg.wide_pct/100            # 50 [default], inclusive
          else 'normal'
    # --- 6. hysteresis state machine ---
    prev = state.prev_label                                # None on first run
    if prev is None or severity(raw) >= severity(prev):
        label = raw                                       # worsening adopts immediately
    elif pct*100 < release_band(prev):                    # extreme->85, wide->45 [default]
        label = raw                                       # release band crossed
    else:
        label = prev                                      # hold: no flip-flop
    # --- 7. emit ---
    return RegimeState(regime_id='R010', state=label, value=TW,
                       estimator_version='1.1.0',
                       computed_at=quotes[-1].event_ts,    # == indicator_ts
                       module_state=OK)
```

`severity = {normal: 0, wide: 1, extreme: 2}` [default];
`release_band('extreme') = extreme_pct − hyst_band`;
`release_band('wide') = wide_pct − hyst_band`;
`hyst_band = 5.0` [default] percentile points.

**Threshold bands (entry = raw label; release = exit the held label):**

| Label | Entry (raw) | Release held label when |
|---|---|---|
| normal | pct `< 50` [default] | — |
| wide | `50 ≤` pct `< 90` [default] | pct `< 45` [default] |
| extreme | pct `≥ 90` [default] | pct `< 85` [default] |

Boundaries are inclusive at the top of each band: pct exactly `50` →
`wide`; pct exactly `90` → `extreme` (pinned by fixture
`R010_hysteresis.csv` rows `8`–`9` [example]).

### R2.2 Edge cases (normative)

- **Missing bars / session gaps:** a day with fewer than
  `min_quotes_per_day` valid quotes → `DEGRADED`, label withheld, value
  still emitted; no interpolation (F1). The day is skipped in the trailing
  history.
- **Halts / auctions:** freeze per §R0.6; quotes inside the halt window and
  contributions spanning the reopen are discarded.
- **Corporate actions:** the proportional QS is split-invariant by
  construction [documented property] — no rebase needed for the primary
  estimator (pinned by `test_split_invariance`). Trade prices feeding the
  Roll cross-check MUST be split-adjusted via the splits reference feed
  before the covariance; an unadjusted price discontinuity > `2`% [default]
  of prior close with no corporate-action record → `UNKNOWN` for the day
  (F1).
- **Crossed/locked NBBO:** reject the quote. If the rejected share >
  `50`% [default] of the session's quotes → `UNKNOWN` (F1).
- **Out-of-order / duplicate events:** dedupe on `sequence_number`, sort by
  `event_ts`; `event_ts > asof` → hold for the next cadence.
- **First run / empty history:** label withheld (`DEGRADED`) until history ≥
  `63` days [default]; the `[example]` synthetic history is for fixtures
  only, never production.

### R2.3 Calibration recipe (no hand-tuned thresholds)

No threshold in §R0.2 may be changed by hand. To calibrate:

1. **Data:** ≥ `252` [default] trading days of TW-QS (SIP Starter quotes),
   own execution fills with realized spread cost per trade, per-venue labels
   if available.
2. **Grid:** `hist_window ∈ {63, 126, 252, 378, 504}` [default];
   `wide_pct ∈ {40, 50, 60}` [default]; `extreme_pct ∈ {85, 90, 95}`
   [default]; `hyst_band ∈ {2.5, 5.0, 7.5}` [default];
   `min_quotes_per_day ∈ {25, 50, 100}` [default].
3. **Objective (walk-forward, `63`-day [default] folds, `5`-day [default]
   embargo):** minimize OOS cost-forecast MAE =
   `mean|forecast_spread_cost − realized_spread_cost|` plus a flip-flop
   penalty (label changes on > `5`% [default] of days).
4. **Selection:** best OOS objective; ties → the more restrictive (higher
   `extreme_pct`). Changing any threshold without re-running this recipe is
   a validation failure.
5. **Re-calibration cadence:** quarterly [default], or after a
   volatility-regime break; every change logged in the §0 changelog.

**Data inputs.** NBBO bid/ask + quote lifetimes (or trade prints for Roll/CS); per-venue for routing decisions.

**Cadence.** daily label; recomputed intraday for execution.

Cross-check [documented]: Roll (1984) `2√(−cov(ΔP))`; Corwin–Schultz (2012)
from daily high/low. Grok's production rule [documented Grok RB1]: if Roll
cov > 0, Roll = 0 and it is *not used to veto* the time-weighted spread. The
reference test's second estimator is the simple (unweighted) mean quoted
spread with relative tolerance `0.25` [default] — same quotes, different
aggregation.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** publishes TW-QS percentile RSV per venue (composite NBBO on
  SIP-only; `DEGRADED` if per-venue requested).
- **Verifier:** recomputes from a second feed (or Corwin–Schultz); cov > 0 ⇒ Roll = 0, no veto (documented Grok rule).
- **Grok-Researcher:** proposes window lengths; leads only.
- **Adversary:** injects a crossed/locked NBBO and a venue outage to test F1/F4; injects band-edge percentiles (`50`, `90`) to test hysteresis.
- **Gate:** rejects absolute-spread cutoffs applied cross-name; rejects backtests that ignore spread widening; rejects threshold changes that skipped the §R2.3 recipe.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Spread is the dominant cost term. The adjustment passes the **measured**
TW-QS through as the spread-cost basis (no invented level) and uses the
regime state only for the forward-conservatism multiplier and routing
constraints. **Only the spread adder of the 4-component cost stack scales —
fees, borrow, and impact are untouched by this regime.**

| Component | normal | wide | extreme |
|---|---|---|---|
| `trade_ok` | `True` | `True` | `False` [default] — cost dominates edge |
| routing constraint | none | `limit_only = True` [default] — no marketable flow | n/a (blocked) |
| `spread_mult` (forward conservatism) | `1.0` [default] | `2.0` [default] | `4.0` [default] |
| `spread_bps_per_side` | `0.5 × TW-QS × 1.0` | `0.5 × TW-QS × 2.0` | n/a |
| `spread_bps_roundtrip` | `TW-QS × 1.0` | `TW-QS × 2.0` | n/a |
| audit tag | `R010:normal@<vintage>` | `R010:wide@<vintage>` | `R010:extreme@<vintage>` |

```python
def cost_adjustment(rsv, base):
    """Maps R010 regime state onto the cost model (Session-02 cost block).
    Only the spread adder scales; fees/borrow/impact pass through unchanged."""
    tw = rsv['value']  # TW-QS in bps, measured this cadence
    adj = dict(base)
    if rsv['state'] == 'extreme':
        adj['trade_ok'] = False      # [default] cost dominates edge
        adj['spread_mult'] = 4.0     # [default] forward conservatism
    elif rsv['state'] == 'wide':
        adj['trade_ok'] = True
        adj['limit_only'] = True     # [default] no marketable flow
        adj['spread_mult'] = 2.0     # [default]
    else:
        adj['trade_ok'] = True
        adj['spread_mult'] = 1.0     # [default]
    adj['spread_bps_per_side'] = 0.5 * tw * adj['spread_mult']
    adj['spread_bps_roundtrip'] = tw * adj['spread_mult']
    adj['regime_tag'] = f"R010:{rsv['state']}@{rsv['data_vintage']}"
    return adj
```

`spread_mult` values are `[default]` starting points, calibrated by the
§R2.3 recipe (objective: OOS cost-forecast MAE), not hand-tuned.
