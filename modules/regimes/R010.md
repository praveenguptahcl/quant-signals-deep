### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; quotes at t label t; execution at t+1+ uses the label).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Quoted spread `QS_t = 2(A_t − B_t)/(A_t + B_t)` in bps; time-weighted over the session [documented definition]. Regime is the percentile of today's TW-QS against its `252`-day [default] history — the absolute level (e.g. `3` bps) is not portable.

## §R2 Exact calculation

$$\text{TW-QS} = \frac{\sum_t QS_t\cdot \text{life}_t}{\sum_t \text{life}_t} \quad\text{[documented]}$$

Regime = percentile of TW-QS vs trailing `252` [default] days (reference history is `[example]` synthetic).

Cross-check [documented]: Roll (1984) `2√(−cov(ΔP))`; Corwin–Schultz (2012) from daily high/low. Grok's production rule [documented Grok RB1]: if Roll cov > 0, Roll = 0 and it is *not used to veto* the time-weighted spread. The reference test's second estimator is the simple (unweighted) mean quoted spread with relative tolerance `0.25` [default] — same quotes, different aggregation.

**Data inputs.** NBBO bid/ask + quote lifetimes (or trade prints for Roll/CS); per-venue for routing decisions.

**Cadence.** daily label; recomputed intraday for execution.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** publishes TW-QS percentile RSV per venue.
- **Verifier:** recomputes from a second feed (or Corwin–Schultz); cov > 0 ⇒ Roll = 0, no veto (documented Grok rule).
- **Grok-Researcher:** proposes window lengths; leads only.
- **Adversary:** injects a crossed/locked NBBO and a venue outage to test F1/F4.
- **Gate:** rejects absolute-spread cutoffs applied cross-name; rejects backtests that ignore spread widening.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Spread is the dominant cost term: the adjustment maps the spread state directly onto the cost model (spread adder × `1/2/4` [example]) and blocks marketable flow in the extreme state.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    if rsv['state'] == 'extreme':
        adj['trade_ok'] = False     # [default] cost dominates edge
        adj['spread_mult'] = 4.0    # [example]
    elif rsv['state'] == 'wide':
        adj['trade_ok'] = True
        adj['limit_only'] = True    # [default]
        adj['spread_mult'] = 2.0    # [example]
    else:
        adj['trade_ok'] = True
        adj['spread_mult'] = 1.0    # [default]
    return adj
```
