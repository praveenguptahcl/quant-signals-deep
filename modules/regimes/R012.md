## §R1 Precise definition

Amihud (2002) [documented]: `ILLIQ = (1/D) Σ |R_d| / VOLD_d`, scaled by `1e6` [documented]. Averages the daily price-impact-per-dollar over `D = 10` [default] days. Regime = percentile of ILLIQ against its own trailing history, with hysteresis entry/exit bands (`60`/`50`, `90`/`80` [default] — calibrated, §R0.2). The `1e6` scale is the documented Amihud convention; the bands are defaults with calibration recipes, not magic numbers.

## §R2 Exact calculation

$$\text{ILLIQ}_t = 10^6\cdot\frac{1}{n_t}\sum_{d\in W_t} \frac{|R_d|}{\text{VOLD}_d} \quad\text{[documented]}$$

where $W_t$ is the window of the `D = 10` [default] expected calendar bars
ending at `t`, $n_t$ the number of present valid bars ($n_t \ge D -
\texttt{max\_missing} = 9$ [default] required for `OK`), and missing/halted
bars are masked — never interpolated. Percentile ties resolve within
`1e-9` [default] relative tolerance. The `1e6` scale is `[documented]`
(Amihud 2002 convention); percentile cutoffs are calibrated (`[default]`,
recipes in §R0.2), never magic.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function detect(state, events, cfg) -> RegimeState:
    assert events non-empty else return UNKNOWN                        # F1
    sort events by event_ts; newest = events[-1]
    if newest.halt: return UNKNOWN(hold state.last_label)              # market-state table: freeze
    grid = [newest.event_ts - k*DAY_ns for k in D-1..0]                # expected calendar bars
    ratios = []                                                        # (r_cc, r_oc) per bar
    for g in grid:
        b = bar_at(g)                        # exact-ts lookup; absent -> masked
        if b is None or b.halt: continue     # mask: no interpolation, ever
        assert b has fields and finite and b.absret >= 0               # F1
                 and b.vold > 0 and b.o > 0 and b.c > 0 else return UNKNOWN
        assert not (b.corpact and not b.adj) else return UNKNOWN       # unadjusted corp action: Gate rejects
        assert b.event_ts not duplicated else keep-first + log         # [default]
        r_cc = b.absret / b.vold * SCALE        # close-to-close (Sentinel)
        r_oc = |ln(b.c / b.o)| / b.vold * SCALE # open-to-close (Verifier)
        ratios.append((r_cc, r_oc))
    n = len(ratios)
    assert n >= 1 else return UNKNOWN                                   # F1: empty window
    ILLIQ = mean(r_cc for (r_cc, _) in ratios)                         # [documented]
    if n < D - max_missing:                                            # [default] 9 of 10
        return DEGRADED(state="warming", value=ILLIQ)                   # label withheld; value still emitted
    dmax = max(|r_cc - r_oc| / max(r_cc, r_oc, 1e-9))                  # [default] eps floor
    if dmax > dual_tol: return UNKNOWN                                 # F3: gap-distorted day -> restrictive
    assert 0 <= ILLIQ <= 1e6 else return UNKNOWN                       # F2: bound derivation below
    p = pct_rank(ILLIQ, hist, tie_tol=1e-9)                            # [default]
    label = HYSTERESIS(state.last_label, p, cfg)                       # entry/exit table below
    state.last_label = label
    return OK(RegimeState(regime_id="R012", state=label, value=ILLIQ,
                          estimator_version="1.1.0", data_vintage=vintage,
                          computed_at=newest.event_ts))
```

**Hysteresis state transitions** (inclusive boundaries; entry ≥, exit ≤):

| prev label | condition on `p` | next label |
|---|---|---|
| none (cold start) | `p < 60` / `60 ≤ p < 90` / `p ≥ 90` | normal / illiquid / extreme |
| normal | `p ≥ 90` / `p ≥ 60` / else | extreme / illiquid / normal |
| illiquid | `p ≥ 90` / `p ≤ 50` / else | extreme / normal / illiquid |
| extreme | `p ≤ 80` / else | illiquid / extreme |

Extreme always steps down through illiquid — a direct extreme→normal jump is
forbidden (a single mild day does not erase a liquidity crisis). Entry/exit
separation is ≥ `10`pp [default]; a single-threshold design flip-flops and is
rejected by the Gate.

**F2 bound derivation.** `ILLIQ = 1e6 · mean(|R|/VOLD) ≤ 1e6 ·
max|R|/min(VOLD)`; with `max|R| = 1` [default] (a `100`% daily move) and
`min VOLD = $1` [default] as the sanity floor, any value above `1e6`
[default] is a data error (e.g. zero-volume division), never a real
illiquidity reading → `UNKNOWN`.

**Edge cases (normative).**
- *Missing bars:* expected calendar grid points with no bar are masked; the
  mean is over present bars only; `max_missing = 1` [default] tolerated for
  `OK`, more → `DEGRADED` (label withheld). Never forward-fill.
- *Halts:* a halt-flagged newest bar freezes the state vector and emits
  `UNKNOWN` (market-state table); halted bars inside the window are masked
  and their contributions discarded across the reopen.
- *Corporate actions:* `adj` must be `1` on every bar; a `corpact=1, adj=0`
  bar → `UNKNOWN` until an adjusted series arrives. Volume discontinuities
  from splits must never enter the mean.
- *Zero/negative volume, NaN, negative |R|:* F1 → `UNKNOWN`, never
  interpolated or clamped.
- *Penny stocks:* price < `$1` [default] → Gate excludes or winsorizes; the
  `1e6` scaling explodes on sub-dollar VOLD.
- *Duplicate `event_ts`:* keep first, log the collision [default].
- *Weekend/holiday gaps:* calendar-normal; the grid is trading-day based, so
  they are not "missing".

**Data inputs.** daily |R| (close-to-close), dollar volume (shares × close,
client-side), open/close for the OC cross-check; split/dividend-adjusted
series required; `≥ 9` of `10` [default] valid bars for `OK`.

**Cadence.** daily.

**Threshold bands (calibrated defaults; recipes in §R0.2).**

| Condition | Label | Tag |
|---|---|---|
| percentile `< 60` (entry) / `≤ 50` (exit) | normal | [default] |
| `60–90` entry band, `50–80` exit band | illiquid (cut size, patient) | [default] |
| percentile `≥ 90` (entry) / `> 80` (exit) | extreme (stand down [default]) | [default] |

| Affected family | Direction | Mechanism |

| Execution / sizing | **amplifies** | illiquid → smaller clips, longer horizons; extreme → demand explicit premium |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes ILLIQ daily over the grid-anchored `D`-bar window (missing/halted bars masked); publishes RSV.
- **Verifier:** recomputes with open-to-close returns; max daily relative CC/OC disagreement `> 0.3` [default] → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes D; leads only.
- **Adversary:** injects a high-|R|/normal-depth day to test the OC cross-check.
- **Gate:** rejects cross-name absolute ILLIQ ranking; rejects unadjusted volume.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

ILLIQ is a price-impact coefficient, so it scales the **impact** component of
the 4-component cost stack directly; **spread** widens empirically in
illiquid states; **fees** and **borrow** do not scale with ILLIQ. The caller
computes the adjusted stack as

`expected_cost_bps = spread_bps×spread_mult + fee_bps×fee_mult + borrow_bps×borrow_mult + impact_bps×impact_mult`

and enforces the `trade_ok` gate and `size_mult` in position sizing. All
multipliers below are `[example]` until calibrated against execution data
(see GROK-NEEDED in §R10); the structure — which components scale — is
`[default]`.

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, fee_bps, borrow_bps, impact_bps, trade_ok, size_mult)
    adj = dict(base)
    st = rsv.get('state')
    if st == 'extreme':
        adj['trade_ok'] = False        # [default] demand the illiquidity premium explicitly
        adj['impact_mult'] = 5.0       # [example]
        adj['spread_mult'] = 2.0       # [example]
        adj['size_mult'] = 0.25        # [example]
    elif st == 'illiquid':
        adj['trade_ok'] = True
        adj['impact_mult'] = 2.0       # [example]
        adj['spread_mult'] = 1.5       # [example]
        adj['size_mult'] = 0.5         # [example]
    else:  # normal
        adj['trade_ok'] = True
        adj['impact_mult'] = 1.0       # [default]
        adj['spread_mult'] = 1.0       # [default]
        adj['size_mult'] = 1.0         # [default]
    adj['fee_mult'] = 1.0              # [default] fees do not scale with ILLIQ
    adj['borrow_mult'] = 1.0           # [default] borrow does not scale with ILLIQ
    adj['reason'] = 'R012:' + str(st)  # [default] provenance tag on the adjustment
    return adj
# UNKNOWN rsv: the caller applies the restrictive default — halve size /
# widen stops / stand down — never treated as benign (F1).
```

Component mapping (normative): `impact` — scales with the ILLIQ bucket
(Amihud ILLIQ *is* the linear impact coefficient [documented]); `spread` —
scales with the empirical widening factor; `fee`, `borrow` — untouched.
`size_mult` feeds the T-module position-size cap; `trade_ok=False` vetoes
entry but never forces an exit (exits are the strategy's own logic).

|---|---|---|
| 1 | Overnight-gap-distorted day (big CC |R|, flat OC) → detect: max daily CC/OC relative disagreement `> 0.3` [default] (F3) → action: `UNKNOWN` (restrictive downstream) → recovery: automatic when the next clean window agrees | `check: dual daily max-rel` |
| 2 | Cross-name absolute ILLIQ ranking → detect: Gate static review finds absolute comparison → action: reject at review; the label is a within-name percentile only | `check: within-name percentile` |
| 3 | Corporate action on unadjusted series → detect: `corpact=1, adj=0` bar (F1) → action: `UNKNOWN` until an adjusted series arrives → recovery: re-ingest adjusted history, replay fixture | `check: adj=1 on all bars` |
| 4 | Trading halt → detect: newest bar `halt=1` → action: freeze state vector, emit `UNKNOWN` (market-state table); window bars masked across the reopen → recovery: first clean bar resumes | `check: halt flag` |
| 5 | Missing bars in the feed → detect: grid point with no bar → action: mask (never interpolate); `n < D − max_missing` → `DEGRADED` (label withheld) → recovery: on refill, recompute causally | `check: mask, no interpolation` |
| 6 | Zero/negative volume, NaN, negative |R| → detect: field validation (F1) → action: `UNKNOWN` → recovery: fix the ingest row, never clamp | `check: vold>0, finite` |

| 10 | Stale feed (`computed_at` older than `3`× cadence [default]) → detect: F4 staleness watchdog → action: `UNKNOWN`, page → recovery: fresh bar clears automatically | `check: staleness TTL` |

DEGRADED vs UNKNOWN discipline: `DEGRADED` = the module is working but the
label is not trustworthy yet (warm-up, auction); downstream may use the raw
value with widened bands. `UNKNOWN` = the module cannot vouch for its output
(bad input, disagreement, staleness, halt); downstream must treat it as
restrictive (halve size / widen stops / stand down), never as benign.
