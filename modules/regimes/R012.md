### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; ILLIQ at t uses days ≤ t; sizes t+1+ flow).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Amihud (2002) [documented]: `ILLIQ = (1/D) Σ |R_d| / VOLD_d`, scaled by `1e6` [documented]. Averages the daily price-impact-per-dollar over `D = 10` [default] days. Regime = percentile vs own history [example cutoffs].

## §R2 Exact calculation

$$\text{ILLIQ} = 10^6\cdot\frac{1}{D}\sum_{d=1}^{D} \frac{|R_d|}{\text{VOLD}_d} \quad\text{[documented]}$$

Cross-check [documented design]: open-to-close `|ln(C/O)|` version with relative tolerance `0.3` [default].

**Data inputs.** daily |R|, dollar volume; open/close for the OC cross-check; corporate-action adjusted.

**Cadence.** daily.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| percentile `< 60` | normal | [example] |
| `60–90` | illiquid (cut size, patient) | [example] |
| percentile `> 90` | extreme (stand down [default]) | [example] |

The `1e6` scale is `[documented]`; percentile cutoffs are `[example]`.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes ILLIQ daily; publishes RSV.
- **Verifier:** recomputes with open-to-close returns; disagreement > `0.3` [default] relative → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes D; leads only.
- **Adversary:** injects a high-|R|/normal-depth day to test the OC cross-check.
- **Gate:** rejects cross-name absolute ILLIQ ranking; rejects unadjusted volume.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

ILLIQ scales the impact estimate directly: the adjustment multiplies expected market impact by the ILLIQ percentile bucket — extreme ILLIQ can make impact exceed the signal's edge, which is when `trade_ok` goes False.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    if rsv['state'] == 'extreme':
        adj['trade_ok'] = False     # [default] demand explicit premium
        adj['impact_mult'] = 5.0    # [example]
    elif rsv['state'] == 'illiquid':
        adj['trade_ok'] = True
        adj['impact_mult'] = 2.0    # [example]
        adj['size_mult'] = 0.5      # [example]
    else:
        adj['trade_ok'] = True
        adj['impact_mult'] = 1.0    # [default]
        adj['size_mult'] = 1.0      # [default]
    return adj
```
