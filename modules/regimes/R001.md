### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; the daily label is known after the close; it gates the next session's signals).
- **Percentile convention:** mid-rank including the current observation,
  `p = (#{trail < RV} + 0.5·#{trail == RV}) / n` [default]; the mid-rank bias
  `0.5/n` falls below `0.008` [default] once `n ≥ 63` [default] (the
  production minimum). The trail is strictly causal: values for bars `< t`
  only, capped at `trail_days` most recent.
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

The sample estimate of quadratic variation of log-price over a window, expressed as annualized volatility and then as a percentile of its own trailing `252`-day [default] distribution. Ex-post (realized) quantity: it needs the price path, not options. Bands are per-name — never pooled across names.

## §R2 Exact calculation

Intraday estimator (Yang–Zhang, drift-robust [documented]):

$$\sigma^2_{YZ} = \sigma^2_{overnight} + k\,\sigma^2_{open\text{-}close} + (1-k)\,\sigma^2_{RS}$$

Daily fallback (Garman–Klass [documented]):

$$\sigma^2_{GK} = 0.5\,\ln(H/L)^2 - (2\ln 2 - 1)\,\ln(C/O)^2, \qquad (2\ln 2-1) \approx 0.386294$$

Second estimator (Parkinson 1980 [documented]): $\sigma^2_P = \ln(H/L)^2 / (4\ln 2)$. Annualize with `252` [documented] trading days. Regime score: $z_{RV} = (RV_{5d} - \mathrm{median}(RV_{252d})) / \mathrm{IQR}(RV_{252d})$ or percentile $p = \mathrm{rank}(RV_{5d})/252$.

**Data inputs.** daily O/H/L/C (currency units), split-adjusted; corporate-action
factor per bar (`splitFactor` or vendor equivalent — the §R2.6 guard needs it);
optional `5-minute` bars for the intraday Yang–Zhang leg (on the §1.5 skip list).
σ in annualized decimal/percent.

**Cadence.** daily close for the level; `30`-minute [default] intraday refresh
for execution gating (intraday leg `UNKNOWN` on EOD-only feeds — §R0.3b).

**Threshold bands (entry/exit with hysteresis — §R2.7).** Values are
`[default]` starting points; production values come from the §R2.5 recipe
(status `calibrate` in §R0.2). Bands are per-name — never pooled across names.

| Band | Entry (strict) | Exit (sticky) | Tag |
|---|---|---|---|
| complacent | `p < 0.20` | stays while `p < 0.25` | [default] |
| normal | — | — | [default] |
| elevated | `p > 0.80` | stays while `p > 0.75` | [default] |
| extreme | `p > 0.95` | stays while `p > 0.90` | [default] |

A spike above the extreme entry promotes from **any** state (complacent
included); an extreme exit steps down to `elevated`, never directly to
`normal` (one step per bar [default]).

### R2.5 Detection calibration recipe (no hand-tuned magic numbers)

1. **Calibration data:** per-name SIP daily OHLC, split-adjusted,
   point-in-time; ≥ `252` bars [default] of history; corporate-action factors
   from the vendor; the evaluation/OOS window is excluded up front (F5).
2. **Grid:** `window_days ∈ {3, 5, 10, 21}` [default] ×
   `trail_days ∈ {63, 126, 252}` [default] ×
   `entry_extreme ∈ {0.90, 0.95, 0.97}` [default] ×
   hysteresis width `∈ {0.03, 0.05, 0.10}` [default]
   (`exit = entry − width`). `dual_tol_rel` is fixed at `0.25` [default],
   never tuned.
3. **OOS selection criterion:** walk-forward with `3` folds [default]. For
   each grid point compute downstream gate quality: the mean after-cost
   bps/trade of trades **blocked** by `extreme`/`UNKNOWN` minus the mean of
   trades **passed** (blocked must underperform by ≥ the expected cost —
   otherwise the gate adds no value). Feature-only fallback when no
   downstream exists: label stability (adjacent-grid agreement ≥ `0.80`
   [default]) **and** extreme-hit rate in `[0.02, 0.08]` [default] of bars
   (rejects degenerate always/never-extreme configs). Select the grid point
   maximizing the OOS objective; ties break toward the smoother config
   (wider hysteresis, longer window) [default].
4. **Re-calibration cadence:** quarterly (`recal_cadence_months = 3`
   [default]); event-driven on tick-size changes, symbol corporate actions,
   or persistent F3 disagreement; never re-fit on the live evaluation
   window (F5).
5. **Degeneracy guards:** extreme-hit rate `< 0.01` [default] on the
   calibration window → lower the entry threshold; `> 0.10` [default] → the
   name is structurally high-vol — use the z-score variant
   (`z_RV = (RV − median)/IQR`) or pool by sector; document the choice, never
   force the bands.

### R2.6 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. `bars[1..T]` newest last,
each with `event_ts` (int64 ns UTC), `o/h/l/c`, optional `adj_factor` and
`market_state`.

```
function DETECT(bars[1..T], prev_label, cfg) -> RegimeState:
  # F1 — input validity: invalid input -> UNKNOWN, never interpolate
  if T == 0: return UNKNOWN("no-bars")
  for bar in bars:
    require finite o,h,l,c; require h >= l > 0, o > 0, c > 0
    else return UNKNOWN("invalid-bar")

  # Corporate-action guard: an unadjusted jump is bad data, not volatility
  if T >= 2 and bars[T].adj_factor is NULL and bars[T-1].adj_factor is NULL:
    if bars[T].c / bars[T-1].c > cfg.adj_jump_tol
       or bars[T].c / bars[T-1].c < 1 / cfg.adj_jump_tol:
      return UNKNOWN("unadjusted-corporate-action")

  # Market-state events
  if bars[T].market_state == HALTED:
    return UNKNOWN("halted", value = DETECT(bars[1..T-1]).value)  # frozen
  auction_hold = (bars[T].market_state == AUCTION)

  # Gap policy: > 3x cadence -> UNKNOWN; (1x, 3x] -> DEGRADED, masked
  if T >= 2:
    dt = bars[T].event_ts - bars[T-1].event_ts
    if dt > 3 * CADENCE: return UNKNOWN("stale-gap")
    gap_masked = (dt > CADENCE)

  # Warm-up
  if T < cfg.window_days: return DEGRADED("warming")  # label withheld

  # Estimators (causal: window ends at T)
  for i in 1..T:
    gk[i] = max(0, 0.5*ln(h[i]/l[i])^2 - (2ln2-1)*ln(c[i]/o[i])^2)  # floor at 0 [default]
    pk[i] = ln(h[i]/l[i])^2 / (4*ln2)                              # Parkinson 1980 [documented]
  RV  = sqrt(mean(gk[T-W+1..T]) * 252)                             # W = cfg.window_days
  trail = { sqrt(mean(gk[j-W+1..j]) * 252) for j in [W..T] }       # causal only
  p = (#{x in trail: x < RV} + 0.5 * #{x in trail: x == RV}) / |trail|

  # F2 — mathematical bounds
  if not finite(RV) or RV > 5.0: return UNKNOWN("out-of-bounds")  # 5.0 [default]

  # F3 — rescaled-Parkinson agreement (variance scale); E[σ²_GK]/E[σ²_P] = 2ln2
  # under zero drift [documented], so rescaling tests contamination, not the
  # structural estimator gap
  agree(gw, pw) = |mean(gw) - 2ln2*mean(pw)| / max(mean(gw), 2ln2*mean(pw), eps)
                  <= cfg.dual_tol_rel
  if not agree(gk[T-W+1..T], pk[T-W+1..T]):
    for j in [T-W+1..T]:                       # leave-one-out: single jump bar?
      if agree(gk[..] \ {j}, pk[..] \ {j}):
        RV_loo = sqrt(mean(gk[T-W+1..T] \ {j}) * 252)
        p_loo  = (#{x in trail: x < RV_loo} + 0.5 * #{x in trail: x == RV_loo}) / |trail|
        label  = HYSTERESIS(prev_label, p_loo, cfg)
        return DEGRADED("jump-excluded", excluded_bar = j, label, RV)
    return UNKNOWN("F3-disagreement")

  label = HYSTERESIS(prev_label, p, cfg)        # §R2.7

  # Honest history rule: production needs >= min_history_days trailing bars
  if |trail| < cfg.min_history_days:
    return DEGRADED("short-trailing-history", label, RV, p)  # emitted, never OK
  if auction_hold: return DEGRADED("auction-hold", label, RV, p)
  if gap_masked:   return DEGRADED("gap-masked", label, RV, p)
  return OK(label, RV, p, computed_at = bars[T].event_ts)
```

### R2.7 State-transition table (hysteresis — normative)

Boundaries: `ee=0.95, ex=0.90, ve=0.80, vx=0.75, cx=0.25, ce=0.20` [default].
Read: entry comparisons are strict (`>` / `<`); exit is sticky — the label
persists while `p` stays on the exit side of the band. A spike `p > ee`
promotes from **any** state; an extreme exit steps down to `elevated`, never
directly to `normal` (one step per bar [default]).

| prev \ p | `> 0.95` | `0.90–0.95` | `0.80–0.90` | `0.75–0.80` | `0.25–0.75` | `0.20–0.25` | `< 0.20` |
|---|---|---|---|---|---|---|---|
| extreme | extreme | extreme (hold) | elevated (exit) | elevated | elevated | elevated | elevated |
| elevated | extreme | extreme | elevated (hold) | elevated (hold) | normal | normal | normal |
| normal | extreme | elevated | elevated | normal | normal | normal | complacent |
| complacent | extreme | normal | normal | normal | normal | complacent (hold) | complacent (hold) |

Boundary values are pinned by unit tests
(`test_hysteresis_entry_exit_boundaries`): `p = 0.95` exactly does **not**
enter extreme; `p = 0.90` exactly exits extreme.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Microstructure signals (S001/S003/S008 family) | **amplifies then inverts** | edge ∝ volatility, cost ∝ spread, and spread is modeled as convex in RV (assumption — verified per name by the §R5 multiplier calibration; if the fit rejects convexity the multipliers collapse to `1.0` [default]): improves in elevated RV (more adverse-selection edge per trade), dies in extreme RV when spreads widen beyond the edge |
| Mean-reversion (RSI-2/IBS family) | **amplifies then inverts** | improves mildly elevated (wider swings to fade); dies in extreme (trends emerge, stops detonate) — reversion assumes stationary variance |
| Trend/momentum | **amplifies** | bigger drifts in elevated RV; chop in complacent RV |
| Pairs/stat-arb | **degrades** | spreads widen in extreme RV → worse fills, better paper divergence |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes Garman–Klass RV at close + `30-min` [default] intraday refresh; publishes the RSV.
- **Verifier:** recomputes with Parkinson (1980), rescaled by `2ln2`
  [documented] so its expectation matches Garman–Klass under zero drift;
  relative disagreement beyond `0.25` [default] on the variance scale →
  leave-one-out jump recovery, else `UNKNOWN`. (The old raw `±15%`
  [default] vol-scale check sat exactly on the structural GK/Parkinson gap
  and could not distinguish contamination from estimator geometry —
  superseded in 1.1.0.)
- **Grok-Researcher:** proposes bands and window choices; all output is a lead until the Verifier reproduces it.
- **Adversary:** checks the percentile lookback excludes the evaluation window (no in-sample percentile); injects a jump day to test contamination handling; probes exact band boundaries (`p = 0.95` / `0.90`).
- **Gate:** rejects any chapter that trades the close on a percentile computed with the same close (lookahead); quarantines on persistent F3 disagreement.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 rescaled-Parkinson agreement within
  the stated tolerance or leave-one-out recovery, else `UNKNOWN`; F4 staleness
  TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Regime state → cost-function adjustment: RV level scales the **spread** and
**impact** legs of `expected_cost_bps`. Borrow and fees do not scale with
RV. `UNKNOWN` is restrictive: multipliers are undefined and
`trade_ok = False`.

| State | `spread_mult` | `impact_mult` | `borrow_mult` / `fees_mult` | `trade_ok` |
|---|---|---|---|---|
| complacent / normal | `1.0` [default] | `1.0` [default] | `1.0` [default] | `True` |
| elevated | `1.5` [example] | `2.0` [example] | `1.0` [default] | `True` (halve size per §R3 gate) |
| extreme | `2.5` [example] | `3.0` [example] | `1.0` [default] | `False` — cost-sensitive strategies stand down |
| UNKNOWN | undefined | undefined | undefined | `False` (restrictive default) |

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, impact_bps, borrow_bps, fees_bps) from the strategy COST block
    # Only spread and impact scale with RV; borrow/fees are unaffected.
    adj = dict(base)
    if rsv['state'] == 'extreme':
        adj['spread_mult'] = 2.5   # [example] starting point — calibrate per below
        adj['impact_mult'] = 3.0   # [example]
        adj['trade_ok'] = False    # stand down cost-sensitive strategies
    elif rsv['state'] == 'elevated':
        adj['spread_mult'] = 1.5   # [example]
        adj['impact_mult'] = 2.0   # [example]
        adj['trade_ok'] = True
    elif rsv['state'] == 'UNKNOWN':
        adj['trade_ok'] = False    # restrictive default: never benign
    else:
        adj['spread_mult'] = 1.0   # [default]
        adj['impact_mult'] = 1.0   # [default]
        adj['trade_ok'] = True
    adj['borrow_mult'] = 1.0       # [default] borrow does not scale with RV
    adj['fees_mult'] = 1.0         # [default] fees do not scale with RV
    return adj
```

**Multiplier calibration recipe** (the `[example]` values above are starting
points, never live values):

1. Per name, from trade-and-quote (or SIP NBBO) data over ≥ `6` months [default], compute the realized effective spread per trade and the RV
   percentile `p` at the trade time.
2. Regress effective spread on percentile deciles; define
   `spread_mult(band) = median spread in band / median spread in the normal
   band`, and analogously `impact_mult` from implementation-shortfall
   slippage deciles.
3. `spread_mult(elevated)` = fitted value at `p = 0.875` [default];
   `spread_mult(extreme)` = fitted value at `p = 0.975` [default].
4. Re-fit quarterly [default]; if the fitted `extreme` multiplier is `< 1.5`
   [default], the name's spread is not RV-convex — set both multipliers to
   `1.0` [default] and document it.

**Executable gate** (for T-module `expected_cost_bps` predicates):

```
eff_cost = expected_cost_bps(notional, adv_pct, venue, side, urgency,
                             spread_bps = base.spread_bps * adj.spread_mult,
                             impact_bps = base.impact_bps * adj.impact_mult)
enter_ok = adj.trade_ok and eff_cost <= k * edge_bps   # k [default] per T chapter
```

`trade_ok = False` vetoes new entries for cost-sensitive strategies
(defined: strategies whose expected edge is `< 2×` [default] the expected
cost); existing positions are managed per the T-module's own exits, never
forced flat by this module.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Jump day inflates RV → detect: rescaled-Parkinson F3 trip (variance-scale rel. diff `> 0.25` [default]) → action: leave-one-out identifies the bar, `DEGRADED` (`jump-excluded`), cross-check R005 jump flag, hold sizing → recovery: bar ages out of the `5`-day [default] window | `check: F3 agrees after excluding ≤ `1` bar [default]` |
| 2 | In-sample percentile lookahead → detect: Adversary appends breakout bar, label at `t` moves → action: halt, fix trailing window to bars `< t` → recovery: re-run no-lookahead test | `check: label_t unchanged by bar t+1` |
| 3 | Unadjusted split/dividend → detect: `|ln(c_t/c_{t-1})| > ln(1.40)` [default] with no `adj_factor` → action: `UNKNOWN` (`unadjusted-corporate-action`), drop symbol that day → recovery: reconcile vendor factor file, replay | `check: no unadjusted corporate-action gaps` |
| 4 | Annualizing a `5`-day [default] window is noisy → detect: single spiky bar flips the label → action: hysteresis exit band absorbs one-bar mean-reversion; F3 cross-checks contamination → recovery: resume when `p` re-enters the band | `check: label persists while p in (exit, entry]` |
| 5 | Estimator disagreement, non-jump (e.g. drift-heavy trending day) → detect: F3 trip, leave-one-out finds no single culprit → action: `UNKNOWN`, log both estimators → recovery: manual review; quarantine after `5` [default] consecutive trips | `check: consecutive F3 trips < 5` [default] |
| 6 | Short trailing history (new listing, post-spin, universe expansion) → detect: `|trail| < 63` [default] → action: label emitted but `DEGRADED` (`short-trailing-history`), downstream treats as restrictive → recovery: history accumulates; `OK` resumes automatically | `check: module_state != OK when |trail| < 63` [default] |
| 7 | Missing bars / multi-day halt → detect: `event_ts` gap `> 3`× cadence → action: `UNKNOWN` (`stale-gap`); gap in (`1`×, `3`×] → `DEGRADED` (`gap-masked`) → recovery: feed resumes; **never interpolate** | `check: no NaN-fill across gaps` |
| 8 | SIP-only / EOD-only stack → detect: feed has no intraday bars → action: honest split — the `30`-min [default] intraday refresh leg is `UNKNOWN` (unmeasurable here), the daily label is unaffected and still emitted → recovery: upgrade feed per §R0.3b escalation | `check: intraday leg UNKNOWN, daily leg OK` |
| 9 | Stale feed / vendor outage → detect: `computed_at` older than `3`× cadence (F4) → action: `UNKNOWN`, page on-call → recovery: feed health check, fixture replay before re-arm | `check: UNKNOWN after 3x cadence` [default] |

Pitfalls: (a) presenting `[default]` bands as institutional standards — they
are starting points for the §R2.5 recipe; (b) pooling percentiles across
names — bands are per-name, always; (c) annualizing without the `252`
[documented] convention pinned — state the day-count; (d) forgetting the GK
floor at `0` [default] — the drift term goes negative on jump days, and an
unfloored negative variance silently poisons the trail.
