### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only

  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; SOFR published T+1 — the label at t uses the latest vintage ≤ t, vintage-tagged).

  `label_ts > indicator_ts` for the earliest gated trade and that appending a

## §R1 Precise definition

Funding stress `S_t = SOFR_t − OIS_3M` in bps [documented construction]. Cross-check: SOFR − IORB [documented]; absolute tolerance `10` bps [example].

## §R2 Exact calculation

$$S_t = (\text{SOFR}_t - \text{OIS}^{3M}_t)\times 100\ \text{bps} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: SOFR `5.32%`, IORB `5.15%` → `S = 17` bp. Bands [documented]: `< 10` normal · `10–25` tight · `> 25` stressed (Sep-2019 printed `> 200` bp intraday; quarter-ends routinely `5–15` bp).

**Data inputs.** daily SOFR, 3M OIS, IORB (FRED/NY Fed). Repo fails volume (NY Fed, weekly) as context.

**Cadence.** daily (T+1).

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `< 10` bps | normal | [documented] |
| `10–25` bps | tight | [documented] |
| `> 25` bps | stressed (delever) | [documented] |

Bands are `[documented]` (RB-list); the fixture ramp runs 17→45 bp and its median `31.5` bp sits in 'stressed'.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Leveraged / basis strategies | **inverts** | die in stress — funding cost spikes and haircuts widen simultaneously (expected return ≈ spread − funding; both legs move against you) |
| High-turnover stat-arb | **inverts** | dies — implicitly funds overnight at the stressed rate |
| Unlevered cash-equity signals | **amplifies** | favored as a risk-off filter — cut gross, keep the unlevered book |

## §R5 Cost interface: regime state → cost-function adjustment

Funding stress reprices the financing leg: the adjustment scales the assumed funding rate and halves size for levered books — stress precedes deleveraging cascades (Brunnermeier–Pedersen).

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'stressed':
        adj['fin_mult'] = 2.0       # [example] funding reprices
        adj['size_mult'] = 0.5       # [example] delever
    elif rsv['state'] == 'tight':
        adj['fin_mult'] = 1.25      # [example]
        adj['size_mult'] = 0.75     # [example]
    else:
        adj['fin_mult'] = 1.0       # [default]
        adj['size_mult'] = 1.0      # [default]
    return adj
```
