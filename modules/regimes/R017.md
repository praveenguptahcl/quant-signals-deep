Stress in dollar funding markets: the SOFR–benchmark spread in basis points (SOFR = NY Fed volume-weighted median of eligible Treasury repo [documented]). ### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the label for value date `t` is computed using only
  data with `event_ts ≤ t`. The final vintage for `t` exists only at
  `asof_ts > t` (T+1 publication [documented]).
- **Gating rule:** a regime label for value date `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`. In backtests the join key is `asof_ts`, not `event_ts`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]); the label is
  vintage-tagged with both `event_ts` (value date) and `asof_ts` (publication).
- **Adversary check (no-lookahead):** the test suite asserts
  `computed_at > event_ts` and `asof_ts > event_ts` for every valid bar, asserts
  the earliest gated trade (`event_ts(t+1)` + US-open offset) is strictly after
  `computed_at(t)`, and asserts **prefix-invariance**: recomputing labels on
  bars `1..t` yields the identical label as the full-tape recompute at `t`
  (the detector is point-in-time — there is no trailing statistic for a future
  bar to move).
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Funding stress `S_t = SOFR_t − bench_t` in bps, point-in-time per value date
[documented construction]. The label follows **hysteresis bands** — entry is
eager, exit requires the band low — so quarter-end wrinkles do not whipsaw
funded books. Cross-check: the verifier leg (SOFR − IORB) must agree within
`dual_tol_bps` [default]; spread values are rounded to `1e-6` bp (float64)
before band comparison so documented boundaries compare deterministically
(§R2 precision rule).

## §R2 Exact calculation

$$S_t = (\text{SOFR}_t - \text{bench}_t)\times 100\ \text{bps} \quad\text{[documented]}$$

Worked example [example]: SOFR `5.32%`, IORB `5.15%` → `S = 17` bp → `tight`.

**Threshold bands** (RB-list priors — see calibration recipes below; honest
status `[default]`, not measured).

| Condition | Label | Tag |
|---|---|---|
| `S < 10` bps (from normal) | normal | [default] |
| `S ≥ 10` bps entry / `S < 8` bps exit | tight | [default] |
| `S > 25` bps entry / `S < 22` bps exit | stressed (delever) | [default] |

Empirical anchor: SOFR "rarely moves more than `20` basis points on a day"
and shows quarter-end seasonality [documented Fed] — the `10`/`25` [default] cuts sit
inside normal calendar noise and outside it, respectively. Sep-2019 printed
`5.25%` vs `2.43%` the prior day (≈ `280`+ bp over the policy rate
[documented Fed]) — two orders of magnitude above the stressed cut.

**Hysteresis transition table** (normative — the pseudocode below is the
reference; prose is commentary).

| From \ S_t | `< exit_tight` (`8` [default]) | `[8, 10)` [default] | `[10, 25]` [default] | `> 25` [default] |
|---|---|---|---|---|
| normal | normal | normal | tight | stressed |
| tight | normal | tight | tight | stressed |
| stressed | normal | tight | tight | stressed |

Boundary pins (rounded to `1e-6` bp [default] first): `10.0` [default] → tight; `25.0` [default] → stays
tight (entry needs strictly `> 25` [default]); `22.0` [default] → stays stressed (exit needs
strictly `< 22` [default]); `8.0` [default] → stays tight (exit needs strictly `< 8` [default]).

**Normative pseudocode** (matches `label_series` in `test_R017.py`):

```
function label_bar(r, prev_label, last_valid, cfg):   # r: one canonical bar
    S = round((r.sofr - r.bench) * 100, 6)            # bps, precision rule [default]
    V = round((r.sofr - r.verifier) * 100, 6) if verifier present else None
    # F1 — missing / invalid (never interpolate)
    if r.sofr is missing:
        if last_valid exists and (r.event_ts - last_valid.event_ts) <= 3 days [default]:
            return CARRY(last_valid)                  # DEGRADED, computed_at pinned
        return UNKNOWN("missing")
    if any raw rate outside [0, 50] % [default]:
        return UNKNOWN("invalid")
    # F2 — mathematical bounds
    if S outside (-100, 500) [default] or (V present and V outside bounds):
        return UNKNOWN("out_of_bounds")
    # Hysteresis step
    label = HYSTERESIS(S, prev_label, cfg)            # table above
    # F3 — dual-estimator agreement
    if V is None:
        return DEGRADED(label, S, note="verifier unavailable")
    if |S - V| > cfg.dual_tol_bps:                   # 10.0 [default]
        return UNKNOWN("dual disagreement", keep label for diagnosis)
    return OK(label, S)

function HYSTERESIS(S, prev, cfg):
    if prev in {None, "normal"}:
        if S > cfg.entry_stressed: return "stressed"
        if S >= cfg.entry_tight:   return "tight"
        return "normal"
    if prev == "tight":
        if S > cfg.entry_stressed: return "stressed"
        if S < cfg.exit_tight:     return "normal"
        return "tight"                                    # hold inside the band
    if prev == "stressed":
        if S < cfg.exit_stressed:
            return "normal" if S < cfg.exit_tight else "tight"   # collapse re-evaluates
        return "stressed"                                 # hold inside the band
```

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Leveraged / basis strategies | **inverts** | die in stress — funding cost spikes and haircuts widen simultaneously (expected return ≈ spread − funding; both legs move against you) |
| High-turnover stat-arb | **inverts** | dies — implicitly funds overnight at the stressed rate |
| Unlevered cash-equity signals | **amplifies** | favored as a risk-off filter — cut gross, keep the unlevered book |

Hysteresis matters here: without the exit bands, quarter-end calendar
tightness (documented seasonality [documented Fed]) would flip funded books
to stand-down on noise several times a year [internal-est].

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** pulls FRED `SOFR`/`IORB` (NY Fed as fallback); publishes RSV with `event_ts` (value date) + `asof_ts` (final vintage) tags.
- **Verifier:** SOFR − IORB cross-check; `|diff| > 10` bps [default] → `UNKNOWN` (F3); verifier leg missing → `DEGRADED`, never silent.
- **Grok-Researcher:** proposes tenor splits and repo-fails gating; leads only (§R10).
- **Adversary:** checks value-date vs publication-date handling (`asof_ts > event_ts` asserted); checks a `2` bp [example] wrinkle is not labeled stress (bands + hysteresis); checks weekend-carry correctness; checks float-boundary determinism (precision rule — the `9.999999999999964` vs `10.0` [example] case).
- **Gate:** rejects intraday presentation of T+1 data; rejects backtest joins on `event_ts`; rejects `bench="ois"` configs without a verified OIS feed (cheapest-build rule).
- **F1–F5 instantiated:** F1 missing/stale/invalid → `UNKNOWN` (restrictive downstream); expected-gap carry (≤ `3` d [default]) → `DEGRADED`, never interpolated;
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Funding stress reprices the **financing leg** of the T-module cost stack
(Brunnermeier–Pedersen: stress precedes deleveraging cascades [documented]).
Venue spread/fees are untouched — the regime reprices funding, not venues
(reason recorded, borrow convention explicit).

| Cost component | normal | tight | stressed | DEGRADED / UNKNOWN | Tag |
|---|---|---|---|---|---|
| `fin_bps` add-on (funding spread over policy) | `+0` | `+50` | `+150` | `+150` (restrictive) | [example] |
| `borrow_bps_per_day` multiplier | `1.0` | `1.25` | `2.0` | `2.0` (restrictive) | [example] |
| `size_mult` (levered books) | `1.0` | `0.75` | `0.5` | `0.5` (restrictive) | [example] |
| `impact_bps` multiplier (wider books) | `1.0` | `1.25` | `1.5` | `1.5` (restrictive) | [example] |
| venue spread / fees | unchanged | unchanged | unchanged | unchanged | [default] |

```python
def cost_adjustment(rsv, base):
    # base: dict with fin_bps, borrow_bps_per_day, impact_bps, size_notional, ...
    # rsv:  regime_state_vector from detect()
    adj = dict(base)
    adj['trade_ok'] = True
    state = rsv['state']
    module_ok = rsv['module_state'] == 'OK'
    if state == 'stressed' or not module_ok:
        adj['fin_bps'] = base['fin_bps'] + 150.0          # [example] funding reprices
        adj['borrow_bps_per_day'] = base['borrow_bps_per_day'] * 2.0  # [example]
        adj['size_mult'] = 0.5                            # [example] delever
        adj['impact_bps'] = base['impact_bps'] * 1.5       # [example] wider books
    elif state == 'tight':
        adj['fin_bps'] = base['fin_bps'] + 50.0            # [example]
        adj['borrow_bps_per_day'] = base['borrow_bps_per_day'] * 1.25  # [example]
        adj['size_mult'] = 0.75                           # [example]
        adj['impact_bps'] = base['impact_bps'] * 1.25      # [example]
    else:  # normal
        adj['fin_bps'] = base['fin_bps']                   # [default] no change
        adj['borrow_bps_per_day'] = base['borrow_bps_per_day']  # [default]
        adj['size_mult'] = 1.0                            # [default]
        adj['impact_bps'] = base['impact_bps']             # [default]
    return adj
```

Notes: `UNKNOWN`/`DEGRADED` take the stressed row (restrictive — never treated
as benign, §R0.5). `size_mult` applies to levered-book sizing; unlevered
