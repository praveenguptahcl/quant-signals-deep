### R0.2.1 Calibration recipe (per parameter — grid + OOS selection, no hand-tuning in production)

- **Data for calibration:** trailing `2` years [example] of daily odd-lot counts for the `500` most-liquid US equities by ADV [example universe]; odd-lot flags from the consolidated tape sale condition (`I`); any ticker whose median daily trade count is below `min_trades` is excluded from the calibration set.
- `retail_cut` (`0.65` [default]): grid `{0.55, 0.60, 0.65, 0.70, 0.75}` [example]; selection = maximize downstream modulation on purged/embargoed walk-forward OOS — short-horizon mean-reversion after-cost Sharpe conditioned on `retail_dominated` minus baseline — subject to median regime persistence ≥ `5` sessions [example]. Re-calibrate annually [default]; never calibrate on a 2020–21-only window [documented rule: 2021 is an outlier sample].
- `base_cut` (`0.50` [default]): same grid procedure on `{0.40, 0.45, 0.50, 0.55, 0.60}` [example]; anchored at the low edge of the documented "normal modern tape" band (`0.45–0.60` [documented Grok RB3: Cboe ~`54.8`% odd-lot trades, MEMX `57`%→`66`%). Sensitivity: low — it only separates baseline from mixed.
- `hyst` (`0.05` [default]): grid `{0.02, 0.03, 0.05, 0.07, 0.10}` [example]; minimize the label-flip rate (transitions per `100` sessions [example]) subject to median detection lag ≤ `1` bar [example] on OOS; exit at `retail_cut − hyst` / entry from baseline at `base_cut + hyst`. Sensitivity: medium — too small chatters, too large lags exits.
- `dual_tol` (`0.05` [default]): grid `{0.02, 0.05, 0.10}` [example]; target Verifier disagreement rate ≤ `1`% of sessions [example] on clean tape — it must fire on data corruption, not estimator noise. Sensitivity: low.
- `min_trades` (`100` [default]): identification floor — days with fewer prints are `DEGRADED`; raise it (up to `500` [example]) for small-cap universes where odd-lot shares are mechanically inflated.
- All chosen values re-validated annually [default]; any change logs a new `params_hash` (C5). Candidate refinement for a future round (not adopted): require the share to be *rising vs its `20`-day mean* in addition to `f ≥ retail_cut` [unverified lead — Grok RB3 suggestion].

### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; the label at t uses prints ≤ t).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Retail share `f_odd = N_odd / N_all` (trade count) + odd-lot volume share complement `v_odd / v_all` [documented construction]. An *odd-lot print* is a print with size `< 100` shares [documented — FINRA/NYSE definition], flagged on the consolidated tape by CTA sale condition `I` ("Odd Lot Trade") [documented — CTS output spec §7; TAQ Daily client spec v3.3c §3]; odd-lot transactions have been reported on the consolidated tape since the 2013 CTA-plan amendment [documented — SEC Release 34-70899].

The regime is a **stateful label**, not a per-bar threshold: entry and exit use different cutoffs (hysteresis `hyst = 0.05` [default]) so the label cannot chatter at a band edge (§R2). Cross-check: Verifier recomputes the share from the independent volume-share estimator; absolute tolerance `dual_tol = 0.05` [default] (F3).

Honesty anchors [documented]: odd lots are now `66`% of industry trades but "not a good way to gauge retail trading activity" (MEMX, Retail Trading Insights); median odd-lot trade share was `24`% with some names ≥ `60`% in O'Hara–Yao–Ye's sample; odd-lot *volume* is a small share of share volume (`~10.7`% in the most liquid quintile, Cboe 2021, via Grok RB3); retail investors account for `30–37`% of daily equity volume with retail wholesalers at `34`% (MEMX, June 2025). Count-share alone is a contaminated proxy — never treat it as "pure retail".

## §R2 Exact calculation

$$f_{odd} = \frac{N_{odd}}{N_{all}}, \qquad v_{odd} = \frac{V_{odd}}{V_{all}} \quad\text{[documented]}$$

`f` = odd-lot *trade-count* share (Sentinel); `v` = odd-lot *share-volume* share (Verifier). Both are fractions in `[0, 1]` [documented construction].

Worked example [documented Grok RB3]: day-10 odd-lot `210`, all trades `380` → `0.5526` ⇒ mixed/baseline (not retail-dominated).

**Data inputs.** trade-level prints with sale-condition flags (`I` = odd lot), per-print share quantity; `ca_day` corporate-action flag; market-state events. Volume-share complement from the same tape (Verifier).

**Cadence.** daily.

**Entry/exit state machine** (hysteresis — boundaries inclusive).

| From → To | Condition | Tag |
|---|---|---|
| any → `retail_dominated` | `f ≥ 0.65` (entry) [default] | [default] |
| `retail_dominated` → `mixed` | `f < 0.60` (exit = `0.65 − 0.05`) [default] | [default] |
| `baseline` → `mixed` | `f ≥ 0.55` (entry = `0.50 + 0.05`) [default] | [default] |
| `mixed` → `baseline` | `f < 0.50` (exit) [default] | [default] |
| `retail_dominated` → `baseline` | `f < 0.50` (direct collapse; no forced mixed stop) [default] | [default] |
| `baseline` → `retail_dominated` | `f ≥ 0.65` (direct jump; no forced mixed stop) [default] | [default] |
| cold start (no prior label) | plain bands: `f ≥ 0.65` → retail; `f < 0.50` → baseline; else mixed [default] | [default] |

Band edges are `[default]` (calibrated per §R0.2.1); the documented content is the contamination caveats.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
# ---- per-bar estimators (pure functions; unit-testable) ----
function primary(row) -> (f, ok):            # Sentinel: count share
    if row missing n_odd/n_all/event_ts:     return (NaN, False)      # F1
    if n_all <= 0 or n_odd < 0 or n_odd > n_all: return (NaN, False)  # F1/F2
    return (n_odd / n_all, True)

function verifier(row) -> (v, ok):           # Verifier: volume share
    if row missing v_odd/v_all:              return (NaN, False)      # F1
    if v_all <= 0 or v_odd < 0 or v_odd > v_all: return (NaN, False)
    return (v_odd / v_all, True)

# ---- hysteresis label (pure function; unit-testable) ----
function label_with_hysteresis(f, prev, cfg):
    rc, bc, h = cfg.retail_cut, cfg.base_cut, cfg.hyst   # [default]s
    if prev == "retail_dominated":
        if f < bc:  return "baseline"                    # direct collapse
        return "retail_dominated" if f >= rc - h else "mixed"
    if prev == "baseline":
        if f >= rc: return "retail_dominated"            # direct jump
        return "mixed" if f >= bc + h else "baseline"
    return "retail_dominated" if f >= rc \
        else ("baseline" if f < bc else "mixed")          # cold start

# ---- module entry point (streaming) ----
function detect(state, events, cfg) -> RegimeState:
    assert len(events) > 0 else return UNKNOWN("missing")             # F1
    row = events[-1]
    if row.market_state == "HALTED":
        return UNKNOWN("frozen")                                     # R0.6 freeze
    (f, ok) = primary(row);  assert ok else return UNKNOWN("invalid") # F1
    assert 0 <= f <= 1 else return UNKNOWN("out_of_bounds")          # F2
    if row.ca_day == 1:
        return DEGRADED(hold=state.prev_label)                       # CA mask
    if row.n_all < cfg.min_trades:                                   # [default]
        return DEGRADED(hold=state.prev_label)                       # thin day
    (v, vok) = verifier(row)
    assert vok and abs(f - v) <= cfg.dual_tol \                       # [default]
        else return UNKNOWN("disagree")                              # F3
    gap = (state.prev_bar is not None) and (row.bar != state.prev_bar + 1)
    label = label_with_hysteresis(f, state.prev_label, cfg)
    if gap:                                                          # missing bar
        return DEGRADED(hold=state.prev_label, value=f)               # mask, no interp
    assert now() - row.event_ts <= cfg.staleness_mult * cadence \     # [default] 3x
        else return UNKNOWN("stale")                                 # F4
    # F5: select_periods=True requires a pre-registered definition
    state.prev_label = label; state.prev_bar = row.bar
    log_decision(rsv, inputs_hash, params_hash)                      # C5 / App g
    return RSV(label, f, computed_at=row.event_ts, module_state=OK)
```

**Edge-case rules (normative).** Missing bar (non-consecutive bar number): mask, hold previous label, `DEGRADED` — never interpolate across the gap (F1). Halted session: freeze counters, emit `UNKNOWN`, discard any prints that span the reopen (per §R0.6). Corporate-action day (`ca_day = 1`, e.g. split/reverse-split): mask the day — re-priced round lots mechanically become odd lots, so counts are contaminated; hold previous label, `DEGRADED`; resume on the next clean bar. Thin day (`n_all < 100` [default]): counts are statistically unreliable; hold previous label, `DEGRADED`. Zero-denominator (`n_all = 0`) and `n_odd > n_all`: `UNKNOWN` (F1/F2).

Causality: every quantity used at bar `t` comes from prints with `event_ts ≤ t`; the hysteresis transition at `t` only affects labels stamped `t` and later, which may gate trades at `t+1`+ (lag contract §R0.5).

- **Grok-Researcher:** proposes windows; leads only.

## §R5 Cost interface: regime state → cost-function adjustment

Retail-heavy flow shortens the profitable horizon and raises execution friction: takers pay wider effective spreads (Boehmer et al. 2021 [documented]: retail trades move prices) and thinner displayed depth raises own-flow impact. Per-share fees and borrow are **not** moved by retail share [default].

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'retail_dominated':
        adj['spread_mult'] = 1.25   # [example] effective spread widens: takers pay the retail imbalance
        adj['impact_mult'] = 1.50   # [example] own-flow impact per share rises (thinner displayed depth)
        adj['fees_mult'] = 1.0      # [default] per-share fees unchanged
        adj['borrow_mult'] = 1.0    # [default] retail share does not move borrow cost
        adj['alpha_mult'] = 0.75    # [example] sentiment noise
        adj['horizon_mult'] = 0.5   # [example] faster turns
    else:
        adj['spread_mult'] = 1.0    # [default]
        adj['impact_mult'] = 1.0    # [default]
        adj['fees_mult'] = 1.0      # [default]
        adj['borrow_mult'] = 1.0    # [default]
        adj['alpha_mult'] = 1.0     # [default]
        adj['horizon_mult'] = 1.0   # [default]
    return adj
```

Which cost components scale, and how much: `spread_mult` `1.25`× and `impact_mult` `1.50`× in `retail_dominated` [example] — the keys plug into the consumer's `expected_cost_bps(notional, adv_pct, venue, side, urgency)` 4-component stack (spread/fees/borrow/impact); `fees_mult` and `borrow_mult` stay `1.0` [default] with the reason stated. Consumers must version the mults with `estimator_version` (`1.1.0`) so a re-calibration changes downstream cost models atomically.
