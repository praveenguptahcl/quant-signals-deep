### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; daily yields as of t).
- **Weekend-carry rule:** a Friday label may gate Monday's signal (the label
  is the latest *known* information); it may not gate any fill inside
  Friday's bar. Staleness is counted in **calendar** days [default].
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

2s10s = y10 − y2 in bps [documented construction]. Cross-check: FRED T10Y2Y or 3-obs average; absolute tolerance `1` bp [default]. RB3 notes verifier tolerance `≤ 1` bp [documented].

Labels with hysteresis (entry/exit bands — normative, see §R2):

| Condition | Label | Tag |
|---|---|---|
| value `≤ −25` bp [default] → enter; exit only when value `> −10` bp [default] | inverted (late-cycle posture) | default |
| between bands | flat | default |
| value `≥ +25` bp [default] → enter; exit only when value `< +10` bp [default] | normal | default |

The documented content is the spread construction and the Estrella–Mishkin
predictive literature; the `±25`/`±10` bands are shipped defaults calibrated
by the §R2.1 recipe, not empirical constants.

## §R2 Exact calculation

$$2s10s = y_{10} - y_{2}\ \text{(bps)} \quad\text{[documented]}$$

Worked example [documented Grok RB3]: `4.2% − 4.8% = −0.6% = −60` bp ⇒ inverted. Dynamic taxonomy [documented Grok RB3]: bull/bear steepener/flattener on top of the level state.

### R2.2 Detection-calibration recipe (thresholds incl. hysteresis)

No magic numbers: the shipped `±25`/`±10` [default] bands are starting
points; this recipe is how they are set and re-set.

1. **Calibration data:** FRED T10Y2Y daily, `1976-06-01` → latest vintage
   [documented]. Percent units; weekend/holiday `.` skipped, never
   interpolated [default]. Revisions tracked via ALFRED vintages [default].
2. **Grid** [default]:
   - `inv_cut ∈ {−50, −45, …, −10}` step `5` bp
   - `inv_relief = inv_cut + {5, 10, 15}` bp
   - `flat_cut ∈ {10, 15, …, 50}` step `5` bp
   - `flat_relief = flat_cut − {5, 10, 15}` bp
   - `dual_tol_bps ∈ {0.5, 1.0, 2.0}` bp
3. **Objective:** regime *stability*, not recession prediction (labels are
   descriptive; F5). Minimize flip-flop rate subject to: inverted episodes
   have median persistence ≥ `60` business days [default]; ≥ `20` labeled
   transitions in the pooled OOS sample [default]; tie-break toward wider
   hysteresis (fewer flips) [default].
4. **OOS selection:** walk-forward `10`-yr train / `2`-yr test [default] with
   a `6`-month embargo [default]; pick the grid point maximizing stability on
   the test folds. No ex-post period cherry-picking (F5): folds are fixed in
   advance in the calibration script's header.
5. **Re-cal cadence:** annual [default], plus on any FRED methodology-note
   change (check ALFRED vintage notes) [default].
6. **Ship rule:** until calibrated, the shipped defaults (`inv_cut −25`,
   `inv_relief −10`, `flat_cut +25`, `flat_relief +10` [default]) stand.
   Defaults change only by re-running this recipe.

### R2.3 Normative detection pseudocode (hysteresis + edge cases)

```text
# NORMATIVE. state persists across bars within one detect() call.
# events: canonical daily bars, oldest first, event_ts int64 ns UTC.

def detect_regime(events, cfg, prev_state):
    label = prev_state            # None on first call (warm-up); hysteresis carry
    out = []
    for e in events:
        y10, y2 = num(e.y10), num(e.y2)          # non-numeric/empty -> None
        if y10 is None or y2 is None:
            return UNKNOWN("F1: missing field; never interpolate", label)
        v = (y10 - y2) * 100.0                  # percent -> bps [documented]
        if not isfinite(v) or not (-1000.0 <= v <= 1000.0):   # [default] F2 bounds
            return UNKNOWN("F2: out of mathematical bounds", label)
        label = transition(label, v, cfg)       # hysteresis state machine
        out.append((e.event_ts, v, label))
    return OK(label, out)

def transition(prev, v, cfg):
    # prev in {None, "flat", "inverted", "normal"}
    if prev == "inverted":
        return "flat" if v > cfg.inv_relief else "inverted"   # exit iff v > -10 [default]
    if prev == "normal":
        return "flat" if v < cfg.flat_relief else "normal"    # exit iff v < +10 [default]
    # prev None/"flat": plain bands on first observation
    if v <= cfg.inv_cut:    return "inverted"    # <= -25 [default]
    if v >= cfg.flat_cut:   return "normal"     # >= +25 [default]
    return "flat"
```

**Hysteresis transition table** (normative; pinned by `R025_hyst.csv`):

| From \ value (bp) | `≤ −25` [default] | `(−25, −10]` [default] | `(−10, +10)` [default] | `[+10, +25)` [default] | `≥ +25` [default] |
|---|---|---|---|---|---|
| flat / None | inverted | flat | flat | flat | normal |
| inverted | inverted | **inverted (hold)** | flat | flat | normal |
| normal | inverted | flat | flat | **normal (hold)** | normal |

**Edge cases (normative):**
- **Missing bars — expected (weekend/holiday):** skip; carry last label;
  keep `OK`; `data_vintage` stays at last observation [default].
- **Missing bars — unscheduled (outage/parse failure):** `UNKNOWN` (F1);
  page if > `1` business day [default]; on backfill, replay history and
  reconcile the decision log (see §R7).
- **FRED restatement:** if a backfilled observation differs from the stored
  vintage by > `1` bp [default] (`revision_tol_bps`), enter `DEGRADED`,
  recompute all labels from the revision point, log the delta, then re-arm.
- **Halt/auction:** n/a for a daily curve; vendor outage is the analog
  (see market-state table).
- **Corporate actions:** n/a — Treasury securities have none; the module
  must not invent handling code for them.
- **First observation:** `warmup_bars = 1` [default]; the first bar gets a
  plain-band label (no hysteresis carry) and `OK`.
- **Float jitter at band edges:** band-edge comparisons use `v` rounded to
  `1e-9` bp [default], so a feed value printed as `−10` bp does not flip on
  `1e-12` representation noise.

## §R5 Cost interface: regime state → cost-function adjustment

Curve shape sets the cycle posture. This block is the **single source of
truth** for how R025 state adjusts a T-module's cost function
`expected_cost_bps(notional, adv_pct, venue, side, urgency)`. The regime
module never computes dollars itself; it publishes these named adjustments
and the T-module applies them inside its own COST block. All values tagged.

| Cost component | Inverted | Flat | Normal | Mechanism |
|---|---|---|---|---|
| `spread_mult` (× on `spread_bps`) | `1.5` [example] | `1.1` [example] | `1.0` [default] | late-cycle credit bid-ask widens; the defensive rotation is crowded |
| `borrow_bps_add` (+ bps/day on `borrow_bps`) | `+2.0` [example] | `0.0` [default] | `0.0` [default] | short cyclical legs get harder to borrow into an inverted consensus |
| `impact_mult` (× on `impact_bps`) | `1.3` [example] | `1.1` [example] | `1.0` [default] | rotation urgency when the posture flips |
| `fee_mult` (× on `fee_bps`) | `1.0` [default] | `1.0` [default] | `1.0` [default] | exchange/regulatory fees do not depend on curve shape |
| `trade_ok` | `True` [default] | `True` [default] | `True` [default] | R025 is advisory; veto decisions live in the T-module's own regime gate, never here |

Portfolio (non-cost) tilts, published alongside for T-module position
logic — clearly separated from the cost stack:

| Tilt | Inverted | Else | Tag |
|---|---|---|---|
| `quality_tilt` | `1.25` | `1.0` | [example] / [default] |
| `duration_tilt` | `0.75` | `1.0` | [example] / [default] |

```python
def cost_adjustment(rsv, base):
    # rsv["state"] in {"inverted", "flat", "normal"}; base has
    # spread_bps, borrow_bps, impact_bps, fee_bps [example schema].
    adj = dict(base)
    s = rsv["state"]
    adj["trade_ok"] = True                                   # [default]
    adj["spread_mult"]   = 1.5 if s == "inverted" else (1.1 if s == "flat" else 1.0)  # [example]/[example]/[default]
    adj["borrow_bps_add"] = 2.0 if s == "inverted" else 0.0   # [example]/[default]
    adj["impact_mult"]   = 1.3 if s == "inverted" else (1.1 if s == "flat" else 1.0)  # [example]/[example]/[default]
    adj["fee_mult"] = 1.0                                    # [default]
    adj["quality_tilt"]  = 1.25 if s == "inverted" else 1.0  # [example]/[default]
    adj["duration_tilt"] = 0.75 if s == "inverted" else 1.0  # [example]/[default]
    return adj
```

T-module call pattern [example]:
`cost = expected_cost_bps(...) * adj["spread_mult"]` applied per component
inside the T-module's own COST block — never re-stated here (single source
of truth: this block). Cost token: the module operates `BEFORE-COST`; its
interface feeds the T-module's `FULL-COST` stack.
