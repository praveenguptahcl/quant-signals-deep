- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).

## §R1 Precise definition

Cross-sectional volatility regime: the sample (ddof = 1) standard deviation of per-name 20-day [example] realized volatilities across a fixed universe — the realized vol-of-vol state. Wide = vol-of-vol is high = dispersion-trading weather; narrow = vol is uniform = short-vol carry weather. This is the *realized, cross-sectional* analogue of the implied vol-of-vol measured by the CBOE VVIX index [documented] — same concept, different estimator and scope (VVIX is implied, single-index; R045 is realized, cross-sectional). (Grok's worked example stated `1.320`% [unverified] but the supplied return set implies a recomputed sample σ of `1.2903`% [measured] — neither figure is used; this module's panel is synthetic [example].)

## §R2 Exact calculation

Per-name 20-day [example] close-to-close realized vol `σ_{i,t}` (percent, daily
[default]); cross-sectional vol-of-vol:

$$XS_t = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N}(\sigma_{i,t} - \bar{\sigma}_t)^2}$$

`ddof = 1` [default]; requires `≥ 2` names [rule], else `UNKNOWN` (F1).

Hand-verified panels (8 names, vols in % [example]). Panel 0:
`[1.2, 0.9, 1.5, 1.1, 1.8, 0.7, 1.4, 1.0]` → `XS ≈ 0.3546`% → NORMAL.
Panel 1: `[2.5, 1.0, 3.0, 1.2, 2.8, 0.8, 2.2, 1.5]` → `XS ≈ 0.8565`% → WIDE.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Per-name 20-day realized vols (percent, daily); fixed universe
(`N` names, frozen ex ante); per-name corporate-action factors.

**Cadence.** Daily.

**Threshold bands (entry/exit with hysteresis — §R2.7).** Values are
`[example]` starting points; production values come from the §R2.5 recipe
(status `calibrate` in §R0.2). Bands are in XS percent units, daily.

| Band | Entry (strict) | Exit (sticky) | Tag |
|---|---|---|---|
| WIDE | `XS ≥ 0.50`% | stays WIDE while `XS ≥ 0.40`% | [example] |
| NORMAL | — | — | [example] |
| NARROW | `XS ≤ 0.25`% | stays NARROW while `XS ≤ 0.30`% | [example] |

A value crossing the far band takes that band from **any** state (e.g.
NARROW → WIDE on a vol explosion is allowed — hysteresis only prevents
chatter, it never blocks genuine regime changes).

### R2.5 Detection calibration recipe (no hand-tuned magic numbers)

1. **Calibration data:** fixed-universe EOD panel, split-adjusted,
   point-in-time; `≥ 252` bars [default] of history; corporate-action factors
   from the vendor; the evaluation/OOS window is excluded up front (F5).
   Universe membership is hashed and frozen — any change is an erratum +
   re-calibration event, never a silent edit.
2. **Grid:** `window_days ∈ {10, 20, 60}` [default set] ×
   `wide_entry ∈ {0.40, 0.50, 0.60, 0.70}` [default set] ×
   hysteresis width `∈ {0.05, 0.10, 0.15}` [default set]
   (`wide_exit = wide_entry − width`) ×
   `narrow_entry ∈ {0.20, 0.25, 0.30}` [default set] ×
   narrow width `∈ {0.05, 0.10}` [default set]
   (`narrow_exit = narrow_entry + width`). `min_coverage_frac` is fixed at
   `0.75` [default], never tuned.
3. **OOS selection criterion:** walk-forward with `3` folds [default]. For
   each grid point compute downstream gate quality: the mean after-cost
   bps/trade of dispersion trades **passed** in WIDE vs **blocked** (or the
   mean of short-vol-carry trades passed in NARROW vs WIDE) — the gate must
   separate trade quality by ≥ the expected cost, otherwise it adds no value.
   Feature-only fallback when no downstream exists: label stability
   (adjacent-grid agreement `≥ 0.85` [default]) **and** WIDE-hit rate in
   `[0.05, 0.30]` [default] of bars (rejects degenerate always/never-WIDE
   configs). Select the grid point maximizing the OOS objective; ties break
   toward the smoother config (wider hysteresis, longer window) [rule].
4. **Re-calibration cadence:** quarterly (`recal_cadence_months = 3`
   [default]); event-driven on universe changes, tick-size changes, or
   persistent F3 outlier-driven flags; never re-fit on the live evaluation
   window (F5).
5. **Degeneracy guards:** WIDE-hit rate `< 0.01` [default] on the calibration
   window → lower the entry threshold; `> 0.50` [default] → the bands are
   degenerate for this universe — switch to a z-scored variant
   (`z_XS = (XS − median(XS)) / IQR(XS)`) with percentile bands, or split the
   universe by sector; document the choice, never force the bands.

### R2.6 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. `events[1..T]` newest last,
each with `event_ts` (int64 ns UTC), per-name vols `v[1..N]` (percent, daily),
optional `adj_factor[1..N]` and `market_state`.

```
function DETECT(events[1..T], prev, hist, cfg) -> RegimeState:
  # F1 — input validity: invalid input -> UNKNOWN, never interpolate
  if T == 0: return UNKNOWN("no-events")
  e = events[T]; ts = e.event_ts

  # Market-state machine (§R0.5)
  if e.market_state == HALTED:  return UNKNOWN("halted")   # frozen; bar not stored
  if e.market_state == AUCTION: return DEGRADED("auction-hold", last_label)
  if e.market_state == CLOSED:  return OFF()

  # Gap policy (F4): > 3x cadence -> UNKNOWN; (1x, 3x] -> DEGRADED, masked
  if last_ts is not None:
    dt = ts - last_ts
    if dt > 3 * CADENCE: return UNKNOWN("stale-gap")   # frozen; bar not stored
    gap_masked = (dt > CADENCE)

  # F1 — coverage: count missing (empty/unparseable) name vols
  present = [v_i for v_i in e.v if v_i is not missing]
  if any(not finite(v) or v < 0 for v in present): return UNKNOWN("bad-vol")  # F2
  if |present| / N < cfg.min_coverage_frac: return UNKNOWN("insufficient-coverage")

  # Corporate-action guard: an unadjusted jump is bad data, not volatility
  if |hist| >= 5:
    for i, v in enumerate(e.v):
      med = median(hist[-20:][i])            # trailing per-name vol
      if med > 0 and v > cfg.ca_jump_tol * med:
        return UNKNOWN("unadjusted-corporate-action")   # 5.0x [default]

  # Estimator (causal: panel at T only)
  if |present| < 2: return UNKNOWN("degenerate-panel")
  XS = stdev(present)                                    # ddof=1 [default]
  if not finite(XS): return UNKNOWN("non-finite-xs")     # F2

  label = HYSTERESIS(prev, XS, cfg)                      # §R2.7

  # F3 — dual estimator: leave-one-name-out band agreement
  reasons = []
  if gap_masked:            reasons += "gap-masked"
  if |present| < N:         reasons += "partial-coverage"
  for i in 1..|present|:
    if BAND(XS without name i) != BAND(XS): reasons += "outlier-driven"; break
  # (offline Verifier: 60-day [default] window recomputation must agree on
  #  band; persistent disagreement -> hold + investigate, never silent)

  store e.v in hist; last_ts = ts; prev = label
  return (reasons ? DEGRADED(reasons, label, XS) : OK(label, XS)),
         computed_at = ts
```

### R2.7 State-transition table (hysteresis — normative)

Boundaries: `we=0.50, wx=0.40, ne=0.25, nx=0.30` [example]. Read: entry
comparisons are strict (`≥` enters — the boundary value itself enters);
exit is sticky — the label persists while `XS` stays on the exit side of
the band. A value crossing the far band promotes/demotes from **any** state.

| prev \ XS | `≥ 0.50` | `0.40–0.50` | `0.30–0.40` | `0.25–0.30` | `≤ 0.25` |
|---|---|---|---|---|---|
| WIDE | WIDE | WIDE (hold) | NORMAL (exit) | NORMAL | NARROW |
| NORMAL | WIDE (entry) | NORMAL | NORMAL | NORMAL | NARROW (entry) |
| NARROW | WIDE | NORMAL | NORMAL | NARROW (hold) | NARROW |

Boundary values are pinned by unit tests
(`test_hysteresis_entry_exit_boundaries`): `XS = 0.50` exactly enters WIDE;
`XS = 0.40` exactly holds WIDE; `XS = 0.25` exactly enters NARROW;
`XS = 0.30` exactly holds NARROW.

## §R3 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: vol-arbitrage / dispersion trading | amplifies | vol-of-vol is the opportunity set: wide cross-sectional vol coincides with the dispersion-trading opportunity (cf. the correlation-risk-premium evidence, §R8) |
| T: short-vol carry | degrades | the short leg can explode when vol is non-uniform; gap risk concentrates in WIDE |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes per-name 20-day [example] realized vols and the cross-sectional std at the close; publishes the RSV.
- **Verifier:** runs the leave-one-name-out band-agreement check in-detect (F3); offline, recomputes XS from a 60-day [example] vol window — persistent band disagreement with the 20-day gauge → hold + investigate, never silent. (The old raw "60-day must agree or UNKNOWN" sat on the estimator's sampling noise and is superseded in 1.1.0: the in-detect guard is the jackknife; the 60-day check is a monitor.)
- **Grok-Researcher:** tracks vol-regime literature — leads only.
- **Adversary:** injects a universe change without errata (the gate must reject it); injects an unadjusted corporate-action jump (must go UNKNOWN, not WIDE); probes exact band boundaries (`XS = 0.50` / `0.40` / `0.25` / `0.30`); drops names below coverage.
- **Gate:** accepts only with the fixed universe and window; quarantines on persistent F3 outlier-driven flags.
- **F1–F5 instantiated:** F1 missing/stale/insufficient-coverage → `UNKNOWN` (restrictive downstream); F2 bounds + corporate-action guard on every emission; F3 leave-one-out band agreement (DEGRADED) + offline 60-day monitor; F4 staleness TTL `3`× cadence → `UNKNOWN`; F5 window and universe fixed ex ante; no ex-post picking.

## §R5 Cost interface: regime state → cost-function adjustment

Regime state → cost-function adjustment: cross-sectional vol scales the
**spread** and **impact** legs of `expected_cost_bps`. Borrow and fees do not
scale with vol-of-vol. `UNKNOWN` is restrictive: multipliers are undefined and
`trade_ok = False`.

| State | `spread_mult` | `impact_mult` | `borrow_mult` / `fees_mult` | `trade_ok` |
|---|---|---|---|---|
| WIDE | `2.0` [example] | `2.0` [example] | `1.0` [default] | `True` (dispersion entries OK; short-vol carry vetoed by the T gate) |
| NORMAL | `1.0` [default] | `1.0` [default] | `1.0` [default] | `True` |
| NARROW | `1.0` [default] | `1.0` [default] | `1.0` [default] | `True` |
| UNKNOWN | undefined | undefined | undefined | `False` (restrictive default) |

```python
def cost_adjustment(rsv_state, base):
    # base: dict(spread_bps, impact_bps, borrow_bps, fees_bps) from the gated
    # strategy's COST block. Only spread and impact scale with vol-of-vol.
    adj = dict(base)
    if rsv_state == "WIDE":
        adj["spread_mult"] = 2.0   # [example] starting point — calibrate per below
        adj["impact_mult"] = 2.0   # [example]
        adj["trade_ok"] = True
    elif rsv_state == "UNKNOWN":
        adj["trade_ok"] = False    # restrictive default: never benign
    else:  # NORMAL / NARROW
        adj["spread_mult"] = 1.0   # [default]
        adj["impact_mult"] = 1.0   # [default]
        adj["trade_ok"] = True
    adj["borrow_mult"] = 1.0       # [default] borrow does not scale with vol-of-vol
    adj["fees_mult"] = 1.0         # [default] fees do not scale with vol-of-vol
    return adj
```

**Multiplier calibration recipe** (the `[example]` values above are starting
points, never live values):

1. Per name, from trade-and-quote (or SIP NBBO) data over `≥ 6` months
   [default], compute the realized effective spread per trade and the XS band
   at the trade time.
2. Regress effective spread on XS bands; define
   `spread_mult(band) = median spread in band / median spread in the NORMAL
   band`, and analogously `impact_mult` from implementation-shortfall
   slippage by band.
3. Re-fit quarterly [default]; if the fitted `WIDE` multiplier is `< 1.5`
   [default], this universe's spread is not vol-of-vol-convex — set both
   multipliers to `1.0` [default] and document it.

**Executable gate** (for T-module `expected_cost_bps` predicates):

```
eff_cost = expected_cost_bps(notional, adv_pct, venue, side, urgency,
                             spread_bps = base.spread_bps * adj.spread_mult,
                             impact_bps = base.impact_bps * adj.impact_mult)
enter_ok = adj.trade_ok and eff_cost <= k * edge_bps   # k [default] per T chapter
```

`trade_ok = False` vetoes new entries for cost-sensitive strategies; existing
positions are managed per the T-module's own exits, never forced flat by this
module.
