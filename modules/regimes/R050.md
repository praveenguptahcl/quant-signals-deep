## §R2 Precise definition

**Capability-gated module.** SIP-vs-direct divergence (the latency/quote gap between the consolidated SIP and colocated direct feeds) is a real regime for latency-sensitive strategies — but it cannot be measured without colocated direct feeds. On this stack (non-colocated, SIP-only), the module is specified and tested but permanently emits `UNKNOWN`. Any SIP-only 'divergence' number would be fabrication; the honest output is `UNKNOWN` with the reason attached.

### Normative detection pseudocode

Pseudocode is normative; prose is commentary. Numeric policy: defaults are
`[default]`; production values MUST be calibrated per the §R3 recipe; none are
exercised on this stack (the gate closes before any arithmetic).

```python
# R050 detect — normative pseudocode
function detect(state, events, cfg) -> RegimeState:
    # 0. capability gate (F1) — evaluated BEFORE any arithmetic
    if not cfg.direct_feeds_available:
        return RegimeState(state=UNKNOWN, value=NaN, module_state=UNKNOWN,
                           reason="F1: no direct feeds; SIP-only stack cannot "
                                  "measure SIP-vs-direct divergence")

    # 1. input validation (F1/F2)
    if events is empty:
        return RegimeState(UNKNOWN, NaN, UNKNOWN, reason="F1: empty events")
    ev = sort_by_event_ts(events)
    if ev has duplicate or unorderable event_ts:
        return RegimeState(UNKNOWN, NaN, UNKNOWN, reason="F1: ambiguous event order")
    for e in ev:
        if e.market_state == HALTED:
            freeze(state)
            return RegimeState(UNKNOWN, NaN, UNKNOWN,
                               reason="halt: freeze and UNKNOWN")
        if e.sip_ts is missing or any venue exchange_ts is missing:
            return RegimeState(UNKNOWN, NaN, UNKNOWN,
                               reason="F1: missing synchronized timestamps")

    # 2. per-bar divergence (§R3), synchronized clocks only
    divs = []
    for e in ev:
        skew_us = abs(e.exchange_ts - e.sip_ts) / 1000   # ns -> us (unit conversion)
        if skew_us > cfg.max_clock_skew_us:
            return RegimeState(UNKNOWN, NaN, UNKNOWN,
                               reason="clock skew exceeds budget")
        D = abs(P_direct(e) - P_sip(e)) / P_sip(e) * 1e4  # §R3 [example]
        if (not isfinite(D)) or D < 0 or D > cfg.div_cap_bps:
            return RegimeState(UNKNOWN, NaN, UNKNOWN,
                               reason="F2: non-finite or out-of-bounds D")
        divs.append(D)

    # 3. hysteresis state machine (no flapping)
    prev = state.prev_state if state.prev_state in {CALM, DIVERGENT} else CALM
    D_t = divs[-1]                       # causal: inputs <= t only
    if D_t >= cfg.enter_bps:    s = DIVERGENT
    elif D_t <= cfg.exit_bps:   s = CALM
    else:                       s = prev    # hysteresis hold between bands

    # 4. market-state handling
    if last(ev).market_state == AUCTION:
        return RegimeState(s, D_t, DEGRADED, reason="auction: hold, DEGRADED")
    return RegimeState(s, D_t, OK, ...)
```

Edge cases handled: empty events → `UNKNOWN` (F1); unorderable/duplicate
timestamps → `UNKNOWN` (F1); `HALTED` → freeze + `UNKNOWN`; `AUCTION` → hold +
`DEGRADED`; clock skew over budget → `UNKNOWN`; non-finite/negative/over-cap
`D` → `UNKNOWN` (F2); SIP-only input → `UNKNOWN` at the gate (F1) — never a
computed number; hysteresis band → hold previous state (no flip-flop).

### Why UNKNOWN is permanent here (preserved by design)

1. `D_t` is defined over two quantities: `P_direct` (observable only from
   colocated exchange feeds) and `P_SIP`. On this stack `P_direct` is absent
   entirely — not delayed, not degraded, absent. There is no estimator, proxy,
   or SIP-derived quantity that identifies `D_t`; a SIP-only 'divergence' is a
   function of one input masquerading as two.
2. What would change this: colocated direct feeds + PTP-synchronized capture
   (§R6) — the §1.5 escalation gate. Nothing else does.
3. Consumer contract: treat `UNKNOWN` as *no information, not neutral*.
   The cost interface forces identity adjustments (§R5); downstream regime
   gates must use `unknown_behavior = "no gate applied"` (restrictive default
   per template) — never substitute a neutral value with confidence.

## §R3 Exact calculation

What would be measured (not measurable here):

$$D_t = \frac{|P^{direct}_t - P^{SIP}_t|}{P^{SIP}_t} \times 10^4 \text{ bps}$$

with synchronized clocks and colocated direct feeds. On this stack both inputs
are unavailable, so `detect` returns `NaN` → `UNKNOWN` by construction (F1/F2).
The fixture is a 3-row stub documenting the gate — including a row where a
SIP-derived proxy value is offered and must be rejected; the acceptance tests
assert `UNKNOWN`, never a fabricated value.
