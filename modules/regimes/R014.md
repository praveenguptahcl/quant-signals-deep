### R0.2b Threshold-calibration recipe (mandatory before production use)

1. **Data.** ≥ `6` months [default] of consolidated trades (SIP-class feed) for
   the target ticker(s), split/dividend-adjusted via the vendor's corporate-action
   calendar (e.g. Massive back to `2008` [documented]). Volume-drought sessions
   are retained and labeled (never silently dropped).
2. **Grid** (each point = a full regime-labeling of the sample):
   - `bucket_adv_frac` ∈ `{0.01, 0.02, 0.05}` [default grid]
   - `buckets` (window `n`) ∈ `{30, 50, 100}` [default grid]
   - `enter_extreme` ∈ `{0.60, 0.65, 0.70, 0.75, 0.80}` [default grid];
     `exit_extreme` = `enter_extreme − δ`, `δ` ∈ `{0.05, 0.10}` [default grid]
   - `enter_elevated` ∈ `{0.20, 0.25, 0.30, 0.35}` [default grid];
     `exit_elevated` = `enter_elevated − 0.05` [default grid]
3. **Procedure.** Expanding-window walk-forward, `3` folds [default], embargo of
   `5` trading days [default] between train and test. Objective: maximize
   avoided adverse-selection cost per alert-day, net of stand-down opportunity
   cost [default objective — book-specific, must be written down before the
   search]. Select the grid point with the best mean OOS objective; ties break
   toward the **wider** hysteresis (fewer label flips) [default tie-break].
   Report the flip rate (label changes per `100` buckets [default]) as the
   stability metric and the dual-estimator agreement rate on the OOS slice.
4. **Acceptance gates.** OOS objective > `0` [default]; flip rate < `5` per
   `100` buckets [default]; dual agreement ≥ `95`% of OOS buckets [default].
5. **Re-cal cadence.** Quarterly [default]; sooner if the trailing `30`-day VPIN
   distribution shifts (two-sample KS test `p < 0.05` [default]) or ADV moves
   > `25`% [default] (bucket size `V` is ADV-relative — ADV drift silently
   rescales the clock).
6. **Magic-number ban.** No shipped default may be presented as tuned. The
   production config records the selected grid point, OOS objective, flip rate,
   and the decision-log entry ID of the calibration run.

### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; VPIN at bucket-close uses buckets ≤ t; gates t+1+ quoting).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

VPIN [documented]: `VPIN = Σ_τ |V^B_τ − V^S_τ| / (n·V)` over n equal-volume buckets; bulk classification `V^B_τ = V_τ·Φ(ΔP_τ/σ)` [documented]. Cross-check [documented RB-list]: tick-rule classification, tolerance `±0.1`; VPIN ∈ [0,1] bounds mandatory.

## §R2 Exact calculation

$$\text{VPIN} = \frac{\sum_{\tau=1}^{n} |V^B_\tau - V^S_\tau|}{n\cdot V}, \qquad V^B_\tau = V_\tau\cdot\Phi(\Delta P_\tau/\sigma_{\Delta P}) \quad\text{[documented]}$$

Worked example [documented Grok RB2]: `Σ|V^B−V^S| = 30,838`, `n·V = 60,000` → `VPIN = 0.514` ⇒ elevated.

**Data inputs.** Consolidated trades (price, size, timestamp, sale conditions)
— full vendor/schema mapping and the trade filter in §R0.3; do NOT substitute
clock-time bars [documented Grok RB2].

**Cadence.** per-bucket intraday.

### R2.2 Normative detection pseudocode

The pseudocode is normative; prose is commentary. `state.prev_label` is the
module-owned label from the previous evaluation (persisted across cadences).

```
function detect(state, events, cfg) -> RegimeState:        # §R0.1
    # R0.5 lag: read only events with event_ts <= t
    bars = [e for e in events if e.kind == TRADE_BUCKET and e.event_ts <= t]
    if bars empty:                      return RSV(state=UNKNOWN, label='missing')        # F1
    if any missing(price,size,event_ts): return RSV(state=UNKNOWN, label='invalid')        # F1
    if any market_state == HALTED:       return RSV(state=UNKNOWN, label='halted')          # freeze
    if len(bars) < cfg.min_buckets:      return RSV(state=DEGRADED, label='warming')        # warm-up
    trades = apply_trade_filter(bars)    # §R0.3: drop I/P/V/7/4 prints + cancels
    if excluded_volume_share > 0.15:     return RSV(state=DEGRADED)                        # tape pathology [default]
    buckets = accumulate_volume_clock(trades, V = cfg.bucket_adv_frac * ADV)              # V ≈ 1/50 ADV [documented]
    if last bucket incomplete:           hold last label; do NOT emit a new one            # never extrapolate
    dp = bucket price changes; sigma = rolling_std(dp, cfg.buckets)
    if sigma <= cfg.sigma_min:           return RSV(state=UNKNOWN)                         # F2 sigma-collapse
    if any |dp_tau|/sigma > cfg.split_guard_sigmas:
        return RSV(state=DEGRADED, label='corporate_action_suspect')                       # §R7-5
    for tau in buckets:
        Vb_tau = V_tau * Phi(dp_tau / sigma)                                              # BVC [documented]
        imb_tau = |Vb_tau - (V_tau - Vb_tau)| / V_tau
    vpin = mean(imb_tau)                                                                  # in [0,1]
    label = HYSTERESIS(vpin, state.prev_label, cfg)                                        # §R2.3
    # F3 dual-estimator agreement (tick-rule verifier)
    vpin_tick = mean(|2*buy_frac_tau - 1|)
    if |vpin - vpin_tick| > cfg.dual_tol: return RSV(state=UNKNOWN)                        # F3
    state.prev_label = label
    return RSV(regime_id='R014', label, vpin, OK, computed_at = newest bar event_ts)

function HYSTERESIS(v, prev, cfg):        # §R2.3 transition table, normative
    if not isfinite(v):            return 'undefined'
    if prev == 'extreme':
        if v >= cfg.exit_extreme:  return 'extreme'
        if v >= cfg.enter_elevated: return 'elevated'
        return 'clean'
    if prev == 'elevated':
        if v >  cfg.enter_extreme: return 'extreme'
        if v >= cfg.exit_elevated: return 'elevated'
        return 'clean'
    # cold start / clean / degraded prev: stateless entry
    if v >  cfg.enter_extreme:     return 'extreme'
    if v >= cfg.enter_elevated:     return 'elevated'
    return 'clean'
```

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Market-making / passive fills | **inverts** | dies above 0.7 — adverse selection spikes; widen quotes 2–3× [documented practitioner] or withdraw |
| Informed-flow following (momentum ignition) | **amplifies then inverts** | improves in 0.5–0.7 (trade *with* the toxic flow's direction); dies above 0.7 (untradeable violence) |
| Retail-style mean reversion | **inverts** | dies — fading informed flow is donating |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes VPIN per bucket; publishes RSV.
- **Verifier:** tick-rule recomputation; |diff| > `0.1` [documented RB-list] → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes bucket counts; leads only.
- **Adversary:** checks volume-time (not clock-time) buckets; checks no lookahead from late-closing buckets.
- **Gate:** rejects directional VPIN strategies; rejects VPIN during volume droughts.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the

  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Toxicity is adverse selection: the adjustment widens the spread assumption
2–3× [documented practitioner] in the extreme state and blocks passive fills —
the cost of being picked off. The dominant economic cost is the opportunity
cost of standing down (missed edge), not modeled here [example — qualitative].

| Component (4-stack) | clean | elevated | extreme | degraded (`halted`, `corporate_action_suspect`, `warming`, …) |
|---|---|---|---|---|
| `spread_bps_mult` | `1.0` [default] | `2.0` [example] | `3.0` [example] | `2.0` [default] |
| `passive_ok` (passive fills) | allowed | **blocked** [default] | **blocked** [default] | **blocked** [default] |
| `trade_ok` (aggressive) | allowed | allowed | **stand down** — no fills assumed [default] | allowed, passive blocked |
| `impact_bps_add` | `0.0` [default] | `0.0` [default] | `0.0` [default] | `0.0` [default] |
| `borrow_bps_per_day` | `0.0` [default] | `0.0` [default] | `0.0` [default] | `0.0` [default] |
| `fee_bps` | unchanged (vendor schedule, `fee_schedule_as_of` in the consuming T-module) | | | |

```python
def cost_adjustment(rsv, base):
    """Regime state -> cost-function adjustment (Appendix h v1.0.0).
    Components named per the 4-component stack (spread/fees/borrow/impact).
    Mirrored verbatim in modules/tests/test_R014.py::cost_adjustment."""
    adj = dict(base)
    st = rsv["state"] if isinstance(rsv, dict) else rsv.state
    if st == "extreme":
        adj["trade_ok"] = False       # [default] stand down: no fills assumed
        adj["passive_ok"] = False     # [default]
        adj["spread_bps_mult"] = 3.0  # [example] top of practitioner 2-3x band
        adj["impact_bps_add"] = 0.0   # [default] impact not modeled at this tier
    elif st == "elevated":
        adj["trade_ok"] = True
        adj["passive_ok"] = False     # [default] no passive fills in toxic flow
        adj["spread_bps_mult"] = 2.0  # [example] mid of practitioner 2-3x band
        adj["impact_bps_add"] = 0.0   # [default]
    elif st in ("halted", "corporate_action_suspect", "warming", "missing",
                "invalid", "undefined"):
        adj["trade_ok"] = True
        adj["passive_ok"] = False     # [default] restrictive default on degradation
        adj["spread_bps_mult"] = 2.0  # [default] widen on degradation
        adj["impact_bps_add"] = 0.0   # [default]
    else:  # clean
        adj["trade_ok"] = True
        adj["passive_ok"] = True
        adj["spread_bps_mult"] = 1.0  # [default]
        adj["impact_bps_add"] = 0.0   # [default]
    adj.setdefault("borrow_bps_per_day", 0.0)  # [default] flat-inventory reason above
    return adj
```

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Clock-time bars → detect: buckets not equal-volume → action: halt, rebuild on the volume clock; recovery: replay from a volume-clocked tape | `check: volume clock` |
| 2 | BVC/tick-rule disagree → detect: `\|diff\| > 0.1` [documented] → action: `UNKNOWN` (F3); recovery: auto-clear on the next agreeing bucket, no manual re-arm [default] | `check: dual agreement` |
| 3 | Volume drought → detect: bucket fill time > `3`× median [default], or a zero-volume bucket → action: `UNKNOWN`, never extrapolate [documented RB-list]; recovery: resume when buckets fill, re-warm `min_buckets` | `check: buckets filling` |
| 4 | Directional use → detect: VPIN signed into a long/short → action: Gate rejects (VPIN is unsigned toxicity); recovery: redesign the consumer | `check: unsigned` |
| 5 | Corporate-action jump on a raw tape → detect: `\|ΔP\| > 20σ` [default] → action: `DEGRADED` (`corporate_action_suspect`), label withheld; recovery: re-vintage on a split/dividend-adjusted series, then re-warm | `check: no split jumps` |
| 6 | σ-collapse → detect: `σ ≤ 1e-8` [default] → action: `UNKNOWN` (F2 — never divide by near-zero σ); recovery: widen the σ lookback or go `DEGRADED` until σ recovers | `check: sigma positive` |
| 7 | Halt mid-session → detect: halt event in the window → action: freeze state, `UNKNOWN`; recovery: discard contributions across the reopen, re-warm `min_buckets` [default] | `check: market-state table` |
| 8 | Tape pathology → detect: excluded-sale-condition share > `15`% of raw volume [default] → action: `DEGRADED`; recovery: investigate the vendor feed, do not silently proceed | `check: filtered share` |
| 9 | Label flicker on threshold noise → detect: flip rate > `5` per `100` buckets [default] in the calibration report → action: widen hysteresis (re-run §R0.2b); recovery: re-calibrated grid point logged | `check: flip rate` |

**Honest DEGRADED/UNKNOWN behavior:** `UNKNOWN` is the restrictive token —
downstream must halve size / widen stops / stand down, never treat it as benign
(§R0.5). `DEGRADED` withholds the label (warming, tape pathology, suspected
corporate action) and recovers only through re-warm or re-vintage — there is no
auto-clear into `OK` except F3 agreement and volume-drought fill (rows 2–3),
which are observable and logged.
