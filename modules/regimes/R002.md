(variance units, decimal) or `VIX − 100·RV_30d` (vol points, desk convention).

## §R1 Precise definition

Difference between risk-neutral expected variance (option-implied) and physical realized variance over the same horizon. Quote in variance units (σ²); desks often quote vol points (`VIX − 100·RV`). Documented qualitative fact: average VRP is positive for equity indices [documented] (Bollerslev–Tauchen–Zhou).

## §R2 Exact calculation

$$VRP_t = IV_t^2 - RV_t^2 \quad\text{(variance points) [documented]}$$

$$VRP^{volpts}_t = VIX_t - 100\cdot RV_t \quad\text{(vol points, desk convention [documented])}$$

with $IV_t$ = VIX/`100` (`30`-day implied vol [documented]) and $RV_t$ the
`21`-day [default] annualized realized vol of SPX log returns. Normalize:
$z = (VRP_t - \mu_{252d}) / \sigma_{252d}$. Documented qualitative facts: the
average VRP is positive for equity indices [documented] — Bollerslev–Tauchen–Zhou
(2011) report monthly implied vol mean `20.08` vs realized `12.68` (1990–2008)
[documented]; Carr–Wu (2009) report long 30-day SPX variance swaps averaging
`−2.74` per `$100` annualized notional, i.e. a positive premium to variance
sellers [documented]. (A point estimate of the average magnitude in variance
points could not be sourced to a specific table — see §R10.)

**Data inputs.** VIX close (index points), 30-day trailing realized variance of
SPX/SPY (decimal, annualized). Both legs same horizon: `rv_window_days = 21`
trading days ≈ `30` calendar days [default].

**Cadence.** daily (uses close prints).

### R2.1 Realized-vol leg (normative)

```python
def realized_vol(adj_closes, rv_window_days):
    # adj_closes: dividend/split-ADJUSTED SPX (or SPY) closes, event_ts <= t, newest last
    rets = [log(adj_closes[i] / adj_closes[i-1]) for i in last rv_window_days bars]
    return sqrt(252) * stdev(rets, ddof=1)   # annualized, decimal; 252 [documented]
```

- Adjusted closes are **normative**: SPX is a price-return index; unadjusted
  ex-div gaps inflate the RV leg [default]. If adjusted closes are unavailable,
  drop the ex-div bar and mask — never interpolate [default].
- `sqrt(252)`: `252` trading days/year [documented].

### R2.2 VRP legs, z-score, and hysteresis machine (normative)

```python
def vrp_bar(vix_close, rv):
    iv = vix_close / 100.0
    return {'var':    iv**2 - rv**2,             # variance units, decimal [documented]
            'volpts': vix_close - 100.0 * rv}   # vol points, desk convention [documented]

def label_bar(vrp_history, cfg, prev_label):
    # vrp_history: vol-point VRP series, event_ts <= t, newest last (strictly causal)
    assert cfg.fear_exit_z > cfg.fear_entry_z             # startup assertion [default]
    assert cfg.complacent_exit_z < cfg.complacent_entry_z # startup assertion [default]
    cur = vrp_history[-1]
    prior = last min(cfg.z_window_days, len(vrp_history) - 1) values before cur  # leave-one-out
    if len(prior) < cfg.z_window_min_bars:
        return ('warming', 'DEGRADED', None)    # label withheld during warm-up
    mu, sd = mean(prior), stdev(prior, ddof=1)
    z = (cur - mu) / sd if sd > 1e-12 [default] else 0.0  # flat history -> no signal [default]
    return (transition(prev_label, z, cfg), 'OK', z)

def transition(prev, z, cfg):                   # hysteresis state machine (normative)
    if prev == 'fear':
        return 'normal' if z > cfg.fear_exit_z else 'fear'
    if prev == 'complacent':
        return 'normal' if z < cfg.complacent_exit_z else 'complacent'
    if z < cfg.fear_entry_z:        return 'fear'         # strict entry bands
    if z > cfg.complacent_entry_z:  return 'complacent'
    return 'normal'
```

**Threshold bands** (entry strict, exit looser — the deadband prevents
flicker; all `[default]`, calibration recipe in §R2.3):

| Entry | Exit | Label | Tag |
|---|---|---|---|
| `z < −1.5` | `z > −1.0` (deadband `0.5`σ) | fear (IV bid up) | [default] |
| — | — | normal | [default] |
| `z > 1.5` | `z < 1.0` (deadband `0.5`σ) | complacent (IV cheap vs realized) | [default] |

**Edge cases (normative).** Missing VIX or RV bar → F1 `UNKNOWN`, mask, never
interpolate. Halt/auction day → freeze per §R0.6; discard contributions across
reopen. Corporate action → adjusted closes per §R2.1; unadjusted ex-div bar
dropped. `vix ≤ 0`, `rv ≤ 0`, or non-finite → F1 `UNKNOWN`. `z_window_days`
counts trading bars only — weekends/holidays are not bars [default].
`sd ≤ 1e-12` [default] → `z = 0.0`, label `normal`, module stays `OK` (flat
vol history carries no information) [default].

### R2.3 Detection calibration recipe (normative procedure; candidate values [example])

The `±1.5`/`±1.0` bands are **uncalibrated defaults** — no OOS calibration run
exists in the changelog as of v1.1.0 [documented]. Do not hand-tune; run this:

1. **Data:** ≥ `10` years [example] of daily VIX closes (FRED `VIXCLS`) +
   dividend-adjusted SPX/SPY closes; both legs horizon-matched (`21` trading
   days ≈ `30` calendar days [default]).
2. **Grid** [example]: `fear_entry_z ∈ {−2.5, −2.25, …, −0.75}`;
   `fear_exit_z = fear_entry_z + d`, `d ∈ {0, 0.25, 0.5, 0.75, 1.0}`;
   complacent mirrored; `z_window_days ∈ {126, 252, 504}`;
   `rv_window_days ∈ {21, 30}`.
3. **OOS protocol:** walk-forward — fit z-normalization stats on trailing data
   only, evaluate on the next `63` trading days [example], step `21` days
   [example]; embargo `21` days [default] between fit and evaluation windows
   (purged embargo, López de Prado 2018 [documented]).
4. **Selection criterion (normative):** maximize OOS state separation
   `S = mean(forward 21-day VRP on fear-labeled days) − mean(forward 21-day VRP
   on normal days)`, subject to label churn ≤ `4` flips/year [example] and
   ≥ `30` fear-days per fold [example]; tie-break toward the wider deadband
   (fewer flips) [default].
5. **Re-calibration cadence:** annually in Q1 [default]; freeze mid-year unless
   F2/F3/F4 trips exceed `3` in a quarter [example] → mandatory review.
6. **Selection disclosure (F5):** publish chosen parameters, OOS `S`, fold
   dates, and the grid in §R8 before deploying calibrated values; calibrated

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Option-selling / premium-harvest | **amplifies then inverts** | improves when VRP strongly positive; dies when VRP negative (buying fear at the wrong time). Expected edge ≈ VRP minus gap risk |
| Volatility-breakout signals | **amplifies** | improves when VRP deeply negative (realized about to exceed implied — repricing ahead) |
| Directional intraday equity signals | **neutral** | VRP is a positioning filter, not a trigger |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** pulls the VIX close + computes the RV leg per §R2.1 (`21`-day
  [default] trailing, dividend-adjusted closes); publishes RSV daily after
  ~16:30 ET [default].
- **Verifier:** recomputes the *full label* from the variance-unit VRP series
  (`(VIX/100)² − RV²`, same machine, same config); the two labels must agree
  or module state is `UNKNOWN` (F3, state-mode agreement). Honest note: for
  positive `vix`/`rv` the two VRP conventions always agree in *sign*
  (`sign(vix − 100·rv) = sign((vix/100)² − rv²)`), so a sign check alone is
  vacuous — the binding check is label agreement across unit conventions
  [documented derivation].
- **Grok-Researcher:** proposes z windows and horizon matching; leads only.
- **Adversary:** verifies the RV window is strictly trailing (no realized-vol lookahead into the 'forecast' window); injects a horizon mismatch (`5`-day RV vs `30`-day VIX) and a vol-point/variance-unit mix — both must trip F2/F3 → `UNKNOWN`.
- **Gate:** rejects chapters that mix vol-point and variance-unit VRP in one predicate; quarantines on label disagreement.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator *label* agreement
  (vol-point vs variance-unit series) or `UNKNOWN`; F4 staleness TTL `3`× cadence [default] → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.
## §R5 Cost interface: regime state → cost-function adjustment

VRP gates premium-harvest overlays. The adjustment scales the strategy's
*cost inputs* and the *required-edge multiplier* — never the edge estimate
itself. Consuming strategies wire it as:

```python
adj = cost_adjustment(rsv, base_cost_inputs)   # base: the strategy's COST block
# entry gate: expected_cost_bps(notional, adv_pct, venue, side, urgency,
#                               spread_bps=adj['spread_bps'], ...) * adj['edge_mult'] <= edge_bps  [default]
# routing:    adj['trade_ok'] False -> block new short-vol entries [default]
```

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, impact_bps, borrow_bps) from the strategy COST block
    adj = dict(base)
    adj['edge_mult'] = 1.0                      # [default] required-edge multiplier
    adj['tags'] = ['R002:' + rsv['state']]      # provenance tag on the adjustment
    st, ms = rsv['state'], rsv['module_state']
    if ms == 'UNKNOWN':
        adj['trade_ok'] = False                 # [default] restrictive: unknown blocks
    elif ms == 'DEGRADED':
        adj['trade_ok'] = False                 # [default] warming: label withheld
        adj['edge_mult'] = 1.5                  # [example]
    elif st == 'fear':
        adj['trade_ok'] = False                 # [default] stand down short-vol
        adj['edge_mult'] = 2.0                   # [example] 2x edge if manually overridden
        adj['spread_bps'] = base['spread_bps'] * 1.5    # [example] fear widens effective spread
        adj['impact_bps'] = base['impact_bps'] * 1.5    # [example] gap-risk impact
        adj['borrow_bps'] = base['borrow_bps'] * 1.25   # [example] borrow tightens in stress
    elif st == 'complacent':
        adj['trade_ok'] = True
        adj['edge_mult'] = 0.8                  # [example] rich premium compensates
    else:  # normal
        adj['trade_ok'] = True                  # passthrough
    return adj
```

Which components scale, by how much: `fear` scales spread ×`1.5` [example],
impact ×`1.5` [example], borrow ×`1.25` [example] and demands `2.0`× [example]
the edge (or blocks outright via `trade_ok = False` [default]);
`complacent` relaxes the required edge to `0.8`× [example]; `normal` passes
through; `UNKNOWN`/`DEGRADED` block new entries [default] (restrictive —
never treated as benign). `test_cost_interface` pins every multiplier.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Horizon mismatch → detect: RV window not the `30`-calendar-day equivalent of the VIX horizon → action: `UNKNOWN`, require matched horizons | `check: rv_window_days in {21, 30} [default] and iv_horizon_days == 30 [documented]` |
| 2 | Vol-point vs variance-unit mix → detect: Gate lint or F3 label disagreement → action: `UNKNOWN` | `check: units consistent; F3 labels agree` |
| 3 | Stale RV after crash → detect: RV leg older than `1` trading day [default] → action: STALE_PREV, no new entries | `check: rv_vintage == today` |
| 4 | F3 label disagreement → detect: vol-point label ≠ variance-unit label → action: `UNKNOWN` | `check: labels agree` |
| 5 | VIX publish missing (holiday / vendor outage) → detect: no VIX print for a trading day → action: `UNKNOWN`, mask (never interpolate); recovery: resume on next print, prior state persists (no re-warm) | `check: vix_vintage == today or last trading day` |
| 6 | Dividend/ex-div distortion → detect: unadjusted SPX close used across an ex-div date → action: recompute RV leg on adjusted closes; if unavailable, drop the bar and mask | `check: closes are dividend-adjusted` |
| 7 | Flat-vol degeneracy → detect: trailing `sd ≤ 1e-12` [default] → action: `z = 0.0`, label `normal`, module stays `OK` (no information, not an error) | `check: sd floor` |
| 8 | Data-rights violation risk → detect: any job programmatically scraping cboe.com delayed quotes → action: block at deploy (startup assertion); Cboe prohibits auto-extraction and blocks offending IPs [documented] | `check: feed in {FRED API, manual Cboe CSV}` |

**Honest DEGRADED/UNKNOWN behavior.** This module is daily-EOD by design and
is fully measurable on a free stack (FRED `VIXCLS` + adjusted SPX closes) —
there is no SIP-only blind spot for the daily detector. Intraday VRP is *not*
measurable here; that needs an OPRA/licensed feed and is the §1.5 escalation
gate, not a silent fallback. During warm-up (`< z_window_min_bars` prior bars
[default]) the module emits `DEGRADED`/`warming` and the label is withheld —
downstream must not gate on it. `UNKNOWN` is restrictive: downstream halves
size / widens stops / stands down (per §R0.5), never treated as benign (F1).
A halted underlying freezes the state per §R0.6; contributions across the
reopen are discarded, never interpolated.
