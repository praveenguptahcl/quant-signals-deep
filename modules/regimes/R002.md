# R002 — Implied-vs-realized spread (variance risk premium)

`VRP_t = IV_t² − E_t[RV²]` (variance points), proxied by `VIX² − RV_30d²`. Positive VRP = options expensive vs subsequent realized vol — the compensation option sellers earn. Sign flips mark fear/complacency turning points. Provenance **[D]**.

## §R1 Precise definition

Difference between risk-neutral expected variance (option-implied) and physical realized variance over the same horizon. Quote in variance units (σ²); desks often quote vol points (`VIX − 100·RV`). Documented qualitative fact: average VRP is positive for equity indices [documented] (Bollerslev–Tauchen–Zhou).

## §R2 Exact calculation

$$VRP_t = IV_t^2 - RV_t^2 \quad\text{(variance points) [documented]}$$

$$VRP^{volpts}_t = VIX_t - 100\cdot RV_t \quad\text{(vol points, desk convention [documented])}$$

with $IV_t$ = VIX/`100` (`30`-day implied vol [documented]) and $RV_t$ the `21`-day [default] annualized realized vol of SPX log returns. Normalize: $z = (VRP_t - \mu_{252d}) / \sigma_{252d}$. Documented: SPX VRP averages ≈ `+3` to `+5` variance points (≈ `+4` vol points) [documented].

**Data inputs.** VIX close (index points), 30-day trailing realized variance of SPX/SPY (decimal, annualized). Both legs same horizon.

**Cadence.** daily (uses close prints).

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `z < −1.5` | fear (IV bid up) | [example] |
| `|z| ≤ 1.5` | normal | [example] |
| `z > 1.5` | complacent (IV cheap vs realized) | [example] |

Bands on the z-score are `[example]`. The documented facts are the positive average VRP and the variance-unit definition — not the z cutoffs.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Option-selling / premium-harvest | **amplifies then inverts** | improves when VRP strongly positive; dies when VRP negative (buying fear at the wrong time). Expected edge ≈ VRP minus gap risk |
| Volatility-breakout signals | **amplifies** | improves when VRP deeply negative (realized about to exceed implied — repricing ahead) |
| Directional intraday equity signals | **neutral** | VRP is a positioning filter, not a trigger |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** pulls VIX + computes RV_30d; publishes RSV daily after Cboe publish.
- **Verifier:** cross-checks IV from a second surface source (CBOE vs broker IV); sign of the variance-unit VRP must match the vol-point VRP or state is `UNKNOWN`; tolerance ±`1` vol point [example].
- **Grok-Researcher:** proposes z windows and horizon matching; leads only.
- **Adversary:** verifies the RV window is strictly trailing (no realized-vol lookahead into the 'forecast' window); injects a horizon mismatch.
- **Gate:** rejects chapters that mix vol-point and variance-unit VRP in one predicate; quarantines on sign disagreement.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

VRP gates premium-harvest overlays: negative VRP widens the required edge (gap risk repriced); the adjustment scales the *required* edge multiple `k` rather than costs directly.

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, impact_bps, borrow_bps) from the strategy COST block
    adj = dict(base)
    adj['edge_mult'] = 1.0  # [default] required-edge multiplier
    if rsv['state'] == 'fear':
        adj['edge_mult'] = 2.0    # [example] demand 2x edge when VRP negative
        adj['trade_ok'] = False   # stand down short-vol
    elif rsv['state'] == 'complacent':
        adj['edge_mult'] = 0.8    # [example] rich premium compensates
        adj['trade_ok'] = True
    else:
        adj['trade_ok'] = True
    return adj
```
