## §R2 Precise definition

Cross-sectional dispersion: the sample (ddof = `1` [documented]) standard deviation of same-day returns across a fixed universe of N names. High dispersion = names moving on their own news = stock-picking weather; low dispersion = the index is the only trade. The universe is fixed ex ante in `universe.yaml`.

### Detection pseudocode (normative)

```python
def dispersion_bar(returns, cfg):
    # returns: same-day returns for the N fixed universe names, event_ts <= t
    if len(returns) != cfg.N:                 return UNKNOWN   # F1 panel-shape
    if any(not finite(r) for r in returns):   return UNKNOWN   # F1 missing name return
    if any(abs(r) > cfg.max_abs_return        # F2 corporate-action guard [default]
           for r in returns):                 return UNKNOWN
    n = len(returns); mu = sum(returns) / n
    D = sqrt(sum((r - mu)**2 for r in returns) / (n - 1))       # ddof=1 [documented]
    if not finite(D) or D < 0:                return UNKNOWN   # F2
    return D

def transition(prev, D, cfg):                 # hysteresis machine (normative)
    assert cfg.picker_exit < cfg.picker_entry  # startup assertion [default]
    assert cfg.index_entry < cfg.index_exit
    assert cfg.picker_exit > cfg.index_exit    # deadbands disjoint [default]
    if prev == 'STOCK_PICKER':
        return 'NEUTRAL' if D < cfg.picker_exit else 'STOCK_PICKER'
    if prev == 'INDEX_ONLY':
        return 'NEUTRAL' if D > cfg.index_exit else 'INDEX_ONLY'
    if D >= cfg.picker_entry:  return 'STOCK_PICKER'  # strict entry bands
    if D <= cfg.index_entry:   return 'INDEX_ONLY'
    return 'NEUTRAL'

def detect_bar(returns, cfg, prev):
    D = dispersion_bar(returns, cfg)
    if D is UNKNOWN:  return (UNKNOWN, 'UNKNOWN')
    D2 = statistics.stdev(returns)            # F3 independent code path
    if transition(prev, D, cfg) != transition(prev, D2, cfg):
        return (UNKNOWN, 'UNKNOWN')           # F3 dual-label disagreement
    return (transition(prev, D, cfg), 'OK')   # prev initialised 'NEUTRAL' [default]
```

**Machine properties (normative).** Entry bands are strict (`>=`/`<=`);
exits are looser (`<`/`>`), so exact-band values hold the current state
[default]. Exits always pass through `NEUTRAL` — the machine never jumps
`INDEX_ONLY ↔ STOCK_PICKER` directly [default]; a spike from `INDEX_ONLY`
into `STOCK_PICKER` territory exits to `NEUTRAL` first.

**Edge cases (normative).** Missing name return → F1 `UNKNOWN`, mask, never
interpolate. Missing bar → mask; other bars' labels unchanged (no
interpolation). Halt/auction day → freeze per §R0.6; contributions across
reopen are discarded (no-op for this same-day statistic, enforced
structurally). Corporate action → vendor `TOTALRETURN` adjustment is
normative [documented]; the `max_abs_return = 0.50` [default] guard catches
unadjusted feeds (e.g. a `1.5` [example] single-day spike from an unadjusted
split) → F2 `UNKNOWN`. Panel name count ≠ `N` → F1 `UNKNOWN` (universe
change is a hard error, never silently absorbed). `D` is same-day — there is
no warm-up period and no trailing window to look ahead into
[documented derivation].

## §R3 Exact calculation

Same-day returns `r_{i,t}`, `i = 1..N`:

$$D_t = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N}(r_{i,t} - \bar{r}_t)^2}$$

Hand-verified panel (6 names [example], 10 bars [example]; full tape in
`modules/fixtures/R042_tape.csv`, `# TYPE: validation-run`). Day 0:
`[0.01, −0.005, 0.02, 0.003, −0.01, 0.008]` → `D ≈ 0.0108197` → NEUTRAL.
Day 2: `[−0.021, −0.019, −0.02, −0.018, −0.022, −0.0195]` → `D ≈ 0.0014289` →
INDEX_ONLY. Day 3: `D ≈ 0.0085007` (hand-computed `0.01552 × √0.3`) — above
`index_entry` yet the state holds INDEX_ONLY: the hysteresis pin. Day 5:
`D ≈ 0.0160001` → STOCK_PICKER entry. Day 9: a `nan` name return → `UNKNOWN`
(F1) inside the fixture.

constants inside it inherit the tag per the tag law (Appendix i v1.0.0).
Worked-check numbers carry their own tags. Threshold bands above are

### Detection calibration recipe (normative procedure; candidate values [example])

The `0.015`/`0.012`/`0.007`/`0.010` bands are **uncalibrated defaults** — no
OOS calibration run exists in the changelog as of v1.1.0 [documented]. Do not
hand-tune; run this:

1. **Data:** ≥ `10` years [example] of daily `TOTALRETURN`-adjusted closes
   for the fixed universe (Norgate Platinum for a survivorship-free universe
   [documented]); returns computed on the adjusted series.
2. **Grid** [example]: `picker_entry ∈ {0.010, 0.0125, 0.015, 0.0175, 0.020,
   0.0225, 0.025}`; `picker_exit = picker_entry − d`,
   `d ∈ {0, 0.002, 0.003, 0.004, 0.005}`; `index_entry ∈ {0.005, 0.006,
   0.007, 0.008, 0.009, 0.010}`, `index_exit = index_entry + d`;
   reject grid points that violate the startup assertions.
3. **OOS protocol:** walk-forward — fit bands on trailing data only, evaluate
   on the next `63` trading days [example], step `21` days [example];
   embargo `21` days [default] between fit and evaluation windows (purged
   embargo, López de Prado 2018 [documented]).
4. **Selection criterion (normative):** maximize OOS state separation
   `S = mean(forward 21-day [example] active return of a reference long/short
   stock-picking strategy on STOCK_PICKER-labeled days) − mean(same on
   INDEX_ONLY-labeled days)`, subject to label churn ≤ `4` flips/year
   [example] and ≥ `30` labeled days per state per fold [example];
   tie-break toward the wider deadband (fewer flips) [default].
5. **Re-calibration cadence:** annually in Q1 [default]; freeze mid-year
   unless F2/F3/F4 trips exceed `3` in a quarter [example] → mandatory
   review.
6. **Selection disclosure (F5):** publish chosen parameters, OOS `S`, fold
   dates, and the grid in §R9 before deploying calibrated values; calibrated
   values replace `[example]` tags with `[measured]`.

def cost_adjustment(rsv, base):

    adj = dict(base)
    adj['spread_mult'] = 1.0    # [default] dispersion does not move cost inputs
    adj['impact_mult'] = 1.0    # [default]
    adj['borrow_mult'] = 1.0    # [default]
    adj['fee_add_bps'] = 0.0    # [default]

        adj['trade_ok'] = False   # [default] restrictive: unknown blocks new entries
    elif ms == 'DEGRADED':

        adj['edge_mult'] = 1.5    # [example] thin alpha demands more edge

**Why cost multipliers are identity.** Dispersion is a cross-sectional
statistic of returns — it conditions the *opportunity set* (documented:
von Reibnitz 2017 finds active-manager outperformance concentrates in
high-dispersion months [documented]), not the per-trade cost inputs. So the
interface scales nothing on the cost side and instead routes entry
permission and the required-edge multiplier. The record is versioned with
`estimator_version` and every application is decision-logged (Appendix g
v1.0.0). `test_cost_interface` pins every multiplier and the
restrictive `UNKNOWN`/`DEGRADED` routing.
