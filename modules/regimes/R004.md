## §R1 Precise definition

GARCH(1,1) (Bollerslev 1986 [documented]): `σ²_t = ω + α·r²_{t−1} + β·σ²_{t−1}`, persistence `π = α + β` (`π < 1` for covariance stationarity [documented]). Half-life of a variance shock: `t_{1/2} = ln(0.5)/ln(π)` days. HAR-RV alternative [documented]: `RV_{t+1} = c + β_d·RV_t + β_w·RV_{t−4:t} + β_m·RV_{t−21:t}`, persistence ≈ `β_d + β_w + β_m`.

## §R2 Exact calculation

$$\sigma^2_t = \omega + \alpha r^2_{t-1} + \beta\sigma^2_{t-1}, \qquad \pi = \alpha+\beta < 1$$

$$t_{1/2} = \frac{\ln(1/2)}{\ln(\pi)} \quad\text{days [documented]}$$

Fit on `252` days [default] of daily log-returns, rolling monthly [example]. Reference implementation uses a coarse grid MLE (operational proxy — the chapter's production fit uses a proper optimizer). Documented: many equity daily GARCH fits have `α+β` in `0.94–0.99` [documented] (model fact, not a trading P&L result).

**Data inputs.** daily log-returns, `2–5`y history [example]; demeaned returns for MLE.

**Cadence.** weekly refit.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `π < 0.85` | low persistence (shocks die fast — fade vol spikes) | [example] |
| `0.85 ≤ π ≤ 0.95` | normal | [example] |
| `π > 0.95` | extreme clustering (HL > `14` days — do not fade) | [example] |

Half-life map (illustrative): `π=0.90 → 6.6`d; `0.95 → 13.5`d; `0.98 → 34`d; `0.99 → 69`d. Bands are `[example]`.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Vol-fade / short-gamma intraday | **amplifies then inverts** | improves in low persistence; dies in extreme clustering (the spike you faded doubles) |
| Stop-loss calibration | **degrades** | stops sized on unconditional vol fail in high-persistence states; scale stops by `√(HL/HL_baseline)` |
| Vol-targeting overlays | **amplifies** | high persistence ⇒ yesterday's σ is still the right scale tomorrow |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** fits GARCH(1,1) weekly; publishes RSV with half-life.
- **Verifier:** fits HAR-RV (Corsi 2009) and requires the same qualitative state (low/normal/extreme) — tolerance is on the *state*, not the parameter; the reference test uses an independent coarse-grid GARCH fit as the deterministic second estimator; else `UNKNOWN`.
- **Grok-Researcher:** proposes windows and grids; leads only.
- **Adversary:** checks the fitting window excludes the evaluation period; injects a structural break to test fit stability.
- **Gate:** rejects α+β pinned at `0.999` as a regime (numerical artifact); requires ≥ `252` [default] observations.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Persistence scales stop distances and position sizing: in `extreme`, stops widen by `√(HL/HL_baseline)` and vol-targeted size shrinks — implemented as a sizing multiplier, not a cost change.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    hl = rsv.get('half_life_d', 14.0)
    adj['stop_mult'] = max(1.0, (hl / 14.0) ** 0.5)  # [example] baseline HL=14d
    adj['size_mult'] = 1.0 if rsv['state'] != 'extreme' else 0.5  # [example]
    adj['trade_ok'] = rsv['state'] != 'unstable'
    return adj
```
