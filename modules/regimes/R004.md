## §R1 Precise definition

GARCH(1,1) (Bollerslev 1986 [documented]): `σ²_t = ω + α·r²_{t−1} + β·σ²_{t−1}`, persistence `π = α + β` (`π < 1` for covariance stationarity [documented]). Half-life of a variance shock: `t_{1/2} = ln(0.5)/ln(π)` days. HAR-RV alternative [documented]: `RV_{t+1} = c + β_d·RV_t + β_w·RV_{t−4:t} + β_m·RV_{t−21:t}`, persistence ≈ `β_d + β_w + β_m`.

## §R2 Exact calculation

$$\sigma^2_t = \omega + \alpha r^2_{t-1} + \beta\sigma^2_{t-1}, \qquad \pi = \alpha+\beta < 1$$

$$t_{1/2} = \frac{\ln(1/2)}{\ln(\pi)} \quad\text{days [documented]}$$

Fit on `252` days [default] of daily log-returns, rolling, refit **weekly**
[default]. Documented stylized fact: daily GARCH(1,1) fits routinely yield
`α+β` close to `1` [documented] (Bollerslev, Chou & Kroner 1992; Lai & Xing
2013); `0.94–0.99` is a typical equity range [example] (model fact, not a
trading P&L result).

Half-life map (illustrative): `π=0.90 → 6.6`d [example]; `0.95 → 13.5`d
[example]; `0.98 → 34`d [example]; `0.99 → 69`d [example].

### R2.1 Normative detection pseudocode

Pseudocode is normative; prose is commentary.

```
REFIT (every Friday after close; cadence = cfg.refit_cadence = weekly [default]):
  bars ← last min(cfg.garch_window_days, available) closes with event_ts ≤ t,
         SPLIT-ADJUSTED (see corporate-action rule below)
  # --- data hygiene (normative) ---
  for each bar: require c finite and c > 0, else → INVALID → UNKNOWN (F1)
  gaps vs exchange calendar:
      1–3 [default] consecutive missing sessions → mask rows (NO interpolation, F1)
      > 3 [default] consecutive missing      → DEGRADED, label withheld
  corporate actions:
      feed flags an action on date d        → use the adjusted series through d
      unadjusted feed AND |overnight return| > 8% [example] on a known ex-date
                                            → mask bar d, DEGRADED (a split must
                                              never print as a volatility shock)
  halt/auction bars (zero volume + unchanged price, or venue halt flag)
                                            → discard contributions across reopen;
                                              freeze per §R0.6
  # --- warmup ---
  if n_closes < cfg.min_obs (252 [default] production):
      emit DEGRADED, state 'warming', label withheld
  # --- estimate ---
  rets ← log differences of adjusted closes, demeaned
  π ← QMLE GARCH(1,1), constraints 0 ≤ α, β and α+β ≤ 0.999 [default]
      (reference implementation: 25-point grid QMLE — operational proxy only;
       production MUST use a real optimizer; [measured] degeneracy note in §R6)
  if solver fails OR π pinned at bound (|π − 0.999| < 1e-6 [default]):
      → state 'unstable', module UNKNOWN (F2)
  # --- verify (F3) ---
  π_har ← HAR-RV OLS on the same returns (needs ≥ 63 obs [example] for stable OLS)
  if classify(π_har) != classify(π): → UNKNOWN (F3)
      # tolerance is on the STATE, not the parameter (§R4)
  # --- classify with hysteresis (normative state machine) ---
  state ← CLASSIFY(prev_valid_state, π, cfg)
  hl ← ln(0.5)/ln(π) if 0 < π < 1 else NaN
  emit RegimeState{regime_id='R004', state, value=π, half_life_d=hl,
                   estimator_version, data_vintage, computed_at=t, module_state}
  prev_valid_state ← state if state ∈ {low, normal, extreme}
                     else prev_valid_state   # 'unstable' holds the last valid label

CLASSIFY(prev, π, cfg):                       # hysteresis (normative)
  if π not finite → 'unstable'                 # F2
  if prev == 'extreme': return 'extreme' if π >  cfg.pi_extreme_exit else 'normal'
  if prev == 'low':     return 'low'     if π <  cfg.pi_low_exit     else 'normal'
  # prev ∈ {normal} ('warming' treated as normal-base once an estimate exists):
  if π ≥ cfg.pi_extreme_enter → 'extreme'
  if π ≤ cfg.pi_low_enter     → 'low'
  return 'normal'
```

| normal | `≥ 0.95` [example] | extreme | enter |
| extreme | `> 0.92` [example] | extreme | hold (hysteresis) |
| extreme | `≤ 0.92` [example] | normal | exit |
| normal | `≤ 0.85` [example] | low | enter |
| low | `< 0.88` [example] | low | hold |
| low | `≥ 0.88` [example] | normal | exit |
| any | non-finite | unstable | F2 |

### R2.2 Threshold & hysteresis calibration (normative procedure)

1. **Data:** per-ticker split-adjusted EOD closes, `≥ 2`y [default] (`≥ 5`y
   preferred [example]); calibration panel `≥ 30` names [example] spanning
   volatility deciles for panel priors. Each ticker calibrated separately —
   no cross-ticker leakage into the OOS fold.
2. **Estimator:** production QMLE GARCH(1,1) (arch/scipy-class optimizer),
   constraints `0 ≤ α, β`, `α+β ≤ 0.999` [default]; rolling window grid
   `{126, 252, 504}` [default]; weekly refit [default].
3. **Threshold grid:** `pi_low_enter ∈ {0.80, 0.85, 0.88}` [example];
   `pi_extreme_enter ∈ {0.93, 0.95, 0.97}` [example];
   exits = enter − `0.03` [default]; `hl_baseline_d ∈ {10, 14, 21}` [example].
4. **Objective (OOS, walk-forward, embargo `≥ 5` trading days [default]):**
   maximize the FULL-COST net Sharpe of the gated consumer (T-vol-target
   family) minus ungated, subject to `≥ 200` OOS gated trades [default] and
   median state dwell `≥ 2` weeks [example]; report DSR, do not threshold on
   it [default].
5. **Selection:** pick the config maximizing the OOS objective; ties → wider
   hysteresis [default].
6. **Re-calibration:** annually [default], or after F3 disagreement on `≥ 4`
   consecutive refits [default] (structural-break signal); thresholds without
   a calibration run-id + decision-log entry are `[unverified]` and blocked
   by Gate (F5).
7. **Anti-overfit:** thresholds are regime-class-level; any per-ticker
   override requires `≥ 5`y history [default] and a second OOS fold.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** fits GARCH(1,1) weekly (production: real QMLE optimizer); publishes RSV with half-life.
- **Verifier:** fits HAR-RV (Corsi 2009) on the same returns and requires the same qualitative state (low/normal/extreme) — tolerance is on the *state*, not the parameter; the reference test uses an independent coarse-grid GARCH fit as the deterministic second estimator; else `UNKNOWN`. HAR-RV verifier needs `≥ 63` daily obs [example] for a stable 4-regressor OLS — below that the verifier abstains and the module is `DEGRADED`.
- **Grok-Researcher:** proposes windows and grids; leads only.
- **Adversary:** checks the fitting window excludes the evaluation period; injects a structural break to test fit stability; runs the boundary-value suite (`test_hysteresis_boundary_values`).
- **Gate:** rejects α+β pinned at `0.999` [default] as a regime (numerical artifact); requires `≥ 252` [default] observations; requires a real QMLE optimizer in production — the chapter's 25-point reference grid is a smoke proxy only ([measured] degeneracy, §R6); rejects `[unverified]` hand-tuned thresholds (F5: calibration run-id required).
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the

  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Persistence does not change the fee schedule — it changes how much of the
spread/impact stack you should expect to pay and how wide stops / how small
size should be. The mapping below is normative; every multiplier is tagged.
`base` is the output of `expected_cost_bps(notional, adv_pct, venue, side,
urgency)` with the 4-component stack `{spread_bps, fees_bps, borrow_bps,
impact_bps}`. The function returns a NEW dict (never mutates `base`) with the
scaled components plus sizing fields and a provenance `tag`.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    state, ms = rsv.get('state'), rsv.get('module_state')
    hl = rsv.get('half_life_d')
    if not (isinstance(hl, (int, float)) and hl == hl and hl > 0):
        hl = 14.0  # [default] baseline half-life when unmeasurable
    tag = 'R004:' + str(state)
    if ms in ('UNKNOWN', 'OFF'):
        # Restrictive default: unknown persistence is never treated as benign.
        adj['size_mult'] = 0.5                        # [default]
        adj['impact_bps'] *= 1.5                      # [example] adverse-selection buffer
        adj['trade_ok'] = False                       # [default]
        adj['tag'] = tag + ':unknown-restrictive'
        return adj
    if state == 'extreme':
        # Clustered variance: fills walk further, spreads widen.
        adj['impact_bps'] *= 1.5                      # [example]
        adj['spread_bps'] *= 1.25                     # [example]
        adj['stop_mult'] = max(1.0, (hl / 14.0) ** 0.5)  # [default] √(HL/HL_baseline)
        adj['size_mult'] = 0.5                        # [example]
    elif state == 'low':
        # Shocks die fast: impact mean-reverts intraday.
        adj['impact_bps'] *= 0.9                       # [example]
        adj['spread_bps'] *= 0.95                      # [example]
        adj['stop_mult'] = 1.0                        # [default]
        adj['size_mult'] = 1.0                        # [default]
    else:  # normal / warming / unstable / missing / invalid
        adj['stop_mult'] = 1.0                        # [default]
        adj['size_mult'] = 1.0 if state == 'normal' else 0.5  # [default]
    adj['trade_ok'] = (state != 'unstable')           # [default]
    adj['tag'] = tag
    return adj
```

Worked row (inputs → bps → $): `base = {spread: 2.0, fees: 0.5, borrow: 0.0,
impact: 3.0}` bps [example]; state `extreme`, `hl = 34.3`d [example] →
`impact = 4.5` bps, `spread = 2.5` bps, `stop_mult = √(34.3/14) ≈ 1.57`
[example], `size_mult = 0.5` [example], tag `R004:extreme`. On a `$1,000,000`
[example] notional the impact line moves from `$300` to `$450` [example]
before the size haircut. All multipliers are `[example]` starting values for
the §R2.2 calibration; the *structure* (which components scale, restrictive
unknown) is normative.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Estimator degeneracy (π pinned at grid bound / solver non-convergence) → detect: `\|π − 0.999\| < 1e-6` [default] or zero Δπ across refits → action: `UNKNOWN` (F2), widen grid / switch optimizer → recovery: Gate re-approval + fixture replay green | `check: pi < 0.999` |
| 2 | In-sample σ_t used for sizing (fit window includes the decision bar) → detect: causality assertion `fit_end ≥ decision_t` in CI / Adversary → action: module `OFF` + page → recovery: fix pipeline, re-run no-lookahead test, Gate sign-off | `check: fit_end < decision_t` |
| 3 | Structural break (regime change mid-window) → detect: GARCH vs HAR-RV states disagree on `≥ 4` consecutive refits [default] → action: `UNKNOWN` (F3), restrictive downstream → recovery: re-run §R2.2 calibration on the post-break subsample, new run-id, Gate re-approval | `check: state_garch == state_har` |
| 4 | Stale feed (`computed_at` older than `3`× cadence [default]) → detect: F4 watchdog → action: `UNKNOWN` → recovery: feed confirmed fresh + fixture replay green → re-arm | `check: now - computed_at <= 3 * cadence` [default] |
| 5 | Zero-variance / split-artifact tape → detect: `v0 = 0` → π non-finite → F2 bounds → action: `UNKNOWN` → recovery: switch to split-adjusted series, mask the bar, replay | `check: variance(returns) > 0` |
| 6 | Corporate action on unadjusted feed (spurious `\|overnight\| > 8%` [example] on ex-date) → detect: corporate-action calendar / split flag → action: `DEGRADED`, mask bar d (no interpolation) → recovery: backfill adjusted series, replay | `check: use_split_adjusted asserted` [fixed] |
| 7 | **Honest limitation — EOD-only stack:** intraday volatility clustering is unmeasurable here → detect: downstream requests sub-daily cadence → action: `DEGRADED`, label withheld (do not extrapolate) → recovery: none on this stack — needs intraday feed (escalation gate, §1.5) | `check: cadence >= daily` [default] |
| 8 | **Honest limitation — slow detector:** a volatility break faster than `~5` trading days [example] is detected late by construction (the 252d [default] window dilutes it) → detect: HAR/GARCH disagreement spike → action: `UNKNOWN` until the window covers the break; never shorten the window ad hoc → recovery: re-run calibration on post-break subsample | `check: no ad-hoc window shortening` |

`UNKNOWN` is restrictive everywhere: downstream halves size / widens stops /
stands down — never treated as benign (F1, §R0.5).
