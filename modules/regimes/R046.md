### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- The correlation window is the trailing `W_eff = min(T, W)` bars [default]
  (`T` = bars seen so far); on short history the window expands causally —
  never padded, never forward-filled.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Liquidity commonality: the mean pairwise Pearson correlation of daily changes in Amihud illiquidity (|r| / dollar volume) across a fixed universe. High commonality = liquidity is a common factor = crowded exits all fail together. Zero-volume bars are excluded (Amihud undefined) — never interpolated.

### R2.5 Detection calibration recipe (no hand-tuned magic numbers)

1. **Calibration data:** per-name SIP daily bars (or Databento DBEQ.BASIC
   `ohlcv-1d`), split-adjusted, point-in-time; ≥ `504` bars (`2` yr [default])
   of history; universe fixed ex ante with a fingerprint; corporate-action
   factors from the vendor; the evaluation/OOS window is excluded up front
   (F5).
2. **Grid:** `W ∈ {42, 63, 126}` [default set] ×
   `common_entry ∈ {0.30, 0.40, 0.50}` [default set] ×
   hysteresis width `∈ {0.05, 0.10, 0.15}` [default set]
   (`common_exit = common_entry − width`; `frag_exit = frag_entry + width`) ×
   `frag_entry ∈ {0.10, 0.15, 0.20}` [default set].
   `min_obs`, `min_pairs`, `min_pair_obs`, `adj_jump_tol` are fixed machinery
   [default], never tuned.
3. **OOS selection criterion:** walk-forward with `3` folds [default]. For
   each grid point compute downstream gate quality: the mean after-cost
   bps/trade of trades **blocked** by `COMMON`/`UNKNOWN` minus the mean of
   trades **passed** (blocked must underperform by ≥ the expected cost —
   otherwise the gate adds no value). Feature-only fallback when no
   downstream exists: label stability (adjacent-grid agreement ≥ `0.80`
   [default]) **and** `COMMON` hit rate in `[0.05, 0.25]` [default] of bars
   (rejects degenerate always/never-`COMMON` configs). Select the grid point
   maximizing the OOS objective; ties break toward the smoother config
   (wider hysteresis, longer `W`) [rule].
4. **Re-calibration cadence:** quarterly (`recal_cadence_months = 3`
   [default]); event-driven on universe changes, tick-size changes, or
   persistent F3 disagreement; never re-fit on the live evaluation window
   (F5).
5. **Degeneracy guards:** `COMMON` hit rate `< 0.02` [default] on the
   calibration window → lower the entry threshold; `> 0.40` [default] → the
   universe is structurally common — split it (e.g. by sector/market-cap) or
   pool per segment; F3 trip rate `> 0.10` [default] → the universe is not
   homogeneous — split it before trusting the label. Document the choice,
   never force the bands.

### R2.6 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. `events[1..T]` newest last,
each with `event_ts` (int64 ns UTC), per-name Amihud changes `a[1..N]`,
optional per-name `|return|` `j[1..N]`, optional `adj_ok`, and `market_state`.

```
function DETECT(events[1..T], prev_label, cfg) -> RegimeState:
  # F1 — input validity: invalid input -> UNKNOWN, never interpolate
  if T == 0: return UNKNOWN("no-events")
  hist = []                      # non-halted rows only
  for e in events[1..T]:         # causal: prefix order
    if e.market_state == HALTED:
      emit(prev_label, prev_value, module_state=UNKNOWN, reason="halted-freeze")
      continue                   # halted row never enters history
      # (if no prior label exists yet, emit state=UNKNOWN)
    if e.market_state == AUCTION:
      emit(prev_label, prev_value, module_state=DEGRADED, reason="auction-hold")
      continue
    hist.append(e)
    if len(hist) < cfg.min_obs:   # corr degenerate below 3 obs [default]
      emit(UNKNOWN, NaN, module_state=DEGRADED, reason="warming")
      continue
    W_eff = min(len(hist), cfg.W)
    window = hist[-W_eff..]       # trailing, causal

    # Name-day exclusion: missing / non-finite / zero-volume-upstream /
    # unadjusted-jump days are excluded from their pairs, never interpolated
    valid(i, d) = finite(a_i[d]) and not (j_i[d] > cfg.adj_jump_tol and not adj_ok)
    # Corporate-action guard: a |return| jump above adj_jump_tol (5.0 [default],
    # i.e. a 500% one-day move) with no adjustment factor is bad data, not signal

    pairs = []
    for i < k in 1..N:
      obs = { d in window : valid(i,d) and valid(k,d) }   # pairwise-complete
      if |obs| >= cfg.min_pair_obs:
        pairs.append(pearson({a_i[d] : d in obs}, {a_k[d] : d in obs}))
    # F2 — insufficient valid pairs -> UNKNOWN
    if len(pairs) < cfg.min_pairs: return UNKNOWN("f2-no-pairs")

    rho = mean(pairs)            # in [-1, 1] by construction
    if not finite(rho): return UNKNOWN("non-finite-rho")

    # F3 — interleaved-half-universe cut must agree on entry band
    rho_cut = mean_pairwise_corr(window, names[2,4,6..])
    if entry_band(rho_cut) != entry_band(rho):
      emit(UNKNOWN, rho, module_state=UNKNOWN, reason="f3-cut-disagree")
      prev_label, prev_value = UNKNOWN, rho
      continue

    label = HYSTERESIS(prev_label, rho, cfg)   # §R2.7
    emit(label, rho, module_state=OK)
    prev_label, prev_value = label, rho

function entry_band(v):
  if v >= cfg.common_entry: return COMMON
  if v <= cfg.frag_entry:   return FRAGMENTED
  return MIXED

function HYSTERESIS(prev, v):   # §R2.7
  if v >= cfg.common_entry: return COMMON        # spike promotes from any state
  if prev == COMMON:
    return COMMON if v >= cfg.common_exit else (FRAGMENTED if v <= cfg.frag_entry else MIXED)
  if prev == FRAGMENTED:
    return FRAGMENTED if v <= cfg.frag_exit else MIXED
  return FRAGMENTED if v <= cfg.frag_entry else MIXED   # prev in (None, MIXED, UNKNOWN)
```

Gap policy: an `event_ts` gap `> 3`× cadence → the label expires to `UNKNOWN`
via F4 (`apply_freshness`); a gap in (`1`×, `3`×] is masked (no interpolation)
and logged. Corporate actions: see the `valid(i,d)` guard above — the jump day
for that name is excluded; the name's other days are unaffected.

### R2.7 Hysteresis state machine (entry strict, exit sticky)

Bare bands flicker when `ρ̄` oscillates around a threshold; the state machine
below replaces them. Starting values are `[default]`; production values come
from the §R2.5 recipe (status `calibrate`).

| From \ To | `ρ̄ ≥ 0.40` [default] | `0.30 ≤ ρ̄ < 0.40` [default] | `0.15 < ρ̄ < 0.30` [default] | `ρ̄ ≤ 0.15` [default] |
|---|---|---|---|---|
| FRAGMENTED | COMMON | MIXED | MIXED | FRAGMENTED |
| MIXED | COMMON | MIXED | MIXED | FRAGMENTED |
| COMMON | COMMON | **COMMON (hold)** | MIXED | FRAGMENTED |
| UNKNOWN | COMMON | MIXED | MIXED | FRAGMENTED |

Entry to `COMMON` is strict (`≥ common_entry`) from **any** state; exit from
`COMMON` is sticky (holds while `≥ common_exit`). Entry to `FRAGMENTED` is
strict (`≤ frag_entry`); exit from `FRAGMENTED` is sticky (holds while
`≤ frag_exit`). One transition per bar [rule].

## §R3 Exact calculation

Amihud illiquidity `ILLIQ_{i,d} = |r_{i,d}| / DVOL_{i,d}` [documented: Amihud
2002], daily change `ΔILLIQ`. Mean pairwise Pearson correlation over the
trailing `W_eff` bars [default], pairwise-complete over valid name-days:

$$\bar{\rho}^{liq}_t = \frac{1}{|P_t|} \sum_{(i,k) \in P_t} \rho(\Delta ILLIQ_i, \Delta ILLIQ_k)$$

where `P_t` = pairs with `≥ min_pair_obs` (`3` [default]) joint valid
observations. `F2` requires `|P_t| ≥ min_pairs` (`3` [default]).

*Formula tag: [documented] for the Amihud construction (Amihud 2002); the
correlation aggregation and window are [default] machinery.*

**Data inputs.** Daily Amihud illiquidity per name (from §R0.3 bars);
fixed universe (fingerprinted ex ante); window `W`.

**Cadence.** Daily.

**Worked check (fixture `R046_tape.csv`, synthetic [example] panel).** Row `8`
(`2026-09-10`): `ρ̄ = 0.4374648` [example] `≥ common_entry` (`0.40` [default])
→ `COMMON` entry, direct promote from `FRAGMENTED`. Rows `29–32`: `ρ̄` in
`[0.30, 0.40)` [example] yet the label stays `COMMON` — the hysteresis hold.
Row `33`: `ρ̄ = 0.2883` [example] `< common_exit` (`0.30` [default]) →
`MIXED` exit. Row `10` has `a3` missing: the name-day is excluded pairwise and
the label stays `COMMON`/`OK`. Row `41` (`HALTED`): label carried
(`MIXED`), `module_state = UNKNOWN`. The row-`8` value is independently
recomputed with `statistics.correlation` in `test_spot_handcheck` (pinned to
`1e-6` [default] tolerance).

## §R5 Cost interface: regime state → cost-function adjustment

Regime state → cost-function adjustment: commonality scales the **spread** and
**impact** legs of `expected_cost_bps` — crowded exits are where the common
liquidity factor bites. Borrow and fees do not scale with commonality
[default] (commonality is a transaction-cost state, not a financing state).
`UNKNOWN` is restrictive: priced like the costly state and new entries are
blocked. Adjustments apply to **exit legs** [default].

| State | `spread_mult` | `impact_mult` | `borrow_mult` | `fee_add_bps` | `trade_ok` |
|---|---|---|---|---|---|
| COMMON | `2.0` [default] | `3.0` [default] | `1.0` [default] | `0.0` [default] | `True` (scale down exits) |
| MIXED | `1.0` [default] | `1.0` [default] | `1.0` [default] | `0.0` [default] | `True` |
| FRAGMENTED | `1.0` [default] | `1.0` [default] | `1.0` [default] | `0.0` [default] | `True` |
| UNKNOWN | `2.0` [default] | `3.0` [default] | `1.0` [default] | `0.0` [default] | `False` (restrictive default) |

```python
COST_ADJUSTMENT_R046 = {
    "regime_id": "R046", "version": "1.1.0",
    "COMMON":     {"spread_mult": 2.0, "impact_mult": 3.0, "borrow_mult": 1.0,
                   "fee_add_bps": 0.0, "trade_ok": True,  "applies_to": ["exit"],
                   "tag": "[default]"},
    "MIXED":      {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0,
                   "fee_add_bps": 0.0, "trade_ok": True,  "applies_to": ["exit"],
                   "tag": "[default]"},
    "FRAGMENTED": {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0,
                   "fee_add_bps": 0.0, "trade_ok": True,  "applies_to": ["exit"],
                   "tag": "[default]"},
    # UNKNOWN is restrictive: priced like the costly state, entries blocked.
    "UNKNOWN":    {"spread_mult": 2.0, "impact_mult": 3.0, "borrow_mult": 1.0,
                   "fee_add_bps": 0.0, "trade_ok": False, "applies_to": ["exit"],
                   "tag": "[default]"},
}

def cost_adjustment(rsv, base):
    # base: dict(spread_bps, impact_bps, borrow_bps, fees_bps) from the strategy COST block
    # Only spread and impact scale with commonality, and only on exit legs.
    adj = COST_ADJUSTMENT_R046[rsv["state"]]   # record above
    eff = dict(base)
    eff["spread_bps"] = base["spread_bps"] * adj["spread_mult"]
    eff["impact_bps"] = base["impact_bps"] * adj["impact_mult"]
    # borrow_mult = 1.0 and fee_add_bps = 0.0 [default]: untouched
    return eff, adj["trade_ok"]
```

**Multiplier calibration recipe** (the values above are `[default]` starting
points, never live values):

1. Per name, from trade-and-quote (or SIP NBBO) data over ≥ `6` months [default],
   compute the realized effective spread per trade and the R046 state at the
   trade time.
2. `spread_mult(COMMON)` = median effective spread in `COMMON` / median in
   `MIXED`∪`FRAGMENTED`; `impact_mult(COMMON)` analogously from
   implementation-shortfall slippage on exit legs.
3. Re-fit quarterly [default]; if the fitted `COMMON` multiplier is `< 1.25`
   [default], the name's costs are not commonality-convex — set both to `1.0`
   [default] and document it.

**Executable gate** (for T-module `expected_cost_bps` predicates):

```
eff, trade_ok = cost_adjustment(rsv, base)   # exit legs only
eff_cost = expected_cost_bps(notional, adv_pct, venue, side, urgency,
                             spread_bps = eff["spread_bps"],
                             impact_bps = eff["impact_bps"])
enter_ok = trade_ok and eff_cost <= k * edge_bps   # k [default] per T chapter
```

`trade_ok = False` vetoes new entries for cost-sensitive strategies
(defined: strategies whose expected edge is `< 2×` [default] the expected
cost). The record is versioned with `estimator_version` and every application
is decision-logged (Appendix g v1.0.0).

`1` core, `<2` GB RAM [internal-est]; same correlation machinery as R031 on

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Zero-volume bar → detect: builder marks the name-day missing; `detect` excludes it from its pairs (`valid(i,d)`) → action: panel survives on the remaining pairs; if valid pairs `< min_pairs` (`3` [default]) → `UNKNOWN` (F2) → recovery: next bar recomputes; **never** `0/0`, never interpolate | `check: no division by zero; NaN never filled` |
| 2 | Missing bar / feed gap → detect: `event_ts` gap `> 3`× cadence → action: `UNKNOWN` (`stale-gap`, F4); gap in (`1`×, `3`×] → masked, logged, no interpolation → recovery: feed resumes; fixture replay before re-arm | `check: UNKNOWN after 3x cadence` [default] |
| 3 | Unadjusted corporate action → detect: `|return| > adj_jump_tol` (`5.0` [default]) with no `adj_ok` → action: that name-day excluded as bad data (equivalence-tested vs a missing cell); the name's other days unaffected → recovery: reconcile vendor factor file, replay | `check: jump-day exclusion == missing-cell value` |
| 4 | Trading halt → detect: `market_state == HALTED` → action: freeze — carry last label/value, emit `UNKNOWN`; the halted row never enters the correlation history → recovery: on reopen the next `CONTINUOUS_TRADING` bar resumes; contributions across reopen discarded | `check: post-halt value == no-halt-run value` |

| 8 | Vendor changes volume reporting → detect: expected.csv replay drift or volume sanity z-score trip → action: `OFF` + page (the "when it dies" trigger) → recovery: reconcile with vendor, re-ingest, re-run calibration recipe | `check: fixture replay green on deploy` |
