## §R2 Precise definition

VIX term-structure state: the spread between 3-month constant-maturity VIX futures and spot VIX. Backwardation (futures below spot) = the market pays for immediacy = fear now; steep contango = complacency = short-vol weather. The 3-month point is constant-maturity interpolated — never the raw front contract across a roll. The average term structure is upward sloping (contango is the normal state [documented]); backwardation is the rare, information-bearing state [documented].

### R2.5 Detection-calibration recipe (no magic numbers)

`bw_entry`/`bw_exit_width` ship as `[default]` starting points; production
values come from this recipe (status `calibrate`).

1. **Calibration data:** daily VIX index (FRED `VIXCLS`) + VX per-contract
   settlements with expiry dates; build the 3m constant-maturity series with
   the §R3 interpolation recipe; `≥ 4` years [default] of history so the
   window covers `≥ 2` stress episodes [default]; the evaluation/OOS window is
   excluded up front (F5).
2. **Grid:** `bw_entry ∈ {1.5, 2.0, 2.5, 3.0}` [default set] ×
   `bw_exit_width ∈ {0.5, 1.0, 1.5}` [default set] (exit line = entry − width).
   `dual_spread_tol` is fixed at `0.5` [default], never tuned.
3. **OOS selection criterion:** walk-forward with `3` folds [default]. For each
   grid point compute downstream gate quality: the mean after-cost bps/trade of
   trades **blocked** by `BACKWARDATION` minus the mean of trades **passed**
   (blocked must underperform passed by `≥` the expected cost — otherwise the
   gate adds no value). Feature-only fallback when no downstream exists: label
   stability (adjacent-grid agreement `≥ 0.80` [default]) **and**
   backwardation-hit rate in `[0.02, 0.10]` [default] of bars (rejects
   degenerate always/never-backwardation configs). Select the grid point
   maximizing the OOS objective; ties break toward the smoother config (wider
   hysteresis) [rule].
4. **Re-calibration cadence:** semi-annual (`recal_cadence_months = 6` [default]); event-driven on CBOE VIX methodology changes, CFE spec changes,
   or persistent F3 disagreement; never re-fit on the live evaluation window
   (F5).
5. **Degeneracy guards:** backwardation-hit rate `< 0.01` [default] on the
   calibration window → lower `bw_entry`; `> 0.10` [default] → the 3m point is
   structurally cheap — raise `bw_entry` or move to a shorter maturity point;
   document the choice, never force the bands.

### R2.6 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. `bars[1..T]` newest last,
each with `event_ts` (int64 ns UTC), `vix`, `vix3m`, `cm` (constant-maturity
flag), optional `market_state`. `bars2` is the second vendor's same-date series.

```
function DETECT(bars[1..T], bars2[1..T], prev_valid_label, cfg) -> RegimeState:
  # F1 — input validity: invalid input -> UNKNOWN, never interpolate
  if T == 0: return UNKNOWN("no-bars")
  b = bars[T]
  if b.market_state == HALTED: return UNKNOWN("halted")       # frozen, §R0.5
  auction = (b.market_state == AUCTION)                        # -> DEGRADED below
  require finite(b.vix) and finite(b.vix3m) else return UNKNOWN("missing-settlement")
  require b.vix > 0 else return UNKNOWN("nonpositive-vix")    # F2

  # Roll guard: the 3m point must be constant-maturity, never the front contract
  if b.cm != 1: return UNKNOWN("unhandled-roll")              # §R3 recipe violated

  S = b.vix3m - b.vix
  # F2 — mathematical bounds
  if not finite(S) or |S| >= cfg.spread_abs_max: return UNKNOWN("out-of-bounds")

  # F4 — gap policy: > stale_mult x cadence -> UNKNOWN; never backfill
  if T >= 2 and b.event_ts - bars[T-1].event_ts > cfg.stale_mult * CADENCE:
    return UNKNOWN("stale-gap")

  # F3 — second vendor agrees on the *entry band* within dual_spread_tol
  if not VERIFY_DUAL(bars[1..T], bars2[1..T], cfg):
    return UNKNOWN("vendor-band-disagreement")

  label = HYSTERESIS(prev_valid_label, S, cfg)                # §R2.7
  prev_valid_label = label      # UNKNOWN never writes hysteresis memory [rule]

  if auction: return DEGRADED("auction-hold", label, S)
  return OK(label, S, computed_at = b.event_ts)

function VERIFY_DUAL(a[1..T], b2[1..T], cfg) -> bool:         # F3
  for i in 1..T:
    if either row non-comparable (missing / bounds / cm != 1): continue
       # detect() already emits UNKNOWN for those rows via F1/F2/roll guard
    if |S(a[i]) - S(b2[i])| > cfg.dual_spread_tol
       and ENTRY_BAND(S(a[i])) != ENTRY_BAND(S(b2[i])):
      return false
  return true

function HYSTERESIS(prev, S, cfg) -> label:                  # §R2.7, normative
  b = cfg.bw_entry; x = b - cfg.bw_exit_width                 # exit lines ±x
  if S >= +b:  return CONTANGO        # entry inclusive
  if S <= -b:  return BACKWARDATION  # entry inclusive
  if prev == CONTANGO and S > +x:     return CONTANGO   # sticky hold
  if prev == BACKWARDATION and S < -x: return BACKWARDATION # sticky hold
  return FLAT                               # exits at S <= +x / S >= -x, inclusive
```

Corporate-action note: VIX is an index and VX futures have no splits, so
corporate actions are **not applicable** — the contract roll is the analog and
is handled by the roll guard above, not by a price-adjustment path.

### R2.7 State-transition table (hysteresis — normative)

Boundaries with defaults `bw_entry = 2.0`, `bw_exit_width = 1.0` [default]:
entry at `±2.0` (inclusive), exit at `±1.0` (inclusive). Direct flips between
CONTANGO and BACKWARDATION in one bar are allowed (single-spike flips are real
fear repricings — e.g. fixture rows 1→2). `UNKNOWN` rows hold the previous
valid label (never reset hysteresis memory).

| prev \ S | `≥ +2.0` | `+1.0 … +2.0` | `−1.0 … +1.0` | `−2.0 … −1.0` | `≤ −2.0` |
|---|---|---|---|---|---|
| CONTANGO | CONTANGO | CONTANGO (hold) | FLAT (exit) | FLAT | BACKWARDATION |
| FLAT | CONTANGO | FLAT | FLAT | FLAT | BACKWARDATION |
| BACKWARDATION | CONTANGO | FLAT | FLAT | BACKWARDATION (hold) | BACKWARDATION |

Boundary pins (unit-tested in `test_hysteresis_entry_exit_boundaries`):
`S = +2.0` → CONTANGO enters; `S = +1.0` → CONTANGO exits to FLAT;
`S = −2.0` → BACKWARDATION enters; `S = −1.0` → BACKWARDATION exits to FLAT.

## §R3 Exact calculation

Spot `V_t`, 3-month constant-maturity futures `F^{(3m)}_t`:

$$S_t = F^{(3m)}_t - V_t$$

**Constant-maturity interpolation recipe (normative for the `cm=1` flag).**
On date `t`, take the two VX contracts straddling `90` days to expiry [default]
(near `N` with `D_N < 90` days, next `X` with `D_X > 90` days):

$$F^{(3m)}_t = w\,F_N + (1-w)\,F_X, \qquad w = \frac{D_X - 90}{D_X - D_N}$$

*Interpolation formula tag: [default] — the `90`-day target maturity is a [default] starting point.*

Use daily **settlements** only (never intraday prints); contract switch is
driven by the CFE expiry calendar, not by a price-jump heuristic. If either leg
is missing on `t`, `vix3m` is missing → `UNKNOWN` (F1), never interpolated.
A series that is not built this way carries `cm=0` and is rejected by the roll
guard — this is the Gate's explicit Adversary case.

**Threshold bands (entry/exit with hysteresis).** Values are `[default]`
starting points; production values come from the §R2.5 recipe.

| Band | Entry (inclusive) | Exit (sticky, inclusive) | Tag |
|---|---|---|---|
| BACKWARDATION — fear now | `S ≤ −bw_entry` (`−2.0` [default]) | stays while `S < −1.0` [default]; exits at `S ≥ −1.0` | [default] |
| FLAT | — | — | [default] |
| CONTANGO — short-vol weather | `S ≥ +bw_entry` (`+2.0` [default]) | stays while `S > +1.0` [default]; exits at `S ≤ +1.0` | [default] |

Worked checks [example] (fixture rows 1–3, hand-verified): `(18, 22)` →
`S = +4.0` → CONTANGO; `(32, 28)` → `S = −4.0` → BACKWARDATION;
`(20, 20.5)` → `S = +0.5` → FLAT. Hysteresis pins (fixture rows 4–8, 15–17):
`S = −2.5` → enters BACKWARDATION; `S = −1.8`, `−1.5` → holds (exit line
`−1.0`); `S = −1.0` → exits to FLAT; `S = −2.0` → re-enters; `S = +3.0` →
holds CONTANGO (exit line `+1.0`); `S = +1.0` → exits to FLAT.

*Formula tag: [default] — constants inside this formula inherit it per the tag
law (Appendix i v1.0.0); worked-check numbers carry their own tags.*

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when |
|---|---|---|---|---|---|
| BACKWARDATION | `2.0` [default] | `2.0` [default] | `1.0` [default] | `0.0` [default] | fear reprices immediacy: wider spreads, larger impact |
| CONTANGO | `1.0` [default] | `1.0` [default] | `1.0` [default] | `0.0` [default] | identity — normal weather |
| FLAT | `1.0` [default] | `1.0` [default] | `1.0` [default] | `0.0` [default] | identity |

**Application rule.** Look up the record by the emitted state; multiply the
strategy's spread and impact components by the state's `spread_mult` /
`impact_mult`, scale the borrow component by `borrow_mult`, and add
`fee_add_bps`. `UNKNOWN`/`DEGRADED`/`OFF` → **identity** (never guess a fear
markup on bad data) [rule]. All multipliers are `[default]` starting points —
calibrate per venue against measured spread/impact widening in backwardation
before production use; they are honest placeholders, not measurements.

**Honesty note.** The record is versioned with `estimator_version` and every
application is decision-logged (Appendix g v1.0.0). No cost figure here is
`[measured]`; the only `[documented]` cost-relevant fact used is that the
term structure inverts in stress (the fear state), which is what the `2.0`
