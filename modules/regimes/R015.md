# R015 — Tick-constraint regime

Whether the instrument is tick-constrained: `TickBind = fraction of quotes with (ask − bid) == τ(t)`, where `τ(t)` is the price-dependent minimum pricing increment (`$0.01` at/above `$1.00`, `$0.0001` below, per Reg NMS Rule 612 [documented]). Binding ticks change queue dynamics entirely — time priority dominates price priority, and the grid (not the economics) sets the inside quote. Provenance **[D]**.

### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only

  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; TickBind at t uses quotes ≤ t; routes t+1+ flow).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /

## §R1 Precise definition

TickBind over the causal trailing window `W` (|W| ≤ `window`, ≥ `min_bars`):

TickBind_W = (1/|W|)·Σ 1{|Ask_t − Bid_t − τ(t)| ≤ eq_tol}, with τ(t) = `$0.01`
if mid(t) ≥ `$1.00` else `$0.0001`, per Reg NMS Rule 612 [documented].
External corroboration [documented]: the SEC defines "tick-constrained" as a
time-weighted average quoted spread of ≤ `1.1` cents, and notes such stocks
are the majority of current trading volume — a dev can cross-check the label
against this benchmark during calibration (§R2). The trade-clustering
cross-check [documented Harris 1991]: the fraction of trade prints on the
tick grid corroborates the constrained state; the verifier abstains when
τ < `$0.01` (on-grid-ness is uninformative on a `$0.0001` grid [default]).

## §R2 Exact calculation

$$\text{TickBind}_W = \frac{1}{|W|}\sum_{t \in W} \mathbf{1}\{|Ask_t - Bid_t - \tau(t)| \le \varepsilon\} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: spreads `1,1,2,1,1,1,3,1,1,2` cents → `7/10 = 0.70` ⇒ tick-constrained at bar `10` (bars `1–9` are `DEGRADED`/warming under `min_bars = 10` [default] — the label is withheld, not estimated).

**Normative detection pseudocode** (pseudocode is normative; prose is commentary; the test file implements it verbatim):

```
INPUT:  events (canonical, newest last, all event_ts <= t), cfg (§R0.2), prev_label
OUTPUT: one RegimeState per event: {state, value, computed_at, module_state}

obs = [] ; trades = [] ; last_tau = None
for e in events:                                     # causal order, no lookahead
    if e.corp_action:                                # split / reverse-split
        obs, trades, prev_label, last_tau = [], [], None, None
        EMIT(state=warming, value=NaN, module_state=DEGRADED)   # label withheld
        continue
    if e.mkt_state != CONTINUOUS_TRADING:            # HALTED / AUCTION / MISSING
        EMIT(state=prev_label or undefined, value=last_v or NaN,
             module_state=UNKNOWN)                   # mask: freeze, never interpolate (F1)
        continue
    if not valid(e):                                 # missing / non-finite / crossed book
        EMIT(state=invalid, value=NaN, module_state=UNKNOWN)    # F1
        continue
    tau = e.tick or rule612_tick(e.mid)              # price-dependent tick [documented]
    if last_tau is not None and tau != last_tau:     # $1.00 boundary cross
        obs, trades, prev_label = [], [], None
        EMIT(state=warming, value=NaN, module_state=DEGRADED)
        last_tau = tau
        continue
    last_tau = tau
    s = e.ask - e.bid
    if e.mid >= 1.00 and s < tau - cfg.eq_tol:
        EMIT(state=invalid, value=NaN, module_state=UNKNOWN)    # sub-penny quote >= $1: data error
        continue
    obs.append(1.0 if abs(s - tau) <= cfg.eq_tol else 0.0)      # never `==` on floats
    trades.append(e.trade_px)
    w_obs, w_tr = obs[-cfg.window:], trades[-cfg.window:]
    if len(w_obs) < cfg.min_bars:
        EMIT(state=warming, value=NaN, module_state=DEGRADED)    # warm-up, label withheld
        continue
    v = sum(w_obs) / len(w_obs)
    assert 0.0 <= v <= 1.0                                       # F2 mathematical bounds
    label = hysteresis_update(prev_label, v, cfg)
    ver = second_estimator(w_tr, tau, cfg)          # trade-clustering cross-check
    if opposite_extremes(label, ver.state):         # constrained vs unconstrained, or
        EMIT(state=label, value=v, module_state=UNKNOWN)        # unmappable verifier: F3
    else:
        EMIT(state=label, value=v, module_state=OK)
    prev_label, last_v = label, v

def hysteresis_update(prev, v, cfg):                # [default] state machine
    if prev == "constrained"   and v >= cfg.constrained_exit: return "constrained"
    if prev == "unconstrained" and v <= cfg.free_exit:        return "unconstrained"
    if v >= cfg.constrained_cut: return "constrained"         # entry, inclusive
    if v <= cfg.free_cut:        return "unconstrained"       # entry, inclusive
    return "intermittent"

def opposite_extremes(a, b):                       # F3 tolerance [default]
    if b == "undefined": return False              # verifier abstention never fires
    bands = ("constrained", "intermittent", "unconstrained")
    if a not in bands or b not in bands: return True           # fail closed
    return {a, b} == {"constrained", "unconstrained"}         # adjacent-band wobble OK
```

**Edge cases** (all covered by fixtures/tests):

| Edge case | Handling |
|---|---|
| Missing bar (HALTED / MISSING / AUCTION) | masked: excluded from the window, never interpolated; label frozen, `UNKNOWN` |
| Halt then reopen | only the halted bars are discarded; the trailing window is preserved (no interpolation); F4 TTL applies to long gaps |
| Corporate action (split / reverse-split) | `corp_action` flag → window reset, `DEGRADED`/warming until `min_bars` post-event bars; pre/post windows never blended |
| Price crosses `$1.00` | τ(t) changes (`$0.01` ↔ `$0.0001`) → same reset path as a corporate action |
| Crossed book (`ask < bid`) | data error → bar quarantined, `UNKNOWN` |

| Sub-`$1.00` price (τ = `$0.0001`) | clustering verifier abstains (`undefined`) — on-grid-ness is uninformative [default] |

| Fewer than `min_bars` observations | `DEGRADED`/warming, label withheld |
| Verifier opposite extreme | `UNKNOWN` (F3); adjacent-band wobble tolerated [default] |

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Queue-position / latency | **amplifies** | only exist in tick-constrained names (queues form because price cannot improve — Yao & Ye 2018 [documented]: large ticks let HFTs establish time priority); die in tick-free names |
| Spread-capture market making | **amplifies then inverts** | improves when constrained (1-tick spread is capturable); dies when a constrained name becomes unconstrained (e.g. after a split — the pilot's wider-tick analog raised taker costs [documented]; no documented `50`% figure, "halves" is [example] illustration only) |
| Penny-jumping / 'improve by one tick' | **inverts** | dies when one tick is the whole spread |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes TickBind on the causal trailing window (`21` bars [default], `min_bars = 10` [default]); publishes RSV per the §R0.5 lag contract.
- **Verifier:** trade-price clustering cross-check; abstains below `$1.00`; strong disagreement → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes windows/cuts; leads only.
- **Adversary:** injects a 4:1 split [example] and a `$1.00` cross; asserts window reset + `DEGRADED` (regression-tested, not just specified).
- **Gate:** rejects non-quote inputs (high–low as spread); rejects sub-penny quotes ≥ `$1.00`; rejects labels with `computed_at` older than the last corporate action (stale post-split labels).
- **F1–F5 instantiated:** F1 missing/stale/invalid → `UNKNOWN` (restrictive downstream), gaps masked never interpolated;
  F2 bounds check on every emission; F3 dual-estimator strong-disagreement (or unmappable verifier) → `UNKNOWN`, adjacent-band wobble tolerated;
  F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Tick-constrained names have capturable 1-tick spreads: the adjustment favors maker flow and trims the assumed impact for patient flow; unconstrained names get taker pricing and no maker edge. Borrow is never moved by the tick regime [default]. One tick in bps is price-dependent — the table below is arithmetic [example], not a quote:

| Price | 1 tick (`$0.01`) in bps | Nasdaq taker fee `$0.0030`/sh in bps [documented] |
|---|---|---|
| `$5` | `20` | `6` |
| `$10` | `10` | `3` |
| `$20` | `5` | `1.5` |
| `$50` | `2` | `0.6` |
| `$100` | `1` | `0.3` |

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, fee_bps, borrow_bps_per_day, impact_bps) -- the 4-component stack.
    # rsv: regime_state_vector. fee_basis_as_of = "2026-09-10" [documented: Nasdaq price list].
    adj = dict(base)
    adj["regime_id"] = "R015"
    bad = rsv["module_state"] != "OK" or \
          rsv["state"] not in ("constrained", "unconstrained", "intermittent")
    if bad:
        adj.update(spread_mult=2.0,     # [default] restrictive penalty
                   impact_mult=1.5,     # [example]
                   borrow_mult=1.0,     # [default] tick regime never moves borrow
                   fee_mult=1.0,        # [default] venue fees unchanged
                   maker_viable=False, # [default]
                   size_mult=0.5)      # [default] halve size
        return adj
    if rsv["state"] == "constrained":
        adj.update(spread_mult=1.0,    # [default] inside quote IS the 1-tick spread: fully measurable
                   impact_mult=0.8,    # [example] time-priority queues: patient flow waits, less impact
                   borrow_mult=1.0,    # [default]
                   fee_mult=1.0,       # [default]
                   maker_viable=True)  # [default] queue games exist only here
    elif rsv["state"] == "unconstrained":
        adj.update(spread_mult=1.5,    # [example] taker crosses a multi-tick spread
                   impact_mult=1.0,    # [default]
                   borrow_mult=1.0,    # [default]
                   fee_mult=1.0,       # [default]
                   maker_viable=False) # [default] spread absorbs the queue edge
    else:  # intermittent
        adj.update(spread_mult=1.25,   # [example]
                   impact_mult=0.9,    # [example]
                   borrow_mult=1.0,    # [default]
                   fee_mult=1.0,       # [default]
                   maker_viable=True)  # [default] partial queue value
    return adj
```

Notes: `spread_mult` scales the spread-cost component (the taker crossing cost); `fee_mult` is `1.0` in all states because venue fees don't depend on the tick regime — the taker/maker choice does, via `maker_viable`. `size_mult` is `1.0` (base) for `OK` states and `0.5` [default] only under `UNKNOWN`/`DEGRADED`.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Split/reverse-split not recomputed → detect: `corp_action` flag, or τ(t) discontinuity, or price jump ≈ integer ratio → action: reset window, `DEGRADED`/warming until `min_bars` post-event bars → recovery: new label under new τ; backfill reference data | `check: split aware` |
| 2 | Price crosses `$1.00` (τ `$0.01` ↔ `$0.0001`) → detect: τ(t) change on reference-data update → action: same reset path as (1); pre/post windows never blended → recovery: resume labeling under the new τ | `check: tick regime` |
| 3 | High–low as spread (no quote tape) → detect: bid/ask fields absent → action: Gate rejects at ingest; module emits `UNKNOWN`, never estimates → recovery: wire an NBBO source (§1.5) | `check: quote tape` |
| 4 | Verifier strongly disagrees (F3) → detect: opposite-extreme labels (constrained vs unconstrained) → action: `UNKNOWN` — restrictive, downstream halves size / widens stops → recovery: auto-clear after `2` [default] consecutive agreeing bars | `check: dual agreement` |
| 5 | Halt / missing bars → detect: `mkt_state` ≠ CONTINUOUS_TRADING → action: mask the bar (excluded from window, never interpolated); freeze last label; `UNKNOWN` while halted → recovery: resume on continuous bars; gaps > `3`× cadence are already `UNKNOWN` via F4 | `check: mask no interpolate` |
| 6 | Stale post-corporate-action labels reused → detect: label `computed_at` older than the last corporate action → action: quarantine the label; downstream must drop it → recovery: recompute under the new τ | `check: vintage fenced` |
| 7 | Sub-penny quoted spread at ≥ `$1.00`, or crossed book → detect: spread < τ − tol, or spread < `0` → action: bar quarantined → `UNKNOWN`; page the vendor → recovery: vendor ticket; resume on clean bars | `check: spread sanity` |
| 8 | Rule 612 variable-tick amendment (2024) takes effect → detect: τ(t) ≠ `$0.01` for ≥ `$1.00` names on the compliance date → action: set `OFF`, page — the flat-tick model assumption is broken → recovery: upgrade τ(t) to the evaluation-period schedule; re-run calibration | `check: rule612 current` |

Honest degradation: `UNKNOWN` always means "do not trust the last label for new risk" (restrictive downstream); `DEGRADED` means "no label is emitted at all" (warming, auction) — the module never silently reuses a stale label.
