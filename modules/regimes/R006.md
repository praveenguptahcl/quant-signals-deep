# R006 — Vol-of-vol regime

The volatility of volatility itself — `σ(σ)`, proxied by VVIX (index) or by the trailing std of daily changes in 30-day ATM IV (single names). When VoV is high, the vol estimate you size on is itself noise. Provenance **[D]**.
Detection is a hysteresis state machine on the VVIX close (calibrated bands in production); a historical-IV verifier leg must agree or the label is `UNKNOWN`.

- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills

- **Backtest lag:** any backtest conditioning on this regime must lag the

## §R1 Precise definition

Market-implied VoV: Cboe VVIX — VIX methodology applied to VIX options, i.e. expected 30-day vol of the 30-day forward VIX [documented]. Historical (realized) VoV: `VoV = stdev(ΔIV_30d, 20d) / mean(IV_30d)` (coefficient of variation of IV changes).

## §R2 Exact calculation

**Units:** VVIX in index points [documented]; `IV_30d` in decimal vol (e.g. `0.20` = 20%) [default convention]; VoV dimensionless [documented definition].

**Estimators.**
- Sentinel (index leg): VVIX close with hysteresis bands — the published label.
- Verifier (history leg): `VoV = stdev(ΔIV_30d, 20d) / mean(IV_30d)` — coefficient of variation of IV changes, three-band cut at `0.05` / `0.12` [default]; must agree with the sentinel (F3) or the label is `UNKNOWN`.

$$VoV = \frac{\mathrm{stdev}(\Delta IV_{30d},\ 20d)}{\mathrm{mean}(IV_{30d})} \quad\text{(verifier-leg construction, documented)}$$

**Threshold bands (fixed mode [default]).** Bands are inclusive/exclusive as written — exact edges resolve per the pseudocode, and are pinned by the fixture (`85`, `90`, `105`, `110` boundary bars).

| Prev label | Print | Next label | Tag |
|---|---|---|---|
| normal | `VVIX > 110` | stressed | [default] |
| normal | `VVIX ≤ 85` | calm | [default] |
| stressed | `VVIX < 105` (= `110 − 5` hysteresis exit) | normal | [default] |
| calm | `VVIX > 90` (= `85 + 5` hysteresis exit) | normal | [default] |
| calm | `VVIX > 110` | stressed (direct jump) | [default] |
| any | otherwise | hold prev | [default] |

Initial prior after warm-up: `normal` [default]. The `85` / `110` bands with a `5`-point [default] hysteresis band are starting defaults for prototyping — production values come from the calibration recipe below; never hand-tune per-symbol in live use. VVIX descriptive ranges from market commentary (illustrative, not Cboe official cuts): `< 90` low, `90–150` normal, `> 150` stress.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function detect(state, events, cfg):
    bars = [e for e in events if e.kind == DAILY_CLOSE]        # newest last
    if bars is empty:
        return RSV(state="UNKNOWN", module_state=UNKNOWN)     # F1
    # F1: mask, never interpolate. Drop bars with missing/non-finite vvix;
    # a masked bar holds the last label (state persists across the gap).
    usable = [b for b in bars if isfinite(b.vvix) and b.vvix > 0]
    if usable is empty:
        return RSV(state="UNKNOWN", module_state=UNKNOWN)     # F1
    # Bands
    if cfg.band_source == "quantile_calibrated":
        hist = trailing cfg.calib_window_days vvix closes ending BEFORE the current bar  # no lookahead
        T_calm   = quantile(hist, cfg.q_calm)     # [calibrate]
        T_stress = quantile(hist, cfg.q_stress)   # [calibrate]
    else:
        T_calm, T_stress = cfg.vvix_calm, cfg.vvix_stressed   # [default]
    hb = cfg.hysteresis_band_pts                                 # [default]
    prev = state.last_label if state.last_label else "normal"    # initial prior [default]
    for b in usable:                    # causal replay; only the last label is emitted
        v = b.vvix
        if not (0.0 < v <= 300.0):      # F2 mathematical bounds [default]
            return RSV(state="UNKNOWN", module_state=UNKNOWN, value=v)
        prev = transition(prev, v, T_calm, T_stress, hb)
    label_ts = usable[-1].event_ts
    # F3: verifier leg (below) must agree with the sentinel label, else UNKNOWN.
    # F4: if now - label_ts > cfg.staleness_mult * cadence -> UNKNOWN.
    return RSV(regime_id="R006", state=prev, value=usable[-1].vvix,
               estimator_version=cfg.estimator_version,
               data_vintage=usable[-1].asof_ts, computed_at=label_ts,
               module_state=OK)

function transition(prev, v, T_calm, T_stress, hb):
    if prev == "stressed":
        return "normal" if v < T_stress - hb else "stressed"
    if prev == "calm":
        if v > T_stress:    return "stressed"
        if v > T_calm + hb: return "normal"
        return "calm"
    # prev == "normal"
    if v > T_stress: return "stressed"
    if v <= T_calm:  return "calm"
    return "normal"

function verifier_state(events, cfg):
    iv = [e.iv30 for e in events if isfinite(e.iv30)]
    if len(iv) < cfg.warmup_bars:          # [default]
        return "warming"                  # F3 treats as disagreement -> DEGRADED/UNKNOWN
    chg = diff(iv)
    vov = stdev(chg[-cfg.hist_window_days:]) / mean(iv[-cfg.hist_window_days:])
    if vov < cfg.verifier_calm:     return "calm"      # [default]
    if vov <= cfg.verifier_stressed: return "normal"   # [default]
    return "stressed"
```

**Edge cases.**
- Missing bars (non-publish day — e.g. the Cboe dissemination gaps covered by the July-2021 spot-index notice [documented]): the bar is masked; the label holds across the gap; no interpolation (F1). `3` consecutive masked bars [default] → `UNKNOWN` with a page alert (§R7 row 5).
- Halts/auctions: VVIX is a daily index close; an intraday halt produces no VVIX bar to consume. Per the market-state table the module freezes on `HALTED` and emits `UNKNOWN`; on `AUCTION` it holds the last label with state `DEGRADED`.
- Corporate actions: N/A — VVIX is an option-implied index of 30-day forward VIX, not a share price; splits/dividends do not apply [documented definition].
- Duplicate timestamps: keep the last published close per date (Cboe revisions are idempotent).
- Backtest replay: recompute by replaying bars in date order; a label dated `t` may only gate trades at `t+1` or later (§R0.5).

**Calibration recipe (mandatory before production use).**
1. Data: trailing `252` daily [default] VVIX closes from the §1.5 cheapest feed plus the single-name 30d ATM IV series for the verifier leg; exclude masked bars; seed-pinned, versioned vintage recorded in `data_vintage`.
2. Grid: `q_calm ∈ {0.05, 0.075, 0.10, 0.15}` [default], `q_stress ∈ {0.90, 0.925, 0.95, 0.975}` [default], `hysteresis_band_pts ∈ {3, 5, 7, 10}` [default].
3. Walk-forward: `5` folds [default] of `252`-day train / `63`-day OOS [default]; bands for each OOS fold are fit on that fold's trailing train only — never on the fold itself.
4. Selection criterion: maximize `separation − λ·churn` on mean OOS, where `separation` = fraction of OOS days labeled stressed that fall in the top decile of trailing realized VoV, `churn` = label-flip rate per `20` days [default], `λ = 0.5` [default]. Tie-break toward wider hysteresis.
5. Re-calibration cadence: quarterly [default]; immediate on a Cboe methodology revision or when the `252`-day [default] median shifts `≥ 20%` [default] vs the prior vintage.
6. Fixed-band mode (`85` / `110` / `5` pts) [default] is the prototyping starting point; any production gate must use calibrated bands and record the calibration vintage.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Vol-targeting / risk-parity overlays | **inverts** | dies when VoV is high — the vol estimate you size on is itself noise; leverage whipsaws. Sizing error ∝ VoV |
| Vega-weighted strategies | **degrades** | edge exists but mark-to-market variance explodes; reduce |
| Directional signals | **neutral** | second-order effect; use as a sizing input, not a trigger |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** replays the §R2 hysteresis `transition` over VVIX closes (fixed or quantile-calibrated bands); publishes the RSV.
- **Verifier:** computes the historical-VoV leg from the single-name IV series; requires state agreement (calm/normal/stressed) or the emission is `UNKNOWN` (F3). Cross-vendor IV reconciliation is optional hardening, not required.
- **Grok-Researcher:** proposes bands; leads only.
- **Adversary:** injects a VIX-option microstructure spike with no SPX jump; checks the label does not leak into equity sizing.
- **Gate:** forces `UNKNOWN` (never a sized label) when any input is `UNKNOWN` under high VoV — do not size on noisy vol.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

The regime's cost interface feeds the consumer's cost stack
(`expected_cost_bps(notional, adv_pct, venue, side, urgency)`): it returns a
multiplier record the consumer applies component-by-component. Every
multiplier defaults to `1.0` [default]; overrides below are [example] until
measured per book. The record carries an audit tag so the cost source is
traceable.

```python
def cost_adjustment(rsv, base):
    """base: consumer's cost record {spread_bps, fee_bps, borrow_bps, impact_bps, ...}.
    Returns the adjustment record; the consumer multiplies its stack components."""
    adj = {
        'trade_ok': True,
        'size_mult': 1.0,      # [default] scales vega sizing
        'edge_mult': 1.0,      # [default] scales the consumer's fee-covering gate predicate
        'spread_mult': 1.0,    # [default] scales the spread cost component
        'impact_mult': 1.0,    # [default] scales the impact cost component
        'borrow_mult': 1.0,    # [default] scales the borrow cost component
        'stop_mult': 1.0,      # [default] scales stop distances
        'cost_tag': f"R006.{rsv['state']}.v1",  # [default] audit tag
    }
    if rsv['state'] == 'normal':
        adj['impact_mult'] = 1.25   # [example] impact models understate in choppy vol
    if rsv['state'] == 'stressed':
        adj['size_mult'] = 0.5      # [example] halve vega sizing
        adj['edge_mult'] = 1.5      # [example] demand 50% more edge
        adj['spread_mult'] = 2.0    # [example] VIX-option spreads gap in stress
        adj['impact_mult'] = 3.0    # [example] impact superlinear in VoV
        adj['borrow_mult'] = 1.5    # [example] vol ETPs go special
        adj['stop_mult'] = 1.5      # [example] widen stops with the vol of vol
    if rsv['module_state'] != 'OK':
        adj['trade_ok'] = False     # [default] restrictive default on UNKNOWN/DEGRADED
        adj['size_mult'] = 0.0      # [default] stand down, do not size on noise
    return adj
```

Component mapping (the contract): `spread_mult` → spread bps, `impact_mult` →
impact bps, `borrow_mult` → borrow bps/day, `edge_mult` → the consumer's
fee-covering gate, `size_mult`/`stop_mult` → position sizing. Which component
scales and by how much is the interface; the numeric values are [example]
until measured.
