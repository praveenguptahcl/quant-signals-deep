- The indicator is causal: the value/state published for time `t` is computed

## §R2 Precise definition

Composite sentiment z-score over trailing `26`-week [default] windows:
`z = w1·z_survey + w2·z_pcr + w3·z_fut` with [example] weights
(`0.4/0.3/0.3`); positive z = optimism, negative z = fear. Extreme negative =
PANIC (crowded fear — contrarian long weather); extreme positive = EUPHORIA.
Surveys are weekly and lagged — a slow-moving state, never a trigger.
Composite weights and the `±2.0`/`0.5` bands are [example] and MUST be
calibrated per instrument before production use (§R3 calibration recipe).

### §R2.1 Normative detection pseudocode

This pseudocode is normative; prose is commentary. `cfg` carries the §R0.2
parameters.

```
function detect(state, events, cfg) -> list[RegimeState]:
    # events: canonical Events, ascending event_ts (int64 ns, UTC)
    # state.prior_label: last emitted label, init "UNKNOWN"
    # state.hist: valid weekly rows (dicts), strictly before current row
    out = []
    for e in events:
        ts = e.event_ts
        row = {bull: e.bull, bear: e.bear, pcr: e.pcr_w, fut_net: e.fut_net}
        stale = state.prev_ts is not None
                and (ts - state.prev_ts) > cfg.stale_days * 86400e9
        if any not finite(row.values()) or stale:
            # F1 / F4: emit UNKNOWN, FREEZE prior label, mask row from windows
            out.append(RegimeState(state="UNKNOWN", value=NaN,
                                  module_state="UNKNOWN", computed_at=ts))
            state.prev_ts = ts
            continue                      # row NOT appended to state.hist
        if len(state.hist) < cfg.warmup_weeks:
            # insufficient history: no label, keep accumulating
            out.append(RegimeState(state="UNKNOWN", value=NaN,
                                  module_state="UNKNOWN", computed_at=ts))
            state.hist.append(row); state.prev_ts = ts
            continue
        z = composite_z(row, state.hist[-cfg.warmup_weeks:], cfg)   # §R3
        if not finite(z) or abs(z) > cfg.z_bound:
            # F2: out-of-bounds indicator value
            out.append(RegimeState(state="UNKNOWN", value=z,
                                  module_state="UNKNOWN", computed_at=ts))
            state.prev_ts = ts
            continue                      # row NOT appended to state.hist
        prior = state.prior_label if state.prior_label != "UNKNOWN" else "ELEVATED"
        label = transition(prior, z, cfg)  # §R2.2 hysteresis
        out.append(RegimeState(state=label, value=z, module_state="OK",
                              computed_at=ts, min_lag_bars=cfg.min_lag_bars))
        state.prior_label = label
        state.hist.append(row); state.prev_ts = ts
    return out

function composite_z(row, win, cfg):
    spread  = row.bull - row.bear
    spreads = [r.bull - r.bear for r in win]
    z_survey = zscore(spread,  spreads)          # + = optimism
    z_pcr    = -zscore(row.pcr, [r.pcr for r in win])     # high p/c = fear
    z_fut    = zscore(row.fut_net, [r.fut_net for r in win])  # + = crowded long
    return cfg.weight_survey*z_survey + cfg.weight_pcr*z_pcr \
         + cfg.weight_fut*z_fut

function zscore(x, vals):
    s = sample_stdev(vals)
    return 0.0 if s == 0 else (x - sample_mean(vals)) / s
```

### §R2.2 Hysteresis state machine (normative)

Bare threshold re-entry causes label flicker at the bands; all exits use a
hysteresis offset. Exit bands with [default] offsets:

- `PANIC_EXIT = −(extreme − hyst_exit) = −1.5` [default]
- `EUPHORIA_EXIT = extreme − hyst_exit = 1.5` [default]
- `CALM_ENTER = calm_band − calm_hyst = 0.4` [default];
  `CALM_EXIT = calm_band + calm_hyst = 0.6` [default]

```
function transition(prior, z, cfg):
    if prior == "PANIC":
        return "ELEVATED" if z > PANIC_EXIT else "PANIC"
        # note: no direct PANIC -> EUPHORIA in one step; exit via ELEVATED
    if prior == "EUPHORIA":
        return "ELEVATED" if z < EUPHORIA_EXIT else "EUPHORIA"
    if prior == "CALM":
        if z <= -cfg.extreme: return "PANIC"
        if z >=  cfg.extreme: return "EUPHORIA"
        return "CALM" if abs(z) <= CALM_EXIT else "ELEVATED"
    # prior ELEVATED (or UNKNOWN re-entry): entry rules
    if z <= -cfg.extreme: return "PANIC"
    if z >=  cfg.extreme: return "EUPHORIA"
    if abs(z) <= CALM_ENTER: return "CALM"
    return "ELEVATED"
```

Boundary pins (exact-boundary semantics, pinned in `test_hysteresis_transitions_pinned`):
`−2.0` from ELEVATED → PANIC; `−1.5` in PANIC → stays PANIC; `−1.49` → ELEVATED;
`+2.0` → EUPHORIA; `1.5` in EUPHORIA → stays; `1.49` → ELEVATED; `0.4` from
ELEVATED → CALM; `0.5` → stays ELEVATED; `0.6` in CALM → stays CALM;
`0.61` → ELEVATED. (Boundary values inherit the tags of the parameters that
define them: entry bands [example], exit offsets [default].)

### §R2.3 Edge cases (normative)

- **Missing bars / missed survey week.** The AAII week is missing (no Thursday
  print) or any input is non-finite → that week's row is `UNKNOWN`
  (module_state `UNKNOWN`), the prior label is **frozen** (not reset), and the
  row is masked from all trailing windows (F1). The detector resumes on the
  next valid week via entry rules.
- **Stale inputs.** `event_ts − prev_ts > stale_days` (`14` days [default])
  → `UNKNOWN` (F4); a published label older than `stale_days` expires to
  `UNKNOWN` via `apply_freshness` (checked by consumers before gating).
- **Market halt / holiday-shortened week.** No valid vendor print exists for
  the week → same path as missing bars (freeze + mask). Per the §R0.5
  market-state table: HALTED → freeze, emit `UNKNOWN`; AUCTION → hold last
  state, `DEGRADED`; CLOSED → emit nothing, state `OFF`.
- **Corporate actions.** N/A by construction: the detector consumes
  market-wide survey/index/COT statistics and **no per-ticker price fields**
  (asserted in `test_no_price_inputs_corporate_actions_na`); splits/dividends
  cannot change the composite.
- **Put/call definition change (e.g. CBOE product mix).** Breaks the trailing
  window's comparability → treated as an estimator change: bump
  `estimator_version`, re-run the §R3 calibration, do NOT splice the old
  window silently. Same for AAII questionnaire changes.
- **COT release-schedule shift (holidays).** The Friday `15:30` ET print moves;
  the Friday print always maps to the *following* weekly bar by `event_ts`
  ordering — never backfilled into the current bar (F5).
- **Zero-variance window.** `zscore` returns `0.0` for a constant trailing
  window (avoids division by zero); documented, not an error.
- **Dual-estimator disagreement (F3).** Verifier recomputes the label with an
  alternate weight set (`0.34/0.33/0.33` [default]); disagreement on an
  extreme classification → `UNKNOWN` + page. Pinned in
  `test_f3_dual_estimator_agreement_on_extremes`.

## §R3 Exact calculation

Component z-scores vs trailing `26`-week [default] windows (construction in
§R0.3; windows use valid rows strictly before `t`):

$$z_t = 0.4\,z^{survey}_t \;-\; 0.3\,z^{pcr}_t \;+\; 0.3\,z^{pos}_t$$

Polarity: `z_survey` is signed so `bull − bear` above its mean is positive;
`z_pcr` is negated because a high put/call ratio is fear; `z_pos` is signed so
crowded-long futures positioning is positive. Weights [example] — see the
calibration recipe below; they MUST sum to `1.0` [rule].

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Threshold bands with hysteresis exits** (entry bands [example], exit offsets
[default]; state machine in §R2.2):

| `z` entry | State | Exit rule | Tag |
|---|---|---|---|
| `≤ −2.0` | PANIC | stays PANIC until `z > −1.5` | [example] / [default] |
| `≥ +2.0` | EUPHORIA | stays EUPHORIA until `z < +1.5` | [example] / [default] |
| `\|z\| ≤ 0.4` (from ELEVATED) | CALM | stays CALM until `\|z\| > 0.6` | [example] / [default] |
| else | ELEVATED | — | [example] |

**Cadence.** Weekly, on the survey calendar (Gate in §R5 accepts only
on-calendar prints).

### §R3.1 Calibration recipe (no magic numbers)

The [example] weights and entry bands MUST be calibrated before production
use; ship no uncalibrated thresholds.

1. **Calibration data.** AAII weekly prints since 1987 [documented], CBOE
   daily put/call since 1995-09-27 [documented], CFTC COT since 1986
   [documented] — `≥ 10` years [default] of history before the first fit; the
   warmup `26`-week window is separate from and shorter than this span.
2. **Objective.** The regime is a conditioner, not a signal: maximize the
   **gated-vs-ungated conditioning gain** on a reference strategy pair — e.g.
   a contrarian/reversal sleeve amplified in PANIC and a trend sleeve vetoed
   in extremes. Metric: out-of-sample Sharpe difference (gated − ungated)
   [default]; secondary: tail-state hit rate (fraction of PANIC weeks followed
   by positive `4`-week [default] contrarian forward return).
3. **Grid.** Weights on the simplex at step `0.1` [default] (`66` combinations [default]); `extreme ∈ {1.5, 1.75, 2.0, 2.25, 2.5}` [default];
   `hyst_exit ∈ {0.25, 0.5, 0.75}` [default]; `calm_band ∈ {0.3, 0.5, 0.7}`
   [default]. `warmup_weeks` fixed at `26` [default] (not gridded — window
   length is a data-economy choice, not a fit parameter).
4. **OOS selection.** Walk-forward with anchored expanding window, embargo =
   `4` weeks [default] between fit and test; minimum `50` [default] tail-state
   (PANIC/EUPHORIA) weeks per test fold; select by max OOS Sharpe-difference
   with DSR multiplicity control over the grid, or "not computed — variant
   count reported" [rule]. No ex-post period selection (F5) — the label series
   used in the backtest is the causal series from §R2.1.
5. **Re-calibration cadence.** Annually [default], or after `> 2` [default]
   extreme episodes fall outside the trailing bands; never re-calibrate on
   `< 1` year [default] of new data. Any weight/band change bumps
   `estimator_version` and is decision-logged (Appendix g v1.0.0).
6. **Per-instrument note.** This module is market-level (US equities). Gating a
   single ticker's strategy with it is a conditioning choice of the S/T
   module, not a re-calibration of R047.

### §R3.2 Worked example [example] (fixture row 2025-12-04, hand-verified)

Inputs: `bull = 12.0`, `bear = 68.0` (spread `−56.0`), `pcr_w = 1.45`,
`fut_net = −28.0`. Trailing `26`-week windows (fixture warmup):

- spread: mean `8.126327`, sd `5.283387` → `z_survey = (−56.0 − 8.126327) / 5.283387 = −12.137353`
- pcr: mean `0.852202`, sd `0.057989` → `z_pcr = −(1.45 − 0.852202) / 0.057989 = −10.308743`
- fut_net: mean `4.659547`, sd `5.786660` → `z_fut = (−28.0 − 4.659547) / 5.786660 = −5.643937`

$$z = 0.4·(−12.137353) − 0.3·(10.308743) + 0.3·(−5.643937) = −9.640745$$

(`0.4·−12.137353 = −4.854941`; `0.3·10.308743 = 3.092623`;
`0.3·−5.643937 = −1.693181`; sum `= −9.640745` — recomputed by hand from the
printed window statistics.) `z ≤ −2.0` from ELEVATED → **PANIC**. Pinned in

## §R4 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: contrarian / reversal | amplifies | extremes are the contrarian's entry — fade the crowd at the tails |
| T: trend-following | degrades | into the extreme the trend *is* the crowd; follow it only after the turn |

**Honest DEGRADED/UNKNOWN behavior.** This module has no `DEGRADED` emission
path of its own except the §R0.5 AUCTION hold (hold last state,
module_state `DEGRADED`, no new labels). Every other failure mode emits
`UNKNOWN` and freezes — a regime conditioner MUST NOT guess: downstream S/T
gates treat `UNKNOWN` restrictively (gate action from the regime record's
`unknown_behavior`; default = no tilt applied, documented in the consuming
module's regime-gate table). Recovery never backfills: missed weeks stay
masked, and the trailing windows simply have fewer valid rows until they
refill (minimum `26` [default] before labeling resumes).

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

```python
COST_ADJUSTMENT_R047 = {
    "regime_id": "R047", "version": "1.1.0",
    "note": "tilt-only regime; identity cost adjustment until venue-calibrated",
    "PANIC":    {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[internal-est]"},
    "EUPHORIA": {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[internal-est]"},
    "CALM":     {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[internal-est]"},
    "ELEVATED": {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[internal-est]"},
}
```

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when |
|---|---|---|---|---|---|
| PANIC | `1.0` | `1.0` | `1.0` | `0.0` | identity — see justification |
| EUPHORIA | `1.0` | `1.0` | `1.0` | `0.0` | identity — see justification |
| CALM | `1.0` | `1.0` | `1.0` | `0.0` | identity — see justification |
| ELEVATED | `1.0` | `1.0` | `1.0` | `0.0` | identity — see justification |

**Justification.** R047 is a market-level sentiment conditioner: it gates
*allocation tilts* in S/T modules (amplify contrarian sleeves in PANIC, veto
trend entries in extremes) rather than changing how any single order executes.
Spread/impact/borrow do widen in panic episodes, but no calibrated
regime-conditional multiplier exists for this module's venue set — shipping an
uncalibrated `spread_mult > 1.0` would be a magic number. The identity record
is therefore the conservative, auditable default [internal-est]: cost
modeling stays entirely in the gated strategy's own COST block, where the
fill model can be calibrated against that strategy's actual executions.

**Application rule.** `identity record: apply no adjustment; R047 gates allocation tilts, never cost inputs` [rule]. The record is versioned with
`estimator_version` and every application is decision-logged (Appendix g
v1.0.0).

**Escalation (do not enable without calibration).** To move beyond identity:
measure venue effective spreads and borrow utilization in weeks labeled PANIC
vs CALM over `≥ 5` years [default] of history, fit `spread_mult` /
`borrow_mult` per venue with confidence intervals, and promote the numbers
with `[measured]` tags plus `fee_schedule_as_of`. Until then, nonzero
adjustments are a validation failure. Calibrated magnitudes are a
§R10 unverified lead (GROK-NEEDED — see final report).
