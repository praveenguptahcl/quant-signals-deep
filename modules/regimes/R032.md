strict inequalities — `rho` exactly equal to ±`rho_entry` or ±`rho_exit`
increments no counter.

## §R2 Precise definition

Sign of the 63-day [example] stock–bond return correlation (SPY vs TLT): negative = normal (bonds hedge equities); positive = inflation-fear regime (both sell off together — 2022 printed sustained positive and the worst 60/40 year on record [documented]). State changes go through a hysteresis machine with entry/exit confirmation — no whipsaw on noise, no flip-flop at the boundary.

### §R2.1 Normative detection pseudocode

This pseudocode is normative; prose is commentary. `detect(state, events, cfg)` processes bars in ascending `event_ts`; the label at `t` uses only inputs with timestamps `≤ t`.

```
state: {label ∈ {TRANSITION, INFLATION_FEAR, FLIGHT_TO_QUALITY},
        up, down, cool, warm ∈ ℕ}          # confirmation counters; persist across calls
pairs: []                                  # valid (spy, tlt) bars seen so far

for e in events (ascending event_ts):
    spy, tlt = parse(e.spy), parse(e.tlt)
    if not (isfinite(spy) and isfinite(tlt)):
        emit(state=UNKNOWN, module_state=UNKNOWN, value=NaN)   # F1; no interpolation
        continue                          # counters frozen; bar excluded from pairs

    spike = (|spy| > 0.50 [default]) or (|tlt| > 0.50 [default])  # sanity: unadjusted split?
    pairs.append((spy, tlt)); n = len(pairs)

    if n < cfg.W_min:                     # cold start / insufficient history
        emit(state=UNKNOWN, module_state=UNKNOWN, value=NaN)
        continue                          # counters frozen

    win = last cfg.W pairs if n ≥ cfg.W else pairs     # trailing PRESENT bars
    rho = pearson(win.spy, win.tlt)                    # NaN iff σ_spy=0 or σ_tlt=0
    if not isfinite(rho):
        emit(state=UNKNOWN, module_state=UNKNOWN, value=rho)   # F2
        continue                          # counters frozen

    # confirmation counters (strict inequalities; exact-threshold rho counts nowhere)
    up   = up+1   if rho >  cfg.rho_entry else 0
    down = down+1 if rho < -cfg.rho_entry else 0
    cool = cool+1 if rho <  cfg.rho_exit  else 0
    warm = warm+1 if rho > -cfg.rho_exit  else 0

    if state.label == TRANSITION:
        if up   ≥ cfg.confirm_days: state.label = INFLATION_FEAR
        elif down ≥ cfg.confirm_days: state.label = FLIGHT_TO_QUALITY
    elif state.label == INFLATION_FEAR and cool ≥ cfg.confirm_days:
        state.label = TRANSITION
    elif state.label == FLIGHT_TO_QUALITY and warm ≥ cfg.confirm_days:
        state.label = TRANSITION
    # no direct INFLATION_FEAR ↔ FLIGHT_TO_QUALITY: exit fires first (cool/warm),
    # re-entry is evaluated on the following bar — a one-bar TRANSITION pause.

    mstate = DEGRADED if (n < cfg.W or spike) else OK
    emit(state=state.label, value=rho, module_state=mstate)

# module-state invariants: invalid input → UNKNOWN (never interpolate);
# partial window or spike → DEGRADED with label still emitted (honest, not silent).
```

### §R2.2 Edge cases (normative)

- **Missing bars / vendor gaps:** bar excluded from `pairs`; confirmation counters freeze (not reset); label for that bar is `UNKNOWN`. Gaps do not shift the window's calendar span — the window is the last `W` present bars.
- **Trading halts / auctions:** halt event → freeze publication, emit `UNKNOWN`, discard window contributions across the reopen (cold restart: require `W_min` fresh post-reopen bars before labels resume; counters reset to 0 on reopen [default]). Auction → hold last label, `module_state=DEGRADED`, no new entries.
- **Corporate actions (splits, dividends):** inputs are *total-return* series (split/dividend-adjusted) — actions are a no-op by construction. If a price-only series is ingested by mistake, the `|r| > 0.50` [default] sanity rule fires → `DEGRADED` + notify, bar kept in window (flagged, not hidden); recovery = re-ingest total-return series and bump `data_vintage`.
- **Half-day sessions / holidays:** a printed bar is a bar (total return over the session); no special handling. No bar → missing-bar rule.
- **Vendor revision:** if the vendor restates history, bump `data_vintage` and re-run; never silently overwrite emitted labels — revisions are decision-logged (Appendix g v1.0.0).
- **IEF substitution (F3b verifier):** on every bar with `n ≥ W`, compute `rho_IEF` over the same window with IEF total returns; if `sign(rho_TLT) ≠ sign(rho_IEF)` → `UNKNOWN` + page (TLT data quirk suspected); recovery = auto when signs agree for `2` consecutive bars [default].

## §R3 Exact calculation

Rolling Pearson `ρ_t` over window `W = 63` trading days [example] on daily
total returns (decimal):

$$\rho_t = \frac{\mathrm{Cov}(r_e, r_b)}{\sigma_e \sigma_b}}$$

Strict FTQ flag (illustrative operationalization of Baur & Lucey (2009) [documented]:
FTQ = significant *decrease* in stock-bond correlation in a falling market;
contagion = *increase* in falling markets):
`FTQ_t = 1[ρ_t < ρ_FTQ] · 1[σ_e,t > σ_e,crit] · 1[r_e,t < 0 < r_b,t]`.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0).*

**Data inputs.** SPY and TLT (or local equity index + 10y total-return) daily series; window W.

**Cadence.** Daily.

### Threshold bands (hysteresis, normative)

| Condition on `ρ_t` | Transition | Tag |
|---|---|---|
| `ρ_t > +ρ_entry` (`0.20`) for `confirm_days` (`21`) consecutive valid bars | TRANSITION → INFLATION_FEAR | [example] |
| `ρ_t < −ρ_entry` for `confirm_days` consecutive valid bars | TRANSITION → FLIGHT_TO_QUALITY | [example] |
| `ρ_t < +ρ_exit` (`0.10`) for `confirm_days` consecutive valid bars | INFLATION_FEAR → TRANSITION | [example] |
| `ρ_t > −ρ_exit` for `confirm_days` consecutive valid bars | FLIGHT_TO_QUALITY → TRANSITION | [example] |
| `|ρ_t| ≤ ρ_entry` | no counter increments (boundary dead zone) | [default] |

### Calibration recipe (no magic numbers)

Every `[example]` threshold above must be re-estimated per instrument before
production. The recipe is the deliverable; the defaults are placeholders:

1. **Data:** the same SPY/TLT (or local pair) total-return EOD series the module will consume in production [default].
2. **Objective:** maximize episode agreement (fraction of canonical macro episodes correctly labelled: 2008 GFC = FLIGHT_TO_QUALITY, Mar-2020 = FLIGHT_TO_QUALITY, 2022 = INFLATION_FEAR [unverified] soft labels) minus `λ = 2` [example] × flips-per-year (whipsaw penalty).
3. **Grid:** `W ∈ {42, 63, 84}`; `confirm_days ∈ {10, 15, 21, 30, 42}`; `rho_entry ∈ {0.10, 0.15, 0.20, 0.25, 0.30}`; `rho_exit ∈ {0.00, 0.05, 0.10, 0.15}` with the hard constraint `rho_exit < rho_entry − 0.05` [default]. All grid values [example].
4. **OOS selection (walk-forward):** `4` folds [example]; each fold trains on `8` y [example], validates on the next `2` y [example]; a `5`-day [example] embargo around episode boundaries prevents label leakage. Select the config with the best median rank across folds; apply the one-standard-error rule (prefer the simplest config within 1 SE of the best) [default].
5. **Re-cal cadence:** annual [default], plus on demand after a structural shock (e.g. a new sustained sign regime like Aug-2022). Every re-cal is changelogged with the selected config and fold scores.
6. **Honesty rule:** if no config beats a coin-flip baseline on episode agreement, the module stays `UNKNOWN`-heavy (high `confirm_days`, wide `rho_entry`) rather than overfitting the grid [default].

### Failure-mode rows: trigger → detect → action → recovery

`check:` lines are the executable assertions; honest `DEGRADED`/`UNKNOWN`
behavior is specified, not implied.

| # | Trigger | Detect | Action | Recovery |
|---|---|---|---|---|
| F1 | vendor EOD bar absent at the `18:30` ET [example] cutoff, or a field non-finite | row-level finiteness parse — `check: assert isfinite(spy) and isfinite(tlt)` | emit `UNKNOWN` for that bar; exclude the bar from the window (no interpolation); confirmation counters **frozen**, never reset | auto-resume on next valid bar; backfill only on vendor revision (bumps `data_vintage`); page if > `1` consecutive [default] |
| F1b | cold start: fewer than `W_min = 21` [default] valid bars | `check: assert n >= W_min` | `UNKNOWN`; counters frozen | automatic once history accumulates |
| F2 | degenerate window: `σ_spy = 0` or `σ_tlt = 0` (e.g. halted ETF printing constants) or non-finite `ρ` | variance guard — `check: assert vx > 0 and vy > 0 and isfinite(rho)` | `UNKNOWN` + page | resumes automatically when variance returns; no manual re-arm |
| F3a | primary Pearson vs independent implementation differ by > `1e-9` [default] on any window | dual run per window — `check: abs(rho_primary − rho_independent) ≤ 1e-9` | `UNKNOWN` + page | code fix + fixture re-verification; manual re-arm (deterministic bug, never self-heals) |
| F3b | IEF-substituted sign disagrees with TLT sign on the same window (TLT data quirk suspected) | second estimator — `check: sign(rho_TLT) == sign(rho_IEF)` | `UNKNOWN` + page | auto when signs agree `2` consecutive bars [default]; escalate if persistent (data-vendor ticket) |
| F4 | no valid print for > `3`× cadence [default] | freshness watchdog on `computed_at` vs now | `UNKNOWN` + notify | auto-resume on fresh print |
| F5 | backtest window chosen after seeing results | review-time CI gate: label lag `≥ min_lag_bars`, window declared pre-run in decision log — `check: no ex-post period selection` | quarantine the backtest | re-run with the declared window |
| H1 | trading halt / auction | market-state table (§R0.5) | halt → freeze publication, `UNKNOWN`, discard window contributions across reopen; auction → hold last label, `DEGRADED` | cold restart: require `W_min` fresh post-reopen bars; counters reset to `0` [default] |
| C1 | possible unadjusted corporate action: single-bar `|r| > 0.50` [default] | spike sanity — `check: abs(r) ≤ 0.50 else flag` | `DEGRADED` + notify; bar kept in window (flagged, not hidden) | re-ingest total-return series; bump `data_vintage` |
| C2 | partial window (`W_min ≤ n < W`) | `check: n < W` | `DEGRADED` with label still emitted (honest degradation, never silent, never UNKNOWN) | automatic at `n = W` |
