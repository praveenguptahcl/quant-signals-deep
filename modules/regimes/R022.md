## §R1 Precise definition

DTC = SI/ADV; utilization = on-loan/lendable; borrow fee annualized [documented constructions]. Cross-check: 3-obs median DTC; relative tolerance `0.2` [default]. Daily carry ≈ fee/360 [documented].

## §R2 Exact calculation

$$DTC = \frac{SI}{ADV},\quad \text{daily carry } \approx \frac{\text{fee}}{360} \quad\text{[documented]}$$

Worked example [documented Grok RB3]: fee `12%`, utilization `93%`, DTC = `12/2 = 6.0` ⇒ squeeze_candidate/HTB. Bands [example]: DTC `> 6` or fee `> 10%` or util `> 90%` = squeeze_candidate; DTC `> 10` or fee `> 15%` or util `> 97%` = hard_to_borrow.

**Data inputs.** borrow fee (annualized), utilization, short interest, ADV.

**Cadence.** daily.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|

| `fee > 15%` or `util > 97%` or `DTC > 10` | hard_to_borrow (shorts forbidden) | [example] |

## §R5 Cost interface: regime state → cost-function adjustment

Borrow constraints can dominate thesis P&L: the adjustment blocks new shorts in hard-to-borrow states and adds the daily borrow carry to the cost model in squeeze-candidate states.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    if rsv['state'] == 'hard_to_borrow':
        adj['trade_ok'] = False       # [default] recall risk
        adj['reason'] = 'hard_to_borrow'
    elif rsv['state'] == 'squeeze_candidate':
        adj['trade_ok'] = True
        adj['size_mult'] = 0.5        # [example]
        adj['borrow_carry'] = 0.12 / 360  # [example] daily carry at 12%
    else:
        adj['trade_ok'] = True
        adj['size_mult'] = 1.0        # [default]
    return adj
```
