### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes. The trailing-`3` [default] verifier medians likewise use only bars
  `≤ t`.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]); FINRA-SI-vintage
  labels carry their vintage tag and are additionally lagged to the SI
  publication date (~`2–4` weeks [documented]).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts == indicator_ts` for the label at `t`, the earliest gated trade is
  strictly after `t`, and that appending a synthetic breakout bar does not move
  the label stamped at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream vetoes new
  shorts / halves size; never treated as benign (F1). `DEGRADED` halves size
  [default] per §R5.

## §R1 Precise definition

- `DTC = SI / ADV` — short interest in shares divided by average daily volume
  in shares/day; ORTEX's published definition [documented].
- `utilization = on-loan ÷ lendable` (`0–1` [documented]) — SEC's definition: "currently on
  loan relative to the total number of shares available for lending"
  [documented].
- `fee_ann` — annualized borrow fee as a decimal. Daily carry ≈ `fee_ann/360`
  [documented] (BIS CPSS 1999: fee = nominal × (days/`360`) × borrow fee).
- **Split adjustment:** SI and ADV are split-adjusted with the vendor's
  adjustment factor before DTC is computed. If no factor is available the bar
  is treated as a corporate-action event (§R2.4), not silently stitched.
- **Cross-check:** trailing-`3`-observation medians of (`fee_ann`, `util`,
  DTC) recomputed independently (Verifier); agreement within relative `0.2`
  [default] or absolute floors (`0.005`/`0.01`/`0.25` [default]) or `UNKNOWN`
  (F3).
- **Label semantics:** the label is a *constraint* state (can we stay short /
  open shorts), never a squeeze *timing* prediction. A squeeze still needs a
  catalyst — high DTC alone is documented not to squeeze [documented].

## §R2 Exact calculation

### R2.1 Normative detection pseudocode

Pseudocode is normative; prose is commentary. Thresholds are strict `>`
on entry (sitting exactly on a threshold does **not** escalate) and strict
`<` on exit.

```
LEVELS = [normal(0), elevated(1), squeeze_candidate(2), hard_to_borrow(3)]

ENTRY(fee, util, dtc):                      # OR-any fires [default]
  if fee > 0.15 or util > 0.97 or dtc > 10.0: return hard_to_borrow
  if fee > 0.10 or util > 0.90 or dtc >  6.0: return squeeze_candidate
  if fee > 0.05 or util > 0.75 or dtc >  4.0: return elevated
  return normal

EXIT(state):                                 # entry minus hysteresis delta [default]
  # elevated:        fee < 0.03 and util < 0.73 and dtc < 3.5
  # squeeze_candidate: fee < 0.08 and util < 0.88 and dtc < 5.5
  # hard_to_borrow:  fee < 0.13 and util < 0.95 and dtc < 9.0

on_new_bar(t, fee, util, si, adv, cfg):       # causal: only event_ts <= t
  F1: require finite fee/util/si/adv, adv > 0, si >= 0, 0 <= util <= 1,
      fee in [0, 10]; else emit UNKNOWN (never interpolate)
  F2: dtc = si / adv; require 0 <= dtc <= 500; else emit UNKNOWN
  market-state table: HALTED -> UNKNOWN (freeze); AUCTION -> hold, DEGRADED;
                      CLOSED -> OFF
  gap check: any inter-bar gap in (1.5x, 5x] cadence -> DEGRADED gap_masked
             (mask: exclude nothing, interpolate nothing); gap > 5x -> F4 UNKNOWN
  corp-action check: event within last 5 bars -> freeze pre-event label,
                     DEGRADED, for 5 bars [default]; re-baseline windows after
  el    = ENTRY(fee, util, dtc)              # instantaneous entry level
  state, hold = prior state, prior hold
  if rank(el) > rank(state):    state, hold = el, 0        # escalate: immediate
  elif rank(el) == rank(state): hold = 0
  else:
      if fee < EXIT_fee(state) and util < EXIT_util(state) and dtc < EXIT_dtc(state):
          hold += 1
      else: hold = 0
      if hold >= 3:                            # [default]
          state = LEVELS[rank(state) - 1]      # step down ONE level only
          hold = 0
  F3 (needs >= 3 bars [default]): verifier medians of trailing 3 (fee, util, dtc);
      max relative deviation <= 0.2 [default] or absolute floors else UNKNOWN
  warm-up (< 3 bars): DEGRADED, label emitted but flagged
  F4: now - computed_at > 5x cadence -> UNKNOWN
  emit RegimeState{regime_id=R022, state, value=dtc, estimator_version,
                   data_vintage, computed_at=event_ts(t), module_state}
```

Hysteresis state-transition summary: escalation is single-bar and may skip
levels (e.g. `elevated → hard_to_borrow` on a recall spike); de-escalation
never skips — one level per `3` consecutive qualifying bars [default]; a
non-qualifying bar resets the hold counter to `0` [default].

### R2.4 Edge cases (normative)

- **Missing bars:** gaps are masked, never interpolated. Gap in (`1.5`×, `5`×] [default]
  cadence → `DEGRADED` (`gap_masked`); the label still emits from available
  bars. Gap `> 5`× cadence → `UNKNOWN` (F4).
- **Trading halts:** `HALTED` → freeze state, emit `UNKNOWN`; contributions
  across the reopen are discarded; resume on the first clean close.
- **Auctions:** `AUCTION` → hold last label, `DEGRADED`; no new labels.
- **Corporate actions:** splits/dividends move SI and ADV discontinuously.
  On a corporate-action event the label freezes at the pre-event level and
  the module emits `DEGRADED` for `5` bars [default]; verifier windows are
  re-baselined to post-event bars only (no stitching across the event without
  a vendor adjustment factor).
- **SI vintage:** FINRA prints are twice-monthly with ~`7`-business-day
  publication lag [documented]. Labels derived from FINRA SI carry the SI
  settlement date as `data_vintage`; if the vintage is older than `21` days
  [default] and no intraday feed is present → `DEGRADED`.
- **Negotiated fees:** printed indicative fees are not realized fees — the
  SEC documents a median same-stock same-day fee range of ~`3`pp
  [documented]. The Verifier's absolute floor (`0.005` [default]) absorbs
  normal negotiation spread; a negotiated print far from the indicative feed
  trips F3 honestly rather than silently.
- **Estimate revisions:** intraday estimate feeds (ORTEX) revise as new
  lending data arrives [documented]. Labels follow the newest vintage only;
  prior labels stay as-stamped in the decision log — never retroactively
  rewritten.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** maintains DTC/fee/util; publishes RSV with the hysteresis state
  machine (§R2.1).
- **Verifier:** trailing-`3` medians of (fee, util, DTC); SI-vintage age check;
  trips F3/F4 honestly.
- **Grok-Researcher:** proposes windows; leads only.
- **Adversary:** checks a catalyst requirement for squeeze *timing* claims;
  checks borrow-locate feasibility; probes boundary straddles.
- **Gate:** rejects shorts in hard_to_borrow without locked borrow; rejects
  squeeze-timing claims without a catalyst feed.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `5`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Reference implementation (also exercised by `test_cost_interface_*`):

```python
def cost_adjustment(rsv_state, module_state, fee_ann, base):
    # base: 4-component stack {spread_bps, fees_bps, borrow_bps, impact_bps}
    adj = dict(base)
    adj["regime"] = rsv_state
    adj["borrow_carry_bps_day"] = fee_ann / 360.0 * 10000.0  # [documented] BIS fee/360
    adj["trade_ok"] = True
    adj["size_mult"] = 1.0                                    # [default]
    if module_state == "UNKNOWN":
        adj["trade_ok"] = False
        adj["reason"] = "regime_unknown"                       # [default] restrictive
    elif module_state == "DEGRADED":
        adj["size_mult"] = 0.5                                # [default]
        adj["reason"] = "regime_degraded"
    if rsv_state == "hard_to_borrow":
        adj["trade_ok"] = False                               # [default] recall risk
        adj["reason"] = "hard_to_borrow"
    elif rsv_state == "squeeze_candidate":
        adj["size_mult"] = min(adj["size_mult"], 0.5)          # [example]
        adj["spread_bps"] = adj["spread_bps"] * 1.5            # [example] squeeze widening
    return adj
```

Component mapping — which cost components scale, and how much:

| Regime state | `trade_ok` | `size_mult` | `spread_bps` | `borrow_carry_bps_day` | Notes |
|---|---|---|---|---|---|
| normal | true | `1.0` [default] | ×`1.0` | `fee/360×10000` [documented] | carry tracked for transparency |
| elevated | true | `1.0` [default] | ×`1.0` | `fee/360×10000` [documented] | no scaling |
| squeeze_candidate | true | `0.5` [example] | ×`1.5` [example] | `fee/360×10000` [documented] | spread widening is the squeeze tax |
| hard_to_borrow | **false** [default] | — | — | — | recall risk: new shorts vetoed, not priced |
| module `UNKNOWN` | **false** [default] | — | — | — | restrictive: never treated as benign |
| module `DEGRADED` | true | `0.5` [default] | ×`1.0` | `fee/360×10000` [documented] | half size while unverified |

`fees_bps`, `borrow_bps` (annualized borrow already in the stack), and
`impact_bps` are unchanged by this module — the daily carry is the
*realization* of the borrow cost, not a second charge; do not double-count.
Recall on an *existing* short is position management, not a new order: the
veto covers new shorts; expected forced-cover cost is scenario-stressed, not
point-estimated (honest limitation).
