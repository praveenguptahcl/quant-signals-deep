### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; z at t uses volumes < t only; contextualizes t+1+ flow).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Volume z-score `z^V_t = (V_t − μ_{V,L})/σ_{V,L}` with the lookback excluding t [documented construction]; turnover `V_t/Float` as the name-normalized variant [documented]. Cross-check: median/MAD robust z; absolute tolerance `1.0` [default].

## §R2 Exact calculation

$$z^V_t = \frac{V_t - \mu_{V,L}}{\sigma_{V,L}} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: lookback `μ = 1.011m`, `σ = 0.119m`; `V_t = 1.45m` → `z ≈ 3.69` ⇒ abnormal. Bands [example]: `z > 2` elevated · `z > 3` abnormal participation.

**Data inputs.** bar/day volume; float or ADV for the turnover variant.

**Cadence.** 5-minute intraday; daily label.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Event-driven / information-release | **amplifies** | improves on abnormal volume (earnings, index adds — volume *is* the event) |
| VWAP/POV algos | **amplifies** | improves: algos scale with capacity — abnormal volume is capacity |
| Mean-reversion assuming 'volume = climax' | **inverts** | dies without a signed-flow overlay (R011/R014) — volume alone is not a reversal signal |
| Breakout | **amplifies then inverts** | improves on heavy pace (fuel); dies on dead pace (< 0.7× [example]) — no fuel |

## §R5 Cost interface: regime state → cost-function adjustment

Abnormal participation compresses volume-clock horizons and widens expected slippage on urgent flow: the adjustment raises the urgency cost multiplier and halves breakout size on dead pace.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'abnormal':
        adj['slip_mult'] = 1.5        # [example] flow day
        adj['horizon_mult'] = 0.5     # [example] volume clock runs fast
    elif rsv['state'] == 'elevated':
        adj['slip_mult'] = 1.25       # [example]
    else:
        adj['slip_mult'] = 1.0        # [default]
    return adj
```
