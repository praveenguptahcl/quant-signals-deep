### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; z at t uses volumes < t only; contextualizes t+1+ flow).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Volume z-score `z^V_t = (V_t − μ_{V,L})/σ_{V,L}` computed over the trailing
`lookback` bars with the lookback **excluding t** [documented construction];
turnover `V_t/Float` as the name-normalized variant [documented]. Cross-check:
median/MAD robust z; absolute tolerance `dual_tol = 1.0` [default]. Labels are
hysteresis states (§R2), not raw threshold crossings — entry sits strictly
above exit so a single bar cannot flicker the label.

## §R2 Exact calculation

$$z^V_t = \frac{V_t - \mu_{V,L}}{\sigma_{V,L}} \quad\text{[documented]}$$

Worked example [documented Grok RB2]: lookback `μ = 1.011m`, `σ = 0.119m`; `V_t = 1.45m` → `z ≈ 3.69` ⇒ abnormal.

**Data inputs.** bar/day volume; `split_factor` for corporate-action
renormalization; float or ADV for the turnover variant.

**Cadence.** 5-minute intraday; daily label.

**Threshold bands (hysteresis: entry > exit, strict inequalities).**

| From state | Condition | To state | Tag |
|---|---|---|---|
| normal | `z > 3.0` | abnormal | entry [default] |
| normal | `z > 2.0` | elevated | entry [default] |
| elevated | `z > 3.0` | abnormal | entry [default] |
| elevated | `z < 1.5` | normal | exit [default] |
| abnormal | `z < 2.0` | elevated | exit [default] |

`z` exactly on a threshold holds the current state (no transition) [default].
Bands carry `[default]` calibration provenance via §R0.2.1; the documented
content is the z-score construction (today excluded) and the Beaver (1968)
volume-event link.

### §R2.1 Normative detection pseudocode

Pseudocode is normative; prose is commentary. `bars` is newest-last; each bar
carries `event_ts`, `vol`, optional `split_factor` (default `1.0` [default]),
and the market-state flag.

```python
def detect(state, bars, cfg):
    # F1 — invalid input -> UNKNOWN, never interpolate
    if not bars: return emit("missing", NaN, UNKNOWN)
    for b in bars:
        if b.vol is None or not isfinite(b.vol) or b.vol < 0:
            return emit("invalid", NaN, UNKNOWN)
    if len(bars) < cfg.min_warmup:
        return emit("warming", NaN, DEGRADED)          # label withheld

    # Edge 3 — corporate actions: renormalize baseline to the newest bar's
    # share-count basis BEFORE any statistic (a 2:1 split ~doubles raw prints)
    f = bars[-1].split_factor or 1.0
    base = [b.vol * f for b in bars[:-1]][-cfg.lookback:]
    mu, sd = mean(base), stdev(base, ddof=1)
    if not isfinite(mu) or not (sd > 0):
        return emit("undefined", NaN, UNKNOWN)          # F2: zero variance

    z = (bars[-1].vol - mu) / sd
    if not isfinite(z) or z < -10.0 or z > 20.0:        # [default] bounds
        return emit("out_of_bounds", z, UNKNOWN)        # F2

    # F3 — dual-estimator agreement (robust z within dual_tol)
    med, mad = median(base), median(|v - median(base)| for v in base)
    zr = (bars[-1].vol - med) / (1.4826 * mad) if mad > 0 else NaN
    if not isfinite(zr) or abs(z - zr) > cfg.dual_tol:
        return emit(state.last_label, z, UNKNOWN)      # hold label, go UNKNOWN

    # Hysteresis state machine (strict inequalities)
    s = state.last_label or "normal"
    if s == "abnormal":
        s = "elevated" if z < cfg.abnormal_exit_z else "abnormal"
    elif s == "elevated":
        if z > cfg.abnormal_entry_z:   s = "abnormal"
        elif z < cfg.elevated_exit_z:  s = "normal"
    else:
        if z > cfg.abnormal_entry_z:   s = "abnormal"
        elif z > cfg.elevated_entry_z: s = "elevated"

    # F4 — staleness (checked by caller with now_ns; 3x cadence TTL)
    return emit(s, z, OK, computed_at=bars[-1].event_ts)
```

**Edge cases (normative):**

1. **Missing bars / gaps.** No interpolation, ever (F1). A gap masks the
   missing contribution; if the gap exceeds the staleness TTL (`3`× cadence
   [default]) the module emits `UNKNOWN` (F4).
2. **Halts.** `HALTED` → freeze state, emit `UNKNOWN`; contributions across
   reopen are discarded (per the R0.6 market-state table) — a halt's
   accumulated imbalance is not scored against the continuous-session
   baseline.
3. **Corporate actions.** Splits/dividends renormalize the *baseline* to the
   newest bar's share basis (edge 3 above, default). The turnover variant
   additionally requires `shares_float` on the same basis; a basis mismatch
   between float and volume → `UNKNOWN` (F2-style guard) [default].
4. **Auction prints.** Open/close auction volume is a different process from
   continuous session: continuous-session profiles exclude auction prints
   [default]; separate auction profiles are an escalation (skip list).
5. **Zero/constant volume.** `σ = 0` → `UNKNOWN` (F2), never `z = 0`. A
   constant-volume window is a data error or a dead symbol, not "normal".
6. **Half-days.** Scored against a half-day seasonal profile, never against
   the full-day profile; without one, emit `DEGRADED` with the label withheld
   [default].

## §R5 Cost interface: regime state → cost-function adjustment

Which cost components scale and by how much (all multipliers on the
consumer's base cost stack; the stack itself is the consumer's single source
of truth — this module only supplies adjustments):

| Component | abnormal (`z > 3.0` [default]) | elevated (`z > 2.0` [default]) | normal / dead pace | Rationale |
|---|---|---|---|---|
| Spread (slippage urgency) | `slip_mult = 1.5` [example] | `slip_mult = 1.25` [example] | `1.0` [default] | urgent flow crosses wider spreads on news days |
| Market impact | `impact_mult = 0.8` [example] | `impact_mult = 0.9` [example] | `1.0` [default] | deeper book on heavy participation (capacity effect) |
| Volume-clock horizon | `horizon_mult = 0.5` [example] | `horizon_mult = 0.75` [example] | `1.0` [default] | volume clock runs ~`2`× on flow days [example] |
| Size (dead pace only, `z < -1.0` [default]) | — | — | `size_mult = 0.5` [example] | no-fuel chop: stand down breakouts |
| Fees, borrow | unscaled | unscaled | unscaled | venue/borrow costs do not depend on participation |
| Trade gate | `trade_ok = True` | `trade_ok = True` | `trade_ok = True` | this module never vetoes; sizing is the lever |

```python
def cost_adjustment(rsv, base):
    """R013 cost interface: regime state -> cost-function adjustment."""
    adj = dict(base)
    adj['trade_ok'] = True
    adj['size_mult'] = 1.0           # [default]
    if rsv['state'] == 'abnormal':
        adj['slip_mult'] = 1.5      # [example] flow day
        adj['impact_mult'] = 0.8    # [example] deeper book
        adj['horizon_mult'] = 0.5   # [example] volume clock runs fast
    elif rsv['state'] == 'elevated':
        adj['slip_mult'] = 1.25     # [example]
        adj['impact_mult'] = 0.9    # [example]
        adj['horizon_mult'] = 0.75  # [example]
    else:
        adj['slip_mult'] = 1.0      # [default]
        adj['impact_mult'] = 1.0    # [default]
        adj['horizon_mult'] = 1.0   # [default]
    if rsv['value'] < -1.0:         # dead_pace_z [default]
        adj['size_mult'] = 0.5      # [example] no fuel: stand down breakouts
    return adj
```

The `slip_mult`/`impact_mult`/`horizon_mult`/`size_mult` values are
`[example]` starting points for the calibration recipe (§R0.2.1) — pin them
per venue before production. `trade_ok` stays `True`: abnormal volume is a
cost *adjuster*, never a trade veto; the veto lives with the strategy.

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Lookahead: window includes today → detect: `label_ts ≤ indicator_ts` assertion fails → action: halt, exclude t, page → recovery: rebuild baseline from `t−lookback..t−1`, re-run no-lookahead test before re-arm (F1) | `check: baseline excludes t` |
| 2 | Auction volume in continuous profile → detect: open/close auction flag on bar → action: exclude auction prints from continuous baseline; hold last label, state `DEGRADED` → recovery: separate auction profiles (escalation, §1.5) | `check: session split` |
| 3 | Wash volume (crypto venues) → detect: venue flagged wash-prone → action: label `reported_volume`, never treat as participation; state `DEGRADED` → recovery: switch to consolidated/regulated venue | `check: venue clean` |
| 4 | Half-day scored as full → detect: calendar half-day → action: `DEGRADED`, label withheld until half-day profile exists → recovery: build half-day seasonal profile | `check: calendar aware` |
| 5 | Threshold flicker: z oscillating across a single threshold → detect: `>2` transitions/day for `5` days [default] → action: widen hysteresis gap per §R0.2.1; state `DEGRADED` while re-calibrating → recovery: re-fit thresholds walk-forward, resume | `check: flicker monitor` |
| 6 | Split/dividend not renormalized → detect: post-event z jump > `5.0` [default] with no news → action: `UNKNOWN`, demand `split_factor` re-ingest → recovery: renormalize baseline, recompute, label resumes | `check: basis match` |
| 7 | Dual-estimator divergence → detect: `|z − z_robust| > dual_tol` (`1.0` [default]) → action: hold last label, emit `UNKNOWN` (F3) → recovery: investigate skew/outlier contamination, resume when agreement restores | `check: estimator agree` |
| 8 | Stale feed → detect: `now − computed_at > 3`× cadence [default] → action: `UNKNOWN` (F4), page if `>30` s [default] → recovery: feed resumes, first fresh bar re-arms to `OK` | `check: staleness TTL` |

Honest degraded behavior: `DEGRADED` means the label is *withheld*, never
interpolated — downstream treats withheld as restrictive (halve size / widen
stops / stand down), per the R0.5 `unknown_behavior` rule. `UNKNOWN` is the
default answer to any unmapped failure.
