### R0.1 Typed signature

```python
def detect(state: RegimeModuleState, events: list[Event], cfg: Config) -> list[RegimeState]:
```

`RegimeState` = `{regime_id, state, value, estimator_version, data_vintage,
computed_at, module_state, min_lag_bars}` — the module's `regime_state_vector`
(§1). `state` is the module-owned named state vector (`short_pct`, `dtc`,

canonical Events (Appendix a v1.0.0), ascending `event_ts`. `value` is the

out-of-bounds indicator values (negative, non-finite) → `UNKNOWN` (F2, never
interpolate); halt/auction events → freeze per the market-state table;
corporate-action float jumps → `UNKNOWN` until the denominator is confirmed.
It emits regime labels and cost-interface adjustments only — never orders,
never signals.

### R0.4 Time contract

> Time contract: clock domain UTC, int64 ns; authoritative causality clock =
> `event_ts`; max_skew = `1` ms [default]; bar-label = open time; staleness TTL
> = `3`× cadence [default] (F4); gap policy = mask, no interpolation; halt →
> freeze and emit `UNKNOWN`.

**Timing box:** `detect@t (per_bar, America/New_York) → regime label gates signals only for trades @open(t+1) or later`

Staleness concretely: with bi-monthly cadence ≈ `15` days [example], the TTL
is `3` × `15` = `45` days [default] — a label older than `45` days [default]
with no fresh print expires to `UNKNOWN` (F4).

### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).
- Publication lag: the FINRA print at settlement date `d` is not *known* until
  dissemination ~`7` business days later [documented]; live gating must stamp
  `data_vintage` = dissemination date, not settlement date.

## §R2 Precise definition

Crowded-short state: short interest as a fraction of float, plus days-to-cover
(short interest ÷ ADV). Both are slow-moving — the module is a state flag,
never a trigger. Prints are bi-monthly (settlement dates the 15th and the
last business day of the month [documented]) and are disseminated ~`7`
business days after the reporting settlement date [documented] — an ≈
two-week information lag [documented]. Staleness beyond `45` days [default]
expires the label. Labels use **entry bands to turn on** and **exit bands to
turn off** (§R2.1) so bi-monthly prints straddling a threshold do not flap the
state every `15` days [example].

### §R2.1 Normative detection pseudocode

Normative — prose is commentary; this pseudocode is the contract
(`tests/test_R043.py` implements it verbatim).

```
function detect(state, events, cfg):
    # events: ascending event_ts; each event carries ts_ns, name,
    #         si_shares, float_shares, adv, market_state (optional)
    memory = state.hysteresis          # per-name last VALID label; default "NORMAL"
    last_float = state.last_float      # per-name, for corporate-action guard
    out = []
    for e in events:
        ts = e.ts_ns; prev = memory.get(e.name, "NORMAL")
        # --- F1: missing print -------------------------------------------------
        if e.si_shares is None or e.float_shares is None or e.adv is None:
            out.append(UNKNOWN(ts, "missing-input")); continue
        # --- halt/auction freeze -----------------------------------------------
        if e.market_state == HALTED:
            out.append(UNKNOWN(ts, "halt-freeze")); continue   # memory preserved
        if e.market_state == AUCTION:
            out.append(HOLD(prev, module_state=DEGRADED, ts=ts)); continue
        # --- F2: bounds ---------------------------------------------------------
        s = e.si_shares / e.float_shares          # short_pct
        d = e.si_shares / e.adv                   # days-to-cover
        if not (isfinite(s) and isfinite(d)) or s < 0 or d < 0:
            out.append(UNKNOWN(ts, "bounds")); continue        # never interpolate
        if e.float_shares <= 0:
            out.append(UNKNOWN(ts, "bad-denominator")); continue
        # --- corporate-action guard ---------------------------------------------
        if last_float.get(e.name) is not None and \
           abs(e.float_shares - last_float[e.name]) / last_float[e.name] > 0.50:
            out.append(UNKNOWN(ts, "float-jump-unconfirmed")); continue
        last_float[e.name] = e.float_shares
        # --- state transitions with hysteresis -----------------------------------
        label = classify(prev, s, d, cfg)         # §R3 bands
        memory[e.name] = label                    # only valid labels update memory
        out.append(RegimeState(ts=ts, name=e.name, state=label, value=s,
                              module_state=OK, data_vintage=e.dissemination_date,
                              computed_at=ts, min_lag_bars=cfg.min_lag_bars))
    return out

function classify(prev, s, d, cfg):
    if s >= cfg.squeeze:                          return SQUEEZE_WATCH   # entry
    if prev == SQUEEZE_WATCH and s >= cfg.squeeze_exit:
                                                  return SQUEEZE_WATCH   # hold
    if s >= cfg.crowded or d >= cfg.dtc_crit:     return CROWDED          # entry
    if prev in {SQUEEZE_WATCH, CROWDED} and (s >= cfg.crowded_exit or d >= cfg.dtc_exit):
                                                  return CROWDED          # hold
    return NORMAL
```

Edge-case coverage: missing bars/prints (F1 → `UNKNOWN`, no interpolation);
halting (freeze + `UNKNOWN`, memory preserved, contributions across reopen
discarded); corporate actions (float jump > `50`% [example] between prints →
`UNKNOWN` until the denominator is confirmed — splits/offerings otherwise
corrupt `short_pct`); stale feed (F4 expires via `apply_freshness`);
hysteresis memory survives `UNKNOWN` prints (a bad print must not flip a
crowded name back to NORMAL).

### §R2.2 Detection-calibration recipes

Every `[example]`-tagged threshold below is a *starting guess* that must be
re-fit before production use. Recipe per threshold — data, grid, objective,
OOS selection, re-cal cadence:

| Threshold (default [example]) | Data | Grid | Objective | OOS selection | Re-cal cadence |
|---|---|---|---|---|---|
| `squeeze` `0.25` | S&P Global Securities Finance daily panel, Sep 2012+ [documented]; or FINRA bi-monthly free [documented] + joined float | `0.20–0.35` step `0.01` [example] | maximize out-of-sample squeeze-event capture (upside jump ≥ `10`% [example] in `5` days [example]) at a fixed false-flag budget of `5`% of prints [example] | `3` chronological folds [default]; threshold chosen on folds 1–2, reported on fold 3 only | annually [default], or on methodology change |
| `crowded` `0.12` | same | `0.08–0.15` step `0.01` [example] | maximize F1 against an ex-ante proxy label (e.g. vendor utilization > `50`% [example] on ≥ `3` consecutive prints [example]) | `3` chronological folds [default] | annually [default] |
| `dtc_crit` `5.0` | same; DTC = SI ÷ `63`-day median ADV [default] | `3.0–8.0` step `0.5` [example] | maximize agreement with the `crowded` leg (Cohen's κ on band) [default] | `3` chronological folds [default] | annually [default] |
| exit bands (`squeeze_exit` `0.22`, `crowded_exit` `0.09`, `dtc_exit` `4.0`) | same | `0.75`×–`0.95`× the fitted entry band, step `0.01` [example] | minimize label-flap rate (state changes per print) subject to ≤ `5` [example] day detection-delay vs entry-only rule | `3` chronological folds [default] | with the entry bands |

**No magic numbers:** every threshold carries a provenance tag; the
calibration log (data vintage, folds, chosen value, OOS metric) is stored with
the module version and the threshold is *not* editable without a changelog
entry. Anti-overfit: thresholds are fit once on the calibration window —
no re-tuning on the OOS fold, no ex-post squeeze-dating (F5).

## §R3 Exact calculation

Short interest `SI`, float `F`, average daily volume `ADV`:

$$\mathrm{short\_pct} = \frac{SI}{F}, \qquad DTC = \frac{SI}{ADV}$$

Emitted scalar `value` = `short_pct` (the DTC leg enters the *state rule*,
not the scalar — §R2.1). ADV for DTC is the `63`-day median daily volume
[default]; float is the as-of-print corporate-action-adjusted float.

**Data inputs.** Short interest, float, ADV; exchange reporting calendar.

**Cadence.** Bi-monthly (settlement dates: 15th and last business day [documented]).

**Threshold bands.**

| short % / DTC | State | Tag |
|---|---|---|
| short_pct `≥ 25`% → enter SQUEEZE_WATCH; exit at `< 22`% | SQUEEZE_WATCH | [example] |
| short_pct `≥ 12`% or DTC `≥ 5` → enter CROWDED; exit at `< 9`% and DTC `< 4` | CROWDED | [example] |
| else | NORMAL | [example] |

Recalibrate every `[example]`-tagged band per instrument per §R2.2 before
production use. Hysteresis: entry uses the entry band; a name already flagged
holds until it falls below the exit band (§R2.1 `classify`); work-check
[example]: `(0.18, 6.2)` → CROWDED; `(0.04, 1.5)` → NORMAL; `(0.25, 9.0)` →
SQUEEZE_WATCH; a name at `(0.115, 2.5)` after being CROWDED *stays* CROWDED.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

```python
COST_ADJUSTMENT_R043 = {
    "regime_id": "R043", "version": "1.1.0",
    "SQUEEZE_WATCH": {"spread_mult": 1.5, "impact_mult": 2.0,
                      "borrow_mult": 5.0, "fee_add_bps": 0.0, "tag": "[example]"},
    "CROWDED":      {"spread_mult": 1.1, "impact_mult": 1.25,
                      "borrow_mult": 2.0, "fee_add_bps": 0.0, "tag": "[example]"},
    "NORMAL":       {"spread_mult": 1.0, "impact_mult": 1.0,
                      "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[default]"},
    "UNKNOWN":      {"spread_mult": 1.0, "impact_mult": 1.0,
                      "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[default]"},
}
```

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when |
|---|---|---|---|---|---|
| SQUEEZE_WATCH | `1.5` | `2.0` | `5.0` | `0.0` | borrow goes special; squeezes widen spreads and impact [example] |
| CROWDED | `1.1` | `1.25` | `2.0` | `0.0` | elevated specials risk [example] |
| NORMAL | `1.0` | `1.0` | `1.0` | `0.0` | identity [default] |
| UNKNOWN | `1.0` | `1.0` | `1.0` | `1.0` | identity — strategies must not trade into UNKNOWN gates [default] |

**Which components scale:** the *borrow* leg scales most (specials),
because the mechanism is in the stock-loan market — D'Avolio (2002) documents
that 91% of stocks borrow for < 1%/yr while the other 9% average 5.4%/yr
[documented], i.e. borrow cost is the dispersed leg; spread and impact scale
moderately (squeezes move price against the crowd); the *fee* leg is
unaffected (fee schedules don't depend on crowdedness).

**Application rule** (executable): given the strategy's
`expected_cost_bps` component decomposition `(spread_bps, impact_bps,
borrow_bps, fee_bps)`:
`spread_bps ×= spread_mult; impact_bps ×= impact_mult; borrow_bps ×=
borrow_mult; fee_bps += fee_add_bps` (multipliers keyed by the current regime
state; `UNKNOWN` = identity, and strategies should treat UNKNOWN as a gate,
not a cost). All multipliers `[example]` unless tagged otherwise — calibrate
per venue against realized borrow-fee series (vendor indicative-fee fields,
§R6); the record is versioned with `estimator_version` and every application
is decision-logged (Appendix g v1.0.0).

## §R7 Failure modes — trigger → detect → action → recovery

| # | Trigger | Detect | Action (state) | Recovery |
|---|---|---|---|---|
| F1 | SI print missing for a name/date | gap check vs reporting calendar | `UNKNOWN`; suppress downstream gates; page | next valid print → resume, hysteresis memory from last valid label |
| F2 | non-finite or negative `short_pct`/DTC; `float ≤ 0` | bounds check in `detect` | `UNKNOWN` + page; never interpolate | valid print → resume |
| F3 | FINRA print disagrees with vendor on band | dual-estimator band compare | `UNKNOWN` (restrictive default) + page | agreement on `2` consecutive prints [default] → re-arm |
| F4 | no fresh print for > `45` days [default] | staleness watchdog (`3`× cadence) | `UNKNOWN` + notify | fresh print → resume |
| F5 | threshold edited without calibration log | changelog/config lint | block deploy | calibration per §R2.2 + changelog entry |
| H1 | trading halt | `market_state == HALTED` event | freeze; `UNKNOWN`; memory preserved | first valid print after reopen; contributions across reopen discarded |
| H2 | auction | `market_state == AUCTION` | hold last label; `DEGRADED` | resume on CONTINUOUS_TRADING |
| C1 | corporate action: float jump > `50`% [example] between prints | float-ratio guard | `UNKNOWN` + notify until denominator confirmed | confirmed as-of float → recompute and resume |
| V1 | vendor feed down; FINRA fallback available | feed heartbeat | `DEGRADED` label from FINRA print only (SI + joined float, no borrow fields) + notify | vendor resumes → `OK` |
| K1 | kill / administrative disable | operator signal | `OFF` + page | manual re-arm with decision-log reconciliation (runbook §R0.7) |

**DEGRADED vs UNKNOWN:** `DEGRADED` = the module still emits a usable label
with reduced inputs (vendor outage → FINRA fallback; auction hold).
`UNKNOWN` = no label may be trusted (missing/bad/stale input, disagreement,
halt, unconfirmed corporate action). `OFF` = administrative only.
