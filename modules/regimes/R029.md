## §R2 Precise definition

Trend-and-location state of the ICE US Dollar Index: the 50-day vs 200-day moving-average spread (golden/death-cross taxonomy) plus where that configuration sits in its own 5-year distribution. A strong dollar tightens global financial conditions (EM stress, commodity headwinds); a weak dollar loosens them. FX trades 24 hours — the module defines the day cut explicitly at `17:00` ET [example].

**Hysteresis definition.** Extreme labels (`STRONG_DOLLAR_UPTREND`, `WEAK_DOLLAR_DOWNTREND`) are entered on the tight entry bands and exited only on the wider exit bands, so a percentile oscillating inside the exit band holds its label instead of flickering. The trend sign (`G > 0` vs `G < 0`) is read through a deadband of `±deadband_pts` [example]: a cross only flips the sign when it clears the deadband; inside the deadband the prior sign is held. The exact entry/exit conditions, state transitions, and edge-case behavior are normative in the §R3 pseudocode.

## §R3 Exact calculation

Simple moving averages and spread (index points):

$$MA_{n,t} = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}, \qquad G_t = MA_{50,t} - MA_{200,t}$$

`G_t > 0` = bull-dollar; `G_t < 0` = bear-dollar [documented TA definition].
Location of the spread in 5 years of history (empirical CDF):

$$\pi_t = \frac{\mathrm{rank}(G_t \text{ in trailing 5y})}{N}$$

Worked check: `MA_50 = 103.5`, `MA_200 = 101.8` → `G = 1.7` points;
`π = 0.80` [example] → strong-dollar uptrend.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** DXY daily close (ICE); 50-day [example] and 200-day [example] MAs from a 250-day [example] history; 5-year [example] trailing distribution of the spread.

**Cadence.** Daily; day cut `17:00` ET [example].

**Threshold bands (entry / exit with hysteresis).** All band constants are
`[example]` starting points with status `calibrate` — fit them with the
calibration recipe below before production.

| Entry condition | Exit condition | State | Tag |
|---|---|---|---|
| `G > deadband_pts`, `π ≥ 0.80` | `π < 0.80 − 0.05 = 0.75` or `G < −deadband_pts` | STRONG_DOLLAR_UPTREND | [example] |
| `G > deadband_pts` | `G < −deadband_pts` | DOLLAR_UPTREND | [documented] sign convention + [example] deadband |
| `G < −deadband_pts` | `G > deadband_pts` | DOLLAR_DOWNTREND | [documented] sign convention + [example] deadband |
| `G < −deadband_pts`, `π ≤ 0.20` | `π > 0.20 + 0.05 = 0.25` or `G > deadband_pts` | WEAK_DOLLAR_DOWNTREND | [example] |
| `|G| ≤ deadband_pts` on the first event (no prior state) | — | sign = UP if `G ≥ 0` else DOWN | [default] first-bar tie-break |

### Normative detection pseudocode

The pseudocode is normative; prose is commentary. Every prose guard above is
present here.

```
detect(state, events, cfg) -> list[RegimeState]:
  # causal: the label at position t uses only events[:t+1] + the module's OWN
  # prior state — never future inputs (Lag contract; enforced by test_no_lookahead)
  st = {"sign": None, "extreme": None}   # named state vector, module-owned
  out = []
  for e in events:                      # ascending event_ts
    G  = e.ma50 - e.ma200                # index points
    pi = e.pctile                        # empirical CDF of G over trailing 5y
    if not finite(G) or not finite(pi):
      emit RegimeState(state=UNKNOWN, module_state=UNKNOWN, computed_at=e.event_ts)  # F1
      continue                           # state vector UNTOUCHED: resume, never backfill (F5)
    if pi < 0 or pi > 1:
      emit RegimeState(state=UNKNOWN, module_state=UNKNOWN, computed_at=e.event_ts)  # F2
      continue                           # state vector UNTOUCHED
    if G > cfg.deadband_pts:        sign = UP
    elif G < -cfg.deadband_pts:     sign = DOWN
    elif st.sign is None:           sign = UP if G >= 0 else DOWN     # [default] first-bar tie-break
    else:                           sign = st.sign                   # deadband hold: absorbs zero-cross whipsaw
    if sign == UP and pi >= cfg.pct_hi:
      label, extreme = STRONG_DOLLAR_UPTREND, STRONG                 # entry band
    elif sign == DOWN and pi <= cfg.pct_lo:
      label, extreme = WEAK_DOLLAR_DOWNTREND, WEAK                   # entry band
    elif st.extreme == STRONG and sign == UP and pi >= cfg.pct_hi - cfg.hyst_pct:
      label, extreme = STRONG_DOLLAR_UPTREND, STRONG                 # hysteresis hold
    elif st.extreme == WEAK and sign == DOWN and pi <= cfg.pct_lo + cfg.hyst_pct:
      label, extreme = WEAK_DOLLAR_DOWNTREND, WEAK                   # hysteresis hold
    elif sign == UP:
      label, extreme = DOLLAR_UPTREND, None
    else:
      label, extreme = DOLLAR_DOWNTREND, None
    st.sign, st.extreme = sign, extreme
    emit RegimeState(regime_id=R029, state=label, value=G,
                     estimator_version, data_vintage, computed_at=e.event_ts,
                     module_state=OK, min_lag_bars=cfg.min_lag_bars)
```

**Edge cases (handled above, not in prose only).**
- *Missing bars:* weekends/holidays have no DXY print — the vendor series masks non-trading days and the detector emits nothing for them (no interpolation, ever). A missing print on a trading day → `UNKNOWN` (F1); the state vector is untouched so the next good bar resumes.
- *Halts:* per the market-state table — `HALTED` → freeze, emit `UNKNOWN`; `AUCTION` → hold last label, `DEGRADED`; `CLOSED` → emit nothing, `OFF`.
- *Corporate actions:* not applicable — DXY is an index; splits/dividends do not exist for it [documented]. An ICE basket/methodology change is the index analogue → `DEGRADED` + re-validation (§R7).
- *Vendor history revision:* the 5-year percentile is recomputed on the new vintage, never cached across revisions (F5); labels stay `DEGRADED` until re-verified.
- *Stale series:* `computed_at` older than `3`× cadence → `UNKNOWN` (F4); recovery resumes on freshness — retroactive labels are never written.

### Calibration recipe (all thresholds — entry, exit, hysteresis)

No magic numbers: every threshold is fit on data and selected out-of-sample.

- **Data:** `≥ 6` years [example] of DXY daily closes from the licensed vendor = one `5`-year [example] trailing percentile window plus `≥ 1` year [example] of out-of-sample data. Suggested split [example]: fit on `2015-01-01`–`2023-12-31`, OOS on `2024-01-01`–`2025-12-31`, walk-forward in `1`-year [example] steps with a `1`-month [example] embargo between fit and evaluation windows (Meridian walk-forward + embargo invariant).
- **Grid [example]:** `pct_hi ∈ {0.75, 0.80, 0.85}`, `pct_lo ∈ {0.15, 0.20, 0.25}`, `hyst_pct ∈ {0.03, 0.05, 0.07}`, `deadband_pts ∈ {0.05, 0.10, 0.20}` index points.
- **Objective:** a regime is not a tradeable signal, so there is no Sharpe to maximize. Primary: minimize the annualized label-transition rate (whipsaws/year). Secondary [internal-est procedure]: maximize mutual information between the STRONG/WEAK label and the sign of next-`20`-day [example] commodity-carry reference returns.
- **OOS selection (overfit guard):** a config is accepted only if its OOS conditional-efficacy gap (gated-strategy return minus baseline, OOS) is `≥ 0.7×` [internal-est] its in-sample gap; configs that collapse OOS are rejected. Among accepted configs, pick the lowest OOS transition rate; ties go to the smaller hysteresis (simpler).
- **Re-cal cadence:** annually, or immediately after an ICE methodology/basket change. Bands are never re-tuned on `< 1` year [rule] of new data. Every re-cal is decision-logged and bumps `estimator_version`.
- **No ex-post selection (F5):** the window, grid, and objective are fixed before fitting; the fixture tape is frozen and never part of the calibration set.
