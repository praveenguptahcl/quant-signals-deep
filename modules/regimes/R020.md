  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; OI publishes T+1 — the label uses the latest published chain, never same-day OI).

  `label_ts > indicator_ts` for the earliest gated trade and that appending a

## §R1 Precise definition

GEX proxy [documented construction]: `GEX = Σ s_j·Γ·OI·100·S²·0.01` (dollars of dealer delta per 1% move); `s = +1` calls / `−1` puts under the standard dealer convention [documented]. Requires full-chain OI — sampled chains understate. This is a *proxy assuming* dealer positioning, never observed inventory.

## §R2 Exact calculation

$$\text{NetGEX} = \sum_{k,j} s_j\,\Gamma_{k,j}\, OI_{k,j}\,100\,S^2\,0.01 \quad\text{[documented]}$$

Worked example [documented Grok RB2, with verification flag]: raw signed `−$0.5M`; with `S = 100` the `×S²×0.01 (= 100)` factor gives `NetGEX ≈ −$50M` ⇒ short-gamma/amplifying proxy. (Grok's own text says '+$0.50 million' — the fixture uses the full formula and flags the inconsistency.) Sign is the regime [documented]; tolerance is on sign and quintile, not the dollar value [documented RB-list].

**Data inputs.** full option chain: Γ (or IVs + rates + tenor for BS gamma), OI, spot. Incomplete chain ⇒ incomplete proxy ⇒ null.

**Cadence.** daily (15:30 ET); intraday on event days.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `NetGEX > 0` | long_gamma (pinning — expect magnet toward high-OI strikes) | [documented] |
| `|NetGEX| small` | neutral | [example] |
| `NetGEX < 0` | short_gamma (amplifying — trend-day violence) | [documented] |

Sign is `[documented]`; magnitude bands must be in dollars for that underlier (no universal cutoff [documented]).

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Intraday mean-reversion / pinning | **amplifies then inverts** | improves in +GEX (dealers hedge *against* moves — free reversion flow); dies in −GEX (hedging *chases* moves — fades get run over) |
| Breakout | **amplifies then inverts** | mirror image — improves in −GEX |
| Short-vol / iron-fly | **amplifies then inverts** | improves in +GEX; dies in −GEX |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** needs full-chain OI (not sampled); publishes RSV tagged 'GEX proxy'.
- **Verifier:** recomputes with an independent greeks engine; tolerance on sign and quintile [documented RB-list].
- **Grok-Researcher:** proposes tenor weights; leads only.
- **Adversary:** checks the assumption is stated in every table; checks thin chains go null.
- **Gate:** rejects GEX presented as observed dealer inventory; rejects same-day OI lookahead.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Gamma positioning sets the intraday vol shape: the adjustment widens stop assumptions 2× [example] in short-gamma states and favors fade/pin execution in long-gamma states.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    adj['gex_proxy'] = True         # [documented] assumption tag
    if rsv['state'] == 'short_gamma':
        adj['stop_mult'] = 2.0        # [example] trend-day violence
        adj['fade_ok'] = False       # [default]
    elif rsv['state'] == 'long_gamma':
        adj['fade_ok'] = True        # [default] pinning regime
        adj['stop_mult'] = 1.0        # [default]
    else:
        adj['stop_mult'] = 1.0        # [default]
    return adj
```
