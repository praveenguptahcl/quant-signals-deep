### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; OI reflects
  end-of-day positions published the next business morning [unverified] — the
  label uses the latest *published* chain, never same-day OI).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

GEX proxy [documented construction]: `GEX = Σ s_j·Γ·OI·100·S²·0.01` (dollars of dealer delta per 1% move [documented]); `s = +1` calls / `−1` puts under the standard dealer convention [documented — SpotGamma published methodology, practitioner]. Requires full-chain OI — sampled chains understate. This is a *proxy assuming* dealer positioning, never observed inventory.

## §R2 Exact calculation

$$\text{NetGEX} = \sum_{k,j} s_j\,\Gamma_{k,j}\, OI_{k,j}\,100\,S^2\,0.01 \quad\text{[documented]}$$

Worked example [documented Grok RB2, with verification flag]: raw signed `−$0.5M`; with `S = 100` the `×S²×0.01 (= 100)` factor gives `NetGEX ≈ −$50M` ⇒ short-gamma/amplifying proxy. (Grok's own text says '+$0.50 million' [unverified] — the fixture uses the full formula and flags the inconsistency.) Sign is the regime [documented]; tolerance is on sign and quintile, not the dollar value [documented RB-list].

**Data inputs.** full option chain: Γ (or IVs + rates + tenor for BS gamma), OI, spot. Incomplete chain ⇒ incomplete proxy ⇒ null.

**Cadence.** daily (15:30 ET); intraday on event days.

**Threshold bands (sign core + hysteresis shell).** The sign is `[documented]`; magnitude bands must be in dollars for that underlier (no universal cutoff [documented]). The detector (§R2.4) wraps the sign in a calibrated hysteresis shell: enter band `enter_frac × trailing_scale`, exit band `exit_frac × trailing_scale`, flip confirmation over `persist_n` snapshots.

| Condition | Label | Tag |
|---|---|---|
| `NetGEX > 0` | long_gamma (pinning — expect magnet toward high-OI strikes) | [documented] |
| `|NetGEX| small` | neutral | [example] |
| `NetGEX < 0` | short_gamma (amplifying — trend-day violence) | [documented] |

### §R2.4 Normative detection pseudocode (one snapshot)

Pseudocode is normative; prose is commentary. The reference implementation is
`modules/tests/test_R020.py` (`SnapshotDetector.observe`); the fixtures pin it.

```
function observe(snapshot_rows, state, cfg, now_ns):
    # 0. Halt / auction: freeze. Committed label is HELD, module goes UNKNOWN (R0.6).
    if any(row.halt): return RegimeState(committed=state.committed, module_state=UNKNOWN,
                                        reason="halt_freeze")

    # 1. F1 validation — never interpolate.
    for row in snapshot_rows:
        require fields {strike, otype, gamma, oi, spot} present
        require gamma >= 0 and oi >= 0 (numeric); otype in {C, P}; spot > 0
        if gamma or oi missing (null): skip row; data_quality.skipped_rows += 1
        else if any check fails: return UNKNOWN(reason="F1_<check>")
    if every row skipped: return UNKNOWN(reason="F1_all_rows_skipped")
    if spot not uniform within 1e-9 [default]: return UNKNOWN(reason="F1_spot_mismatch")
    # oi = 0 rows are VALID (contribute 0); negative gamma/oi are INVALID.

    # 2. Warm-up: thin chain -> DEGRADED, label WITHHELD (committed unchanged).
    usable = rows with gamma and oi present
    if len(usable) < cfg.min_strikes (5 [default]):
        return RegimeState(committed=state.committed or "warming", value=nan,
                           module_state=DEGRADED, reason="thin_chain")

    # 3. Corporate-action guard: a spot jump with no adjustment calendar is
    #    indistinguishable from a bad print. Hold, do not flip.
    if state.prev_spot and |spot/state.prev_spot - 1| > cfg.corp_action_tol (0.20 [default]):
        return RegimeState(committed=state.committed, value=nan,
                           module_state=DEGRADED, reason="corp_action_hold")
        # action: reconcile against the corporate-action calendar, then re-arm.

    # 4. Indicator value.
    v = sum(s_j * gamma * oi * 100 * spot^2 * 0.01)   # $ delta per 1% move [documented]

    # 5. F2 bounds.
    if not (|v| <= 1e12 [default]): return UNKNOWN(reason="F2_out_of_bounds")

    # 6. Trailing scale + hysteresis bands.
    scale = max(|v| over last cfg.trailing_window (60 [default]) snapshots)
    if no history: scale = |v|                        # [default]
    if scale <= 0: scale = 1.0                        # degenerate guard [default]
    t_enter = cfg.enter_frac (0.20 [default]) * scale
    t_exit  = cfg.exit_frac  (0.10 [default]) * scale
    prev_raw = state.pending or state.committed
    if |v| < max(cfg.min_abs_net_gex (0.0 [default]), t_exit): raw = "neutral"
    elif v > +t_enter: raw = "long_gamma"
    elif v < -t_enter: raw = "short_gamma"
    else: raw = prev_raw if prev_raw in labels else "neutral"   # deadband hold

    # 7. Persist / confirm (debounce flip-flop). First label commits immediately [default].
    if state.committed is None: commit raw
    elif raw == state.committed: pending = None
    elif raw == state.pending:
        pending_n += 1
        if pending_n >= cfg.persist_n (2 [default]): commit raw
    else: pending, pending_n = raw, 1

    append |v| to trailing scale; prev_spot = spot

    # 8. F3 dual-estimator agreement (gated): the Verifier recomputes on the
    #    chain minus the farthest-from-spot strike. Sign agreement is required
    #    ONLY when |v| >= t_enter [default]; below it the Verifier defers to the
    #    Sentinel's hysteresis state. Disagreement -> UNKNOWN.
    if |v| >= t_enter and sign(verifier_v) != sign(v):
        return RegimeState(committed=state.committed, value=v,
                           module_state=UNKNOWN, reason="F3_dual_disagree")

    # 9. F4 staleness.
    if now_ns - computed_at > 3 * cadence [default]:
        return UNKNOWN(reason="F4_stale")

    # 10. F5: ex-post period selection without a pre-registered definition raises.
    return RegimeState(regime_id="R020", state=committed, value=v,
                       estimator_version="1.1.0", data_vintage=<chain vintage>,
                       computed_at=snapshot event_ts, module_state=OK,
                       raw_state=raw, data_quality={skipped_rows})
```

Edge cases handled: missing bars → gap policy mask, staleness watchdog fires
(F4); halts → freeze; corporate actions → DEGRADED hold; thin chains →
DEGRADED withhold; invalid rows → UNKNOWN; all-invalid → UNKNOWN.

### §R2.5 Calibration recipe (no magic numbers)

Every threshold above is a starting point [default]; the recipe below is how a
quant dev turns them into per-underlier values.

1. **Objective.** Maximize the cost-adjusted overlay P&L (or DSR of
   regime-conditioned strategy returns) out-of-sample [example].
2. **Data.** Daily `15:30 ET` full-chain snapshots, ≥ `2` years including ≥ `1`
   stress episode [example]. OI column = latest *published* chain (T+1
   publication [unverified]) — never same-day OI.
3. **Grid** [example]: `enter_frac` ∈ {0.05, 0.10, 0.15, 0.20, 0.30, 0.50};
   `exit_frac` ∈ {0.00, 0.05, 0.10, 0.20}; `persist_n` ∈ {1, 2, 3, 5};
   `trailing_window` ∈ {30, 60, 120}; `min_abs_net_gex` per underlier in
   dollars (start `0.0` [default], set to a percentile of trailing `|v|`).
4. **Selection.** Walk-forward with embargo ≥ `1` bar [default]; argmax OOS
   objective; disclose the full grid + runner-up (selection disclosure);
   tie-break toward fewer flips [default].
5. **Re-cal cadence.** Quarterly [default], or on calibration-drift alert
   (flip rate > `2`× trailing [example]) → notify, re-run recipe.
6. **Record.** Chosen values + grid + OOS metric go in the run's decision log;
   `1.0.0`→`1.1.0` table values remain the documented starting points.

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** needs full-chain OI (not sampled); publishes RSV tagged 'GEX proxy'.
- **Verifier:** recomputes with an independent greeks engine on the chain minus the farthest-from-spot strike; sign agreement required only at/above the dual floor (`t_enter` [default]).
- **Grok-Researcher:** proposes tenor weights; leads only.
- **Adversary:** checks the assumption is stated in every table; checks thin chains go null.
- **Gate:** rejects GEX presented as observed dealer inventory; rejects same-day OI lookahead.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

Rationale: `short_gamma` — trend-day violence means hedging *chases* moves, so
realized impact and effective spreads widen [example]; `long_gamma` — pinning
flow absorbs prints, impact compresses [example]. Degradation is checked
*first*: an `UNKNOWN` label is restrictive regardless of the last committed
state (F1 doctrine); `trade_ok = False` forces downstream to stand down or
halve [default].

```python
def cost_adjustment(rsv, base_bps):
    """Regime state -> cost-function adjustment. base_bps: dict(spread_bps,
    fees_bps, borrow_bps, impact_bps). Returns (adjusted, meta)."""
    mult = {"spread": 1.0, "fees": 1.0, "borrow": 1.0, "impact": 1.0}  # [default]
    meta = {"trade_ok": True, "fade_ok": True, "stop_mult": 1.0}      # [default]
    st, mstate = (rsv.state, rsv.module_state) if isinstance(rsv, RegimeState) \
        else (rsv, "OK")
    if mstate == "UNKNOWN":                       # restrictive first [default]
        mult.update(impact=2.0, spread=1.25)      # [default]
        meta.update(trade_ok=False, fade_ok=False, stop_mult=2.0)  # [default]
    elif mstate in ("DEGRADED", "OFF"):           # [default]
        mult.update(impact=1.5)                   # [default]
        meta.update(trade_ok=False, fade_ok=False, stop_mult=1.5)  # [default]
    elif st == "short_gamma":
        mult.update(impact=1.50, spread=1.25)     # [example]
        meta.update(trade_ok=True, fade_ok=False, stop_mult=2.0)   # [example]/[default]
    elif st == "long_gamma":
        mult.update(impact=0.80)                  # [example]
        meta.update(trade_ok=True, fade_ok=True, stop_mult=1.0)    # [default]
    elif st == "neutral":
        meta.update(trade_ok=True, fade_ok=True, stop_mult=1.0)    # [default]
    else:  # unmapped label with OK state: restrictive (should not occur)
        mult.update(impact=1.5)                   # [default]
        meta.update(trade_ok=False, fade_ok=False, stop_mult=1.5)  # [default]
    adjusted = {k: base_bps[k] * mult[k] for k in ("spread", "fees", "borrow", "impact")}
    return adjusted, meta
```

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | OI-as-inventory claim → detect: prose/table says 'dealer inventory' → action: Gate rejects promotion → recovery: relabel 'GEX proxy' everywhere | `check: proxy labeled` |
| 2 | Sampled chain → detect: strikes < listed coverage → action: null the proxy (`DEGRADED`, label withheld) → recovery: re-ingest full chain | `check: full chain` |
| 3 | Same-day OI → detect: OI `asof` dated today → action: reject (lookahead) → recovery: fall back to latest published T+1 chain | `check: T+1 OI` |
| 4 | Sign flip (customer call-buying regime) → detect: convention-break evidence (flow data) → action: null or invert under review; default null → recovery: recalibrate convention on customer-flow data | `check: convention holds` |
| 5 | Thin chain (< `5` strikes [default]) → detect: `len < min_strikes` → action: `DEGRADED`, label withheld, committed held → recovery: next full snapshot re-arms automatically | `check: min_strikes` |
| 6 | Invalid input (negative gamma, bad otype, spot mismatch) → detect: row validation F1 → action: `UNKNOWN`, never interpolate → recovery: auto on next clean snapshot | `check: F1 clean` |
| 7 | Halt/auction → detect: halt flag or market-state event → action: freeze — committed held, module `UNKNOWN` (R0.6); discard contributions across reopen → recovery: resume on first clean snapshot | `check: freeze honored` |
| 8 | Corporate action (spot jump > `0.20` [default]) → detect: jump vs previous spot → action: `DEGRADED` hold → recovery: reconcile against adjustment calendar, then re-arm | `check: jump reconciled` |
| 9 | Stale OI (> `3`× cadence [default]) → detect: F4 watchdog → action: `UNKNOWN` → recovery: fresh chain re-arms | `check: TTL` |
| 10 | Dual disagreement (verifier sign ≠ sentinel sign at/above dual floor) → detect: F3 → action: `UNKNOWN` → recovery: investigate chain quality (often a bad farthest-strike print) | `check: F3 agree` |
| 11 | Calibration drift (flip rate > `2`× trailing [example]) → detect: flip-rate monitor → action: notify, schedule re-cal → recovery: §R2.5 recipe | `check: drift reviewed` |

Honest `DEGRADED`/`UNKNOWN` behavior: `DEGRADED` withholds or holds the label
but keeps the committed state vector intact for audit; `UNKNOWN` is
restrictive — downstream halves size / widens stops / stands down and the cost
interface gates trading off (`trade_ok = False` [default]). Neither state is
ever treated as benign.
