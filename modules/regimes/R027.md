## §R2 Precise definition

A rolling score of whether activity data have been beating or missing consensus. The industry benchmark is the Citigroup Economic Surprise Index (CESI): weighted historical standard deviations of data surprises (actual releases vs Bloomberg survey median), with sign convention CESI > 0 meaning data on balance beating consensus [documented sign convention]. Citi's exact weights and decay are proprietary; this module ships a faithful public clone with weights fixed ex ante.

### §R2.1 Normative detection pseudocode

Pseudocode is normative; prose is commentary. `detect(state, events, cfg)`
processes canonical Events in ascending `event_ts` and emits one `RegimeState`
per event (Lag contract: value/state at `t` use only inputs with ts `≤ t`).

```
# R0: config invariant (fail fast, never silently clamp)
assert cfg.enter_pos > cfg.exit_pos >= 0 >= cfg.exit_neg > cfg.enter_neg  # [rule]
assert cfg.lam > 0 and cfg.min_lag_bars >= 1                              # [rule]

releases = []            # (weight, days_ago, z) — module-owned history
prev = "NEUTRAL"         # hysteresis memory; start neutral [default]

for e in events:                                    # ascending event_ts [rule]
    ts = e.event_ts
    if e.market_state == "HALTED":                  # R0.5
        emit {state: prev, value: NaN, module_state: UNKNOWN}   # frozen, F1
        continue                                    # history NOT extended
    if e.market_state == "AUCTION":                 # R0.5
        emit {state: prev, value: NaN, module_state: DEGRADED}   # held
        continue
    z = parse(e.z_i) if finite else (e.actual - e.consensus)/e.sigma
    w = parse(e.weight); d = parse(e.days_ago)
    if not (finite(z) and finite(w) and finite(d) and w >= 0 and d >= 0):
        emit {state: UNKNOWN, value: NaN, module_state: UNKNOWN} # F2: SKIP row
        continue                        # never interpolate, never fold in [rule]
    if e.event_ts < last_emitted_ts and e not in releases:
        flag = DEGRADED                  # L4: late arrival, one bar [default]
    else:
        flag = OK
    releases.append((w, d, z))
    value = fsum(w * exp(-cfg.lam * d) * z for releases)   # causal at t [rule]
    if not finite(value):
        emit {state: UNKNOWN, value: value, module_state: UNKNOWN}  # F2
        continue
    # --- hysteresis state machine (thresholds from Config, §R3.1) ---
    if prev == "UPSIDE":
        prev = "DOWNSIDE" if value <= cfg.enter_neg else \
               "NEUTRAL"  if value <  cfg.exit_pos  else "UPSIDE"
    elif prev == "DOWNSIDE":
        prev = "UPSIDE"   if value >= cfg.enter_pos else \
               "NEUTRAL"  if value >  cfg.exit_neg  else "DOWNSIDE"
    else:  # NEUTRAL (also the resume state after UNKNOWN — §R7.1)
        prev = "UPSIDE"   if value >= cfg.enter_pos else \
               "DOWNSIDE" if value <= cfg.enter_neg else "NEUTRAL"
    emit {regime_id: R027, state: prev, value: value,
          estimator_version: "1.1.0", data_vintage: vintage,
          computed_at: ts, module_state: flag, min_lag_bars: cfg.min_lag_bars}
```

Edge-case rules (all enforced in `modules/tests/test_R027.py`):

- **E1 missing release / empty feed** → single `UNKNOWN` (F1). No release in
  `30` days [example] → staleness watchdog expires the label to `UNKNOWN` (F4);
  recovery resumes from `NEUTRAL` [default] — hysteresis memory is cleared, so a
  stale UPSIDE cannot whipsaw back on.
- **E2 non-finite z / bad weight / negative days_ago** → that event is
  `UNKNOWN` and SKIPPED: it is not folded into `releases`, and hysteresis
  memory (`prev`) is preserved across the skip (F2). Folding a NaN would poison
  every later value — asserted in `test_f2_nan_row_skipped_not_folded_in`.
- **E3 halt / auction** → per R0.5 table (freeze + `UNKNOWN` / hold + `DEGRADED`).
- **E4 late / out-of-order release** (`event_ts` older than the last emitted
  label): folded into history, CURRENT value/state recomputed deterministically;
  already-emitted labels are append-only and never rewritten [rule]; the
  recomputed bar is flagged `DEGRADED` for one bar [default] and decision-logged.
- **E5 revisions**: use first-release vintages only (ALFRED / PIT feeds
  [documented]); later revisions are ignored unless a vendor errata forces a
  re-pin, which requires a changelog entry (F5).
- **E6 corporate actions**: not applicable — inputs are macro statistics, not
  securities prices [documented by construction]. No splits/dividends handling.
- **E7 σ estimation**: per-release surprise σ over trailing `sigma_lookback_days`
  = `730` [example] of `(actual − consensus)`; fewer than `sigma_min_obs` =
  `30` [example] observations → that release is excluded and its event is
  `UNKNOWN` [default]. σ is computed on data `≤ t` only (no lookahead) [rule].
- **E8 exact-zero boundary**: `value == 0.0` → `NEUTRAL` from any prior state
  (`0.0 < exit_pos`, `0.0 > exit_neg`) — pinned in
  `test_boundary_exact_zero_is_neutral`.

## §R3 Exact calculation

Public clone (Citi's exact weights/decay are proprietary):

$$\mathrm{CESI}_t = \sum_{k} w_k\, e^{-\lambda \Delta t_k}\, \frac{x_k - c_k}{\sigma_k}$$

`x_k, c_k` actual/consensus in native units; `σ_k` that release's historical
surprise SD (trailing `730` days [example], min `30` obs [example] — §R2.1 E7);
`w_k` fixed ex-ante weights (sha256-pinned weight file, F5); `Δt_k` days since
release `k`; `λ = 1/45` per day [example] (≈3-month memory). Worked check
(`modules/fixtures/R027_tape.csv` rows 1–2, weights as filed): Claims `+1.2`
(58d, w=`0.15`), Retail `+0.9` (51d, w=`0.20`) →
CESI = `0.15·e^(−58/45)·1.2 + 0.20·e^(−51/45)·0.9` ≈ `0.1076` [measured fixture]
→ crosses `enter_pos` = `0.10` [example] → UPSIDE entry (row 1 alone gives
`0.0496` → NEUTRAL). Hand-verified to `1e-16` against independent arithmetic;
asserted in `test_spot_handcheck`.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Economic calendar (NFP, ISM, retail sales, claims, GDP); consensus medians (Bloomberg survey or vendor economist-average); per-release surprise σ; fixed weight file.

**Cadence.** Daily; recomputed on each release.

**Threshold bands (Config-driven, hysteresis).**

| Band | State | Tag |
|---|---|---|
| `value ≥ enter_pos` (`0.10`) | enter/hold UPSIDE | [example] |
| `value ≤ enter_neg` (`−0.10`) | enter/hold DOWNSIDE | [example] |
| `exit_pos ≤ value < enter_pos` (`0.02–0.10`) | hysteresis: hold prior state | [example] |
| `enter_neg < value ≤ exit_neg` (`−0.10–−0.02`) | hysteresis: hold prior state | [example] |
| `exit_neg < value < exit_pos` | NEUTRAL | [example] |
| `value == 0.0` | NEUTRAL (boundary pin) | [example] |

The official CESI print lives on its own scale (chart readings of roughly
`−160` to `+300` are [unverified] — see §R10). Classify the official print by
its documented sign convention only (`> 0` = beating consensus [documented]);
NEVER apply the toy-clone thresholds above to the official print [rule].

### §R3.1 Threshold-calibration recipe

No magic numbers ship to production. Calibrate `enter_pos/exit_pos/enter_neg/exit_neg`
(and optionally `λ`) per traded universe with this recipe; record the chosen
values, grid, and OOS result in the decision log.

1. **Data.** Vendor surprise history: actual, consensus, σ per release, ≥`10`
   years [example] so σ estimates (trailing `730`d [example]) are stable.
   Freeze the weight file ex ante (Scotti-style factor-contribution weights
   [documented] or equal-risk [example]); weights are NOT part of the grid (F5).
2. **Grid** [example — widen if OOS is flat]:
   `enter ∈ {0.05, 0.10, 0.15, 0.20}`, `exit = enter × {0.1, 0.2, 0.5}`,
   `λ ∈ {1/30, 1/45, 1/60, 1/90}` per day; neg bands mirror pos by default
   (asymmetric bands allowed only with a documented mechanism).
3. **Walk-forward OOS.** Expanding window: `5`y train / `1`y test [example],
   stepped yearly; embargo = `21` trading days [example] between train end and
   test start (macro releases cluster — the embargo must exceed the release
   cycle). Indicator at `t` uses inputs `≤ t`; labels gate the traded
   strategy only at `t+1`+ (Lag contract).
4. **Selection criterion (OOS only, never in-sample)** [rule]: maximize the
   regime-conditional separation
   `Δ = mean(next-20d cyclical−defensive spread | UPSIDE) − mean(… | DOWNSIDE)`,
   t-stat with Newey-West (`20` lags [example]); require `|t| ≥ 2.0` [example]
   on OOS. Alternative: maximize the gated strategy's OOS information ratio.
5. **Multiplicity disclosure** [rule]: report the grid size (default grid =
   `96` variants [example]); apply a haircut (DSR or Bonferroni-style) before
   claiming significance. Variant count and haircut are decision-logged.
6. **Re-calibration cadence**: annual [default], or immediately when the vendor
   changes release coverage/consensus methodology — the module goes `UNKNOWN`
   until re-calibrated, with a changelog errata entry [rule].
7. **Lock-in**: write the winning thresholds into Config with status updated
   from `example` → `default`, pin the OOS report hash in §R9, and re-run
   `test_cmd` — the fixture's `[example]` bands are then replaced, never edited
   in place without the recipe.

The honest indirect channel: R027 gates *sizing/tilt*, which changes `notional`
— cost moves through the `notional` argument, never through the multipliers
[rule]. `fee_add_bps` is `0.0` [default] in every state: a regime label never
changes the fee schedule.

**Measuring a state-conditional cost shift (recipe, not a claim).** Before any
multiplier may differ from `1.0`, run: (1) collect ≥`500` fills [example] per
state (UPSIDE/DOWNSIDE/NEUTRAL) on the same venue+side+urgency mix; (2) compute
realized slippage vs arrival in bps per fill; (3) test
`mean(slip|DOWNSIDE) − mean(slip|NEUTRAL) ≠ 0` with clustered SEs by day;
(4) require significance after multiplicity control across the 4 components and
an economic magnitude ≥ `0.5` bps [example] to promote the multiplier from
`[default]` to `[measured]`, version the record, and log the study in §R9.
Until then the identity record stands — inventing a cost tilt without this
evidence is a validation failure.
