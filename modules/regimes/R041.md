## §R2 Precise definition

Variance decomposition of close-to-close returns into overnight and intraday components: r_cc = r_ON + r_ID with r_ON = open/prev-close − 1 and r_ID = close/open − 1. The overnight share s = σ²_ON / σ²_cc (with σ²_cc = σ²_ON + σ²_ID + 2·Cov). Sample variances (ddof = 1) throughout. Use total-return-adjusted series — corporate actions corrupt the close/open alignment silently.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function session_returns(bar):                       # bar: canonical daily bar, total-return-adjusted
    r_on = bar.open / bar.prev_close_adj - 1         # overnight: close(t-1) -> open(t)
    r_id = bar.close / bar.open - 1                  # intraday:  open(t)   -> close(t)
    return (r_on, r_id)

function hysteresis(prev, s, cfg):                   # normative transition table
    HI, LO, H = cfg.on_hi, cfg.on_lo, cfg.hyst       # [example]/[default] 0.60/0.40/0.05; calibrate per §R6.1
    if prev == ON_DOMINANT:
        if s <= LO:      return ID_DOMINANT           # direct flip across the dead band
        if s < HI - H:   return BALANCED              # exit strictly below HI-H (float 0.5499999999999999 [default])
        return ON_DOMINANT                            # hold inside the hysteresis band
    if prev == ID_DOMINANT:
        if s >= HI:      return ON_DOMINANT
        if s > LO + H:   return BALANCED              # exit strictly above LO+H
        return ID_DOMINANT
    if s >= HI: return ON_DOMINANT                    # cold entry from BALANCED/UNKNOWN
    if s <= LO: return ID_DOMINANT
    return BALANCED

function detect(state, events, cfg) -> list[RegimeState]:
    for e in events ascending by event_ts:
        ts = e.event_ts
        assert e.event_ts > state.prev_ts else emit(UNKNOWN, ts)   # F1: strictly increasing, no reorder
        state.prev_ts = e.event_ts
        if e.market_state == HALTED:
            emit(UNKNOWN, ts); continue                # freeze: no contributions across reopen (F1)
        if e.adjustment != "total_return" or e.type == SPLIT_UNADJUSTED:
            emit(UNKNOWN, ts); continue                # Gate: reject unadjusted series — never a fake gap
        (r_on, r_id) = session_returns(e)
        if not (finite(r_on) and finite(r_id)):
            emit(UNKNOWN, ts); continue                # F1/F2: missing or non-finite -> UNKNOWN, never interpolate
        state.window.append((r_on, r_id))
        state.window = state.window[-cfg.window_days:]  # rolling [default] 60; fixtures use 4 [example]
        if len(state.window) < 2:
            emit(UNKNOWN, ts); continue                # need >= 2 bars for ddof=1 variance
        (vo, vi, cv) = sample_var_cov(state.window)    # ddof = 1 [documented]
        vcc = vo + vi + 2*cv
        if not finite(vcc) or vcc <= 0:
            emit(UNKNOWN, ts); continue                # F2: degenerate variance
        s = vo / vcc
        state.label = hysteresis(state.label, s, cfg)
        emit(OK(state.label, s, ts))
    # Lag contract: a label finalized at t gates signals only for trades at t+1 or later.
```

**Edge-case behavior table** (normative — pinned by `R041_edge_*` fixtures):

| Edge case | Detection | Action | Recovery |
|---|---|---|---|
| Missing bar (no open/close) | non-finite or absent session return | `UNKNOWN` for that bar; excluded from window, never interpolated | next valid bar resumes `OK` automatically |
| Non-finite return | `not finite(r_on, r_id)` | `UNKNOWN` (F1/F2); excluded from window | same as missing bar |
| Halted day | `market_state == HALTED` | `UNKNOWN`; freeze — the bar contributes nothing across reopen | first post-reopen bar resumes; the reopen gap itself is a valid overnight return |
| Unadjusted corporate action | bar flagged `SPLIT_UNADJUSTED` or `adjustment != "total_return"` | `UNKNOWN`; Gate-rejected — the bar never enters the window, so an unadjusted split can never print a fake `ON_DOMINANT` gap | manual: verify the adjusted series, replay fixture, re-arm |
| `σ²_cc ≤ 0` or non-finite | variance guard | `UNKNOWN` (F2) + page | investigate feed; do not trade the label |
| `< 2` valid bars in window | window length guard | `UNKNOWN` | accumulates naturally as bars arrive |

## §R3 Exact calculation

Log or simple returns, sample (ddof = 1) variances over the window:

$$\sigma^2_{cc} = \sigma^2_{ON} + \sigma^2_{ID} + 2\,\mathrm{Cov}(r_{ON}, r_{ID}), \qquad
s_t = \frac{\sigma^2_{ON,t}}{\sigma^2_{cc,t}}$$

Hand-verified panel (5 days [example]):
r_ON = [0.004, 0.001, 0.005, −0.002, 0.003], r_ID = [0.003, 0.002, 0.004, 0.001, 0.002] [example]
→ `σ²_ON = 7.7e-6`, `σ²_ID = 1.3e-6`, `Cov = 2.9e-6`, `σ²_cc = 1.48e-5`
→ `s ≈ 0.5203` → BALANCED. (Grok's stated `0.626` for its own example could not
be reproduced from the data supplied with it — independently recomputed `0.7072`;
neither figure is used here. This module's panel is synthetic [example].)

*Formula tag: [documented] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Daily open and prior close (total-return adjusted); estimation window.

**Cadence.** Daily.

**Threshold bands (hysteresis — normative).**

| Transition | Condition on `s` | Result | Tag |
|---|---|---|---|
| Cold entry to ON | `s ≥ on_hi = 0.60` | ON_DOMINANT | [example] |
| Exit from ON | `s < on_hi − hyst = 0.55` (float `0.5499999999999999`) | BALANCED (or ID_DOMINANT on direct flip) | [default] exit edge |
| Cold entry to ID | `s ≤ on_lo = 0.40` | ID_DOMINANT | [example] |
| Exit from ID | `s > on_lo + hyst = 0.45` | BALANCED (or ON_DOMINANT on direct flip) | [default] exit edge |
| Otherwise | inside the dead band | hold previous label | [default] |

While ON_DOMINANT, gated intraday-only strategies size down or stand down
(§R4); while ID_DOMINANT, overnight-hold sizing steps back. The dead band
(`hyst = 0.05` [default]) exists so a label flickering at `s ≈ 0.60` does not
whipsaw gated strategies — every threshold crossing inside the band is a
no-op by construction. Recalibrate every `[example]`-tagged band per
instrument per §R6.1 before production use.

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when |

**Which components scale, and why.** Only the **impact** component scales, and
only in ON_DOMINANT: when the overnight share is high, the opening print
absorbs the accumulated overnight information, so market impact estimated for
open-auction / first-`30`-min [example] executions is multiplied by
`impact_mult`. Spread, borrow, and fees are untouched by this regime: the
spread at the open is a venue microstructure input, not a session-attribution
output, and this module has no borrow signal — scaling them would be a magic
number with no mechanism.

**Application rule (normative).**

```
adjusted = apply_cost_adjustment(label, cost_inputs)   # cost_inputs = the 4-component stack
    feed into the strategy's expected_cost_bps(notional, adv_pct, venue, side, urgency)
adjusted.impact_bps = cost_inputs.impact_bps * impact_mult[label]   # only this line is regime-dependent
```

**Calibrating `impact_mult` (normative).** Default `1.2` [example] is a
placeholder. Per venue: `impact_mult = mean(realized open-auction slippage in
bps) / mean(modeled impact in bps)` over the trailing `63` days [default],
re-estimated monthly [default]; freeze the value if it stays within
`0.9–1.3` [default] across two consecutive re-estimations; page if it exits
`0.7–1.6` [default] (the venue's open microstructure changed — re-verify the
fill model). The record is versioned with `estimator_version` and every
application is decision-logged (Appendix g v1.0.0).

### §R6.1 Threshold / hysteresis / window calibration procedure (normative)

Defaults are starting points, not fitted values. Calibrate per symbol — or per
ADV-decile bucket for small caps — never pooled across buckets [default].

1. **Data:** `≥ 2`y [default] of vendor total-return-adjusted daily OHLC;
   `≥ 500` bars [default] per calibration unit. The ingest gate asserts
   `series.adjustment == "total_return"` (§R0.3).
2. **Objective (normative):** maximize walk-forward *state separation*
   `S = (E[s|ON_DOMINANT] − E[s|ID_DOMINANT]) / σ_pooled` on the test fold,
   subject to: each extreme state occupies `≥ 10`% of test days [default]
   (kills degenerate thresholds that never fire), and the label flip-rate is
   `≤ 8` flips per `100` bars [default] (this is the constraint hysteresis is
   there to satisfy).
3. **Grid:** `window_days ∈ {30, 60, 90, 120}` [example];
   `on_hi ∈ {0.55, 0.60, 0.65, 0.70}` [example];
   `on_lo ∈ {0.30, 0.35, 0.40, 0.45}` [example];
   `hyst ∈ {0.03, 0.05, 0.08}` [example].
4. **Walk-forward:** train `252`d [default], embargo `5`d [default], test `63`d
   [default]; roll quarterly [default].
5. **OOS selection:** accept a re-fit only if test `S ≥ 0.8 ×` train `S`
   [default] and per-state occupancy shifts `≤ 10`pp [default] train→test.
   Reject silently-failing re-fits — keep the previous parameters.
6. **Re-cal cadence:** quarterly [default]; sooner if the live flip-rate
   exceeds `2`× the calibrated flip-rate [default] (the session structure
   changed — see §R7 failure mode 6).
7. **Sensitivity freeze rule:** perturb `hyst` by `±0.02` [default] around the
   chosen point; freeze any parameter whose flip-rate or occupancy moves
   `< 15`% [default], re-grid the rest. `on_hi` is the highest-sensitivity
   knob (ON occupancy ≈ linear in threshold over the calibrated range
   [internal-est]); `window_days` mainly smooths the label.
8. **Anti-overfit:** never calibrate a single ticker on `< 1`y [default];
   bucket thin names by ADV decile. Thresholds mined on `1` month overfit —
   require the OOS selection rule (5) to pass on two consecutive quarterly
   rolls [default] before the re-fit goes live.
