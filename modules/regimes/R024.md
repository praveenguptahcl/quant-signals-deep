### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; strip as of t; the label is an expectation, not a realized policy).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade, that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`,
  and that replacing the hysteresis FSM with single-threshold relabeling
  fails the transition-sequence test.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

P(+25bp) = (implied EFFR_eom − starting EFFR)/0.25 [documented construction — the CME FedWatch binary formula]. The full production form adds meeting-day weighting per the CME methodology (N/M day-weighting [documented]); the binary block is the prototype simplification. Cross-check: 3-obs average implied path; absolute tolerance `0.15` [default]. Compute from the ZQ strip — never scrape FedWatch [documented].

## §R2 Exact calculation

$$P(+25bp) = \frac{\text{implied EFFR}_{eom} - \text{starting EFFR}}{0.25} \quad\text{[documented]}$$

Worked example [documented construction]: implied `4.50%`, starting `4.33%` → `(0.17)/0.25 = 0.68 = 68%` ⇒ hike_biased.

**Data inputs.** ZQ futures strip → implied end-of-month EFFR (`100 − settle_price` [documented quote convention]); starting EFFR (FRED `DFF`; `"."` rows dropped, never interpolated [documented marker]). Contract identity via the strip builder: front = earliest contract month with `last_trading_day ≥ event_ts` (last trading day = last business day of the delivery month [documented]); expired months never contribute — the roll is silent by construction and pinned by test 14.

**Cadence.** daily (intraday on FOMC days only at the real-time tier).

### R2.1 Normative detection pseudocode

The pseudocode is normative; prose is commentary. Every guard in the prose
appears below.

```
function DETECT(state, events, cfg):
    # --- F5: ex-post period selection guard
    if selecting_periods and not preregistered_definition:
        raise RegimeMiningError

    bars = [e for e in events if e.type == BAR]          # CORPORATE_ACTION ignored (§R2.3)
    if bars is empty:
        return RSV(state="missing", value=NaN, module_state=UNKNOWN)     # F1
    for b in bars:                                       # F1 field validity
        require 0 <= b.effr_start <= 20 and 0 <= b.effr_implied <= 20
        on violation: return RSV("invalid", NaN, UNKNOWN)                # never interpolate
    market = market_state(events)
    if market == HALTED:
        return RSV(last_label, last_value, UNKNOWN)     # freeze; §R0.6

    # --- causal walk: value + hysteresis FSM, newest bar last
    prev = state.prev_label or "on_hold"
    for b in bars (causal order):
        p = (b.effr_implied - b.effr_start) / 0.25       # normative §R2 formula
        prev = HYSTERESIS(prev, p, cfg)                 # §R2.2; no single-threshold relabel
    ts = newest(bars).event_ts

    # --- F2 bounds
    if not (isfinite(p) and -1.5 <= p <= 1.5):           # [default] mathematical bounds
        return RSV("out_of_bounds", p, UNKNOWN)

    # --- F3 dual-estimator agreement (one-shot at the newest bar, §R4)
    q = (mean(last 3 bars' effr_implied) - newest.effr_start) / 0.25
    if not (isfinite(q) and |p - q| <= cfg.dual_tol):    # dual_tol 0.15 [default]
        return RSV(prev, p, UNKNOWN)

    # --- warm-up: insufficient lookback
    if len(bars) < cfg.min_bars:                        # min_bars 3 [default]
        return RSV("warming", p, DEGRADED)              # label withheld, never guessed

    # --- F4 staleness
    now = clock_now() or (ts + cadence)
    if now - ts > 3 * cadence:                          # 3x cadence [default]
        return RSV(prev, p, UNKNOWN)

    # --- churn guard: whipsaw detection
    flips = count(label changes in last cfg.churn_window)  # window 5 [default]
    if flips >= cfg.churn_max_flips:                    # 2 [default]
        widen exits by cfg.churn_widen (0.05 [default]); log
        return RSV(prev, p, DEGRADED)

    state.prev_label = prev
    return RSV(prev, p, OK, computed_at=ts,
               rsv_effr_level=newest.effr_implied,     # absolute EFFR for §R5
               rsv_fomc_window=(ts within fomc_window_days of a meeting))  # 3 [default]
```

### R2.2 Hysteresis FSM (entry vs exit bands)

Single-threshold relabeling churns the label on boundary noise; the FSM
requires a full entry threshold to engage a bias and a strictly inside exit
band to release it. Boundaries are **inclusive** (pinned by test 11).

| From | Condition on P | To |
|---|---|---|
| on_hold | `P ≥ 0.6` [default] | hike_biased |
| on_hold | `P ≤ −0.2` [default] | cut_biased |
| on_hold | otherwise | on_hold |
| hike_biased | `P ≤ 0.45` [default] and `P > −0.2` | on_hold |
| hike_biased | `P ≤ −0.2` [default] (cut entry) | cut_biased |
| hike_biased | otherwise | hike_biased (sticky) |
| cut_biased | `P ≥ −0.05` [default] and `P < 0.6` | on_hold |
| cut_biased | `P ≥ 0.6` [default] (hike entry) | hike_biased |
| cut_biased | otherwise | cut_biased (sticky) |

Threshold bands.

| Condition | Label | Tag |
|---|---|---|
| entry `P ≥ 0.6` / exit `P ≤ 0.45` | hike_biased (duration underweight) | [default] |
| entry `P ≤ −0.2` / exit `P ≥ −0.05` | cut_biased (duration overweight) | [default] |
| otherwise | on_hold | [default] |

### R2.3 Edge cases

- **Missing bars:** mask, never interpolate. Labels exist only for present
  bars; each is stamped at its own `event_ts`. FRED `"."` rows are dropped
  upstream [documented marker].
- **Halts:** freeze per the §R0.6 market-state table; discard contributions
  across reopen (no backfill of the gap into the label).
- **Corporate actions:** futures have none — dividends/splits are n/a for ZQ.
  Any `CORPORATE_ACTION` record in the event stream is filtered before the
  walk and cannot move the label (test 15). Expiry is not a corporate action:
  it is handled by the strip builder.
- **Contract roll:** handled by `select_front` (§R0.3); the roll is silent —
  implied-EFFR continuity `|Δp| ≤ 1e-9` [default] is asserted in the test.
- **EFFR revision:** an `asof_ts > event_ts` restatement never rewrites a
  past label; the original label stands in the audit log and the revision is
  appended as a new observation.

### R2.4 Calibration recipe (all thresholds — no magic numbers)

The `[default]` thresholds above are starting values. Origin: `hike_p_entry
0.6` ⇔ `15`bp priced-in via the CME binary formula [documented arithmetic;
the `15`bp choice itself is [default]); `cut_p_entry −0.2` ⇔ `5`bp of cut
priced-in — the asymmetry is a modeling choice [internal-est], re-estimated
by this recipe.

1. **Data:** ≥ `5` years or ≥ `40` FOMC meetings [default] of (ZQ front-month
   implied EOM EFFR, FRED DFF, realized meeting decision from Fed meeting
   statements). Vintage-tag every observation; revisions appended, never
   overwritten.
2. **Grid:** `hike_p_entry ∈ {0.5, 0.55, 0.6, 0.65, 0.7}` [default];
   `cut_p_entry ∈ {−0.3, −0.25, −0.2, −0.15}` [default];
   exits = entry ∓ `{0.1, 0.15, 0.2}` [default] (hike) / ± same (cut).
3. **Objective:** maximize OOS label-agreement F1 against the realized
   3-class outcome (hike/hold/cut) minus `0.5` × (label flips per meeting)
   [default] — the churn penalty prices whipsaw directly.
4. **OOS selection:** walk-forward over meetings — train on the first `60`%,
   validate on the next `20`%, confirm on the final `20`% [default]; embargo:
   drop meetings ±`1` around each train/test boundary [default]. Select the
   highest-objective grid point on the validation fold; the test fold only
   confirms (no re-selection).
5. **Re-cal cadence:** annually, or after `12` FOMC meetings [default], or
   when the trailing-`12`-month label churn doubles [default] — whichever
   comes first. Re-cal is a config change with a changelog entry, never a
   silent edit.

## §R5 Cost interface: regime state → cost-function adjustment

The policy path reprices duration **and** funding. The interface maps each
regime state to concrete adjustments of the strategy cost-function inputs
(`expected_cost_bps(notional, adv_pct, venue, side, urgency)`-style base):

| Cost component | hike_biased | cut_biased | on_hold | Scales? |
|---|---|---|---|---|
| Funding / borrow (`borrow_bps_per_day`, funding leg) | floor = implied EFFR × `100` bps [documented arithmetic]; stress ×`1.25` [example] | floor = implied EFFR × `100` bps [documented arithmetic] | floor = implied EFFR × `100` bps | **yes** — tracks the policy rate |
| Spread (taker) | ×`1.0` | ×`1.0` | ×`1.0`; ×`1.5` inside the FOMC window (`3` days [default]) | **yes** — only on policy-uncertainty days [example] |
| Fees (clearing/exchange) | ×`1.0` (static) | ×`1.0` (static) | ×`1.0` (static) | no — regime-independent |
| Impact | not scaled directly | not scaled directly | not scaled directly | no — exposure scaled instead via `duration_mult` |

Normative reference implementation (pure function; never mutates `base`):

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    s = rsv['state']
    # duration exposure gate [example multipliers; default 1.0]
    adj['duration_mult'] = {'hike_biased': 0.5, 'cut_biased': 1.5}.get(s, 1.0)
    # funding/borrow floor tracks the policy rate: percent -> bps [documented arithmetic]
    effr = rsv.get('effr_level')          # absolute implied EFFR, percent
    adj['funding_bps_floor'] = (effr * 100.0) if effr is not None else None
    # spread widens only inside the FOMC window [example 1.5x; default 1.0]
    adj['spread_mult'] = 1.5 if rsv.get('fomc_window') else 1.0
    adj['fees_scale'] = 1.0              # fees static [default]
    adj['regime_id'] = rsv['regime_id']  # audit tag
    return adj
```

T-modules consume `duration_mult` to scale `max_notional` on
duration-sensitive legs and `funding_bps_floor` as the borrow-rate floor in
their own COST block; the adjustment dict is tagged into the decision log.

## §R7 Failure modes & pitfalls

= restrictive (downstream halves size / widens stops / stands down, never
benign); `DEGRADED` = usable-with-caution (label withheld or under review);
`OFF` = silent.
