## §R1 Precise definition

Lo–MacKinlay variance ratio [documented]: if increments are uncorrelated, q-period variance equals q times 1-period variance. `VR(q) > 1` implies positive autocorrelation (momentum); `VR(q) < 1` implies mean reversion [documented]. `VR(2) ≈ 1 + ρ₁`.

## §R2 Exact calculation

$$VR(q) = \frac{\hat{\sigma}^2_c(q)}{q\,\hat{\sigma}^2_a} \quad\text{[documented]}$$

Overlapping q-period estimator per Lo–MacKinlay (1988/89) [documented]: with
`n` one-period log-returns, `μ̂ = mean(r)` [documented],
`σ̂²_a = Σ(r_t − μ̂)² / (n−1)` [documented], and the overlapping q-variance
`σ̂²_c = (1/m) Σ_{i=1}^{m} (Σ_{k=0}^{q−1} r_{i+k} − qμ̂)²` over `m = n − q + 1`
overlapping q-period blocks [documented]; null `VR = 1` [documented];
`VR(2) ≈ 1 + ρ₁` [documented].

Inference (homoskedastic, reference-implementation simplification):
`z = √(nq)·(VR − 1) / √(2(2q−1)(q−1)/(3q))` [documented].
Production inference (heteroskedasticity-robust): `z* = √(nq)·(VR − 1) / √θ̂`
with `θ̂(q) = Σ_{j=1}^{q−1} (2(q−j)/q)² δ̂_j` and
`δ̂_j = [Σ_t (r_t−μ̂)²(r_{t−j}−μ̂)²] / [Σ_t (r_t−μ̂)²]²` (Lo–MacKinlay 1988,
Theorem 2) [documented] — the reference test computes `z*` as a finite-value
sanity check; the gating path uses the homoskedastic `z` as the documented
simplification and the chapter ships the `z*` formula so production upgrades
need no re-derivation.

**Data inputs.** daily log-returns from adjusted closes; trailing `window`
of `120` returns [default]; `q = 2` [default] on the strategy's bar frequency.

**Cadence.** weekly — the label is recomputed weekly after Friday close; the
estimator needs enough bars for the test to have power.

### R2.1 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. Every numeric literal is
tagged; `[default]` values come from §R0.2.

```
function DETECT(rows, cfg):
    # 1. validate + sort (F1)
    if rows is empty: return RSV(state=indeterminate, module_state=UNKNOWN)
    sort rows by event_ts ascending
    for each row: require numeric event_ts, numeric c > 0;
                  strictly increasing event_ts (duplicates/out-of-order -> UNKNOWN)
    # 2. corporate-action guard (F1): unadjusted split/dividend jumps are data
    #    errors, not regimes
    for i in 2..len(rows):
        ratio = rows[i].c / rows[i-1].c
        if (ratio > 3.0 [default] or ratio < 1/3 [default])
           and rows[i].adjusted is false:
            return RSV(state=indeterminate, module_state=UNKNOWN,
                       reason="unadjusted corporate action")
    # 3. segmentation: gaps are masked, never interpolated (F1)
    segments = []
    current = []
    for each row in order:
        if gap to previous event_ts > cfg.max_gap_days (4 [default]):
            segments.append(current); current = []     # fresh window; warm-up restarts
        if row is HALTED: continue                    # §R0.6: freeze; discard
                                                      # contributions across reopen
        current.append(row)
    segments.append(current)
    seg = segments.last
    # 4. warm-up gate (F1/F5): no labels on thin data
    t = newest event_ts in seg                        # label stamped at t (causal)
    closes = [b.c for b in seg with b.event_ts <= t]
    rets = [log(closes[i]/closes[i-1]) for i in 2..len(closes)]
    rets = last cfg.window (120 [default]) entries
    if len(rets) < cfg.min_bars (120 [default]):
        return RSV(state=indeterminate, module_state=DEGRADED,
                   reason="warming", computed_at=t)
    # 5. estimator
    v = VR(cfg.vr_q=2 [default], rets)                # overlapping estimator above
    z = Z_HOMO(v, n=len(rets), q=2)                   # documented simplification
    if not isfinite(v) or v < 0.0 or v > 4.0 [default]:
        return RSV(state=indeterminate, module_state=UNKNOWN,
                   reason="F2 bounds")                # e.g. zero variance -> 0/0
    # 6. hysteresis + significance state machine (R2.2), prev = last label
    state = TRANSITION(v, z, prev_state, cfg)
    return RSV(state=state, value=v, module_state=OK, computed_at=t)

function TRANSITION(v, z, prev, cfg):
    if not isfinite(v): return indeterminate
    zsig  = isfinite(z) and |z| >= cfg.z_act   (1.96 [default])   # enter gate
    zhold = isfinite(z) and |z| >= cfg.z_hold  (1.64 [default])   # hold gate
    if prev == mr:
        if v > cfg.mr_exit (0.92 [default]) or not zhold: return indeterminate
        return mr
    if prev == momentum:
        if v < cfg.mom_exit (1.08 [default]) or not zhold: return indeterminate
        return momentum
    # from indeterminate: strict inequality at the boundary, significance required
    if zsig and v < cfg.mr_enter  (0.85 [default]): return mr
    if zsig and v > cfg.mom_enter (1.15 [default]): return momentum
    return indeterminate
```

### R2.2 Why hysteresis and the z-gate exist

Single thresholds flicker: a VR oscillating around `0.85` [default] would
whipsaw downstream family selection weekly. The entry/exit split
(`mr_enter < mr_exit`, `mom_exit < mom_enter`) creates a no-trade band where
the previous state holds [default]. The z-gate exists because VR point
estimates are noisy at `n = 120` [default] — requiring `|z| ≥ 1.96` [default]
to *enter* a directional state keeps "most weeks indeterminate" honest, and
the softer hold gate `1.64` [default] avoids dropping a real regime on one
weak week.

### R2.3 Calibration recipe (no hand-tuned magic numbers)

The §R0.2 defaults are starting points; production bands are calibrated per
universe and re-calibrated on a cadence. Recipe:

1. **Calibration data.** ≥ `10` years [default] of daily adjusted closes for
   ≥ `100` names [default] — current *and delisted* constituents (Norgate
   Platinum class, `$630`/yr [documented]) so the MR/momentum base rates are
   not survivorship-biased. Research labels may use the free tier, but band
   calibration must not.
2. **Grid.** `mr_enter ∈ {0.80, 0.85, 0.90}` [default],
   `mr_exit ∈ {mr_enter+0.05, mr_enter+0.07}` [default],
   `mom_enter ∈ {1.10, 1.15, 1.20}` [default],
   `mom_exit ∈ {mom_enter−0.05, mom_enter−0.07}` [default],
   `z_act ∈ {1.64, 1.96, 2.58}` [default], `z_hold = z_act − 0.32` [default],
   `q ∈ {2, 4}` [default].
3. **Splits.** Chronological train/validation/test split `60/20/20` [default], with an embargo of ≥ `5` trading days [default] between splits
   (no shared `window` bars across the boundary).
4. **Objective.** On validation: Spearman rank correlation [default] between
   the weekly regime label (mr = −1, indeterminate = 0, momentum = +1) and
   the forward-1-week spread P&L of (short-horizon contrarian family minus
   momentum family) on that universe, minus a turnover penalty of
   `0.10` [default] per label transition per week.
5. **Selection.** Pick the grid point maximizing the validation objective;
   break ties toward wider hysteresis bands (fewer transitions) [default].
   Report train/validation/test objectives; a validation–test rank-correlation
   drop `> 0.30` [default] rejects the calibration (re-grid, do not ship).
6. **Re-calibration cadence.** Quarterly [default], or on drift: a
   Kolmogorov–Smirnov test of the trailing-`252`-day [default] VR distribution
   vs the calibration distribution with `p < 0.01` [default] triggers an
   off-cycle re-calibration. Band changes require a fresh validation pass —
   never edit bands on live P&L (F5).

**Threshold bands (defaults, pre-calibration).**

| Condition | Label | Tag |
|---|---|---|
| `VR < 0.85` and `\|z\| ≥ 1.96` | MR-dominant (enter) | [default] |
| `VR > 0.92` or `\|z\| < 1.64` while in MR | exit to indeterminate | [default] |
| `0.85 ≤ VR ≤ 1.15` (from indeterminate) | indeterminate (first-class state — trade half size [default]) | [default] |
| `VR > 1.15` and `\|z\| ≥ 1.96` | momentum-dominant (enter) | [default] |
| `VR < 1.08` or `\|z\| < 1.64` while in momentum | exit to indeterminate | [default] |

The documented facts are the null `VR = 1` and the sign interpretation; magnitude cutoffs and the z-gates are `[default]` starting points subject to the §R2.3 recipe.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Short-horizon contrarian / MR | **amplifies then inverts** | VR < 1: improves; VR > 1 at that horizon: dies |
| Momentum / continuation | **amplifies then inverts** | VR > 1: improves; VR < 1: fade dies |
| Pairs trading | **amplifies then inverts** | improves when idiosyncratic VR < 1 (spreads mean-revert); dies when the common factor goes momentum-dominant (legs diverge together) |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes VR(q) on the strategy's bar frequency; publishes RSV.
- **Verifier:** computes first-order autocorrelation sign as the second estimator; states must agree or `UNKNOWN` (F3).
- **Grok-Researcher:** proposes q; leads only.
- **Adversary:** checks for multiple-testing: VR scanned across many q values must use a joint test; checks the evaluation return is excluded.
- **Gate:** rejects VR computed on < `120` [default] bars as a regime label.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

The regime module never prices a trade; it outputs an adjustment record that
the strategy's `expected_cost_bps(notional, adv_pct, venue, side, urgency)`
harness consumes. Two adjustment channels:

1. **Execution-style inputs** — the RSV's state sets `side`, `urgency`, and
   `maker_share` (the fraction of volume worked passively), which the T-chapter
   cost function already takes as arguments.
2. **Component multipliers** — the 4-component cost stack (spread / fees /
   borrow / impact) is scaled per state. `size_mult` scales notional before the
   cost call.

| Regime state | side | urgency | maker_share | spread_mult | fee_mult | impact_mult | borrow_mult | size_mult |
|---|---|---|---|---|---|---|---|---|
| `mr` | mixed | low | `0.7` [default] | `0.4` [example] (passive fills earn part of the spread) | `1.0` [default] (fees are venue-determined) | `0.6` [example] (contrarian entries are low-turnover) | `1.0` [default] (VR gates family, not borrow) | `1.0` [default] |
| `momentum` | taker | high | `0.2` [default] | `1.0` [default] (full cross) | `1.0` [default] | `1.3` [example] (immediacy costs) | `1.0` [default] | `1.0` [default] |
| `indeterminate` | hold | low | hold | `1.0` [default] | `1.0` [default] | `1.0` [default] | `1.0` [default] | `0.5` [default] (first-class state — trade half size) |

```python
def cost_adjustment(rsv, base):
    """rsv: regime_state_vector. base: the strategy's cost inputs + 4-component
    stack {notional, adv_pct, venue, side, urgency, maker_share,
           spread_bps, fee_bps, borrow_bps_day, impact_bps}.
    Returns an adjusted copy; all multipliers tagged per the table above."""
    adj = dict(base)
    st = rsv['state']
    if st == 'indeterminate':
        adj['size_mult'] = 0.5      # [default] first-class indeterminate state
        adj['urgency'] = 'low'      # [default]
        # component multipliers stay 1.0 [default]; style inputs held
    elif st == 'mr':
        adj['side'] = 'mixed'       # [default]
        adj['urgency'] = 'low'      # [default]
        adj['maker_share'] = 0.7    # [default]
        adj['spread_bps'] *= 0.4    # [example] passive fills capture the bounce
        adj['impact_bps'] *= 0.6    # [example] low-turnover contrarian flow
        adj['size_mult'] = 1.0      # [default]
    else:  # momentum
        adj['side'] = 'taker'       # [default]
        adj['urgency'] = 'high'     # [default]
        adj['maker_share'] = 0.2    # [default]
        adj['impact_bps'] *= 1.3    # [example] immediacy premium
        adj['size_mult'] = 1.0      # [default]
    # fee_bps and borrow_bps_day are never scaled by this module [default]:
    # fees are venue-determined; VR gates the trading family, not borrow.
    return adj
```

Worked through a T-chapter cost call: a strategy with `notional = $1.0M`
[example] under `mr` passes `notional × 1.0` [default] with

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Tiny n → detect: one-period returns in trailing window < `120` [default] → action: `DEGRADED`, label withheld (state indeterminate) → recovery: resume labeling automatically once the window refills | `check: n >= 120` [default] |
| 2 | Homoskedastic z under GARCH → detect: variance clustering present (or z* disagrees in sign with z) → action: switch inference to z*, else `DEGRADED` → recovery: re-label the affected weeks with z* and log the correction | `check: robust z used` |
| 3 | Stale-price contamination → detect: index VR vs single-name VR disagree → action: prefer single-name; index labels marked `DEGRADED` → recovery: non-synchronicity adjustment (dimson-style lags) before re-labeling | `check: nonsynchronicity adjusted` |
| 4 | Bounce mistaken for MR → detect: VR < 1 with wide R010 (spread) → action: attribute to R010, not alpha; withhold the MR label → recovery: re-label after spread normalization | `check: spread sane` |
| 5 | Unadjusted corporate action (split/dividend) → detect: close-ratio jump `> 3`× or `< 1/3`× [default] with `adjusted=false` → action: `UNKNOWN` for that label (F1), bar masked → recovery: re-ingest the vendor's adjusted series and replay the fixture | `check: adjusted series` |
| 6 | Feed gap (halt days, vendor outage) → detect: `event_ts` step > `4` days [default] → action: start a fresh trailing window, `DEGRADED` until it refills; never interpolate → recovery: backfill, then replay `test_cmd` before re-arming | `check: gap masked` |
| 7 | Multiple-testing across q → detect: VR scanned over many q values without a joint test → action: Gate rejects the label; require a single pre-registered q or a joint test → recovery: re-run with the pre-registered q only | `check: single q or joint test` |
| 8 | **Intraday VR requested on an EOD/SIP-only stack** → detect: requested bar frequency finer than daily → action: honest `UNKNOWN` with reason `unmeasurable-on-this-stack` — the module does not fabricate intraday VR from daily bars → recovery: none on this stack; escalate to an intraday feed (this is a capability boundary, not a bug) | `check: bar frequency supported` |

Honest degradation summary: on a SIP-only EOD stack this module measures
**daily-bar VR only**; anything finer is `UNKNOWN`, never interpolated. During
warm-up, halts, gaps, and stale feeds the module emits `UNKNOWN`/`DEGRADED`
and downstream halves size or stands down — an unlabeled week is a feature,
not an outage.
