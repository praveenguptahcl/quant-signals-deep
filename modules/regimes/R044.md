## §R2 Precise definition

Ownership concentration: HHI over holder weights `w_i` (fraction of shares outstanding held by holder `i`), plus the effective number of holders `N_eff = 1/HHI` [documented]. The tail (holders outside the top ten) is modeled as equal-weighted over `tail_names = 490` [example] holders — a stated assumption, not a measurement. 13F is quarterly with a `45`-day filing lag [documented]; short positions are not disclosed on 13F [documented-as-observation]; listed option legs are reported (`putCall`) [documented] but OTC derivatives, cash, and debt are not 13(f) securities.

### R2.5 Detection calibration recipe (no hand-tuned magic numbers)

1. **Calibration data:** per-name 13F panel from the SEC bulk data sets (INFOTABLE.tsv), point-in-time as-filed; ≥ `20` quarters [default] of history; weights on the **SH** legs only, denominators from contemporaneous shares outstanding; quarter-end calendar. The evaluation/OOS window is excluded up front (F5). Amendments (13F/A) are applied as dated supersessions — the panel carries both vintages, never a silently rewritten quarter.
2. **Grid:** `conc ∈ {0.015, 0.020, 0.025}` [default set] × exit gap `∈ {0.002, 0.005}` [default set] (`conc_exit = conc − gap`) × `diffuse ∈ {0.008, 0.012}` [default set] × `diffuse_exit = diffuse + 0.001` [default] × `tail_names ∈ {490, 1000}` [default set] (sensitivity probe on the tail assumption). Bands are per-name — never pooled across names. `dual_tol_rel` is fixed at `0.25` [default], never tuned.
3. **OOS selection criterion:** walk-forward with `3` folds [default]. For each grid point compute downstream gate quality: the mean after-cost bps/trade of trades **blocked** by `CONCENTRATED`/`UNKNOWN` minus the mean of trades **passed** (blocked must underperform by ≥ the expected cost — otherwise the gate adds no value). Feature-only fallback when no downstream exists: label stability (adjacent-grid agreement ≥ `0.80` [default]) **and** concentrated-name fraction in `[0.05, 0.25]` [default] (rejects degenerate always/never-concentrated configs). Select the grid point maximizing the OOS objective; ties break toward the smoother config (wider hysteresis, longer history) [rule].
4. **Re-calibration cadence:** annually (`recal_cadence_months = 12` [default] — the regime moves quarterly, bands do not); event-driven on SEC 13F rule changes, `$100`M threshold changes, or holder-aggregation rule changes; never re-fit on the live evaluation window (F5).
5. **Degeneracy guards:** concentrated fraction `< 0.01` [default] on the calibration window → lower the entry threshold; `> 0.50` [default] → the name is structurally concentrated (dual-class, closely held) — document it and exclude the name from gating, never force the bands.

### R2.6 Normative detection pseudocode

Prose is commentary; this pseudocode is normative. Inputs are quarterly
snapshots newest-last; each snapshot carries `quarter_end` (int64 ns UTC),
`filing_ts` (int64 ns UTC, the as-filed vintage), and the top-10
`(sshPrnamt, sshPrnamtType, putCall)` rows.

```
function DETECT(snapshots[1..T], prev_label, cfg) -> RegimeState:
  # F1 — input validity: invalid input -> UNKNOWN, never interpolate
  if T == 0: return UNKNOWN("no-snapshots")
  s = snapshots[T]  # current quarter only — quarters are independent events
  require s.top10 has exactly 10 rows; all finite
    else return UNKNOWN("missing-or-short-panel")
  require sshPrnamtType == SH and putCall empty for every row
    else return UNKNOWN("non-share-leg")      # options/PRN legs are not shares

  # Weights: fraction of shares outstanding (contemporaneous denominator)
  w[i] = s.sshPrnamt[i] / shares_outstanding(s.quarter_end)
  require 0 <= w[i] < 1 for all i; require sum(w) < 1
    else return UNKNOWN("out-of-bounds-weight")   # F2

  # Corporate-action guard: a split changes share counts between quarters,
  # so an unadjusted denominator is bad data, not concentration
  if shares_outstanding is not split-adjusted at s.quarter_end
     and |ln(shares_out(T)/shares_out(T-1))| > 0.5:      # ~65% jump [default]
    return UNKNOWN("unadjusted-corporate-action")

  # Amendment discipline: 13F/A restatement for quarter q recomputes q,
  # bumps data_vintage to the amendment filing_ts, and decision-logs the
  # old vs new label. History is never silently rewritten (§R7 row 2).
  if s.is_amendment:
    label_q = HYSTERESIS(prev_label_at(q-1), recomputed_hhi, cfg)
    return OK(label_q, value=recomputed_hhi, vintage=s.filing_ts, amended=true)

  # Market-state events (quarterly cadence: a HALTED quarter is rare but fatal)
  if s.market_state == HALTED: return UNKNOWN("halted", value=nan)  # frozen

  # F4 — staleness: no filing within stale_days of quarter end -> UNKNOWN
  if now_ns - s.filing_ts > cfg.stale_days * 86400e9:
    return UNKNOWN("stale-holdings")

  # HHI (causal: this quarter's panel only)
  tail = (1 - sum(w)) / cfg.tail_names
  hhi  = sum(w[i]^2) + cfg.tail_names * tail^2
  neff = 1 / hhi
  require 0 <= hhi <= 1 else return UNKNOWN("out-of-bounds-hhi")  # F2

  # F3 — verifier agreement (band + relative tolerance)
  v2 = verifier_hhi(s)   # WhaleWisdom Standard API, or None if unreachable
  if v2 is not None and not F3_AGREE(hhi, v2, cfg):
    return UNKNOWN("F3-disagreement")
  degraded = (v2 is None)   # honest: label emitted, F3 pending, never OK

  label = HYSTERESIS(prev_label, hhi, cfg)   # §R2.7

  # Honest history rule: production needs >= min_history_quarters trailing panels
  if T < cfg.min_history_quarters:
    return DEGRADED("short-trailing-history", label, hhi)

  module_state = DEGRADED if degraded else OK
  return RegimeState(R044, label, hhi, estimator_version, s.filing_ts,
                     computed_at=now_ns, module_state, min_lag_bars)

function F3_AGREE(v1, v2, cfg):
  rel = |v1 - v2| / max(v1, v2, 1e-18)
  return PLAIN_BAND(v1, cfg) == PLAIN_BAND(v2, cfg) and rel <= cfg.dual_tol_rel
```

### R2.7 State-transition table (hysteresis — normative)

Boundaries: `conc=0.020, conc_exit=0.018, diffuse=0.012, diffuse_exit=0.013`
[default]. Read: entry comparisons are strict (`>=` for concentrated,
`<` for diffuse); exit is sticky — the label persists while `hhi` stays on
the exit side of the band. One label change per quarter maximum [rule]: no
`CONCENTRATED ↔ DIFFUSE` jumps.

| prev \ hhi | `>= 0.020` | `0.018–0.020` | `0.012–0.018` | `0.012–0.013` | `< 0.012` |
|---|---|---|---|---|---|
| CONCENTRATED | CONCENTRATED | CONCENTRATED (hold) | MODERATE (exit) | MODERATE | MODERATE |
| MODERATE | CONCENTRATED (entry) | MODERATE | MODERATE | MODERATE | DIFFUSE (entry) |
| DIFFUSE | MODERATE (one step) | MODERATE | MODERATE | DIFFUSE (hold) | DIFFUSE |

Note the overlap cell: `hhi ∈ [0.012, 0.013)` is inside MODERATE's band but
DIFFUSE holds there (sticky exit) — the column ranges above are plain-band
references; the transition rules (§R2.6 `HYSTERESIS`) are authoritative.
Boundary values are pinned by unit tests
(`test_hysteresis_entry_exit_boundaries`): `hhi = 0.020` exactly enters
CONCENTRATED; `hhi = 0.018` exactly stays CONCENTRATED; `hhi = 0.012` exactly
does **not** enter DIFFUSE; `hhi = 0.013` exactly exits DIFFUSE.

## §R3 Exact calculation

Holder weights `w_i`, top-10 disclosed, tail equal-weighted:

$$HHI = \sum_{i=1}^{10} w_i^2 + N_{tail}\left(\frac{1-\sum_{i=1}^{10}w_i}{N_{tail}}\right)^2, \qquad
N_{eff} = \frac{1}{HHI}$$

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

Regime state → cost-function adjustment: ownership concentration scales the
**impact** leg — a few holders *are* the marginal flow, so flow-driven
dislocations are larger (Greenwood & Thesmar 2011 [documented] link
concentration to non-fundamental volatility). Spread, borrow, and fees do not
scale with HHI on any documented basis and stay at identity. `UNKNOWN` is
restrictive: multipliers are undefined and `trade_ok = False`.

| State | `spread_mult` | `impact_mult` | `borrow_mult` / `fees_mult` | `trade_ok` |
|---|---|---|---|---|
| CONCENTRATED | `1.0` [default] | `1.5` [example] | `1.0` [default] | `True` (halve size per §R4 gate) |
| MODERATE | `1.0` [default] | `1.0` [default] | `1.0` [default] | `True` |
| DIFFUSE | `1.0` [default] | `1.0` [default] | `1.0` [default] | `True` |
| UNKNOWN | undefined | undefined | undefined | `False` (restrictive default) |

```python
COST_ADJUSTMENT_R044 = {
    "regime_id": "R044", "version": "1.1.0",
    "CONCENTRATED": {"spread_mult": 1.0, "impact_mult": 1.5,
                     "borrow_mult": 1.0, "fees_mult": 1.0,
                     "fee_add_bps": 0.0, "trade_ok": True, "tag": "[example]"},
    "MODERATE":     {"spread_mult": 1.0, "impact_mult": 1.0,
                     "borrow_mult": 1.0, "fees_mult": 1.0,
                     "fee_add_bps": 0.0, "trade_ok": True, "tag": "[default]"},
    "DIFFUSE":      {"spread_mult": 1.0, "impact_mult": 1.0,
                     "borrow_mult": 1.0, "fees_mult": 1.0,
                     "fee_add_bps": 0.0, "trade_ok": True, "tag": "[default]"},
    "UNKNOWN":      {"spread_mult": None, "impact_mult": None,
                     "borrow_mult": None, "fees_mult": None,
                     "fee_add_bps": 0.0, "trade_ok": False, "tag": "[rule]"},
}

def cost_adjustment(rsv, base):
    # base: dict(spread_bps, impact_bps, borrow_bps, fees_bps) from the strategy COST block
    # Only impact scales with ownership concentration; spread/borrow/fees are unaffected.
    adj = dict(base)
    state = rsv["state"]
    rec = COST_ADJUSTMENT_R044[state]
    if state == "UNKNOWN":
        adj["trade_ok"] = False   # restrictive default: never benign
        return adj
    adj["impact_mult"] = rec["impact_mult"]  # 1.5 [example] starting point — calibrate below
    adj["spread_mult"] = rec["spread_mult"]  # 1.0 [default]
    adj["borrow_mult"] = rec["borrow_mult"]  # 1.0 [default]
    adj["fees_mult"] = rec["fees_mult"]      # 1.0 [default]
    adj["trade_ok"] = rec["trade_ok"]
    return adj
```

**Application rule.** `apply impact multiplier to the name's expected_cost_bps impact input; halve allocation size for flow strategies under CONCENTRATED (§R4); UNKNOWN vetoes cost-sensitive strategies`. All multipliers `[example]` unless
tagged otherwise — calibrate per venue; the record is versioned with
`estimator_version` and every application is decision-logged (Appendix g
v1.0.0).

**Multiplier calibration recipe** (the `[example]` values above are starting
points, never live values):

1. Per name, from execution records over ≥ `12` months [default], compute
   realized implementation-shortfall slippage per trade and the R044 label
   at the trade time.
2. Regress slippage on HHI quintiles; define
   `impact_mult(band) = median slippage in band / median slippage in the
   MODERATE band`.
3. `impact_mult(CONCENTRATED)` = fitted value at the `0.90` HHI quantile
   [default].
4. Re-fit annually [default]; if the fitted `CONCENTRATED` multiplier is
   `< 1.2` [default], the name's impact is not concentration-convex — set it
   to `1.0` [default] and document it.

**Executable gate** (for T-module `expected_cost_bps` predicates):

```
eff_cost = expected_cost_bps(notional, adv_pct, venue, side, urgency,
                             impact_bps = base.impact_bps * adj.impact_mult)
```

Honest note: Greenwood & Thesmar (2011) [documented] measure fragility from
mutual-fund ownership and predict *volatility*, not slippage — `1.5` is an
[example] starting point justified by the fragility channel, not a measured
impact elasticity. The recipe above is what turns it into a number.

**Honest DEGRADED/UNKNOWN doctrine.** `UNKNOWN` is emitted for: no filing,
bad weights, verifier band disagreement, stale holdings, halted quarter,
unadjusted corporate actions. `DEGRADED` (label emitted, never `OK`) is
emitted for: verifier unreachable (F3 pending), short trailing history
(< `20` quarters [default]), structurally-concentrated names. `UNKNOWN`
always vetoes cost-sensitive strategies; `DEGRADED` halves their size at
most — never a full allocation.
