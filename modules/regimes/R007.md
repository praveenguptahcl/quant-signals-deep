### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; ADX at bar t needs H/L of bar t; the label gates signals evaluated at t for t+1+ only).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

ADX (Wilder 1978 [documented]) measures strength of directional movement, not direction. Hurst exponent H from rescaled-range measures long memory: `H > 0.5` persistent (trend-like), `H < 0.5` anti-persistent [documented interpretation].

## §R2 Exact calculation

**Sentinel (ADX).** True range $TR_i = \max(H-L, |H-C_{i-1}|, |L-C_{i-1}|)$;
Wilder-smoothed $\pm DM$; $\pm DI = 100\cdot S\pm DM / STR$;
$DX = 100\cdot|+DI - -DI| / (+DI + -DI)$; $ADX$ = Wilder mean of DX,
`n = 14` [documented]. Seeding is exact Wilder: sums over the first `n` bars,
then recursive $S \leftarrow S - S/n + x_i$; $DX_1$ is defined at bar `n+1`,
the first $ADX$ = mean of the first `n` $DX$ values is defined at bar `2n`
(`min_bars = 28` [default]) — *not* at bar `n+1` (a common implementation
bug this chapter's fixture caught).

**Verifier (Hurst).** Classical rescaled-range $H = \ln(R/S)/\ln(n)$ [documented]
(Hurst 1951), $S$ = sample stdev (ddof=`1`) [default], computed over the
trailing `verifier_window = 28` [default] closes for F3 agreement (partial
window accepted down to `verifier_min = 20` [default] closes), plus a
63-bar [default] research Hurst logged per bar but never gating.

**Data inputs.** Daily (and 60-min [example]) H/L/C, split/dividend-adjusted
(§R0.3). **Cadence.** Daily; 60-minute for intraday strategies.

### R2.1 Normative detection pseudocode

Prose is commentary — this pseudocode is normative. One causal pass, oldest
bar first; `prev` is the module-owned state `(label, pend, pcount)`.

```
function PROCESS(bars, cfg):                      # bars: oldest -> newest
  smoother, closes, tr_hist = reset()
  prev_label, pend, pcount = None, None, 0
  last_ts, pc = None, None                       # no previous bar yet
  for b in bars:                                   # b = (event_ts, h, l, c, flags)
    if b.market_state == HALTED:                   # E3: halt
      emit(state='unknown', module_state=UNKNOWN, reason='halt_freeze')
      continue                                    # freeze; discard contributions across reopen
    if last_ts is not None \
       and b.event_ts - last_ts > cfg.gap_reset_mult * cadence:   # E2: long gap
      smoother, closes, tr_hist = reset()          # stale smoothing is untrustworthy
      prev_label, pend, pcount = None, None, 0
      pc = None
    if not VALID(b):                              # F1: never interpolate
      emit(state='invalid', module_state=UNKNOWN, reason='F1_invalid_row'); continue
    TR = max(b.h - b.l, |b.h - pc|, |b.l - pc|) if pc else (b.h - b.l)
    if b.split or (|log(b.c/pc)| > cfg.ca_jump    # E1: corporate action
                   and TR > cfg.ca_tr_mult * median(tr_hist[-20:])):
      emit(state=prev_label or 'unknown', module_state=DEGRADED,
           reason='corporate_action_freeze')      # skip bar; re-baseline pc=b.c
      last_ts, pc = b.event_ts, b.c; continue
    update Wilder smoother with (TR, +DM, -DM); append TR, b.c
    if smoother.adx is None:                      # < min_bars = 2*adx_n
      emit(state='warming', module_state=DEGRADED, reason='warmup'); continue
    hv = HURST_RS(trailing closes, cfg.verifier_window)
    if not finite(hv):
      emit(state='warming', module_state=DEGRADED, reason='warmup'); continue
    if not (0 <= adx <= 100) or not (-0.5 <= hv <= 1.5):   # F2 [default] Hurst guard
      emit(state='unknown', module_state=UNKNOWN, reason='F2_bounds'); continue
    ra = 'trending' if adx > cfg.adx_trend else ('chop' if adx < cfg.adx_chop
                                                 else 'transitional')
    rh = 'trending' if hv > cfg.hurst_trend else ('mr' if hv < cfg.hurst_mr
                                                 else 'random')
    raw = ra if AGREE(ra, rh) else None           # F3: dual-estimator agreement
    # AGREE = {(trending,trending), (chop,mr), (transitional,random)}
    label, mstate, prev_label, pend, pcount = HYSTERESIS(prev_label, pend, pcount,
                                                        raw, cfg)
    emit(state=label, module_state=mstate, value=adx, hurst=hv,
         computed_at=b.event_ts,                  # label stamped AT the newest bar
         reason='F3_disagree' if raw is None else 'ok')
    last_ts, pc = b.event_ts, b.c                 # advance causal clock

function HYSTERESIS(prev, pend, pcount, raw, cfg):
  # Entry band (25 [documented]) != exit band (20 [documented]) = hysteresis.
  # Transitions into trending/chop additionally need confirm_bars consecutive
  # agreeing raw labels, so a single boundary touch cannot flip the state.
  if raw is None:                                 # F3 disagreement
    return ('unknown', UNKNOWN, prev, None, 0)    # restrictive; keep prev for resume
  if prev is not None and raw == prev:
    return (prev, OK, prev, None, 0)
  if raw == 'transitional':                       # exit is immediate via the band
    return ('transitional', OK, 'transitional', None, 0)
  pend, pcount = (raw, pcount + 1) if raw == pend else (raw, 1)
  if pcount >= cfg.confirm_bars:                  # 2 [default]
    return (raw, OK, raw, None, 0)
  return ((prev or 'unknown'), OK, prev, pend, pcount)   # hold old label while confirming
```

**State-transition summary** (entry needs `2` [default] consecutive agreeing
raw labels; exit from trending/chop passes through `transitional`):

| From | Raw (agreed) | Emitted | Module state |
|---|---|---|---|
| any | disagreement | `unknown` | `UNKNOWN` (F3, restrictive) |
| `chop` | `trending` ×`1` | `chop` (held) | `OK` |
| `chop` | `trending` ×`2` | `trending` | `OK` |
| `trending` | `transitional` ×`1` | `transitional` | `OK` |
| `trending` | `chop` ×`2` | `chop` | `OK` |
| none (startup) | `chop` ×`2` | `chop` | `OK` (first bar emits `unknown`/`OK` while confirming) |

**Edge cases.** Missing bars: mask, never interpolate (F1); a gap
`> 5`× [default] cadence resets the smoother and restarts warmup (E2) —
stale Wilder state is worse than no state. Halts/auctions: per §R0.6, freeze
and discard contributions across reopen (E3). Corporate actions: E1 tripwire
above; adjusted feeds should never trip it — if it trips repeatedly, the feed
is unadjusted and every label is suspect (DEGRADED until fixed). First bar has
no previous close: $TR_1 = H - L$ [default].

### R2.3 Detection calibration recipe

No threshold ships hand-tuned. To replace a `[default]`/`[example]`:

- **Data:** Norgate US Platinum EOD (survivorship-bias-free: delisted
  securities + historical constituents back to 1992 [documented]) —
  Platinum is required *for calibration* even though Silver suffices for
  production (§1.5). Universe: S&P 500 historical constituents [example],
  1996–2025 [example], daily HLC adjusted.
- **Ground truth (pre-registered before running the grid — F5):** a 63-day
  [example] segment is labeled `trending` iff `|cumulative log return| >
  2.0 × realized vol` [example] over the segment *and* the sign is consistent
  across the two non-overlapping 31-day [example] halves; otherwise `chop`.
  (Crude and honest — it labels sustained directional drift, nothing more.)
- **Grid** (all grid values are [example] starting points, not recommendations):
  `adx_n ∈ {10, 14, 21}`; `adx_trend ∈ {20, 25, 30}`;
  `adx_chop ∈ {15, 20}` with constraint `adx_chop ≤ adx_trend − 5` [default];
  `verifier_window ∈ {20, 28, 40}`; `hurst_trend ∈ {0.52, 0.55, 0.58}`;
  `hurst_mr ∈ {0.42, 0.45, 0.48}`; `confirm_bars ∈ {1, 2, 3}`.
- **Protocol:** walk-forward, train `5` yr / test `2` yr [example], step `2` yr
  [example]; embargo `21` trading days [example] between train and test
  (no shared bars, no shared smoother state).
- **Selection criterion:** maximize `balanced_accuracy(trending|chop labels on
  test segments) − 0.5 × label_churn_rate` [example] (churn = fraction of bars
  where the emitted label differs from the previous bar — penalizes flapping);
  tie-break toward Wilder defaults (`14`/`25`/`20`) [default].
- **Re-calibration cadence:** annually [default], and after any feed schema or
  corporate-action-handling change [default]. If calibration cannot beat the
  defaults out-of-sample, keep the defaults and say so in the decision log.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Momentum/breakout (Donchian, time-series momentum) | **amplifies then inverts** | improves strongly with ADX > 25; dies below 20 (whipsaw) — trend filters convert a 50/50 entry into positive expectancy only when autocorrelation is positive |
| Mean-reversion | **inverts** | mirror image — improves in chop, dies in trend (fade-the-move gets run over) |
| Breakout initiation | **amplifies** | high ADX + squeeze resolution (R008) + VR>1 (R009) = breakout cluster |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes ADX + Hurst; publishes RSV.
- **Verifier:** requires agreement of ADX-state and Hurst-state (trend/chop/random) — disagreement → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes bar frequencies; leads only.
- **Adversary:** tests that daily ADX is not used to gate 5-minute signals without validation; injects post-trend chop to test ADX lag.
- **Gate:** rejects any label computed with < `28` [default] bars of history
  (first true Wilder ADX) or < `20` [default] closes for the verifier Hurst.
- **F1–F5 instantiated:** F1 missing/stale/invalid → `UNKNOWN`, never
  interpolate; F2 bounds check on every emission (ADX ∈ `[0, 100]`
  [documented], verifier Hurst ∈ `[-0.5, 1.5]` [default] guard); F3 crisp
  dual-estimator agreement — matched pairs only
  (`trending`/`trending`, `chop`/`mr`, `transitional`/`random`) — else
  `UNKNOWN`; F4 staleness TTL `3`× cadence [default] → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

The regime does not set costs — it *adjusts the strategy's cost-function
inputs*. `base` is the strategy's 4-component cost stack in bps
(`spread_bps`, `fees_bps`, `borrow_bps_per_day`, `impact_bps`) as produced by
its `expected_cost_bps(...)` callable (§T2 COST block). The adjustment scales
components and sets gating flags; every multiplier is tagged and must survive
the §R2 calibration pass before production.

```python
def cost_adjustment(rsv, base):
    """rsv: regime_state_vector dict with 'state'. base: 4-component cost
    stack in bps. Returns (adjusted_stack, gates)."""
    adj = dict(base)
    gates = {'trade_ok': True, 'mr_veto': False, 'size_mult': 1.0,
             'edge_mult': 1.0}                     # [default] neutral gates
    s = rsv['state']
    if s == 'chop':
        # Whipsaw regime: trend-family strategies churn — more round-trips
        # per unit of P&L, wider effective spreads on stop-outs.
        adj['impact_bps'] *= 1.5                   # [example]
        adj['spread_bps'] *= 1.25                  # [example]
        gates['size_mult'] = 0.5                   # [example] halve trend-family size
        gates['edge_mult'] = 2.0                   # [example] fee-covering gate doubles
    elif s == 'trending':
        gates['mr_veto'] = True                    # [default] never fade a strong trend
    elif s == 'transitional':
        adj['impact_bps'] *= 1.25                  # [example]
        gates['size_mult'] = 0.75                  # [example]
    else:  # 'unknown' | 'warming' | 'invalid' | 'missing'
        gates['trade_ok'] = False                  # [default] restrictive:
        gates['size_mult'] = 0.0                   # [default] no NEW risk on UNKNOWN
    return adj, gates
```

| Regime state | spread | fees | borrow/d | impact | size_mult | edge_mult | mr_veto | trade_ok |

## §R7 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | ADX lag after trend ends (ADX still `> 25` [documented] while the 28-bar [default] verifier Hurst has fallen `< 0.55` [example]) → detect: F3 agreement fails → action: `UNKNOWN` (restrictive — downstream halves size / widens stops / stands down), never a stale `trending` label → recovery: automatic when estimators re-agree | `check: _agree(raw_adx, raw_hurst) or state == 'unknown'` |
| 2 | Early bars (`< 28` [default], first true Wilder ADX undefined) or verifier `< 20` [default] closes → detect: smoother incomplete → action: `DEGRADED`, label withheld (`warming`) → recovery: automatic at bar `28` [default] | `check: n_bars >= 28` [default] |
| 3 | Wrong bar frequency (daily ADX gating 5-min signals) → detect: Gate frequency check → action: reject without validation → recovery: resample to 60-min [example] ADX and re-validate, or gate daily signals only | `check: frequency matches` |
| 4 | Corporate action on unadjusted feed (split prints `> 20`% [default] overnight jump + `> 3`× [default] TR spike) → detect: E1 tripwire → action: skip bar, `DEGRADED`, label held, re-baseline → recovery: automatic next bar; if it trips repeatedly the feed is unadjusted — fix the feed, not the guard | `check: not ca_tripwire or adjusted_feed` |
| 5 | Missing bars / feed gap `> 5`× [default] cadence → detect: `event_ts` jump → action: reset Wilder smoother, restart warmup (`DEGRADED`) — stale smoothing is worse than no smoothing → recovery: automatic after `28` [default] fresh bars | `check: gap <= 5 * cadence` [default] |
| 6 | Halt/auction mid-session → detect: `market_state` event → action: freeze, emit `UNKNOWN`, discard contributions across reopen → recovery: resume on `CONTINUOUS_TRADING`; the reopen bar re-baselines `pc` | `check: market_state == CONTINUOUS_TRADING or module_state != OK` |
| 7 | Estimator disagreement at every regime flip (verifier reacts faster than ADX) → detect: F3 → action: `UNKNOWN` through the transition (fixture bars `55–69`, `133–141`) → recovery: automatic on re-agreement; do NOT "fix" by widening agreement — the `UNKNOWN` stretch is the documented cost of a lagging sentinel | `check: unknown_spell <= 30 bars` [example] `else recalibrate verifier_window` |
| 8 | SIP-only stack → honest assessment: this detector is **fully measurable on SIP EOD** (needs only H/L/C, all in the SIP feed) — no `UNKNOWN`-by-construction. It degrades only if (a) the SIP series is unadjusted and splits trip E1 every few months (row 4), or (b) you need the 60-min intraday path and your SIP aggregation runs late — then staleness TTL (`3`× [default] cadence, F4) fires `UNKNOWN` until the bars land. There is no hidden premium-data dependency. | `check: staleness_ttl_ok` |

**Pitfall — the 63-bar Hurst as verifier:** a 63-bar [default] Hurst lags ADX by
weeks and *cannot* catch ADX lag (it agrees with the stale label). That is why
F3 uses the 28-bar [default] verifier window (`= 2*adx_n`); the 63-bar Hurst
stays as a logged research anchor only. Calibrating `verifier_window` up
toward `63` [default] reintroduces the blind spot — the §R2 criterion's churn penalty
pushes back against it.
