## §R1 Precise definition

ADX (Wilder 1978 [documented]) measures strength of directional movement, not direction. Hurst exponent H from rescaled-range measures long memory: `H > 0.5` persistent (trend-like), `H < 0.5` anti-persistent [documented interpretation].

## §R2 Exact calculation

True range $TR_i = \max(H-L, |H-C_{i-1}|, |L-C_{i-1}|)$; Wilder-smoothed $\pm DM$; $\pm DI = 100\cdot S\pm DM / STR$; $DX = 100\cdot|+DI - -DI| / (+DI + -DI)$; $ADX$ = Wilder mean of DX, `n = 14` [documented].

Classical R/S Hurst: $H = \ln(R/S)/\ln(n)$ where R = max cumulative deviation − min cumulative deviation, S = stdev [documented].

Bands [documented]: ADX `> 25` trending · ADX `< 20` chop (Wilder's original cutoffs). Hurst bands are `[example]`: `H > 0.55` trending · `0.45–0.55` random · `H < 0.45` mean-reverting.

**Data inputs.** daily (and 60-min [example]) H/L/C; `63`-day [example] window for Hurst.

**Cadence.** daily; 60-minute for intraday strategies.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `ADX > 25` | trending | [documented] |
| `20 ≤ ADX ≤ 25` | transitional | [example] |
| `ADX < 20` | chop | [documented] |

ADX cutoffs are `[documented]` (Wilder). Hurst cutoffs are `[example]`. ADX and Hurst must *agree* (trend/chop/random) or the state is `UNKNOWN` (F3).

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Momentum/breakout (Donchian, time-series momentum) | **amplifies then inverts** | improves strongly with ADX > 25; dies below 20 (whipsaw) — trend filters convert a 50/50 entry into positive expectancy only when autocorrelation is positive |
| Mean-reversion | **inverts** | mirror image — improves in chop, dies in trend (fade-the-move gets run over) |
| Breakout initiation | **amplifies** | high ADX + squeeze resolution (R008) + VR>1 (R009) = breakout cluster |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes ADX + Hurst; publishes RSV.
- **Verifier:** requires agreement of ADX-state and Hurst-state (trend/chop/random) — disagreement → `UNKNOWN` (F3).
- **Grok-Researcher:** proposes bar frequencies; leads only.
- **Adversary:** tests that daily ADX is not used to gate 5-minute signals without validation; injects post-trend chop to test ADX lag.
- **Gate:** rejects ADX values computed with < `28` [default] bars of history as regime labels.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Chop vs trend changes the whipsaw rate: in chop, high-turnover trend strategies face repeated stop-outs — the adjustment halves their size and doubles required edge; in trend, mean-reversion entries are vetoed.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'] == 'chop':
        adj['size_mult'] = 0.5      # [example] whipsaw regime
        adj['edge_mult'] = 2.0      # [example]
    elif rsv['state'] == 'trending':
        adj['mr_veto'] = True       # [default] do not fade the trend
        adj['size_mult'] = 1.0      # [default]
    else:
        adj['size_mult'] = 0.75     # [example] transitional
    return adj
```
