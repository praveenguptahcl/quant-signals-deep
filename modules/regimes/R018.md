### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; component z's use history ≤ t; SI/COT lags carried as vintage tags).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Composite z = mean(PCR z, SI% z, COT z), sign-aligned (+ = crowded long) [documented construction]. Cross-check: median composite; absolute tolerance `0.5` [default]. Verifier requires ≥2 of 3 inputs fresh or `UNKNOWN` [documented RB-list].

## §R2 Exact calculation

$$z^{crowd} = \tfrac{1}{3}\,(z^{PCR} + z^{SI} + z^{COT}) \quad\text{[documented]}$$

Equal-weight mean composite of three z-scores, sign-aligned so that
**+ = crowded long** (weights fixed ex ante; no weight-mining [documented RB-list]).

Worked example [documented Grok RB2]: SI `12.0m`/float `80.0m` = `15.0%`; DTC = `12/2.5 = 4.8` days ⇒ crowded short / elevated unwind risk.

### R2.1 Sign alignment (mandatory — the fastest way to invert every label)

Raw inputs are z-scores of the *raw* series. Two of them point the wrong
way relative to the + = crowded long convention; the alignment flips are
part of the normative calculation, not a post-processing choice.

| Raw input | Raw z direction | Crowded-side reading | Aligned z [default] |
|---|---|---|---|
| CBOE total put/call ratio (volume-based) | high PCR = bearish positioning | crowded **short** | `−z(pcr_raw)` |
| FINRA short interest % float | high SI% = crowded shorts | crowded **short** | `−z(si_raw)` |
| CFTC COT net non-commercial (or managed-money) long | high net long = crowded longs | crowded **long** | `+z(cot_raw)` |

Implementation trap [documented-construction]: PCR is a *market-wide*
series (no float concept); SI% and COT are position series. The z-score
windows below differ on purpose.

### R2.2 Z-score windows

| Component | Rolling z-score window | Tag |
|---|---|---|
| PCR | `21` trading days of the daily total put/call ratio | [default] |
| SI% float | `12` reports (~`6` months) of bi-weekly SI / split-adjusted float | [default] |
| COT net | `26` weeks of the net long position (Tuesday as-of) | [default] |

`z = (x − rolling_mean) / rolling_std` with `ddof=1` [default]; the window
uses only observations with `asof_ts ≤ t` (vintage-aware, §R0.5).

DTC convention: `DTC = SI_shares / ADV_50d` (`50`-day average daily volume [default]).

### R2.3 Hysteresis threshold bands (entry ≠ exit)

| Condition | Label | Tag |
|---|---|---|
| `|z| ≥ 2.0` from non-extreme | `extreme_long` / `extreme_short` (enter extreme) | [default] |
| `|z| ≥ 1.5` from extreme | hold `extreme_*` (exit band) | [default] |
| `|z| ≥ 1.25` from normal | `crowded_long` / `crowded_short` (enter crowded) | [default] |
| `|z| ≥ 0.75` from crowded | hold `crowded_*` (exit band) | [default] |
| `|z| < 0.75` | `normal` | [default] |

State machine: an `extreme_*` label that falls below `1.5` drops to the
crowded band (never straight to `normal`); a `crowded_*` label that reaches
`2.0` jumps to `extreme_*`. Side always follows `sign(z)` [default].
Warm-up: first `4` bars [default] → `DEGRADED` (label withheld, §R7).
Bounds (F2): `|z| > 5.0` → `UNKNOWN` (data error, never a regime) [documented-construction].

The old single-threshold bands (`|z| < 1` normal · `1–2` crowded · `> 2`
extreme) are superseded — a single threshold flickers at the boundary.

### R2.4 Normative detection pseudocode

Pseudocode is normative; prose is commentary. Handles documented edge
cases: missing bars, single-component outages, halts, corporate actions.

```
function DETECT(state, events, cfg) -> RegimeState:        # events newest last
    bars = VALIDATE(events)                                # invalid fields -> UNKNOWN (F1); never interpolate
    if MARKET_STATE(events) == HALTED:                    # halt/auction per R0.6
        state.freeze()
        return RegimeState(R018, state.last_label, state.last_z, v, vintage, now, UNKNOWN)
    if MARKET_STATE(events) == AUCTION:
        return RegimeState(R018, state.last_label, state.last_z, v, vintage, now, DEGRADED)

    aligned = []
    for b in bars[-cfg.lookback:]:                        # lookback covers the longest z window
        raw = {pcr: b.pcr_raw_z, si: b.si_raw_z, cot: b.cot_raw_z}
        a   = {pcr: -raw.pcr, si: -raw.si, cot: +raw.cot}  # R2.1 sign alignment
        stale = any(vintage(b, k) > cfg.min_fresh for k in a) or any(not finite)
        aligned.append((a, stale))                        # missing bar -> row absent; gap policy = mask
    fresh = [a for (a, stale) in aligned if not stale]
    if len(fresh) < 2:                                   # F1: need >= 2 of 3 inputs fresh [documented RB-list]
        return RegimeState(R018, "missing", NaN, v, vintage, now, UNKNOWN)

    z  = mean(fresh[-1].values())                        # sentinel [documented]
    zm = median(fresh[-1].values())                      # verifier
    if not finite(z) or abs(z) > cfg.f2_bound:           # F2
        return RegimeState(R018, "out_of_bounds", z, v, vintage, now, UNKNOWN)
    if abs(z - zm) > cfg.dual_tol:                       # F3
        return RegimeState(R018, state.last_label, z, v, vintage, now, UNKNOWN)
    if len(bars) < cfg.warmup_bars:                      # warm-up
        return RegimeState(R018, "warming", NaN, v, vintage, now, DEGRADED)

    # corporate action: split-adjusted float discontinuity breaks SI% z
    if abs(float_shares(t) / float_shares(t-1) - 1) > cfg.corp_action_float_jump:
        si_stale = True                                  # restate SI% on adjusted shares; recompute window
        if len(fresh_excl_si) < 2: return UNKNOWN else: recompute z without SI

    label = HYSTERESIS(z, state.prev_label, cfg)         # R2.3 entry/exit pairs
    state.prev_label = label
    vintage_tags = {pcr: "EOD T+0", si: "T+~7bd", cot: "T+3d"}   # [documented] lags
    return RegimeState(R018, label, z, v=1.1.0, vintage_tags, computed_at=events[-1].event_ts, OK)
```

a = abs(z); side = "long" if z >= 0 else "short"
if prev in {"extreme_long","extreme_short"}:
    return "extreme_"+side if a >= cfg.exit_extreme \

### R2.5 Calibration recipe (all thresholds — no magic numbers)

1. **Data:** public feeds per §R0 datasets, history from `2015` [default]; seeds pinned (§0); vintage tags carried (no as-of backfill).
2. **Grid:** `enter_crowded ∈ {1.00, 1.25, 1.50}` [default]; guard-band width
   `(enter_crowded − exit_crowded) ∈ {0.25, 0.50, 0.75}` [default];
   `enter_extreme ∈ {1.75, 2.00, 2.50}` [default] with `exit_extreme = enter_extreme − 0.50` [default].
3. **OOS selection:** walk-forward — train `2019–2023`, select on `2024–2026` [default]. Criterion: maximize precision of `extreme_long` labels preceding a `≥5%` [default] index drawdown within `10` trading days [default], subject to extreme duty-cycle `< 10%` [default] of weeks; tie-break → widest guard band (fewest label flips).
4. **Re-calibration cadence:** annually each January on trailing `10` years [default]; weights stay equal — changing weights is a module-version change, not a re-cal.
5. **Anti-mining:** the grid, windows, and selection criterion are fixed *before* the first calibration run and recorded in the decision log (F5); the evaluation set is never used to pick the guard band.

**Data inputs.** CBOE total put/call (21-day MA [default]), FINRA short interest / float (bi-weekly), CFTC COT net non-commercial (weekly, Tuesday as-of).

**Cadence.** weekly.

## §R5 Cost interface: regime state → cost-function adjustment

Crowding concentrates exit risk. The adjustment below maps each regime
state onto the T-module COST block's 4-component stack
(`spread_bps, fee_bps, borrow_bps_per_day, impact_bps`) plus two sizing
knobs. **Which components move:** spreads and impact scale up (the exit
door shrinks); borrow gets a buffer on the crowded-short side
(squeeze/locate risk); **fees never move** — venue fee schedules are fixed
with respect to crowding [default].

```python
def cost_adjustment(rsv, base):
    """Regime state -> cost-function adjustment. `base` is the T-module
    4-component cost stack; the adjustment returns multipliers/add-ons that
    the T module applies before its fee-covering gate."""
    adj = dict(base)
    state = rsv['state']
    adj['trade_ok'] = True
    adj['spread_mult'] = 1.0       # [default] normal
    adj['impact_mult'] = 1.0       # [default]
    adj['borrow_bps_add'] = 0.0    # [default] bps/day
    adj['size_mult'] = 1.0         # [default]
    adj['stop_mult'] = 1.0         # [default]
    if state in ('crowded_long', 'crowded_short'):
        adj['size_mult'] = 0.75        # [example] fade new entries in the crowded direction
        adj['spread_mult'] = 1.25      # [default] exit-door crowding widens quoted spreads
        adj['impact_mult'] = 1.5        # [default] concentrated exit flow
    if state in ('extreme_long', 'extreme_short'):
        adj['size_mult'] = 0.5         # [example] air-pocket risk
        adj['spread_mult'] = 1.5       # [default]
        adj['impact_mult'] = 2.0       # [default] violent reversals, small door
        adj['stop_mult'] = 1.25        # [default] widen stops on reversal tails
        adj['contrarian_watch'] = True  # [default] contrarian watch, not a fade signal
    if state in ('crowded_short', 'extreme_short'):
        adj['borrow_bps_add'] = 25.0   # [example] bps/day — squeeze-aware borrow buffer
    # adj['fee_bps'] intentionally untouched: exchange/SEC fees do not
    # respond to crowding [default].
    return adj
```

Application contract for the T module: apply `spread_mult`/`impact_mult`
to its spread and impact components, add `borrow_bps_add` to
`borrow_bps_per_day` for short-side tickets, multiply intended size by
`size_mult`, and multiply stop distance by `stop_mult` — *before* the
`expected_cost_bps(...) <= k * edge_bps` fee-covering gate [default]. In
`UNKNOWN`, T modules halve size and widen stops (restrictive, §R0.5); in
`DEGRADED` (warm-up, no label), treat the label as absent = `UNKNOWN`.

## §R7 Failure modes & pitfalls

Honest degradation contract: `UNKNOWN` is **restrictive** — downstream
halves size, widens stops, stands down new entries (never treated as
benign, §R0.5). `DEGRADED` means the label is **withheld** (warm-up,
auction): consumers must treat a withheld label as `UNKNOWN`, not as
"still normal". Recovery always ends with a decision-log entry before
re-arm (R0.8 runbook).

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Stale SI as live → detect: input vintage > `2` weeks [default] → action: `UNKNOWN` unless 2 of 3 inputs fresh → recovery: hold last label max `3`× cadence, then `OFF`; recompute on next SI release | `check: vintage fresh` |
| 2 | COT release delayed (Friday holiday) → detect: release missing at Friday `15:30` ET + `1` day [default] → action: `UNKNOWN` → recovery: ingest the delayed release, recompute with corrected vintage tags, log the gap | `check: release calendar` |
