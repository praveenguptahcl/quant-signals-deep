### R0.5 Lag contract (mandatory)

- **Indicator causal rule:** the indicator at time `t` is computed using only
  data with `event_ts ≤ t`. Bar-close values of bar `t` are unavailable until
  bar `t` finalizes.
- **Gating rule:** a regime label computed at `t` may gate a signal evaluated
  at `t` **only for trades executable at `t+1` or later** — never for fills
  inside bar `t`.
- **Backtest lag:** any backtest conditioning on this regime must lag the
  label by ≥ `1` bar [default] (min_lag = `1` bar [default]; component z's use history ≤ t; SI/COT lags carried as vintage tags).
- **Adversary check (no-lookahead):** the test suite asserts
  `label_ts > indicator_ts` for the earliest gated trade and that appending a
  synthetic breakout bar does not move the trailing percentile used at `t`.
- **unknown_behavior:** `UNKNOWN` is restrictive — downstream halves size /
  widens stops / stands down; never treated as benign (F1).

## §R1 Precise definition

Composite z = mean(PCR z, SI% z, COT z), sign-aligned (+ = crowded long) [documented construction]. Cross-check: median composite; absolute tolerance `0.5` [default]. Verifier requires ≥2 of 3 inputs fresh or `UNKNOWN` [documented RB-list].

## §R2 Exact calculation

$$z^{crowd} = \tfrac{1}{3}\,(z^{PCR} + z^{SI} + z^{COT}) \quad\text{[documented]}$$

Worked example [documented Grok RB2]: SI `12.0m`/float `80.0m` = `15.0%`; DTC = `12/2.5 = 4.8` days ⇒ crowded short / elevated unwind risk. Bands [example]: `|z| < 1` normal · `1–2` crowded · `> 2` extreme.

**Data inputs.** CBOE total put/call (21-day MA), FINRA short interest / float (bi-weekly), CFTC COT net non-commercial (weekly-lagged).

**Cadence.** weekly.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Momentum/trend | **amplifies then inverts** | improves entering uncrowded; dies when extremely crowded (no marginal buyer; reversals violent) |
| Mean-reversion | **amplifies** | improves at crowding extremes (the unwind *is* the reversion) |
| Momentum shorts after panic | **inverts** | dies — Daniel–Moskowitz (2016): crashes cluster after lagged declines; the short leg rebounds violently |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** maintains the composite; publishes RSV with vintage tags.
- **Verifier:** median-composite cross-check; requires ≥2 of 3 inputs fresh [documented RB-list].
- **Grok-Researcher:** proposes windows; leads only.
- **Adversary:** checks composite weights were fixed ex ante (no weight-mining); checks SI lag is carried into any compound score.
- **Gate:** rejects live use of bi-weekly SI; rejects fading crowded without a catalyst as a backtested claim.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Crowding concentrates exit risk: the adjustment halves size for new entries in the crowded direction and flags the short leg for squeeze-aware placement (DTC + borrow, not narrative).

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    if rsv['state'].startswith('extreme'):
        adj['size_mult'] = 0.5        # [example] air-pocket risk
        adj['contrarian_watch'] = True  # [default]
    elif rsv['state'].startswith('crowded'):
        adj['size_mult'] = 0.75       # [example] fade new entries
    else:
        adj['size_mult'] = 1.0        # [default]
    return adj
```
