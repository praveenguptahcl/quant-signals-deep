### R0.2.1 Calibration procedure (per parameter — grid + OOS selection, no hand-tuning in production)

- **Data for calibration:** historical rebalance events `2015–2025` [example] — announcements + effective dates from index providers; index AUM estimates quarterly from ETF issuer disclosures; ADV (`adv_window_days`-day [example]) and split-adjusted prices from Norgate US Stocks Platinum. Event universe frozen ex ante (benchmarks file, git-tagged); no adding names after seeing results.
- `entry_large` (`0.25` [example]): grid `{0.15, 0.20, 0.25, 0.30, 0.40}` [example]; `exit_large = entry_large − {0.02, 0.05}` [example]. Objective (pick ONE ex ante [default]): maximize Spearman rank correlation between π and next-session abnormal volume, or maximize net-of-cost Sharpe of a canonical front-run/completion strategy gated by the label. Selection: purged walk-forward by calendar year with a `5`-session [example] embargo; choose on validation years, lock, evaluate once on held-out test years. Sensitivity: high — this is the flow-dominance line.
- `entry_moderate` (`0.05` [example]): grid `{0.03, 0.04, 0.05, 0.06, 0.08}` [example]; `exit_moderate = entry_moderate − 0.01` [example]; same OOS protocol. Sensitivity: medium.
- `pre_window_days` / `post_window_days` (`5` / `1` [example]): grid `{3, 5, 10}` × `{0, 1, 2}` [example]; objective: cover `≥95`% [example] of realized close-auction volume-spike days with the smallest window. Sensitivity: medium — wider windows dilute the gate.
- `adv_window_days` (`20` [example]): grid `{10, 20, 60}` [example]; stability criterion: ADV estimate coefficient of variation `< 0.5` [example] on the calibration panel. Sensitivity: low.
- `stale_aum_quarters` (`1` [example]): NOT calibrated — safety invariant. AUM vintage older than one quarter ⇒ `UNKNOWN` (F4). Sensitivity: n/a (fail-safe, not a tuning knob).
- `dual_tol` (`1e-12` [default]): numerical-agreement floor between the two estimator orderings; not a trading parameter.
- **Re-cal cadence:** annually after the December quarterly rebalance [example], or immediately on an index methodology change (which invalidates all bands → `UNKNOWN` until re-run, §R7.9). Every re-cal logs a new `params_hash` and bumps the module minor version.

### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).
- `NO_FLOW` labels never gate; hysteresis memory is untouched by `UNKNOWN` or
  `NO_FLOW` emissions.

## §R2 Precise definition

Mechanical index flow gauge: participation rate π = shares_to_trade / ADV, where shares_to_trade = Δw × AUM / price. A large π means the rebalance flow dominates the name's normal volume — the flow *is* the price action into the effective date. AUM estimates are order-of-magnitude inputs, not fill predictors.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
# ---- per-event estimation (pure functions; unit-testable) ----
function estimate_v1(w, aum_bn, price, adv) -> float:      # primary
    return w * aum_bn * 1e9 / price / adv                  # shares_to_trade / ADV

function estimate_v2(w, aum_bn, price, adv) -> float:      # dual (F3)
    return (w * 1e9 * aum_bn) / price / adv               # same math, independent order

function transition(prev, pi, cfg) -> label:              # hysteresis state machine
    if prev == ADD_LARGE:
        if pi < cfg.exit_large:
            return ADD_SMALL if pi < cfg.exit_moderate else ADD_MODERATE
        return ADD_LARGE                                  # hold inside (exit_large, entry_large)
    if prev == ADD_MODERATE:
        if pi >= cfg.entry_large:   return ADD_LARGE
        if pi < cfg.exit_moderate:  return ADD_SMALL
        return ADD_MODERATE                               # hold inside (exit_moderate, entry_large)
    # prev == ADD_SMALL (also the cold-start state for a new symbol)
    if pi >= cfg.entry_large:    return ADD_LARGE         # entry inclusive
    if pi >= cfg.entry_moderate: return ADD_MODERATE      # entry inclusive
    return ADD_SMALL

# ---- module entry point ----
function detect(state, events, cfg) -> list[RegimeState]:
    assert cfg.exit_large < cfg.entry_large                # hysteresis invariants
    assert cfg.exit_moderate < cfg.entry_moderate
    if state is None: state = {labels: {}}                 # per-symbol hysteresis memory
    if len(events) == 0: return [UNKNOWN]                  # F1
    out = []
    for e in events:                                       # ascending event_ts; causal per prefix
        ts = e.ts_ns; sym = e.symbol
        if e.market_state == HALTED:
            out.append(UNKNOWN(ts)); continue              # freeze; memory untouched
        degraded = (e.market_state == AUCTION)
        (w, aum, price, adv) = parse(e.w_new, e.aum_bn, e.price, e.adv)
        if any unparseable or missing:                     # missing bars surface here:
            out.append(UNKNOWN(ts)); continue              # F1 — never interpolate
        if not all finite or price <= 0 or adv <= 0 or w < 0 or aum <= 0:
            out.append(UNKNOWN(ts)); continue              # F2
        if e.ca_adjusted == false:                         # split/dividend between
            out.append(UNKNOWN(ts)); continue              # announcement and effective
                                                           # date, price not adjusted — F2
        if quarter_diff(ts, e.aum_vintage) > cfg.stale_aum_quarters:
            out.append(UNKNOWN(ts)); continue              # F4 — stale AUM
        v1 = estimate_v1(w, aum, price, adv)
        v2 = estimate_v2(w, aum, price, adv)
        if not finite(v1) or abs(v1 - v2) > cfg.dual_tol:
            out.append(UNKNOWN(ts, v1)); continue           # F3 — dual estimator disagree
        lo = e.effective_date_ns - cfg.pre_window_days * DAY_NS
        hi = e.effective_date_ns + cfg.post_window_days * DAY_NS
        if not (lo <= ts <= hi):
            out.append(RegimeState(NO_FLOW, v1, OK, ts))    # window gate: gauge
            continue                                       # computed, label does not gate
        prev = state.labels.get(sym, ADD_SMALL)            # cold start = ADD_SMALL
        label = transition(prev, v1, cfg)
        state.labels[sym] = label                          # memory updated on OK/DEGRADED only
        out.append(RegimeState(label, v1, DEGRADED if degraded else OK, ts))
        log_decision(label, v1, inputs_hash(e), params_hash(cfg))   # Appendix g
    assert fill_event > signal_event   # t→t+1 causality: labels gate trades at t+1+
    return out
```

Edge cases handled: empty event list (F1); unparseable/missing fields incl. a
missing adjusted bar for the event date (F1, never interpolate); non-finite or
non-positive price/ADV (F2); corporate action unadjusted through the effective
date (F2); stale AUM vintage (F4); dual-estimator disagreement (F3);
HALTED → freeze + `UNKNOWN` with memory untouched; AUCTION → `DEGRADED`, hold
last label; events outside `[effective_date − pre_window_days,
effective_date + post_window_days]` → `NO_FLOW` (value still emitted, never
gates). `UNKNOWN` emissions never update hysteresis memory.

## §R3 Exact calculation

Weight change `Δw`, index AUM `A`, price `P`, average daily volume
`ADV`:

$$N = \frac{\Delta w \times A}{P}, \qquad
\pi = \frac{N}{ADV}$$

Worked check [example]: `Δw = 0.0015`, `A = $200`B, `P = $50`, `ADV = 8`M →
`N = 6.0`M shares, `π = 0.75` → ADD_LARGE. Second: `Δw = 0.0002`, `A = $200`B,
`P = $120`, `ADV = 20`M → `π ≈ 0.0167` → ADD_SMALL.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Index weight changes; AUM estimate + vintage; split-adjusted price; ADV (`adv_window_days`-day [example]); effective-date calendar.

**Cadence.** Daily on the rebalance calendar.

**Threshold bands (hysteresis — entry vs exit).**

| `π` | Entered from below at | Exited below | State | Tag |
|---|---|---|---|---|
| `≥ 0.25` | `entry_large = 0.25` (inclusive) | — | ADD_LARGE | [example] |
| hold | — | `exit_large = 0.20` | ADD_LARGE (hold zone `0.20 ≤ π < 0.25`) | [example] |
| `≥ 0.05` | `entry_moderate = 0.05` (inclusive) | — | ADD_MODERATE | [example] |
| hold | — | `exit_moderate = 0.04` | ADD_MODERATE (hold zone `0.04 ≤ π < 0.25`) | [example] |
| `< 0.05` | — | — | ADD_SMALL | [example] |

State-transition diagram (normative; matches `transition/3` in §R2):

```
ADD_SMALL --π ≥ 0.25--> ADD_LARGE --π < 0.20--> ADD_MODERATE
    | --π ≥ 0.05--> ADD_MODERATE --π < 0.04--> ADD_SMALL
    ^                                                        |
    └────────────── π < 0.04 from ADD_LARGE ─────────────────┘
```
(all band constants [example]; see the table above)

Boundary pins (fixture-enforced): `π = 0.25` exactly → ADD_LARGE (entry
inclusive); `π = 0.05` exactly → ADD_MODERATE (entry inclusive); `π = 0.20`

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

**Which cost components scale:** impact only. When index flow is `≥ entry_large`
(`0.25` [example]) of ADV, the continuous-session tape is dominated by
one-directional mechanical flow: a strategy trading *with* the flow realizes
roughly `2`× [example] its reference impact, and a strategy fading it faces
adverse selection (handled by the §R4 `degrades` gate, not by cost). Spread,
fees, and borrow are untouched by this regime at daily cadence (identity
multipliers [default]) — any venue-specific spread widening on the effective
date is a calibration item, not a default.

**Application rule.** The consumer computes its reference cost stack, then
multiplies `impact_bps` by the regime's `impact_mult` for any trade scheduled
inside `[effective_date − pre_window_days, effective_date + post_window_days]`
(`5` / `1` days [example]); `spread_bps`, `fee_bps`, `borrow_bps` are
untouched. The multipliers are `[example]` placeholders — calibrate per venue
by regressing realized slippage against participation on historical rebalance
tapes, re-pin quarterly [example]. The record is versioned with
`estimator_version` and every application is decision-logged (Appendix g
v1.0.0).

## §R7 Failure modes (trigger → detect → action → recovery)

Honest degradation contract: `UNKNOWN` means "do not trust this label" (gates
downstream to no-trade); `DEGRADED` means "last good label held, treat with
suspicion"; the module never emits a confident label from incomplete inputs.

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Missing announcement for a calendar name → detect: no event by `effective_date − pre_window_days` (`5` [example]) → action: `UNKNOWN` for that symbol, page → recovery: backfill announcement, replay fixture | `check: event present for every calendar name` |
| 2 | Non-finite π, `ADV ≤ 0`, `price ≤ 0` (F2) → detect: bounds assertion in `detect` → action: `UNKNOWN` + page → recovery: fix vendor series, replay | `check: isfinite(pi) and adv > 0 and price > 0` |
| 3 | Corporate action unadjusted through effective date → detect: `ca_adjusted == 0` → action: `UNKNOWN` + page → recovery: apply adjustment factor, recompute π | `check: ca_adjusted == 1` |
| 4 | Missing adjusted bar for event date → detect: price unparseable → action: `UNKNOWN` (F1), never interpolate → recovery: backfill bar, replay | `check: bar present for event date` |
| 5 | Dual-estimator disagreement (F3) → detect: `|v1 − v2| > dual_tol` (`1e-12` [default]) → action: `UNKNOWN` + page → recovery: investigate float/ingest divergence | `check: abs(v1 - v2) <= dual_tol` |
| 6 | Stale AUM vintage (F4) → detect: `quarter_diff > stale_aum_quarters` (`1` [example]) → action: `UNKNOWN` + notify → recovery: refresh AUM table, replay | `check: quarter_diff(event, aum_vintage) <= 1` |
| 7 | Published label staleness (F4) → detect: `now − computed_at > 3`× cadence [default] → action: expire to `UNKNOWN` + notify → recovery: re-run `detect` on fresh events | `check: now_ns - computed_at <= 3 * CADENCE_NS` |
| 8 | Halt → detect: `market_state == HALTED` → action: freeze hysteresis memory, emit `UNKNOWN`, discard contributions across reopen → recovery: resume on next CONTINUOUS_TRADING event | `check: no label emitted from halted events` |
| 9 | Auction → detect: `market_state == AUCTION` → action: hold last label, emit `DEGRADED` → recovery: recompute on continuous trading | `check: auction emits DEGRADED with held label` |
| 10 | Index methodology change → detect: methodology version ≠ pinned version → action: `UNKNOWN` for the affected index + notify → recovery: re-run §R0.2.1 calibration, bump minor version | `check: methodology version pinned in config` |
| 11 | Kill / administrative disable → action: `OFF` + page → recovery: runbook re-arm checklist (§R0.7) | `check: kill switch tested` |
