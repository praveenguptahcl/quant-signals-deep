### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Event-driven macro state: around scheduled releases (NFP, CPI, PPI, FOMC, ECB, BoE, BoJ — the RB-list's eight [example]), the magnitude-of-surprise index M = |actual − consensus| / σ_hist [example] determines the window state. Only actual release timestamps are used — scheduled timestamps that slip silently shift the window (the Adversary tests a slipped release).

## §R3 Exact calculation

Per release `k` with actual `A_k`, consensus `C_k`, trailing surprise
std `σ_k`:

$$M_k = \frac{|A_k - C_k|}{\sigma_k}, \qquad
t_{rel} = t - T_{actual,k}$$

Window state at `t`: `ACTIVE` if `|t_rel| ≤ 45` min [example] around the release
or `M_k ≥ 3` [example]; `WATCH` if `M_k ≥ 1.5` [example]; else `QUIET`.
Worked check: NFP `M = 3.0` at `t_rel = −60` min → ACTIVE (surprise band);
`M = 1.4` at `t_rel = +120` min → QUIET.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Release calendar with actual timestamps; consensus and actual values; trailing surprise std per release.

**Cadence.** Intraday (`60` s [example]) around releases; daily otherwise.

**Threshold bands.**

| `M` | State | Tag |
|---|---|---|
| `≥ 3.0` | ACTIVE — vol expansion, spreads widen | [example] |
| `1.5–3.0` | WATCH | [example] |
| `< 1.5` | QUIET | [example] |

## §R4 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: macro-factor / news-momentum | amplifies | the surprise *is* the trade; directional persistence is highest in the window |
| T: single-name mean-reversion | degrades | cross-name correlation spikes; mean-reversion fills worsen |
| T: liquidity provision | degrades-then-amplifies | spreads widen (worse), then post-release volume rewards provision |
