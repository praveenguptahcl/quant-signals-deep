### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Event-driven macro state: around scheduled releases (NFP, CPI, PPI, FOMC, ECB, BoE, BoJ — the RB-list's eight [example]), the magnitude-of-surprise index M = |actual − consensus| / σ_hist [default] determines the window state. Only actual release timestamps are used — scheduled timestamps that slip silently shift the window (the Adversary tests a slipped release).

State is assigned by a **hysteresis machine**: entry thresholds differ from exit
thresholds so the label cannot flap when M hovers at a boundary. Exact entry
values (`==`) always enter; exits require strictly below the exit band.

| Previous | Condition | Next |
|---|---|---|
| QUIET / UNKNOWN | `M ≥ 3.0` [default] or `\|t_rel\| ≤ 45` min [default] | ACTIVE |
| QUIET / UNKNOWN | `M ≥ 1.5` [default] | WATCH |
| QUIET / UNKNOWN | otherwise | QUIET |
| WATCH | `M ≥ 3.0` [default] or `\|t_rel\| ≤ 45` min [default] | ACTIVE |
| WATCH | `M < 1.0` [default] | QUIET |
| WATCH | otherwise | WATCH |
| ACTIVE | `\|t_rel\| ≤ 45` min [default] | ACTIVE |
| ACTIVE | `M < 1.0` [default] | QUIET |
| ACTIVE | `M < 2.5` [default] | WATCH |
| ACTIVE | otherwise | ACTIVE |

### Normative detection pseudocode

```python
# R036 detect — normative. All thresholds from cfg (§R0.2); prose is commentary.
def detect(state, events, cfg):
    out = []
    prev = state.prev_label if state else "QUIET"   # cold start [default]
    for e in sorted(events, key=lambda x: x.event_ts):  # out-of-order guard;
        # late events older than TTL are dropped (F4), never reprocessed
        ms = market_state(e)
        if ms == "HALTED":                          # freeze (F-H2, §R7.1)
            freeze(state); out.append(label("UNKNOWN", "UNKNOWN", e)); continue
        if ms == "AUCTION":                         # hold last label
            out.append(label(prev, state.prev_value, e, module_state="DEGRADED"))
            continue
        if ms == "CLOSED":
            continue                                # emit nothing; state OFF
        rel = get_release(e.release_id)             # idempotent on release_id:
        # duplicate release events collapse to one (first print wins)
        if rel is None or rel.actual is None:
            out.append(label("UNKNOWN", NaN, e, module_state="UNKNOWN")); continue  # F1; prev frozen
        if abs(rel.actual_ts - rel.scheduled_ts) > cfg.f3_ts_tol_s * 1e9:  # 60 s [default] (F3)
            out.append(label("UNKNOWN", NaN, e, module_state="UNKNOWN")); continue
        if rel.is_revision:                         # keep first print only
            log_revision(rel); continue              # state unchanged
        M = abs(rel.actual - rel.consensus) / rel.sigma_hist
        # sigma_hist over cfg.sigma_lookback_releases = 20 [default] trailing releases
        if not (isfinite(M) and M >= 0.0):          # F2: |.|/sigma can't be negative
            out.append(label("UNKNOWN", M, e, module_state="UNKNOWN")); continue  # prev frozen
        t_rel_min = (e.event_ts - rel.actual_ts) / 60e9   # ns -> minutes
        in_window = abs(t_rel_min) <= cfg.win_half_min    # 45 [default]
        new = transition(prev, M, in_window, cfg)   # hysteresis machine, table above
        rs = RegimeState(regime_id="R036", state=new, value=M,
                         estimator_version="1.1.0", data_vintage=vintage(cfg),
                         computed_at=e.event_ts, module_state="OK",
                         min_lag_bars=cfg.min_lag_bars)
        emit_cost_adjustment(rs)                    # §R5 Cost interface
        decision_log(rs)                            # Appendix g v1.0.0
        prev = new; out.append(rs)
    state.prev_label = prev
    return out
```

### Edge cases (normative)

- **Missing bars:** a bar gap longer than the staleness TTL (`3`× cadence
  [default]) → `UNKNOWN`; resume on the next bar; never interpolate across the
  gap (gap is decision-logged).
- **Halts:** freeze; emit `UNKNOWN`; discard any partial-window contributions
  across the reopen; require `1` full cadence [default] of clean bars before
  returning to `OK`.
- **Corporate actions:** not applicable — the macro surprise index is a
  cross-asset information-arrival state; single-name actions are a documented
  no-op (no invented handling).
- **Scheduled vs actual timestamp slip:** disagree by more than `60` s
  [default] → `UNKNOWN` (F3); the window follows the *actual* timestamp only.
- **Revisions:** restatements are versioned and ignored for M; the first print
  is the information event (ALFRED vintage dates give the first-print series
  [documented]).
- **DST transitions:** release times are `America/New_York`-fixed; convert via
  tz database — naive UTC offsets shift the window by `1` h [documented as the
  DST offset] on transition weekends.
- **Duplicate / out-of-order release events:** collapse on `release_id`
  (idempotent); sort by `event_ts`; drop events older than the TTL.

## §R3 Exact calculation

Per release `k` with actual `A_k`, consensus `C_k`, trailing surprise
std `σ_k` (over `20` [default] trailing releases):

$$M_k = \frac{|A_k - C_k|}{\sigma_k}, \qquad
t_{rel} = t - T_{actual,k}$$

Window state at `t` follows the §R2 hysteresis machine. Worked check (from
`QUIET`): NFP `M = 3.0` at `t_rel = −60` min → ACTIVE (entry boundary, `==`
enters); `M = 1.4` at `t_rel = +120` min → QUIET (below watch entry).

*Formula tag: [default] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Release calendar with actual timestamps; consensus and actual values; trailing surprise std per release.

**Cadence.** Intraday (`60` s [example]) around releases; daily otherwise.

**Threshold bands (entry / hysteresis exit).**

| `M` | Entry → state | Exit (strict `<`, out of window) | Tag |
|---|---|---|---|
| `≥ 3.0` | → ACTIVE | stays ACTIVE until `M < 2.5` | [default] |
| `1.5–3.0` | → WATCH | stays WATCH until `M < 1.0` | [default] |
| `\|t_rel\| ≤ 45` min | → ACTIVE (window overrides M) | ACTIVE held while in window | [default] |
| else | QUIET | — | [default] |

### §R3.1 Detection-calibration recipe (no magic numbers)

Every `[default]` threshold above is a starting point, not a finding. Promote
to production only via this recipe:

1. **Data.** `≥ 3` y [example] of release panel (`actual`, `consensus`,
   `actual_ts`, first-print only) for the covered releases, plus `1`-min
   [example] bars of the gated universe around each release (to measure
   spread/vol response). Point-in-time only — no revised prints in the
   surprise series (F5).
2. **Grid.** `M_active_entry ∈ {2.0, 2.5, 3.0, 3.5, 4.0}` [example];
   `M_active_exit = entry − {0.25, 0.5, 0.75}` [example];
   `M_watch_entry ∈ {1.0, 1.25, 1.5, 2.0}` [example];
   `M_watch_exit = entry − {0.25, 0.5}` [example];
   `win_half_min ∈ {30, 45, 60, 90, 120}` [example].
3. **Objective.** Maximize out-of-sample conditioning contrast: the gated
   strategy's Sharpe (or spread-capture) inside ACTIVE vs QUIET, subject to
   ACTIVE duty cycle `≤ 10%` [example] of bars — a window that is always on
   conditions nothing.
4. **Selection (OOS).** Walk-forward by calendar quarter; embargo `5` trading
   days [example] between train and test release sets (no release appears in
   both); pick argmax on the validation fold, report the held-out test fold.
   Publish the full grid table, not just the winner.
5. **Re-cal cadence.** Annually [default], or when ACTIVE duty cycle drifts
   `> 50%` [example] relative from baseline, or after any venue/feed change.
6. **Anti-magic rule.** Every threshold in §R0.2 carries status
   `calibrate`/`default` with this recipe's reference; CI fails a threshold
   whose exit band is not strictly below its entry band.

## §R4 Efficacy modulation

Direction ∈ `amplifies | degrades | inverts`; mechanism states *why*.

| Affected S/T families | Direction | Mechanism |
|---|---|---|
| T: macro-factor / news-momentum | amplifies | the surprise *is* the trade; directional persistence is highest in the window |
| T: single-name mean-reversion | degrades | cross-name correlation spikes; mean-reversion fills worsen |
| T: liquidity provision | degrades-then-amplifies | spreads widen (worse), then post-release volume rewards provision |

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

```python
COST_ADJUSTMENT_R036 = {
    "regime_id": "R036", "version": "1.1.0",
    "ACTIVE": {"spread_mult": 2.0, "impact_mult": 2.0,
               "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[example]"},
    "WATCH":  {"spread_mult": 1.25, "impact_mult": 1.25,
               "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[example]"},
    "NORMAL": {"spread_mult": 1.0, "impact_mult": 1.0,
               "borrow_mult": 1.0, "fee_add_bps": 0.0, "tag": "[default]"},
}
```

| State | Spread × | Impact × | Borrow × | Fee add (bps) | Applies when | Basis |
|---|---|---|---|---|---|---|
| ACTIVE | `2.0` | `2.0` | `1.0` | `0.0` | in window or `M ≥ 3.0` [default] | direction [documented]: Fleming & Remolona (1999) find spreads "widen dramatically at announcement" then "remain moderately wide"; magnitude [example] — calibrate per venue |
| WATCH | `1.25` | `1.25` | `1.0` | `0.0` | `1.5 ≤ M < 3.0` [default] | [example] — partial adjustment, calibrate |
| else (incl. QUIET) | `1.0` | `1.0` | `1.0` | `0.0` | identity | [default] |

**Which components scale and why.** *Spread* scales: the announcement
widens quoted spreads (inventory-control pullback — Fleming & Remolona 1999
[documented]). *Market impact* scales: volatility stays elevated after the
print (Ederington & Lee 1993: "substantially higher than normal for roughly
fifteen minutes and slightly elevated for several hours" [documented]), so
urgency-equivalent fills cost more. *Borrow* does not scale (`1.0` [default]:
no documented borrow-rate channel for macro windows). *Fees* do not scale
(`0.0` [default]: exchange fees are schedule-fixed).

**Application rule.** Apply the ACTIVE record inside the release window or when
`M ≥ M_active_entry`; the WATCH record when the label is WATCH; else identity.
All multipliers `[example]` unless tagged otherwise — calibrate per venue; the
record is versioned with `estimator_version` and every application is
decision-logged (Appendix g v1.0.0).
