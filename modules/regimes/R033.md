### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0). History extends
  *after* z is computed — the current bar never enters its own estimator.
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Joint tail-risk state: co-occurrence of extreme moves across assets, measured by the fraction of benchmarks jointly in their tails (co-exceedance). Crisis if ≥ `3` of `8` benchmarks breach on the same day [example], or `2` consecutive days with ≥ `2` [example] (the streak-promotion rule). The label is hysteretic: once CRISIS, it holds until the count drops below the exit threshold — the label never flickers on the boundary. Crisis state requires Gate-level human acknowledgment to *trade into* — the fail-safe default action on crisis is reduce, never add. Normative form: §R3.

## §R3 Exact calculation

**Units.** `r_{i,t}` = log return on split/dividend-adjusted closes
(total-return), dimensionless; `μ`, `σ` in the same units; `z` dimensionless;
`κ` in σ units; `C_t` an integer count `0–M`.

Per benchmark `i`, return `r_{i,t}`, trailing mean `μ_{i,t}` and std `σ_{i,t}`
over lookback `z_window_days` (population std, `ddof = 0` [default], floored at
`sigma_floor = 1e-6` [default]):

$$z_{i,t} = \frac{r_{i,t} - \mu_{i,t}}{\sigma_{i,t}}, \qquad
C_t(\kappa) = \sum_{i=1}^{M} \mathbf{1}[z_{i,t} < -\kappa]$$

Crisis entry: `C_t ≥ k_crit` with `κ = 2.5` [example], `k_crit = 3` [example],
`M = 8` [example]. Breach is a **strict** inequality: `z = −κ` exactly is not a
breach (pinned in the fixture). The verifier recomputes with the shorter
`z_window_days_w2 = 126` [example] window; crisis-verdict disagreement →
`UNKNOWN` (F3). Worked check: z-values
`−3.1, −2.8, −2.6, −1.2, 0.5, −0.8, 1.1, −2.0` → `C_t = 3 ≥ 3` → CRISIS.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

### §R3.1 Normative pseudocode

```text
# Runs per bar, causal: bar t uses inputs with ts <= t only.
# r_adj[i,t] = log(C_adj[i,t] / C_adj[i,t-1]) on split/dividend-adjusted closes.

function DETECT_BAR(bar, hist, mem, cfg):
    # bar  = {ts, prints: [(bench, r_adj)], mkt}
    # hist = {bench: deque of trailing r_adj, newest last}
    # mem  = {label, prev_C, acked}   # acked set out-of-band by the Gate
    if bar.mkt != CONTINUOUS_TRADING:
        return (UNKNOWN, UNKNOWN, mem)            # freeze: memory untouched
    n = len(bar.prints)
    if n < cfg.M_min_prints:
        return (UNKNOWN, UNKNOWN, mem)            # F1: panel too thin
    degraded = (n < cfg.M)                        # missing prints count as non-breaches
    zs, breaches_w2 = [], 0
    for (bench, r) in bar.prints:
        h = hist[bench]
        if len(h) < cfg.z_min_bars:
            return (UNKNOWN, UNKNOWN, mem)        # warmup: not enough history
        mu  = MEAN(h[-cfg.z_window_days:])
        sd  = MAX(PSTDEV(h[-cfg.z_window_days:], ddof=cfg.ddof), cfg.sigma_floor)
        sd2 = MAX(PSTDEV(h[-cfg.z_window_days_w2:], ddof=cfg.ddof), cfg.sigma_floor)
        z1, z2 = (r - mu)/sd, (r - mu)/sd2
        if not (ISFINITE(z1) and ISFINITE(z2)):
            return (UNKNOWN, UNKNOWN, mem)        # F2: never interpolate
        zs.append(z1)
        breaches_w2 += (z2 < -cfg.kappa)
    for (bench, r) in bar.prints:                 # history extends AFTER z (causal)
        hist[bench].append(r)
    C = COUNT(z < -cfg.kappa for z in zs)         # strict inequality
    if (C >= cfg.k_crit) != (breaches_w2 >= cfg.k_crit):
        return (UNKNOWN, UNKNOWN, mem)            # F3: dual-estimator disagreement
    label = HYSTERESIS(mem.label, mem.prev_C, C, cfg)
    mstate = DEGRADED if (degraded or (label == CRISIS and not mem.acked)) else OK
    mem.label, mem.prev_C = label, C
    return (label, C, mstate, mem)

function HYSTERESIS(prev, prev_C, C, cfg):
    if prev == CRISIS:
        return CRISIS if C >= cfg.k_exit_crisis else WATCH
    if prev == WATCH:
        if C >= cfg.k_crit: return CRISIS
        if C >= cfg.k_watch and prev_C >= cfg.k_watch: return CRISIS  # streak_days = 2 [example]
        if C < cfg.k_exit_watch: return NORMAL
        return WATCH
    if C >= cfg.k_crit: return CRISIS      # jump straight from NORMAL allowed
    if C >= cfg.k_watch: return WATCH
    return NORMAL
```

Edge cases (normative): **missing bars** — gap policy is mask; the staleness
watchdog (F4) expires the label to `UNKNOWN` after `3`× cadence [default]
without a fresh bar. **Halts** — a single halted benchmark is a missing print
(§R5 row 1); a whole-market `HALTED`/`AUCTION` event freezes the hysteresis
memory and emits `UNKNOWN` per §R0.5. **Corporate actions** — `r_adj` must come
from split/dividend-adjusted closes (`StockPriceAdjustmentType.TOTALRETURN`
[documented]); a benchmark whose corporate action cannot be resolved is dropped
to a missing print — z is never computed on unadjusted prices (§R5 row 7).

### §R3.2 Threshold bands (with hysteresis)

| From \ `C_t` | `0` | `1` | `2` | `≥ 3` |
|---|---|---|---|---|
| NORMAL | NORMAL | NORMAL | WATCH | CRISIS |
| WATCH | NORMAL | WATCH | WATCH (streak day 1) → CRISIS on 2nd consecutive | CRISIS |
| CRISIS | WATCH | WATCH | CRISIS (hold) | CRISIS |

`k_exit_crisis = 2`, watch entry at `k_watch = 2`, watch exit below
`k_exit_watch = 1`, streak promotion after `streak_days = 2` consecutive days
with `C_t ≥ 2`.

### §R3.4 Worked transition check

`C_t` sequence `0, 1, 2, 3, 2, 1, 0` from NORMAL yields labels
`NORMAL, NORMAL, WATCH, CRISIS, CRISIS, WATCH, NORMAL` — the `3 → 2` step holds
CRISIS (hysteresis), the `2 → 1` step exits to WATCH. Two consecutive `2`s
from WATCH promote to CRISIS (streak rule). Pinned in `R033_tape.csv` bars
`1–9` [example].

## Cost interface: regime state → cost-function adjustment

The regime state maps to an adjustment record applied to the strategy's
`expected_cost_bps(notional, adv_pct, venue, side, urgency)` inputs. The record
is the *only* cost channel (no cost numbers are restated elsewhere).

```python
COST_ADJUSTMENT_R033 = {
    "regime_id": "R033", "version": "1.1.0",  # [default] version pin
    "CRISIS": {"spread_mult": 5.0, "impact_mult": 5.0, "borrow_mult": 2.0,  # [example]
               "fee_add_bps": 0.0,  # [default]
               "edge_mult": 2.0,  # [example] required-edge multiplier
               "directional_ok": False, "tail_hedge_ok": True, "tag": "[example]"},
    "WATCH":  {"spread_mult": 2.0, "impact_mult": 2.0, "borrow_mult": 1.0,  # [example]
               "fee_add_bps": 0.0,  # [default]
               "edge_mult": 1.5,  # [example]
               "directional_ok": True, "tail_hedge_ok": True, "tag": "[example]"},
    "NORMAL": {"spread_mult": 1.0, "impact_mult": 1.0, "borrow_mult": 1.0,  # [default]
               "fee_add_bps": 0.0, "edge_mult": 1.0,  # [default]
               "directional_ok": True, "tail_hedge_ok": True, "tag": "[default]"},
}
```

| Cost component | CRISIS | WATCH | NORMAL |
|---|---|---|---|
| Spread × | `5.0` [example] | `2.0` [example] | `1.0` [default] |
| Impact × | `5.0` [example] | `2.0` [example] | `1.0` [default] |
| Borrow × (per day) | `2.0` [example] | `1.0` [example] | `1.0` [default] |
| Fee add (bps) | `0.0` [default] | `0.0` [default] | `0.0` [default] |
| Required-edge × | `2.0` [example] | `1.5` [example] | `1.0` [default] |
| Directional entries | blocked | allowed | allowed |
| Tail-hedge entries | allowed | allowed | allowed |

**Which components scale and why.** Spread and impact scale hardest — liquidity
evaporates in a crisis; borrow scales because short demand spikes into stress;
exchange/regulatory fees do not move with regime (`0.0` [default]). The
required-edge multiplier is the primary gate: in CRISIS only explicit
tail-hedge flow may trade, and it must clear `2`× edge [example].

**Application rule.** Multipliers apply to the strategy's `expected_cost_bps`
inputs for *residual* exposure only — directional stands down in CRISIS, so the
`5.0`× rows are shown for completeness of the interface, not as a trading
assumption. The label gates trades at `t+1`, so the adjustment first bites at
`open(t+1)`. Every application is decision-logged (Appendix g v1.0.0); the
record is versioned with `estimator_version`. NORMAL is the identity
[default]. All non-default multipliers are [example] starting points —
calibrate per venue (GROK-NEEDED: documented crisis spread/impact/borrow
widening magnitudes).
