## §R1 Precise definition

Robust z = (reported_liq − median30)/(1.4826 × MAD30) [documented construction].
The `1.4826` = 1/Φ⁻¹(3/4) is the MAD→σ consistency constant for a Gaussian
(R `mad` docs; Wikipedia "Robust measures of scale") [documented] — it is a
fixed mathematical constant, not a calibrated parameter. Labels use
**hysteresis bands**: enter stress at z ≥ `3.0` [default], exit below `2.5`
[default]; enter cascade at z ≥ `6.0` [default], exit below `4.5` [default].
Cross-check: robust z on a `25`-day baseline [default]; relative tolerance
`0.5` [default].

## §R2 Exact calculation

$$z = \frac{reported\_liq - median_{30}}{1.4826\times MAD_{30}} \quad\text{[documented]}$$

Worked example [documented Grok RB3]: reported `$480M`, median30 `$90M`, MAD `$25M` → `z = 390 / 37.065 ≈ 10.52` ⇒ cascade; raw ratio `5.33×`.

**Data inputs.** daily reported liquidations — `aggregated_long_liquidation_usd` + `aggregated_short_liquidation_usd` summed to `reported_liq` (USD), per §R0.3 [documented].

**Cadence.** daily (`1d` buckets).

### R2.1 Normative detection pseudocode

Pseudocode is normative; prose is commentary. `prev` persists across bars
in the module state vector (init `"normal"` [default]).

```
function detect(state, events, cfg) -> RegimeState:
    rows = events sorted by event_ts ascending
    if rows empty: return RSV(state="missing", module_state=UNKNOWN)      # F1
    baseline = []          # reported_liq in USD, causal; masked at breaks
    prev = state.prev_label # "normal" | "stress" | "cascade"
    for i, e in enumerate(rows):
        if e.vintage_break:                    # symbol redenomination / contract
            baseline = []; prev = "normal"      # migration / delisting: re-baseline,
                                               # never interpolate across the break
        x = e.reported_liq_usd
        if x is null or x < 0:
            emit(i, state="invalid", module_state=UNKNOWN); continue     # F1
        if i > 0 and e.event_ts - rows[i-1].event_ts > 1.5 * cadence:
            baseline.append(x)                   # keep the value for the window
            emit(i, state="gap", module_state=UNKNOWN); continue  # mask, no interpolation
        baseline.append(x)
        if len(baseline) < cfg.base_days:
            emit(i, state="warming", module_state=DEGRADED); continue    # F1 warm-up
        hist = last cfg.base_days values of baseline, excluding current bar
        med = median(hist); mad = median(|h - med| for h in hist)
        if mad == 0: z = +inf if x > med else (-inf if x < med else 0.0)
        else:        z = (x - med) / (1.4826 * mad)
        prev = transition(prev, z, cfg)          # §R2.2 hysteresis
        emit(i, state=prev, value=z, module_state=OK)
    newest = last emitted label
    F2: require isfinite(z) and |z| <= 1e4 [default], else UNKNOWN        # garbage bounds
    F3: dual robust-z on verify_base_days window must agree within dual_tol (rel), else UNKNOWN
    F4: if now - computed_at > 3 * cadence: UNKNOWN (staleness)
    return newest as RegimeState

function transition(prev, z, cfg):            # entries strict (>=); exits release below
    if prev == "cascade": return "cascade" if z >= cfg.cascade_exit else "stress"
    if prev == "stress":
        if z >= cfg.cascade_entry: return "cascade"
        if z <  cfg.stress_exit:   return "normal"
        return "stress"
    if z >= cfg.cascade_entry: return "cascade"   # from normal/warming
    if z >= cfg.stress_entry:  return "stress"
    return "normal"
```

**Edge cases (normative).** Missing bars → `gap`/`UNKNOWN`, baseline keeps
subsequent values, the missing bar's z is never interpolated. Venue halt /
maintenance (no bars published) → same gap path; contributions across the
reopen are discarded, never smoothed. Corporate-action analogue (coin
redenomination, contract migration, delisting/relisting): set
`vintage_break` on the first bar of the new symbol — baseline restarts,
module is `DEGRADED` until `base_days` post-break bars exist. Negative or
null prints → `invalid`/`UNKNOWN` (never clamped to zero — a negative print
is a feed bug, not a quiet day). Flat baseline (MAD = `0`) → z = ±inf →
F2 `UNKNOWN` until variance returns.

### R2.2 Hysteresis transition table (pinning)

Defaults: stress_entry `3.0` / stress_exit `2.5` / cascade_entry `6.0` /
cascade_exit `4.5` [default].

| prev \ z | z < `2.5` | `2.5` ≤ z < `3.0` | `3.0` ≤ z < `4.5` | `4.5` ≤ z < `6.0` | z ≥ `6.0` |
|---|---|---|---|---|---|
| normal | normal | normal | stress | stress | cascade |
| stress | normal | stress | stress | stress | cascade |
| cascade | stress | stress | stress | cascade | cascade |

Guard bands (`2.5–3.0`, `4.5–6.0`) hold the prior state — this is what stops
the label flapping on boundary noise. Cascade exits through stress (one bar
minimum in stress before normal) [default].

### R2.3 Threshold bands (summary)

| Condition | Label | Tag |
|---|---|---|
| entry z ≥ `3.0`, exit z < `2.5` | stress (halve leverage) | [default] |
| entry z ≥ `6.0`, exit z < `4.5` | cascade (stand aside) | [default] |

The documented content is the robust-z construction and the lower-bound

## §R5 Cost interface: regime state → cost-function adjustment

`cost_adjustment(rsv, base) -> dict` — `rsv` is the regime_state_vector,
`base` is the T-module COST-block dict. Which components scale, by state:

- **cascade:** hard veto — `trade_ok = False`, `size_mult = 0.0` [default].
  No cost curve survives a mechanical unwind; the adjustment does not try
  to price the cascade, it stands aside.
- **stress:** multiplicative widening — `spread_mult = 2.0` [example],
  `impact_mult = 3.0` [example], `slippage_buffer_bps = 50` [example],
  `size_mult = 0.5` [example]. Fees and borrow do **not** scale
  (`fee_mult = 1.0`, `borrow_mult = 1.0` [default] — perps have no
  stock-borrow leg; funding is priced in the T-module cost block).
- **normal:** identity — all multipliers `1.0` [default].
- **`UNKNOWN` module state (restrictive default):** `trade_ok = False`
  regardless of label — never treated as benign.

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    st = rsv['state']
    if st == 'cascade':
        adj['trade_ok'] = False        # [default] stand aside
        adj['size_mult'] = 0.0          # [default]
        adj['reason'] = 'R023 cascade - mechanical unwind; stand aside'
    elif st == 'stress':
        adj['trade_ok'] = True
        adj['size_mult'] = 0.5          # [example]
        adj['spread_mult'] = 2.0        # [example] spreads widen
        adj['impact_mult'] = 3.0        # [example] impact blows out
        adj['slippage_buffer_bps'] = 50 # [example]
        adj['fee_mult'] = 1.0           # [default] fees do not scale
        adj['borrow_mult'] = 1.0        # [default] no borrow leg in perps
        adj['reason'] = 'R023 stress - halve size, widen cost'
    else:  # normal
        adj['trade_ok'] = True
        adj['size_mult'] = 1.0          # [default]
        adj['spread_mult'] = 1.0        # [default]
        adj['impact_mult'] = 1.0        # [default]
        adj['fee_mult'] = 1.0           # [default]
        adj['borrow_mult'] = 1.0        # [default]
        adj['reason'] = 'R023 normal'
    if rsv.get('module_state') == 'UNKNOWN':
        adj['trade_ok'] = False         # [default] restrictive
        adj['reason'] = 'R023 UNKNOWN - restrictive default'
    return adj
```

The multipliers above are starting points from the §R2.4 calibration
mindset — re-fit `spread_mult`/`impact_mult` per venue from realized
slippage before sizing real capital [internal-est].
