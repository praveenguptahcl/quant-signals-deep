## §R1 Precise definition

Put/call ratio regime: the CBOE equity put/call volume ratio level. High = fear (put buying) = contrarian-long weather; low = complacency = short-premium weather with crash risk. The series definition (equity-only) is fixed ex ante.

Documented series facts (see §R9): CBOE publishes daily summary data including an equity put/call calculation that isolates single-stock options flow trading on the Cboe Options Exchange (C1) [documented]. Over a recent five-year window the daily average ranged about `0.4`–`0.8` with a trendline near `0.6` — roughly three puts for every five calls [documented]; extremes spiked to `0.85` in Q1 2020 while `18` months at very low levels near `0.4` marked the 2020–21 bull run [documented]. The classic contrarian reading — high ratios = excessive pessimism (buy), low ratios = excessive optimism (sell) — is documented in practitioner literature (Schaeffer, via *New Thinking in Technical Analysis*) [documented]; Webb, Simon & Wiggins (2001) found the put–call ratio had statistically and economically significant forecasting power for S&P 500 futures over `10`/`20`/`30`-day horizons and that fear-indicator extremes marked buying opportunities, including in out-of-sample trading simulations [documented].

## §R2 Exact calculation

Published ratio `PCR_t = P_t / C_t` (volumes). State is assigned by the
hysteresis machine below — the pseudocode is normative; prose is commentary.

**Normative pseudocode** (handles missing prints, bounds, halts, corporate
actions, hysteresis; never interpolates):

```
function DETECT(state, events, cfg):                 # cfg: fear, greed, hysteresis, bounds_hi
    if events is empty: return [UNKNOWN]             # F1
    out = []
    prev = state.prev_state or "NORMAL"
    for e in events (ascending event_ts):
        if market_state(e) in {HALTED}:             # §R0.5
            out.append(UNKNOWN); continue           # prev frozen
        pcr = parse_float(e.pcr)                     # adj_flag IGNORED (documented no-op)
        if pcr is not finite:                       # F1
            out.append(UNKNOWN); continue           # prev frozen
        if not (0 < pcr < cfg.bounds_hi):           # F2
            out.append(UNKNOWN); continue           # prev frozen
        st = HYSTERESIS_LABEL(pcr, prev, cfg)        # below
        prev = st                                    # only OK emits advance prev
        out.append(OK(st, value=pcr))
    state.prev_state = prev
    return out

function HYSTERESIS_LABEL(pcr, prev, cfg):          # h = cfg.hysteresis
    h = cfg.hysteresis
    if prev == "FEAR" and pcr >= cfg.fear - h:      # hold, inclusive
        return "FEAR"
    if prev == "COMPLACENCY" and pcr <= cfg.greed + h:  # hold, inclusive
        return "COMPLACENCY"
    if pcr >= cfg.fear:                             # entry, inclusive
        return "FEAR"
    if pcr <= cfg.greed:                            # entry, inclusive
        return "COMPLACENCY"
    return "NORMAL"
```

**State-transition semantics.** Entry bands are inclusive (`1.20` → FEAR,
`0.60` → COMPLACENCY) [default]; exits are strict on the hysteresis-offset
band (`1.10` == `fear − h` still holds FEAR, `1.099` exits to NORMAL; `0.70`
== `greed + h` still holds COMPLACENCY, `0.701` exits) [default]. A print that
crosses both hold intervals in one bar falls through to the stateless entry
bands (e.g. FEAR → `0.60` → COMPLACENCY, no intermediate NORMAL required)
[default]. `UNKNOWN` never advances `prev_state`: hysteresis resumes correctly
when the print returns [default].

**Threshold bands** (with `hysteresis` = `0.1` [default]; entry/exit semantics above):

| PCR | State | Tag |
|---|---|---|
| `≥ 1.2` | FEAR | [default] |
| `0.6–1.2` | NORMAL | [default] |
| `≤ 0.6` | COMPLACENCY | [default] |

**Calibration recipe** (normative — run before production; the shipped bands
are placeholders, not calibrated values):

1. **Training data** [default]: daily CBOE equity P/C series (public prints,
   §R6) plus the gated strategy's daily returns; at least `5` years [default]
   so the sample spans a full fear/greed cycle.
2. **Candidate grid** [example]: `fear ∈ {1.0, 1.1, 1.2, 1.3, 1.4}`;
   `greed ∈ {0.5, 0.6, 0.7}`; `hysteresis ∈ {0.0, 0.05, 0.10, 0.15}`;
   constraint `fear − hysteresis > greed + hysteresis`.
3. **OOS selection criterion** [default]: walk-forward with expanding training
   windows and `1`-year [default] test blocks, embargo gap `≥ 20` trading days
   [default] between train and test; objective = maximize the gated
   contrarian-reversal strategy's after-cost information ratio net of

the module never guesses.
