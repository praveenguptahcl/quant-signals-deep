### Lag contract

- The indicator is causal: the value/state published for time `t` is computed
  using only inputs with timestamps `≤ t` (Appendix e v1.0.0).
- A regime label finalized at `t` may gate signals only for trades at `t+1`
  or later — `earliest fill @open(t+1)` per the bar-label rule.
- Backtests: regime-conditioned variants lag the label by `≥ min_lag_bars` =
  `1` bar(s) [default]; no ex-post period selection (F5).
- No-lookahead check: for every prefix of the input series, the label at `t`
  is identical with and without later data (enforced in `test_no_lookahead`).

## §R2 Precise definition

Average pairwise Pearson correlation of returns across a fixed basket of asset-class proxies (SPY, TLT, GLD, DBC, UUP, HYG, EEM, QQQ — set fixed ex ante). High correlation = diversification breakdown = risk-on/risk-off monoculture. The benchmark set is published ex ante in `benchmarks.yaml`; changes require chapter errata.

## §R3 Exact calculation

`N` assets, rolling window `W` trading days, simple returns `r_{i,d}`:

$$\rho_{i,j,t} = \frac{\mathrm{Cov}(r_i, r_j)}{\sigma_i \sigma_j}, \qquad
\bar{\rho}_t = \frac{2}{N(N-1)} \sum_{i<j} \rho_{i,j,t}$$

Optional fusion gauge: `E_t = (2/(N(N−1))) Σ 1[ρ_{i,j,t} > 0.50]` [example edge
threshold]. Worked check (5-asset × 10-day co-moving panel, illustrative
[example]): all pairwise `ρ ∈ 0.96–0.99` → `ρ̄ ≈ 0.9892` → FUSED. Pearson on
raw returns is biased upward in high-vol windows (Forbes–Rigobon (2002)
[documented]) — a heteroskedasticity correction is phase 2.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Daily total-return series for the N fixed proxies; window W (trading days).

**Cadence.** Daily.

**Threshold bands.**

| `ρ̄` | State | Tag |
|---|---|---|
| `≥ 0.50` | fused / monoculture | [documented] |
| `0.30–0.50` | elevated (macro factor dominates) | [example] |
| `≤ 0.30` | diversification-friendly | [example] |

Recalibrate every `[example]`-tagged band per instrument before production use.

## §R4 Efficacy modulation

| Affected S/T families | Direction | Mechanism |
