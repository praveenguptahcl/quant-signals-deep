## §R2 Precise definition

Average pairwise Pearson correlation of returns across a fixed basket of asset-class proxies (SPY, TLT, GLD, DBC, UUP, HYG, EEM, QQQ — set fixed ex ante). High correlation = diversification breakdown = risk-on/risk-off monoculture. The benchmark set is published ex ante in `benchmarks.yaml`; changes require chapter errata.

## §R3 Exact calculation

`N` assets, rolling window `W` trading days, simple returns `r_{i,d}`:

$$\rho_{i,j,t} = \frac{\mathrm{Cov}(r_i, r_j)}{\sigma_i \sigma_j}, \qquad
\bar{\rho}_t = \frac{2}{N(N-1)} \sum_{i<j} \rho_{i,j,t}$$

Optional fusion gauge: `E_t = (2/(N(N−1))) Σ 1[ρ_{i,j,t} > 0.50]` [example edge
threshold]. Worked check (5-asset × 10-day co-moving panel, illustrative
[example]): all pairwise `ρ ∈ 0.96–0.99` → `ρ̄ ≈ 0.9892` → FUSED. Pearson on
raw returns is biased upward in high-vol windows (Forbes–Rigobon (2002)
[documented]) — a heteroskedasticity correction is phase 2.

*Formula tag: [example] — constants inside this formula inherit it per the tag law
(Appendix i v1.0.0); worked-check numbers carry their own tags.*

**Data inputs.** Daily total-return series for the N fixed proxies; window W (trading days).

**Cadence.** Daily.

**Threshold bands (hysteresis).** Entry is inclusive; a label persists across
the dead band between entry and exit.

| `ρ̄` | State | Tag |
|---|---|---|
| `≥ fused` (`0.50` [example]) | FUSED entry — monoculture | calibrated per recipe in §R0.2 |
| `fused_exit ≤ ρ̄ < fused` (`0.40–0.50` [example]) | FUSED held if previous label was FUSED (hysteresis); otherwise ELEVATED | [example] |
| `diverse_exit < ρ̄ < fused_exit` (`0.38–0.40` [example]) | ELEVATED — factor dominates but not monoculture | [example] |
| `diverse < ρ̄ ≤ diverse_exit` (`0.30–0.38` [example]) | DIVERSIFIED held if previous label was DIVERSIFIED (hysteresis); otherwise ELEVATED | [example] |
| `≤ diverse` (`0.30` [example]) | DIVERSIFIED entry — diversification-friendly | calibrated per recipe in §R0.2 |

**Normative detection pseudocode** (pseudocode is normative; prose is commentary):

```
function detect(state, events, cfg):                      # events ascending by event_ts
    if events is empty: return [UNKNOWN]                  # F1

    clean = []            # parsed return rows admitted to the window
    prev  = "ELEVATED"    # hysteresis memory; neutral start
    out   = []

    for e in events:
        ts = int(e.ts_ns)

        if e.market_state == HALTED:                      # halt/auction edge case
            out.append(UNKNOWN(ts))                       # freeze: keep prev, rho_bar; emit UNKNOWN
            continue                                      # halted bar NEVER enters the window

        row = parse(e, ASSETS)                            # missing/unparseable -> None
        if row is None or any(not finite(r) for r in row):
            out.append(UNKNOWN(ts))                       # F1: mask, never interpolate
            continue

        spiked = [abs(r) > cfg.split_guard for r in row]  # corporate-action edge case
        if any(spiked) and not all(spiked):
            out.append(UNKNOWN(ts))                       # one leg spiked: suspect split/dividend;
            continue                                      #   bar excluded; vendor TR panel re-checks
                                                          # (all legs spiking = market tail day, not a split)

        clean.append(row)
        window = clean[-cfg.W:]
        if len(window) < 2:
            out.append(UNKNOWN(ts))                       # insufficient lookback
            continue

        rho = mean_pairwise_pearson(window)
        if not finite(rho):                               # F2: zero-variance leg or degenerate panel
            out.append(UNKNOWN(ts))
            continue

        # ---- hysteresis state machine (entry inclusive, exits inclusive) ----
        if rho >= cfg.fused:        label = "FUSED"
        elif rho <= cfg.diverse:    label = "DIVERSIFIED"
        elif prev == "FUSED":
            label = "FUSED" if rho >= cfg.fused_exit else "ELEVATED"
        elif prev == "DIVERSIFIED":
            label = "DIVERSIFIED" if rho <= cfg.diverse_exit else "ELEVATED"
        else:
            label = "ELEVATED"
        # ---------------------------------------------------------------------

        prev = label
        cost = COST_ADJUSTMENT[label]                      # cost interface (see below)
        log_decision(ts, rho, prev, cost)                 # Appendix g v1.0.0
        out.append(RegimeState(R031, label, rho, ESTIMATOR_VERSION,
                              DATA_VINTAGE, ts, "OK", cfg.min_lag_bars))

    return out
```

Edge-case notes (normative):

- **Missing bars** (vendor gap, no event emitted): the window is built from
  admitted rows only; gaps are masked, never interpolated. If the panel is
  stale beyond `3`× cadence, F4 fires → `UNKNOWN` (§R0.6).
- **Halts**: a halted bar is excluded from the window ("discard contributions
  across reopen"); `prev` is frozen so the hysteresis memory survives the halt.
- **Corporate actions**: production input is the vendor *total-return* series
  (adjusted close), which absorbs splits/dividends. The `split_guard` is a
  runtime tripwire for a bad vendor day or a corporate action the TR series
  missed: one leg jumping `> 0.90` [example] while the others do not.
- **Auction**: per §R0.5, no new labels; hold last state; `DEGRADED`.
- **Zero variance**: a constant leg makes its pairwise correlations undefined
  → `UNKNOWN` (F2), never `0.0` by fiat.
