## §R1 Precise definition

Shape of implied vol across maturities. Practitioner ratio `IVTS = VIX / VIX3M`: contango iff `IVTS < 1` (VIX < VIX3M) [documented convention]; backwardation iff `IVTS > 1` [documented convention].

## §R2 Exact calculation

$$Slope = \frac{IV_{long} - IV_{short}}{IV_{short}}, \qquad IVTS = \frac{VIX}{VIX3M} \quad\text{[documented]}$$

Backwardation ⟺ `IVTS > 1` ⟺ `Slope < 0` (same statement). For single names: `30`d vs `90`d ATM IV [example]. Johnson (2017) [documented]: the slope prices variance risk and predicts excess returns of variance swaps, VIX futures, and SPX straddles.

**Data inputs.** two points on the IV term structure (VIX and VIX3M for index; 30d vs 90d ATM IV for single names [example]).

**Cadence.** daily; intraday on event days.

**Threshold bands.**

| Condition | Label | Tag |
|---|---|---|
| `Slope > +0.10` | steep contango (calm) | [example] |
| `−0.05 ≤ Slope ≤ +0.10` | flat (watch) | [example] |
| `Slope < −0.05` | backwardation (stress/event bid) | [example] |

The documented facts are the contango/backwardation definitions via `IVTS ⋚ 1`; the slope cutoffs are `[example]`. Acute inversion `IVTS > 1.15` is a practitioner illustrative cut.

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Calendar/vol-carry | **amplifies then inverts** | improves in steep contango (roll-down harvest); dies in backwardation (term structure pays you to be short front vol — crowded) |
| Event-driven (earnings/FOMC) | **amplifies** | backwardation confirms the event is priced; fade-the-event improves after the print when slope normalizes |
| Mean-reversion equity signals | **degrades** | persistent backwardation = trending fear → worse |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes slope from surface snapshots; publishes RSV.
- **Verifier:** checks put-call IV parity (no-arbitrage sanity: call/put IV within `2` vol points [example]); sign of `(1 − IVTS)` must agree with slope sign or `UNKNOWN`.
- **Grok-Researcher:** proposes tenor pairs; leads only.
- **Adversary:** injects a stale surface (> `1` day) and a roll-date curve mismatch; checks both force `UNKNOWN`/flat.
- **Gate:** rejects chapters that assign a multi-day crisis regime to a one-day inversion.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission; F3 dual-estimator agreement within the
  stated tolerance or `UNKNOWN`; F4 staleness TTL `3`× cadence → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition.

## §R5 Cost interface: regime state → cost-function adjustment

Backwardation reprices near-term gap risk: vol-carry overlays must widen their required edge and shorten holding-period assumptions; the adjustment gates short-vol carry (`trade_ok = False` when backwardated).

```python
def cost_adjustment(rsv, base):
    adj = dict(base)
    adj['trade_ok'] = True
    adj['edge_mult'] = 1.0  # [default]
    if rsv['state'] == 'backwardation':
        adj['trade_ok'] = False   # stand down short-vol carry
        adj['edge_mult'] = 2.0    # [example]
    elif rsv['state'] == 'flat':
        adj['edge_mult'] = 1.25   # [example] watch state
    return adj
```
