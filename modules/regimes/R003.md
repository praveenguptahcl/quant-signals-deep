## §R1 Precise definition

Shape of implied vol across maturities. Practitioner ratio `IVTS = VIX / VIX3M`: contango iff `IVTS < 1` (VIX < VIX3M) [documented convention]; backwardation iff `IVTS > 1` [documented convention]. Units: slope is a dimensionless ratio; computation in float64 [default].

## §R2 Exact calculation

$$Slope = \frac{IV_{long} - IV_{short}}{IV_{short}}, \qquad IVTS = \frac{VIX}{VIX3M} \quad\text{[documented]}$$

Backwardation ⟺ `IVTS > 1` ⟺ `Slope < 0` (same statement). For single names: `30`d vs `90`d ATM IV [example]. Johnson (2017) [documented]: the second principal component SLOPE summarizes nearly all variance-risk pricing information in the VIX term structure, predicting excess returns of synthetic SPX variance swaps, VIX futures, and SPX straddles for all maturities, incremental to other proxies.

**Data inputs.** two points on the IV term structure (VIX and VIX3M closes for the index; 30d vs 90d ATM IV for single names [example]).

**Cadence.** daily; intraday on event days.

### Normative detection pseudocode (§R2 is normative; prose is commentary)

```
function TRANSITION(prev, slope, cfg):
    # entries: strict; exits: hysteresis band; direct cross-through allowed
    if slope < cfg.enter_backwardation:            return 'backwardation'
    if slope > cfg.enter_contango:                 return 'contango'
    if prev == 'backwardation' and slope < cfg.enter_backwardation + cfg.hysteresis:
        return 'backwardation'                     # hysteresis hold
    if prev == 'contango' and slope > cfg.enter_contango - cfg.hysteresis:
        return 'contango'                          # hysteresis hold
    return 'flat'

function DETECT(state, events, cfg, now):
    bar ← last(events)
    if events empty:                               return RSV(state='missing', module=UNKNOWN)
    if bar.vix missing or bar.vix3m missing:       return RSV(state='missing', module=UNKNOWN)      # F1
    if bar.vix ≤ 0 or bar.vix3m ≤ 0
       or not finite(bar.vix), not finite(bar.vix3m):
                                                   return RSV(state='invalid', module=UNKNOWN)      # F1
    slope ← (bar.vix3m − bar.vix) / bar.vix
    if slope ≤ −1 or slope > 5:                    return RSV(state='out_of_bounds', module=UNKNOWN) # F2
        # lower bound is mathematical (vix3m > 0 ⟹ slope > −1) [documented]; 5 is a plausibility guard [default]
    prev ← state.prev_label if state.prev_label ∈ {contango, backwardation} else 'flat'
    label ← TRANSITION(prev, slope, cfg)
    ivts ← bar.vix / bar.vix3m
    if sign(slope) ≠ sign(1 − ivts):               return RSV(state=label, module=UNKNOWN)           # F3
        # algebraic cross-check only: guards implementation error, NOT vendor error (documented limitation)
    if now − bar.event_ts > cfg.max_surface_age_days × 86400s:
                                                   return RSV(state=label, module=UNKNOWN)           # F4
    state.prev_label ← label
    return RSV(regime_id='R003', state=label, value=slope,
               estimator_version='1.1.0', data_vintage=bar.date,
               computed_at=bar.event_ts, module=OK)
```

**Edge cases.** Missing bars: masked, never interpolated; the hysteresis
memory carries the prior label and the staleness counter advances. Halts: an
SPX-options halt freezes the surface — treat as stale per the market-state
table. Corporate actions: N/A at index level; the single-name extension
(30d/90d ATM IV) requires a split/dividend-adjusted chain vendor and is an
escalation, not the cheapest path. Backfilled rows (pre-live-dissemination)
are flagged, not excluded [default], so the calibration set is explicit

## §R3 Efficacy modulation

| Affected family | Direction | Mechanism |
|---|---|---|
| Calendar/vol-carry | **amplifies then inverts** | improves in steep contango (roll-down harvest); dies in backwardation (term structure pays you to be short front vol — crowded) |
| Event-driven (earnings/FOMC) | **amplifies** | backwardation confirms the event is priced; fade-the-event improves after the print when slope normalizes |
| Mean-reversion equity signals | **degrades** | persistent backwardation = trending fear → worse |

## §R4 Loop spec (Sentinel / Verifier / Grok-Researcher / Adversary / Gate)

- **Sentinel:** computes slope from surface snapshots; publishes RSV.
- **Verifier:** (a) algebraic cross-check — sign of `(1 − IVTS)` must agree
  with slope sign or `UNKNOWN` (F3; implementation-error guard only —
  documented limitation, §R2); (b) put-call IV parity (no-arbitrage sanity:
  call/put IV within `2` vol points [example]) — **conditional on an options
  chain feed**; on the cheapest path this check is unavailable and the module
  reports `DEGRADED` with `curve_agrees=False` rather than pretending.
- **Grok-Researcher:** proposes tenor pairs; leads only.
- **Adversary:** injects a stale surface (> `1` day) and a roll-date curve mismatch; checks both force `UNKNOWN`/`DEGRADED`.
- **Gate:** rejects chapters that assign a multi-day crisis regime to a one-day inversion; rejects threshold triples shipped without the §R2 OOS pass.
- **F1–F5 instantiated:** F1 missing/stale → `UNKNOWN` (restrictive downstream);
  F2 bounds check on every emission (`slope ≤ −1` is mathematically
  impossible for `vix3m > 0` [documented]; `> 5` is a plausibility trip
  [default]); F3 dual-estimator agreement within the stated tolerance or
  `UNKNOWN`; F4 staleness TTL `max_surface_age_days` → `UNKNOWN`;
  F5 no ex-post backtest-period selection without a pre-registered definition
  (the stress-day list in §R2 must be registered before tuning).

## §R5 Cost interface: regime state → cost-function adjustment

Backwardation reprices near-term gap risk. The interface is normative; the
multiplier values are `[example]` until the consumer calibrates them on its
own walk-forward — the regime chapter supplies the *state*, the consumer
owns the *magnitudes* [default].

```python
def cost_adjustment(rsv, base):
    # base: dict(spread_bps, fee_bps, borrow_bps, impact_bps,
    #            edge_mult, trade_ok, max_holding_days)
    adj = dict(base)
    adj.setdefault('edge_mult', 1.0)                       # [default]
    adj['trade_ok'] = True
    if rsv['state'] == 'backwardation':
        adj['trade_ok'] = False                            # [rule] stand down short-vol carry
        adj['edge_mult'] = 2.0                             # [example] required edge doubles
        adj['spread_bps'] = base['spread_bps'] * 1.5       # [example] gap-risk widening
        adj['impact_bps'] = base['impact_bps'] * 2.0       # [example] thin book
        adj['max_holding_days'] = base.get('max_holding_days', 5) * 0.5  # [example]
        adj['borrow_bps'] = base['borrow_bps']             # unchanged
        adj['fee_bps'] = base['fee_bps']                   # unchanged
    elif rsv['state'] == 'flat':
        adj['edge_mult'] = 1.25                            # [example] watch state
    adj['rsv_state'] = rsv['state']                        # provenance tag on every adjustment
    return adj
```

Component mapping: **fees and borrow are untouched** by this regime (no
evidence they reprice with slope); **spread and impact scale** (gap risk,
thin book); **edge_mult gates entry**; **max_holding_days shortens**.
Consumer calibration recipe [default]: on the consumer's own walk-forward,
grid `edge_mult ∈ {1.5, 2.0, 3.0}`, `spread_scale ∈ {1.25, 1.5, 2.0}`,
`impact_scale ∈ {1.5, 2.0, 3.0}` [example], OOS-select by after-cost Sharpe
of the gated strategy; multipliers ship as the consumer's `[measured]`
values, never as this chapter's.
