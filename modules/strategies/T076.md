## §1.5 — Standing blocks

### B1. Module intent

This module specifies one strategy rule completely: its gates, its cost model,
its failure modes, and its kill lifecycle. It is buildable by an AI engineer
from this file alone plus the fixtures.

### B2. Scope boundary

The module emits OrderTicket **intentions** only. It never places, routes, or
cancels real orders; it never touches a broker API. Position management,
portfolio constraints, and execution live outside this module.

### B3. OrderTicket doctrine

Every emitted intent is a canonical Appendix C OrderTicket: `ticket_id`,
`strategy_id`, `symbol`, `side`, `qty`, `order_type`, `limit_price`,
`time_in_force`, `signal_ts`, `expiry_ts`. Partial fills are the broker's
domain; this module's policy is stated in §T0. Cancel/replace emits a new
ticket intent with a new `ticket_id`, never a mutation.

### B4. Time causality

`assert fill_event > signal_event`. A signal computed on bar `t` may not fill
before bar `t+1`. Fixture `signal_ts` values precede any modeled fill; tests
enforce the ordering. There is no lookahead anywhere in this module.

Cost is a four-part stack (spread, fee, borrow, impact) computed only by
`expected_cost_bps(...)`. The gate `expected_cost_bps(...) <= k * edge_bps`
runs before any ticket intent. COST values appear only in the §T2 COST block;
§T4 shows the function call and its result, never restated components.

### Module-state enum

`OK | DEGRADED | UNKNOWN | OFF`. Invalid input → `UNKNOWN`, never
interpolated. Feed lag > `5` s [default] trips the kill switch (→ `OFF` via
`TRIPPED`). `DEGRADED` = gates running on stale-but-valid bars within TTL.
`OFF` = kill switch not `ARMED` (or manual operator halt); emits nothing.

### Child-order state and partial fills

- Working intents are tracked by `ticket_id`; state is `WORKING`, `FILLED`,
  `PARTIAL`, `CANCELLED`, `EXPIRED`.
- Partial fills: the residual stays `WORKING` until `expiry_ts`; no new intent
  is emitted for the residual. Sizing downstream must assume partial fills.
- Cancel/replace: emit a **new** ticket intent with a new `ticket_id` and
  `replaces: <old ticket_id>`; never mutate a ticket in place.

### Kill lifecycle

`ARMED` → `TRIPPED` → `RECOVERY` → `ARMED`.

- **ARMED:** gates evaluated; intents emitted only on full pass.
- **TRIPPED** — any of:
- daily loss <= -3R [default]
- venue feed lag > 5 s [default]
- second cascade bar while armed
- venue halt/maintenance
  All working intents expire unfilled; no new intents. The trip is logged to
  the decision log with a hash chain.
- **RECOVERY:** manual review of the trip reason; losses reconciled; feeds
  verified healthy; fixture replay green.
- **ARMED (re-entry):** only via the re-arm checklist below.

### Re-arm checklist

- [ ] losses reconciled against the decision log [default]
- [ ] feeds healthy (no lag beyond the class budget) [default]
- [ ] risk limits reviewed and re-pinned [default]
- [ ] decision-log hash chain intact [default]
- [ ] fixture replay green on the current build [default]

### 3. Exits + post-exit cooldown (normative)

```
EXIT := (retrace >= 50% of cascade drop) [default]
        OR (new low below cascade low by 0.5x cascade-bar range) [default]
        OR (hold >= 12 h) [default]
        OR (new cascade bar prints)
ON_EXIT: cooldown_until = now + 12 h   # [default]; C4 (exit-cooldown compliance rule)
```

Exit is evaluated before any new entry on every bar; the module holds at most
one position per symbol (no pyramiding). The cooldown applies after any exit,
including the second-cascade emergency exit. Short side mirrors (new high
above cascade high by 0.5× range).

### 4. Position sizing (normative fenced function)

```python
def size_shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost) -> int:
    """shares = f(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost)."""
    if stop_distance <= 0:
        return 0                      # degenerate stop -> no ticket, never negative size
    qty = math.floor(risk_budget_R / stop_distance)   # R = $250 [example]; stop = 0.5x cascade range [default]
    qty = min(qty, math.floor(ADV_cap))               # ADV_cap = 0.10 * bar_volume [default]
    return max(qty, 0)                # cost is enforced by the cost gate, not by sizing
```

`vol_estimate` is accepted for the interface (used to sanity-check the stop
against the bar range upstream); `cost` is accepted but sizing does not
discount for cost — the cost gate (`§T2.7`) is the binding constraint.

### 9. Conformance items (Robustness + Compliance sub-block)

The 10 coded compliance rules are covered by C1–C12 below (extensions noted
in parentheses); every rule has a monitorable predicate or a schema check.

**C1.** Self-trade prevention: every ticket intent carries `stp=True`; no wash risk by construction.
  - Message-rate / cancel-to-trade: ≤ `10` messages/s per symbol [default]; cancel-to-trade ratio ≤ `5:1` per session [default]. IOC intents rarely cancel, so a high ratio indicates a quoting bug, not this strategy — page on breach.

**C2.** Time causality: `assert fill_event > signal_event`; signals on bar `t` fill at `t+1` or later.

**C3.** Invalid input → `UNKNOWN`: never interpolate or carry forward (F1/F2).

**C4.** Kill switch: `ARMED` → `TRIPPED` → `RECOVERY` → `ARMED`; `TRIPPED` emits nothing.
  - Halt/auction table: venue halt/maintenance → TRIP (see §T0 market-state table); `AUCTION`/`CLOSED` are n/a for USDⓈ-M perps [default].
  - Exit cooldown: after any exit, `cooldown_until = now + 12 h` [default] before re-entry; the re-arm checklist requires the cooldown to have expired.

**C5.** Decision log: every gate verdict is hash-chained; the chain is verified on replay.
  - Public-dissemination gate: intents are internal OrderTicket records only; nothing in this module publishes quotes, prints, or signals externally. The decision log is retained for audit, never broadcast.

**C6.** Cost gate: `expected_cost_bps(...) <= k * edge_bps` before any intent.

**C7.** Fixed gate order: entry-Boolean gates evaluate in documented order; no reordering.

**C8.** Intent-only + bona-fide intent: OrderTickets are intentions, never orders; every intent is a genuine trading intention, passable by the cost gate and sized within risk limits; no broker calls.
  - Pre-trade fat-finger trio (checked before any intent): price collar (expected fill within `2%` of last close [default]), size collar (`qty ≤ 0.10 × bar_volume` [default]), notional cap (`notional ≤ $5M` [example]); any breach → veto, logged.
  - Locate check: n/a for USDⓈ-M perps — no Reg-SHO locate; shorts are margin positions, so the check is margin sufficiency (see §T0 crypto block liq-buffer veto) [default].

**C9.** Ticket schema: Appendix C fields complete on every intent.

**C10.** Fixture reproducibility: the reference stub reproduces the expected ticket set from the raw tape.

**C11.** Censored-tape honesty: every stored liquidation field carries the `reported_` prefix; never impute the censored portion — trigger: any field missing the prefix → check: schema lint → action: block ingest → log: COMPLIANCE_BLOCK
  - Data-entitlement assertions (startup, before ingest): venue agreement permits liquidation-stream use; no redistribution of licensed data (see §T5 Data rights); fixtures are synthetic and labeled as such.
  - Vendor schema pin: `forceOrder` fields `o.s / o.S / o.q / o.ap / o.T` [documented] (Binance USDⓈ-M docs, https://developers.binance.com/docs/derivatives/usds-margined-futures/websocket-market-streams/All-Market-Liquidation-Order-Streams); only the largest liq order per symbol per `1000` ms is pushed [documented] — aggregation must assume the censored tail.

**C12.** Single-venue discipline: intents reference exactly one venue's feed — trigger: cross-venue mix in one ticket → check: venue field equality → action: veto → log: GATE_VETO

## §T3 — Math and normative pseudocode

### Math

- `edge_bps`: per-case expected edge in bps, mapped from the parent signal
  score via `map_score_to_edge(score)`. Reference value from the gate-pass
  fixture row: `120.0 bps [example]`.
- `cost_bps = expected_cost_bps(notional, adv_pct, venue, side, urgency)` —
  four-part stack, §T2.6 only.
- Gate: `expected_cost_bps(...) <= k * edge_bps` with `k = 0.5 [default]`.
- Sizing: normative fenced function `size_shares(risk_budget_R, stop_distance,
  vol_estimate, ADV_cap, cost)` — see §T2.4.
- Exits: normative `EXIT` Boolean + post-exit cooldown — see §T2.3.
- Fills modeled at bar `t+1` or later; `assert fill_event > signal_event`.

### Normative pseudocode (pseudocode is normative; prose is commentary)

```python
import math

def map_score_to_edge(parent_score: float, ref: float = 120.0) -> float:
    """Score -> edge_bps. Reference build: constant ref [example].
    Production: calibrated monotone map fit on embargoed OOS."""
    return ref  # [example]

def exit_triggered(pos, b, cfg) -> bool:
    """EXIT Boolean for a LONG fade (short side mirrors). All thresholds [default]."""
    cascade_drop = pos.cascade_high - pos.cascade_low
    retrace = (b.price - pos.cascade_low) / cascade_drop if pos.side == +1 \
              else (pos.cascade_high - b.price) / cascade_drop
    new_extreme = (b.low < pos.cascade_low - 0.5 * pos.cascade_range) if pos.side == +1 \
                  else (b.high > pos.cascade_high + 0.5 * pos.cascade_range)
    timed_out = (b.close_ts - pos.entry_ts) >= cfg.hold_max_h * 3_600_000_000_000
    new_cascade = b.reported_liq_notional / b.median_5min_notional_20d >= cfg.liq_ratio_min
    return (retrace >= 0.50) or new_extreme or timed_out or new_cascade

def size_shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost) -> int:
    """shares = f(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost) — normative."""
    if stop_distance <= 0:
        return 0
    qty = math.floor(risk_budget_R / stop_distance)   # R = $250 [example]; stop = 0.5x cascade range [default]
    qty = min(qty, math.floor(ADV_cap))                # ADV_cap = 0.10 * bar_volume [default]
    return max(qty, 0)   # cost enforced by the cost gate, not by sizing

def emit(state: ModuleState, events: list[Bar5m], cfg: T076Config) -> list[OrderTicket]:
    """Typed signature (normative). Emits OrderTicket intentions only — never orders.
    Invalid input -> module_state UNKNOWN, never interpolated (F1/F2)."""
    tickets: list[OrderTicket] = []
    if not events:                                     # F1: non-empty signal bundle
        state.module_state = UNKNOWN
        return tickets
    b = events[-1]                                     # newest 5-minute bar
    if not (b.close_ts > b.open_ts and b.price > 0
            and b.reported_liq_notional >= 0):          # F2: bar sanity
        state.module_state = UNKNOWN
        return tickets
    if state.kill != ARMED:                            # C4: kill switch dominates
        state.module_state = OFF
        return tickets
    if any(e.venue != b.venue for e in events):         # C12: single-venue discipline
        log_decision("GATE_VETO", "cross-venue-mix", b)  # C5: decision-log
        state.module_state = UNKNOWN
        return tickets
    # Exits first: at most one open position per symbol (no pyramiding)
    if state.position is not None:
        if exit_triggered(state.position, b, cfg):      # §T2.3 EXIT Boolean
            tickets.append(flatten_intent(state.position, b))
            state.position = None
            state.cooldown_until = b.close_ts + cfg.cooldown_h * 3_600_000_000_000  # 12 h [default]; C10
        return tickets
    if b.close_ts < state.cooldown_until:               # post-exit cooldown
        return tickets
    # g1: cascade-bar detection (arms on the flush bar itself)
    liq_ratio = b.reported_liq_notional / b.median_5min_notional_20d
    if liq_ratio >= cfg.liq_ratio_min:
        state.cascade_bar = b
    c = state.cascade_bar
    if c is None:
        return tickets
    bars_since = b.bar_index - c.bar_index
    if not (3 <= bars_since <= 6):                      # never the first flush [default]
        return tickets
    # g2: liquidation decay from the cascade peak
    decay_pct = 100.0 * (1.0 - b.reported_liq_notional / c.reported_liq_notional)
    # g3: confirmation — OI fall, funding direction, range contraction
    oi_fall_pct = 100.0 * (1.0 - b.open_interest / c.pre_cascade_oi)
    range_ok = b.range_5m <= cfg.range_contract_frac * c.range_5m      # [default]
    side = +1 if c.cascade_side == "LONG_LIQ" else -1  # long liqs -> fade long
    funding_ok = (b.funding_ann <= cfg.funding_max_ann_pct) if side == +1 \
                 else (b.funding_ann >= -cfg.funding_max_ann_pct)      # [default]
    confirm_score = min(oi_fall_pct / cfg.oi_fall_min_pct,
                        1.0 if funding_ok else 0.0,
                        1.0 if range_ok else 0.0)
    enter = (liq_ratio >= cfg.liq_ratio_min and decay_pct >= cfg.decay_min_pct
             and confirm_score >= 1.0)
    if not enter:
        log_decision("GATE_VETO", "entry-boolean", b)
        return tickets
    stop_distance = 0.5 * c.range_5m                                  # [default]
    qty = size_shares(cfg.per_trade_R, stop_distance,
                      vol_estimate=b.range_5m, ADV_cap=0.10 * b.volume_5m,
                      cost=None)                                      # §T2.4
    if stop_within_liq_buffer(b, side, stop_distance, cfg.liq_buffer_mult):
        log_decision("GATE_VETO", "liq-buffer", b)     # §T0 crypto block: stop must sit above venue liquidation
        return tickets
    edge_bps = map_score_to_edge(b.parent_score, ref=120.0)           # [example]
    notional = qty * b.price
    cost_ok = expected_cost_bps(notional, adv_pct=notional / b.adv_usd,
                                venue=b.venue, side="taker",
                                urgency="normal") <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    if not cost_ok:
        log_decision("GATE_VETO", "cost-gate", b)
        return tickets
    if not (fat_finger_ok(b, qty, notional)):          # C8: price/size/notional collars
        log_decision("GATE_VETO", "fat-finger", b)
        return tickets
    t = OrderTicket(
        ticket_id=new_ticket_id(), strategy_id="T076", symbol=b.symbol,
        side="BUY" if side == +1 else "SELL", qty=qty, order_type="MARKET",
        limit_price=None, time_in_force="IOC",
        signal_ts=b.close_ts, expiry_ts=b.close_ts + 300_000_000_000,  # 5 min [default]
        parent_signal=f"{b.parent_sid}@{b.close_ts}", stp=True)         # C1
    log_decision("EMIT_INTENT", "enter", t, inputs_hash(b), params_hash(cfg))  # C5
    state.position = open_position(t, b, stop_distance)
    tickets.append(t)
    assert t.signal_ts < fill_ts(t)                     # t->t+1 causality
    assert all(fill_ts(x) > x.signal_ts for x in tickets)  # no same-bar fills
    return tickets
```
