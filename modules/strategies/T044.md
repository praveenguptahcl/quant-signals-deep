# T044 — Diurnal Deseasonalization Normalizer

A data-normalization layer, not a trading strategy: it removes the documented U-shaped intraday volatility periodicity (Wood–McInish–Ord 1985; Andersen–Bollerslev 1997) via the multiplicative-component method (Engle–Sokalska 2012), so downstream intraday signals compare like with like. Its 'edge' is preventing every intraday signal from rediscovering the open/close. Provenance **[D]**.

**Kill-switch state machine:** `ARMED → TRIPPED → RECOVERY → ARMED`.

- `ARMED`: normal operation; every bar evaluates the kill conditions.
- `TRIPPED`: any kill condition fires → cancel all working intents
  (`NEW`/`WORKING` → `CANCELLED`, idempotent), flatten managed positions via
  the exit rule, emit nothing new, state `OFF`, log `KILL_TRIP`.
- `RECOVERY`: manual operator review only — no automatic transition.
- `ARMED` (re-entry): only after the re-arm checklist passes in full, logged
  as `KILL_REARM` with the checklist result.

**Re-arm checklist** (all must be true):

- [ ] Feed health green: all §T5 inputs fresh inside the staleness TTL.
- [ ] Kill condition cleared: the tripping metric is back inside limits for `30 min [default]` [default].
- [ ] Decision log reconciled: `KILL_TRIP` record present and hash chain intact.
- [ ] Risk re-check: per-trade R and gross caps re-confirmed against current equity.
- [ ] Operator sign-off: named human approves re-arm (no automatic recovery).

## §T2 Specification

### Universe

Any intraday signal; the normalizer is signal-agnostic.

### Entry rule (Boolean — no prose-only conditions)

```
profile[b] = median(|r_b| / median|r|) over reestimate_days   # Engle–Sokalska [documented]
r_norm = r / profile[bin(t)]                                    # deseasonalized
FORWARD r_norm to downstream signals
```

### Exits (with post-exit cooldown)

```
normalizer holds no positions; it transforms the feed
re-estimate every reestimate_days; alert on profile drift
(post-exit cooldown: n/a — no positions; C10 cooldown binds downstream strategies)
```

### Position sizing (fenced function)

```python
def shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost):
    # The production normalizer holds no positions: it divides the feed by the
    # diurnal profile (r_norm = r / profile[bin]). This harness function sizes
    # the *pass-through* intents of the reference implementation so the cost
    # gate and kill switch stay mechanically testable in §T4.
    raw = risk_budget_R / max(stop_distance * vol_estimate, 1e-9)  # price == vol_estimate here [example]
    cap = int(ADV_cap * ADV_shares)
    return max(1, min(int(raw), cap))
```

## §T3 Math + normative pseudocode

Wood–McInish–Ord (1985) [documented]: the U-shaped intraday pattern — volatility
and volume high at open/close. Andersen–Bollerslev (1997) [documented]: intraday
periodicity and volatility persistence — the reason this layer exists. Engle–Sokalska
(2012) [documented]: multiplicative-component GARCH separates the diurnal factor from
stochastic volatility and improves forecasts — the method implemented here.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
def emit(state, signals, cfg):
    sig = primary(signals, "S067")          # deseasonalized series + profile health
    if sig is None or invalid(sig): return [], state.unknown()
    # Production role: transform the feed (r / profile[bin]) for downstream signals.
    # In this module pack the reference implementation models the normalized
    # hand-off with the standard cost-gated intent pattern so the fixture,
    # the cost gate, and the kill switch stay mechanically testable.
    cost = expected_cost_bps(notional(), adv_pct(), venue(), "taker", "normal", cfg)
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    if cost <= cfg.cost_gate_k * sig.edge_bps and sig.profile_ok:
        t = OrderTicket.intent("BUY", qty=shares(cfg.risk_budget_R_usd, sig.stop_distance, sig.price, cfg.ADV_cap_pct / 100, cost), limit=last_price())
        # ^^^ qty bound to the §T2 fenced sizing function shares=f(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost)
        t.intent_ts = sig.computed_at
        assert fill_event > signal_event      # t->t+1 causality: no-signal-bar fills
        return [t], state.ok()
    log("GATE_VETO", cost=cost); return [], state.ok()
```

Causality: every feature uses inputs with `event_ts ≤ t` only; the earliest
fill for a bar-`t` intent is bar `t+1`'s open. Mandatory unit test:
no-signal-bar fills.
