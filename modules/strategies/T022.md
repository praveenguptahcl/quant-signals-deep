## §T2 Strategy stack — dependencies, rules, costs, compliance

### Universe

Liquid US large-caps with tight spreads [example]: quoted spread ≤ `2`¢
[example], ADV > `5`M shares [example]. Session RTH `09:45`–`15:30` ET
[example]. Quote `1` lot [example] (`100` shares [example]) on the heavy side. Exclude:
earnings days, halts/auctions, VPIN-stress names. Gould–Bonart skill is
strongest on large-tick names and moderate on small-tick names [documented] —
prefer large-tick names for the prototype.

### Entry rule (Boolean expressions)

```text
QUOTE := (|I_t| >= I_quote) AND (VPIN_t <= vpin_cancel) AND (|q| <= inv_max)
         AND (l1_fresh) AND (market_state == CONTINUOUS_TRADING)
         AND (side != SHORT OR locate_ok)
         AND (s011_veto == False)
         AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
SIDE  := BUY  if I_t > 0 else SELL            # quote the heavy side
PX    := bid  if SIDE == BUY else ask          # join the touch; never cross
FLAT (cancel working quotes) := otherwise
```

`I_t` is the S003 v1.0.1 queue imbalance (pinned in §T3); `VPIN_t` the S008
v1.1.0 toxicity estimate; `q` the module inventory in lots. Every guard in this
rule appears verbatim in the §T3 pseudocode.

### Exits (with post-exit cooldown)

```text
CANCEL_WORKING := (VPIN_t > vpin_cancel)        # toxicity cancel (C12)
               OR (sign(I_t) flipped since quote placed)
               OR (|q| > inv_max)               # inventory veto (C11)
               OR (not l1_fresh)                # staleness (F4)
               OR (event_ts >= 15:30 ET)        # session flatten [example]
               OR (module_state != OK)
               OR (market_state != CONTINUOUS_TRADING)
ON_EXIT: cooldown_until = event_ts + cooldown_s   # 1 s [default]; C10
```

### Position sizing (fenced function)

```python
def shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost):
    """T022 quote-size function. Market-making: the quote IS the sizing
    decision — size is the resting quote, not the bet."""
    lot = 100                    # 1 lot [example]

    n = min(lot, cap)
```

```python
    """Callable cost model — T022 COST block (single source of truth)."""
    spread_bps = -4.0   # [example] maker: earns half the 2c spread @ $50 = -4 bps/round-trip
```

### Robustness

The imbalance threshold is the calibration surface: `I_quote` in `0.15`–`0.35`
[example] trades frequency for edge. The toxicity cancel (`0.35` [default]) is
the adverse-selection screen, not a forecast. **Caveat:** ELO themselves argue
VPIN is meaningful in relative terms — the CDF of VPIN, not its absolute level
[documented] (Flow Toxicity paper, §3) — so an absolute `0.35` cancel threshold
is a design placeholder pending calibration, not a measured toxicity level
(GROK-NEEDED 1). Gould–Bonart skill is strongest on large-tick names, moderate
on small-tick names [documented] — the universe exclusion follows from this. The edge model (`edge_bps = 4.0 − vpin·10.0`
[example]) is deliberately conservative: it assumes half the maker edge is
consumed by toxicity at VPIN `0.4` [example]. Purged/embargoed OOS per S088.

- **C3 | Message-rate / cancel-to-trade.** Trigger: cancel-to-trade ratio

  Action: throttle quoting, then pull quotes. Log: `COMPLIANCE_BLOCK`.
- **C4 | Pre-trade fat-finger trio.** Trigger: every ticket. Check: price

  `$500k` [example]; max `10` tickets/s per symbol [default]. Action: block.
  Log: `COMPLIANCE_BLOCK`.
- **C5 | Decision-log schema.** Trigger: every material action (intent, veto,

- **C6 | Halt/auction state table.** Trigger: `market_state` change. Check:
  state ∈ {`HALTED`, `AUCTION`, `CLOSED`}. Action: pull + cancel working

- **C7 | Locate check (short sales).** Trigger: SELL ticket that would open or
  increase a short position. Check: `locate_ok` — easy-to-borrow list or

- **C8 | Public-dissemination gate.** Trigger: any external publication of

- **C9 | Data-entitlement assertions.** Trigger: startup and any entitlement

  Log: `COMPLIANCE_BLOCK`.
- **C10 | Post-exit cooldown.** Trigger: any exit or compliance block. Check:
  `event_ts >= cooldown_until`. Action: no re-entry inside `cooldown_s`

- **C11 | Inventory discipline.** Trigger: `|q| > 5` lots [example]. Check:

## §T3 Math + normative pseudocode

**Thesis.** Quote on the heavy side of the book when the queue imbalance is
strong (S003), pull quotes when flow is toxic (S008), and veto quoting when
inventory is extreme (S011 screen + own discipline). The maker's edge is spread
capture plus the maker rebate, minus adverse selection — the toxicity cancel is
the only honest part of the edge.

**Pinned consumed formulas** (verbatim excerpts ≤10 lines, provider ID +
version + spec-hash):

```text
# P1 — S003 v1.0.1, spec-hash sha256:82d06bf415788464
I_t = (Q^b_t - Q^a_t)/(Q^b_t + Q^a_t) in [-1,1]; Q^b_t, Q^a_t displayed sizes
at the best bid/ask (shares; not both zero)

# P2 — S008 v1.1.0, spec-hash sha256:97560e323744dcd3
VPIN_t = sum_{tau=t-n+1..t} OI_tau / (n*V) in [0,1]; OI_tau = |V^B_tau - V^S_tau|;
ELO convention n=50 buckets [documented] ("a sample length of 50 buckets"),
bucket size sized for ~50 volume buckets/day [documented] (working V = ADV/50,
derived arithmetic, not a quoted parameter); bulk volume classification (BVC)
```

**Edge model.**

```text
edge_bps = 4.0 − VPIN_t × 10.0        # [example] spread capture less toxicity penalty
```

At VPIN `0.4` [example] the modeled edge is `0` [example] — the cancel threshold
(`0.35` [default]) sits just inside the zero-edge point by construction.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```text
function emit(state, signals, cfg) -> list[OrderTicket]:
    # --- F1: all three consumed signals required; missing -> UNKNOWN, never interpolate ---
    q   = signals.get('S003')     # newest L1 snapshot with imbalance
    tox = signals.get('S008')     # VPIN record
    vet = signals.get('S011')     # illiquidity screen (veto flag)
    if q is None or tox is None or vet is None:
        return _unknown(state, reason='missing_signal')          # F1
    # --- F2: mathematical bounds ---
    if not (isfinite(q.imbalance) and -1 <= q.imbalance <= 1):
        return _unknown(state, reason='imbalance_bounds')        # F2
    if not (isfinite(tox.vpin) and 0 <= tox.vpin <= 1):
        return _unknown(state, reason='vpin_bounds')             # F2
    if q.bid <= 0 or q.ask <= q.bid:
        return _unknown(state, reason='crossed_or_locked')       # F1/F2
    # --- F4: staleness ---
    if state.now_ns - q.event_ts > cfg.staleness_ttl_s * 1e9:
        return _unknown(state, reason='stale_l1')                # F4
    # --- kill switch: TRIPPED -> OFF, emit nothing ---
    if state.kill == 'TRIPPED':
        return []
    # --- C12 toxicity cancel: toxic flow pulls quotes ---
    if tox.vpin > cfg.vpin_cancel:
        cancel_all_quotes()
        log_decision(GATE_VETO, rule='C12', inputs_hash, params_hash)
        return []
    # --- C11 inventory veto ---
    if abs(state.inventory_q) > cfg.inv_max:
        log_decision(COMPLIANCE_BLOCK, rule='C11', inputs_hash, params_hash)
        return []
    # --- S011 illiquidity screen: veto flag kills quoting (§T5 pinned contract) ---
    if vet.veto_flag:
        log_decision(GATE_VETO, rule='S011-VETO', inputs_hash, params_hash)
        return []
    # --- C6 market-state gate ---
    if state.market_state != 'CONTINUOUS_TRADING':
        log_decision(GATE_VETO, rule='C6', inputs_hash, params_hash)
        return []
    side = 'BUY' if q.imbalance > 0 else 'SELL'                   # heavy side
    # --- C7 locate check for short side ---
    if side == 'SELL' and not state.locate_ok:
        log_decision(COMPLIANCE_BLOCK, rule='C7', inputs_hash, params_hash)
        return []
    # --- C10 post-exit cooldown ---
    if state.now_ns < state.cooldown_until:
        log_decision(GATE_VETO, rule='C10', inputs_hash, params_hash)
        return []
    # --- edge + cost gate (C3): normative predicate, verbatim ---
    edge_bps = 4.0 - tox.vpin * 10.0                             # [example]
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side='maker', urgency='normal') <= cfg.cost_gate_k * edge_bps
    if not cost_ok:
        log_decision(GATE_VETO, rule='C3', inputs_hash, params_hash)
        return []
    # --- entry rule ---
    if abs(q.imbalance) < cfg.I_quote:
        return []
    px = q.bid if side == 'BUY' else q.ask                        # join the touch
    n = shares(cfg.per_trade_R, cfg.stop_distance, cfg.vol_estimate, cfg.ADV_cap,
               expected_cost_bps(notional, adv_pct, venue, 'maker', 'normal'))
    # --- C4 pre-trade fat-finger trio ---
    if abs(px - q.ref_px) / q.ref_px > 0.01:                     # 1% collar [default]
        log_decision(COMPLIANCE_BLOCK, rule='C4', inputs_hash, params_hash)
        return []
    if n * px > 500000:                                          # $500k/ticket [example]
        log_decision(COMPLIANCE_BLOCK, rule='C4', inputs_hash, params_hash)
        return []
    tk = OrderTicket(symbol=q.symbol, side=side, qty=n, limit=px, tif='DAY',
                     ticket_id=new_uuid(), parent_signal=f"S003@{q.event_ts}",
                     intent_ts=state.now_ns, state='NEW')
    log_decision(tk, inputs_hash, params_hash)                   # C5 / App. g
    assert tk.intent_ts > q.event_ts                             # t->t+1 causality
    # no signal-bar fills: enforced by the mandatory acceptance test
    return [tk]
```

Causality: `I_t` and `VPIN_t` use only data with `event_ts ≤ t`; any fill
reacting to them must satisfy `fill_event.event_ts > signal.computed_at`. The
backtest harness fills tickets strictly after the signal event; any fill
timestamped at or before its signal event is a harness bug and trips the kill
switch.

## §T6 Execution assumptions

Intent-side child-order state machine (Appendix C v1.0.0): `NEW → WORKING →
FILLED`, with `WORKING ↘ CANCELLED` and `WORKING ↘ PARTIAL → FILLED |
CANCELLED`. Terminal tickets never re-enter; a new intent is a new
`ticket_id`. Partial fills update the remaining quantity of the same ticket —
no child tickets. Fill allocation across tickets for one symbol: oldest
`intent_ts` first (FIFO). Cancel-replace = cancel old `ticket_id` (→
`CANCELLED`) + new ticket carrying `replaces: <old_ticket_id>` in the decision
log; forbidden while the old ticket is `FILLED`. Quote TTL `300` ms [example]:
stale quotes are cancelled, not left to be picked off. Honesty: any latency
figure derived from SIP timestamps is *simulated only — requires MBO/ITCH*
(SIP jitter is 10s of microseconds [documented], Appendix E v1.0.0); production
quoting requires exchange-timestamped L1 (Databento MBP-1 or equivalent).

and adverse selection eat it. (4) The fixture's `−4.8` bps stack [example] is
assumed achievable — it is a reference stack, not a measured cost.
