## §1.5 — Standing blocks

### B1. Module intent

This module specifies one strategy rule completely: its gates, its cost model,
its failure modes, and its kill lifecycle. It is buildable by an AI engineer
from this file alone plus the fixtures.

### B2. Scope boundary

The module emits OrderTicket **intentions** only. It never places, routes, or
cancels real orders; it never touches a broker API. Position management,
portfolio constraints, and execution live outside this module.

### B3. OrderTicket doctrine

Every emitted intent is a canonical Appendix C OrderTicket: `ticket_id`,
`strategy_id`, `symbol`, `side`, `qty`, `order_type`, `limit_price`,
`time_in_force`, `signal_ts`, `expiry_ts`. Partial fills are the broker's
domain; this module's policy is stated in §T0. Cancel/replace emits a new
ticket intent with a new `ticket_id`, never a mutation.

### B4. Time causality

`assert fill_event > signal_event`. A signal computed on bar `t` may not fill
before bar `t+1`. Fixture `signal_ts` values precede any modeled fill; tests
enforce the ordering. There is no lookahead anywhere in this module.

Cost is a four-part stack (spread, fee, borrow, impact) computed only by
`expected_cost_bps(...)`. The gate `expected_cost_bps(...) <= k * edge_bps`
runs before any ticket intent. COST values appear only in the §T2 COST block;
§T4 shows the function call and its result, never restated components.

### Time contract

- **Clock domain:** exchange event time (XNAS); authoritative causality clock.
- **Canonical form:** int64 nanoseconds, UTC. Dual `(signal_ts, asof_ts)`.
- **max_skew:** 2 s [default] between snapshot publish (`signal_ts`) and
  module receipt (`asof_ts`); beyond skew → the snapshot is discarded.
- **Staleness TTL:** 180 s [default] (3 snapshots); a snapshot older than the
  TTL at evaluation → input invalid → `UNKNOWN`.
- **Gap policy:** no interpolation, no carry-forward (F1/F2). A missing
  snapshot resets the persistence counter; the entry gate cannot pass until
  K [default] fresh consecutive snapshots re-accumulate.
- **Jitter budget:** evaluation must complete within 5 s [default] of the
  snapshot boundary.

### Market-state table

| State | Entries | Exits | Decision log |
|---|---|---|---|
| CONTINUOUS_TRADING | allowed (full gate set) | allowed | EMIT_INTENT / GATE_VETO |
| HALTED | vetoed | managed per broker | GATE_VETO (halt) |
| AUCTION | vetoed | vetoed new; working intents expire | GATE_VETO (auction) |
| CLOSED | not evaluated | not evaluated | SESSION_CLOSE |

### Module-state enum

`OK | DEGRADED | UNKNOWN | OFF` — the only degradation vocabulary.

- **OK:** all gate inputs computable and within TTL.
- **DEGRADED:** non-fatal staleness (e.g. halt flag stale > TTL → halt treated
  as possible → entries vetoed, exits still managed) [default].
- **UNKNOWN:** invalid input (NaN, non-positive price, unknown side, stale
  snapshot) — never interpolated, never carried forward (F1/F2).
- **OFF:** kill switch TRIPPED/RECOVERY, or operator disable; emits nothing.

### Kill lifecycle

`ARMED` → `TRIPPED` → `RECOVERY` → `ARMED`.

- **ARMED:** gates evaluated; intents emitted only on full pass.
- **TRIPPED** — any of:
- 2 consecutive stopped trades [example]
- spread > s_max [default]
- realized spread+fees > expected move [default]
- daily loss <= -5R [default] (matches `daily_loss_stop_R`; the reference
  build's only daily-stop unit is R)
  All working intents expire unfilled; no new intents. The trip is logged to
  the decision log with a hash chain.
- **RECOVERY:** manual review of the trip reason; losses reconciled; feeds
  verified healthy; fixture replay green.
- **ARMED (re-entry):** only via the re-arm checklist below.

```python
function emit(state, signals, cfg: T091Config) -> list[OrderTicket]:

    s = signals[-1]  # 60-second snapshot at bar t
    assert isfinite(s.S_A) else return [] and state UNKNOWN          # F2: finite
    if kill.state != ARMED: return [] and state OFF                  # C4
    if s.market_state != CONTINUOUS_TRADING: return []               # C15: halt/auction veto
    if now < state.cooldown_until: return []                        # C18: exit cooldown
    if s.refill_event: s.S_A = 0.5 * s.S_A                          # spoof/flicker penalty [example]
    persist = (sign(s.P_star) == state.prev_sign for the last cfg.persist_K)  # K=8 [default]
    edge_bps = abs(s.S_A) * cfg.edge_scale                          # 24.0 [example] ⇒ S_A=1.25 → 30 bps
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps (C6)
    enter_long = (s.S_A >= +cfg.S_A_min and persist
                  and s.spread_bps <= cfg.spread_max_bps and cost_ok)
    enter_short = (s.S_A <= -cfg.S_A_min and persist
                   and s.spread_bps <= cfg.spread_max_bps and cost_ok)
    if enter_short and not s.locate_ok: return []                    # C7/C12: locate veto
    enter = enter_long or enter_short
    tickets = []
    if enter:
        stop = 0.85 * s.sigma_20                                    # 0.85 [example]
        qty = size_shares(0.003 * state.equity, stop, s.sigma_20, 0.08 * s.disp_3lvl, expected_cost_bps(...))
        # ^^^ 0.003 [example], 0.08 [example]; normative §T2.3 sizing
        limit_px = s.touch_px                                      # passive at touch [default]
        fat_finger_ok = (qty > 0 and qty * limit_px <= cfg.max_gross_notional
                         and abs(limit_px - s.touch_px) / s.touch_px <= 0.01)  # C14; 1% [default]
        if not fat_finger_ok: return []                             # C14: veto
        side = BUY if s.S_A > 0 else SHORT
        t = OrderTicket(sym, side, qty, limit_px, DAY, uuid(), f'S005@{s.ts}', now(), NEW)
        assert fill_event > signal_event                            # C2: t->t+1
        log_decision(t, inputs_hash, params_hash)                    # C5
        tickets.append(t)
    return tickets

function on_exit(state, position, reason) -> None:
    # EXIT triggers: +1.25σ profit [example] | -0.85σ stop [example] |
    # time stop 45-90 min / session end [example] | VWAP signal-flip 0.5σ [example]
    state.cooldown_until = now + cfg.cooldown_min * 60_000_000_000  # 15 min [default]; C18
    log_decision(EXIT, reason, inputs_hash, params_hash)            # C5
```
