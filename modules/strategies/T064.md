### Position sizing (fenced function)

```python
def shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost):
    """Mandated signature: shares = f(risk_budget_R, stop_distance,
    vol_estimate, ADV_cap, cost).

    risk_budget_R : $ per trade [default] — R_usd
    stop_distance : $/share to stop [example] — stop_atr * vol_estimate
    vol_estimate  : ATR in $ [example]
    ADV_cap       : max shares = participation_cap * ADV [default]
    cost          : expected_cost_bps(...) [callable] — reduces size when
                    cost consumes the edge
    """
    qty = int(risk_budget_R // max(stop_distance, 1e-9))      # dollar-risk core
    qty = min(qty, int(ADV_cap))                              # participation cap
    if cost is not None:
        cost_bps = cost                                        # per-trade bps
        qty = int(qty * max(0.0, 1.0 - cost_bps / 10.0))      # cost haircut [example]
    return max(qty, 0)
```

`stop_distance = $1.0` [example] → `400` shares on the fixture; `ADV_cap`
binds only when `adv_pct` participation exceeds the cap.

## §T3 Math + normative pseudocode

Intraday U-shape (Wood, McInish & Ord 1985): volume and volatility are
high at the open, low midday ($11{:}00$–$14{:}00$ ET [example]), high into the
close. Lull fade: fade drifts beyond $0.5 \times$ ATR [example] during the
lull window. Close ride: after 15:00 [example], trade with the auction
imbalance (S067) into the close. Per-name profiles over $60$ days [example];
stand down when today's midday volume exceeds $2 \times$ average [default]
(news day).

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function emit(state, signals, cfg) -> list[OrderTicket]:
    assert signals non-empty else return UNKNOWN                    # F1
    if state.kill_state != ARMED: return []                         # kill switch: §T0.7
    for bar t in signals (newest last):
        s = U-shape deviation (drift beyond lull norm), signed                                            # data <= t only
        assert isfinite(s) else return UNKNOWN                      # F2
        if midday_vol(t) > 2 * avg_60d: stand down today            # §T2 news-day veto (F5)
        edge_bps = abs(dev) * 6.5                                   # [example] — modeled per-trade edge in bps
        cost = expected_cost_bps(notional, adv_pct, venue, side, urgency)
        cost_ok = expected_cost_bps(...) <= k * edge_bps
        # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
        if state.position is None and state.module_state == OK:
            lull_leg  = (t in [lull_start, lull_end)) and (drift beyond 0.5 ATR)   # ENTER_LULL_FADE
            close_leg = (t >= 15:00 ET) and (imbalance aligned with drift)         # ENTER_CLOSE_RIDE
            if (lull_leg or close_leg) and cost_ok:
                ticket = OrderTicket(symbol, side, qty, limit, tif,
                                     ticket_id=uuid(),
                                     parent_signal=("S046@t" if lull_leg else "S067@t"),
                                     intent_ts=t.event_ts, state=NEW)
                log_decision(ticket, inputs_hash, params_hash)     # C5 / Appendix g
                assert fill_event > signal_event                    # t->t+1 causality
        else if state.position is not None:
            if ((window ends) or (stop hit)):
                emit exit intent (cancel-replace rules, Appendix c) # C1
                state.cooldown_until = t + cooldown_bars            # C10
                assert fill_event > signal_event
    return tickets
```

Harness note: the test sketch implements the lull leg only (`ENTER_LULL_FADE`
with the window gate); the close leg (`ENTER_CLOSE_RIDE`) requires the S067
auction-imbalance feed, which the cheapest stack does not source — see §1.5

Causality: every quantity at bar `t` uses only data `≤ t`; the earliest fill
is bar `t+1`'s open. Mandatory unit test: no-signal-bar fills

## §T9 Failure modes & pitfalls

### Regime gates (machine records)

Restrictive default: `unknown_behavior` is always stand down — regime labels
are read from the §R0.5 lag contracts of the cited modules, and a regime
label computed at `t` gates only trades executable at `t+1` or later
(`min_lag = 1` bar [default] [documented] in each cited lag contract).

| regime_id | direction | mechanism | condition | action | min_lag | unknown_behavior |
|---|---|---|---|---|---|---|
| R005 | degrades | jump discontinuity breaks the 60-day U-shape average | jump flag on bar `t` | veto | `1` bar [documented] | stand down |
| R013 | degrades | abnormal midday volume = news day, no lull | midday vol `>2`× trailing average | pause_entry | `1` bar [documented] | stand down |
| R007 | inverts | strong trend day — the lull fade is fought by drift | trend-strength label high on bar `t` | veto (fade leg) | `1` bar [documented] | stand down |
| R010 | degrades | wide spreads raise the cost gate exactly when the close leg trades | spread-regime label wide on bar `t` | halve (close leg) | `1` bar [documented] | stand down |
