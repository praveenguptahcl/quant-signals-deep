```text

         AND (market_state == CONTINUOUS_TRADING) AND (module_state != OFF)

FLAT (pull) := otherwise

Every clause is a named predicate with a threshold — no prose-only conditions.

```

## §T3  Math & normative pseudocode

**Math** (Avellaneda–Stoikov 2008 [documented]; DOI 10.1080/14697680701381228).

```text
reservation price:  r = s − q·γ·σ²·(T−t)                              [documented]
optimal spread:     δ = γ·σ²·(T−t) + (2/γ)·ln(1 + γ/κ)                  [documented]
optimal quotes:     bid = r − δ/2,  ask = r + δ/2                       [documented]
inventory skew:     q > 0 (long) → r < s → quotes skew down, encouraging sells [documented]
```
Implementation note: the symmetric-spread form above is the small-|q| form used in code [example]; the exact AS optimal bid/ask distances are inventory-asymmetric [documented]. Modeled edge: `edge_bps = spread_capture_bps − adverse_selection_bps` [example].

**Normative pseudocode** (complete; every prose guard present; no black boxes).

```text
function emit(state, events, cfg) -> list[OrderTicket]:
    # F1/F4 staleness; F2 bounds — invalid input -> UNKNOWN, never interpolate
    snap = events.l1_snapshot                       # bid, ask, bid_sz, ask_sz, event_ts
    assert snap.bid > 0 and snap.ask > snap.bid else return UNKNOWN   # crossed/locked -> UNKNOWN
    assert now_ns() - snap.event_ts <= 1_000_000_000 else return UNKNOWN  # L1 TTL 1 s [default]
    vpin = events.vpin                              # from S008@1.1.0
    assert isfinite(vpin) and 0.0 <= vpin <= 1.0 else return UNKNOWN  # F2 bounds

    if vpin > cfg.vpin_veto:                        # C12 toxicity veto
        pull_quotes()                               # cancel WORKING intents (Appendix C cancel path)
        log(GATE_VETO, "C12", vpin)                 # Appendix G record
        return []                                   # -> DEGRADED(reason=toxicity)

    q = state.inventory_q                           # lots, int
    if abs(q) > cfg.inv_max:                        # C11 inventory discipline
        skew_only(q)                                # widen the adverse side; no NEW quotes
        log(COMPLIANCE_BLOCK, "C11", q)
        return []                                   # -> DEGRADED(reason=inventory)

    s = (snap.bid + snap.ask) / 2.0
    var = state.sigma2                              # calibrated session variance [default]
    T = session_seconds_remaining()                 # (T-t) to the 15:30 ET flatten [example]
    r = s - q * cfg.gamma * var * T                 # [documented] AS reservation price
    delta = cfg.gamma * var * T + (2.0/cfg.gamma) * log(1.0 + cfg.gamma/cfg.kappa)  # [documented]
    bid_px = r - delta/2.0
    ask_px = r + delta/2.0

    edge_bps = 4.0 - vpin * 10.0                    # [example] spread capture minus adverse selection
    cost_bps = expected_cost_bps(notional=100*s, adv_pct=0.01, venue="XNAS",
                                side="maker", urgency="normal")   # §T2 COST block
    assert cost_bps == -3.0                         # [example] single-source stack check
    if not (cost_bps <= cfg.cost_gate_k * edge_bps):
        log(GATE_VETO, "C3", (cost_bps, edge_bps))  # normative cost-gate predicate
        return []

    tickets = [make_ticket(side="BUY",  qty=100, limit=bid_px, tif="DAY", maker=True,
                           parent_signal="S010@" + str(snap.event_ts)),
               make_ticket(side="SELL", qty=100, limit=ask_px, tif="DAY", maker=True,
                           parent_signal="S010@" + str(snap.event_ts))]
    for tk in tickets:
        assert passes_fat_finger(tk, s)             # C16: ±5% collar [default], ≤1 lot [example], ≤$50k [example]
        assert locate_ok(tk)                        # C7 short discipline
        log_decision(tk, inputs_hash(snap, vpin), params_hash(cfg))  # C5 / Appendix G
    assert all(tk.intent_ts > snap.event_ts for tk in tickets)  # intents after the signal event
    # Fills (broker-side) satisfy fill_event > signal_event (C4); the harness asserts it —
    # no signal-event fills, ever. Child-order state machine + partial-fill policy: Appendix C v1.0.0.
    return tickets
```

Helpers (defined, not black boxes): `pull_quotes()` = emit cancel intents for all `WORKING` tickets (Appendix C cancel path); `skew_only(q)` = cancel the quote on the inventory-adverse side, keep/widen the favorable side, issue no new `ticket_id`s; `log(...)` / `log_decision(...)` = Appendix G `DecisionRecord`; `passes_fat_finger` / `locate_ok` per C16/C7; `session_seconds_remaining()` = seconds to the `15:30` ET flatten [example].
