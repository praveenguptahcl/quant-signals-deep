### T0.7 Risk contract + kill switch

```yaml
risk_contract:
  per_trade_risk_R: 250            # USD risk budget per trade [example]
  max_adverse_per_trade: 1.0 R     # stop distance multiple [default]
  daily_loss_stop_R: 12            # then no new entries; session ends at -12R [default]
  max_concurrent_positions: 20     # no pyramiding [default]
  max_gross_notional: 1000000      # USD sleeve cap [example]
  sleeve_stop_pct: 3.0             # sleeve daily loss stop, % of NAV [default]
  inelig_kill: 3                   # strategies ineligible in one month [default]
  kill_conditions:
    - sleeve daily loss <= -3% NAV → TRIP (expire working intents, no new intents)
    - 3+ sub-strategies ineligible in one month → TRIP (halve sleeve on re-arm)
    - meta-label precision collapse (precision < 0.5) → TRIP
    - data feed break for a sub-strategy → TRIP
    - decision-log write failure → TRIP (halt emission)
  enforcement: intraday-hard  # trips are automatic, not advisory [default]
  calibration_recipe: >
    Walk-forward on 12 monthly blocks [example]: fit tau / strat_cap / k on
    block t, freeze, validate sleeve Sharpe vs equal-weight on block t+1;
    shrink per-trade R until max monthly drawdown < sleeve_stop_pct/2 [default].
```

**Kill-switch state machine:** `ARMED → TRIPPED → RECOVERY → ARMED`.

- `ARMED`: normal operation; every bet evaluates the kill conditions.
- `TRIPPED`: any kill condition fires → all working intents expire unfilled
  (idempotent), emit nothing new, state `OFF`, log `KILL_TRIP` with a hash
  chain.
- `RECOVERY`: manual operator review only — no automatic transition.
- `ARMED` (re-entry): only after the re-arm checklist passes in full, logged
  as `KILL_REARM` with the checklist result.

**Re-arm checklist** (all must be true):

- [ ] Losses reconciled against the decision log [default].
- [ ] Feeds healthy: no lag beyond the class budget [default].
- [ ] Risk limits reviewed and re-pinned [default].
- [ ] Decision-log hash chain intact [default].
- [ ] Fixture replay green on the current build [default].
- [ ] Operator sign-off: named human approves re-arm (no automatic recovery) [default].

### Entry rule (Boolean — no prose-only conditions)

```
haircut_ok  = haircut_score_i >= haircut_min          # >= 0.0 [default]
meta_ok     = meta_p >= meta_p_min                    # >= 0.5 [default]
weight_ok   = (w_i > 0) and (sleeve_drawdown_pct < sleeve_stop_pct)   # [default]
cost_ok     = expected_cost_bps(...) <= k * edge_bps  # normative predicate [default]

ALLOCATE := haircut_score_i = median − 0.5×IQR (CPCV PSR) [example];
            w_i = softmax(score_i / τ), τ = 0.40 [calibrate];
            score_i < haircut_min → w_i = 0 [default];
            w_i <= strat_cap (0.70) [default]; 90% invested, 10% cash [default]
BET := sub-strategy signal at t AND meta_ok AND weight_ok AND cost_ok
     AND (now >= cooldown_until) AND (kill.state == ARMED)
ENTRY = haircut_ok and meta_ok and weight_ok and cost_ok \
        and (now >= cooldown_until) and (kill.state == ARMED)
```

Gate order is fixed: haircut_ok → meta_ok → weight_ok → cost gate → ticket
intent. No reordering.

### Exits (with post-exit cooldown)

```
deselect   -> haircut_score_i < haircut_min: w_i = 0 at next rebalance [default]
meta_veto  -> meta_p < meta_p_min: no bet intent, veto-before-generation (C12) [default]
sleeve_stop-> sleeve_drawdown_pct >= sleeve_stop_pct: TRIP (kill), expire working intents [default]
psr_wide   -> psr_band > psr_band_mult * median_score: hold weights (no rebalance) [default]
ON_EXIT: cooldown_until = next_rebalance; C10 suppresses re-entry until the cooldown elapses [default]
```

Exits are never cost-gated: de-selecting and stop exits always fire [default].

### Position sizing (fenced function)

Bet sizing is delegated to the sub-strategy; the selector scales and caps it
inside the R budget, net of the expected cost.

```python
def size_sleeve_bet(risk_budget_R, stop_distance, vol_estimate, adv_cap, cost_bps, cfg):
    """shares = f(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost). [default]"""
    sleeve_i = state.weights[sub_id] * cfg.sleeve_nav          # allocation dollars [default]
    meta_scale = min(max(meta_p / cfg.meta_p_min, 0.5), 1.5)   # 50–150% [example]
    sub_qty = b.sub_qty * meta_scale * state.weights[sub_id]   # sub-strategy size, scaled [default]
    stop_leg = risk_budget_R / max(stop_distance * ref_price, 1e-12)
    vol_leg = risk_budget_R / max(vol_estimate * ref_price, 1e-12)
    adv_leg = 0.10 * adv_cap                                   # 10% participation [default]
    cost_shares = (cost_bps / 1e4 * sleeve_i) / max(ref_price, 1e-12)  # expected $ cost in shares [example]
    qty = min(sub_qty, stop_leg, vol_leg, adv_leg)
    return int(max(qty - cost_shares, 0))
```

def expected_cost_bps(notional, adv_pct, venue, side, urgency) -> float:

## §T3 Math + normative pseudocode

### Math

- `haircut_score_i = median − 0.5×IQR` over the CPCV PSR distribution [example].
  CPCV: `N = 6` groups, `k = 2` test groups → `15` splits tiling into `5`
  backtest paths [example]; purge window and embargo scale with the label
  horizon; embargo ≈ `10–20%` of the label horizon [documented] (skfolio
  convention; de Prado recommends a small embargo ≈ `1%` [documented]).
- `w_i = softmax(score_i / τ)`, `τ = 0.40` [calibrate]; `score_i <
  haircut_min → w_i = 0`; `w_i ≤ strat_cap`; `Σw = 1 − cash_pct`.
- `edge_bps`: per-bet expected edge in bps, mapped from the parent signal
  score. Reference value from the gate-pass fixture row: `40.0 bps [example]`.
- `cost_bps = expected_cost_bps(notional, adv_pct, venue, side, urgency)` —
  four-part stack, §T2 only.
- Gate: `expected_cost_bps(...) <= k * edge_bps` with `k = 0.5 [default]`.
- Sizing: `shares = f(risk_budget_R, stop_distance, vol_estimate, ADV_cap,
  cost)` per the §T2 fenced function (sub-strategy size, meta-scaled
  50–150% [example], R/stop/vol/ADV-capped, net of expected cost).
- Exits: monthly de-select at `haircut_min`; meta-label veto per bet;
  sleeve stop at `sleeve_stop_pct` → TRIP; `ON_EXIT: cooldown_until =
  next_rebalance` [default]; exits never cost-gated.
- Fills modeled at bar `t+1` or later; `assert fill_event > signal_event`.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```python
function emit(state, signals, cfg) -> list[OrderTicket]:
    # The selector allocates; entries are the sub-strategies' signals.
    assert signals non-empty else return [] and state.module_state = UNKNOWN   # F1
    b = signals[-1]  # bet candidate from a sub-strategy
    assert b.sub_id in state.weights else return [] and state.module_state = UNKNOWN  # F2
    if kill.state != ARMED: return []                        # C11; state OFF
    if market_state != CONTINUOUS_TRADING:                  # C6 / §T0.5
        state.module_state = UNKNOWN if market_state == HALTED else DEGRADED
        return []
    if state.weights[b.sub_id] <= 0: return []              # de-selected
    if b.meta_p < cfg.meta_p_min:                           # C12 veto-before-generation
        log GATE_VETO; return []
    if now < state.cooldown_until: return []                # C10 exit cooldown
    haircut_ok = b.haircut_score >= cfg.haircut_min         # g1 [default]
    meta_ok = b.meta_p >= cfg.meta_p_min                    # g2 [default]
    weight_ok = (state.weights[b.sub_id] > 0) and (sleeve_drawdown_pct < cfg.sleeve_stop_pct)  # g3 [default]
    edge_bps = b.sub_edge_bps * state.weights[b.sub_id]
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    enter = haircut_ok and meta_ok and weight_ok and cost_ok
    tickets = []
    if enter:
        qty = size_sleeve_bet(cfg.per_trade_R, stop_distance, vol_estimate, adv_cap, cost_bps, cfg)
        t = OrderTicket(b.sym, b.side, qty, None, IOC, uuid(), f'{b.sub_sig}@{b.ts}', now(), NEW)
        assert fill_event > signal_event                    # t->t+1
        assert t.stp is True                                # C1 self-trade prevention
        log_decision(t, inputs_hash, params_hash)           # C5 hash-chained
        tickets.append(t)
    return tickets
    # Monthly (separate cadence): recompute CPCV haircut scores; w = softmax(score/τ);
    # cut score<haircut_min to zero; cap w_i at strat_cap; hold if psr_band too wide.
```

## §T8 Failure modes

| Trigger | Detect | Action | Recovery | Check |
|---|---|---|---|---|
