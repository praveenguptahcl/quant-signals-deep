# T039 — ETF Creation/Redemption Flow Trader

Trades ETF premium/discount dislocations against the creation/redemption mechanism: when an ETF trades rich to NAV beyond the creation cost plus the cost gate, sell the ETF and buy the basket (creation arbitrage); when cheap, the reverse. Engle–Sarkar (2006) anchor domestic dislocations as small/transient; Petajisto (2017) documents where they are not. Provenance **[D]**.

```yaml
    shrink per-trade R until max drawdown < daily_loss_stop/2 [default].
```

**Kill-switch state machine:** `ARMED → TRIPPED → RECOVERY → ARMED`.

- `ARMED`: normal operation; every bar evaluates the kill conditions.
- `TRIPPED`: any kill condition fires → cancel all working intents
  (`NEW`/`WORKING` → `CANCELLED`, idempotent), flatten managed positions via
  the exit rule, emit nothing new, state `OFF`, log `KILL_TRIP`.
- `RECOVERY`: manual operator review only — no automatic transition.
- `ARMED` (re-entry): only after the re-arm checklist passes in full, logged
  as `KILL_REARM` with the checklist result.

**Re-arm checklist** (all must be true):

- [ ] Feed health green: all §T5 inputs fresh inside the staleness TTL.
- [ ] Kill condition cleared: the tripping metric is back inside limits for `30 min [default]` [default].
- [ ] Decision log reconciled: `KILL_TRIP` record present and hash chain intact.
- [ ] Risk re-check: per-trade R and gross caps re-confirmed against current equity.
- [ ] Operator sign-off: named human approves re-arm (no automatic recovery).

## §T2 Specification

### Universe

ETFs with published iNAV and creation/redemption access; liquid baskets.

### Entry rule (Boolean — no prose-only conditions)

```
premium_bps = (ETF - iNAV) / iNAV * 1e4
ENTRY rich: premium_bps >= trigger_bps -> sell ETF / buy basket (creation)
ENTRY cheap: premium_bps <= -trigger_bps -> buy ETF / sell basket (redemption)
```

### Exits (with post-exit cooldown)

```
converge -> |premium| <= 2 bps [example] -> unwind
create/redeem -> deliver basket vs ETF at NAV -> FLAT
stop -> adverse stop_bps -> unwind
```

### Position sizing (fenced function)

```python
def size_etf(risk_R_usd, stop_bps, px, creation_unit, adv_shares, cfg):
    raw = risk_R_usd / (stop_bps / 1e4 * px)
    # creation-unit quantization: round down to whole units
    units = int(raw // creation_unit)
    return min(units * creation_unit, cfg.adv_cap_pct / 100 * adv_shares)
```

```python
def expected_cost_bps(notional, adv_pct, venue, side, urgency, cfg):
    """COST-block callable. ETF arb: creation fee priced, no market impact modeled."""
    spread = cfg.spread_full_bps / 2.0                 # ETF half-spread
    fee = cfg.taker_fee_bps + 2.0                      # + creation/redemption fee [example]
    borrow = cfg.borrow_bps
    impact = cfg.impact_k * math.sqrt(max(adv_pct, 0.0) / 100.0)
    if urgency == "high":
        impact *= 1.5
    return spread + fee + borrow + impact
```

## §T3 Math + normative pseudocode

Lettau–Madhavan (2018) [documented]: creation/redemption architecture bounds the
premium by the creation cost. Engle–Sarkar (2006) [documented]: domestic dislocations are
small and transient — the empirical anchor. Petajisto (2017) [documented]: ~100 bps
deviations exist on identical-portfolio ETFs — the 'why APs get paid' result. Jain et al.
(2021) [documented]: algorithmic competition shrinks deviations — the decay evidence.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
def emit(state, signals, cfg):
    sig = primary(signals, "S056")          # premium vs creation bound
    if sig is None or invalid(sig): return [], state.unknown()
    if state.position != 0:
        if abs(sig.premium_bps) <= 2.0 or sig.disruption or stopped(state, cfg):
            return exit_tickets(state), state.flat()
        return [], state.ok()
    if abs(sig.premium_bps) >= cfg.trigger_bps and sig.ap_access:
        sides = ("SELL","BUY") if sig.premium_bps > 0 else ("BUY","SELL")
        cost = expected_cost_bps(notional(), adv_pct(), venue(), "taker", "normal", cfg)
        # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
        if cost <= cfg.cost_gate_k * sig.edge_bps:
            t1 = OrderTicket.intent(sides[0], qty=size_etf(...), limit=px_etf())
            t2 = OrderTicket.intent(sides[1], qty=size_etf(...), limit=px_basket())
            for t in (t1, t2): t.intent_ts = sig.computed_at
            assert fill_event > signal_event  # t->t+1 causality: no-signal-bar fills
            return [t1, t2], state.open("ETF_ARB")
        log("GATE_VETO", cost=cost)
    return [], state.ok()
```

Causality: every feature uses inputs with `event_ts ≤ t` only; the earliest
fill for a bar-`t` intent is bar `t+1`'s open. Mandatory unit test:
no-signal-bar fills.
