## §1.5 — Standing blocks

### B1. Module intent

This module specifies one strategy rule completely: its gates, its cost model,
its failure modes, and its kill lifecycle. It is buildable by an AI engineer
from this file alone plus the fixtures.

### B2. Scope boundary

The module emits OrderTicket **intentions** only. It never places, routes, or
cancels real orders; it never touches a broker API. Position management,
portfolio constraints, and execution live outside this module.

### B3. OrderTicket doctrine

Every emitted intent is a canonical Appendix C OrderTicket: `ticket_id`,
`strategy_id`, `symbol`, `side`, `qty`, `order_type`, `limit_price`,
`time_in_force`, `signal_ts`, `expiry_ts`. Partial fills are the broker's
domain; this module's policy is stated in §T0. Cancel/replace emits a new
ticket intent with a new `ticket_id`, never a mutation.

### B4. Time causality

`assert fill_event > signal_event`. A signal computed on bar `t` may not fill
before bar `t+1`. Fixture `signal_ts` values precede any modeled fill; tests
enforce the ordering. There is no lookahead anywhere in this module.

### B5. Cost doctrine

Cost is a four-part stack (spread, fee, borrow, impact) computed only by
`expected_cost_bps(...)`. The gate `expected_cost_bps(...) <= k * edge_bps`
runs before any ticket intent. COST values appear only in the §T2 COST block;
§T4 shows the function call and its result, never restated components.

### Time contract

- **Clock domain:** exchange wall clock `America/New_York`, canonicalized to
  UTC int64 ns at ingest. **Authoritative causality clock:** `signal_ts`
  (the bar-close event ts).
- **max_skew:** 1 s [default] between feed clocks; a feed exceeding skew is
  marked stale.
- **Jitter budget:** not binding for daily bar-clock [default].
- **Bar-label rule:** bars are labeled by the NYSE session date of their close
  (America/New_York); the signal event is the close of bar `t`.
- **Staleness TTL:** daily bars are valid until the next session open; the
  options-flow confirmation has TTL = 1 session [default]. Beyond TTL the
  confirmation is treated as **missing** (entry vetoed), never carried forward.
- **Gap policy:** missing/skipped sessions → the module emits nothing for the
  gap; invalid input → `UNKNOWN`; never interpolate (F2).
- Timestamps are dual: `(event_ts, asof_ts)` — the fixture's `signal_ts` /
  `fill_ts` are the `event_ts` pair on a synthetic monotone clock for causality
  checks, not market data.

### Module-state enum

`OK | DEGRADED | UNKNOWN | OFF` (Appendix E; the single canonical vocabulary).

- **OK:** inputs fresh, kill `ARMED`, all gates evaluable.
- **DEGRADED:** operator-flagged degraded operation (e.g. the RECOVERY
  observation window) — intents still pass the full gate set; every record is
  flagged in the decision log [default].
- **UNKNOWN:** any invalid or stale input (F1/F2) — emits nothing, never
  interpolates.
- **OFF:** kill `TRIPPED`, or data entitlement missing — emits nothing until
  re-armed (kill) or licensed (entitlement).

### Kill lifecycle

`ARMED` → `TRIPPED` → `RECOVERY` → `ARMED`.

- **ARMED:** gates evaluated; intents emitted only on full pass.
- **TRIPPED** — any of:
- sleeve daily loss <= -2% [example]
- false-break rate >50% over 20 signals [example]
- options confirmation feed stale
- market halt
  All working intents expire unfilled; no new intents. The trip is logged to
  the decision log with a hash chain.
- **RECOVERY:** manual review of the trip reason; losses reconciled; feeds
  verified healthy; fixture replay green.
- **ARMED (re-entry):** only via the re-arm checklist below.

### 3. Position sizing (normative)

```python
def size_shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost_bps, edge_bps) -> int:
    # risk_budget_R = $500 [example] (cfg.per_trade_R)
```

### 8. Robustness + Compliance (coded rules)

**C1.** Self-trade prevention: every ticket intent carries `stp=True`; no wash risk by construction.

**C2.** Time causality: `assert fill_event > signal_event`; signals on bar `t` fill at `t+1` or later.

**C3.** Invalid input → `UNKNOWN`: never interpolate or carry forward (F1/F2).

**C4.** Kill switch: `ARMED` → `TRIPPED` → `RECOVERY` → `ARMED`; `TRIPPED` emits nothing.

**C5.** Decision log: every gate verdict is hash-chained; the chain is verified on replay.

**C6.** Cost gate: `expected_cost_bps(...) <= k * edge_bps` before any intent.

**C7.** Fixed gate order: entry-Boolean gates evaluate in documented order; no reordering.

**C8.** Intent-only + bona-fide intent: OrderTickets are intentions, never orders; every intent is a genuine trading intention, passable by the cost gate and sized within risk limits; no broker calls.

**C9.** Ticket schema: Appendix C fields complete on every intent.

**C10.** Fixture reproducibility: the reference stub reproduces the expected ticket set from the raw tape.

**C11.** No chasing: the breakout bar itself is never traded — trigger: fill modeled on bar t → check: timing box → action: block → log: COMPLIANCE_BLOCK

**C12.** False-break stand-down: 5 sessions on the name after a false break [example] — trigger: entry during stand-down → check: stand-down map → action: veto → log: GATE_VETO

**C13.** Message-rate / cancel-to-trade: the strategy emits at most
`max_concurrent_positions` (3 [default]) new intents per session by
construction; cancels occur only as cancel-replace on re-gate [default].
Venue throttles are enforced by the broker adapter — the cheapest stack cannot
measure them. A broker-reported throttle rejection moves the module to `OFF` +
page [default].

**C14.** Pre-trade fat-finger trio: (i) price collar — limit intents must sit
within ±5% of the t+1 open reference [default]; the reference build emits
marketable OPG intents with `limit=None`, so the collar is vacuous there;
(ii) qty collar — qty is the risk-sized `size_shares(...)` output, already
capped at `0.06 × adv_20d` [example]; (iii) notional cap — ticket notional ≤
`max_ticket_notional` ($1M [default]). Any breach → `COMPLIANCE_BLOCK`, no intent.

**C15.** Locate check: any `SHORT` intent requires an affirmative locate at
intent time. The reference build carries no locate source, so `SHORT` intents
are vetoed (`LOCATE_VETO`) in the reference harness — the reference build is
long-only. Enabling the short leg requires a locate source plus a borrow

**C16.** Public-dissemination gate: this module publishes nothing publicly —
no quotes, no indications, no market-making obligations. Any
dissemination/reporting obligation (e.g. large-trader reporting) lives with
the broker/operator [default].

**C17.** Halt/auction state table: see the §T0 market-state table. `HALTED` →
entries vetoed, working intents expire unfilled; `AUCTION` → evaluation
suspended, OPG intents participate in the t+1 open auction; `CLOSED` → no
evaluation. Trigger: evaluation attempted in a non-continuous state → check:
market-state table → action: veto/block → log: `COMPLIANCE_BLOCK`.

**C18.** Data-entitlement assertions (startup): licensed entitlements for SIP

## §T3 — Math and normative pseudocode

### Math

- `edge_bps`: per-case expected edge in bps, mapped from the parent signal
  score. Reference value from the gate-pass fixture row: `40.0 bps [example]`.
- `cost_bps = expected_cost_bps(notional, adv_pct, venue, side, urgency)` —
  four-part stack, §T2 only.
- Gate: `expected_cost_bps(...) <= k * edge_bps` with `k = 0.5 [default]`.
- Sizing (normative):

```python
def size_shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost_bps, edge_bps) -> int:
    # risk_budget_R = $500 [example] (cfg.per_trade_R)
    # stop_distance = min(band_edge_dist, stop_sigma_mult * vol_estimate)
    q_risk = risk_budget_R / stop_distance
    q_adv = ADV_cap * adv_20d            # ADV_cap = 0.06 [example]
    q = min(q_risk, q_adv)
    haircut = max(0.0, 1.0 - cost_bps / edge_bps)  # cost as fraction of edge [example]
    return int(q * haircut)
```

- Exits (normative):

```
EXIT := target +2.0 x breakout-bar true range [example]
        OR stop at opposite band edge / -1.0 x sigma_20d, tighter [example]
        OR time stop 10 sessions [example]
        OR false-break filter: close back inside band within 2 sessions -> exit at next open [example]
        OR 5-session stand-down on that name after a false break [example]
ON_EXIT: cooldown_until = next session   # [default]; C10
```

- Fills modeled at bar `t+1` or later; `assert fill_event > signal_event`.

### Normative pseudocode

```python
def emit(state: ModuleState, signals: list[Bar], cfg: T094Config) -> list[OrderTicket]:
    assert signals non-empty else return [] and state UNKNOWN               # F1
    b = signals[-1]  # daily bar t, labeled by its NYSE session close date (America/New_York)
    assert b.ts is int64 ns UTC else return [] and state UNKNOWN            # time contract
    assert b.close > 0 else return [] and state UNKNOWN                     # F2
    if kill.state != ARMED: return []                                       # C4
    if market_state != CONTINUOUS_TRADING: return []                        # C17: halt/auction table
    if options_feed.stale_beyond(ttl=1_session): return []                  # confirmation missing -> veto
    if state.name_standdown.get(b.sym, 0) > now: return []                  # C12 false-break stand-down
    if state.open_positions >= cfg.max_concurrent_positions: return []      # risk limit
    if now < state.cooldown_until: return []                                # C10 post-exit cooldown
    edge_bps = 2.0 * b.breakout_tr_bps                                     # modeled: target pays for its vol [example]
    cost = expected_cost_bps(notional, adv_pct, venue, side, urgency)       # §T2 COST stack
    if not (cost <= cfg.cost_gate_k * edge_bps): return []                  # C6: verbatim cost gate
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    enter = (b.squeeze and b.band_break and b.options_agree and b.vol_expansion
             and now >= state.cooldown_until)
    tickets = []
    if enter:
        side = BUY if b.direction == LONG else SHORT
        if side == SHORT and not locate_confirmed(b.sym): return []         # C15 locate check
        stop = min(b.band_edge_dist, cfg.stop_sigma_mult * b.sigma_20d)     # vol_estimate = sigma_20d
        qty = size_shares(cfg.per_trade_R, stop, b.sigma_20d,
                          cfg.participation_cap, cost, edge_bps)            # §T2.3 normative sizing
        qty = min(qty, int(cfg.max_ticket_notional / b.close))              # C14 fat-finger: notional cap
        assert qty > 0 else return [] and state UNKNOWN                     # invalid sizing -> UNKNOWN
        t = OrderTicket(sym, side, qty, None, OPG, uuid(), f'S030@{b.ts}', now(), NEW)
        # breakout confirmed at close t; OPG = execute at the t+1 open; never chase bar t
        assert fill_event > signal_event                                    # C2: no same-bar fills
        log_decision(t, inputs_hash, params_hash)                           # C5
        tickets.append(t)
    return tickets
```
