## §S3 Math + normative pseudocode

**Overnight adjustment** [documented] (C-S (2012)): the two-day high/low is contaminated by the close-to-open jump. Before estimation, subtract the overnight move from each day's range:
$$\Delta\mathrm{PON}_d = \max(L_d - C_{d-1}, 0) + \max(C_{d-1} - H_d, 0),\qquad H^{\mathrm{adj}}_d = H_d - \Delta\mathrm{PON}_d,\; L^{\mathrm{adj}}_d = L_d - \Delta\mathrm{PON}_d.$$

For consecutive (adjusted) days with highs/lows $(H_t, L_t)$, $(H_{t+1}, L_{t+1})$ and two-day high/low $(H_{t,t+1}, L_{t,t+1})$ [documented]:
$$\beta = \mathbb{E}\left[\sum_{j=0}^{1} \left(\ln\tfrac{H_{t+j}}{L_{t+j}}\right)^2\right],\quad \gamma = \left(\ln\tfrac{H_{t,t+1}}{L_{t,t+1}}\right)^2,$$
$$\alpha = \frac{\sqrt{2\beta} - \sqrt{\beta}}{3 - 2\sqrt{2}} - \sqrt{\frac{\gamma}{3 - 2\sqrt{2}}},\quad S = \frac{2(e^{\alpha} - 1)}{1 + e^{\alpha}}.$$
Per two-day pair, the expectation is replaced by the single observation: $\beta = \ln(H_t/L_t)^2 + \ln(H_{t+1}/L_{t+1})^2$ [documented]. Denominator constant $K_2 = 3 - 2\sqrt{2} \approx 0.1715728753$ [documented].

Negative $\alpha$ → spread is floored at zero: per-pair contribution is $\max(S, 0)$ [documented]. If $\beta \le 0$ (degenerate $H=L$ pair) the spread is **unidentified** — the pair is skipped, never assigned a negative spread [documented]. The module spread is the **mean of the identified per-pair spreads** over the trailing window [documented]; applications of C-S (2012) commonly average over `10` two-day periods [documented]. **Causal timing:** trailing window only [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function cs_pair(H0, L0, H1, L1) -> (beta, gamma, alpha, spread) | None:
    if not (H0 >= L0 > 0 and H1 >= L1 > 0): return None        # F1: invalid bar
    beta  = ln(H0/L0)^2 + ln(H1/L1)^2                          # [documented]
    if beta <= 0: return None                                  # unidentified: never negative [documented]
    gamma = ln(max(H0,H1) / min(L0,L1))^2                      # [documented]
    alpha = (sqrt(2*beta) - sqrt(beta))/K2 - sqrt(gamma/K2)   # K2 = 3-2√2 [documented]
    S     = 2*(e^alpha - 1)/(1 + e^alpha)                      # [documented]
    return (beta, gamma, alpha, max(S, 0.0))                   # documented zero-floor

function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                # F1
    ohlc = daily_ohlc(events, cfg.window_days + 2)            # newest last; +1 donor bar for ΔPON
    if len(ohlc) < cfg.min_days + 1:                           # `22` [default]
        return FLAT(DEGRADED, aux={"reason": "min_days"})
    spreads = []; identified = 0
    for i in 1 .. len(ohlc)-1:                                 # trailing window only
        H0, L0, _ = bar(ohlc[i-1]); H1, L1, _ = bar(ohlc[i])
        if cfg.overnight_adjust:                               # `True` [documented]
            pon0 = max(L0 - C(ohlc[i-2]), 0) + max(C(ohlc[i-2]) - H0, 0)
            pon1 = max(L1 - C(ohlc[i-1]), 0) + max(C(ohlc[i-1]) - H1, 0)
            H0, L0 = H0 - pon0, L0 - pon0
            H1, L1 = H1 - pon1, L1 - pon1
        out = cs_pair(H0, L0, H1, L1)
        if out is None: continue                               # unidentified pair: skip, never negative
        identified += 1
        spreads.append(out.spread)
    n_pairs = len(ohlc) - 1
    pos_share = identified / n_pairs
    if pos_share < cfg.min_pos_share:                          # `0.5` [default]
        return FLAT(DEGRADED, aux={"pos_share": pos_share})    # window unidentified
    cs_bps = mean(spreads) * 10000
    assert cs_bps >= 0 else return UNKNOWN                     # F2
    # normative cost-gate predicate (applied by consumers; S013 emits direction=0):
    # expected_cost_bps(...) <= cfg.cost_gate_k * edge_bps, with edge_bps = 0.0 [example]
    sig = SignalVector(symbol, direction=0, confidence=1.0, capital=0.0,
                       computed_at=events[-1].event_ts, staleness=now()-events[-1].asof_ts,
                       module_state=state.module_state,
                       aux={"cs_bps": cs_bps, "screen_pass": cs_bps <= cfg.spread_high_bps,
                            "overnight_adjust": cfg.overnight_adjust, "pos_share": pos_share})
    log_decision(sig, inputs_hash, params_hash)                # C5 / Appendix g
    assert fill_event > signal_event  # t->t+1 causality: trailing window only
    return sig
```

Causality: trailing-window estimator on OHLC; the spread at `T` describes the past - tradable no earlier than `T+1`. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Negative beta: beta <= 0 makes alpha undefined -> detect: beta <= 0 -> action: `DEGRADED`/`UNKNOWN`, never negative spread -> recovery: longer window or drop the name | `check: beta > 0` |
| 2 | Lookahead leakage: bar-close feature traded intra-bar → detect: causality audit flags `fill_event <= signal_event` → action: halt, fix bar finalization → recovery: re-run no-signal-bar-fills test | `check: all(fill_ts > computed_at)` |
| 3 | Staleness/latency: feed timestamps in a race → detect: jitter > budget → action: `DEGRADED`, label simulated-only → recovery: direct feed or stand down | `check: asof_ts - event_ts <= jitter_budget` |
| 4 | Stale bars: corporate actions or halts corrupt the window → detect: adjustment/ halt flags → action: `UNKNOWN`, mask bars → recovery: backfill and replay | `check: no unadjusted bars in window` |
| 5 | Cost blowup: spread+fees+impact on the round trip → detect: cost gate failing on `[measured]` costs → action: widen `k` gate or stand down → recovery: re-pin fee schedule | `check: expected_cost_bps(...) <= k * edge_bps` |
| 6 | Regime breaks: depth/volatility regime shifts → detect: feature distribution break → action: veto entries → recovery: resume when stable for `5` min [default] | `check: feature_z_within_3_sigma [default]` |
| 7 | Overfitting: parameters mined on `1` period → detect: OOS decay → action: purged/embargoed re-validation → recovery: shrink per-symbol | `check: oos_sharpe > 0.5 * is_sharpe [default]` |
| 8 | Data errors: bad ticks, splits, halts → detect: bounds/`seq`-gap monitors → action: `UNKNOWN`, mask bars → recovery: backfill and replay | `check: no crossed quotes in window` |
| 9 | Overnight gap distortion: close-to-open jumps inflate the two-day range γ → detect: `|ln(O_d/C_{d-1})| > 2 × mean(ln(H/L))` [default] → action: apply the overnight ΔPON adjustment (default on) → recovery: re-estimate with adjustment on | `check: overnight_jump <= 2 * intraday_range [default]` |
| 10 | Degenerate zero-range days: H==L → beta=0 → pair unidentified → detect: `cs_pair` returns None → action: skip the pair; if `pos_share < min_pos_share` → `DEGRADED` → recovery: longer window | `check: pos_share >= min_pos_share` |
