# S074 — Gamma exposure / dealer positioning

**Gamma** is the second derivative of an option's price with respect to the underlying: it measures how fast the option's delta changes as the stock moves. Market makers who are *short* gamma must **buy when the stock falls and sell when it rises** to stay delta-neutral --- the opposite of what stabilizes prices. **Gamma exposure (GEX)** aggregates this across all strikes: `GEX = Σ gamma × net_OI × 10,000` [example], in dollars of delta-hedge flow per `1`% [example] underlying move. Positive total GEX (dealers long gamma) damps moves and **pins** the price into expiry; negative total GEX (dealers short gamma) **amplifies** moves, feeding momentum. S074 is a regime classifier and fade input: it computes OI-based GEX under an assumed sign convention and emits a direction for the amplifying regime. Provenance **[SR]** (standard desk reconstruction: the GEX arithmetic is a practitioner standard, but dealer positioning itself is never observed --- see the honesty box).

## §S3 Math + normative pseudocode

$$\mathrm{GEX}_i = \gamma_i \times \mathrm{net\_OI}_i \times 10{,}000, \qquad \mathrm{total\_GEX} = \sum_i \mathrm{GEX}_i, \qquad \mathrm{regime} = \begin{cases}\mathrm{amplify} & \mathrm{total\_GEX} < 0 \\ \mathrm{pin} & \text{otherwise}\end{cases} \quad\text{[example]}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    # state: {symbol, gex_history, module_state, now_ns}; cfg per §S0.2; all rows in one print batch share event_ts
    if empty(events): return UNKNOWN                                  # F1
    if state.symbol is None or empty: return UNKNOWN                  # F1; symbol is never hardcoded
    prints = group events by event_ts; rows = prints[max_key(prints)] # latest OI print batch
    b = rows[0]
    if any(not finite(r.gamma) or r.gamma < 0 for r in rows): return UNKNOWN    # F2 [default]
    if any(not finite(r.net_oi) for r in rows): return UNKNOWN                  # F2 [default]
    assert all(r.asof_ts >= r.event_ts for r in rows)                 # dual-clock rule (Appendix a)
    if state.now_ns - b.asof_ts > cfg.staleness_ttl_s * 1e9: return UNKNOWN    # F4: 3-day TTL [default]; 1e9 = ns-per-second conversion
    tot = sum(r.gamma * r.net_oi * cfg.gex_multiplier for r in rows)  # OI-based GEX, assumed sign [example]
    # negative dealer gamma -> amplifying regime -> fade momentum (direction -1) [example convention]
    regime = "amplify" if tot < cfg.regime_threshold else "pin"
    direction = -1 if regime == "amplify" else 0
    confidence = min(1.0, abs(tot) / cfg.confidence_scale) if direction else 0.0  # [example] scale
    edge_bps = abs(tot) / 1e6                                        # modeled per-trade edge [example]
    cost_bps = expected_cost_bps(notional=1.0, adv_pct=0.001,
                                venue="XNAS", side="taker",
                                urgency="normal")                      # [example] reference inputs
    if not (cost_bps <= cfg.cost_gate_k * edge_bps):
        direction, confidence = 0, 0.0                                 # cost gate [default] k
    earliest_fill_ts = b.event_ts + 86_400_000_000_000                 # next-day open [example]; tradable no earlier than t+1
    assert earliest_fill_ts > b.event_ts                             # causality: no signal-bar fills
    return SignalVector(state.symbol, direction, confidence,
                        cfg.capital_fraction * confidence,
                        b.event_ts, b.asof_ts - b.event_ts, "OK")
```

Causality: computed on the daily OI print from data ≤ *t*; tradable no earlier than *t+1*. Mandatory unit test: no-signal-bar fills. `state.now_ns` is the causality reference clock (wall clock in live, injected in test); the module never interpolates across gaps.
