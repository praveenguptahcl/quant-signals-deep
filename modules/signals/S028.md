### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG  := (close_t > donch_up_t) AND (spread_ticks <= 3) AND (now >= cooldown_until)
               AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT := (close_t < donch_lo_t) AND (spread_ticks <= 3) AND (locate_ok)
               AND (now >= cooldown_until) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT        := otherwise
```

`edge_bps` = rail distance `|close − midline| / close × 10,000` bps [example] — expected expansion beyond the rail.
`spread_ticks` is an optional NBBO-derived Event extension (§S0.3); absent →
the spread gate is skipped [default]. `locate_ok` is asserted by the consumer
per C7; shorts default to absent = not-ok.

## §S3 Math + normative pseudocode

Let $H_t, L_t, C_t$ be the high, low, close of bar $t$, $N$ the lookback. The channel is computed on **completed bars only** — the triggering bar $t$ is excluded (StockCharts ChartSchool documents this convention [documented]):

$$D^U_t(N) = \max_{i \in [t-N,\, t-1]} H_i, \qquad D^L_t(N) = \min_{i \in [t-N,\, t-1]} L_i, \qquad M_t = \frac{D^U_t + D^L_t}{2}$$

Entry (example thresholds — not an institutional standard):

$$\mathrm{long}_t = \mathbf{1}\{C_t > D^U_t\}, \qquad \mathrm{short}_t = \mathbf{1}\{C_t < D^L_t\}$$

Causal timing: the signal is fully determined at the close of bar $t$ and tradable no earlier than the open of bar $t+1$ — without the one-bar shift a breakout is arithmetically impossible (the triggering bar would be compared against a channel including its own high).

**Normative pseudocode** (pseudocode is normative; prose is commentary).
Every §S2 guard appears here; undefined helpers are a spec bug:

```
function signal(state, events, cfg) -> SignalVector:
    # --- F1/F2: input validation — invalid input -> UNKNOWN, never interpolate
    if events is empty:
        return SignalVector(direction=0, confidence=0.0, capital=0.0,
                            computed_at=0, module_state=UNKNOWN)
    e = events[-1]
    if not valid(e):                       # high<low | non-positive prices | missing fields
        return SignalVector(direction=0, confidence=0.0, capital=0.0,
                            computed_at=e.event_ts, module_state=UNKNOWN)
    # --- warmup: need N completed bars before the triggering bar
    if len(events) <= cfg.lookback:
        return SignalVector(direction=0, confidence=0.0, capital=0.0,
                            computed_at=e.event_ts, module_state=OK)
    # --- features on COMPLETED bars only: bar t is excluded (anti-lookahead)
    win = events[len(events) - cfg.lookback - 1 : len(events) - 1]   # N bars
    up  = max(high(win))                    # D^U_t [documented] construction
    lo  = min(low(win))                     # D^L_t [documented] construction
    mid = (up + lo) / 2.0
    signal_event = e.event_ts
    # --- exit handling on an open signal position (§S2 exits, C10)
    pos = state.get("position")
    if pos is not None and pos.direction != 0:
        bars_held = len(events) - pos.entry_len
        exit_hit = ((pos.direction == +1 and (e.close <= mid or e.close < lo))
                 or (pos.direction == -1 and (e.close >= mid or e.close > up))
                 or (bars_held >= 10))                              # 10 [example] bar stop
        if exit_hit or state.module_state != OK:
            state.position = none
            state.cooldown_until = signal_event + cfg.cooldown_s * 1e9   # ns; C10
            log_decision(exit_record(...))                              # C5
            return SignalVector(direction=0, ..., computed_at=signal_event,
                                module_state=state.module_state)
    # --- C10 post-exit cooldown: no re-entry
    if signal_event < state.get("cooldown_until", 0):
        log_decision(cooldown_suppress_record(...))                      # C5
        return SignalVector(direction=0, ..., computed_at=signal_event,
                            module_state=state.module_state)
    # --- entry rule (§S2 Boolean rule, executable): close-through breakout
    brk = +1 if e.close > up else (-1 if e.close < lo else 0)
    spread_ok = (e.spread_ticks is None) or (e.spread_ticks <= cfg.max_spread_ticks)  # [default] absent -> pass
    direction = brk if spread_ok else 0
    # --- C7 locate gate: no SHORT without asserted locate
    if direction == -1 and not state.get("locate_ok", False):
        log_decision(locate_veto_record(...))                           # C5/C7
        direction = 0
    # --- conviction [default] functional form; calibrate OOS per §S2 recipes
    if direction != 0:
        rail = up if direction == +1 else lo
        break_bps = abs(e.close - rail) / e.close * 1e4                 # [default]
        vol_ratio = e.volume / max(mean(volume(win)), 1.0)              # [default]
        conviction = min(0.95, 0.40 + break_bps / 10.0 + 0.20 * min(vol_ratio, 2.0))  # [default]
    else:
        conviction = 0.0
    confidence = conviction
    capital = 0.5 * confidence                                           # 0.5 [default]
    # --- normative cost-gate predicate (C2): executable, concrete arguments
    edge_bps = abs(e.close - mid) / e.close * 1e4                       # [example] rail distance
    cost = expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XNAS",  # [example] reference call
                             side="taker", urgency="normal")
    cost_ok = cost <= cfg.cost_gate_k * edge_bps
    if not cost_ok:
        log_decision(gate_veto_record(...))                             # C5/C2
        direction, confidence, capital = 0, 0.0, 0.0
    # --- book-keep entry for exit/cooldown tracking
    if direction != 0:
        state.position = {direction: direction, entry_len: len(events)}
    sig = SignalVector(symbol=e.symbol, direction=direction, confidence=confidence,
                       capital=capital, computed_at=signal_event,
                       staleness=now() - e.asof_ts, module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                         # C5 / Appendix g
    # --- t→t+1 causality assertion (normative): earliest fill is the NEXT bar's open
    earliest_fill_event = open_time_of_bar(t + 1)       # Timing box: signal@t -> fill@open(t+1)
    assert earliest_fill_event > signal_event, "signal-bar fill"        # no lookahead fills
    return sig
```

`valid(e)` := `e.high >= e.low` and all of `open/high/low/close > 0` and required fields present [default].
`expected_cost_bps` is the §S2 COST-block reference implementation; its `notional`/`adv_pct`/`venue`/`urgency` arguments are part of the interface contract — the reference stack is invariant to them (flagged `[example]`); venue-calibrated variants must consume them and pin a new `fee_schedule_as_of`.

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|
| 1 | Lookahead via forming-bar inclusion → detect: causality audit flags `fill_event ≤ signal_event` → action: halt, fix bar finalization → recovery: re-run no-signal-bar-fills test | `check: all(fill_ts > computed_at)` |
| 2 | Whipsaw bleed: chop manufactures reversing breakouts → detect: `3`+ consecutive failed breaks [default] → action: stand down for the session → recovery: re-arm next session | `check: consec_failures < 3` |
| 3 | Cost blowup: several round-trips/day × spread+fees+impact → detect: cost gate failing on `[measured]` costs → action: require expected move > `2`–`3`× round-trip cost [default] → recovery: re-pin fee schedule | `check: expected_cost_bps(...) <= k * edge_bps` |
| 4 | Parameter mining: `N=20` vs `21` vs `55` always has an in-sample winner → detect: OOS decay → action: purged/embargoed re-validation → recovery: freeze `N` from first principles | `check: oos_sharpe > 0.5 * is_sharpe` [default] |
| 5 | Data errors: bad tick prints a false N-bar high; unadjusted split collapses the channel → detect: bad-tick/`seq` monitors → action: `UNKNOWN`, mask bars → recovery: backfill and replay | `check: no bad ticks in window` |
| 6 | Microstructure noise: on thin names the "breakout" is the spread → detect: spread/ADV screen → action: veto entries → recovery: re-screen universe | `check: spread_ticks <= 3` |
| 7 | Regime breaks: trending-tape breakouts fail at the range transition → detect: higher-timeframe trend-slope flip → action: veto → recovery: resume on trend re-confirmation | `check: htf_trend_aligned` |
| 8 | Stop-cascade chasing: entries placed as stops into resting-stop clusters → detect: order-type policy audit → action: close-confirmed entries only → recovery: policy review | `check: entry_policy == close_confirmed` |
