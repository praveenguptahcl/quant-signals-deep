# S094 — Unusual intraday volume (RVOL) & signed block-trade pressure

Volume vs its own time-of-day history (RVOL) plus the buy/sell imbalance of large block prints. RVOL answers 'is anyone here?' — abnormal participation vs the same time-of-day history; signed blocks answer 'which way are they going?' — volume without direction is noise [documented]. The edge is in the combination: participation confirms the move is institutional, the sign gives the direction, and the fade comes when the imbalance mean-reverts. The RVOL/block-imbalance composite is practitioner-standard reconstruction; the Lee–Ready signing step is documented within it.

### Entry rule (Boolean — no prose-only conditions)

```
RVOL(b)    := V_b / mean(V_b over 20 days, same time-of-day bin)   # [documented]
SIGN       := Lee-Ready: quote test vs 5-s-lagged mid; tick test on midquote prints [documented]
BLOCKIMB   := (BuyVol_blocks - SellVol_blocks) / TotalVol_blocks in [-1,+1]   # size >= 10k [example]
TRIGGER    := RVOL > 2.0 AND |BLOCKIMB| > 0                                   # [example] gates
DIRECTION  := sign(BLOCKIMB) iff TRIGGER else FLAT
```

```

```

## §S3 Math + normative pseudocode

For time-of-day bin b on day t: `RVOL_{t,b} = V_{t,b} / mean(V_{t−d,b})` over `N = 20` days [example]; time-of-day matching removes the diurnal U-shape [documented]. Trigger: `RVOL > 2` [example]. Direction from signed blocks: Lee–Ready (1991) — the quote test compares the trade price to the 5-second-lagged midquote, the tick test resolves midquote trades against the previous price [documented]; blocks are prints ≥ `10,000` shares [example]; `BlockImb = (BuyVol − SellVol)/TotalVol ∈ [−1,+1]`. Trade with the sign of BlockImb; fade/exit when it mean-reverts [documented]. Cost gate: `expected_cost_bps(...) <= k * edge_bps`, `k = 0.5` [default].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
rvol = V_bin / mean(V_same_bin_last_20d)     # completed bins/days only, data <= t
sign = lee_ready(trade.price, lagged_mid(5s), prev_price)  # [documented]
blocks = trades[size >= 10000]                 # [example] threshold
imb = (buy_vol(blocks) - sell_vol(blocks)) / total_vol(blocks)
if rvol > 2.0 and abs(imb) > 0:               # [example] gates
    direction = sign(imb)
    edge_bps = illustrative_drift_bps         # per-event [example]
    assert expected_cost_bps(notional, adv_pct, venue, side, urgency) <= k * edge_bps  # k = 0.5 [default]
else:
    direction = 0                             # volume without direction is noise
assert fill_event > signal_event              # bin-close computation; fill no earlier than next bin
```

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
