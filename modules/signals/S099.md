# S099 — Google Trends attention (ASVI exposure scaler)

An attention gauge, not a direction signal. The canonical ASVI is `log(SVI_t) − log(median(prior 8 weeks))` with the current week excluded [documented]; separately downloaded Trends series are not cross-sectionally comparable — the prior-8-week median must come from a download that strictly precedes the current week, never renormalized on fresh data [documented]. The module is an exposure scaler (long-only `1 + clipped ASVI`) — direction is always `1` as an exposure multiplier, never a long-only direction call [documented].

## §S2 Specification

### Universe

One ticker's weekly SVI; fixture: `9` weeks (seed `99` [example]).

### Entry rule (Boolean — no prose-only conditions)

```
ASVI_t := log(SVI_t) - log(median(SVI_{t-8..t-1}))   # current week EXCLUDED [documented]
exposure := 1 + clip(ASVI_t, -delta, +delta)         # long-only scale [example]
direction := 1 ALWAYS                                # exposure scaler, NOT a direction signal [documented]
```

### Exits (with post-exit cooldown)

```
No exits — an exposure scaler has no position. The consumer re-scales weekly.
Post-change cooldown: after any applied exposure change (including a gate-veto
neutral 1.0), a proposed change within `cooldown_weeks` (= `2` [default]) of
`last_change_week` is vetoed: the module holds `last_exposure` and emits state
DEGRADED (see §S3). Post-change cooldown `2` w [default].
```

### Position sizing (fenced function)

```python
def size_shares(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost,
                confidence, adv_shares):
    # S-module requests capital fraction only; share math lives in the strategy.
    # Reference: capital = 0.5 * confidence  (confidence in [0,1])  [default]
    risk_notional = risk_budget_R * 0.5 * confidence          # [default] 0.5 factor
    shares = risk_notional / max(stop_distance, 1e-9)
    return int(min(shares, ADV_cap * adv_shares * 0.001))     # 0.1% ADV cap [default]
```

## §S3 Math + normative pseudocode

Per week: `ASVI_t = log(SVI_t) − log(median(SVI_{t−8..t−1}))` — current week excluded [documented]. Worked numbers: `ln(100) = 4.6052`, `ln(50) = 3.9120`, ASVI `+0.6931`; `ln(75) = 4.3175` → `+0.4055` [example]. Exposure `= 1 + clip(ASVI, ±0.5)` [example]; direction `1` (scaler, not a signal); confidence `= min(1, |ASVI|)`; capital `0.5 × confidence` [example]. Cost: the COST-block total [example]; edge `= |ASVI| × 100` bps [example]; gate `expected_cost_bps(...) <= k * edge_bps`, `k = 0.5` [default] → fixture week 9 passes [measured].

**Normative pseudocode** (pseudocode is normative; prose is commentary). All
variables are bound; all guards are inline. `event = (event_ts, week, svi)`
with `event_ts` in int64 ns UTC; `cfg = {delta, cost_gate_k, notional,
cooldown_weeks, svi_min}`; module state = `(B_hist, last_event_ts,
last_exposure, last_change_week, market_state)`. Constants: `STALE_NS = 3 ×
604800 × 1e9` ns (3-week TTL, 3× the 1-week cadence per F4 [default]);
`adv_pct = 0.01` [example] (the constant cost stack ignores it; bound here so
the gate call is executable).

```
# --- Guards (ordered; any guard returns without advancing B_hist) ---
if market_state in (HALTED, AUCTION):                     # §S0.5 freeze
    return SignalVector(direction=1, module_state=(UNKNOWN if HALTED else DEGRADED))
if last_event_ts is not None and (event_ts - last_event_ts) > STALE_NS:
    return SignalVector(direction=1, module_state=UNKNOWN)   # F4 staleness
if not (isfinite(event_ts) and isfinite(svi)) or svi <= 0:
    return SignalVector(direction=1, module_state=UNKNOWN)   # F1, never interpolate
if svi < cfg.svi_min:
    return SignalVector(direction=1, module_state=UNKNOWN)    # thin-SVI floor
# locate: long-only scaler — this module never emits SHORT, so the C7 locate
# gate cannot trigger here; the consumer must assert locate before shorting.

# --- Feature ---
B_hist.append(log(svi))                                   # [documented]
last_event_ts := event_ts
if len(B_hist) < 9:
    return SignalVector(direction=1, module_state=UNKNOWN)    # need 8 priors + current
priors := B_hist[:-1][-8:]                                # 8 most recent valid points before
                                                          # the current week; current EXCLUDED [documented]
ASVI := log(svi) - median(priors)
proposed := 1.0 + clip(ASVI, -cfg.delta, +cfg.delta)       # long-only scaler [example]
direction := 1                                            # scaler, NOT a direction signal [documented]
confidence := min(1.0, abs(ASVI))
edge_bps := abs(ASVI) * 100.0                             # [example] illustrative
cost_bps := expected_cost_bps(cfg.notional, adv_pct, "XNAS", "taker", "normal")

# --- Executable cost gate ---
gate_pass := cost_bps <= cfg.cost_gate_k * edge_bps       # normative predicate
if not gate_pass:
    applied := 1.0              # C2 for scalers: neutral scale, direction stays 1
else:
    applied := proposed

# --- Post-change cooldown ---
if last_exposure is not None and abs(applied - last_exposure) > 1e-9 \
        and (week - last_change_week) < cfg.cooldown_weeks:
    applied := last_exposure    # veto the change
    module_state := DEGRADED
elif last_exposure is None or abs(applied - last_exposure) > 1e-9:
    last_exposure, last_change_week := applied, week
    module_state := OK
else:
    module_state := OK

# --- Causality: signal at t, earliest fill strictly after t ---
signal_event := event_ts
fill_event := event_ts + 1
assert fill_event > signal_event                          # t -> t+1, machine-enforced
emit SignalVector(direction=1, confidence=confidence, capital=0.5*confidence,
                  exposure=applied, asvi=ASVI, edge_bps=edge_bps,
                  cost_bps=cost_bps, gate_pass=gate_pass,
                  module_state=module_state, computed_at=signal_event,
                  fill_event_ts=fill_event)
```

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
