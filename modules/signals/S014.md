## §S3 Math + normative pseudocode

For a buy at price $p$ against quotes $(b, a)$ with midpoint $m = (b+a)/2$ and midpoint $m_{t+H}$ at horizon $H$:
$$\text{quoted half-spread} = (a - b)/2,\quad \text{effective} = d\,(p - m),\quad \text{realized} = d\,(p - m_{t+H}),\quad \text{adverse selection} = \text{effective} - \text{realized},$$
$d = +1$ buy / $-1$ sell (S007). Fixture (all *example*): buy at `$100.015` vs `100.00/100.02` -> effective `0.005`; `m_{t+5} = 100.02` -> realized `-0.005`; adverse selection `0.010`. The decomposition is an *ex-post* measurement: it can only gate future aggression, never justify the fill it measured [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    fills = signed_fills(events)                                  # S007-signed
    assert len(fills) >= 10 else return FLAT(DEGRADED)             # [default]
    decomp = [decompose(f, cfg.horizon_min) for f in fills]       # eff / realized / adv-sel
    adv = mean(d.adverse_selection_bps for d in decomp)
    assert isfinite(adv) else return UNKNOWN                      # F2
    edge_bps = 0.0                                                 # [example] analytics-only
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    sig = SignalVector(symbol, direction=0, confidence=1.0, capital=0.0,
                       computed_at=events[-1].event_ts, staleness=now()-events[-1].asof_ts,
                       module_state=state.module_state,
                       aux={"adv_sel_bps": adv, "screen_pass": adv <= cfg.adv_sel_high_bps})
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event  # t->t+1 causality: ex-post measurement gates future fills only
    return sig
```

Causality: the decomposition is measured *after* the fill; it gates the next hour's aggression - it can never justify or alter the fill it measured. Mandatory unit test: no-signal-bar fills.
