# S054 — Copula pairs trading

Correlation asks how much two assets move together on average. A copula asks the full question: given B had a really bad day — say its 5th-percentile return — what is the probability A also had a really bad day, versus a surprisingly good one? That conditional probability can see things correlation cannot: two names may barely correlate day-to-day but always crash together on the ten worst days of the year. The signal converts each day's returns into probability-integral-transform uniforms, computes the conditional probability p(A|B) under the fitted dependence model, and trades when the model says today's joint outcome was nearly impossible. The danger is model risk: the trigger is a derivative of your fitted copula, so a small tail-dependence error becomes a large probability error near 0 and 1. Provenance **[D]**.

### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG_A_SHORT_B  := (p_ab < p_L) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT_A_LONG_B := (p_ab > p_U) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT                 := otherwise
```

### Robustness

Family sensitivity first: the trigger is ∂C/∂v, so small tail-dependence errors → large probability errors near 0/1. Fit the family set (Gaussian/t/Clayton/Gumbel/Frank + rotations) and select by rolling OOS likelihood, never in-sample AIC alone. Validate the PIT: Z_t = Φ⁻¹(P(U≤u|V)) ≈ N(0,1) and serially independent — if the uniforms aren't uniform, everything downstream is fiction.

## §S3 Math + normative pseudocode

Gaussian-copula conditional probability (the reference implementation; t/Clayton/Gumbel/Frank conditionals are computed numerically):

Setup: $u_t = \hat{F}_A(r_{A,t})$, $v_t = \hat{F}_B(r_{B,t})$, clipped at $\varepsilon = 10^{-4}$–$10^{-2}$ [example].
$$p_{A|B,t} = \Phi\!\left(\frac{\Phi^{-1}(u_t) - \rho\,\Phi^{-1}(v_t)}{\sqrt{1-\rho^2}}\right), \qquad p_{B|A,t} = \Phi\!\left(\frac{\Phi^{-1}(v_t) - \rho\,\Phi^{-1}(u_t)}{\sqrt{1-\rho^2}}\right).$$
Trading rule (computed at bar $t$ on data $\le t$; tradable no earlier than $t+1$): enter long A / short B if $p_{A|B,t} < p_L$; enter short A / long B if $p_{A|B,t} > p_U$; exit when $p_{A|B}$ crosses back through $0.5$.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN                        # F1
    b = bars[-1]
    assert 0 < b.u < 1 and 0 < b.v < 1 else return UNKNOWN           # F1/F2
    x1 = norm_ppf(b.u);  x2 = norm_ppf(b.v)
    p = norm_cdf((x1 - cfg.rho * x2) / sqrt(1 - cfg.rho^2))          # rho=0.8 [example]
    assert isfinite(p) else return UNKNOWN                           # F2
    edge_bps = abs(p - 0.5) * 40.0                                   # [example]
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    direction = 1 if (p < cfg.p_L and cost_ok) else (-1 if (p > cfg.p_U and cost_ok) else 0)
    # p_L=0.05, p_U=0.95 [example]
    confidence = min(1, abs(p - 0.5) * 2.0) if direction != 0 else 0
    capital = 0.5 * confidence                                        # [default]
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=b.event_ts, staleness=now()-b.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                      # C5 / Appendix g
    assert fill_event > signal_event                                # t→t+1 causality: no fill on the signal bar
    return sig
```

Causality: The copula is fitted on the formation window (data strictly before the trading window); $p_{A|B,t}$ uses data $\le t$; earliest fill bar $t+1$'s open. Mandatory unit test: no-signal-bar fills.
