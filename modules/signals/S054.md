# S054 — Copula pairs trading

Correlation asks how much two assets move together on average. A copula asks the full question: given B had a really bad day — say its 5th-percentile return — what is the probability A also had a really bad day, versus a surprisingly good one? That conditional probability can see things correlation cannot: two names may barely correlate day-to-day but always crash together on the ten worst days of the year. The signal converts each day's returns into probability-integral-transform uniforms, computes the conditional probability p(A|B) under the fitted dependence model, and trades when the model says today's joint outcome was nearly impossible. The danger is model risk: the trigger is a derivative of your fitted copula, so a small tail-dependence error becomes a large probability error near 0 and 1. Provenance **[D]**.

### Universe

US common stocks with 250–1,000 clean daily observations [example]; economic prefilter (sector/geography); ADV/spread liquidity filter before the pair enters the screen.

### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG_A_SHORT_B  := (p_ab < p_L) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT_A_LONG_B := (p_ab > p_U) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT                 := otherwise

`p_ab = Φ((x1 − ρ·x2)/√(1−ρ²))` with `x1 = Φ⁻¹(u)`, `x2 = Φ⁻¹(v)` [Gaussian copula, ρ = 0.8 [example]]; `edge_bps = |p_ab − 0.5| × 40.0` [example] modeled per-trade edge.
```

### Exits (with post-exit cooldown)

```
EXIT := p_ab crosses back through 0.5 [example] (the pair looks "normal" again)
        OR (module_state != OK)
ON_EXIT: prev_direction = 0
         cooldown_until_ns = now_ns + cooldown_ns   # cooldown_ns = 60 s [default]; C10
ENTRY VETO: while now_ns < cooldown_until_ns, direction is forced to 0 (entries vetoed, exits impossible since flat)
PRECEDENCE: an exit on bar t takes precedence over a reversal entry on the same bar — the module goes flat and re-evaluates at t+1 (earliest fill after cooldown)
```

Family sensitivity first: the trigger is ∂C/∂v, so small tail-dependence errors → large probability errors near 0/1. |---|---|---|

## §S3 Math + normative pseudocode

Gaussian-copula conditional probability (the reference implementation; t/Clayton/Gumbel/Frank conditionals are computed numerically):

Setup: $u_t = \hat{F}_A(r_{A,t})$, $v_t = \hat{F}_B(r_{B,t})$, clipped at $\varepsilon = 10^{-4}$–$10^{-2}$ [example].
$$p_{A|B,t} = \Phi\!\left(\frac{\Phi^{-1}(u_t) - \rho\,\Phi^{-1}(v_t)}{\sqrt{1-\rho^2}}\right), \qquad p_{B|A,t} = \Phi\!\left(\frac{\Phi^{-1}(v_t) - \rho\,\Phi^{-1}(u_t)}{\sqrt{1-\rho^2}}\right).$$
Trading rule (computed at bar $t$ on data $\le t$; tradable no earlier than $t+1$): enter long A / short B if $p_{A|B,t} < p_L$; enter short A / long B if $p_{A|B,t} > p_U$; exit when $p_{A|B}$ crosses back through $0.5$ [example].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    # normative: events newest-last; now_ns = authoritative causality clock
    # (state["now_ns"] is a test-only override)
    assert len(events) > 0 else return UNKNOWN                        # F1
    b = events[-1]                                                    # newest event
    now_ns = state.get("now_ns", b.asof_ts)
    assert now_ns >= b.event_ts                                       # causality sanity

    # --- F1/F2 input validation (invalid input -> UNKNOWN, never interpolate)
    assert isfinite(cfg.rho) and 0.1 <= cfg.rho < 1.0 else return UNKNOWN   # F2; |rho|>=1 undefined; 0.1 bound from Config range [example]
    assert 0 < b.u < 1 and 0 < b.v < 1 else return UNKNOWN             # F1/F2
    assert now_ns - b.asof_ts <= TTL_NS else return UNKNOWN            # F1 staleness; TTL_NS = 3 s [default]

    # --- F4 market-state handling
    if state.market == HALTED:  return UNKNOWN
    if state.market == AUCTION:  return DEGRADED(hold=state.last_sig) # hold last, no new signals

    # --- core conditional-probability trigger (data <= t)
    x1 = norm_ppf(b.u);  x2 = norm_ppf(b.v)
    p = norm_cdf((x1 - cfg.rho * x2) / sqrt(1 - cfg.rho^2))            # rho fitted per refit; 0.8 [example] default
    assert isfinite(p) else return UNKNOWN                            # F2

    # --- exits take precedence over reversal entries
    prev = state.get("prev_direction", 0)
    if prev == +1 and p >= 0.5:
        return exit_flat(state, now_ns)                                # LONG A exited: pair normalized
    if prev == -1 and p <= 0.5:
        return exit_flat(state, now_ns)                                # SHORT A exited: pair normalized

    # --- entry rule (Boolean) with executable cost gate
    edge_bps = abs(p - 0.5) * 40.0                                     # [example] modeled per-trade edge
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    direction = 1 if (p < cfg.p_L and cost_ok) else (-1 if (p > cfg.p_U and cost_ok) else 0)
    # p_L=0.05, p_U=0.95 [documented]

    # --- C10 post-exit cooldown: entries vetoed while the cooldown is live
    if now_ns < state.get("cooldown_until_ns", 0):
        direction = 0

    confidence = min(1, abs(p - 0.5) * 2.0) if direction != 0 else 0   # [default] formula
    capital = 0.5 * confidence                                        # [default]
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=b.event_ts, staleness=now_ns - b.asof_ts,
                       module_state=OK)
    state.prev_direction = direction
    state.last_sig = sig
    log_decision(sig, inputs_hash, params_hash)                      # C5 / Appendix g
    assert fill_event > signal_event                                 # t->t+1 causality: no fill on the signal bar
    return sig

function exit_flat(state, now_ns) -> SignalVector:
    state.prev_direction = 0
    state.cooldown_until_ns = now_ns + COOLDOWN_NS                    # COOLDOWN_NS = 60 s [default]; C10
    sig = SignalVector(symbol, 0, 0.0, 0.0,
                       computed_at=now_ns, staleness=0, module_state=OK)
    state.last_sig = sig
    log_decision(sig, inputs_hash, params_hash)                      # C5
    assert fill_event > signal_event
    return sig
```

Causality: The copula is fitted on the formation window (data strictly before the trading window); $p_{A|B,t}$ uses data $\le t$; earliest fill bar $t+1$'s open. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Lookahead leakage → fitting the copula on trading-window data → detect: window audit → action: strict walk-forward, formation ends ≥`1` day [default] before first signal → recovery: re-fit | `formation_end + 1d <= trading_start` |
| 2 | Misspecification sensitivity → small tail-dependence errors → large probability errors near 0/1 → detect: PIT validation Z_t ≈ N(0,1) → action: family set + rolling OOS likelihood selection → recovery: re-select | `pit_uniform_pvalue > 0.05 [default]` |
| 3 | PIT validation skipped → uniforms not uniform, everything downstream fiction → detect: uniformity tests → action: validate before trading → recovery: re-fit marginals | `pit_uniform_pvalue > 0.05 [default]` |
| 4 | Cost blowup → conditional-probability triggers fire often → detect: turnover audit → action: full cost model per trade; require edge to clear ~5–25 bps round trip [example] → recovery: tighten thresholds | `expected_cost_bps(...) <= k * edge_bps` |
| 5 | Multiple testing → 124,750 pair tests find tail dependence by luck → detect: — → action: economic prefilter, FDR control, OOS validation → recovery: re-screen | `fdr_q <= 0.10 [default]` |
| 6 | Regime breaks → 2019 copula doesn't fit March 2020 → detect: rolling OOS likelihood drop → action: rolling refits; stand down on break → recovery: re-fit | `oos_likelihood_drop < threshold [default]` |
| 7 | Family/threshold mining → one family + one threshold works in-sample → detect: stability audit → action: purged/embargoed CV over full pipeline → recovery: re-validate | `stable_across_families` |
| 8 | Stale/illiquid legs → zero-volume days fake PIT ranks → detect: volume filter → action: ADV/spread liquidity filter before screening → recovery: re-screen | `adv >= min_adv [default]` |
