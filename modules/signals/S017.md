**Calibration ladder (normative — run before any production fit):**

1. **Window sanity:** fit on rolling windows of `fit_window_events`; require `<1000`-event windows to refuse (state `DEGRADED`, S10.2) [default] — below this the MLE is unidentified and `br` prints are noise.
2. **Parameter stability:** `μ`, `α`, `β` must not drift more than `25`% [default] across `5` consecutive windows; drift → shorten window or mark `DEGRADED` (regime shift biases `n` upward [documented], Filimonov & Sornette 2013).
3. **Goodness-of-fit:** time-rescaling check (Ogata 1988 [documented]) — transformed inter-arrival residuals `τᵢ = Λ(tᵢ) − Λ(tᵢ₋₁)` must pass a KS test against unit-exponential at `p > 0.05` [default]; fail → kernel misspecification, try power-law or add a second exponential (phase `2`).
4. **Kernel choice:** compare exponential vs power-law by AIC on a held-out window; exponential is the reference default [default]; power-law fits are documented to bias the branching ratio upward when the true kernel differs (Filimonov & Sornette 2013 [documented]).
5. **Empirical anchors:** on US equities expect branching ratio `n = α/β` in `0.3–0.7` [documented] (Filimonov & Sornette 2012: endogeneity rose from `~0.3` (1998) to `>0.7` (2010) on E-mini S&P 500; `n ≈ 1` prints in equity microstructure are more often calibration bias than true criticality [documented], Filimonov & Sornette 2013 — see §S12). `n ≥ br_max` → HALT (S10.1).
6. **Significance budget:** statistically significant Hawkes fits on real tape needed `~3` months of session data [documented] (arXiv:1406.3967) — intraday rolling fits are *monitoring* gauges, not structural estimates; do not quote their `n` as a market property.

**Sensitivity notes:** `burst_z` is the scheduler's main knob: `3.0` [default] is a conventional `3σ` excursion; lowering to `2.5` [example] roughly doubles burst-flag frequency on stationary fits [internal-est] (tune against scheduler capacity, not PnL). `br_max = 0.95` [default] leaves a `0.05` margin to criticality; empirical equity `n` rarely exceeds `0.7` [documented], so a print above `0.85` [default] should trigger the bias checklist (timestamp grouping? regime shift? quote events mixed in?) before any model change.

## §S3 Math + normative pseudocode

Univariate Hawkes with exponential kernel:
$$\lambda(t) = \mu + \sum_{t_i < t} \alpha e^{-\beta (t - t_i)},\quad \text{branching ratio } n = \alpha/\beta < 1.$$
Stationarity requires $n < 1$; $n \ge 1$ means the fit is non-stationary and the module must HALT [documented]. Mean stationary intensity $\mathbb{E}[\lambda] = \mu/(1-n)$ [documented]. Fixture (closed-form check - *example*): `mu = 0.5`, `alpha = 0.4`, `beta = 1.0`, events at `t = 0, 1, 2` -> `lambda(3) = 0.5 + 0.4*(e^-3 + e^-2 + e^-1) = 0.7212007171103676`. The fixture checks the intensity formula, not a trading decision [documented].

### S3.1 Normative MLE (Ozaki 1979 [documented])

The fitter maximizes the recursive exponential-kernel log-likelihood (Ozaki 1979 [documented]; recursion form per Ogata 1981 [documented]) over event times $t_1 < \dots < t_N$ on $(0, T]$:

$$\log L(\theta) = -\mu T - \frac{\alpha}{\beta}\sum_{i=1}^{N}\!\left(1 - e^{-\beta(T - t_i)}\right) + \sum_{i=1}^{N} \log\!\left(\mu + \alpha A(i)\right),$$

with $A(1) = 0$ and the O(`1`) [documented] recursion
$$A(i) = e^{-\beta(t_i - t_{i-1})}\,(1 + A(i-1)), \quad i > 1.$$

**Normative optimizer contract** (prose is commentary; the contract below is normative):

- **Bounds:** `mu > 0`, `alpha > 0`, `beta > 0`, and `alpha/beta < 1` enforced in the objective (return `-inf` outside; never clamp silently) [default].
- **Initialization:** `mu0 = N/T` [default], `alpha0 = 0.4 * mu0` [default], `beta0 = 1.0` (per second on second-normalized times) [default]; restart from `3` jittered starts [default] (`±20`% [default]) and keep the best log-likelihood — the objective is non-convex [documented].
- **Optimizer:** L-BFGS-B on the bounded box; gradient via finite differences or autograd [default]; tolerance `ftol = 1e-9` [default], `maxiter = 1000` [default].
- **Convergence check:** all starts must agree on `n = alpha/beta` within `0.05` [default]; otherwise emit `DEGRADED` (S10.9). Non-convergence after `maxiter` → `DEGRADED`, reuse last good `theta_hat`.
- **Input guards (normative):** event times must be strictly increasing and in seconds (convert from ns once, at ingest); duplicate or non-monotonic timestamps → `UNKNOWN` (F1) — simultaneous events make `log λ` undefined and `A(i)` degenerate; never de-duplicate silently. Times with `t_i <= 0` or `t_i > T` → `UNKNOWN` (F2).
- **Per-event intensity (live path):** maintain the recursive state `R(t) = Σ α·e^{-β(t−tᵢ)}` across events — on each new event at `t`: `R ← R·e^{-β(t−t_prev)}`, `λ(t) = μ + R`, then `R ← R + α`. This is O(`1`) [documented] per event and exactly matches the closed form.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function hawkes_loglik(times, mu, alpha, beta, T) -> float:   # S3.1 normative objective
    assert strictly_increasing(times) else raise NonMonotonic  # -> UNKNOWN at module level (F1)
    assert mu > 0 and alpha > 0 and beta > 0 else return -inf
    assert alpha / beta < 1.0 else return -inf                 # stationarity box
    A = 0.0
    ll = -mu * T
    prev = None
    for i, t in enumerate(times):
        if i == 0:
            A = 0.0
        else:
            A = exp(-beta * (t - prev)) * (1.0 + A)           # Ogata/Ozaki recursion [documented]
        ll += log(mu + alpha * A)
        ll -= (alpha / beta) * (1.0 - exp(-beta * (T - t)))   # compensator term
        prev = t
    return ll

function hawkes_mle(times, kernel, T) -> (mu, alpha, beta):
    assert len(times) >= 1000 else raise UnderIdentified       # -> DEGRADED at module level [default]
    require kernel == "exponential"  # powerlaw is phase 2
    best = argmax over 3 jittered L-BFGS-B starts of hawkes_loglik  # S3.1 contract
    assert starts agree on alpha/beta within 0.05 else raise NonConverged  # -> DEGRADED [default]
    return best

function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    times = event_times(events, cfg.fit_window_events)            # trade prints only, seconds, per §S2 Universe
    if not strictly_increasing(times): return UNKNOWN             # duplicate/non-monotonic ts (S10.10)
    if len(times) < 1000: return FLAT(DEGRADED)                   # [default] unidentified
    (mu, alpha, beta) = hawkes_mle(times, cfg.kernel, T=times[-1] - times[0])
    br = alpha / beta
    if br >= 1.0: return FLAT(HALT)                               # non-stationary guard [documented]
    lam = intensity_recursive(state, times, mu, alpha, beta)      # O(1) per-event recursion
    z = (lam - state.lam_mean) / state.lam_std
    assert isfinite(lam) else return UNKNOWN                      # F2
    edge_bps = 0.0                                                 # [example] timing input only
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    sig = SignalVector(symbol, direction=0, confidence=min(abs(z)/5.0, 1.0), capital=0.0,
                       computed_at=events[-1].event_ts, staleness=now()-events[-1].asof_ts,
                       module_state=state.module_state,
                       aux={"intensity": lam, "burst": z >= cfg.burst_z, "branching_ratio": br,
                            "mu": mu, "alpha": alpha, "beta": beta})
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event  # t->t+1 causality: intensity at t schedules execution at t+1
    return sig
```

**Goodness-of-fit (normative check, calibration step 3):** after each refit, compute compensator increments `τᵢ = Λ(tᵢ) − Λ(tᵢ₋₁)` via the fitted `λ`; under a correct model these are i.i.d. unit-exponential by the random time-change theorem (Ogata 1988 [documented]; Papangelou 1972 [documented]). Run a KS test vs `Exp(1)`; `p ≤ 0.05` [default] → reject the fit, mark `DEGRADED`, and fall back to the last passing `theta_hat` while the kernel-misspecification path (S10.10) is investigated.

Causality: intensity is computed from events strictly before `t`; it schedules execution after `t` - never retroactively. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Non-stationarity: branching ratio >= 1 -> detect: br >= 1 -> action: HALT, refit on shorter window -> recovery: br < 0.95 [default] for 5 min | `check: branching_ratio < 1.0` |
| 2 | Lookahead leakage: bar-close feature traded intra-bar → detect: causality audit flags `fill_event <= signal_event` → action: halt, fix bar finalization → recovery: re-run no-signal-bar-fills test | `check: all(fill_ts > computed_at)` |
| 3 | Staleness/latency: feed timestamps in a race → detect: jitter > budget → action: `DEGRADED`, label simulated-only → recovery: direct feed or stand down | `check: asof_ts - event_ts <= jitter_budget` |
| 4 | Fleeting quotes/spoofing: displayed size cancels pre-execution → detect: quote lifetime `<50` ms [example] share rising → action: down-weight sub-`50` ms quotes → recovery: re-tune weights | `check: fleeting_share < 0.3 [default]` |
| 5 | Cost blowup: spread+fees+impact on the round trip → detect: cost gate failing on `[measured]` costs → action: widen `k` gate or stand down → recovery: re-pin fee schedule | `check: expected_cost_bps(...) <= k * edge_bps` |
| 6 | Regime breaks: depth/volatility regime shifts — including parameter regime shifts that bias the estimated branching ratio upward toward `1` [documented] (Filimonov & Sornette 2013) → detect: feature distribution break; `n` rising without flow change → action: veto entries, force refit on a shorter clean window → recovery: resume when stable for `5` min [default] | `check: feature_z_within_3_sigma [default]` |
| 7 | Overfitting: parameters mined on `1` period → detect: OOS decay → action: purged/embargoed re-validation → recovery: shrink per-symbol | `check: oos_sharpe > 0.5 * is_sharpe [default]` |
| 8 | Data errors: bad ticks, splits, halts → detect: bounds/`seq`-gap monitors → action: `UNKNOWN`, mask bars → recovery: backfill and replay | `check: no crossed quotes in window` |
| 9 | MLE non-convergence: multi-start disagreement on `n` > `0.05` [default] → detect: convergence check in §S3.1 → action: `DEGRADED`, reuse last good `theta_hat` → recovery: widen window or shorten fit horizon, re-run calibration ladder step 2 | `check: max_start_spread(n) <= 0.05 [default]` |
| 10 | Kernel misspecification: true decay is power-law, fit is exponential → detect: KS time-rescaling test rejects at `p <= 0.05` [default]; `n` drifting to `br_max` on stationary tape → action: `DEGRADED`, fall back to last passing fit → recovery: AIC comparison on held-out window; power-law kernel is phase `2` | `check: ks_pvalue > 0.05 [default]` |
| 11 | Timestamp pathology: duplicate/non-monotonic stamps; exchange packet-grouping → detect: strict-monotonicity guard; `br` jumps on unchanged flow → action: `UNKNOWN` on guard trip (never de-duplicate silently); label SIP-grouped work simulated-only → recovery: exchange-timestamped feed, or stand down | `check: strictly_increasing(times)` |
