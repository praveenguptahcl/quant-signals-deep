## §S3 Math + normative pseudocode

Univariate Hawkes with exponential kernel:
$$\lambda(t) = \mu + \sum_{t_i < t} \alpha e^{-\beta (t - t_i)},\quad \text{branching ratio } n = \alpha/\beta < 1.$$
Stationarity requires $n < 1$; $n \ge 1$ means the fit is non-stationary and the module must HALT [documented]. Fixture (closed-form check - *example*): `mu = 0.5`, `alpha = 0.4`, `beta = 1.0`, events at `t = 0, 1, 2` -> `lambda(3) = 0.5 + 0.4*(e^-3 + e^-2 + e^-1) = 0.5 + 0.4*0.5530 = 0.7212`. The fixture checks the intensity formula, not a trading decision [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    times = event_times(events, cfg.fit_window_events)
    assert len(times) >= 1000 else return FLAT(DEGRADED)           # [default]
    (mu, alpha, beta) = hawkes_mle(times, cfg.kernel)
    br = alpha / beta
    assert br < 1.0 else return FLAT(HALT)                         # non-stationary guard
    lam = intensity(times, mu, alpha, beta)
    z = (lam - state.lam_mean) / state.lam_std
    assert isfinite(lam) else return UNKNOWN                      # F2
    edge_bps = 0.0                                                 # [example] timing input only
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    sig = SignalVector(symbol, direction=0, confidence=min(abs(z)/5.0, 1.0), capital=0.0,
                       computed_at=events[-1].event_ts, staleness=now()-events[-1].asof_ts,
                       module_state=state.module_state,
                       aux={"intensity": lam, "burst": z >= cfg.burst_z, "branching_ratio": br})
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event  # t->t+1 causality: intensity at t schedules execution at t+1
    return sig
```

Causality: intensity is computed from events strictly before `t`; it schedules execution after `t` - never retroactively. Mandatory unit test: no-signal-bar fills.
