### Entry rule (Boolean — no prose-only conditions)

```
VETO := (regime_p >= 0.5) OR (crisis_flag == 1)          # 0.5 [default]; defensive: de-risk / hedge, never a long call
STAND_DOWN := VETO  →  flatten or hedge directional exposure
RE-ARM     := (regime_p < 0.3) for 5 consecutive days [example]
```

Veto state machine (normative; mirrored by `veto_update` in the
`modules/tests/test_S032.py` reference implementation): `veto_active` turns
true when VETO holds and `event_ts >= cooldown_until`; it turns false only
when RE-ARM holds, at which point `cooldown_until = event_ts + cooldown_s`
(C10) suppresses re-entry into the veto. While `veto_active`, direction =
`-1`; otherwise `0`. Any direction ≠ `0` emission must pass the cost gate
(C2) or is zeroed to `0`.

`edge_bps` = `2.0 × |regime_score|` bps [example] — stress-avoidance value of the veto.

## §S3 Math + normative pseudocode

Daily log returns $r_t = \ln(C_t/C_{t-1})$; rolling vol $\sigma_{60}(t) = \sqrt{252}\,\mathrm{sd}(r_{t-59:t})$, realized vol $RV_{60}(t) = \sqrt{252\,\overline{r^2}_{60}}$, equity–bond correlation $\rho_{60}(t)$, drawdown $DD_{60}(t)$, vol-of-vol $\mathrm{sd}(\sigma_{60}, 20)$.

$$z_i(t) = \frac{c_i(t) - \mu_{1260}(c_i)}{\sigma_{1260}(c_i)}, \qquad S_t = \frac{1}{6}\sum_{i=1}^{6} z_i(t), \qquad \mathrm{crisis}_t = \mathbf{1}[S_t \ge 0.9]$$

$$P(\mathrm{crisis}_{t+1}) = \sigma(\beta_0 + \beta_1 S_t)$$

fit by ridge-penalized Newton–Raphson on the trailing `1,260` days [default] (the reference implementation fits once on the final training window as a fixture simplification; production refits daily). Causal timing: everything at day $t$ uses data $\le t$; the veto applies to $t+1$'s session. The filter is late by construction — it confirms stress after arrival.

**Normative pseudocode** (pseudocode is normative; prose is commentary). The
reference implementation in `modules/tests/test_S032.py` is the executable
counterpart of this block (`compute_features` ≡ `features`, `veto_update` ≡
`veto_update`, fixture column `regime_score` ≡ `score`):

```
function features(e, cfg) -> record:                       # causal: data <= t only
    r_t      = ln(C_t / C_{t-1})
    rollvol  = sqrt(252) * sd(r, cfg.roll_window)          # annualized vol level
    rv60     = sqrt(252 * mean(r^2, cfg.roll_window))      # realized vol
    rho60    = corr(r_eq, r_bond, cfg.roll_window)
    dd       = (max(C, cfg.roll_window) - C) / max(C, cfg.roll_window)
    vov      = sd(rollvol, 20)                             # 20 [default] vol-of-vol
    disloc   = abs(rho60 - mean(rho60, cfg.roll_window))    # correlation dislocation
    z_i      = (c_i - mean(c_i, cfg.z_window)) / sd(c_i, cfg.z_window)   # 6 components
    score    = mean(z_1..z_6)
    crisis   = 1[score >= cfg.crisis_threshold]            # 0.9 [default]
    regime_p = logistic(b0 + b1 * score_{t-1})              # AR(1); (b0, b1) = ridge-penalized
                                                          # Newton-Raphson fit, lambda = cfg.logistic_lambda,
                                                          # on the trailing cfg.z_window scored days
    return {rollvol, rv60, rho60, dd, vov, disloc, score, crisis, regime_p}

function veto_update(st, f, e, cfg, cost_ok) -> st:        # normative veto state machine
    enter = (f.regime_p >= 0.5) or (f.crisis_flag == 1)    # 0.5 [default]
    calm  = (f.regime_p < 0.3)                             # 0.3 [default]
    st.calm_streak = st.calm_streak + 1 if calm else 0
    if enter and e.event_ts >= st.cooldown_until:
        st.veto_active = True
    if st.veto_active and st.calm_streak >= 5 and cost_ok: # 5 days [example]
        st.veto_active = False
        st.cooldown_until = e.event_ts + cfg.cooldown_s   # C10
    return st

function signal(state, events, cfg) -> SignalVector:
    assert len(events) > 0 else return UNKNOWN             # F1
    e = events[-1]
    assert valid_bar(e) else return UNKNOWN                # F1/F2: never interpolate
    assert e.event_ts > state.last_ts else return UNKNOWN  # monotonic clock: out-of-order -> UNKNOWN
    state.last_ts = e.event_ts
    f = features(e, cfg)
    edge_bps = 2.0 * abs(f.score)                          # [example] stress-avoidance value of the veto
    cost_ok  = expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XNAS",
                                 side="taker", urgency="normal") <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    state = veto_update(state, f, e, cfg, cost_ok)
    direction = -1 if state.veto_active else 0             # regime veto: de-risk, never a long call
    if direction != 0 and not cost_ok:
        direction = 0                                      # C2 bona-fide intent: sub-threshold -> direction 0
    confidence = f.regime_p if direction != 0 else 0.0
    capital = 0.5 * confidence                             # 0.5 [default]
    assert 0.0 <= confidence <= 1.0 and 0.0 <= capital <= 0.5   # C4 bounds
    sig = SignalVector(symbol=e.symbol, direction=direction, confidence=confidence,
                       capital=capital, computed_at=e.event_ts,
                       staleness=now_ns() - e.asof_ts, module_state=state.module_state)
    log_decision(sig, inputs_hash=hash(e), params_hash=hash(cfg))  # C5 / Appendix g
    assert fill_event_ts > sig.computed_at                # t->t+1 causality: no signal-bar fills
    return sig
```

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
