# S098 — Short-squeeze / borrow-stress (exclusion gate)

A crowded-short detector that gates — never initiates. Per-name features (SI/float, days-to-cover, borrow fee) are cross-sectionally z-scored and summed into an illustrative crowding score (desk-specific, NOT an institutional standard [documented]); names in the squeeze-risk corner are NO-SHORT and NO-LONG exclusions, and the squeeze is a `3–5` day anti-short window on the trigger day [documented]. Direction is always `0` — the module emits flags, the consumer owns the book.

## §S3 Math + normative pseudocode

Per name: `crowd = z(SI/float) + z(DTC) + z(fee)` cross-sectionally (sample SD) [documented] — the illustrative desk-specific composite, NOT an institutional standard. Fixture scores: MEMEQ `+4.72`, PWRS `+1.51`, KLVR `+0.12`, ZQTA `−2.54`, NORD `−1.90`, DLTA `−1.91` [documented]. MEMEQ hand-checks: `42/150 = 28.0`%; `42/4.5 = 9.33` days; `42 × 30/365 = 3.45`% `30`-day drag on `$1`M [documented]. Hard flag: `fee_bps > 100` [example] (KLVR `850` bps → hard; ZQTA `40` bps → not). Squeeze flag: crowd `> 0.60`, DTC `> 5`, fee `> 500` bps, util `> 90.0` (percent units) [example]. Direction is always `0` [documented]; edge is `0` — the normative gate `expected_cost_bps(...) <= k * edge_bps` is exercised in the test on reference edges (passes at `100`, blocks at `0.01`) [measured].

**Normative pseudocode** (pseudocode is normative; prose is commentary). Every
symbol is bound below; there are no undefined names. Units: si_m/float_m/adv_m
in M shares; fee_ann in %/ann; util in PERCENT (`0–100`); fee_bps in bps;
crowd unitless; timestamps int64 ns UTC.

```
# --- inputs: one panel event per name -------------------------------------

float_m  := e.float_m        # shares float, M shares
adv_m    := e.adv_m          # 20-day ADV, M shares
fee_ann  := e.fee_ann        # borrow fee, %/ann

dix      := e.dix            # optional dark-pool proxy, %
event_ts := e.event_ts       # signal-event clock
asof_ts  := e.asof_ts        # data-vintage clock
market   := e.market_state   # CONTINUOUS_TRADING | HALTED | AUCTION | CLOSED

# --- config (§S0.2) -------------------------------------------------------
hard_fee_bps, sqz_crowd, sqz_dtc, sqz_fee_bps, sqz_util, k := cfg.*   # k = 0.5 [default]
ttl_ns      := 3 * 86_400_000_000_000   # 3 d staleness TTL [default] (time constant in ns)
cooldown_ns := 5 * 86_400_000_000_000   # 5 d post-window cooldown [default]

# --- guards (in order; a guard failure emits direction 0 and returns) -----
if market in {HALTED, AUCTION, CLOSED}:            # §S0.5 — freeze, no new flags
    module_state := UNKNOWN if market == HALTED else DEGRADED
    return
if any_invalid(si_m, float_m, adv_m, fee_ann, util):   # NaN/None/non-finite, float_m<=0, adv_m<=0, si_m<0
    module_state := UNKNOWN; return                        # F1: never interpolate
if (now_ns - asof_ts) > ttl_ns:                            # F4 staleness
    module_state := UNKNOWN; return
if squeeze_window_active(name) and (now_ns - window_end_ns) < cooldown_ns:
    hold_flags(); return                                    # §S2 post-exit cooldown
# C7 locate is consumer-side: this module emits direction 0 ONLY. Any consumer
# short intent MUST assert locate_ok (Reg-SHO threshold list → direction 0).

# --- features (data at t only; no lookahead) ------------------------------
si_float_pct := si_m / float_m * 100.0
dtc_days     := si_m / adv_m
fee_bps      := fee_ann * 100.0
crowd        := z(si_float_pct, panel) + z(dtc_days, panel) + z(fee_ann, panel)
                # cross-sectional, sample SD [documented]
                # ILLUSTRATIVE desk-specific composite, NOT an institutional standard

# --- flags ------------------------------------------------------------------
hard    := fee_bps > hard_fee_bps                                          # 100 bps [example]
squeeze := (crowd > sqz_crowd) and (dtc_days > sqz_dtc)                     # 0.60 / 5 [example]
           and (fee_bps > sqz_fee_bps) and (util > sqz_util)                # 500 bps / 90.0% [example]

# --- output -------------------------------------------------------------------
out.direction  := 0 ALWAYS                       # module GATES, never initiates [documented]
out.confidence := 0.0; out.capital := 0.0; out.edge_bps := 0.0
out.gate_pass  := hard or squeeze                # veto path: flagged names are excluded downstream
module_state   := OK

# --- cost gate (exercised on reference edges; the module never initiates) ---
notional := 10_000.0        # [example] reference notional
adv_pct  := 0.01             # [example] reference participation
venue    := "XNAS"           # [example]
side     := "taker"          # [default] short entries take liquidity
urgency  := "normal"         # [default]
assert expected_cost_bps(notional, adv_pct, venue, side, urgency) <= k * ref_edge_bps
    # ref_edge_bps := 100.0 [example] → passes; ref_edge_bps := 0.01 [example] → blocks  [measured]

# --- causality ------------------------------------------------------------------

fill_event   := open(t+1)                    # earliest reaction @open(t+1); signal-bar fills forbidden
```
