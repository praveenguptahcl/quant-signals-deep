# S083 — Imbalance/tick/volume/dollar bars

Alternative bar clocks — tick, volume, dollar, and imbalance bars — sample by trading activity or one-sided flow instead of wall-clock minutes. Volume/dollar bars have better statistical properties (closer to Gaussian, less heteroskedastic) than minute bars; imbalance bars concentrate information arrival. This is infrastructure, not alpha: bars make downstream statistics cleaner but predict nothing by themselves [documented].

## §S3 Math + normative pseudocode

Tick bars: close every N trades. Volume bars: close when Σq_i ≥ V*. Dollar bars: close when ΣP_i·q_i ≥ D*. Imbalance bars: θ_T=Σb_i·v_i (or Σb_i, or Σb_i·P_i·v_i), close when |θ_T| ≥ E_0[T]·|E_0[θ]| (expected bar length × expected per-trade imbalance, EWMA-estimated [documented]). Each bar emits OHLCV: O=first P, H=max P, L=min P, C=last P, V=Σq. Bar k is complete only when its close condition fires; features on bar k are tradable no earlier than bar k+1's first trade [documented].

Fixture scope: the chapter's 15-trade synthetic tape (seed 83 [example]) plus 2
validation rows (ev16 corrupt price, ev17 `HALTED`), processed under all three
clocks in one pass — tick N=5, volume V*=3000 shares, imbalance |θ|≥1500 signed
shares [example]. Production-scale defaults (N 1k–50k, V* 0.1–2% ADV, D* $1M–$50M)
are documented in §S2; the fixture uses toy thresholds so all three close rules
fire inside 15 trades. Tick-rule sign: uptick +1, downtick −1, zero-tick reuses
the previous sign [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary). All
symbols are bound; every guard from the prose appears inline:

```
# CONFIG (bound in §S0.2): tick_n, vol_shares, imb_theta, theta_lambda,
#   tick_rule="carry_forward" [default], ttl_mult=3 [default], cost_k=0.5 [default]
# STATE per symbol: for clock in {tick, vol, imb}: {bar_id, acc, o,h,l,c};
#   last_event_ts (int64 ns | None); last_vector; market_state
# INPUT: e = one canonical Event (newest trade). Direction of all S083
#   emissions is 0 (infrastructure emits no tradeable hint) [documented].

def on_trade(state, e, cfg):
    # G1 — halt/auction guards (§S0.5 market-state table)
    if e.market_state == HALTED:
        freeze(state)                      # accumulators, bar ids, last_event_ts untouched
        return vector(module_state=UNKNOWN, reason="halt")   # contributions across reopen discarded
    if e.market_state == AUCTION:
        state.module_state = DEGRADED
        return hold(state.last_vector, module_state=DEGRADED)  # no new signals

    # G2 — locate/cooldown: degenerate for infrastructure. No orders are emitted,
    # so there is nothing to locate and no position cooldown. Locate (C7) and
    # post-exit cooldown (C10) are enforced by the consuming T-modules.
    # Session-boundary rule: reset θ at the open (or carry explicitly, logged) [documented].

    # G3 — input validity (F1): invalid -> UNKNOWN, never interpolate
    if e.event_ts is None:                 return vector(UNKNOWN, "missing-ts")
    if not (isfinite(e.price) and e.price > 0):  return vector(UNKNOWN, "bad-price")
    if not (isfinite(e.size)  and e.size  > 0):  return vector(UNKNOWN, "bad-size")
    if e.sign not in {+1, -1}:              return vector(UNKNOWN, "bad-sign")

    # G4 — causality pin 1: event_ts strictly increasing; stale feed -> UNKNOWN (F4)
    assert e.event_ts > state.last_event_ts or state.last_event_ts is None, "ts must be strictly increasing"
    if e.event_ts - state.last_event_ts > cfg.ttl_mult * median_bar_cadence(state):
        return vector(UNKNOWN, "stale-feed")

    # G5 — accumulate + close rules (§S2 entry rule, weights per clock)
    for clock, weight, thresh, use_abs in [
            ("tick", 1,             cfg.tick_n,     False),
            ("vol",  e.size,        cfg.vol_shares, False),
            ("imb",  e.sign*e.size, cfg.imb_theta,  True)]:
        s = state[clock]
        s.o, s.h, s.l, s.c = first_or_update(s, e.price)
        s.acc += weight
        hit = (abs(s.acc) >= thresh) if use_abs else (s.acc >= thresh)
        if hit:
            close_bar(clock, s)            # emit OHLCV for bar s.bar_id; snapshot acc as theta
            # causality pin 2: a closed bar's close event precedes the next bar's first trade
            assert bar_close_event_ts(clock, s.bar_id) <= next_bar_first_event_ts(clock, s.bar_id + 1)
            s.bar_id += 1; s.acc = 0.0; reset_ohlc(s)

    # G6 — open-bar lookahead guard (§S10.3): only closed bars enter features
    assert feature_bar_id < open_bar_id, "never feature the open bar"

    # G7 — executable cost gate: expected_cost_bps(...) <= k * edge_bps
    cost = expected_cost_bps(notional=0.0, adv_pct=0.0, venue="n/a", side="n/a", urgency=0.0)
    edge = 0.0                              # infrastructure emits no edge [documented]
    assert cost_gate_passes(cost, edge, k=cfg.cost_k), "cost gate"   # 0.0 <= 0.5*0.0: vacuous pass [documented]

    # G8 — causality pin 3 (t -> t+1): earliest fill strictly after the signal event
    fill_event_ts = e.event_ts + 1
    assert fill_event_ts > e.event_ts, "fill_event must be > signal_event"
    assert no_signal_bar_fill(), "no fills on the signal bar"

    state.last_event_ts = e.event_ts
    v = vector(direction=0, confidence=0.0, capital=0.0, module_state=OK,
               edge_bps=0.0, cost_bps=cost, computed_at=e.event_ts, fill_event_ts=fill_event_ts)
    state.last_vector = v
    log_decision(e, v)                      # Appendix g v1.0.0, hash-chained (C5)
    return v

# Session end with an incomplete open bar: carry forward or discard — never backfill [documented].
```

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|
| 1 | Minute-bar approximation → resampling 1-min OHLCV into 'volume bars' is not the same object [documented] → true bars require trades → minute bars silently mis-stated as volume bars | `check: input granularity == tick` |
| 2 | Threshold mis-setting → too-small thresholds → noise bars; too large → stale bars [documented] → EWMA-estimated expected imbalance; monitor bar rates → bar rate drifts 2×+ from baseline [example] | `check: bar rate within [0.5×, 2×] baseline` |
| 3 | Open-bar lookahead → using the incomplete current bar's OHLC as a feature [documented] → only closed bars enter features; carry the open bar explicitly → backtest uses bar k while bar k still open | `check: feature bar id < current open bar id` |
| 4 | Session-boundary θ → carrying imbalance overnight mixes regimes [documented] → reset θ at the open; document the choice → overnight θ carried silently | `check: θ reset logged at session open` |
| 5 | Tick-rule error → mis-signed trades corrupt θ [documented] → prefer exchange flags; Lee–Ready fallback with quotes (S007) → sign agreement < 80% vs flags [example] | `check: signing agreement rate reported` |
| 6 | Storage blowup → archiving full tick history 'just in case' [documented] → build bars once, archive bars + a trade sample → terabytes retained with no consumer | `check: retention policy per symbol-day` |
| 7 | Overfitting the clock → tuning N/V*/D* on the backtest [documented] → round thresholds a priori; the clock is plumbing, not a parameter to mine → threshold chosen by backtest Sharpe | `check: thresholds fixed before backtest` |
| 8 | Downstream fixed-spacing assumption → models assuming bars are equally spaced in time [documented] → pass bar durations; use event-time models → time-series model on bar index as clock | `check: model consumes bar timestamps` |
