## §S3 Math + normative pseudocode

$$R_{i,t} = \sum_{j=1}^{m} \beta_{ij} F_{j,t} + \tilde{R}_{i,t}$$ [documented] — factor decomposition (Avellaneda & Lee 2010).
$$\Sigma v_j = \lambda_j v_j, \qquad u_t = z_t - \sum_{j=1}^{m} v_j (v_j^\top z_t)$$ [documented] — PCA residual.
$$Q_{ki} = v_{ki}/\sigma_i, \quad F_{kt} = \sum_i Q_{ki} r_{it}, \quad s_{it} = (X_{it}-\mu_i)/(\sigma_i/\sqrt{2\kappa_i})$$ [documented] — eigenportfolio + OU s-score.

Estimation window ends at t; residuals tradable at t+1 (no look-ahead). Standardize by trailing volatility (correlation PCA). PCA on the past `252` trading days and a `30`-day residual-returns lookback are the documented construction (Epstein et al. 2025, describing the Avellaneda & Lee 2010 parametric benchmark [documented]). Fixture scope: the stated-Σ two-asset reduction u=(A−B)/2 with m=1 [example].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:      # invoked per name, per_bar daily
    assert len(events) > 0 else return UNKNOWN                    # F1
    e = events[-1]                                               # newest event
    if e.market_state != CONTINUOUS_TRADING:                     # C6 / §S0.5
        return UNKNOWN if e.market_state in {HALTED, CLOSED} else DEGRADED
    assert (e.asof_ts - e.event_ts) <= 1e6                       # max_skew 1 ms [default]
    assert now_ns() - e.event_ts <= 3 * 86400e9                  # F4 staleness TTL 3 days [default]
    P = point_in_time_close_to_close_returns(events, window=cfg.W)  # data <= t only
    assert all_finite(P) else return UNKNOWN                     # F1 (returns: negatives legal)
    N = P.shape[0]
    if N < cfg.W:
        return DEGRADED("insufficient_history")
    sigma_hat = trailing_vol(P, cfg.W)                           # per-name trailing vol
    Z = P / sigma_hat                                            # correlation PCA inputs
    Sigma = correlation(Z)                                       # N x N, window ending at t
    lam, V = eigh(Sigma); V = V[:, argsort(-lam)[:cfg.m]]        # top-m eigenvectors, unit norm
    z_t = Z[:, -1]                                               # standardized panel at t
    F_t = V.T @ z_t                                              # factor returns, shape (m,)
    u_t = z_t - V @ F_t                                          # residuals, shape (N,)
    i = self_index                                               # this invocation's name
    X = cumsum(u_i) over last 60 obs                              # [documented] OU lookback
    a_hat, b_hat = ols(X[1:], on=[1, X[:-1]])                     # AR(1) on cumulative residual
    kappa_hat = -log(b_hat) / dt_years                           # annualized mean-reversion speed
    R2_OU = 1 - SS_res / SS_tot                                  # fit quality
    assert all_finite([kappa_hat, R2_OU]) else return UNKNOWN    # F2
    s = (X[-1] - mean(X)) / (std(resid) / sqrt(2*kappa_hat))      # OU s-score [documented]
    if state.cooldown_until[i] is not None and e.event_ts < state.cooldown_until[i]:
        entry_ok = FALSE                                         # C10 post-exit cooldown
    else:
        notional_i = cfg.p_max * NAV                              # per-name planned notional
        edge_bps = abs(s) * 2.0                                  # [example] residual edge per s unit
        cost_bps = expected_cost_bps(notional_i, adv_pct_i, venue_i, "taker", "normal")
        cost_ok = cost_bps <= cfg.cost_gate_k * edge_bps          # executable cost-gate predicate
        ou_ok = (R2_OU >= cfg.r2_crit) and (kappa_hat > 8.4)      # [documented] AL speed threshold
        borrow_ok = borrow_state[i].locate_ok and (not borrow_state[i].recalled)  # C7
        side_ok = (s <= 0) or borrow_ok                          # SHORT leg requires locate
        entry_ok = (abs(s) > cfg.c_thresh) and ou_ok and borrow_ok and side_ok and cost_ok
    if state.position[i] != 0 and abs(s) < cfg.z_exit:
        state.position[i] = 0                                    # exit on s-score decay
        state.cooldown_until[i] = e.event_ts + cfg.cooldown_s * 1e9
    direction = 0
    if entry_ok:
        direction = -1 if s > 0 else +1
        state.position[i] = direction
        state.cooldown_until[i] = e.event_ts + cfg.cooldown_s * 1e9
    fill_event = open_time(t + 1)                                # earliest fill @open(t+1)
    assert fill_event > e.event_ts                               # t->t+1 causality, never the signal bar
    sig = SignalVector(symbol=names[i], direction=direction,
                       confidence=min(1.0, abs(s)/4.0),
                       capital=min(cfg.p_max, confidence * cfg.p_max),
                       computed_at=e.event_ts, fill_event_ts=fill_event,
                       module_state=OK,
                       aux={s_score: s, kappa_hat: kappa_hat, R2_OU: R2_OU,
                            edge_bps: edge_bps, cost_bps: cost_bps,
                            cost_gate_ok: cost_ok, borrow_ok: borrow_ok})
    log_decision(sig, inputs_hash, params_hash)                  # C5 / Appendix g
    return sig
```

Fixture-scope reductions (documented in §S4): the tape fixes the stated-Σ two-asset reduction `u=(A−B)/2` with `m=1` [example], assumes the OU fit passed (`R²_OU=1.0` [default], `κ̂>8.4` [default]) and borrow available (`borrow_ok=TRUE` [default], `locate_ok=TRUE` [default]); `sigma_u=0.72` [example] is the fixture residual-scale constant, not a calibrated parameter. Veto-path, boundary, cooldown, halt, and exit tests override these defaults explicitly.

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
