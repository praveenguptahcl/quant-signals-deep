## §S2 Specification

### Universe

US common-stock pairs with a documented economic link; both legs price > `$5` [example]; short leg locatable.

### Entry rule (Boolean — no prose-only conditions)

```
ENTER_SHORT := (z >= entry_z) AND (pair_cointegrated) AND (locate_ok on short leg)
               AND (now >= cooldown_until) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_LONG  := (z <= -entry_z) AND (pair_cointegrated)
               AND (now >= cooldown_until) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT        := otherwise
```

`edge_bps` = `20 * |z|` bps [example] — twenty bps per unit of spread z-score.

### Exits (with post-exit cooldown)

```
EXIT := (|z| <= exit_z) OR (pair_broken) OR (module_state != OK)
ON_EXIT: cooldown_until = now + cooldown_s   # C10
```

## §S3 Math + normative pseudocode

With the stipulated pair $(A, B)$ and the `form_days` formation window
(`12` [example] on the fixture, `60`–`250` [example] in production):

$$s_t = \frac{P_{A,t}}{P_{B,t}} - 1, \qquad z_t = \frac{s_t - \mu_{\mathrm{form}}}{\sigma_{\mathrm{form}}}$$

$$\mathrm{enter\_short}_t = \mathbf{1}\{z_t \ge \texttt{entry\_z}\}, \qquad \mathrm{exit}_t = \mathbf{1}\{|z_t| \le \texttt{exit\_z}\}$$

with `entry_z`/`exit_z` [example] from the Config. Chapter S4 (seed $49$): $\mu_{\mathrm{form}} = 0.000417$ [example], $\sigma_{\mathrm{form}} = 0.010326$ [example] (sample sd, ddof=`1` [default]); day $13$: $z = +2.3807$ [example] $\to$ short the spread; day $15$: $z = +0.4438$ [example] $\to$ exit. The spread is a pure function of the two closes — no estimated hedge ratio enters (that distinction is S050).

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    # --- F1/F2 input gates: invalid input -> UNKNOWN, never interpolate ---
    assert len(events) > 0 else return UNKNOWN(state)                 # F1
    e = events[-1]
    assert valid_event(e) else return UNKNOWN(state)                 # F1/F2: positive prices, sane ts
    assert market_state(events) == CONTINUOUS_TRADING else per §S0.5

    # --- causal day aggregation: one (close_A, close_B) per complete day ---
    days = []
    for each calendar day d with events:
        if leg A and leg B both have a valid close:
            days.append((d, ts=max(ts_A, ts_B), close_A, close_B))
        else:
            mask d                                                   # incomplete day: no contribution
    assert all(d.ts <= e.event_ts for d in days)                     # causality: data <= t only

    # --- formation: first cfg.form_days complete days; sample sd (ddof=1) ---
    W = [d for d in days if d.index <= cfg.form_days]
    if len(W) < cfg.form_days:
        return SignalVector(symbol=pair_id, direction=0, confidence=0.0,
                            capital=0.0, computed_at=e.event_ts, staleness=0,
                            module_state=OK)                         # still forming: flat, not a failure
    mu = mean(spread over W); sd = sample_sd(spread over W, ddof=1)
    assert sd > 0 and finite(mu) and finite(sd) else return UNKNOWN(state)  # F2

    # --- today's features ---
    t = latest complete day of days
    spread_t = close_A(t) / close_B(t) - 1
    z = (spread_t - mu) / sd
    assert source_ts(t) <= e.event_ts                                # t→t causality on features

    # --- eligibility gates (broken-pair veto, locate) ---
    if not state.pair_cointegrated:                                  # R002 action
        return flat_OK(e)                                            # broken-pair veto: no entry, force FLAT
    short_leg = A if z >= 0 else B
    assert state.locate_ok(short_leg) else return flat_OK(e)         # C7: no SHORT without locate

    # --- normative cost-gate predicate (C2 bona-fide-intent) ---
    edge_bps = 20.0 * abs(z)                                        # [example] edge model
    cost_bps = expected_cost_bps(notional, adv_pct, venue, side, urgency)
    cost_ok = cost_bps <= cfg.cost_gate_k * edge_bps                 # <<< executable predicate
    if not cost_ok:
        return flat_OK(e)                                            # gate veto: direction 0, still OK

    # --- position state machine: one position per episode ---
    if state.position == 0 and z >= cfg.entry_z and now >= state.cooldown_until:
        state.position = -1                                          # z>0: short the stretched spread
    elif state.position == 0 and z <= -cfg.entry_z and now >= state.cooldown_until:
        state.position = +1
    elif state.position != 0 and (abs(z) <= cfg.exit_z or not state.pair_cointegrated):
        state.position = 0
        state.cooldown_until = now + cfg.cooldown_s                   # C10 post-exit cooldown

    direction = state.position
    confidence = 0.6 if direction != 0 else 0.0                     # [example] entry conviction
    capital = 0.5 * confidence                                      # [default]
    sig = SignalVector(symbol=pair_id, direction=direction, confidence=confidence,
                       capital=capital, computed_at=e.event_ts,
                       staleness=now() - e.asof_ts, module_state=OK)
    log_decision(sig, inputs_hash, params_hash)                     # C5 / Appendix g
    assert fill_event_ts > sig.computed_at                          # t→t+1: no signal-bar fills
    return sig

flat_OK(e) := SignalVector(symbol=pair_id, direction=0, confidence=0.0,
                           capital=0.0, computed_at=e.event_ts, staleness=0,
                           module_state=OK)
```
