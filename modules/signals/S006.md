### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG  := (z_delta >= z_entry) AND (now >= cooldown_until) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT := (z_delta <= -z_entry) AND (now >= cooldown_until) AND (locate_ok) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
```

## §S3 Math + normative pseudocode

Trades $i=1,\dots,N_t$ in window $t$, each with price $P_i$, size $V_i$, aggressor sign $\varepsilon_i \in \{+1,-1\}$ ($+1$ = buyer-initiated, via S007 signing):
$$\mathrm{TI}_t = \sum_i \varepsilon_i V_i, \qquad \Delta_t = \frac{V^{\text{buy}}_t - V^{\text{sell}}_t}{V^{\text{buy}}_t + V^{\text{sell}}_t} = \frac{\mathrm{TI}_t}{\sum_i V_i} \in [-1,1], \qquad z_t = \frac{\Delta_t - \mu_{t-L:t-1}}{\sigma_{t-L:t-1}}.$$
**Predictive regression form** (Chordia–Subrahmanyam style [documented]): $r_{t+1} = a + b\cdot\mathrm{OIB}_t + \gamma' X_t + u_{t+1}$. **Tick rule** (Lee–Ready style, no quotes needed): $\varepsilon_i = +1$ if $P_i > P_{i-1}$, $-1$ if $P_i < P_{i-1}$, else carry forward $\varepsilon_{i-1}$ [documented]. With contemporaneous quotes prefer the quote rule; exchange aggressor flags beat both [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    trades = [e for e in events if e.event_type == TRADE]
    assert trades non-empty else return FLAT(OK)                   # no trades: flat, not UNKNOWN
    signed = [sign_trade(t, state.prev_price) for t in trades]    # S007: quote rule, else tick rule
    state.trade_window.extend(signed)
    win = state.trade_window[-cfg.window_trades:]
    TI = sum(s.v for s in win); tot = sum(abs(s.v) for s in win)
    assert tot > 0 else return UNKNOWN                             # F2
    delta = TI / tot
    z = zscore(delta over trailing window)
    assert isfinite(z) else return UNKNOWN                         # F2
    edge_bps = abs(z) * 1.5                                        # [example]
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    direction = +1 if (z >= cfg.z_entry and cost_ok and gates_pass()) else
                -1 if (z <= -cfg.z_entry and cost_ok and gates_pass() and locate_ok) else 0
    confidence = min(1, abs(z) / (2*cfg.z_entry)) if direction != 0 else 0
    capital = 0.5 * confidence                                     # [default]
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=trades[-1].event_ts, staleness=now()-trades[-1].asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event  # t→t+1 causality: fills strictly after the last trade
    return sig
```

Causality: delta at trade `t` uses only trades ≤ `t`; tradable no earlier than `t+1`. Signing uses quotes at or before the trade — never the quote that already reacted. Mandatory unit test: no-signal-bar fills.
