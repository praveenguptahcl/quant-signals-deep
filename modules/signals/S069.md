# S069 — Implied-vs-realized spread / variance risk premium

**Implied variance** is the market's forecast of future volatility, read off option prices. **Realized variance** is what actually happened, measured from price changes. The **variance risk premium** is the gap: implied minus realized. On average, for equity indices, implied exceeds realized --- option sellers collect a premium for bearing volatility and crash risk, the same way insurers collect premiums for bearing fire risk. Picture month-start: 30-day S&P 500 implied vol at `16.1`% [example], your HAR (S066) forecast of realized vol at `13.9`% [example] --- the market is paying you to be short volatility. Why the premium exists: crash aversion, structural dealer short-gamma rebalancing demand, and volatility-of-volatility risk. It is compensation for a risk that periodically realizes against you (`2008`, `2020` [documented]) --- not an arbitrage. Provenance **[D]**.

### Robustness

Compare implied against *expected future realized* over a matched horizon --- never against today's realized vol. Two practical rules (documented in the chapter): interpolate **total variance** w(K,T) = σᵢᵥ²(K,T)·T across maturities, never raw vol; interpolate across strikes in log-moneyness k = ln(K/F). Exclude stale zero-bid quotes from the model-free sum per the Cboe selection rule. Z-score VRP against its trailing history --- raw VRP is meaningless across regimes. Flag: one source line rendered the vol-points analog as IVol − √(RV) ambiguously --- the render was garbled; the variance-points form above is the verified one; do NOT code the vol-points variant as confirmed.

## §S3 Math + normative pseudocode

Canonical variance-units form [documented]; desk-shorthand vol-units form [example]:

$$\mathrm{VRP}_t = (\mathrm{IV}_t^{\mathrm{ann}})^2 - \mathbb{E}_t\big[(\mathrm{RV}_{t,T}^{\mathrm{ann}})^2\big] \quad\text{(variance points)} \quad\text{[documented]}$$

$$\mathrm{VRP}_t^{\sigma} = \mathrm{IV}_t^{\mathrm{ann}} - \mathbb{E}_t\big[\mathrm{RV}_{t,T}^{\mathrm{ann}}\big] \quad\text{(vol points)} \quad\text{[example]}$$

Ex-post: $\mathrm{VRP}_t^{\text{ex-post}} = (\mathrm{IV}_t^{\mathrm{ann}})^2 - (\mathrm{RV}_{t,T}^{\mathrm{ann}})^2$ with RV from 5-min log returns: $\mathrm{RV} = 252 \times \sum_i r_i^2$, annualized [documented]. Model-free implied variance per the Federal Reserve Board definition [documented]:

$$\mathrm{IV}_t^{\mathrm{ann}} = \frac{2e^{rT}}{T}\left[\sum_{K_i<K_0}\frac{\Delta K_i}{K_i^2}P(K_i) + \sum_{K_i>K_0}\frac{\Delta K_i}{K_i^2}C(K_i)\right] - \frac{1}{T}\left(\frac{F_t}{K_0}-1\right)^2 \quad\text{[documented]}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary).
Every symbol below is bound: inputs (`state`, `events`, `cfg`), the newest
event `b`, the trailing window `hist`, and all derived quantities.

```
function signal(state, events, cfg) -> SignalVector:
    # ---- 0. guard: empty input ----
    if len(events) == 0:
        return SignalVector(symbol="", direction=0, confidence=0.0, capital=0.0,
                            computed_at=0, staleness=0, module_state="UNKNOWN")   # F1

    b = events[-1]                       # newest last; b: Event{event_ts, asof_ts, symbol,
                                         #   iv_ann, rv_ann, market_state} (Appendix a v1.0.0)
    now_ns = wall_clock_ns()             # authoritative causality clock = event_ts (§S0.4)

    # ---- 1. guards: market state (inline, §S0.5 table) ----
    if b.market_state == "HALTED":
        state.module_state = "UNKNOWN"
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts, 0, "UNKNOWN")
    if b.market_state == "AUCTION":
        state.module_state = "DEGRADED"
        return state.last_signal_vector        # hold last; no new signals
    if b.market_state == "CLOSED":
        state.module_state = "OFF"
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts, 0, "OFF")

    # ---- 2. guards: staleness, cooldown, bounds ----
    if now_ns - b.asof_ts > cfg.staleness_ttl_ns:        # 3 s [default]; F3
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts,
                            b.asof_ts - b.event_ts, "UNKNOWN")   # never interpolate
    if now_ns - state.last_compliance_block_ts < cfg.cooldown_ns:  # C10: 60 s [default]
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts,
                            b.asof_ts - b.event_ts, "UNKNOWN")
    if not (isfinite(b.iv_ann) and isfinite(b.rv_ann)) \
       or b.iv_ann <= 0 or b.rv_ann <= 0:                 # F2 bounds
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts,
                            b.asof_ts - b.event_ts, "UNKNOWN")

    # ---- 3. core computation: trailing-window z of vol-points VRP ----
    n = len(events)
    w = cfg.window_months                            # 4 [example] (calibrate)
    vrp_now = b.iv_ann - b.rv_ann                     # vol-points VRP [example]
    hist = [e.iv_ann - e.rv_ann for e in events[max(0, n - w):n]]
    mu = sum(hist) / len(hist)
    sd = sqrt(sum((v - mu) ** 2 for v in hist) / len(hist)) if len(hist) > 1 else 0.0
    z = (vrp_now - mu) / sd if sd > 0 else 0.0
    if len(hist) < 2:
        z = 0.0                                      # single observation -> z = 0 [example]

    # ---- 4. cost gate: executable predicate ----
    edge_bps = z * 100.0                             # modeled per-trade edge [example]
    gate_ok = expected_cost_bps(cfg.reference_notional_usd,   # 1,000,000 [example]
                                cfg.reference_adv_pct,         # 0.001 [example]
                                cfg.venue,                     # "CBOE" [example]
                                cfg.side,                      # "taker" [default]
                                cfg.urgency)                   # "normal" [default]
                <= cfg.cost_gate_k * edge_bps                  # 0.5 [default]
    if z > cfg.z_entry and gate_ok:
        direction = +1                               # rich VRP -> harvest (short-vol intent for T010) [example]
    else:
        direction = 0                                # strict >: z == z_entry does NOT enter

    # ---- 5. locate guard (C7; defensive — S069 never emits -1) ----
    if direction == -1 and not cfg.locate_ok:
        return SignalVector(b.symbol, 0, 0.0, 0.0, b.event_ts,
                            b.asof_ts - b.event_ts, "UNKNOWN")

    confidence = min(1.0, z / 3.0) if direction != 0 else 0.0   # [example] scale
    capital = 0.5 * confidence                                 # [default] 0.5 factor

    # ---- 6. causality: machine assertion on bound timestamps ----
    signal_event = b.event_ts
    fill_event = next_regular_session_open_ns(signal_event, tz="America/New_York")
    assert fill_event > signal_event, "no signal-bar fills"

    # ---- 7. state update + emit ----
    state.vrp_history.append(vrp_now)
    state.seq = state.seq + 1
    state.module_state = "OK"
    out = SignalVector(symbol=b.symbol, direction=direction, confidence=confidence,
                       capital=capital, computed_at=signal_event,
                       staleness=b.asof_ts - b.event_ts, module_state="OK")
    state.last_signal_vector = out
    return out
```

Causality: computed at close *t* from options ≤ *t* and RV forecasts ≤ *t*;
tradable no earlier than *t+1*. Mandatory unit test: no-signal-bar fills
(`test_no_signal_bar_fills` + `test_causality_pins`).

**Honest bottom line.** The strongest documented evidence is at weekly → monthly → multi-month horizons --- **not intraday**. **As a standalone swing factor the VRP is one of the most robust findings in the vol literature; as an intraday trigger it is a different, much weaker animal.**
