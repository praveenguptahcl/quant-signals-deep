# S075 — Dispersion trading

**Dispersion** is the gap between how volatile an index *should* be, given its constituents' volatilities and their correlations, and how volatile the options market prices it. Index variance decomposes as: `σ_index² = Σ wᵢ²σᵢ² + Σ_{i≠j} wᵢwⱼσᵢσⱼρ` [documented]. Rearranged, the options market implies a correlation **ρ_impl**; realized returns give **ρ_real**. When implied correlation runs rich vs realized --- the documented **correlation risk premium** (Driessen, Maenhout & Vilkov) --- the trade is **long dispersion**: buy single-stock straddles, sell the index straddle, collecting the correlation premium as index options overprice co-movement. S075 computes ρ_impl from constituent IVs, compares it to realized correlation, and goes long dispersion when the spread exceeds `κ = 0.10` [example]. You are not betting on direction --- you are betting that stocks move *independently* more than the index options imply. Provenance **[D]**.

### Parameter calibration procedure

Defaults are starting points, not fitted values. Calibrate per index universe,
never pooled across indices [default]:

1. **Objective (normative):** maximize cost-aware forward utility on
   purged/embargoed walk-forward folds — for each candidate parameter set, emit
   long-dispersion triggers on spread > kappa, and score
   `Σ_trigger (spread_capture − expected_cost_bps(...)/1000)` [example modeled]
   where `spread_capture` is the realized contraction of implied-minus-realized
   correlation over the holding window. Objective is after-cost by construction.
2. **Grid + OOS selection rule (each parameter gets one):**
   - `kappa ∈ {0.05, 0.075, 0.10, 0.15, 0.20}` [example] — select by max
     cost-aware OOS utility subject to a minimum of `30` OOS triggers
     [default]; keep `0.10` [default] unless the OOS trigger count collapses
     (too high) or crisis-tail losses dominate (too low). Never set kappa below
     `0.05` [default] — the noise zone of realized-correlation estimation.
   - `cost_gate_k ∈ {0.25, 0.5, 1.0, 2.0}` [example] — per the proposal's open
     item (`0.5` vs T002-style `2`): select by maximizing cost-aware OOS
     utility subject to a minimum of `30` OOS triggers [default]; keep `0.5`
     [default] until `[measured]` cost stacks justify otherwise. Never above
     `2.0` [default] without documented impact accounting.
   - `vrp_z_entry ∈ {1.0, 1.5, 2.0}` [example] — only when `use_vrp_gate=True`;
     select by crisis-period spread-capture retention vs entry-rate loss on OOS
     folds [default].
   - `rho_real_window ∈ {20, 30, 63}` sessions [example] — select by matching
     the implied tenor (COR1M→`30` d [example], COR3M→`63` d [example]);
     mismatch biases the spread by the term-structure slope [internal-est].
     Keep the tenor matched at all times — this is an invariant, not a
     preference [default].
   - `conf_scale` stays `[example]` (fixed at `0.30`) — fitted, not gridded:
     fit a logistic map from spread to realized spread-capture hit rate on the
     validation fold [default]; `0.30` is a placeholder until fitted.
3. **Walk-forward:** train `2` y [default], embargo `21` sessions [default],
   test `1` y [default]; roll quarterly. Never calibrate kappa on `< 2` years
   of surface history [default]; re-calibrate quarterly [default].
4. **`edge_bps` β mapping:** the `spread * 1000.0` [example] mapping is a
   modeled guess, not measured: regress realized implied-correlation

## §S3 Math + normative pseudocode

$$\rho_{\mathrm{impl}} = \frac{\sigma_{\mathrm{idx}}^2 - \sum_i (w_i\sigma_i)^2}{\sum_{i<j} 2\,w_i w_j\,\sigma_i\sigma_j}, \qquad \mathrm{spread} = \rho_{\mathrm{impl}} - \rho_{\mathrm{real}} \quad\text{[documented]}$$

derived from the index-variance decomposition [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN                          # F1
    b = bars[-1]
    if b.asof_ts - b.event_ts > cfg.staleness_ttl_ns: return UNKNOWN   # F1 staleness: missing close print
    if any(v <= 0 or not finite(v)) for v in (b.iv_a, b.iv_b, b.iv_c, b.rho_real): return UNKNOWN   # F2 [default]
    if cfg.use_vrp_gate and (missing(b.vrp_z) or not finite(b.vrp_z)): return UNKNOWN  # F1: gate input absent
    ivs = [b.iv_a, b.iv_b, b.iv_c]; w = 1/3                            # toy; live = index weights [example]
    num = 27.0**2 - sum((w*s)**2 for s in ivs)
    den = sum(2*w*w*ivs[i]*ivs[j] for i in range(3) for j in range(i+1, 3))
    rho = num / den if den > 0 else 0.0                                 # never divide by zero [default]
    spr = rho - b.rho_real
    vrp_ok = (not cfg.use_vrp_gate) or (b.vrp_z >= cfg.vrp_z_entry)     # S069 VRP gate
    direction = 1 if (spr > cfg.kappa and vrp_ok) else 0               # long dispersion [example]
    confidence = min(1.0, spr / cfg.conf_scale) if direction else 0.0  # [example] scale
    edge_bps = spr * 1000.0                                            # modeled per-trade edge [example]; fit per §S2
    assert fill_event > signal_event                                    # causality: close print tradable no earlier than t+1
    cost = expected_cost_bps(1.0, 0.001, "CBOE", "taker", "normal")     # reference stack, §S2 [example inputs]
    if not (cost <= cfg.cost_gate_k * edge_bps):
        direction, confidence = 0, 0.0                                  # cost gate [default] k
    return SignalVector("TEST", direction, confidence, 0.5 * confidence,
                        b.event_ts, b.asof_ts - b.event_ts, "OK")
```

Causality: computed at the daily close from surfaces ≤ *t*; tradable no earlier than *t+1*. Mandatory unit test: no-signal-bar fills.

**Honest bottom line.** The correlation risk premium is one of the better-documented vol findings: implied correlation systematically exceeds realized. **As a traded dispersion strategy it is a professional multi-leg operation --- four option legs plus delta-hedging `N` names --- with the largest cost stack in this batch.** The edge is real on average; the crisis tail (correlations → `1` [example]) is the business risk.
