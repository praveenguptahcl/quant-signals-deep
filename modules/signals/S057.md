# S057 — Index futures cash-and-carry arbitrage

An index future is a contract to buy the whole index later; its fair price is nailed down by arithmetic: buy all `500` [example] stocks today, finance until expiry, subtract the dividends you collect --- the *cost of carry*. The *basis* (futures minus fair value) is the market's price for carrying the basket. When the basis exceeds the all-in cost stack, buy the basket and sell the future (or the reverse) and hold to expiry to lock it. The edge accrues to whoever funds cheapest and trades the basket cheapest, not to whoever spots the deviation first. Provenance **[D]**.

## §S3 Math + normative pseudocode

Cost of carry = financing minus dividends. Fair value is a financing identity; everything else is friction. Continuous fair value with dividend yield q, rate r, time T:

$$F^* = S\cdot e^{(r-q)\cdot T}, \qquad m = F - F^*, \qquad r_{impl} = \tfrac{1}{T}\ln(F/S) + q.$$

Trade rule: if $m > +bound$: buy the cash basket, sell futures, hold to expiry. If $m < -bound$: short the basket, buy futures. $bound$ = round-trip all-in cost (financing + basket spreads/commissions + borrow + ops + margin funding).

**Normative pseudocode** (pseudocode is normative; prose is commentary). Reference constants for the gate call: `NOTIONAL_REF = 1e6` ($1M [example]), `ADV_PCT_REF = 0.001` (`0.1`% of ADV [example]), `VENUE_REF = "CME"`, `URGENCY_REF = "normal"`.

```
function signal(state, bars, cfg) -> SignalVector:
    if bars is empty: return SignalVector(dir=0, conf=0, capital=0, computed_at=0, state=UNKNOWN)   # F1
    b = bars[-1]
    if not (finite(b.spot) and finite(b.futures) and b.spot > 0):                                  # F2
        return SignalVector(dir=0, conf=0, capital=0, computed_at=b.event_ts, state=UNKNOWN)
    if b.market_state in {HALTED}:                                                                # §S0.5
        return SignalVector(dir=0, conf=0, capital=0, computed_at=b.event_ts, state=UNKNOWN)
    Fstar      = b.spot * exp((cfg.r - cfg.q) * cfg.T)              # fair value (cost-of-carry identity)
    m          = b.futures - Fstar                                   # mispricing in index points (signed)
    signed_bps = m / b.spot * 10000.0                                # signed deviation in bps of spot
    dev_bps    = abs(signed_bps)                                     # unsigned magnitude
    edge_bps   = dev_bps                                             # [example] modeled per-trade edge
    if signed_bps >  cfg.cost_bound_bps: dir = -1                    # futures rich: buy basket, sell futures
    elif signed_bps < -cfg.cost_bound_bps: dir = +1                  # futures cheap: short basket, buy futures
    else: dir = 0
    # executable cost-gate predicate (§S2 COST block): a Boolean veto, never a raise
    gate_cost = expected_cost_bps(NOTIONAL_REF, ADV_PCT_REF, VENUE_REF, cfg.side, URGENCY_REF)
    gate_ok   = gate_cost <= cfg.cost_gate_k * edge_bps
    if dir != 0 and not gate_ok: dir = 0
    conf    = min(1.0, edge_bps / cfg.cost_bound_bps - 1.0) if dir != 0 else 0.0
    capital = 0.5 * conf                                             # [default] 0.5 factor (§S2 sizing)
    out = SignalVector(symbol, dir, conf, capital,
                       computed_at = b.event_ts, staleness = b.asof_ts - b.event_ts, state = OK)
    # CAUSALITY INVARIANT (test-enforced, test 3): for every fill f consuming `out`,
    #     fill.event_ts > out.computed_at. signal@t -> earliest fill @open(t+1). (§S2 timing box)
    return out
```

Note: the §S2 entry rule is the signed formulation (`m = F - F*`); the test stub mirrors it exactly. Causality: Fair value and mispricing are computed at bar $t$'s close on data $\le t$; the earliest fill is bar $t+1$'s open. Convergence is guaranteed only if both legs are actually held to settlement. Mandatory unit test: no-signal-bar fills.

**Honest bottom line.** The documented evidence shows the basis mean-reverts within transaction-cost bands (MacKinlay & Ramaswamy 1988; Roll) and that `1`-minute [documented] mispricings exist (Zhuo et al. 2012), all **before-cost**. Net capture accrues to the cheapest funder with the cheapest basket execution --- the apparent premium compensates funding/balance-sheet usage, inventory, crash risk, dividend uncertainty, and margin liquidity, not a free lunch. Report net-of-all-costs carry capture with dividend-forecast error bands --- never gross mispricing frequency.
