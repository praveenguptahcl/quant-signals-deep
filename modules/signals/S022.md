## §S3 Math + normative pseudocode

Initial balance from the first `ib_minutes`: $IB = [L_{IB}, H_{IB}]$, $R_{IB} = H_{IB} - L_{IB}$. **Expansion:** developing range $R_t > 1.5 \times R_{IB}$ [default] with a close beyond the IB extreme -> trend-day signal. Fixture (*example*): `IB = [100.00, 100.40]` (`R = 0.40`); bar closes `100.70` with developing range `0.70 > 0.60` -> LONG expansion. Rotational days (no expansion) are the veto: do not force trades [documented].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    bars = intraday_bars(events)
    (ibh, ibl) = initial_balance(bars, cfg.ib_minutes)
    assert ibh > ibl else return UNKNOWN                          # F2
    rib = ibh - ibl
    dev_range = developing_range(bars)
    expand = dev_range > cfg.exp_mult * rib
    side = 1 if (expand and bars[-1].c > ibh) else (-1 if (expand and bars[-1].c < ibl) else 0)
    edge_bps = 2.0                                                # [example] before-cost illustration
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= 0.5 * edge_bps
    if not cost_ok: return FLAT(DEGRADED)
    sig = SignalVector(symbol, direction=side, confidence=0.6 if expand else 0.0, capital=0.0,
                       computed_at=bars[-1].event_ts, staleness=now()-bars[-1].asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event  # t->t+1 causality: entry at next bar's open
    return sig
```

Causality: the expansion bar must close before the signal fires; entry is at the next bar's open. Mandatory unit test: no-signal-bar fills.
