# S055 — Johansen VECM cointegration

Engle–Granger tests one pair for one cointegrating relation. Johansen counts how many independent long-run relations bind an N-leg basket — the rank of the cointegration space — and estimates the error-correction speeds (α) and hedge weights (β) jointly in a vector error-correction model (VECM). The trading signal is the error-correction spread: when the basket deviates from its estimated long-run equilibrium, the VECM says the legs must adjust back, and the speed of that adjustment is the edge. The test is a measurement instrument, not an edge: its trading value is entirely downstream of basket quality, costs, and break handling. Provenance **[D]**.

### Robustness

Small-sample rank over-rejection is the documented failure: Cheung & Lai (1993)
[documented] identified small-sample biases in the tabulated Johansen critical
values (the test over-rejects the rank-`0` null on short samples) and recommend
a small-sample adjustment — apply the `(T − N)/T` [documented] degrees-of-freedom
scaling (Reinsel & Ahn 1992, per Onatski & Wang's survey [documented]) to the
trace statistic before comparing to critical values. Require ≥`120` daily obs
[example] (≥ `min_obs` [default]) and confirm rank on a second window before
allocating. Deterministic spec must match the data (`det_order = 0` [default]
for levels with intercepts; `1` if levels trend; recalibrate per §S2 recipe).
Keep N ≤ `5` [example]; pre-cluster economically for wide universes.

## §S3 Math + normative pseudocode

VECM error-correction form (Johansen 1988, 1991):

$$\Delta y_t = \Pi y_{t-1} + \sum_{i=1}^{p-1} \Gamma_i \Delta y_{t-i} + \varepsilon_t, \qquad \Pi = \alpha \beta',$$
where $\mathrm{rank}(\Pi) = r$ is the number of cointegrating relations, $\beta$ holds the hedge weights and $\alpha$ the adjustment speeds. The tradable spread is $e_t = \beta' y_t$; enter when $|e_t - \mu| > \kappa \cdot \sigma$ ($\kappa = 2.0$ [example]).

**Normative pseudocode** (pseudocode is normative; prose is commentary).
`bars` below are canonical Events per §S0.3 (`X1..X3` leg prices, `event_ts`/`asof_ts` int64 ns UTC).

```
function estimate(formation_panel, cfg) -> (beta, rank, mu, sd):
    # formation_panel: (T x N) matrix of levels, strictly BEFORE trading (C12)
    T, N = shape(formation_panel)
    assert T >= cfg.min_obs else return (None, 0, None, None)      # min_obs [default]
    assert formation_end < trading_start                            # C12 hard split
    # Johansen rank test — statsmodels.tsa.vector_ar.vecm.coint_johansen
    # semantics: det_order -1|0|1 = none|constant|trend [documented];
    # k_ar_diff = lagged differences [documented]; returns lr1 (trace), cvt
    # = 90/95/99% critical values [documented].
    res = coint_johansen(formation_panel, cfg.det_order, cfg.k_ar_diff)
    col = {0.01: 2, 0.05: 1, 0.10: 0}[cfg.johansen_significance]
    rank = 0
    for r in 0..N-1:
        trace_adj = res.lr1[r] * (T - N) / T                       # small-sample scaling [documented]
        if trace_adj > res.cvt[r, col]: rank = r + 1 else: break
    if rank == 0: return (None, 0, None, None)                     # no relation — never trade
    beta = normalize(res.evec[:, res.ind[0]])                     # r=1: leading eigenvector
    e = [beta' * y for y in formation_panel]
    mu = mean(e);  sd = pstdev(e)                                 # population stdev [default]
    assert isfinite(mu) and sd > 0 else return (None, 0, None, None)
    return (beta, rank, mu, sd)

function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN                        # F1
    b = bars[-1]
    assert all finite(b.X1, b.X2, b.X3) else return UNKNOWN          # F1/F2
    assert (b.asof_ts - b.event_ts) <= cfg.staleness_ttl_ns else return UNKNOWN   # staleness TTL
    if state.beta is None or state.rank == 0: return UNKNOWN        # not estimated yet
    if now_ns() < state.cooldown_until:                             # C10
        return flat SignalVector(..., module_state=OK)
    e = state.beta' * [b.X1, b.X2, b.X3]
    ec = e - state.mu                                               # mu/sd from formation window [default]
    sd = state.sd
    assert isfinite(ec) and sd > 0 else return UNKNOWN               # F2
    edge_bps = abs(ec) * 30.0                                       # [example]
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    direction = -1 if (ec > cfg.kappa*sd and cost_ok) else (1 if (ec < -cfg.kappa*sd and cost_ok) else 0)
    confidence = min(1, abs(ec)/(cfg.kappa*sd) - 1.0) if direction != 0 else 0
    capital = 0.5 * confidence                                        # [default]
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=b.event_ts, staleness=now_ns()-b.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                      # C5 / Appendix g
    assert fill_event > signal_event                                # t→t+1 causality: no fill on the signal bar
    return sig
```

Causality: The cointegrating vector is estimated on the formation window (data strictly before trading); $e_t$ uses data $\le t$; earliest fill bar $t+1$'s open. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Small-sample rank over-rejection → short windows find cointegration everywhere → detect: second-window confirmation → action: ≥120 daily obs minimum → recovery: re-estimate | `n_obs >= 120 [example]` |
| 2 | Asynchronous prices → legs closing minutes apart manufacture fake mean-reversion → detect: timestamp audit → action: synchronized bars only; common grid intraday → recovery: re-sample | `bar_sync_ok` |
| 3 | Wrong deterministic spec → det_order mismatched to data distorts critical values → detect: drift/trend inspection → action: match the spec → recovery: re-test | `spec_matches_data` |
| 4 | Structural breaks → relation dies, spread trends → detect: half-life explosion / rank → 0 → action: rolling re-estimation; unwind rule → recovery: stand down | `rank > 0 and half_life_stable` |
| 5 | β̂ estimation error → sizing as if estimates were truth over-leverages → detect: CI width audit → action: shrink weights; cap per-basket gross → recovery: re-size | `ci_width_checked` |
| 6 | Cost blindness → 3–5 leg baskets pay 3–5 spreads + borrow per short leg → detect: cost gate failing → action: full multi-leg cost model; HTB legs veto → recovery: resume when costs normalize | `expected_cost_bps(...) <= k * edge_bps` |
| 7 | Lookahead in formation → trading window inside the Johansen fit → detect: window audit → action: hard formation/trading split; purged re-estimation → recovery: re-split | `formation_end < trading_start` |
| 8 | Large-N fragility → rank tests on 20+ legs numerically fragile → detect: N audit → action: keep N ≤ 5; pre-cluster economically → recovery: re-cluster | `n_legs <= 5 [example]` |
