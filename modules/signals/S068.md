# S068 — VIX term structure

The VIX is a spot number: the market's 30-day volatility forecast, right now. But options exist for many expiries, so there is also a *term structure*: VIX futures (VX, on CFE) expiring in `1` month, `2` months, `3` months [example] --- and its *slope* is the signal. Normal times: the curve slopes upward (**contango**, future above spot) --- traders are paid to bear volatility risk over longer horizons. Stress: the curve inverts (**backwardation**, front above back) --- everyone wants insurance *now*. Two mechanisms make the slope tradable: **carry/roll-down** (short front-month in contango harvests the convergence toward spot) and **stress inversion** (backwardation is one of the cleanest real-time stress gauges; the return to contango marks stress exhaustion). The slope is the pricing of *when* the market wants vol insurance. Provenance **[D]**.

### Robustness

The slope is two futures minus each other --- the failure surface is all calendar and vintage: CFE holiday calendar vs equity calendar; the Wednesday-morning SOQ settlement print (final settlement = the Wednesday `30` days before the third Friday of the following month [documented]) moves the slope by tenths that matter at scale --- pin every roll to the curve calendar (C11); VIX9D/VIX methodology revisions; delayed (15-min [unverified]) data making "intraday inversion" fire on stale prints (label Tier-0 builds daily-only). Normalize (normative, §S3): z-score the slope against its trailing `60`-day [example] history (population std, ddof=`0` [default]); with fewer than `60` observations the module emits `DEGRADED` and falls back to the raw-slope rule --- never a silent fallback. Never compare futures to spot: front-month futures can trade below spot VIX (negative basis) without backwardation.

## §S3 Math + normative pseudocode

VIX spot (Cboe model-free implied variance, Demeterfi et al. 1999; Britten-Jones & Neuberger 2000) [documented]:

$$\sigma^2(T) = \frac{2e^{rT}}{T}\left[\sum_{K_i < K_0}\frac{\Delta K_i}{K_i^2}P(K_i) + \sum_{K_i > K_0}\frac{\Delta K_i}{K_i^2}C(K_i)\right] - \frac{1}{T}\left(\frac{F}{K_0} - 1\right)^2 \quad\text{[documented]}$$

Term-structure features (the S068 features) [example]:

$$S_{1\times2} = VX_2 - VX_1 \quad\text{(points)}, \qquad \text{rel} = VX_2/VX_1 - 1 \quad\text{(percent)} \quad\text{[example]}$$

Inversion: `slope < inversion_tau` with `inversion_tau = −1.0` [example];
production confirm: `z_slope < z_floor` with `z_floor = −1.0` [example].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN
    b = events[-1]                                        # canonical Event (Appendix a v1.0.0)
    mkt = state.get("market_state", "CONTINUOUS_TRADING")
    if mkt == HALTED: return UNKNOWN
    if mkt == CLOSED:  return OFF
    if any(v <= 0 or not finite(v)) for v in (b.vix, b.vx1, b.vx2): return UNKNOWN   # F2 [default]
    slope = b.vx2 - b.vx1                                 # 1x2 slope [example]
    hist = state.slope_history                            # retained trailing slopes (max 252 kept) [default]
    warm = len(hist) < cfg.z_lookback_days
    if not warm:
        w = hist[-cfg.z_lookback_days:]
        z = (slope - mean(w)) / pstdev(w, ddof=0)         # [example] normalization
    hist.append(slope)
    direction = 1 if slope < cfg.inversion_tau else 0     # inversion → long vol carry unwind [example]
    if direction and not warm and z >= cfg.z_floor:
        direction = 0                                     # z-confirm veto [example]
    confidence = min(1.0, abs(slope - cfg.inversion_tau) / cfg.conf_scale) if direction else 0.0   # [example] scale
    edge_bps = abs(slope) * cfg.edge_bps_per_point       # modeled per-trade edge [example]
    signal_event = b.event_ts
    fill_event = open_of_bar(b.bar_id + 1)                # earliest tradable event: next bar's open
    assert fill_event > signal_event                      # causality: curve at close t tradable no earlier than open t+1
    if not (expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XCFE", side="taker", urgency="normal") <= cfg.cost_gate_k * edge_bps):
        direction, confidence = 0, 0.0                    # cost gate: expected_cost_bps(...) <= k * edge_bps [default] k
    mstate = "DEGRADED" if (warm or mkt == AUCTION) else "OK"
    if mkt == AUCTION: direction, confidence = 0, 0.0     # hold: no new signals in auction
    return SignalVector("S068", direction, confidence, cfg.capital_factor * confidence,
                        b.event_ts, asof_now - b.event_ts, mstate)
```

**Calibration note (honest, not hidden).** At the example calibration (`edge_bps_per_point = 50.0` [example], cost `2.70` bps [example], `k = 0.5` [default]) the cost gate passes for *every* inversion trigger (`|slope| ≥ 1.0` [example, from the example tau] → `edge_bps ≥ 50` [example] `≥ 2 × cost`), so the gate binds only if `edge_bps_per_point` calibrates below `~5.4` [example] or urgency is aggressive — at this calibration the z-confirm veto is the binding filter. The gate is kept executable because it is the doctrine's entry predicate, not because it bites here.

Causality: the curve at close *t* uses only quotes ≤ *t*; a position is entered no earlier than *t+1* (next open). Mandatory unit test: no-signal-bar fills.
