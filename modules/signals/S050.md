## §S2 Specification

### Universe

US common-stock pairs passing an Engle–Granger two-step cointegration test on
the formation window [documented]; both legs price > `$5` [example]; short
leg locatable.

**Formation procedure (normative).** `1.` Fit `A = α + β·B` by OLS on
`formation_window_days` (`12` [example] in the fixture; production calibrate
to `60`–`252` [example]) of adjusted daily closes — `60`+ [example] bars are
recommended, since a `12`-bar [example] ADF test has near-zero power; the
fixture stipulates a passed formation as an arithmetic illustration, not a
valid test sample. `2.` Run an ADF test on the residuals (constant, no trend
[default]; lag length chosen by BIC up to `coint_lag_max` = `10` [default]
lags); pass requires the test statistic below the MacKinnon `5`% [documented]
critical value `−3.36` [documented] for a bivariate regression with constant
[documented]. `3.` Economic-link check: the pair must share an economic
rationale (same sector, ADR/ordinary, ETF-basket overlap) — a statistically
passing pair with no economic link is rejected as likely spurious
[documented-as-assessment]. `4.` Pin the stipulated ratio `beta_stip`
(formation `β̂`, recorded in the ratio-provenance log, C11); subsequent entries
must use this pinned ratio, never a re-estimate.

**Re-formation:** re-run the full two-step every `formation_fresh_days`
(`63` [default]) trading days or on a corporate action on either leg; a failed
re-test sets `break_flag` → force FLAT and require a documented re-formation
before new entries. **Break monitor:** the rolling re-test on the trailing
window is the runtime cointegration health check; its flags feed the §S2 entry
gates and the R002 regime record.

### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG  := (z <= -entry_z) AND coint_test_passed AND (beta_used == beta_stip)
               AND (NOT break_flag) AND formation_fresh AND (now >= cooldown_until)
               AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT := (z >= entry_z) AND coint_test_passed AND (beta_used == beta_stip)
               AND (NOT break_flag) AND formation_fresh AND (locate_ok)
               AND (now >= cooldown_until)
               AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT        := otherwise  # the estimated ratio never enters the rule
```

`edge_bps` = `20 * |z|` bps [example] — twenty bps per unit of residual z-score.

**Flag definitions (normative):**

- `coint_test_passed` := formation EG two-step passed at `adf_significance`
  (`0.05` [calibrate]); the fixture stipulates a passed formation (seed `50`
  [example]).
- `break_flag` := rolling EG re-test on the trailing
  `formation_window_days` window fails, or a corporate action lands on either
  leg since the last formation.
- `formation_fresh` := bars since last successful formation `≤`
  `formation_fresh_days` (`63` [default]).
- `beta_used` := the ratio actually used in the spread; `beta_used ==
  beta_stip` is asserted every emission (C11). The diagnostic OLS estimate
  `(beta_hat, alpha_hat)` over the trailing `ols_window_days` (`252`
  [default]) bars never enters the spread.
- `drift_flag` := `|beta_hat − beta_stip| > drift_tolerance` (`0.10`
  [default]) → R003 re-formation review; a drifted ratio is evidence, not an
  input.

**Cost-gate calibration note:** at `entry_z = 1.5` [example] the minimum edge
is `1.5 × 20 = 30` bps [example], and the gate allows `0.5 × 30 = 15` bps
[default] — the `3.80`-bps reference stack [example] therefore never vetoes a
triggered entry under defaults. The gate bites only when `cost_gate_k` is
lowered, costs are measured above `15` bps [default], or `edge_bps` is
re-calibrated. Calibrate `edge_bps` per pair from the formation residual
distribution before trusting the gate [documented-as-assessment].

## §S3 Math + normative pseudocode

With the stipulated ratio $\beta = 2.0$ [example] pinned:

$$s_t = A_t - \beta B_t, \qquad z_t = \frac{s_t - \mu_{\mathrm{form}}}{\sigma_{\mathrm{form}}}$$

$$\mathrm{enter\_long}_t = \mathbf{1}\{z_t \le -1.5\}, \qquad \mathrm{exit}_t = \mathbf{1}\{|z_t| \le 0.5\}$$

with $1.5$/$0.5$ [example] thresholds. The diagnostic OLS runs on the trailing
`252`-day window [default] (the fixture's `30`-day tape [example] lies
entirely inside the window). The full-sample OLS $(\hat\beta, \hat\alpha)$ is a **diagnostic**: chapter S4's example gives $\hat\beta = 2.0301$ [documented-as-chapter-value], $\hat\alpha = -3.3233$ [documented-as-chapter-value]; this fixture's tape gives $\hat\beta = 1.720914$ [example], $\hat\alpha = 3.545001$ [example] — in both cases $\hat\beta \ne 2.0$, which is the point: the estimated ratio measures how far the stipulated ratio has drifted, and substituting it silently is a specification violation. Chapter S4 entry: day $15$, $z = -1.5374$ [example] $\to$ long the spread.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    e = events[-1]
    assert valid(e) else return UNKNOWN                            # F1/F2: never interpolate
    # --- formation (pinned once per formation; fixture: stipulated, 12 days)
    (mu_form, sd_form, beta_stip, form_day) = load_formation(state)  # §S2 procedure
    assert beta_stip == state.ratio_provenance.ratio               # C11: no silent substitution
    # --- per-bar features: only data <= t (causality)
    spread_t = A_t - beta_stip * B_t         # STIPULATED ratio; OLS never enters
    z_t = (spread_t - mu_form) / sd_form
    # --- diagnostics (evidence only)
    (beta_hat, alpha_hat) = OLS(A on B, trailing cfg.ols_window_days)  # diagnostic ONLY
    coint_test_passed = state.formation.coint_test_passed
    break_flag = rolling_EG_retest_fails(trailing cfg.formation_window_days) \
                 OR corp_action_since(form_day)
    formation_fresh = (t - form_day) <= cfg.formation_fresh_days
    drift_flag = abs(beta_hat - beta_stip) > cfg.drift_tolerance
    if break_flag: return force_FLAT(state, reason="break")        # R002
    # --- entry / exit (§S2 Boolean rule)
    edge_bps = abs(z_t) * 20.0                                    # [example]
    cost_ok = expected_cost_bps(...) <= cfg.cost_gate_k * edge_bps # normative predicate
    direction = entry_rule(e, z_t, coint_test_passed, break_flag,
                           formation_fresh, cost_ok, cfg)
    # --- conviction sizing (normative): |z|/denom, capped at 1
    confidence = min(1.0, abs(z_t) / cfg.confidence_denom) if direction != 0 else 0.0
    capital = 0.5 * confidence                                     # 0.5 [default]
    sig = SignalVector(symbol=e.symbol, direction, confidence, capital,
                       computed_at=e.event_ts, staleness=now()-e.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event                               # t→t+1: no signal-bar fills
    assert all(data_ts <= e.event_ts for data in inputs)           # no lookahead
    return sig
```

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
