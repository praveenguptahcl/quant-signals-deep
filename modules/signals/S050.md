### Entry rule (Boolean — no prose-only conditions)

```
ENTER_LONG  := (z <= -entry_z) AND (coint_test_passed) AND (ratio == BETA_STIP)
               AND (now >= cooldown_until) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
ENTER_SHORT := (z >= entry_z) AND (coint_test_passed) AND (ratio == BETA_STIP) AND (locate_ok)

FLAT        := otherwise  # the estimated ratio never enters the rule
```

`edge_bps` = `20 * |z|` bps [example] — twenty bps per unit of residual z-score.

## §S3 Math + normative pseudocode

With the stipulated ratio $\beta = 2.0$ [example] pinned:

$$s_t = A_t - \beta B_t, \qquad z_t = \frac{s_t - \mu_{\mathrm{form}}}{\sigma_{\mathrm{form}}}$$

$$\mathrm{enter\_long}_t = \mathbf{1}\{z_t \le -1.5\}, \qquad \mathrm{exit}_t = \mathbf{1}\{|z_t| \le 0.5\}$$

with $1.5$/$0.5$ [example] thresholds. The full-sample OLS $(\hat\beta, \hat\alpha)$ is a **diagnostic**: chapter S4's example gives $\hat\beta = 2.0301$ [documented-as-chapter-value], $\hat\alpha = -3.3233$ [documented-as-chapter-value]; this fixture's tape gives $\hat\beta = 1.720914$ [example], $\hat\alpha = 3.545001$ [example] — in both cases $\hat\beta \ne 2.0$, which is the point: the estimated ratio measures how far the stipulated ratio has drifted, and substituting it silently is a specification violation. Chapter S4 entry: day $15$, $z = -1.5374$ [example] $\to$ long the spread.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    e = events[-1]
    assert valid(e) else return UNKNOWN                            # F1/F2: never interpolate
    spread_t = A_t - BETA_STIP * B_t        # STIPULATED ratio (pinned)
    z_t = (spread_t - mu_form) / sd_form
    (beta_hat, alpha_hat) = OLS(A on B, full tape)   # diagnostic ONLY
    enter long if z <= -1.5; exit if |z| <= 0.5
    edge_bps = abs(z) * 20.0                                       # [example]
    cost_ok = expected_cost_bps(...) <= k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    direction = entry_rule(e, features, cost_ok, cfg)              # §S2 Boolean rule
    confidence = min(1, conviction(features)) if direction != 0 else 0
    capital = 0.5 * confidence                                     # 0.5 [default]
    sig = SignalVector(symbol=e.symbol, direction, confidence, capital,
                       computed_at=e.event_ts, staleness=now()-e.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                    # C5 / Appendix g
    assert fill_event > signal_event                               # t→t+1: no signal-bar fills
    return sig
```

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
