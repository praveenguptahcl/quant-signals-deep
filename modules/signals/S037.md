## §S3 Math + normative pseudocode

With intraday log-returns $r_1,\dots,r_k$ after the open and $r_{\mathrm{open}} = \log(P_o/P_{c,-1})$:

$$V = \frac{\pi}{2}\,\frac{1}{k-1}\sum_{i=1}^{k-1} |r_i r_{i+1}|, \qquad Z = \frac{r_{\mathrm{open}}}{\sqrt{V}}, \qquad T = \frac{Z - A_n}{B_n}$$

with the Lee–Mykland extreme-value normalization ($A_n, B_n$ as in Lee & Mykland 2008 [documented], $n=k$). At $5$\%, the Gumbel threshold is $2.9702$ [documented]. Chapter tape: $r_{\mathrm{open}} = 0.019803$ [example], $V = 1.5351\times10^{-5}$ [example], $Z = 5.0542$ [example], $T = 6.99$ [example] $>$ threshold $\to$ veto. Fixture recomputation under the stated normalization gives $T = 7.23$ [example] — same verdict; see §S12.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert events non-empty else return UNKNOWN                    # F1
    e = events[-1]
    assert valid(e) else return UNKNOWN                            # F1/F2: never interpolate
    assert e.event_ts >= state.last_ts else return UNKNOWN        # monotonic clock (F3)
    state.last_ts = e.event_ts
    if e.market_state != CONTINUOUS_TRADING:                       # §S0.5
        return freeze(e)                                           # halt/auction/closed semantics
    if now() < state.cooldown_until:                               # C10 post-exit cooldown
        log_decision("cooldown_suppress", e, params_hash(cfg))     # C5 / Appendix g
        return SignalVector(symbol=e.symbol, direction=0, confidence=0, capital=0,
                            computed_at=e.event_ts, staleness=now()-e.asof_ts,
                            module_state=DEGRADED)
    sess = bars of e.session with ts <= e.event_ts                 # causality: data <= t only
    if len(sess) < cfg.min_bars:                                   # warmup: 3 [default]
        state.veto_flag = False
        log_decision("warmup", e, params_hash(cfg))
        return SignalVector(symbol=e.symbol, direction=0, confidence=0, capital=0,
                            computed_at=e.event_ts, staleness=now()-e.asof_ts,
                            module_state=OK)
    if not (sess.prior_close > 0 and sess.open > 0):               # F1: bad anchor
        return UNKNOWN                                            # never interpolate
    r_open = log(sess.open / sess.prior_close)                     # overnight return
    px = [sess.open] + sess.closes                                 # open, close_1, ..., close_k
    rets = [log(px[i+1]/px[i]) for i in 0..k-1]                    # k intraday log-returns
    adj = sum(|rets[i] * rets[i+1]| for i in 0..k-2)
    V = (pi/2) * adj / (k-1)                                       # bipower variation
    Z = r_open / sqrt(V)
    n = k
    A_n = sqrt(2*ln(n)) - (ln(pi) + ln(ln(n))) / (2*sqrt(2*ln(n))) # LM EV normalization [documented]
    B_n = 1 / sqrt(2*ln(n))
    T = (Z - A_n) / B_n
    veto = (T > cfg.jump_thresh)                                   # 2.9702 [documented]; veto -> dir 0, never reverse
    state.veto_flag = veto                                         # consumers read this flag (C11)
    # ---- normative cost gate: expected_cost_bps(...) <= k * edge_bps
    edge_bps = 0.0                                                 # [example]: filter has no tradeable edge
    cost = expected_cost_bps(notional=0, adv_pct=0, venue="XNAS",  # callable from §S2 COST block
                             side="taker", urgency="normal")
    cost_ok = (cost <= cfg.cost_gate_k * edge_bps)                 # executable predicate
    assert cost_ok == False                                        # invariant: RISK-FILTER-ONLY, gate vacuous by construction
    assert veto == (T > cfg.jump_thresh)                           # veto definition
    assert all(ts <= e.event_ts for ts in feature_ts)              # causality: no lookahead
    sig = SignalVector(symbol=e.symbol, direction=0, confidence=0, capital=0,
                       computed_at=e.event_ts, staleness=now()-e.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash(events), params_hash(cfg), veto) # C5 / Appendix g
    assert fill_event_ts > sig.computed_at                         # t->t+1: no signal-bar fills
    return sig
```

Notes on the normative semantics: the module **always** emits `direction = 0` — on veto (jump: stand down) and on pass (no jump: defer to the S036 gap-fade rule, which makes its own entry decision). The veto is communicated via `state.veto_flag` and the decision log (C11); a consumer mapping veto to a reversal is a specification violation (§S10 #1). The cost gate is normative but vacuous inside S037: `edge_bps = 0` [example] makes `cost_ok` provably `False`, so any future emission with `direction != 0` would fail CI — this is the executable form of the `RISK-FILTER-ONLY` verdict and of C2 (bona-fide intent).

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
