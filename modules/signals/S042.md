# S042 — SOTM: settle-to-open momentum (monthly vol)

### Entry rule (Boolean — no prose-only conditions)

```
# Bindings (all normative):
closes      := last cfg.window_closes closes with event_ts <= e.event_ts   # 24 [example]
valid_bar   := (len(closes) == cfg.window_closes) AND all(c > 0)            # F1/F2
r_i         := ln(C_i / C_{i-1}) for i = 1..(cfg.window_closes − 1)
fwd_var     := sum(r_i^2);  T := (cfg.window_closes − 1) / 252
SOTM        := (fwd_var / T − cfg.realized_vol^2) / (2 · cfg.realized_vol)
edge_bps    := |SOTM| × 10,000                                              # [example]
cost_ok     := expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XNAS",  # args [example]
                                 side="taker", urgency="normal")
               <= cfg.cost_gate_k × edge_bps
in_cooldown := now() < state.cooldown_until                                 # C10
locate_ok   := consumer-asserted locate flag in state (default False)       # C7

ENTER_LONG  := valid_bar AND (SOTM >= +cfg.sotm_threshold)                  # 0.015 [example]
               AND (NOT in_cooldown) AND cost_ok
ENTER_SHORT := valid_bar AND (SOTM <= −cfg.sotm_threshold)
               AND locate_ok AND (NOT in_cooldown) AND cost_ok
FLAT        := otherwise
```

## §S3 Math + normative pseudocode

With $r_i = \ln(C_i/C_{i-1})$ over the `cfg.window_closes`-close settle window (`cfg.window_closes − 1` returns; the fixture pins `24`/`23`):

$$\mathrm{fwd\_var} = \sum_{i=1}^{W-1} r_i^2, \qquad T = \frac{W-1}{252}, \qquad \mathrm{SOTM} = \frac{\mathrm{fwd\_var}/T - \sigma_r^2}{2\,\sigma_r}$$

where $W$ = `cfg.window_closes` and $\sigma_r$ = `cfg.realized_vol` = $11.2\%$ [example] trailing realized vol. Positive SOTM: the forward window prices more variance than realized (chapter hand-check: $+1.5\%$ [example]). Direction rule (example — not an institutional standard): long variance exposure at $\mathrm{SOTM} \ge +1.5\%$, short at $\le -1.5\%$. Causal timing: computed at the settle from closes $\le$ settle; tradable no earlier than the next session's open.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, events, cfg) -> SignalVector:
    assert len(events) > 0 else return UNKNOWN                          # F1
    e = events[-1]
    assert e.close > 0 else return UNKNOWN                              # F1/F2: never interpolate
    closes = last cfg.window_closes closes with event_ts <= e.event_ts
    assert len(closes) == cfg.window_closes and all(c > 0)              # F1/F2: window must be full
        else return UNKNOWN
    r_i = ln(C_i / C_{i-1}) for i = 1..(cfg.window_closes − 1)
    fwd_var = sum(r_i^2);  T = (cfg.window_closes − 1) / 252
    SOTM = (fwd_var / T − cfg.realized_vol^2) / (2 · cfg.realized_vol)
    edge_bps = abs(SOTM) * 10000.0                                     # [example]
    # vvv normative cost-gate predicate vvv
    cost_ok = expected_cost_bps(notional=1.0, adv_pct=0.001,           # args [example]
                                venue="XNAS", side="taker", urgency="normal")
              <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate ^^^
    in_cooldown = now() < state.cooldown_until                         # C10
    locate_ok = consumer_asserted_locate(state, e.symbol)              # C7; default False
    tol = 1e-12                                                            # [default] numeric guard: calibrated equalities survive float noise
    direction = +1 if (SOTM >= +cfg.sotm_threshold - tol) \
                else (-1 if (SOTM <= -cfg.sotm_threshold + tol) else 0)
    if direction == -1 and not locate_ok: direction = 0                # C7: no locate, no short
    if (not cost_ok) or in_cooldown: direction = 0                     # C2, C10
    confidence = min(1.0, cfg.confidence_slope * abs(SOTM)) if direction != 0 else 0.0
    capital = 0.5 * confidence                                         # 0.5 [default]
    sig = SignalVector(symbol=e.symbol, direction=direction,
                       confidence=confidence, capital=capital,
                       computed_at=e.event_ts,
                       staleness=now() - e.asof_ts,
                       module_state="OK")
    log_decision(sig, inputs_hash=hash(closes), params_hash=hash(cfg)) # C5 / Appendix g
    fill_event_ts = next_regular_open(e.event_ts)                      # earliest tradable event: t+1 open
    assert fill_event_ts > sig.computed_at                             # t→t+1: no signal-bar fills
    return sig
```

Helpers: `now()` = evaluation wall-clock (int64 ns UTC); `next_regular_open(ts)` = the next
regular-session open from the §0.4 session calendar; `consumer_asserted_locate`
reads the consumer's locate flag from state (default `False` — Reg-SHO
threshold securities force direction `0` per C7).

Causality: features at event/bar `t` use only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar-fills.
