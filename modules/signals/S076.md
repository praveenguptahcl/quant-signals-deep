# S076 — Volatility breakout / squeeze positioning

**Volatility is mean-reverting in a particular way**: it compresses, then expands. A **squeeze** is the compression phase --- the Bollinger Bandwidth (band width relative to the moving average) falls to a local low, meaning the market has gone quiet. A **breakout** is the expansion --- today's range explodes to multiples of its recent average, meaning something is happening. S076 measures both: the **range ratio** (today's high−low vs the mean of up to the prior ten ranges) flags breakouts above `k = 1.75` [calibrate], and the **Bollinger Bandwidth** (`4 × SD(closes) / mean` over the trailing ten bars) flags squeezes at local bandwidth lows. The stub's reference direction follows the breakout bar's own direction (long if close ≥ open) --- a momentum convention, not a prediction of the squeeze's resolution. The central honesty point: squeezes tell you *that* a move is coming, not *which way* --- direction here is a bar-following convention, and the fixture's squeeze column is `0` [measured] on every row. Provenance **[D]** (documented Bollinger construction; the breakout-direction convention is a desk-standard reconstruction).

### Entry rule (Boolean — no prose-only conditions)

```
BREAKOUT_UP   := (rr > k) AND (close >= open) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)   # expansion, bar-following long [example convention]
BREAKOUT_DN   := (rr > k) AND (close < open) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)    # expansion, bar-following short [example convention]
FLAT          := otherwise → UNKNOWN on invalid input

`range = high − low`; `hist` = up to prior `N = 10` [example] ranges (excludes current bar);
`rr = range / mean(hist)`, empty hist → `0.0` [example];
`bw = 4 × pop_SD(closes in trailing-10 window) / mean` (Bollinger Bandwidth) [documented];
squeeze = `1` iff `bw <= p10` and bar index `> 0` (fixture convention) [example];
`k = 1.75` [calibrate]; `edge_bps = max(0, rr − k) × edge_scale`, `edge_scale = 10.0` [example];
`confidence = min(1, rr / 4.0)` [example] when breakout.

Gate-binding note: the edge is the *excess* expansion beyond `k`, so the
cost gate `expected_cost_bps(...) <= cost_gate_k × edge_bps` binds on
marginal breakouts and passes clean expansions. With reference constants,
cost `1.80` bps [example] vetoes any breakout with `rr − k < 0.36` [example]
(`0.5 × 10.0 × 0.36 = 1.8`); the fixture's bar-`8` expansion (`rr = 7.33`
[measured]) passes with wide margin. (v1.0.0 used `edge_bps = rr × 8.0`,
under which the gate was vacuous — `1.8 <= 4×rr` always holds when
`rr > 1.75` — a dead veto path; fixed in 1.1.0.)
```

### Parameter calibration procedure

Defaults are starting points, not fitted values. Calibrate per symbol bucket
(price/spread decile), never pooled across buckets [default]:

1. **Objective (normative):** maximize cost-aware forward utility on
   purged/embargoed walk-forward folds — for each candidate (`k`, `N`),
   flag breakouts, keep only cost-gated ones, and score
   `Σ_events (signed_next_range_bps − expected_cost_bps(...))`, where
   `signed_next_range_bps` is the next bar's range in bps signed by the
   bar-following direction [example]. Objective is after-cost by
   construction.
2. **Grid:** `k ∈ {1.25, 1.5, 1.75, 2.0, 2.5, 3.0}` [example];
   `N ∈ {5, 8, 10, 15, 20, 30}` [example];
   `cost_gate_k ∈ {0.25, 0.5, 1.0}` [example] — per the proposal's open
   item (`0.5` vs T002-style `2`): keep `0.5` [default] until [measured]
   cost stacks justify otherwise. `edge_scale` stays [example] fixed at
   `10.0` — sized so the gate vetoes marginal breakouts (`rr − k < 0.36`
   [example]) while passing clean expansions; refit only against
   [measured] per-trade edge.
3. **Walk-forward:** train `12` months [default], embargo `5` trading days
   [default], test `3` months [default]; roll quarterly. Never calibrate
   `k`/`N` on `< 6` months [default]; re-calibrate annually [default]
   (breakout statistics are slow-moving).
4. **Selection metric:** OOS cost-gated breakout follow-through — the
   fraction of cost-gated breakouts whose next-bar signed move ≥
   `expected_cost_bps(...)` [default]; require ≥ `300` OOS breakout events
   [default] pooled across names in the bucket.
5. **Sensitivity freeze rule:** perturb each parameter ±`1`σ [default]
   around the chosen point; freeze any parameter whose OOS event count or
   follow-through moves `< 10`% [default], re-grid the rest. `N` in
   `8`–`15` keeps the baseline stable [internal-est]; `k` is the
   highest-sensitivity knob (event count ≈ exponential in threshold).
6. **Anti-overfit:** `k`/`N` mined on `< 6` months overfit — require OOS
   follow-through ≥ `0.5`× IS follow-through [default] before accepting a
   re-fit.

## §S3 Math + normative pseudocode

$$\mathrm{rr}_t = \frac{\mathrm{high}_t - \mathrm{low}_t}{\mathrm{mean}(\mathrm{range}_{t-N}, \dots, \mathrm{range}_{t-1})}, \qquad \mathrm{BW}_t = \frac{4 \cdot \sigma_{\mathrm{pop}}(\mathrm{close}_{t-N+1}, \dots, \mathrm{close}_t)}{\mu} \quad\text{[example]}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    symbol = state.get("symbol", "TEST")                       # bound from module-owned state [rule]
    unknown = lambda ts: SignalVector(symbol, 0, 0.0, 0.0, ts, 0, "UNKNOWN")
    if not bars: return unknown(0)                             # F1: empty input [rule]
    b = bars[-1]
    signal_event = b.event_ts
    staleness = b.asof_ts - b.event_ts
    # --- guards: staleness / halt / auction / cooldown -------------------------
    if staleness > cfg.staleness_ttl_ns: return unknown(signal_event)   # F4 staleness TTL [default]
    if state.get("market_state") == "HALTED": return unknown(signal_event)  # freeze; discard across reopen [rule]
    if state.get("market_state") == "AUCTION":                  # hold last vector [rule]
        last = state.get("last_vector") or unknown(signal_event)
        return SignalVector(last.symbol, last.direction, last.confidence, last.capital,
                            signal_event, staleness, "DEGRADED")
    if signal_event < state.get("cooldown_until_ns", 0):       # C10 post-exit cooldown [default]
        return SignalVector(symbol, 0, 0.0, 0.0, signal_event, staleness, "OK")
    # --- OHLC integrity (F1/F2, never interpolate) ------------------------------
    ohlc_ok = (b.high >= b.low and b.high >= max(b.open, b.close) and b.low <= min(b.open, b.close)
               and min(b.open, b.high, b.low, b.close) > 0
               and all finite(v) for v in (b.open, b.high, b.low, b.close))
    if not ohlc_ok: return unknown(signal_event)               # [rule]
    # --- features: current bar excluded from its own baseline (causal) ----------
    ranges = [r.high - r.low for r in bars]
    hist = ranges[:-1][-cfg.N:]                                # prior bars only [rule]
    rr = ranges[-1] / (sum(hist) / len(hist)) if hist else 0.0  # empty hist -> 0.0 [example]
    closes = [r.close for r in bars][-cfg.N:]
    mu = mean(closes)
    sd = pop_sd(closes) if len(closes) > 1 else 0.0
    bw = 4 * sd / mu if mu > 0 else 0.0                        # Bollinger Bandwidth [documented]
    # --- direction: breakout in the bar's own direction (convention) ------------
    direction = 0
    if rr > cfg.k and b.close >= b.open: direction = 1         # [example] convention
    elif rr > cfg.k: direction = -1
    if direction == -1 and not state.get("locate_ok", False):  # C7: no SHORT without locate [rule]
        direction = 0
    # --- confidence / modeled edge ------------------------------------------------
    confidence = min(1.0, rr / 4.0) if direction else 0.0      # [example] scale
    edge_bps = max(0.0, rr - cfg.k) * cfg.edge_scale           # excess expansion [example]
    # --- cost gate: executable predicate -------------------------------------------
    cost = expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XNAS", side="taker", urgency="normal")
    if not (cost <= cfg.cost_gate_k * edge_bps):               # [default] k
        direction, confidence = 0, 0.0                         # gate veto [rule]
    # --- causality -------------------------------------------------------------------
    earliest_fill_event = next_bar_open_ts                    # supplied by the consumer harness [rule]
    assert earliest_fill_event > signal_event                  # no signal-bar fills [rule]
    sv = SignalVector(symbol, direction, confidence, 0.5 * confidence,   # 0.5 capital factor [default]
                      signal_event, staleness, "OK")
    state["last_vector"] = sv
    return sv
```

Causality: computed on the bar close from bars ≤ *t*; tradable no earlier than the next bar. Mandatory unit test: no-signal-bar fills.
