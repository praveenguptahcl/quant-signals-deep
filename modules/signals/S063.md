# S063 — Range-based realized-volatility estimators

A close-to-close squared return is a noisy volatility estimate --- one draw from the day's distribution. The day's high and low record the whole path, so Parkinson (`1980`) [documented] and Garman–Klass (`1980`) [documented] squeeze `5`–`8`× [documented] more efficiency out of the same daily bar. This module computes four range-based estimators (Parkinson, Garman–Klass, Rogers–Satchell, Yang–Zhang) on daily OHLC and emits annualized vol state. It is measurement infrastructure, not a trade: it predicts nothing and has no directional edge by design --- it feeds size and gating to strategies that do (T041, T010). Provenance **[D]**.

## §S3 Math + normative pseudocode

OHLC bars carry more information than closes: the high-low range is a far more efficient variance estimator than squared returns.

$$PARK = \frac{1}{4\ln 2}\left(\ln\frac{H}{L}\right)^{2} \quad\text{[documented --- Parkinson 1980]}$$

$$GK = \tfrac{1}{2}\left(\ln\tfrac{H}{L}\right)^{2} - (2\ln 2 - 1)\left(\ln\tfrac{C}{O}\right)^{2} \quad\text{[documented --- Garman–Klass 1980]}$$

$$RS = \left(\ln\tfrac{H}{C}\right)\left(\ln\tfrac{H}{O}\right) + \left(\ln\tfrac{L}{C}\right)\left(\ln\tfrac{L}{O}\right) \quad\text{[documented --- Rogers–Satchell 1991]}$$

$$YZ = \sigma_{o}^{2} + k\sigma_{c}^{2} + (1-k)\sigma_{rs}^{2}, \qquad k = \frac{0.34}{1.34 + (N+1)/(N-1)} \quad\text{[documented --- Yang–Zhang 2000]}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    # --- guards (every prose guard below appears here) ---
    assert bars non-empty else return UNKNOWN                     # F1
    assert cfg.ann_factor > 0 else return UNKNOWN                  # F2: wrong annualization
    b = bars[-1]
    assert all finite and > 0: b.open, b.high, b.low, b.close else return UNKNOWN   # F2
    assert b.high >= max(b.open, b.close) and b.low <= min(b.open, b.close) else return UNKNOWN  # F1/F2: containment
    assert b.asof_ts >= b.event_ts else return UNKNOWN            # F2: timestamp inversion

    # --- single-day estimators on bar t (all [documented] formulas) ---
    hl = log(b.high / b.low)                                      # [documented] Parkinson 1980
    park = hl^2 / (4 * log(2))                                    # [documented] Parkinson 1980
    co = log(b.close / b.open)
    gk = 0.5 * hl^2 - (2*log(2) - 1) * co^2                       # [documented] Garman–Klass 1980
    rs = log(b.high/b.close)*log(b.high/b.open) + log(b.low/b.close)*log(b.low/b.open)  # [documented] Rogers–Satchell 1991

    # --- Yang–Zhang, N-day rolling window ending at bar t ---
    N = cfg.yz_window_n                                           # 21 [default], 5 [example] in fixture
    yz = None
    if len(bars) > N:                                             # need N days + 1 prior close
        win = bars[-N:]
        prev_close = bars[-N-1].close
        overnight = [log(win[i].open / (prev_close if i == 0 else win[i-1].close)) for i in 0..N-1]
        oc        = [log(win[i].close / win[i].open) for i in 0..N-1]
        rs_i      = [log(win[i].high/win[i].close)*log(win[i].high/win[i].open)
                     + log(win[i].low/win[i].close)*log(win[i].low/win[i].open) for i in 0..N-1]
        s2o = mean(overnight^2); s2c = mean(oc^2); s2rs = mean(rs_i)
        k  = 0.34 / (1.34 + (N+1)/(N-1))                          # [documented] Yang–Zhang 2000
        yz = s2o + k*s2c + (1-k)*s2rs
    # insufficient history: yz masked, single-day estimators still emit (tested)

    # --- annualization + signal ---
    ann_vol = sqrt(max(park, 0) * cfg.ann_factor) * 100            # cfg.ann_factor = 252.0 [default]
    confidence = min(1.0, ann_vol / 50.0)                         # [example] vol-regime salience
    edge_bps = ann_vol                                            # [example] sizing-edge proxy

    # --- executable cost gate (normative predicate) ---
    cost = expected_cost_bps(notional=1.0, adv_pct=0.001, venue="XNAS", side="taker", urgency="normal")
    gate_pass = (cost <= cfg.cost_gate_k * edge_bps)              # [default] k = 0.5
    st = "OK" if gate_pass else "DEGRADED"

    # --- causality assertions (normative; tested by no-signal-bar-fills) ---
    assert b.event_ts == bars[-1].event_ts                       # signal is stamped at bar t's close
    # the consumer's earliest fill is bar t+1's open:
    assert fill_event_ts > b.event_ts                            # fill must be strictly after the signal event

    return SignalVector("TEST", 0, confidence, 0.0, b.event_ts, b.asof_ts - b.event_ts, st)
```

Causality: Estimators are computed on bar $t$'s OHLC; the earliest consumer fill is bar $t+1$'s open. No intra-bar high/low peeking is possible after the close. Mandatory unit test: no-signal-bar fills.

## §S9 Efficacy — documented evidence

| Study / source | Market & period | Metric | Before/after cost | Caveat |
|---|---|---|---|---|
| Parkinson (1980) [documented] | theory + simulation | extreme-value estimator ~`5`× as efficient as close-to-close | `BEFORE-COST` (n/a --- efficiency) | efficiency ratios assume diffusion; discrete prices erode them (Beckers 1983 [documented]) |
| Garman & Klass (1980) [documented] | theory + simulation | OHLC estimator `7`–`8`× as efficient as close-to-close | `BEFORE-COST` (n/a) | same diffusion caveat; best with liquid names |
| Rogers & Satchell (1991) [documented] | theory | drift-independent estimator via high/low/close | `BEFORE-COST` (n/a) | handles non-zero drift; still jump-fragile |
| Yang & Zhang (2000) [documented] | theory + simulation | minimum-variance combination, independent of drift and overnight jumps | `BEFORE-COST` (n/a) | open-to-close vs close-to-close choice still matters |
| Alizadeh, Brandt & Diebold (2002) [documented] | simulation + data | range-based proxies approximately Gaussian, robust to microstructure noise | `BEFORE-COST` (n/a) | not a directional edge |

**Honest bottom line.** The documented evidence shows range-based estimators are `5`–`8`× [documented] more efficient than close-to-close, all **before-cost** (n/a --- statistical efficiency, not a return). That is a measurement edge, not a trading edge: it becomes money only through a sized consumer.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Invalid OHLC → poisoned estimate → detect: containment check fails → action: emit `UNKNOWN` (F1/F2), never interpolate → recovery: re-ingest the bar | `high ≥ max(open,close) AND low ≤ min(open,close)` |
| 2 | Wrong annualization → vol off by √factor → detect: factor ≤ 0 or unit mismatch → action: `UNKNOWN` (F2) → recovery: fix config | `ann_factor = `252.0` [default]` |
| 3 | Jump day → estimator misreads jump as diffusive vol → detect: S064 jump flag → action: route to jump-robust estimators → recovery: exclude the bar | `S064 gate` |
| 4 | Intraday seasonality → fake vol on unseasonalized bars → detect: S067 factor missing → action: deseasonalize first → recovery: recompute | `S067 factors required for sub-daily [documented practice]` |
| 5 | Revised OHLC → lookahead vol → detect: asof regression → action: point-in-time bars only → recovery: rebuild from raw | `as-of timestamps (Appendix g)` |
