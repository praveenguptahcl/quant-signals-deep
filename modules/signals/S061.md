# S061 — ADR / dual-listed premium

An ADR represents a fixed number of foreign shares (the *depositary ratio*). *Parity* is the no-arbitrage price: ADR = ratio × home price × FX. A *premium* (ADR rich) or *discount* should be arbitraged by converting via the depositary bank --- but spreads, issuance/cancellation fees, borrow, and FX hedging mean a statistically real premium is often economically untradeable. The z-score formulation here standardizes the premium against its trailing window and trades it toward zero, time-aligned across sessions. Provenance **[D]**.

### Entry rule (Boolean — no prose-only conditions)

```
ENTER_SHORT_ADR := (z > +z_entry AND premium_bps > Pi_min) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)   # ADR rich
```

## §S3 Math + normative pseudocode

FX-adjusted premium Π_t and its z-score against a trailing window of length W:

$$\Pi_t = P_{ADR,t}/(n\cdot P_{local,t}/X_t) - 1, \qquad \ell_t = \log P_{ADR,t}-\log n-\log P_{local,t}+\log X_t.$$

$$z_t = (\Pi_t - mean(\Pi_{t-W+1..t}))/std(\Pi_{t-W+1..t}).$$

Trade toward zero: short ADR / buy local when $z_t>+z_{entry}$; buy ADR / short local when $z_t<-z_{entry}$; exit when $|z_t|<z_{exit}$. Time-align: never mix a live ADR quote with a stale home-market close.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN
    b = bars[-1]
    if not b.home_open: return UNKNOWN                     # session-overlap gate
    if not finite(b.local_px, b.fx, b.adr_px) or b.fx <= 0: return UNKNOWN
    fair = b.local_px / b.fx * b.ratio                     # FX-adjusted parity
    Pi = b.adr_px / fair - 1
    z = (Pi - mean(Pi_window)) / std(Pi_window)            # trailing window W
    edge_bps = abs(Pi) * 10000
    if z > cfg.z_entry and edge_bps > cfg.premium_bound_bps: dir = -1   # ADR rich
    elif z < -cfg.z_entry and edge_bps > cfg.premium_bound_bps: dir = +1 # ADR cheap
    else: dir = 0
    assert expected_cost_bps(...) <= cfg.cost_gate_k * edge_bps  # cost gate
    assert fill_event > signal_event  # causality: no signal-bar fills
    conf = min(1.0, edge_bps / cfg.premium_bound_bps - 1.0) if dir else 0.0
    return SignalVector(dir, conf, 0.5 * conf, event_ts=b.event_ts, state=OK)
```

Causality: $z_t$ is computed at the close of bar/session $t$ on data $\le t$; the earliest tradable fill is bar $t+1$ (or the next overlapping session). Mandatory unit test: no-signal-bar fills.
