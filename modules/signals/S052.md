# S052 — Kalman-filter dynamic hedge ratio

A static OLS hedge ratio is a photograph; the relationship is a film. The Kalman filter --- a state-space estimator --- treats the hedge ratio as a hidden quantity that random-walks a little each bar and updates its estimate on every new price, blending the old estimate with the new observation via the Kalman gain. The trading signal is built on the innovation --- the difference between the observed leg-B price and what the filter predicted --- standardized by its predicted variance. Adaptivity is not free: every wiggle of the hedge ratio re-hedges the book and pays spread plus fees plus slippage, so the production rule is to use Kalman only when estimated hedge-ratio drift exceeds the cost of adapting. ## §S3 Math + normative pseudocode

State-space model (the chapter's §S3; the reference implementation runs the 1-state $\beta_t$ form with a separately estimated intercept — clearer arithmetic; production usually uses the joint $[\mu_t, \beta_t]$ form):

$$y_t = \mu_t + \beta_t x_t + \varepsilon_t, \qquad \varepsilon_t \sim N(0, R),$$
$$\theta_t = \theta_{t-1} + \eta_t, \qquad \eta_t \sim N(0, Q),$$
Predict: $\hat\theta_{t|t-1} = \hat\theta_{t-1|t-1}$, $P_{t|t-1} = P_{t-1|t-1} + Q$.
Update: $e_t = y_t - H_t\hat\theta_{t|t-1}$; $F_t = H_t P_{t|t-1} H_t^\top + R$; $K_t = P_{t|t-1}H_t^\top F_t^{-1}$; $\hat\theta_{t|t} = \hat\theta_{t|t-1} + K_t e_t$; $P_{t|t} = (I - K_tH_t)P_{t|t-1}$.
Signal: $z_t = e_t/\sqrt{F_t}$; long the spread if $e_t < -c\sqrt{F_t}$, short if $e_t > c\sqrt{F_t}$ ($c = 1.0$–$2.5$ [example]).

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN                        # F1
    b = bars[-1]
    assert b.x != 0 and isfinite(b.x) and isfinite(b.y) else return UNKNOWN  # F1/F2
    (beta, P) = (state.beta, state.P)  # prior beta=1.20 [example], P=0.04 [example]
    for r in bars:                       # replay = the fixture's _kf
        Pp = P + q_beta                   # q_beta=3.021e-6 [example]
        e = r.y - beta * r.x              # innovation
        F = r.x^2 * Pp + R                # R=0.10610 [example]
        K = Pp * r.x / F                  # Kalman gain
        beta = beta + K * e;  P = (1 - K * r.x) * Pp
    z = e / sqrt(F)
    assert isfinite(z) else return UNKNOWN                           # F2
    edge_bps = abs(z) * 2.0                                         # [example]
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    direction = -1 if (z >= cfg.z_entry and cost_ok) else
                 1 if (z <= -cfg.z_entry and cost_ok) else 0
    confidence = min(1, abs(z) / (2*cfg.z_entry)) if direction != 0 else 0
    capital = 0.5 * confidence                                       # [default]
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=b.event_ts, staleness=now()-b.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash, params_hash)                      # C5 / Appendix g
    assert fill_event > signal_event                                # t→t+1 causality: no fill on the signal bar
    return sig
```

Causality: $\hat\theta_{t|t}$ uses data $\le t$; $z_t$ is computed at bar $t$'s close; the earliest fill is bar $t+1$'s open. Normative: `assert fill_event > signal_event`. Mandatory unit test: no-signal-bar fills.

| # | Trigger → Detect → Action → Recovery | check: |
