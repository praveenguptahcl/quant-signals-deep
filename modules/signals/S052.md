# S052 — Kalman-filter dynamic hedge ratio

A static OLS hedge ratio is a photograph; the relationship is a film. The Kalman filter --- a state-space estimator --- treats the hedge ratio as a hidden quantity that random-walks a little each bar and updates its estimate on every new price, blending the old estimate with the new observation via the Kalman gain. The trading signal is built on the innovation --- the difference between the observed leg-B price and what the filter predicted --- standardized by its predicted variance. Adaptivity is not free: every wiggle of the hedge ratio re-hedges the book and pays spread plus fees plus slippage, so the production rule is to use Kalman only when estimated hedge-ratio drift exceeds the cost of adapting. ### Robustness

Q sensitivity: `q_beta = alpha_beta * R / Var(x)` with `alpha_beta = 10^{-4}` [example] start; diagnostic `lambda_beta = q_beta * Var(x) / R` --- small = stable/slow, large = responsive/noisy. `Q = 0` reproduces the fixed model --- the honest null every calibration must beat. ### Calibration recipes (per `calibrate` parameter in §S0.2)

Common frame: `60`/`20`/`20` anchored walk-forward folds [default]; embargo = `5` bars [default] between formation and traded folds (purge bars sharing the formation window); selection metric = OOS net-of-cost Sharpe with DSR vs benchmark Sharpe `0` [default]; minimum `30` OOS trades per fold [default]; break ties toward fewer trades / wider margins. Freeze winners on formation data; never re-tune on the traded sample (failure mode #6).

- **R1 — `z_entry` and `cost_gate_k` (joint grid).** Grid `z_entry ∈ {0.5, 0.75, …, 5.0}` [default] × `cost_gate_k ∈ {0.1, 0.2, …, 2.0}` [default]. For each cell: run the §S3 filter over formation bars, apply the cost-gate predicate, compute fold OOS net Sharpe. Select the cell with max DSR; reject the cell if OOS net Sharpe ≤ `0` (no trade) or if OOS trades < `30` (insufficient evidence). Sanity gates: chosen `z_entry` must satisfy `z_entry ≥ cost_gate-implied floor` (i.e. typical `edge_bps = z_entry·edge_bps_per_sigma ≥ 2·expected_cost_bps` [default], else the gate vetoes everything); chosen `cost_gate_k ≤ 1.0` [default] unless OOS turnover is demonstrably flat.
- **R2 — `q_beta` / `R` (filter dynamics).** `R`: closed-form estimate = residual variance of the formation-window OLS hedge regression [default]; re-estimate at most annually [default]. `q_beta`: grid `alpha_beta ∈ {1e-5, 3e-5, 1e-4, 3e-4, 1e-3}` [default]; per grid point replay formation data, compute OOS net Sharpe **and** the `Q = 0` null on the same folds; select the smallest `alpha_beta` whose ΔNet Sharpe (Kalman − Q=0 null) > `0` with DSR p < `0.10` [default] and turnover ≤ `1.5`× the null's turnover [default]; if no grid point passes, ship the null (static hedge) and disable the filter for that pair (failure mode #2). Re-run R2 whenever formation data rolls or the drift pre-test (§S10 #3) changes state.
- **R3 — `exit_band`, `edge_bps_per_sigma` (example params).** `exit_band`: grid `0.25`–`1.5` step `0.25` [example]; joint with `z_entry` only if OOS sample ≥ `100` trades [default], else hold at `0.5` [example]. `edge_bps_per_sigma`: not tuned --- set from the desk's per-σ edge model; document the value and its source in the decision log.

## §S3 Math + normative pseudocode

State-space model (the chapter's §S3; the reference implementation runs the 1-state $\beta_t$ form with a separately estimated intercept — clearer arithmetic; production usually uses the joint $[\mu_t, \beta_t]$ form):

$$y_t = \mu_t + \beta_t x_t + \varepsilon_t, \qquad \varepsilon_t \sim N(0, R),$$
$$\theta_t = \theta_{t-1} + \eta_t, \qquad \eta_t \sim N(0, Q),$$
Predict: $\hat\theta_{t|t-1} = \hat\theta_{t-1|t-1}$, $P_{t|t-1} = P_{t-1|t-1} + Q$.
Update: $e_t = y_t - H_t\hat\theta_{t|t-1}$; $F_t = H_t P_{t|t-1} H_t^\top + R$; $K_t = P_{t|t-1}H_t^\top F_t^{-1}$; $\hat\theta_{t|t} = \hat\theta_{t|t-1} + K_t e_t$; $P_{t|t} = (I - K_tH_t)P_{t|t-1}$.
Signal: $z_t = e_t/\sqrt{F_t}$; long the spread if $e_t < -c\sqrt{F_t}$, short if $e_t > c\sqrt{F_t}$ ($c = 1.0$–$2.5$ [example]).

**Normative pseudocode** (pseudocode is normative; prose is commentary).
All guards in prose appear below as executable assertions; `now()` is the
authoritative causality clock (`event_ts`, int64 ns UTC per §S0.4).

```
function signal(state, bars, cfg) -> SignalVector:
    # cfg fields: z_entry, cost_gate_k, q_beta, R, beta0, P0, cooldown_s,
    #             staleness_ttl_s, exit_band, edge_bps_per_sigma  (§S0.2)
    # state: module-owned named state (beta, P, cooldown_until, module_state, market_state)
    assert len(bars) > 0 else return UNKNOWN                                  # F1
    b = bars[-1]
    assert isfinite(b.x) and isfinite(b.y) else return UNKNOWN                # F1: bad input -> UNKNOWN, never interpolate
    assert b.x != 0 else return UNKNOWN                                      # F2: out of mathematical bounds
    assert isfinite(cfg.z_entry) and cfg.z_entry > 0 else return UNKNOWN     # F2: config guard
    assert isfinite(cfg.q_beta) and cfg.q_beta >= 0 and isfinite(cfg.R) and cfg.R > 0 else return UNKNOWN  # F2
    ms = market_state(b)   # CONTINUOUS_TRADING | HALTED | AUCTION | CLOSED (§S0.5)
    if ms == HALTED:   return UNKNOWN                                       # freeze; discard contributions across reopen
    if ms == CLOSED:    return OFF
    if ms == AUCTION:   return (last SignalVector, DEGRADED)                # hold last vector, no new signal
    assert now() - b.asof_ts <= cfg.staleness_ttl_s else return UNKNOWN      # staleness TTL; mask, no interpolation
    (beta, P) = (state.beta or cfg.beta0, state.P or cfg.P0)
    for r in bars:                       # replay from priors = fixture's _kf core
        Pp = P + cfg.q_beta
        e  = r.y - beta * r.x          # innovation
        F  = r.x^2 * Pp + cfg.R        # forecast variance
        K  = Pp * r.x / F              # Kalman gain
        beta = beta + K * e;  P = (1 - K * r.x) * Pp
    z = e / sqrt(F)
    assert isfinite(z) else return UNKNOWN                                   # F2
    in_cooldown = now() < state.cooldown_until
    edge_bps = abs(z) * cfg.edge_bps_per_sigma                              # [example] modeled per-trade edge
    # normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    # arg bindings (reference-stack call; inputs accepted, not used — §S2 COST):
    notional = 1.0; adv_pct = 0.001; venue = "XNAS"; side = "taker"; urgency = "normal"
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    raw_dir = -1 if z >= cfg.z_entry else (1 if z <= -cfg.z_entry else 0)
    direction = 0 if (in_cooldown or not cost_ok) else raw_dir               # C10 cooldown + C2/C7 cost/locate gate
    confidence = min(1, abs(z) / (2*cfg.z_entry)) if direction != 0 else 0
    capital = 0.5 * confidence                                               # [default] §S2 sizing
    state.beta, state.P = beta, P
    fill_event = bar_open(b.event_ts) + bar_ns                             # earliest fill = next bar's open: t -> t+1
    sig = SignalVector(symbol, direction, confidence, capital,
                       computed_at=b.event_ts, staleness=now()-b.asof_ts,
                       module_state=state.module_state)
    log_decision(sig, hash_inputs(bars, cfg), hash_params(cfg))             # C5 / Appendix g
    assert fill_event > sig.computed_at                                     # t->t+1 causality: no signal-bar fills
    return sig
```

Note: the exit handler (consuming strategy, §S2 Exits) sets
`state.cooldown_until = now() + cfg.cooldown_s` on exit/compliance block;
entries are suppressed while `now() < cooldown_until` (C10). The
`in_cooldown` line above is the normative enforcement of that rule.

Causality: $\hat\theta_{t|t}$ uses data $\le t$; $z_t$ is computed at bar $t$'s close; the earliest fill is bar $t+1$'s open. Normative: `assert fill_event > signal_event`. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Q too large → filter chases noise; turnover explodes → detect: turnover vs baseline → action: OOS-calibrated Q, start `alpha_beta = 10^{-4}` [example] → recovery: re-validate on embargoed OOS | `turnover <= 1.5 * baseline [default]` |
| 2 | Q too small / Q = 0 → expensive static OLS with extra steps → detect: `beta_t` flat → action: compare against the Q=0 null → recovery: drop the filter where drift is absent | `var(beta_t) > 0` |
| 3 | Stable-beta pairs → adaptation adds nothing but trades → detect: drift pre-test fails → action: static hedge → recovery: re-test drift quarterly | `drift_test_passes` |
| 4 | Illiquid pair / wide spreads → re-hedging costs swamp gains → detect: cost gate failing → action: liquidity filter, veto → recovery: resume when spreads normalize | `expected_cost_bps(...) <= k * edge_bps` |
| 5 | Borrow dominance → short-leg fees exceed the spread edge → detect: borrow-fee gate → action: veto shorts (C11) → recovery: re-check borrow panel | `borrow_bps <= desk_limit` |
| 6 | Lookahead in Q calibration → tuning Q on the traded sample → detect: OOS decay → action: walk-forward / purged CV, freeze Q on formation → recovery: re-freeze | `oos_sharpe > 0.5 * is_sharpe [default]` |
| 7 | Fat-tailed innovations → gain overreacts to jumps → detect: |z| > `5` [example] bars → action: winsorize / jump screen → recovery: re-tune | `max_abs_z <= 5 [example]` |
| 8 | Stale inputs → filter updates on dead quotes → detect: staleness TTL breach → action: `UNKNOWN`, mask → recovery: backfill and replay | `asof_ts - event_ts <= ttl` |
