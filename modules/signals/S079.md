# S079 — HMM regime switching

A hidden Markov model infers the market's latent regime — calm vs. volatile — from returns, and gates other signals by the filtered regime probability. A meta-signal (risk dial / veto), not a directional trigger. Provenance **[D]** (Hamilton 1989 lineage; Christensen–Godsill–Turner 2020).

### Entry rule (Boolean — no prose-only conditions)

```
GATE_CALM     := (P_vol < p_halve)            # full risk for downstream signals
GATE_ELEVATED := (p_halve <= P_vol < p_suspend)  # halve downstream size
GATE_VOLATILE := (P_vol >= p_suspend)           # SUSPEND downstream entries
DIRECTION := +1 if GATE_CALM else (0 if GATE_ELEVATED else -1)   # risk-on / neutral / risk-off
EMIT := (module_state == OK) AND (expected_cost_bps(...) <= cost_gate_k * edge_bps)
FLAT := otherwise

`P_vol` = filtered P(volatile | data `≤ t`) via the forward algorithm (never the smoother);
`edge_bps = cfg.edge_bps = 2.0` [example] modeled per-bar risk-avoidance value.
```

### Exits (with post-exit cooldown)

```
EXIT := (P_vol crosses above p_suspend while DIRECTION != -1)   # gate flips are the exits
        OR (module_state != OK)
ON_EXIT: cooldown_until = now + cooldown_s   # 300 s [default]; C10
```

## §S3 Math + normative pseudocode

Two-state Gaussian HMM on bar returns $r_t$ (bp) [documented, Hamilton 1989 lineage]:

$$r_t \mid s_t = k \sim \mathcal{N}(\mu_k, \sigma_k^2), \qquad P(s_t=j \mid s_{t-1}=i) = A_{ij}$$ [documented]

**Forward (filtered) recursion** — the only recursion live code may use:

$$\alpha_t(j) = \phi(r_t;\mu_j,\sigma_j)\sum_i \alpha_{t-1}(i)\,A_{ij}, \qquad P(s_t=j \mid r_{1:t}) = \frac{\alpha_t(j)}{\sum_k \alpha_t(k)}$$

Expected durations: $E[D_k] = 1/(1-A_{kk})$ (operator-verified correction [documented-as-observation]): $E[D_{calm}] \approx 33.3$ bars, $E[D_{vol}] = 12.5$ bars [example]. **Smoothed probabilities (forward–backward) use future data — research plots only, never live signals.** Baum–Welch (EM) estimates $(A,\mu,\sigma)$ from history; relabel states by $\sigma$ ascending after every fit.

Filtered probabilities use data `≤ t` only; tradable no earlier than `t+1`. Constants inside cited formulas inherit the formula's tag (`[documented]`).

**Normative pseudocode** (pseudocode is normative; prose is commentary). Every
variable below is bound here; guards are inline:

```
function signal(state, events, cfg) -> SignalVector:
    # --- F1: presence / shape ---
    if len(events) == 0:
        return UNKNOWN("F1: empty events")
    e = events[-1]                                  # newest event
    if e.kind != "bar":
        return UNKNOWN("F1: non-bar event")
    # --- staleness guard (F4, §S0.4) ---
    staleness_s = (e.asof_ts - e.event_ts) / 1e9
    if staleness_s > cfg.staleness_ttl_s:           # 900.0 s [default]
        return UNKNOWN("F4: stale input")
    # --- halt / auction guard (§S0.5, C6) ---
    if e.halted:
        return UNKNOWN("C6: halted")
    if e.auction:
        state.module_state = DEGRADED
        return state.last_signal                     # hold last SignalVector
    # --- F1/F2: validity, never interpolate ---
    if not isfinite(e.ret_bp):
        return UNKNOWN("F1: non-finite ret_bp")
    if not (cfg.sigma[0] > 0 and cfg.sigma[1] > 0):
        return UNKNOWN("F2: sigma out of bounds")
    if abs(sum(state.alpha) - 1.0) > 1e-12:         # [default] tolerance
        return UNKNOWN("F2: alpha not a distribution")
    # --- forward filter ONLY — the smoother is banned in live code (C11) ---
    K = cfg.K                                        # 2 [calibrate]
    pred[j] = sum(state.alpha[i] * cfg.A[i][j] for i in 0..K-1)   for j in 0..K-1
    like[j] = gauss_pdf(e.ret_bp, cfg.mu[j], cfg.sigma[j])        for j in 0..K-1
    num[j]  = pred[j] * like[j]                                   for j in 0..K-1
    tot     = sum(num)
    if not (tot > 0 and all(isfinite(num))):
        return UNKNOWN("F2: degenerate filter")
    alpha = [num[j] / tot for j in 0..K-1]
    state.alpha = alpha
    p_vol = alpha[1]                                 # index 1 = volatile (relabel invariant)
    # --- locate gate (C7) ---
    locate_ok = cfg.locate_asserted                   # consumer asserts via consumes contract [default]
    # --- cost gate: normative executable predicate ---
    notional = cfg.ref_notional_usd                   # [default] 1e6 — reference scale
    adv_pct  = cfg.ref_adv_pct                        # [default] 0.01
    venue    = cfg.venue                              # [default] "XNAS"
    side     = cfg.side                               # [default] "taker"
    urgency  = "normal"                               # [default]
    cost_bps = expected_cost_bps(notional, adv_pct, venue, side, urgency)
    edge_bps = cfg.edge_bps                           # [example] 2.0 modeled per-bar risk-avoidance value
    cost_ok  = (cost_bps <= cfg.cost_gate_k * edge_bps)
    # --- gate decision (§S2 Boolean rules) ---
    if p_vol < cfg.p_halve:            gate, direction = "FULL",    +1
    elif p_vol < cfg.p_suspend:        gate, direction = "HALVE",    0
    else:                             gate, direction = "SUSPEND", -1
    if not cost_ok:                              gate += "|COST";     direction = 0
    if e.event_ts < state.cooldown_until:         gate += "|COOLDOWN"; direction = 0   # C10
    if direction == -1 and not locate_ok:         gate += "|LOCATE";   direction = 0   # C7
    # --- emission ---
    confidence = abs(p_vol - 0.5) * 2.0               # [example]
    capital    = 0.5 * confidence                      # [default] 0.5 cap
    sig = SignalVector(symbol=e.symbol, direction=direction, confidence=confidence,
                       capital=capital, computed_at=e.event_ts,
                       module_state=state.module_state)
    log_decision(sig, inputs_hash=hash(events), params_hash=hash(cfg))   # C5 / Appendix g
    # --- causality: machine assertion (harness-enforced, unit-tested) ---
    assert for every fill f produced from sig: f.event_ts > sig.computed_at
    # i.e. assert fill_event > signal_event: t→t+1, no-signal-bar fills
    return sig
```

State init (reference): `alpha = stationary(A)` — `(0.7273, 0.2727)` [example]
for the demo A; production seeds from the first Baum–Welch fit. `cooldown_until
= 0` [default]; `last_signal = None` until first emission.

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|
| 1 | Smoothed vs filtered lookahead — the big one → detect: live output path calls the backward pass (code audit / unit test) → action: separate `filter_live()` from `smooth_research()`; halt on violation → recovery: re-run no-signal-bar-fills + smoother-ban test | ``check: no backward pass in live path`` |
| 2 | State label switching between refits → detect: σ ordering flips after refit → action: relabel by estimated σ ascending after every fit → recovery: replay | ``check: sigma[0] <= sigma[1]`` |
| 3 | EM local maxima → detect: likelihood drops vs prior fit → action: multiple random inits, keep best likelihood → recovery: refit | ``check: loglik >= prev_loglik - tol`` |
| 4 | Detection lag (`1–2` periods) → detect: whipsaw around turns → action: min-persistence + hysteresis bands; never pretend the lag away → recovery: widen bands | ``check: flips_per_day <= 3`` |
| 5 | Overfit K (`3`+ states on short windows) → detect: penalized likelihood prefers K=`2` → action: penalized-likelihood / CV state-count selection → recovery: drop to 2-state | ``check: K <= 2 on short windows`` |
| 6 | Cost blowup on gated book churn → detect: cost gate failing on `[measured]` costs → action: widen hysteresis; stand down → recovery: re-pin fee schedule | ``check: expected_cost_bps(...) <= k * edge_bps`` |
| 7 | Lookahead leakage: smoothed probs in live gate → detect: causality audit flags `fill_event ≤ signal_event` → action: halt, fix → recovery: re-run causality test | ``check: all(fill_ts > computed_at)`` |
| 8 | Anything unmapped → detect: — → action: `UNKNOWN` + page → recovery: runbook | ``check: module_state in {OK, DEGRADED, UNKNOWN, OFF}`` |
