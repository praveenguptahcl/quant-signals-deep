# S053 — Pair-quality filter — zero crossings (Do–Faff)

Most candidate pairs are not tradeable — they are slow divergences wearing a correlation costume. The Do–Faff zero-crossing filter is a formation-period quality gate: count how many times the pair's spread crossed its own mean during formation. Pairs that crossed often mean-reverted often; pairs that never crossed just drifted. It never fires an entry — it is a veto that keeps bad pairs out of the book, and its value is measured in blow-ups avoided and profit-per-trade, not in signals generated. Provenance **[D]**.

## §S3 Math + normative pseudocode

Zero-crossing count on the formation-period spread (Do & Faff 2010):

$$zc = \#\{t : (s_t - \bar{s})(s_{t-1} - \bar{s}) < 0\}, \qquad \text{trade\_it} = zc \ge zc_{\min}$$

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
function signal(state, bars, cfg) -> SignalVector:
    assert bars non-empty else return UNKNOWN                        # F1
    b = bars[-1]
    assert isfinite(b.spread) else return UNKNOWN                    # F1/F2
    spreads = [r.spread for r in bars if r.pair == b.pair]
    zc = #{i >= 1 : spreads[i-1] * spreads[i] < 0}
    quality = min(1, zc / 20.0)                                      # [example]; gate never emits entries
    edge_bps = 12.0                                                  # [example] modeled net edge per gated trade
    cost_ok = expected_cost_bps(notional, adv_pct, venue, side, urgency) <= cfg.cost_gate_k * edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    module_state = OK if cost_ok else DEGRADED
    sig = SignalVector(b.pair, 0, quality, 0.0,                     # direction always 0
                       computed_at=b.event_ts, staleness=now()-b.asof_ts,
                       module_state=module_state)
    log_decision(sig, inputs_hash, params_hash)                      # C5 / Appendix g
    assert fill_event > signal_event                                # t→t+1 causality: no fill on the signal bar
    return sig
```

Causality: The gate is computed on the formation window only; pairs passing the gate become tradable no earlier than the next bar. Mandatory unit test: no-signal-bar fills.

## §S9 Efficacy — documented evidence

| Study / source | Market & period | Metric | Before/after cost | Caveat |
|---|---|---|---|---|
| Gatev, Goetzmann & Rouwenhorst (2006) [documented] | CRSP US, 1962–2002 | ~11% p.a. excess return; entries at 2σ, exits at the next zero crossing | `BEFORE-COST` | the exit mechanic this filter is built around; decay after 1989 |
| Do & Faff (2010) [documented] | US, 1962–2009 | profitability concentrated in 1970s–80s; marked decline after ~1989 | `BEFORE-COST` | via the CIR working-paper PT2.5 summary; motivates quality gating |
| Do & Faff (2012) [documented] | US | transaction costs materially erode pairs profitability | `AFTER-COST` | via the published version (MDPI) and CIR summaries; the filter must earn its keep net of costs |
| Rad, Low & Faff (2016) [documented] | full US market, 1962–2014 | distance/cointegration/copula at 91/85/43 bps mean monthly excess return before costs; post-2009 decline in distance/cointegration opportunities | `BEFORE-COST` | second Do–Faff replication — the motivation for quality gating |

**Honest bottom line.** As a standalone trigger this signal is a *zero* edge — it never fires an entry. As a formation-period quality gate it is a *cheap, sensible screen with documented pedigree but thin standalone after-cost proof*: validate it as what it is — a veto — by comparing gated vs ungated portfolios on net Sharpe, max drawdown, and turnover, not on gross returns.
