# S053 — Pair-quality filter — zero crossings (Do–Faff)

Most candidate pairs are not tradeable — they are slow divergences wearing a correlation costume. The Do–Faff zero-crossing filter is a formation-period quality gate: count how many times the pair's spread crossed its own mean during formation. Pairs that crossed often mean-reverted often; pairs that never crossed just drifted. It never fires an entry — it is a veto that keeps bad pairs out of the book, and its value is measured in blow-ups avoided and profit-per-trade, not in signals generated. Provenance **[D]**.

### Calibration recipes (per parameter — grid + OOS selection)

General discipline for every recipe: formation strictly before trading, embargo
gap of `5` trading days [default] between them (C12); never select on the
evaluation universe; record the selection in §S9 (selection disclosure). A
filter is scored as a veto — compare the gated portfolio against the ungated
portfolio on net Sharpe, max drawdown, and turnover, never on the gate's own
gross returns.

- **`zc_min`** — grid `{2, 3, 5, 10, 20}` [example]. (1) Walk-forward over the
  pair universe: per fold, count zc in formation, build gated vs ungated
  portfolios over the trading window. (2) Selection metric: OOS net Sharpe
  (`FULL-COST`) of gated minus ungated ≥ `0` [default] AND breadth ≥
  `breadth_floor`. (3) Pick the smallest `zc_min` meeting both — bias to the
  looser gate. (4) OOS acceptance: criterion holds on ≥ `2` non-overlapping OOS
  windows [default].
- **`cost_gate_k`** — grid `{0.25, 0.5, 1.0, 2.0}` [example]. Sweep k on the
  same OOS walk-forward; select the largest k such that the gated portfolio's
  net-of-cost return ≥ `0` across folds. `0.5` [default] is the conservative
  prior when no calibration has run.
- **`formation_bars`** — grid `{63, 126, 252}` [example]; match the downstream
  strategy's formation length (S049/S050). Longer windows stabilize counts but
  slow regime response. Do not tune the window to maximize in-sample zc.
- **`quality_norm`** — grid `{10, 20, 40}` [example]. Monotonic rescale only:
  calibrate by rank correlation between `quality` and the forward convergence
  rate of gated pairs across OOS formation cohorts; low sensitivity.
- **`edge_bps`** — NOT fitted. Recipe: replace the placeholder with the
  downstream T-module's measured OOS net edge per trade [measured] before any
  production decision; if none exists, the cost gate stays in its conservative
  `0.5` [default] posture and the gate is research-only.
- **`breadth_floor`, `max_pairs`** — capacity-driven: derive from
  `max_notional = f(participation_cap, ADV, spread_regime)`; sanity-grid

## §S3 Math + normative pseudocode

Zero-crossing count on the formation-period spread, demeaned (Do & Faff 2010):

$$zc = \#\{t : (s_t - \bar{s})(s_{t-1} - \bar{s}) < 0\}, \qquad \text{trade\_it} = zc \ge zc_{\min}$$

The demean makes the statistic level-invariant: a pair trading at a persistent
premium still reveals its reversion frequency, and a drifting spread is not
rewarded for wandering. Where the S049/S050 spread construction already
normalizes the formation mean to ≈ `0` [example], the demean is a no-op — the
fixture's Pair C exists precisely to pin the demeaned definition against the
raw-zero-count alternative.

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
DOWNSTREAM_REF := (notional = 1e6 [example], adv_pct = 1e-4 [example],
                   venue = "XNAS" [example], side = "taker" [default],
                   urgency = "normal" [default])

function signal(state, bars, cfg) -> SignalVector:
    if len(bars) == 0:
        return UNKNOWN                                            # F1: missing input
    b := bars[-1]
    if not isfinite(b.spread):
        return UNKNOWN                                            # F1/F2: never interpolate
    spreads := [r.spread for r in bars if r.pair == b.pair]
    if len(spreads) < cfg.formation_bars:
        return UNKNOWN                                            # insufficient formation window
    m := mean(spreads)
    d := [x - m for x in spreads]                                 # demeaned formation spread
    zc := #{i >= 1 : d[i-1] * d[i] < 0}                           # strict: mean-touches do not count
    # ^^^ normative zero-crossing definition (Do & Faff 2010 [documented])
    pass_gate := (zc >= cfg.zc_min)
    quality := min(1, zc / cfg.quality_norm)                      # [example] norm; gate never emits entries
    cost_ok := expected_cost_bps(*DOWNSTREAM_REF) <= cfg.cost_gate_k * cfg.edge_bps
    # ^^^ normative cost-gate predicate: expected_cost_bps(...) <= k * edge_bps
    module_state := OK if cost_ok else DEGRADED
    sig := SignalVector(symbol = b.pair, direction = 0,           # direction always 0: a filter emits no entries
                        confidence = quality, capital = 0.0,
                        computed_at = b.event_ts, staleness = now_ns() - b.asof_ts,
                        module_state = module_state)
    log_decision(sig, inputs_hash, params_hash)                   # C5 / Appendix g
    assert fill_event > signal_event                              # t->t+1 causality: no fill on the signal bar
    return sig
```

Causality: the gate is computed on the formation window only; pairs passing
the gate become tradable no earlier than the next bar. Mandatory unit test:
no-signal-bar fills.

## §S9 Efficacy — documented evidence

| Study / source | Market & period | Metric | Before/after cost | Caveat |
|---|---|---|---|---|
| Gatev, Goetzmann & Rouwenhorst (2006) [documented] | CRSP US, 1962–2002 | ~11% p.a. excess return; entries at 2σ, exits at the next zero crossing | `BEFORE-COST` | the exit mechanic this filter is built around; decay after 1989 |
| Do & Faff (2010) [documented] | US, 1962–2009 | profitability concentrated in 1970s–80s; marked decline after ~1989 | `BEFORE-COST` | via the CIR working-paper PT2.5 summary; motivates quality gating |
| Do & Faff (2012) [documented] | US | transaction costs materially erode pairs profitability | `AFTER-COST` | via the published version (MDPI) and CIR summaries; the filter must earn its keep net of costs |
| Rad, Low & Faff (2016) [documented] | full US market, 1962–2014 | distance/cointegration/copula at 91/85/43 bps mean monthly excess return before costs; post-2009 decline in distance/cointegration opportunities | `BEFORE-COST` | second Do–Faff replication — the motivation for quality gating |

**Honest bottom line.** As a standalone trigger this signal is a *zero* edge — it never fires an entry. As a formation-period quality gate it is a *cheap, sensible screen with documented pedigree but thin standalone after-cost proof*: validate it as what it is — a veto — by comparing gated vs ungated portfolios on net Sharpe, max drawdown, and turnover, not on gross returns.

## §S10 Failure modes & pitfalls

| # | Trigger → Detect → Action → Recovery | check: |
|---|---|---|
| 1 | Regime breaks → formation rhythm doesn't carry into trading → detect: rolling-zc health monitor → action: cut pairs whose recent crossing rate collapses → recovery: re-form | `recent_zc >= 0.5 * formation_zc [default]` |
| 2 | Over-tight gating → zc_min too high leaves 3 pairs, concentration risk → detect: breadth floor → action: top-slice (quartile) not absolute thresholds → recovery: re-run gate | `n_pass >= 5 [default]` |
| 3 | False crossings from noise → microstructure chop around zero inflates zc → detect: crossing excursion audit → action: count crossings of a lightly smoothed spread → recovery: re-count | `min_excursion > 0 [example]` |
| 4 | Corporate-action artifacts → split mid-formation fabricates crossings → detect: action reconciliation → action: back-adjusted series → recovery: re-form | `actions_reconciled` |
| 5 | Lookahead via window overlap → formation bleeding into trading → detect: window audit → action: strict formation/trading split + embargo → recovery: re-split | `formation_end < trading_start` |
| 6 | Crowded quality → everyone screens on the same statistic → detect: — → action: treat gate as hygiene not edge; combine with idiosyncratic screens → recovery: — | `n/a` |
| 7 | Ignoring costs → high-zc pairs untradeable after borrow/spread → detect: cost gate failing → action: apply cost/borrow gate AFTER the quality gate → recovery: resume when costs normalize | `expected_cost_bps(...) <= k * edge_bps` |
| 8 | Survivorship in screening → delisted pairs vanish, flattering formation stats → detect: constituent audit → action: point-in-time constituent histories → recovery: rebuild screen | `point_in_time_constituents` |
