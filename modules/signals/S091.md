# S091 — News sentiment z-score (ESS)

A per-story sentiment trigger. Each story arrives with an event sentiment score `S_b ∈ [−1,1]` (vendor ESS or an own Loughran–McDonald scorer); the module z-scores it against the trailing sentiment panel `z_b = (S_b − μ_trail)/σ_trail` and enters with the sign of `S_b` when `|z_b| > z_entry` and the story clears relevance and novelty floors [documented]. The classical dictionary version (Tetlock 2007) scores pessimism as negative-words/total-words; use the Loughran–McDonald finance dictionary — roughly three-quarters of Harvard 'negatives' are neutral accounting terms in finance [documented].

## §S2 Specification

### Universe

One symbol's story flow; fixture: `5` synthetic stories (seed `91` [example]).

### Entry rule (Boolean — no prose-only conditions)

```
S_b       := ESS in [-1,1]                     # vendor or Loughran-McDonald scorer [documented]
z_b       := (S_b - trail_mean) / trail_sd      # trailing z-score [documented]
FLOORS    := rel >= rel_floor AND nov >= nov_floor   # 80 / 70 [example]
ENTER     := |z_b| > z_entry AND FLOORS          # z_entry = 2.0 [example]
DIRECTION := sign(S_b) iff ENTER else FLAT
```

### Exits (with post-exit cooldown)

```
EXIT := after `h` minutes as the reaction completes (`h = 30` min [example]); or on story correction/supersede → flatten immediately. Post-exit cooldown `1` session [default].
```

## §S3 Math + normative pseudocode

Per story b: sentiment `S_b ∈ [−1,1]` (vendor ESS or own scorer) [documented]; trailing panel `(μ_trail, σ_trail)` over the last `trail_n = 30` stories [example]; `z_b = (S_b − μ_trail)/σ_trail` [documented]. Enter with `sign(S_b)` iff `|z_b| > z_entry = 2.0` [example] and `rel ≥ 80`, `nov ≥ 70` [example]. The classical dictionary score (Tetlock 2007) is pessimism = (# negative words)/(# total words) [documented]. Cost gate: `expected_cost_bps(...) <= k * edge_bps`, `k = 0.5` [default]; the fixture's story-1 edge is `42.7` bps [example] vs the `3.0` bps stack [example].

**Normative pseudocode** (pseudocode is normative; prose is commentary):

```
S_b = ess(story_text)                       # in [-1,1]; vendor or L-M scorer; text <= t
z_b = (S_b - trail_mean) / trail_sd           # trailing panel, data <= t
floors_ok = (rel >= 80.0) and (nov >= 70.0)   # [example] floors
if abs(z_b) > 2.0 and floors_ok:              # z_entry [example]
    direction = sign(S_b)
    edge_bps = illustrative_move_bps          # 42.7 [example]
    assert expected_cost_bps(notional, adv_pct, venue, side, urgency) <= k * edge_bps  # k = 0.5 [default]
else:
    direction = 0                             # no trade: below z, or floors failed
assert fill_event > signal_event              # availability ts; never the publication ts
```

Causality: the computation at `t` uses only data `≤ t`; earliest reaction is
`t+1`. Mandatory unit test: no-signal-bar fills.
