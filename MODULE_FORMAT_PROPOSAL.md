# Module Format Proposal — v1.0.0
**Quant Signals Compendium: standalone, AI-implementable module format**
Date: 2026-09-10 · Status: Phase 1 proposal (do NOT retrofit MASTER.md yet)

## 0. Purpose and scope
The 200-chapter MASTER.md is a reader's document. The 250-module program (S001–S100, T001–T100, R001–R050 as separate files) needs a **builder's spec**: each file must let an AI agent implement a working, independent, testable module for any identifying ticker, with the **cheapest/least-build path clearly highlighted**.

Phase 1 reviewed the S/T/R formats with 20 quant experts and ran 5 brainstorming sessions. This proposal is their converged output. Reviews: `batches/format-review/reviews/R01–R20`. Sessions: `batches/format-review/sessions/session-01..05`.

| 6 | CRITICAL (a) | **Cost has no architecture.** No callable cost function; 0 fee as-of dates; cost restated in 5+ sections (T050 contradicts itself in two adjacent paragraphs); fee-covering gate as code in 1/100 T chapters; borrow convention inconsistent. | R17 |
| 7 | CRITICAL (a) | **Risk/kill/fail-safes are prose.** T kill-switch prose; F1–F5 (RB-list) referenced by 0/200 chapters; 3 vocabularies for module state (DEGRADED / UNTRUSTED_FLAT / UNKNOWN). | R16, R03 |
| 8 | CRITICAL (a) | **Compliance is structurally invisible.** 0/200 chapters have a compliance section; zero self-trade/wash-trade rules in 36,207 lines; spoofing treated as others' noise, not a constraint on own quoting; no audit-log schema; no locate/Reg-SHO gate; no entitlement assertions. | R12 |
| 9 | MAJOR (a/b) | **No event/time/causality contract.** No int64-ns timestamp convention; bar-label rules undeclared; staleness TTL absent; halt/auction behavior = "exclude and mask" backtest hygiene, not runtime state machine. | R04, R10, R12 |

Honorable mention (MAJOR, deferred to R001–R050 pass): 0/200 chapters reference any R-ID; no per-chapter regime-gate schema.

**Doctrines to preserve:** (i) Strategies emit *intentions only*; execution/broker layers create orders. T-modules emit order intents via a global OrderTicket schema; cost/fill simulation lives in the T-module harness, never in signals. (ii) S-modules emit only `Signal{symbol, direction, confidence, capital}` + cadence/staleness. (iii) t→t+1 causality as machine assertion: `assert fill_event > signal_event`, mandatory "no signal-bar fills" unit test. (iv) `(example)` honesty tagging — extended, not replaced.

## 2. Session decisions (5 sessions)

**Session 01 — Module/API/data contracts:** Uniform YAML front-matter (id, kind, version semver, status, batch, family, provenance_tier, sources, unverified_sources, regime_ids[], correlates_with, shares_feed_with, seed, rng algorithm+lib pin, plot_script, test_cmd, datasets with lineage fingerprints, changelog). New mandatory `§S0/§T0 Module contract` block: typed signature `signal(state, events, cfg) -> SignalVector`, single `Config` dataclass with per-parameter type/default/range/status, canonical Event/Bar schema mapping + timestamp contract, error taxonomy = single module-state enum `OK | DEGRADED | UNKNOWN | OFF` (invalid input emits UNKNOWN, never interpolates — RB-list F1–F5 ported into every chapter), `tests/test_<SID>.py` with CSV fixture, ops tail (schedule, health, alerts, resource budget, runbook) in the same section, secrets env-only. Canonical SignalVector agreed. Dependencies: one machine edge list `deps.yaml` (`{from, to, function, arg_types, return_types, version_pin, role}`); S5/T3 generated from it, CI asserts symmetry. Formulas live once in the provider's contract; consumers inline only the 2–3 decisive constants with version pin. Cheapest layer = YAML + deps.yaml + §S0/T0 + one fixture+test per chapter + Gate QC lint.

**Session 02 — Causality/backtest/execution/costs:** Mandatory structured COST block in §T2 (single source of truth; re-stating numbers elsewhere is a validation failure) **plus** callable `expected_cost_bps(notional, adv_pct, venue, side, urgency)` with reference implementation per chapter. Required fields: 4-component stack (spread/fees/borrow/impact), `fee_schedule_as_of`, venue/tier/source, `side: taker|maker|mixed`, `borrow_bps_per_day` (0 needs a reason), marker taxonomy + new `[measured]`. Cost-level tokens BEFORE-COST/COMM-ONLY/FULL-COST; before/after-cost column mandatory in §S9/§T7. Fee-covering entry gate as executable predicate `expected_cost_bps(...) <= k * edge_bps` in T3 pseudocode. Backtest: per-chapter acceptance checklist (walk-forward + embargo with pass/fail, min OOS trades, cost level, DSR/PBO or "not computed" + variant count); mandatory fill-model table; fixtures with TYPE header (accounting-demo|validation-run) + seed; T4 rows show the cost-function call, not just a cost column. R chapters get a 5th block: "Cost interface: regime state → cost-function adjustment." Cheapest build = L2 constant-stack + callable wrapper from day one (impact=0 flagged `[example]`); fee versioning, side field, cost tokens non-negotiable even in MVB.

**Session 03 — Risk/regimes/portfolio/compliance:** Fenced YAML risk contract per T chapter (`per_trade_R`, `daily_loss_stop`, `max_gross`, `kill_conditions[]`, `enforcement` ∈ {intraday-hard, review-only}, calibration recipe); mandatory `max_adverse_per_trade` row with CI gate; kill-switch state machine `ARMED → TRIPPED → RECOVERY → ARMED` with re-arm checklist; `UNKNOWN` = single canonical degradation token. Regime gates as machine records `{regime_id, direction ∈ amplifies/degrades/inverts, mechanism, condition, action ∈ veto/halve/double/widen_stops/pause_entry, min_lag, unknown_behavior}` with restrictive default. Compliance = new mandatory contract block (10 coded rules minimum: STP + self-match, bona-fide-intent, message-rate/cancel-to-trade, pre-trade fat-finger trio, decision-log schema, halt/auction state table, locate check, public-dissemination gate, data-entitlement assertions, exit cooldown). Triage card: 5 fixed fields under chapter header (edge_verdict · build_cost · data_cost · latency_class · risk_class) with closed enums. Capacity as `max_notional = f(participation_cap, ADV, spread_regime)`; correlation/crowding metadata (`correlated_with`, `shares_data_feed_with`, `crowding_proxy`).

**Session 04 — Derivatives/crypto/venue + data/time/precision:** Mandatory Time contract block (clock domain, authoritative causality clock, int64 ns, UTC canonical, max_skew, jitter budget, live/simulated-only); fixed-wording timing box atop every S3/T2: `signal@t (<cadence>, <TZ>) → earliest fill @open(t+1)`; dual `(event_ts, asof_ts)` timestamps; staleness TTL + no-interpolation gap policy; runtime market-state table (CONTINUOUS_TRADING / HALTED / AUCTION / CLOSED). Domain & session block required (asset class, venues, sessions+TZ, calendar/holiday, settlement); extension blocks conditional on domain, shared material in appendices: options (ChainSnapshot appendix, Pricing & Greeks block, expiry/assignment rules, options cost-ledger lines), crypto (per-venue funding interval, venue definition snapshot, margin & self-liquidation block). Numeric: per-chapter precision declaration, mandatory units line (decimal vs percent vol, fixed return definition, day-count), one-token processing model (`per_event | per_bar | per_snapshot`), named state vector + `on_event(e)` spec for streaming chapters. Data: canonical logical names + per-vendor column mapping; dataset fingerprints; Data rights row as startup assertions; structured cheapest-source verdict row (`min_tier, latency_class, required_fields, price_band, build_or_buy`); single cost-assumption register, referenced never restated.

**Session 05 — Final convergence:** §S1/T1 locked as canonical reviewer card (edge verdict enum AFTER-COST-EDGE / PREDICTIVE-FEATURE-ONLY / NO-DOCUMENTED-EDGE / INSUFFICIENT-EVIDENCE, after-cost token + one-sentence verdict, build cost `Tier M · 20–60 h · $3k–9k loaded`, data $/mo, latency/risk class, capacity, executability, risk summary, "when it dies" triggers, regime gates, emits). **S1–S12 / T1–T10 numbering frozen** (merge keys, QC, stage mapping depend on it) — new content lands in `§0` front-matter, `§S0/§T0` prepended blocks, and fixed-order mandatory sub-blocks inside existing sections, not new section numbers. Compliance = mandatory sub-block inside §T2-Robustness (+ Data rights row in §S6/T5), not a new T11/S13. Cheapest-build path = new mandatory `§S1.5/§T1.5` block after §S1 with prototype hour band, cheapest-source row, resource budget, skip list, DO-NOT-CUT list, escalation gate. Numeric-tag enum unified: `[documented]/[default]/[example]/[unverified]/[internal-est]/[measured]`. Migration: `notes/module-template.md` v1.0.0 succeeds `notes/chapter-template.md` (archived); CI additions: front-matter lint, S5↔T3 symmetry vs edge list, example-tag lint (unlabeled cost numbers fail), cost-block single-source, §T2 sub-block presence, §S1/T1 schema, secrets grep, cross-ref link lint, repro/seed check, version-pin lint. Retrofit priority: §0 + schema block + F1–F5 fail-safes first; pinned excerpts and regime-gate tables ride the R001–R050 annotation pass.

**Cross-session conflict resolved:** sessions 1/3/4 proposed new numbered sections (S13/T11); session 5 froze numbering. Final ruling: **freeze wins** — module contract → §S0/§T0; compliance → §T2-Robustness sub-block (+§S2 for signals); acceptance/fixtures → §S0/T0 test_cmd + fixture files; everything else as mandatory sub-blocks. Content preserved, numbering untouched.

## 3. Final module file structure (v1.0.0)

Every one of the 250 module files has this exact structure. "M" = mandatory, "C" = conditional on domain/asset class, "O" = optional.

```
§0   Front-matter (YAML, machine-parsed) .............. M
§1   5-minute reviewer card ............................ M
§1.5 Cheapest/least-build path ........................ M
§S0/§T0 Module contract (I/O, state, error, test_cmd,
     ops tail: schedule/health/alerts/resource/runbook) M
§S1/§T1 [subsumed by §1 card above; legacy §S1/§T1
     content becomes §1 rows]
§S2–§S11 / §T2–§T9  [frozen legacy sections, with
     mandatory fixed-order sub-blocks as below] ....... M
§S12/§T10 Source log + unverified leads .............. M
```

Section-by-section spec:

- **§0 Front-matter (M).** `id, kind ∈ {signal,strategy,regime}, version (semver), template_version: 1.0.0, status, batch, family, provenance_tier (legend once in compendium header), sources[], unverified_sources[] (always present), consumes[{id, version_pin, role}], regime_ids[] (provisional), correlates_with[], shares_data_feed_with[], seed, rng {algorithm, lib_pin}, plot_script, test_cmd, datasets[{name, vendor, product, schema_version, fingerprint, vintage, rights}], changelog[]`. Numeric-literal convention compendium-wide: backticked `` `example` `` / `` `fixed` `` / `` `rule` ``, lint-enforced; all other numeric tags from the unified enum.
- **§1 Reviewer card (M).** Locked row schema: Module · Edge verdict enum · after-cost token + one-sentence verdict · build cost `Tier · h · $loaded` · data cost $/mo (research+production) · latency_class · risk_class · capacity ($ band) · executability · risk summary · "when it dies" triggers · regime gates (provisional) · emits (signal_vector | order_intents). The summary layer; §S9/§T7 + §S8/T6 are the evidence layer.
- **§1.5 Cheapest-build path (M).** Prototype hour band; structured cheapest-source row (`min_tier, latency_class, required_fields, price_band, build_or_buy`); resource budget row + compute pattern (`per_event | per_bar | per_snapshot`); **skip list**; **DO-NOT-CUT list** (causality assertions, COST block, kill/safe-mode, audit log, bona-fide-intent + self-trade prevention, provenance tags, fixtures, secrets-via-env); escalation gate (when to upgrade from cheapest).
- **§S0/§T0 Module contract (M).** Typed signature `signal(state, events, cfg) -> SignalVector` (core function, not ingest code, handles documented edge cases); single `Config` dataclass (parameter, type, default, range, status ∈ {fixed, default, calibrate, example, internal-est}); mapping to canonical Event/Bar schema; Time contract (clock domain, int64 ns, UTC, max_skew, jitter, bar-label rule, staleness TTL, gap policy); market-state table (CONTINUOUS_TRADING / HALTED / AUCTION / CLOSED); module-state enum `OK | DEGRADED | UNKNOWN | OFF` (invalid input → UNKNOWN, never interpolate); risk contract (T: YAML block + kill-switch state machine `ARMED → TRIPPED → RECOVERY → ARMED` + re-arm checklist); ops tail (schedule spec + owner, health checks, alert table, resource budget, runbook stub); secrets = env-only (Gate-grepped). R chapters: §R0 front-matter + Lag contract + "Cost interface: regime state → cost-function adjustment" block.
- **§S2/§T2 with fixed-order mandatory sub-blocks (M):** Universe · Entry rule (Boolean expressions, no prose-only conditions) · Exits (with post-exit cooldown) · Position sizing as fenced function `shares = f(risk_budget_R, stop_distance, vol_estimate, ADV_cap, cost)` · Risk limits · **COST block** (single source of truth; 4-component stack; `expected_cost_bps(notional, adv_pct, venue, side, urgency)` reference implementation; `fee_schedule_as_of`; `side: taker|maker|mixed`; `borrow_bps_per_day` with reason if 0; all values tagged, unlabeled cost numbers fail CI) · Execution/fill model table (latency, partial-fill, impact, adverse-fill) · Robustness + **Compliance sub-block** (10 coded rules; decision-log schema; halt/auction state table; STP/self-match; bona-fide-intent; message-rate/cancel-to-trade; pre-trade fat-finger trio; locate check; public-dissemination gate; entitlement assertions) · Parameter table (symbol, value, tag, sensitivity) · Timing box `signal@t (<cadence>, <TZ>) → earliest fill @open(t+1)`.
- **§S3/§T3 (M).** Precise math + **normative pseudocode** (pseudocode is normative; prose is commentary): every prose guard present; cost gate as executable predicate `expected_cost_bps(...) <= k * edge_bps`; causality assertions inline. Consumed formulas = pinned verbatim excerpts (≤10 lines, ID + version + spec-hash, CI hash-checked).
- **§S4/§T4 (M).** Worked example shipped as `fixtures/<SID>_tape.csv` + expected outputs + tolerance; TYPE header (accounting-demo|validation-run); T4 rows show the cost-function call (inputs → bps → $); acceptance tests 3–5 per chapter (`tests/test_<SID>.py`, `test_cmd` in §0).
- **§S5–§S11 / §T5–§T9 (M).** Generated from `deps.yaml` edge list where applicable (S5/T3 tables never hand-written; CI symmetry). Regime gates as machine records `{regime_id, direction, mechanism, condition, action, min_lag, unknown_behavior}`. Failure modes as trigger → detect → action → recovery rows with `check:` lines. Domain extensions (C): options Pricing & Greeks / expiry-assignment; crypto funding/margin/liquidation; each conditional on the §0 domain field, shared material in appendices. Evidence tables with mandatory Before/after-cost column + cost-level token + selection disclosure; `[measured]` provenance on observed cost figures.
- **§S12/§T10 (M).** Source log + unverified leads (chatbot-sourced evidence segregated here, not in evidence tables); per-chapter process metadata collapsed/moved out of the reference tail.
- **AI build prompt (M, appendix to each file).** Copy-paste prompt for any chat agent: module ID, §0 summary, cheapest path, fixture/test commands, definition of done = `test_cmd` exits 0.

**Category deltas:** S modules emit SignalVector only, never orders (may/must-NOT line in §S0); T modules emit order intents via global OrderTicket schema with child-order state machine, partial-fill policy, cancel-replace rules; R modules follow RB-list format + §R0 + Lag contract + Cost interface block. Global appendices (defined once, imported by reference, version-pinned): Canonical Event/Bar schema, SignalVector schema, OrderTicket schema, ChainSnapshot schema, Time/causality conventions, F1–F5 fail-safes, decision-log schema, glossary, marker-taxonomy legend, data rights conventions.

## 4. Do-not-regress list
t→t+1 causality discipline; `(example)` honesty tagging (extended to `[documented]/[default]/[unverified]/[internal-est]/[measured]`); synthetic-data labeling + named seeds; "simulated only — requires MBO/ITCH" honesty; S12/T10 source-log + unverified-leads segregation; "Where the example is optimistic" sections; before/after-cost distinction; RB-list's RSV and F1–F5 fail-safes; strategy-emits-intentions-only doctrine; on-disk ledger discipline; stage↔ID mapping as machine key.
