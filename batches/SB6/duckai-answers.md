## Q-SB6-1: Formulas + worked examples — VERBATIM (key content)

### 1. Overnight-gap fade (+ Lee–Mykland jump filter)
g(t) = (O(t)−C(t−1))/C(t−1); fade s(t) = −sign(g(t)). R(t,k) = (P(t,k)−O(t))/O(t). Fade return Π(t,k) = −sign(g(t))·(P(t,k)−O(t))/O(t) − costs. Enter if |g(t)| ≥ g(min) (optionally ≤ g(max)); exit at prior close / k=5–30min / partial fill / opening-vol stop.
Practical: g(min) 0.5–2.0% liquid equities (0.2–0.8% liquid futures/FX); g(max) 3–8% (exclude info gaps); entry delay 1–5 min bars; hold 5–60 min; exit target 25–100% of gap; stop 0.5–1.5 opening ATR or 25–75% of gap; volume/spread/news filters.
**Lee–Mykland:** p(i)=log P(i), r(i)=p(i)−p(i−1). Local bipower variation V̂(i) = (π/2)·Σ_{j=i−k+2}^{i} |r(j−1)|·|r(j)|; Z(i) = r(i)/√V̂(i). Extreme-value normalization: T(i) = (|Z(i)| − C(Δ))/S(Δ); C(Δ) = √(2log(1/Δ)) − (logπ + loglog(1/Δ))/(2√(2log(1/Δ))); S(Δ) = 1/√(2log(1/Δ)). Null: Pr(T(i)≤x) ≈ exp(−e^(−x)). Reject no-jump when T(i) > q(1−α), q(1−α) = −log[−log(1−α)]; q(0.95)=2.970, q(0.99)=4.600. Practical: α=1–10% (5% exploratory); local window k=30–120 1-min returns; 10-min opening calc = illustrative only, NOT statistically reliable. Jump-filtered rule: fade only if |g(t)| ≥ g(min) AND T(open) ≤ q(1−α). Detected opening jump = "do NOT fade immediately", not auto-reverse.

### 2. Sub-hour microstructure reversal
p(t)=log P(t); R(t,L)=p(t)−p(t−L); s(t) = −sign(R(t,L)). Scaled: z(t,L)=R(t,L)/σ̂(t,L). Hold return Π(t,t+H)=s(t)·(p(t+H)−p(t))−costs. Microstructure version: p(t) = m(t) + (spread(t)/2)·q(t) + ε(t); measure reversal on transaction p(t), midquote m(t), or quote-adjusted returns — midquote preferred to isolate bounce.
Practical: L=1–30min; H=1–60min; grid L∈{1,2,5,10,15,30}; |z|≥0.5–2.0; exclude spread >2–3× intraday median; evaluate net of spread/fees/latency/impact.

### 3. Idiosyncratic/residual reversal
r(i,t) = α(i) + β(i)ᵀf(t) + u(i,t); residual û = r − α̂ − β̂ᵀf. U(i,t,L) = Σ_{ℓ=0}^{L−1} û(i,t−ℓ); s(i,t) = −sign(U). Scaled: z = U/(σ̂(u,i,t)·√L). Cross-sectional dollar-neutral: w(i,t) = −(rank(U)−rank̄)/Σ|rank(U)−rank̄|.
Practical: factor window 1–6 months intraday / 60–250d daily; residual lookback 5–60min intraday / 1–5d daily; hold 15min–1d intraday; residual z 0.5–2.0; re-estimate betas every 1–20d. Residualization separates genuine idiosyncratic reversal from broad-market moves.

### 4. LOB resiliency / temporary-impact reversion
I(t|Q) = m(t) − m(t,0) = λQ·e^(−κt); half-life t(1/2) = log2/κ; reversion fraction = 1−e^(−κt). Estimate: y(j) = log|I(t(j))| = log|λQ| − κt(j) + ε(j); κ̂ = −Σ(t−t̄)(y−ȳ)/Σ(t−t̄)²; t̂(1/2) = log2/κ̂. Permanent component: I(t|Q) = I(∞) + (I(0)−I(∞))e^(−κt). Spread: S(t) = S(∞)+(S(0)−S(∞))e^(−κ(S)t); depth: D(t) = D(∞)−(D(∞)−D(0))e^(−κ(D)t). Spread resiliency(t) = (S(t)−S(∞))/(S(0)−S(∞)); depth recovery(t) = (D(t)−D(0))/(D(∞)−D(0)).
Practical: event window 1–300s liquid (longer illiquid); sampling 10ms–1s message or 1–5s quote snapshots; drop first few obs if feed-latency/discreteness dominates; ≥20–50 events per liquidity regime; half-life grid 1–60s liquid / 30s–10min illiquid; separate half-lives for spread, depth, OFI, price impact (need NOT coincide). Exponential = practical reduced form, not universal law. (Citation: arXiv "Limit Order Book Simulations: A Review".)

### 5. Hayashi–Yoshida lead-lag
X observed at t(i,X), Y at t(j,Y). ΔX(i), ΔY(j) returns. Overlap: min(t(i,X),t(j,Y)) > max(t(i−1,X),t(j−1,Y)). [X,Y]̂(T,HY) = Σ_iΣ_j ΔX(i)ΔY(j)·1{overlap} — no common grid forced (JSTOR citation). Lead-lag: Ĉ(XY,HY)(ℓ) = ΣΣ ΔXΔY·1{I(i,X)∩(I(j,Y)+ℓ)≠∅}; ℓ̂ = argmax ρ̂(XY,HY)(ℓ); ρ̂ = Ĉ/√(Ĉ_XX·Ĉ_YY).
Practical: native timestamps + HY directly; tolerance 1–100ms liquid / 0.1–2s slow feeds; lag grid ±5s very-HF / ±1min 1-min bars; increment 1–10ms message / 100ms–1s trade; pre-averaging/sparse sampling for noise. "Do NOT interpret max lag as causal — can reflect latency, async reporting, common-news timing."

## Q-SB6-3: Documented evidence — VERBATIM (key content; no worked arithmetic)
**Summary: "effects exist in the literature, but tradable after-cost versions much narrower than headline backtests."**
**(1) Overnight-gap fade:** g(t)=(O−C(t−1))/C(t−1); fade targets C(t−1). Documented: small non-news gaps often partially revert; large catalyst gaps often continue; unconditional fill probability ≠ positive expectancy; high win rate can coexist with poor expectancy (fat losers). S&P 500: same-session fills ~60–70% descriptive; very small index gaps <0.3% ~80–90%; large E-mini gaps >1.2×14d ATR ~8% same-day (shareplanner.com — descriptive, not academic constants). Practitioner gap-fade test: gross win ~60–70%, ~100–150 opps/yr; edge later shrank to ~5%/yr; "one realistic execution mistake per month could eliminate it"; live drawdowns coincided with other strategies' losses (systematicindividualinvestor.com — NOT peer-reviewed). Academic: most index long-run return overnight; open-to-close after positive overnight move weak/negative — consistent with conditional fade, NOT a proven fade strategy. Costs: R(net) = R(gross) − half-spread×2 − commission − slippage − impact; all-in ~3–15bp very liquid, more individual stocks; 5–10bp gross expectancy → ≈0 or negative net. "Entered during most volatile/widest-spread part of session." Failure: earnings/news gaps, CPI/payrolls/FOMC/geopolitical, breakaway gaps, strong trends, large vs ATR, illiquid/wide-spread names, big opening imbalances, genuine repricing days.
**(2) Jump-filtered gap reversal:** Lee–Mykland identifies information-like discontinuities (individual jumps ↔ earnings/company news; index jumps ↔ market news — Lee & Mykland 2012; ssrn.com) — CLAIM 1 SUPPORTED. CLAIM 2 (removing jumps improves net strategy) NOT generally published across broad US samples. Filter helps if jump days have negative fade expectancy; hurts if biggest profitable fades classified as jumps / auction mechanics misclassified / BV window contaminated / jump followed by partial reversion / trade count collapses / adverse selection on survivors. Correct eval = OOS difference-in-differences Δ(filter) = NetReturn(fade+filter) − NetReturn(fade only), with full per-trade stats by gap size/catalyst/vol regime. "A filter that increases Sharpe by deleting two extreme losing days but leaves only 40 observations is not persuasive." Honest prior: sensible risk-control/segmentation, NOT assumed alpha creation.
**(3) Short-term reversal (Jegadeesh/Lehmann) intraday:** Lehmann (1990) weekly: winners −0.35% to −0.55% next week, losers +0.86% to +1.24%, contrarian spread >2%/month (historical, alphaarchitect.com). Jegadeesh (1990) monthly reversal; decomposition: conventional STR ~0.33%/mo 3-factor alpha (weak), discount-rate-news reversal ~1.34%/mo, within-industry double sort ~1.72%/mo; spread-cost burden ~0.80%/mo (newyorkfed.org). Residual reversal: net ~44bp/mo largest 500, ~54bp/mo largest 100 after costs + 1-day lag; less cost-exposed than naïve (Academia). Intraday: reversal concentrated <~1h; bid/ask/midpoint tests → only first 30-min lag significant; longer-lag transaction-price reversals disappear → "remaining very-short effect = liquidity resiliency, rest largely bid–ask bounce" (arXiv). transaction-price reversal = true reversal + bounce + temporary liquidity. P(0)=ask, P(1)=bid → mechanical negative return w/o efficient-price move. Contamination checks: run on r(trade), r(mid), r(bid), r(ask) separately; quote-midpoint entry/exit; Lee–Ready/aggressor; lagged execution; effective-spread costs; no-trade/stale filters; venue+spread controls. Reversal only in transaction prices = suspect. Failure: wide spreads, small caps, auctions, stale quotes, discreteness, adverse selection, high vol, fast news, quote flickering, signal-to-order latency. "Strongest evidence: residual/midpoint-based strategy surviving realistic spread+slippage+lag+capacity — not that 'reversal exists'."
**(4) Futures–spot / cross-asset lead-lag:** price discovery: futures often lead cash when longer hours/concentrated liquidity/basket/hedgeable (CME order flow highly informative for both futures AND NYSE cash returns in 5-min regressions; futures lead especially pronounced S&P 500 — aeaweb.org). = price discovery, NOT executable signal; 5-min coefficient ≠ residual > costs. ETF vs constituents: ETF may lead (liquid basket), constituents may lead on stock-specific news, futures lead broad moves, constituents lead sector moves. Lead-time hierarchy: 5–30min measurable in liquid data; 1–5min measurable but regime-dependent; 1s event-level but ts-sensitive; 10–100ms needs exchange ts + sync + market access; µs = colocated HFT MM. "ES leads SPY by X ms" claims: demand instrument/venue/ts-field/feed-path/clock/matching-engine-event/trade-vs-quote/lag-grid/sample/cost-model specs. Non-colocated: 5–30min potentially; 1–5s possible selected conditions, competed; sub-second no with retail/cloud; 10s of ms no w/o comparable infra. Slower residuals via basket hedging, creation/redemption, rebalances, async constituents, macro diffusion. Stress test Ĉ(ℓ+d), d∈{0,10,50,100,250,500,1000}ms: vanishes at 50–100ms delay → not monetizable non-colocated. Failure: macro announcements, halts, vol spikes, futures rolls, creation/redemption stress, overnight/premarket, stale/consolidated ts, changing market share, index rebalances, big constituent news, leading-market liquidity loss. SIP fine for minute-level, NOT ms claims.
**(5) Macro-announcement drift:** A. Pre-announcement: pre-FOMC 24h window holds large share of equity excess returns since 1980s — anticipation/risk compensation (newyorkfed.org); higher equity returns on days with inflation/labor/FOMC announcements = risk premium, NOT exploitable directional prediction (sign unknown) (aeaweb.org). B. Immediate: futures/FX move in 100ms–seconds; HF FX study 100ms slices: burst of quote revisions/trades/imbalance/vol in first 30s (ScienceDirect). t(release)→feed→signal→order→fill chain. Needs low-latency econ feed + deterministic parsing + pre-positioned logic; retail calendar notification = too slow for first move. C. Post-announcement: PEAD better established for earnings (Ball & Brown; Bernard & Thomas — wikipedia.org); macro post-reaction: continuation if surprise changes growth/rate expectations, reversal if liquidity vanishes, delayed if hard to interpret, cross-asset propagation; no stable universal number. Latency table: 1–5min drift → sub-second–seconds OK if effect persists; first move → 1–100ms feed-to-order; first quote revisions → venue-native + sync + low-latency routing + colo; 30min/daily premium → ordinary systematic infra OK but must forecast direction/risk; pre-FOMC drift → no ms latency needed, challenge = crowding + risk adjustment. Failure: spread widening, quote withdrawal, partials, gaps through limits, throttling, feed delays, data revisions, time ambiguity, simultaneous releases, wrong-sign interpretation, hedge slippage, IV crush, tail losses. Pre-event: accessible but event-risk/crowding; first-reaction: infrastructure race; post-continuation: accessible over minutes+, unstable, regime-dependent.
**Overall verdict table:** gap fade — fragile, can hit 0/negative after costs. Jump-filtered — plausible risk filter, no general net-return evidence. Intraday reversal — strong transaction-price, much smaller after midpoint correction; bounce = major contaminant. Residual reversal — documented net profits some large-stock impls; capacity/crowding concerns. Futures–spot lead-lag — futures lead price discovery; tradable at multi-minute; sub-second needs specialist infra. Macro drift — pre-FOMC/announcement-day premia documented; pre-event accessible; first-reaction latency-constrained.
**Recurring lesson: net alpha = conditional return − spread − slippage − impact − latency loss − model-selection bias. Standard = positive after realistic execution + midpoint/ts diagnostics + genuinely OOS regimes, NOT statistical significance of raw return.**
