## Q-SB5-1: Formulas + worked example — VERBATIM (key content)

### Formulas (all parameters illustrative examples, not universal defaults)
1. **Donchian:** D_t^U(N) = max_{i=t−N}^{t−1} H_i; D_t^L(N) = min_{i=t−N}^{t−1} L_i; midline = (U+L)/2. Bullish: C_t > D_t^U; bearish: C_t < D_t^L. Intraday: N=10–20 fast; 20–55 common; 50–100 slow. (earn2trade.com)
2. **Keltner:** TR_t = max(H_t−L_t, |H_t−C_{t−1}|, |L_t−C_{t−1}|); ATR_t(N) = (1/N)ΣTR_i (simple). K_t^M = EMA_t(N), α=2/(N+1); K_t^U = K_t^M + m·ATR_t(A); K_t^L = K_t^M − m·ATR_t(A). Break: C_t beyond upper/lower. Ranges: N,A=10–30; common 20/20/m=2; fast 10–14, m=1.5–2; wide 20–30, m=2–3. (stockcharts.com)
3. **Bollinger BW:** μ_t = SMA(N); σ_t = population std; B_t^{U/L} = μ_t ± kσ_t. BW_t = (U−L)/μ_t = 2kσ_t/μ_t; k=2 → 4σ_t/μ_t. Percentile: BWPercentile_t = 100·#{j∈[t−R,t−1]: BW_j ≤ BW_t}/R. Squeeze: percentile ≤ p (commonly 5/10/20). Ranges: N=15–30, k=1.5–2.5, R=50–250 bars, p=5–20%.
4. **Initial balance:** 5-min bars → first hour = 12 bars. IBH = max H over first 12; IBL = min L; IBR = IBH−IBL. Expansion: C_t > IBH+δ (bearish: < IBL−δ); δ = q·ATR_t(A): δ=0 any close outside; q=0.05–0.25 small buffer; 0.25–0.50 strong; IB = 30/60/90 min by market.
5. **Stretched z:** z_t = (C_t − μ_t(N))/σ_t(N). Thresholds: 1.5 frequent; 2.0 conventional; 2.5–3.0 highly extended. Return variant: r_t(M) = ln(C_t/C_{t−M}), z of r_t(M).

## Q-SB5-3: Documented evidence — VERBATIM (key content; no worked arithmetic to check)
**Short version:** Donchian/ATR breakouts = plausible trend-following payoff, intraday results highly regime-dependent, commonly disappear after whipsaws/spread/slippage/session effects. Bollinger squeeze = volatility-state timing, NOT self-contained directional edge. Gap-and-go/fade = no stable universal continuation %; answer changes with gap size, news, premarket volume, trend, liquidity, "continue" definition. Heston–Korajczyk–Sadka = documents intraday periodicity/continuation at matched half-hour intervals (persists ≥40 trading days), NOT a simple retail "first 30 min predicts last 30 min" rule. Auction imbalance = predictive info exists (esp. near open/close), but tradable edge concentrated with direct low-latency venue access + auction order types.
**(1) Donchian/ATR:** strongest evidence = trend-following positive convexity when trends persist; failure = chop (repeated false breakouts; practitioner sources ID range-bound as principal failure — altrady.com). Recent BTC daily Donchian/ATR study: positive but highly cost/param/regime-sensitive — NOT evidence of durable intraday US-equity edge (ssrn.com). After-cost: gross few bps needs exceptional liquidity/passive execution/regime conditioning/controlled turnover. Report: gross, spread-crossing, vol-scaled impact, delayed-entry, capacity by liquidity, trending vs range-bound separately. Regime diagnostic: HTF trend slope, ADX, realized-vol expansion, breadth, VWAP distance, index trend, prior-day range/gap. Verdict: reasonable hypothesis, not documented universal intraday alpha; edge in regime selection + execution, not the channel formula.
**(2) Bollinger squeeze:** defensible = volatility-timing: low vol → vol clusters → transitions higher; DIRECTION NOT determined by compression. Common setup = Bollinger compression + Donchian breakout (low-vol before a move) — a trading hypothesis, not a universal after-cost premium (forextraininggroup.com). Failure: dead low-liquidity stocks, news-spike expansions, against-HTF-trend breaks, immediate range return, signal defined after the move, correlated triggers/crowding. Test: squeeze-only vs squeeze+breakout vs squeeze+trend-filter vs squeeze+volume/imbalance; question = improved RISK-ADJUSTED AFTER-COST returns or merely predicted realized-vol increase.
**(3) Gap-and-go/fade:** G = (O_t − C_{t−1})/C_{t−1}; "continuation" has multiple definitions (O+λG, close above OR, same side of prior close, close farther than open, MFE>MAE) → materially different base rates. NO stable universal continuation fraction. Continuation more plausible: earnings/material news, high premarket volume, large market/sector move, strong OR break, persistent OFI, gap with HTF trend. Fade more plausible: small, no-news, overnight index noise, extended vs ATR, weak opening volume, immediate rejection. After-cost: fades = high win rate but poor loss distribution (few news gaps = large losses); goes = positive skew, poor hit rate, big entry slippage. Compare E[return] = P(win)E[win] − P(loss)E[loss] − costs, not P(continue) vs P(fade). Stratify: gap size in ATR, news/no-news, premarket volume, opening spread, market direction, liquidity, prior-day trend, 5/15/30-min range break.
**(4) HKS:** half-hour cross-sectional periodicity, continuation at exact multiples of a trading day, ≥40 trading days; short-term reversal from liquidity imbalance/bid-ask bounce (ssrn.com). Pronounced in first/last half-hours (academia.edu). US stocks, post-decimalization intraday; NOT futures/FX-only, NOT single-stock time-series. Effect size: no portable "first-30-min predicts last-30-min by X bps" — depends on formation/holding/universe/weighting/rebalancing/spread treatment/signal-to-execution delay. 2025 follow-up: open+close periodicities persist OOS; open pattern ≈ VWAP-like trading, close ≈ MOC activity; institutional proxies explain all open+midday periodicity, up to 30% of close (northwestern.edu). Paper: timing trades can save ≈ effective spread — NOT a claimed large standalone alpha. Tradability: best as portfolio-rebalance/execution-timing effect, cross-sectional rank feature, intraday-strategy enhancement. Verdict: documented periodicity; not a large standalone after-cost first→last-30min rule.
**(5) Auction imbalance:** fields = paired shares, buy/sell imbalance, indicative clearing price, reference price, auction status, venue, ts, updates/corrections. Intuition: large buy imbalance + rising indicative price = unresolved demand → price pressure. Documented informational content in microstructure literature; used by exchanges/pros. NOT a guaranteed directional signal. Stronger: near auction, large vs normal volume, consistent indicative-price move, differs open vs close, by venue/security; weaker after dissemination. Tradable hierarchy: (a) direct auction participants (members/sponsored, low-latency, auction order types, react in cutoff window); (b) institutional API users (normalized feed + broker, latency/routing/venue/cutoff/order-type/fees matter); (c) retail (delayed/normalized imbalance, MOO/LOO/MOC/LOC via broker — no first-arrival access, queue priority, full venue coverage, identical ts, post-cutoff cancel, few-bps post-auction capture). Failure: pre-auction cancellations, indicative-price instability, cross-venue fragmentation, price limits/vol interruptions, news in window, stale snapshots, queue disadvantage, spread/impact > predicted move. Test MUST use message SEQUENCE ("what was known at t?") — final imbalance predicting earlier trade = look-ahead bias.
**Research-value ranking:** Donchian/ATR — moderate broad trend-following, weak universal intraday / edge in regimes / fail: chop+costs. Squeeze — better vol-transition evidence than direction / vol timing / expansion without direction. Gap-and-go/fade — conditional, no stable base rate / news+volume+flow+regime / tail losses+slippage. HKS periodicity — peer-reviewed cross-sectional evidence / institutional trading patterns / costs+crowding+implementation. Auction imbalance — strong microstructure rationale + venue data / unresolved auction supply-demand / latency+cancel+access+venue rules.
**Best candidates:** (1) regime-conditioned Donchian/ATR; (2) squeeze as vol-transition filter; (3) news/volume/OR-conditioned gap classification; (4) HKS features for ranking/execution timing; (5) auction imbalance with event-time data + venue-aware execution. "For all five, the decisive test is a point-in-time replay with realistic fills, spread crossing, market impact, borrow constraints, auction cutoffs, and delisted securities — not a close-to-close or next-bar backtest with vendor-adjusted historical data."
