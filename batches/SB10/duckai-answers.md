## Q-SB10-1: Formulas + worked examples — VERBATIM (key content)

### 1. PIN (Easley–O'Hara)
Day t: B_t buyer-initiated, S_t seller-initiated trades. α = P(info event); δ = P(good news | event); μ = informed arrival rate; ε_b, ε_s = uninformed buy/sell arrival rates.
Three Poisson states: no news (1−α): B~Po(ε_b), S~Po(ε_s); good news (αδ): B~Po(μ+ε_b), S~Po(ε_s); bad news (α(1−δ)): B~Po(ε_b), S~Po(μ+ε_s).
**PIN = αμ/(αμ+ε_b+ε_s)**; if ε_b=ε_s=ε: PIN = αμ/(αμ+2ε).
Likelihood L_t(θ) = αδ·Po(B|μ+ε_b)·Po(S|ε_s) + α(1−δ)·Po(B|ε_b)·Po(S|μ+ε_s) + (1−α)·Po(B|ε_b)·Po(S|ε_s). ℓ(θ) = Σ_t log L_t; θ=(α,δ,ε_b,ε_s,μ); 0<α,δ<1; ε,μ>0. Compute with log-sum-exp; later factorized likelihoods reduce underflow/boundary bias [citations: FRDS, JBF 2012 via repec].
Procedure: (1) classify trade direction (exchange aggressor flags; else Lee–Ready/quote-midpoint); (2) aggregate to DAILY counts (standard PIN = counts, not dollars); (3) window T: illustrative 60–120d baseline; 20–60d fast research; 120–250d robustness; (4) constrained MLE from multiple starts (α∈{0.2,0.4,0.6,0.8}, δ∈{0.25,0.5,0.75}, μ from high-vs-low-activity-day difference, ε from median daily counts); (5) keep max log-lik; (6) reject/flag boundary solutions, implausible μ, start/window sensitivity; (7) compute PIN.

**[VERIFIED] Worked example A:** 10-day B/S: (90,40),(40,90),(42,38),(39,41),(40,40),(88,42),(41,87),(38,42),(40,39),(41,40). B̄ = 499/10 = 49.9 ✓; S̄ = 49.9 ✓. Moment-matched (illustrative, NOT optimizer output): α̂=0.40, δ̂=0.50, μ̂=50, ε̂_b=ε̂_s=40. Day-1 likelihood terms match Poisson means (good-news B~Po(90)/S~Po(40); bad-news B~Po(40)/S~Po(90); no-news both Po(40)) ✓. **PIN = 0.40×50/(0.40×50+40+40) = 20/100 = 0.20 = 20% ✓.**

### 2. Crypto funding-rate / basis cash-and-carry
N = notional; f_j = funding rate in interval j (length h_j hours); H = holding hours; q = H/h equivalent intervals. Payment F_j = N_j f_j. Positive funding: longs pay shorts; delta-neutral carry (long spot + short perp) RECEIVES ≈ N_j f_j [coinbase.com]. Annualization: **f_ann ≈ (8760/h)·f̄** (simple; 8h → 1,095×f̄); compound f_ann = (1+f̄)^{8760/h}−1 (or product over variable f_j). Simple = more transparent; NOT guaranteed yield — funding can flip sign. Gross P&L: Π_gross ≈ Σ N_j f_j + Π_basis; Π_basis = (S_1−S_0)+(P_0−P_1) per matched $1; 0 if basis unchanged. Net: Π_net = Π_gross − N_spot(c_entry+c_exit) − N_perp(c_entry+c_exit) − borrow/margin/slippage. Illustrative: funding hourly/4h/8h; hold 24h–30d; crypto annualization = 365 days; fees 0.01–0.10%/leg; slippage 0.00–0.20%/leg normal; monitor basis widening.
**[VERIFIED] Worked example B:** $10k long spot + $10k short perp; 8h funding rates 0.020%, 0.015%, 0.025%. Funding = 10,000×0.00060 = **$6.00 ✓**; R_24h = 0.060% ✓; f_ann = 0.00060×365 = **21.9% ✓** (simple convention as stated); fees 4×10,000×0.0004 = **$16.00 ✓**; Π_net = −$10.00, −0.10% ✓. "Gross 21.9% annualized loses money over 1 day — evaluate funding strategies on realized rates, basis, fees, slippage, holding period, not displayed funding rate alone."

### 3. Google Trends ASVI
SVI_t = Google Trends normalized index (0–100, relative to selected period/region). **ASVI_t = (SVI_t − SVĪ_{t,W})/s_{t,W}** (rolling mean + sample sd, W−1 denominator); equiv. (SVI_t − μ̄_{R_t})/σ̂_{R_t} over reference period R_t. Positive = unusually high attention. Procedure: download SVI (ticker/company name, weekly/daily); W = 8/13/26 weeks weekly or 30/60/90 days daily (illustrative); rolling mean+sd; standardize; winsorize e.g. ±5; align to trading calendar (weekends/holidays); optional cross-sectional demeaning. **Key practical issue: Trends values are relative and change when queries are downloaded separately — use common comparison term or joint download for cross-sectional comparability.**

### 4. PEAD intraday leg (SUE sorts)
UE_{i,q} = EPS_{i,q} − E_{i,q}; **SUE_{i,q} = UE_{i,q}/σ(UE_{i,q})** (σ from prior 8–12 quarters, illustrative). Seasonal random-walk: E = EPS_{i,q−4}; SUE = (EPS_{i,q}−EPS_{i,q−4})/σ_{i,q}. Analyst version: EPS − median forecast, scaled by historical forecast-error sd. Intraday leg: τ = announcement timestamp; R_{i,τ_0,τ_1} = ln(P_{i,τ_1}/P_{i,τ_0^−}); AR = R − R_market. Before open → τ_0 = opening auction/first tradable quote; intraday → first quote after timestamp; after close → next open or first 15/30-min return. SUE long-short: R^{PEAD}_{τ_0,τ_1} = mean(H)−mean(L), H/L = high/low SUE groups. Illustrative: quintile/decile sorts; windows announcement-to-close, first 30/60 min, announcement-to-next-open; market/factor/industry benchmarks; min-price/min-volume screens, exclude penny stocks.
Sources: frds.io (PIN); ideas.repec.org (JBF 2012); coinbase.com; kraken.com; metamask.io; quantconnect.com (SUE); sciencedirect.com (PEAD); pmc.ncbi (ASVI); wikipedia (PEAD); quantpedia.com.

## Q-SB10-3: Documented evidence — VERBATIM (key content; no worked trading P&L to verify)

**Bottom line:** PIN = slow adverse-selection/liquidity-risk variable, NOT real-time signal. Stealth = trade size contains info, but size bucket market/venue-specific; fixed "medium trade" rule fragile. Crypto funding/liquidations = crowding + tail-risk detection; funding reversal NOT a timing oracle; liquidation data incomplete. ASVI = predicted short-horizon attention/price pressure w/ later reversal; expect DECAY after publication/adoption. Social = can contain short-horizon info, but noise/reflexivity/bots/promotion/API changes → broad averages unreliable. PEAD = economically documented; easiest adjustment occurs quickly; intraday needs timestamp quality + low latency + low costs.
**(1) PIN:** mechanism: higher info-asymmetry → wider spreads / larger adverse-selection component. Easley–O'Hara model; Easley–Hvidkjaer–O'Hara documented PIN–expected-returns link; later work links PIN to spreads/adverse selection. Useful interp: PIN_t = expected informed arrivals / expected total arrivals. Higher PIN → larger adverse-selection spreads, greater price impact, more post-trade variance, higher required returns (esp. where asymmetry hard to diversify). **High PIN ≠ positive return — high-PIN stock can realize negative returns when informed side sells or news is bad.** Real-time honesty: canonical PIN NOT naturally real-time — estimated over tens/hundreds of days. Difficulties: (a) observes signed trades, not information sets; (b) signing errors; (c) local maxima/boundary solutions; (d) weak identification in short windows; (e) HF estimation overflow/float problems; (f) stationary-window lags when arrival rates time-vary. Documented: naïve likelihood overflow; factorized likelihoods reduce truncation error/bias [Lin & Ke show computing restrictions → downward-biased PIN]. Intraday PIN extensions (U-shaped intraday pattern) = extension of structural model, NOT evidence PIN observable instantly from minutes of data. Defensible: estimate monthly/quarterly; condition spreads/impact/position size/holding period; combine w/ liquidity+vol; never present daily PIN change as clean info shock. Real-time signal = order-flow imbalance, VPIN-like toxicity, signed volume, spread decomposition, quote-based predictors — NOT daily PIN. Failure: sparse trading, bad classification, market-structure changes, time-varying news rates, multiple informed-event types, algo splitting, crisis/list/delist windows. **"After costs, PIN is more credible as a risk-control or cross-sectional conditioning variable than as a standalone alpha signal."**
**(2) Stealth trading (Barclay–Warner):** hypothesis: informed traders split into medium-size trades (small = unprofitable after costs; large = reveal info). Audit-trail evidence attributes disproportionate medium-size price impact to informed (not uninformed) trading. Core stat: price-impact share_k = Σ_{t∈k}ΔP_t/ΣΔP_t vs trade share N_k/N and volume share V_k/V; interesting when impact share >> trade/volume share. Modern relevance: orders still split (fragmented markets, dark pools, algos, crypto visible books, single-large-order-reveals-info names). **BUT "medium" bucket NOT portable — $25k = large in one small-cap, noise in a large-cap.** Calibrate buckets to median $ volume, quoted depth, vol, tick, cap, venue, time of day. Pure order-driven market results differ from dealer-market findings — size–impact is market-structure-dependent. Modern impl: PI_q = Σ_{size∈q}|r_{t,t+Δ}|/Σ|r| over size percentiles (1–5, 5–25, 25–75, 75–95, top 5%). Use as CONDITIONAL EXECUTION signal: unusual medium-size impact → informed/urgent flow; low impact → replenishing liquidity/absorption; signed > absolute for direction. Failure: stale buckets, different venue fragmentation, large orders via many small prints, news moves all sizes, widened spreads mistaken for info, signal measured after price moved. **"More likely to improve execution timing and market-impact models than to generate standalone directional alpha."**
**(3) Crypto funding reversal + liquidation cascades:** extreme funding = crowded positioning; contrarian r_{t+h} = a + b·z(f_t) + c·z(ΔOI_t) + d·z(LIQ_t) + ε; reversal expects b<0 at extremes — ONLY conditionally. **"Funding can remain extreme during strong trends; fading extreme funding unconditionally is a reliable way to lose money."** Funding spreads time-varying, mean-reverting over multi-day horizons; strongest reversal around stress episodes. Cascade: ΔP → margin breach → forced flow → ΔP_{t+1}; nonlinear (crowded stable for weeks, then huge minutes-long move at clustered liquidation thresholds). Honest returns: funding carry positive before costs; reversal can perform strongly in stress; distribution highly skewed; small frequent gains can be wiped by basis widening, hedge-leg liquidation, exchange failure. R_net = R_funding + R_basis − R_fees − R_slippage − R_borrow − R_liquidation/financing. **CENSORED-DATA CAVEAT: public liquidation feeds = reported, venue-specific, size-thresholded subset — generally a LOWER BOUND, not total forced flow.** Strategies calibrated on reported liquidations underestimate tail risk. Failure: funding stays extreme in trend, spot/perp hedge breaks, short leg liquidated despite hedge, caps/formulas change, exchange outages, spreads/slippage explode in cascade, feed misses largest events. **"More defensible use is regime detection and leverage reduction, not unconditional contrarian trading."**
**(4) ASVI (Da–Engelberg–Gao):** Google search frequency = retail attention; abnormal SV predicts short-horizon returns — attention-driven price pressure then reversal. Stylized: β_h = ∂E[r_{t+h}]/∂ASVI_t; β_h>0 short horizons (days–~2 weeks); Σ later β_h<0 if reversal. **Decay honesty: do NOT carry original magnitude forward — Trends widely used, search variables known, query/normalization changed, attention shocks rapidly arbitraged, large-caps incorporate faster, searches can reflect already-incorporated news.** Modern expectation: smaller, heterogeneous, conditional — concentrated in neglected/small stocks, ambiguous tickers, retail-heavy names, non-news attention shocks, high-vol events. Later methodology: current SVI vs long historical mean EXCLUDING most recent data (avoid look-ahead). Failure: generic-word tickers, nonfinancial search spikes, search follows price, stock already in major news, Google sampling/normalization changes, look-ahead samples, 2-week horizon w/o momentum/volume/news controls. **"More promising as cross-sectional attention filter or event-confirmation variable than standalone signal."**
**(5) Social sentiment:** credible short-horizon info in Twitter/stock-board studies, esp. around attention shocks. But observations = mixed: informed commentary, genuine retail, jokes/memes, reposts, coordinated promotion, post-return emotion, bots/duplicates, wrong-ticker discussion. Recent research: noisy + vulnerable to manipulation (pump campaigns, coordinated inauthentic behavior). Defensible signal: Σ_{u∈U_t} w_u q_u Sentiment(post_u) (w = user-quality/predictive weight; q = relevance/originality/bot adjustment) + unique-author counts, original-post share, dispersion, velocity, engagement concentration, bot/duplicate penalties, lead-vs-follow test. Manipulation diagnostic: Concentration_t = Σ_u(posts_{u,t}/posts_t)² — spike from few accounts ≠ spike from many independents. Failure: bot-dominated, platform API/ranking changes, coordinated campaigns, sarcasm, data arrives after move, thin liquidity, backtests on deleted/edited posts unavailable in real time. **Most defensible: short-horizon attention/flow variable, volatility/crowding indicator, combined w/ price/volume/news/order-flow. Least defensible: "bullish sentiment = buy."**
**(6) PEAD intraday:** tendency for returns to continue in earnings-surprise direction. SUE_i = (EPS_i−E[EPS_i])/σ(...); long high-SUE / short low-SUE. Classic evidence economically large cross-sectionally, but magnitude depends on: SUE definition, forecast source, formation, timing, microcap exclusions, cost assumptions, period, measurement window. **Intraday timing:** before open → opening auction/first quote; intraday → minutes; after close → next session/opening auction; next-day/multi-day PEAD = residual drift, smaller, harder to capture. Intraday leg = 4 components: immediate reaction, opening-auction adjustment, early-session continuation/reversal, slower drift. First component MOST latency-sensitive: delay of minutes = trading a different (worse) signal than seconds. Magnitude honesty: no universal intraday number — depends on spread, auction slippage, impact, short constraints, borrow fees, halts, delayed detection, surprise revisions, institutional competition. Report R_net = R_high-SUE − R_low-SUE − 2c_entry − 2c_exit − impact − borrow. "Do not infer tradability from close-to-close event-study returns if implementation enters intraday." Required latency: announcement-to-close needs timestamp precision ≥ seconds (ideally ms), immediate release detection, trades+quotes feed, identifiable first tradable quote, known release class (pre/intra/post). First-30-min: minutes of delay materially changes trade; lower-freq drift relaxes latency but execution costs dominate. Failure: expectations already incorporated, stale/noisy forecasts, misclassified times, hard-to-borrow, illiquid/halted, trading after initial adjustment, small-firm concentration w/ large costs, survivorship bias. **"More likely to work in carefully screened liquid universe with precise timestamps than as broad cross-sectional screen."**
**Comparative after-cost assessment:** PIN — best role: info-risk/liquidity conditioning / horizon monthly→quarterly / risk: model ID + classification / expectation: risk control, not alpha. Stealth — best: execution + informed-flow detection / minutes→days / risk: buckets + fragmentation / expectation: execution improvement. Funding/liquidation — best: crowding + tail-risk regime / hours→weeks / risk: basis + feed censorship / expectation: regime detection. ASVI — best: attention shock + price-pressure filter / days→~2 weeks + reversal / risk: normalization + decay / expectation: conditional filter. Social — best: short-horizon attention/flow input / minutes→days / risk: bots + manipulation + reflexivity / expectation: weak standalone. PEAD intraday — best: event-driven directional leg / minutes→days / risk: latency + auction execution + costs / expectation: screened universe only.
**Discipline: "separate documented association from tradable net return. A signal can be statistically real and economically uninteresting after costs."**
