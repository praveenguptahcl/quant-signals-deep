## Q-SB4-1: Formulas + worked example — VERBATIM (key content)

### 1. Multi-level OFI / integrated OFI (Cont–Cucuringu–Zhang)
Level-k event contribution: e_{k,t} = 1{P^b_{k,t} ≥ P^b_{k,t−1}}Q^b_{k,t} − 1{P^b_{k,t} ≤ P^b_{k,t−1}}Q^b_{k,t−1} − 1{P^a_{k,t} ≤ P^a_{k,t−1}}Q^a_{k,t} + 1{P^a_{k,t} ≥ P^a_{k,t−1}}Q^a_{k,t−1}. Equal-price cases intentionally included in both indicators (bid unchanged → Q^b_{k,t} − Q^b_{k,t−1}).
Bucket B: OFI_{k,B} = Σ_{t∈B} e_{k,t}; OFI_B = [OFI_{1,B} … OFI_{L,B}]ᵀ.
Weighted: OFI^{(w)}_B = Σ_k w_k OFI_{k,B} (equal / inverse-depth / regression weights).
Integrated OFI (Cont–Cucuringu–Zhang): iOFI_B = v_1ᵀ(OFI_B − μ); v_1 = unit eigenvector of largest eigenvalue of Cov(OFI_B); sign chosen so +iOFI = buying pressure. Motivation: level OFIs strongly correlated; PC1 captures common variation.
Price-impact regression: r_B = α + β·iOFI_B + ε_B (r_B = contemporaneous mid-price return).
Practical: L=1–5 robust for ordinary equities; 5–10 liquid reliably-populated books; >10 only with depth + regularization (severe collinearity). Buckets: 100–1,000 updates or 100ms–5s (shorter for very liquid, longer for thin). PCA loadings on rolling 1–20d window; standardize OFI levels if units differ. Citations: ssrn.com, researchgate.net ("Cross-Impact of Order Flow Imbalance in Equity Markets").

### 2. Lee–Ready + BVC
Lee–Ready: m_i = (a_i+b_i)/2 (quote usually lagged slightly). Quote rule: d^Q_i = +1 if p_i > m_i; −1 if p_i < m_i; 0 if p_i = m_i. Midpoint → tick rule: j<i most recent p_j ≠ p_i: d^T_i = +1 if p_i > p_j else −1. d_i = quote rule, or tick rule at midpoint. +1 = buyer-initiated. Signed imbalance: OFI^{trade}_B = Σ_{i∈B} d_i v_i.
BVC: volume bars b=1..M, target volume V*. V_b = bar volume; p_{b,o}, p_{b,c} = bar open/close. z_b = (p_{b,c} − p_{b,o})/σ_p. F̂_b = Φ(z_b) (std-normal CDF). V̂^{buy}_b = V_b Φ(z_b); V̂^{sell}_b = V_b(1−Φ(z_b)); BVC_b = V_b(2Φ(z_b)−1). BVC allocates bar volume probabilistically — does NOT classify individual trades.
Practical: V* = 50–500 median trades or 0.1–1% daily volume; liquid equities 1,000–100,000 shares/bar; σ_p window 50–500 bars; cap z_b ≈ ±3; Lee–Ready when trade-level labels needed, BVC when only aggregated data available.

### 3. Kyle's lambda by regression
Δp_t = α + λq_t + ε_t; q_t = d_t v_t signed volume. λ̂ = Σ(q_t−q̄)(Δp_t−Δp̄)/Σ(q_t−q̄)² (with intercept); λ̂_0 = Σq_tΔp_t/Σq_t² (without). Cross-instrument: r_t = α + λ(q_t/ADV) + ε_t.
Practical: rolling 500–10,000 trades HF; intraday bars 30–240min; daily 20–120d; mid-price changes preferred; report units explicitly ($/share per share traded, or bps per fraction of DV); robust/Newey–West SEs (serially correlated flow).

### 4. Roll implied spread
γ̂_1 = Cov(Δp_t, Δp_{t−1}); model: γ_1 = −s²/4 → ŝ = 2√(−γ̂_1), γ̂_1<0. Sample: γ̂_1 = 1/(T−2)Σ_{t=2}^{T−1}(Δp_t−Δp̄)(Δp_{t−1}−Δp̄). If γ̂_1 ≥ 0 → no real spread: report undefined / lengthen window / corrected estimator (drift, discreteness, asymmetry).
Practical: window 100–5,000 transactions; 1–15min bars or regular intervals; require clearly negative autocov + adequate obs.

### 5. Hawkes self-exciting order-flow intensity
Bivariate exponential: λ_i(t) = μ_i + Σ_{j∈{+,−}} ∫_0^t α_ij exp[−β_ij(t−s)] dN_j(s), i∈{+,−}. Kernel φ_ij(u) = α_ij e^{−β_ij u} 1{u>0}; integrated K_ij = α_ij/β_ij. Stationarity: ρ(K) < 1; 1-D: α/β < 1. Signed spec: λ_±(t) = μ_± + Σ_j ∫ α_{±j} e^{−β_{±j}(t−s)} dN_j(s).
Practical: kernel half-life h = ln2/β; 10ms–1s very-HF, 1–60s lower-freq flow; 1–3 exponentials if single decay too restrictive; 10⁴–10⁶ events; branching ratio <0.8–0.95 for stability (theoretical <1); separate buy/sell processes for asymmetry.

## Q-SB4-3: Documented evidence — VERBATIM (key content)
**Lead warning: "stronger evidence for short-horizon statistical predictability than for after-cost tradability. Treating improved R²/accuracy/forecast loss as net execution profit is the main mistake."**
**(1) Multi-level vs touch-only OFI (Xu–Gould–Howison):** six liquid Nasdaq stocks, 2016 LOBSTER data; OOS fit improves with more levels for ALL six. Magnitudes: small-tick ≈ **15–30% lower OOS RMSE** (10-level vs 1-level); large-tick ≈ **65–75% lower** (Oracle, Cisco, Micron big gains; Amazon, Tesla, Netflix smaller). Regularized estimation required (collinearity; naive OLS obscures value). **These are RMSE reductions, NOT returns/profits. [FLAG: cross-check %s against paper's own results tables before quoting downstream — unverified from chat.]** After-cost: target is contemporaneous/short-interval mid-price change; hurdle = E[gross move] > spread + fees + slippage + impact. "Supports incremental information in deeper book flow, not a universal after-cost edge." Failure: small tick, fast replenishment/spoof, news shocks, delayed/dropped quotes, consolidated feed, long horizons, liquidity-regime shift. MBP aggregates size by level — no queue position/order identity. Citations: arXiv, repec.org, alphaxiv.org ("Multi-Level Order-Flow Imbalance in a Limit Order Book").
**(2) Lee–Ready vs BVC accuracy:** "No single modern instrument-independent accuracy number honestly quotable." LR: older studies ~80–90% for ordinary trades; worse for midpoints, delayed quotes, fast markets, inside-spread trades. Key limit = ERROR CONCENTRATION: misclassification clusters exactly when signal most active; 85% individual accuracy can still bias HF imbalance seriously. Fails: fast markets, stale quotes, midpoints, odd lots, off-exchange, locked/crossed. BVC: NOT an individual-trade classifier — asking per-trade accuracy is a category error; evaluate aggregate buy-volume error or bar-level imbalance prediction. Less informative than exchange-level signs for precise direction; unstable with tiny/poor-vol bars, multi-regime bars, hidden/off-exchange activity. After-cost: relevant quantity = E[d_t Δm_{t+h}] − E[spread] − E[fees] − E[slippage], NOT accuracy. Modern equities: direct aggressor flag or exchange trade+quote feed preferred when accuracy matters.
**(3) Kyle lambda / Amihud as slippage predictors:** λ = local impact coefficient, not full cost forecast; needs correct signing, horizon match, mid-price regression, normalized volume, stable regime, small-enough Q (impact̂ ≈ λ̂Q first-order only; large orders nonlinear; IS = spread + temp + permanent impact + delay + fees). Better as relative liquidity ranking/conditioning variable. Amihud ILLIQ_d = |r_d|/DollarVolume_d: cross-sectional/medium-horizon comparisons; too coarse for specific intraday orders (vol, news, market moves, seasonality, close-measurement, mkt cap, aggregation). "No universal '1σ Amihud → X bps slippage' statement." Combine with spread, depth, vol, participation, time-of-day. Failure: news/jumps, auctions, thin names, large participation, nonlinear impact, tick changes, hidden liquidity, spread widening, stale quotes, daily-Amihud-for-intraday.
**(4) Hawkes order flow:** documents clustering (self/cross excitation, buy/sell asymmetry); improves probabilistic forecasts of near-term event/price-move risk vs unconditional/memoryless baseline — WEAKER claim than a fee-adjusted strategy. Edge via buy/sell clustering, persistence, cancellation bursts, excitation asymmetry, queue imbalance; concentrated ms–seconds, decays fast. Fee survival: **no general documented result**; profitability consumed by half-spread, queue, fees, latency, missed fills, adverse selection, impact. Test: net PnL = MTM − fees − spread − impact − unfilled opportunity cost. Significant direction accuracy ≠ positive net PnL if move < 1 tick or spread crossed. Failure: macro announcements, auctions, halts, vol regime changes, feed changes, symbol news, near-critical branching, nonstationarity, trade-only Hawkes ≠ full book model (no queue depletion/cancellation/hidden liquidity unless modeled).
**(5) Retail/odd-lot flow:** no blanket "informed/uninformed". Retail heterogeneous: liquidity-taking/attention-driven, contrarian, noise, informed around earnings/news/specialized, liquidity-providing to institutions. Predictive in some cross-sectional/event settings; sign/persistence non-universal. Odd lots NOT automatically noise: retail MOs, fractional shares, algo slices, high-priced stocks (standard lots economically arbitrary), inside-NBBO prints — may carry effective-price-path info (esp. high-priced/fragmented). Measurement problems: historic SIP odd-lot quote treatment, no protected-NBBO update, ambiguous direction, venue fragmentation, volume-definition changes. After-cost: high turnover + short holds → spread crossing, adverse selection, queue priority, price improvement, routing delay, partials, odd-lot constraints eat gross edge. Midpoint-marked evaluation with marketable-order implementation = overstated. Failure: size-only retail definition, high-priced-stock slices looking retail, odd-lot quote omission/timestamping, splits/corp actions, news shocks, assuming uniform small-trade informativeness, training on zero-commission/meme era and applying elsewhere.
**Bottom-line table:** MLOFI — stronger OOS fit (15–30% / 65–75% RMSE reduction) / promising, not established universally profitable. Lee–Ready — ~80–90% favorable settings / depends on quote alignment + turnover. BVC — aggregate estimator, not per-trade accuracy / coarse flow, weak for execution. Kyle λ — local impact coeff / conditioning variable, not slippage forecast. Amihud — medium-horizon illiquidity / too coarse intraday. Hawkes — better short-horizon forecasts / fee survival strategy+fill-dependent, not universal. Retail/odd-lot — conditional heterogeneous / overfit-prone, spread-vulnerable.
**Robust design: report BOTH OOS forecast improvement AND net implementation performance after spread/fees/latency/realistic fills. Without the second, call them predictive features, not demonstrated edges.**
