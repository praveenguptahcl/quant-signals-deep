## Q-SB3-1: Procedures + worked example — VERBATIM (key content)

### 1. Gatev–Goetzmann–Rouwenhorst distance pairs
Formation: X_{i,t} = P_{i,t}/P_{i,0} (normalized price path, t=1..T_F). Pair score D_{A,B} = Σ_t (X_{A,t} − X_{B,t})². Rank ascending; select lowest-distance pairs subject to liquidity/sector/borrow/concentration constraints + min dollar volume, short availability, corp-action cleanliness, min correlation (commonly 0.7–0.9), validation-period stability. GGR used ~6-month formation + 6-month trading. Practical ranges: formation 60–252d; trading 20–126d; pairs 10–100; re-select monthly–quarterly; entry 1.5–2.5σ; exit 0–0.5σ; max hold 10–60d.
Trading rule: d_t = X_{A,t} − X_{B,t}; μ_d, σ_d from formation; z_t = (d_t − μ_d)/σ_d. If z_t ≤ −z_entry: buy A sell B; if z_t ≥ z_entry: sell A buy B; close at |z_t| ≤ z_exit or zero-cross; stop at max hold or adverse threshold. GGR = normalized-price distance (NOT regression hedge ratio); modern impls often add dollar/vol neutrality. Ref: GGR "Pairs Trading: Performance of a Relative-Value Arbitrage Rule," RFS 2006 (working paper 1999) (repec.org).
**All parameter estimates must use info strictly before the trading/validation interval.**

### 2. Engle–Granger cointegration z-score pairs
Step 1 — hedge ratio: P_t^A = α + βP_t^B + ε_t → spread S_t = P_t^A − α̂ − β̂P_t^B. Long spread = long 1 unit A, short β̂ units B (and reverse). Dollar neutrality: q_A·P_t^A ≈ q_B·P_t^B; vol neutrality via per-leg vol scaling.
Step 2 — ADF: ΔS_t = γS_{t−1} + Σ_{j=1}^{p} φ_j ΔS_{t−j} + u_t; H0: γ=0 (no cointegration) vs H1: γ<0. Use Engle–Granger critical values, NOT ordinary t-dist.
Step 3 — z-score: μ_{S,t}(L), σ_{S,t}(L) rolling; z_t = (S_t − μ)/σ. Practical: formation 126–504d; z-window L 20–120d; entry/exit/stop threshold cells didn't render — stated sensible default: T_F=252, L=60, z_entry=2, z_exit=0, z_stop=3; max hold 10–60d; ADF lags p 0–5 (AIC/BIC); re-estimate daily–monthly. Regression direction matters (A-on-B ≠ B-on-A); choose economically or test both with pre-specified rule. Ref: Engle & Granger, Econometrica 1987 (via portfoliooptimizationbook.com §15.4).

### 3. Two-state Gaussian HMM for intraday regimes
r_t = 5-min log returns; Z_t ∈ {1,2}. Emission: r_t|Z_t=k ~ N(μ_k, σ_k²), typically σ_calm < σ_volatile. Transition A_{ij} = Pr(Z_t=j|Z_{t−1}=i); A = [p11, 1−p11; 1−p22, p22]. **Expected duration E[D_i] = 1/(1 − A_{ii})** [page rendered without fraction — corrected]. Estimation: Baum–Welch EM; forward recursion α_t(j) = f(r_t|Z_t=j)·Σ_i α_{t−1}(i)A_{ij}; filtered Pr(Z_t=k|r_{1:t}) = α_t(k)/Σ_j α_t(j). USE FILTERED (not smoothed) FOR LIVE SIGNALS — smoothed uses future data. Practical: bars 1–30 min; train 20–120d; 2 states (occasionally 3); ≥1,000–5,000 bars; vol-regime trigger 0.6–0.8; min persistence 3–20 bars; refit daily–weekly; diagonal/scalar covariance. Example rule: normal if Pr(calm)>0.7; halve size if Pr(volatile)>0.7; suspend entries if Pr(volatile)>0.8. Multiple random inits (EM local maxima); label states by estimated variance post-fit.

### 4. Triple-barrier labeling
Event at t0: entry p_{t0}; horizon h; profit u>0; stop ℓ>0; side s∈{+1,−1}. Long barriers: p(1+u), p(1−ℓ). Log returns r_{t0,τ} = log(p_{t0+τ}/p_{t0}); side-adjusted r^{side} = s·r. Label: +1 if r^{side} ≥ u first; −1 if r^{side} ≤ −ℓ first; sign(r^{side}_{t0,h}) if neither touched by h. Same-bar touch → use intrabar H/L; closes-only → deterministic convention (adverse first) or exclude as ambiguous. Practical: intraday h 30min–2d; daily h 3–20d; u, ℓ 0.5–2.0 vol units; vol lookback 20–60 bars; usually u=ℓ or u:ℓ=1.5:1; event spacing 1–10 bars. Vol-scaled: u = c_u·σ̂_{t0}, ℓ = c_ℓ·σ̂_{t0}, σ̂ from data BEFORE t0 only.

### 5. Purged/embargoed CV
Event i: start t_i(0), end t_i(1) (first barrier hit or vertical), interval I_i = [t_i(0), t_i(1)]. Test fold interval I_test = [tmin, tmax]. PURGE: drop training events with I_i ∩ I_test ≠ ∅ (t_i(0) ≤ tmax AND t_i(1) ≥ tmin). EMBARGO: with N obs and embargo fraction e, L_E = ⌈eN⌉; typical: 0–1% short non-overlapping; 2–5% daily 5–10d horizons; 5–10% long horizons; 5–20% highly overlapping intraday. Set embargo ≥ max look-forward horizon (L_E ≥ max_i(t_i(1) − t_i(0))); use larger of % rule and horizon rule. Ref: López de Prado, AFML 2018.

## Q-SB3-3: Documented evidence — VERBATIM (key content)

Intraday coint pairs = very high published Sharpes possible but extremely spec/market/cost-sensitive. ETF-vs-basket = cleanest captured by APs/MMs/low-latency. News = first minute hardest; later drift exists but crowded. Meta-labeling = improves selection/sizing given REAL primary signal; cannot manufacture alpha.

NOT available today: long sample, favorable historical conditions, specific design, small/liquid historical universe, estimated costs, no modern crowding/borrow/latency/capacity. Original used 12-month formation + 6-month trading (alphaarchitect.com). Post-period: Do–Faff "Does Simple Pairs Trading Still Work?" → profitability declined over time [specific after-cost numbers didn't render — only "declining but still economically meaningful" summary captured] (econjournals.com). Crowding/decay: signal discovery, faster reaction, lower spreads, shorting friction, common-factor shocks, capacity, selection instability. **Underwriting for small liquid-large-cap op: expected net Sharpe ≈ 0.2–0.7** pre-tax, high uncertainty. Claimed net Sharpe >1 requires: point-in-time universe, delistings, realistic borrow, bid/ask execution, impact, no overlapping-label leakage, untouched OOS.
**(2) Intraday coint z-score pairs:** harder than daily (bid/ask bounce, latency, async prints, fragmentation, auctions, vol seasonality, temp OFI). Conservative underwriting: daily/slow intraday convergence Sharpe 0.2–0.8; 5–30-min liquid pairs 0.3–1.0; sub-minute high-turnover often unattractive after costs; Sharpe 2+ = exceptional, not base case. "Net Sharpe ≈ 0.5 already respectable." Failure: earnings, M&A, sector news, vol shocks, auctions, halts, one-leg liquidity loss, borrow recalls, microstructure changes, index rebalances. **(3) ETF-vs-basket/iNAV:** iNAV ≈ basket value; trade attractive only if discrepancy > creation/redemption fees + financing + impact + risk reserve. Captured by: APs, ETF MMs, prop firms, banks w/ creation access, cheap financing/securities lending, low-latency hedgers. iNAV ≠ free arb price: stale prices, closed foreign markets, wide-spread components, futures/swaps, corp actions, creation restrictions, different hours. **Creation-unit economics (VERIFIED): 50,000 shares × $100 = $5,000,000 notional; 5bps = 0.0005 → $2,500 gross/creation**, must cover ETF+basket execution, spreads, commissions/fees, borrow, financing, creation fee, ops, adverse basket-assembly drift, tracking error. "Most visible iNAV deviations are not monetizable after costs."
**(4) News first-minute:** effects: immediate discovery, delayed reaction, post-news drift, post-shock reversal. No universal first-minute drift number — varies by timestamp quality, embargo, source latency, liquidity, mkt cap, surprise, category, novelty, pre-move, execution delay. Liquid large-cap first-minute raw response often small. Decomposition: fast discovery (needs faster/better-classified feed) + microstructure + temporary impact. Half-lives: scheduled liquid news — minutes to tens of min (fastest); earnings drift — hours to sessions; slow attention/sentiment — days (low SNR, factor contamination). After-cost: raw headline maybe useful; 1–5min signal much weaker; after spread/slippage/adverse selection frequently ≈0 for mega-caps; less-liquid = bigger gross, much bigger execution/gap risk.
