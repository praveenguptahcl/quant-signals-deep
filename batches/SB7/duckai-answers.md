### 1. OU half-life estimation
S_t stationary spread, e.g. S_t = log P_t^(1) − β log P_t^(2). Continuous: dS_t = κ(μ−S_t)dt + σdW_t. Half-life t_{1/2} = ln2/κ. Discrete: ΔS_t = α + φS_{t−1} + ε_t; φ = e^{−κΔt} − 1; κ̂ = −ln(1+φ̂)/Δt; **t̂_{1/2} = −Δt·ln2/ln(1+φ̂)**, need −1<φ̂<0. OLS: φ̂ = Σ(S_{t−1}−S̄_L)(ΔS_t−ΔS̄)/Σ(S_{t−1}−S̄_L)²; α̂ = ΔS̄ − φ̂S̄_L; μ̂ = −α̂/φ̂.
Practical: regression window 60–250 daily / 500–5,000 intraday (100–150 starting); half-life <~2–3 obs often too fast to trade after costs; >~50–100 daily may = weak/unstable MR. "OU model does NOT determine the hedge ratio — estimate separately." (epchan.blogspot.com)

### 2. Kalman dynamic hedge ratio
y_t = μ_t + β_t x_t + ε_t, ε_t~N(0,R). State θ_t=[μ_t,β_t]ᵀ; H_t=[1,x_t]; y_t = H_tθ_t + ε_t. Random-walk evolution: θ_t = θ_{t−1} + η_t, η_t~N(0,Q), Q = diag(q_μ,q_β).
Recursion: predict θ̂_{t|t−1}=θ̂_{t−1|t−1}, P_{t|t−1}=P_{t−1|t−1}+Q; innovation e_t = y_t − H_tθ̂_{t|t−1}; F_t = H_tP_{t|t−1}H_tᵀ + R; update K_t = P_{t|t−1}H_tᵀF_t^{−1}; θ̂_{t|t}=θ̂_{t|t−1}+K_t e_t; P_{t|t}=(I−K_tH_t)P_{t|t−1}.
Estimated spread Ŝ_t = y_t − μ̂_t − β̂_t x_t. Innovation std √F_t. Signal: long if e_t < −c√F_t; short if e_t > c√F_t (c = 1.0–2.5); exit when innovation back inside 0.25–0.75√F_t (arbitragelab Kalman Filter docs).
Q/R scale-aware: R = Var(short-run regression residual); q_β = α_β·R/Var(x_t); α_β = 10^{−6}–10^{−3}/obs (10^{−4} reasonable start); q_μ = 0.1R–1.0R; R from 60–250-obs OLS; Q=0 = fixed model; raise Q on persistent OOS adaptation lag; or MLE/EM. Diagnostic λ_β = q_β·Var(x_t)/R: small = stable/slow, large = responsive/noisy (portfoliooptimizationbook.com 15.6).

### 3. Copula pairs trading
Marginals F_1, F_2; PIT: U_t = F_1(r_{1,t}), V_t = F_2(r_{2,t}), clipped at ε = 10^{−4}–10^{−2}. C joins: P(R_1≤r_1,R_2≤r_2) = C(U,V). Conditional: P(U≤u|V=v) = ∂C(u,v)/∂v. p_{1|2,t} = ∂C(u_t,v_t)/∂v; p_{2|1,t} = ∂C(u_t,v_t)/∂u.
Rule: buy 1/short 2 if p_{1|2,t} < p_L; short 1/buy 2 if > p_U (illustrative p_L=0.05, p_U=0.95, or 0.10/0.90); exit near 0.5. Mispricing score M_t = p_{1|2,t} − p_{2|1,t}; trade when |M_t| exceeds empirical threshold.
Families: Gaussian ρ∈(−1,1) — symmetric, no tails — baseline. Student-t ρ∈(−1,1), ν>2 — symmetric tail dependence — fat tails. Clayton θ>0 — lower-tail dependence — joint downside. Gumbel θ≥1 — upper-tail — joint upside. Frank θ∈ℝ\{0} — central dependence, weak tails — moderate. Rotated Clayton/Gumbel — opposite-tail — negative pairs.
Practical: marginal window 250–1,000; copula window 250–1,000 (500 daily reasonable); refit weekly/monthly; τ≈0 → weak signals; select family by rolling likelihood/AIC/BIC/OOS log-likelihood; Student-t ν = 4–30 (large ν → Gaussian).

### 4. Variance-ratio / Hurst regime test
r_t(k) = Σ_{j=0}^{k−1} r_{t−j}. Lo–MacKinlay: VR(k) = Var(r_t(k))/[k·Var(r_t)] (overlapping k-period returns, consistent variance calc). VR≈1 random walk; >1 momentum/persistence; <1 oscillation/MR. Z(k) = (VR(k)−1)/√Vâr[VR(k)] (hetero-robust preferred).
Hurst mapping: Var(r_t(k)) ∝ k^{2H} ⇒ Ĥ(k) = (1/2)[1 + lnVR(k)/lnk]. H≈0.5 RW; >0.5 persistence; <0.5 anti-persistence.
Regime horizons: k=2,4,8 short; 5,10,20 daily swing; 20,60 longer; rolling window 100–500 (illustrative); short-term: 250 obs, k∈{2,4,8,16}. "Single short sample can contradict across horizons — diagnostic, not standalone rule."

## Q-SB7-3: Documented evidence — VERBATIM (key content; no worked arithmetic)

**(1) OU half-life timing vs fixed z exits:** Fixed: z_t=(S_t−S̄_W)/s_W; enter |z|>z_entry, exit |z|<z_exit. OU: expected decay E[S_{t+h}−μ|S_t]=(S_t−μ)e^{−κh}; or prob of crossing exit boundary by horizon — distinguishes 2d vs 40d half-life pairs, lengthening half-lives, large-but-unlikely-to-revert deviations. Documented: supports half-life-aware holding/exit vs NAIVE fixed holding, NOT universal improvement over every optimized fixed-window z strategy. Benefit via: lower avg hold time, fewer slow/unstable-spread trades, better sizing, earlier broken-relationship abandonment, better turnover-adjusted perf. After-cost: gross improvement must beat round-trip spread + borrow + impact + financing + async-leg slippage. **(2) Kalman dynamic vs static OLS hedge:** Static OLS one fixed β̂; Kalman adaptive, lower turnover for static. **Documented after-cost: Kalman NOT automatically better. 2026 walk-forward study of 50 S&P 500 equities over unstable 2020–2024: negative net-of-cost fold-average Sharpe for ALL branches — static OLS ≈ −0.157 vs baseline Kalman ≈ −2.080. "Warning: dynamic estimation may improve hedge accuracy + drawdown while REDUCING net Sharpe via over-trading." Kalman advantage per other docs = no arbitrary rolling window + time-varying adaptation — methodological, not proof of after-cost superiority (arbitragelab). Kalman beats OLS when: β_t materially changes, genuine drifting relationship, low costs, posterior-uncertainty filter, OOS-calibrated Q, signals suppressed when forecast variance high. Loses when: stable β, noisy spread, Q too large, trades every small move, illiquid pair, borrow/shorting dominates. Report ΔNet Sharpe = NetSharpe_Kalman − NetSharpe_OLS + turnover, avg hold, max DD, β drift, gross/net P&L, multiple cost assumptions. **Production rule: "use Kalman only when estimated hedge-ratio drift exceeds the cost of adapting."**
**(3) Copula vs linear coint:** Copula adds when dependence nonlinear/asymmetric/tail-dependent, poorly represented by Pearson/Gaussian. **After-cost superiority evidence weak, sample-dependent.
